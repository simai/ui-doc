# Меню

Меню помогает перейти в другой раздел сайта или открыть группу вложенных
разделов. В SIMAI Framework это один компонент: его можно показать вертикально
в боковой панели или горизонтально в шапке.

## Когда использовать

Используйте Menu для навигации по сайту, разделу или личному кабинету. Для
команд, которые выполняются рядом с выбранным объектом, используйте
[Context Menu](/ru/smart-components/reference/context-menu/). Сложное меню
панели управления собирайте через
[Admin Menu](/ru/smart-components/reference/admin-menu/).

## Быстрый старт

Корневой список получает класс `sf-menu`, а каждый пункт — `sf-menu-item`.
Обычный пункт содержит ссылку. Если внутри пункта есть ещё один `sf-menu`,
Loader распознает ветку, добавит кнопку раскрытия и загрузит нужные стили и
JavaScript.

## Как выбрать вид меню

| Вид | Когда подходит | Как включить |
|:---|:---|:---|
| Вертикальное | Боковая панель, каталог, настройки | `sf-menu` |
| Горизонтальное | Основные разделы в шапке | `sf-menu sf-menu--horizontal` |
| Дерево документации | Многоуровневая навигация в документации | `sf-menu sf-menu--documentation-tree` |

Это варианты одного компонента. Создавать отдельный компонент для каждого
внешнего вида не нужно: структура пунктов и правила раскрытия остаются общими.

## Горизонтальное меню и подменю

Класс `sf-menu--horizontal` добавляется только к корневому списку. Его первый
уровень выстраивается в строку. Подменю первого уровня открывается вниз, а
следующие уровни — в сторону. Внутри все подменю остаются вертикальными.

Если подменю не помещается у края экрана, Framework раскрывает его в свободную
сторону. Открытие одного верхнего раздела закрывает соседний. Щелчок вне меню
закрывает открытую ветку.

:::

## Вложенные уровни

Подменю создаётся обычным вложенным списком `sf-menu`. Framework сам определяет
уровень и назначает классы от `sf-menu-element--level-1` до
`sf-menu-element--level-4`. Четырёх уровней достаточно для понятной навигации;
более глубокую структуру лучше разделить на несколько страниц или меню.

## Публичные классы и атрибуты

| Имя | Куда добавить | Что меняется |
|:---|:---|:---|
| `sf-menu` | `ul` | Создаёт вертикальный список меню |
| `sf-menu--horizontal` | Корневой `sf-menu` | Выстраивает первый уровень в строку |
| `sf-menu--documentation-tree` | Корневой `sf-menu` | Включает компактное дерево документации |
| `sf-menu-item` | `li` | Обозначает пункт меню |
| `sf-menu-element` | Ссылка или строка пункта | Оформляет кликабельную часть пункта |
| `open` или `expanded` | `sf-menu-item` с подменю | Показывает вложенный список |
| `disabled` | `sf-menu-item` с подменю | Запрещает раскрытие ветки |
| `icon="имя"` | `sf-menu-item` | Добавляет значок перед текстом |
| `trailing-icon="имя"` | `sf-menu-item` с подменю | Заменяет стандартную стрелку |
| `text="Текст"` | `sf-menu-item` | Явно задаёт подпись пункта |

Для текущей страницы добавьте ссылке `aria-current="page"`. Недоступную ссылку
лучше убрать из навигации. `disabled` нужен прежде всего для ветки, которую
временно нельзя раскрыть.

## Клавиатура и доступность

Оборачивайте меню в `nav` и задавайте понятное имя через `aria-label` или
`aria-labelledby`. Не добавляйте `role="menu"`: обычная навигация должна
сохранять привычное поведение списков и ссылок.

| Действие | Результат |
|:---|:---|
| `Enter` или `Пробел` на ветке | Открывает или закрывает подменю |
| `Escape` в горизонтальном меню | Закрывает текущую ветку и возвращает фокус на её кнопку |
| Щелчок вне горизонтального меню | Закрывает открытый верхний раздел |

Loader поддерживает `aria-expanded` и `aria-controls` в актуальном состоянии.
Если название ветки одновременно ведёт на страницу, оставьте ссылку и кнопку
раскрытия отдельными элементами: ссылка выполняет переход, кнопка показывает
подменю.

## Узкие экраны и направление текста

Горизонтальное меню рассчитано на строку в шапке и не переносит пункты на
несколько рядов. На телефоне показывайте тот же набор пунктов вертикально в
выдвижной панели. Меняется только представление; данные и порядок разделов
остаются теми же.

Положение подменю использует логические стороны. Поэтому в интерфейсе справа
налево направление раскрытия меняется автоматически.

## Ограничения и проверка

- Добавляйте `sf-menu--horizontal` только корневому списку.
- Не смешивайте в одном пункте несколько независимых кнопок раскрытия.
- Проверяйте длинные подписи и подменю у обоих краёв экрана.
- Проверяйте мышь, `Enter`, `Пробел`, `Escape`, телефон и направление справа
  налево.

Loader подключает Menu вместе с зависимостями Icons и Icon Buttons, когда
находит класс `sf-menu`. Публичные методы JavaScript компоненту не требуются:
состояние задаётся разметкой и поддерживается самим Framework.
