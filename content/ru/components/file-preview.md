# Предпросмотр файла

Компонент показывает выбранный или прикреплённый файл: его тип, имя, размер и
доступные действия. Он подходит для списков вложений и состояния файла перед
отправкой формы.

## Особенности применения

Имя файла должно оставаться доступным текстом. Действия оформляйте нативными
кнопками с доступными именами, а декоративные иконки скрывайте от экранного
диктора с помощью `aria-hidden="true"`.

## Недоступное состояние

Класс `disabled` обозначает файл, с которым временно нельзя взаимодействовать.
Недоступность действий дополнительно задавайте нативным атрибутом `disabled`.
