# Выпадающий список

Выпадающий список экономит место и позволяет выбрать значение из набора
вариантов.

## Пример

:::example {id="components/dropdown/overview" label="Результат"}
:::

## Особенности применения

Используйте понятную подпись и храните машинное значение в `data-value`.
Loader управляет раскрытием, выбором, клавиатурой и `aria-expanded`. Для
небольшого постоянно видимого набора лучше использовать radio или checkbox.

## Варианты оформления

`sf-dropdown--outlined` показывает границу, а `sf-dropdown--filled` — тональную
поверхность. `sf-dropdown--text` предназначен для одиночного текстового выбора.

:::example {id="components/dropdown/variants" label="Результат"}
:::

## Множественный выбор

`sf-dropdown--tag` отображает выбранные значения тегами. Для множественного
выбора добавьте `data-multiple="true"` и скрытое поле для отправки значения.

:::example {id="components/dropdown/tags" label="Результат"}
:::

## Размеры

Доступны размеры `1`, `2` и `3`. Выбирайте размер по плотности формы.

:::example {id="components/dropdown/sizes" label="Результат"}
:::

## Состояния

Выбранный пункт получает `selected`, недоступный пункт или весь список —
`disabled`.
