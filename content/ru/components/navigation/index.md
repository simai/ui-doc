# Навигация и процесс

Навигация переводит человека к другому месту или части страницы. Выберите компонент по тому, куда и как он ведёт.

| Задача | Что брать |
|:---|:---|
| Переход по тексту | [Ссылка](/ru/components/navigation/link/) |
| Путь от корня сайта до текущей страницы | [Хлебные крошки](/ru/components/navigation/breadcrumbs/) |
| Разделы сайта или приложения | [Меню](/ru/components/navigation/menu/) |
| Части длинного списка | [Пагинация](/ru/components/navigation/pagination/) |
| Соседние разделы одного экрана | [Вкладки](/ru/components/navigation/tabs/) |
| Значение или действие из скрытого списка | [Выпадающий список](/ru/components/navigation/dropdown/) |
| Действия над выбранным объектом | [Контекстное меню](/ru/components/navigation/context-menu/) |
| Вложенная иерархия | [Дерево](/ru/components/navigation/tree/) |
| Этапы процесса и текущий шаг | [Шаги](/ru/components/navigation/step/) |

## Все компоненты раздела

- **[Ссылка](/ru/components/navigation/link/)** — текстовый переход, в том числе с иконкой и недоступным состоянием.
- **[Хлебные крошки](/ru/components/navigation/breadcrumbs/)** — путь пользователя в иерархии сайта или приложения.
- **[Меню](/ru/components/navigation/menu/)** — список навигационных ссылок и действий.
- **[Пагинация](/ru/components/navigation/pagination/)** — переход между частями длинного списка.
- **[Вкладки](/ru/components/navigation/tabs/)** — переключение между связанными разделами содержимого.
- **[Вкладка](/ru/components/navigation/tab/)** — отдельный элемент навигации внутри набора вкладок.
- **[Выпадающий список](/ru/components/navigation/dropdown/)** — выбор значения или действия из скрытого списка.
- **[Контекстное меню](/ru/components/navigation/context-menu/)** — действия, связанные с выбранным объектом или областью.
- **[Дерево](/ru/components/navigation/tree/)** — навигация по вложенной иерархии.
- **[Элемент дерева](/ru/components/navigation/tree-item/)** — отдельный узел иерархической навигации.
- **[Шаги](/ru/components/navigation/step/)** — последовательность этапов и текущий прогресс пользователя.
