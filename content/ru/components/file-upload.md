# Загрузка файла

Компонент открывает системный выбор файлов, поддерживает drag-and-drop и
показывает список выбранных файлов с ходом загрузки.

:::

## Особенности применения

Указывайте допустимые форматы через `accept`, множественный выбор — атрибутом
`multiple`. Ограничения размера и формата должны проверяться повторно на
сервере. После выбора компонент отправляет событие `sf-file-upload:change`.

## Размеры

Доступны размеры `1/3`, `1/2`, `1`, `2` и `3`.

:::example {id="components/file-upload/sizes" label="Результат"}
:::

## Состояния загрузки

Файл может загружаться, завершиться успешно или завершиться ошибкой. Для этих
состояний используются `process`, `done` и `error`.

:::example {id="components/file-upload/progress" label="Результат"}
:::

## Недоступное состояние

Класс `disabled` отключает выбор и перенос файлов.
