# Основа Admin Menu

`component.admin-menu` — служебная визуальная основа составного
[Smart Admin Menu](/ru/smart-components/composite/admin-menu/). Она сохраняется
для совместимости и документирования низкоуровневого контракта, но не считается
самостоятельным пользовательским компонентом. Для обычного списка команд или
ссылок используйте компонент «Меню».

## Особенности применения

Прямое использование оправдано только при разработке или диагностике визуального
слоя Smart-компонента. Текущий раздел отмечайте классом `active` и атрибутом
`aria-current="page"`. Поиск, пользовательские настройки, сохранение состояния
и объединение зависимых интерактивных элементов принадлежат Smart Admin Menu.

В контейнере с естественной высотой все пункты остаются видимыми. Если оболочка
приложения ограничивает высоту, компонент автоматически оставляет доступные
пункты и добавляет действие для показа остальных.

## Вложенный раздел

Основная и вложенная панели используют одну структуру пунктов. Кнопка перехода
должна сообщать, что открывает следующий уровень.

## Ограниченная высота

В полноэкранной административной оболочке меню может занимать только доступную
высоту. Задайте высоту окружающему контейнеру системной утилитой и растяните
меню с панелью через `h-full`: компонент сам определит переполнение и покажет
действие для остальных пунктов.
