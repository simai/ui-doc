# Теги

Тег показывает категорию, фильтр, выбранное значение или компактный статус.

## Пример

:::example {id="components/tags/overview" label="Результат"}
:::

## Особенности применения

Кликабельный тег получает подходящую роль и клавиатурное управление. Для
удаляемого значения используйте отдельную кнопку закрытия с доступным именем.

## Типы содержимого

Тег может содержать checkbox, иконку, цвет или аватар. Все опубликованные типы
используют размер `1`.

:::example {id="components/tags/types" label="Результат"}
:::
