# Модальное окно

Модальное окно временно переводит пользователя к одной важной задаче, не уводя
с текущей страницы.

## Когда использовать

Используйте модальное окно для короткого подтверждения, компактной формы или
задачи, которую нужно завершить перед возвратом к странице. Для длинного
самостоятельного процесса лучше отдельная страница, а для необязательной
подсказки — tooltip или раскрываемая область.

## Поведение

Экземпляр `Modal` создаётся после `SF.Loader.ready('Modal', callback)`. Метод
`render()` добавляет окно, `open()` открывает его, а элементы с
`data-sf-modal-close="<id>"` закрывают соответствующий экземпляр.

Поддерживаются центральное окно и позиции `left`, `right`, `top`, `bottom`, а
также управление закрытием по Escape и клику по overlay. Отключайте эти способы
только когда пользователь обязан принять осознанное решение и всегда оставляйте
видимую кнопку выхода.

## Доступность

- заголовок должен точно называть задачу;
- после открытия фокус переносится внутрь, после закрытия возвращается к
  инициатору;
- фон не должен попадать в порядок клавиатурного обхода;
- Escape закрывает обычное окно;
- основное и отменяющее действие имеют однозначные подписи.

## Справочник

| Назначение | Контракт |
| --- | --- |
| Корень | `sf-modal` |
| Поверхность | `sf-modal-surface` |
| Заголовок | `sf-modal-header` |
| Кнопка закрытия | `sf-modal-close-button` |
| Loader ID | `modal` |
| JavaScript class | `Modal` |

Компонент зависит от blur-utility для вариантов размытия overlay; базовое окно
работает без ручного подключения файлов.
