# Модальное окно

Модальное окно временно переводит пользователя к одной важной задаче, не уводя
с текущей страницы.

## Особенности применения

Создавайте экземпляр `Modal` после готовности компонента. Метод `render()`
добавляет окно в документ, `open()` открывает его, а элемент с
`data-sf-modal-close="<id>"` закрывает соответствующее окно. Для длинного
самостоятельного процесса лучше использовать отдельную страницу.

## Положение

Параметр `position` размещает поверхность по центру или у одного из краёв:
`center`, `left`, `right`, `top`, `bottom`.

## Закрытие и блокирующий режим

По умолчанию обычное окно закрывается по Escape, клику по фону и собственной
кнопке закрытия. Параметр `unclose` отключает эти способы для обязательного
решения; в таком окне предусмотрите явные и однозначные действия внутри
содержимого.
