# Группа кнопок

Группа объединяет несколько связанных действий в один компактный элемент.
Framework соединяет соседние кнопки, сохраняет внешнее скругление и выделяет
активный сегмент поверх общей границы.

## Особенности применения

Используйте группу только для связанных действий или вариантов одного выбора.
Контейнеру задавайте доступное имя через `aria-label` или `aria-labelledby`, а
выбранной переключаемой кнопке — `aria-pressed="true"`. Скрипт Framework сам
добавляет контейнеру роль `group`, ориентацию и служебные классы сегментов.

## Вертикальная группа

Для вертикального расположения задайте контейнеру
`aria-orientation="vertical"`. Кнопки займут общую ширину группы и сохранят
один внешний контур.
