# Группа кнопок

Группа объединяет связанные действия в один визуальный элемент и автоматически
формирует внешние и внутренние скругления кнопок.

## Когда использовать

- для компактного выбора одного режима представления;
- для небольшой группы равноправных действий;
- для вертикального набора связанных команд в узкой области.

Не объединяйте несвязанные действия только ради экономии места. Для выбора
одного значения формы используйте radio, если группа должна отправляться вместе
с формой.

## Варианты

По умолчанию группа горизонтальная. Для вертикального расположения добавьте
`aria-orientation="vertical"`. Компонент сам назначает сегменты первому,
средним и последнему элементам.

Активное значение обозначайте не только оформлением: используйте
`aria-pressed="true"` для переключаемой кнопки.

## Доступность

- задайте контейнеру `role="group"` и доступное имя через `aria-label` или
  `aria-labelledby`;
- сохраняйте логичный порядок кнопок в DOM;
- не удаляйте видимый focus;
- для группы выбора синхронизируйте `aria-pressed` с фактическим состоянием.

## Справочник

| Назначение | Контракт |
| --- | --- |
| Контейнер | `sf-button-group` |
| Элементы | `sf-button` или `<sf-button>` |
| Ориентация | `aria-orientation="horizontal|vertical"` |
| Loader ID | `button-group` |

Компонент работает совместно с [кнопками](/ru/components/buttons/), но является
отдельным публичным контрактом.
