# Кнопки

Кнопка запускает действие: сохраняет изменения, отправляет форму или подтверждает
выбор. Базовая кнопка использует основной вариант, цветовую схему `primary` и
размер `1`.

## Особенности применения

Используйте нативный элемент `<button>`. Для обычного действия задавайте
`type="button"`, для отправки формы — `type="submit"`, для сброса —
`type="reset"`. У кнопки должна быть понятная видимая подпись, а у кнопки без
текста — доступное имя через `aria-label`.

## Варианты оформления

Framework поддерживает четыре варианта: основной `default`, мягкий `tonal`,
контурный `outline` и текстовый `link`. Для них доступны только предусмотренные
исходными стилями сочетания с цветовыми схемами `primary`, `secondary` и
`on-surface`.

## Размеры

Размеры `1/3`, `1/2`, `1`, `2` и `3` меняют высоту, отступы, текст и иконки как
единый элемент управления. Размер `1` используется по умолчанию.

:::

## Иконки

Иконку можно разместить перед подписью или после неё. Декоративная иконка не
должна повторяться в доступном имени кнопки, поэтому в обычной HTML-разметке ей
задают `aria-hidden="true"`.

:::example {id="components/buttons/icons" label="Результат"}
:::

## Состояния

Для выбранной кнопки используется класс `active`, для недоступной — нативный
атрибут `disabled`. Состояние загрузки обозначается классами `loading` и
`sf-button-state-loading` вместе с `aria-busy="true"`.

:::example {id="components/buttons/states" label="Результат"}
:::

## Плотность

Модификаторы `tightness-low`, `tightness-high` и `tightness-highest` меняют
вертикальные отступы, не затрагивая выбранный размер текста.

:::example {id="components/buttons/tightness" label="Результат"}
:::

## Скругление

Без модификатора кнопка использует системный радиус компактных элементов
управления `--sf-radius--ui`. Обычно его менять не нужно. Модификатор
`radius-square` явно убирает скругление, а `radius-rounded` делает края
полностью округлыми. Радиус крупных поверхностей `--sf-radius-default` не
является штатной вариацией кнопки.

:::
