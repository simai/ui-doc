# Кнопки

Кнопка запускает действие: сохраняет изменения, отправляет форму или подтверждает
выбор. Используйте нативный `<button>` с базовым классом `sf-button`, вариантом,
цветовой схемой и размером.

## Быстрый старт

:::example {id="components/buttons/basic" label="Базовая кнопка"}
:::

`type="button"` защищает кнопку от случайной отправки формы. Для основной
кнопки формы используйте `type="submit"`, а для сброса — `type="reset"`.

## Публичные классы

| Задача | Классы |
|:---|:---|
| Основа | `sf-button`, `sf-button-text-container` |
| Вариант | `sf-button--default`, `sf-button--tonal`, `sf-button--outline`, `sf-button--link` |
| Схема | `sf-button--primary`, `sf-button--secondary`, `sf-button--on-surface` |
| Размер | `sf-button--size-1/3`, `sf-button--size-1/2`, `sf-button--size-1`, `sf-button--size-2`, `sf-button--size-3` |
| Состояние | `active`, `loading`, `sf-button-state-loading` |
| Плотность | `tightness-low`, `tightness-high`, `tightness-highest` |
| Радиус | `radius-default`, `radius-square`, `radius-rounded` |
| Сегмент | `segment-start`, `segment-middle`, `segment-end` |

Loader обнаруживает компонент по классу `sf-button` и точечно подключает его
CSS и JavaScript. Не подключайте полный набор компонентов вручную.

## Варианты оформления

Framework поддерживает четыре варианта: основной `default`, мягкий `tonal`,
контурный `outline` и текстовый `link`. Используйте только сочетания, которые
есть в примере и CSS: не каждая схема выпущена для каждого варианта.

## Размеры

Размеры `1/3`, `1/2`, `1`, `2` и `3` согласованно меняют высоту, внутренние
отступы, текст и иконку. Размер `1` — основной для форм и панелей.

## Иконки

Иконку можно разместить перед подписью или после неё. Декоративной иконке
задавайте `aria-hidden="true"`. Если видимого текста нет, используйте компонент
кнопки с иконкой и обязательно задайте доступное имя через `aria-label`.

## Состояния

| Состояние | Разметка | Правило |
|:---|:---|:---|
| Нажатая toggle-кнопка | `active` и `aria-pressed="true"` | Доступное имя не меняется при переключении |
| Недоступная | нативный `disabled` | Кнопка не получает фокус и не запускает действие |
| Загрузка | `loading sf-button-state-loading`, `aria-busy="true"`, `disabled` | Повторный запуск блокируется до завершения |

:::example {id="components/buttons/states" label="Состояния кнопок"}
:::

Анимация загрузки использует motion-токены Framework и отключается при
`prefers-reduced-motion`.

## Плотность, радиус и сегменты

Плотность меняет вертикальные отступы, не подменяя выбранный размер. Обычная
кнопка использует системный UI-радиус; `radius-square` убирает скругление, а
`radius-rounded` делает края полностью округлыми.

:::

:::example {id="components/buttons/radius" label="Радиус кнопок"}

Классы `segment-start`, `segment-middle` и `segment-end` предназначены для
соседних кнопок одного составного элемента. Не используйте их вместо
семантической группы: связанный выбор должен иметь общее доступное имя.

## Формы и доступность

- Видимая подпись должна описывать результат действия: «Сохранить», а не «Да».
- Для toggle-кнопки используйте `aria-pressed`; для перехода — ссылку `<a>`.
- Не имитируйте `disabled` только цветом или классом.
- После асинхронного действия сообщите результат рядом с кнопкой или через
  подходящую область статуса.

## Responsive и LTR/RTL

Сам компонент не выпускает responsive-модификаторы. Для расположения кнопок
используйте responsive-утилиты контейнера. Иконки «до» и «после» задавайте
порядком элементов в разметке; логические отступы Framework зеркалятся в RTL.

## Ограничения и проверка

- Компонент не управляет запросом и не снимает `loading` автоматически.
- Пара `active` + `aria-pressed` нужна только настоящему переключателю.
- Проверьте Enter и Space, видимый фокус, disabled/loading, светлую и тёмную
  темы, мобильную ширину и LTR/RTL.
