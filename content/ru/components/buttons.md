# Кнопки

Кнопка запускает действие: сохраняет изменения, отправляет форму или подтверждает
выбор. Используйте нативный `<button>` с базовым классом `sf-button`, вариантом,
цветовой схемой и размером.

## Когда использовать

| Задача | Элемент |
|:---|:---|
| Запустить действие на текущей странице | Кнопка `<button>` |
| Перейти на другую страницу или к разделу | Ссылка `<a>` |
| Показать действие только иконкой | [Кнопка с иконкой](/ru/components/icon-buttons/) с доступным именем |
| Включать и выключать один параметр | Кнопка-переключатель с `aria-pressed` |

Не заменяйте ссылку кнопкой только ради внешнего вида: правильный HTML-элемент
сохраняет ожидаемую работу клавиатуры, браузера и вспомогательных технологий.

`type="button"` защищает кнопку от случайной отправки формы. Для основной
кнопки формы используйте `type="submit"`, а для сброса — `type="reset"`.

## Состав кнопки

Минимальная разметка состоит из двух обязательных частей:

1. Нативный `<button>` с классами варианта, схемы и размера.
2. `<span class="sf-button-text-container">` с видимой подписью.

Иконка с классом `sf-icon` добавляется до или после контейнера подписи. Базовый
класс `sf-button` служит также маркером для Loader: по нему подключаются CSS и
JavaScript только этого компонента.

## Публичные классы

| Задача | Классы |
|:---|:---|
| Основа | `sf-button`, `sf-button-text-container` |
| Вариант | `sf-button--default`, `sf-button--tonal`, `sf-button--outline`, `sf-button--link` |
| Схема | `sf-button--primary`, `sf-button--secondary`, `sf-button--on-surface` |
| Размер | `sf-button--size-1/3`, `sf-button--size-1/2`, `sf-button--size-1`, `sf-button--size-2`, `sf-button--size-3` |
| Состояние | `active`, `loading`, `sf-button-state-loading` |
| Плотность | `tightness-low`, `tightness-high`, `tightness-highest` |
| Радиус | `radius-default`, `radius-square`, `radius-rounded` |
| Сегмент | `segment-start`, `segment-middle`, `segment-end` |

## Варианты оформления

SIMAI Framework поддерживает четыре варианта. Для каждого из них выпущены только
указанные ниже цветовые схемы.

| Вариант | Допустимые схемы | Когда применять |
|:---|:---|:---|
| `default` | `primary`, `on-surface` | Главное или заметное действие |
| `tonal` | `secondary`, `on-surface` | Второстепенное действие без контура |
| `outline` | `primary`, `on-surface` | Второстепенное действие с контуром |
| `link` | `primary`, `on-surface` | Малозаметное действие без заливки |

Например, сочетание `sf-button--tonal sf-button--primary` не входит в
поставляемые стили и не должно использоваться.

## Размеры

Размеры `1/3`, `1/2`, `1`, `2` и `3` согласованно меняют высоту, внутренние
отступы, текст и иконку. Размер `1` — основной для форм и панелей.

## Иконки

Иконку можно разместить перед подписью или после неё. Декоративной иконке
задавайте `aria-hidden="true"`. Если видимого текста нет, используйте компонент
кнопки с иконкой и обязательно задайте доступное имя через `aria-label`.

## Состояния

| Состояние | Разметка | Правило |
|:---|:---|:---|
| Нажатая кнопка-переключатель | `active` и `aria-pressed="true"` | Доступное имя не меняется при переключении |
| Недоступная | нативный `disabled` | Кнопка не получает фокус и не запускает действие |
| Загрузка | `loading sf-button-state-loading`, `aria-busy="true"`, `disabled` | Повторный запуск блокируется до завершения |

:::example {id="components/buttons/states" label="Состояния кнопок"}
:::

Классы показывают состояние, но не управляют запросом. Приложение само добавляет
их перед началом операции, снимает после завершения и сообщает пользователю
результат.

## Плотность, радиус и сегменты

Плотность меняет вертикальные отступы, не подменяя выбранный размер. Обычная
кнопка использует системный UI-радиус; `radius-square` убирает скругление, а
`radius-rounded` делает края полностью округлыми.

## Формы и доступность

- Видимая подпись должна описывать результат действия: «Сохранить», а не «Да».
- Для кнопки-переключателя используйте `aria-pressed`; для перехода — ссылку `<a>`.
- Не имитируйте `disabled` только цветом или классом.
- После асинхронного действия сообщите результат рядом с кнопкой или через
  подходящую область статуса.

## Узкие экраны и направление текста

У самого компонента нет модификаторов для разных ширин экрана. Перенос,
растягивание и расположение кнопок задавайте утилитами контейнера. Иконки «до» и
«после» располагайте в соответствующем порядке в HTML. Логические отступы и
края сегментов SIMAI Framework зеркалит для письма справа налево (RTL).

## Ограничения и проверка

- Компонент не управляет запросом и не снимает `loading` автоматически.
- В текущем CSS полосы загрузки не отключаются автоматически при системной
  настройке уменьшения движения. Не используйте анимацию как единственный
  признак загрузки: сохраняйте текст и `aria-busy="true"`.
- Пара `active` + `aria-pressed` нужна только настоящему переключателю.
- Проверьте Enter и пробел, видимый фокус, недоступность и загрузку, светлую и
  тёмную темы, узкий экран и оба направления текста.
