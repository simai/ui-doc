# Карусель

Карусель показывает материалы по одному маршруту перелистывания и использует
Swiper для навигации и пагинации.

## Особенности применения

Не помещайте в скрытые слайды информацию, без которой нельзя завершить основную
задачу. Кнопки должны иметь доступные имена, а текущий слайд — понятный статус.

## Оформление навигации

Для переключателей доступны основной, вторичный, inverse и surface-варианты;
пагинация поддерживает обычный и увеличенный размер.
