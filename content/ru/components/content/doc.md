# Документ

и демонстрационных поверхностей в технической документации.

## Особенности применения

Это служебный компонент документации. Для карточек файлов и документов в
прикладном интерфейсе используйте семантическую разметку, поверхности и обычные
компоненты действий.

Компонент не содержит JavaScript. Подсветкой кода управляет Highlight, копированием — Clipboard.
