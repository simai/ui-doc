# Документ

Компонент оформляет служебные поверхности технической документации:
область примера, исходный код под ней, вводный абзац и фоны для показа
прозрачности. Берите его для страниц документации и витрин компонентов; для
карточек документов в прикладном интерфейсе нужны обычные поверхности и
компоненты действий.

## Разметка

Минимальную разметку показывает пример выше: блок `sf-doc-example` с
содержимым примера. Классы компонента независимы, и каждый ставится на свой
элемент:

- `sf-doc-example` — область примера: заливка, граница, радиус поверхности
  и внутренний отступ. Если перед ней есть содержимое, она получает отступ
  сверху.
- `sf-doc-pair` — обёртка пары «пример и исходник»: не даёт содержимому
  выйти за ширину колонки.
- `sf-doc-source` — блок исходного кода на тёмной поверхности с прокруткой.
- `sf-doc-lead` — вводный абзац.
- `sf-doc-checkerboard` и `sf-doc-stripes` — служебные фоны.
- `sf-doc-code` — моноширинный шрифт для встроенного фрагмента кода, как у
  элемента `code`.

У компонента нет своего JavaScript: подсветку кода выполняет
[Highlight](/ru/components/content/highlight/), копирование —
[Clipboard](/ru/components/actions/clipboard/).

## Варианты

### Вводный текст

`sf-doc-lead` набирает абзац крупным текстом второстепенного цвета: так
выделяют назначение раздела перед подробным содержимым.

:::example {id="components/doc/lead" label="Вводный абзац"}
:::

### Результат и исходник

В `sf-doc-pair` за `sf-doc-example` следует `<pre class="sf-doc-source">`:
нижние углы примера и верхние углы исходника становятся прямыми, и два
блока читаются как одно целое.

:::example {id="components/doc/source-pair" label="Пример и исходник"}
:::

### Служебный фон

`sf-doc-checkerboard` — шахматный фон, на котором видна прозрачность
изображения или цвета; `sf-doc-stripes` — полосатый фон, который отмечает
служебную или пустую область. Оба фона строятся из ступеней поверхности и
читаются в обеих темах.

:::example {id="components/doc/patterns" label="Шахматный и полосатый фон"}
:::

## Доступность

- Компонент только оформляет: заголовки, подписи и порядок чтения задаёт
  разметка страницы.
- Длинный исходник прокручивается внутри блока; дайте ему видимую подпись
  или заголовок, если на странице несколько примеров.
- Служебный фон декоративный: не передавайте им смысл, который нужно
  прочитать.
- В режиме высокой контрастности области и фоны получают рамку системного
  цвета текста, а узор заменяется системным фоном.

## Классы

| Что | Классы |
|:---|:---|
| Части | `sf-doc-checkerboard`, `sf-doc-code`, `sf-doc-example`, `sf-doc-lead`, `sf-doc-pair`, `sf-doc-source`, `sf-doc-stripes` |

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Переменные

Компонент читает свои переменные, а модификаторы задают им значения. Чтобы изменить вид, задайте переменную на элементе или в своём слое для всего проекта — CSS компонента менять не нужно. Значение по умолчанию — из базового правила блока (`.sf-doc`); переменную без него задают только модификаторы. Какие переменные публичный контракт, а какие служебные, Framework ещё уточняет.

| Переменная | По умолчанию | Задаёт |
|:---|:---|:---|
| `--sf-doc-pattern-color` | не задана; задают модификаторы, например `.sf-doc-stripes`: `var(--sf-surface-1)` | `background-image` |
