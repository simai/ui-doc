# Флаг

:badge[sf-flag]{variant=outline scheme=on-surface size=1/2} :badge[1.3.0]{variant=outline scheme=on-surface size=1/2}

Флаг показывает страну картинкой: в телефонном поле, списке стран, рядом с
ценой или адресом. Берите его вместо флага-эмодзи: эмодзи рисует системный
шрифт, и в одних системах флаг выглядит иначе, а в других (Windows) вместо
него стоят две буквы. Картинки набора выглядят одинаково везде.

## Разметка

Минимальную разметку показывает пример выше: пустой
`<span class="sf-flag sf-flag--rect" data-country="ru">`.

- `data-country` — код страны из двух букв по ISO 3166-1 alpha-2, регистр не
  важен. Скрипт вставляет в элемент картинку `<img>`.
- Класс формы `sf-flag--rect` или `sf-flag--circle` выбирает файл набора и
  пропорции; без него скрипт берёт прямоугольник.
- `data-alt` задаёт картинке текстовую альтернативу; без него флаг
  декоративный (см. «Доступность»).
- `data-lazy="false"` загружает файл сразу. По умолчанию файл грузится,
  когда флаг подходит к экрану: длинный список стран не тянет все файлы
  ради видимых.
- `data-flag-base` на элементе или любом предке задаёт свой набор. Он
  повторяет раскладку набора Framework: `<база>/rect/<код>.svg`,
  `<база>/circle/<код>.svg` и `<база>/index.json` со списками кодов каждой
  формы. Без атрибута путь берётся из рантайма Framework.

## Варианты

### Форма

`sf-flag--rect`, `sf-flag--circle` • [справочник](#классы)

`sf-flag--rect` — прямоугольник 28×20, форма по умолчанию для полей,
списков и таблиц. `sf-flag--circle` — круг 24×24 рядом с аватарами, где
важнее общая форма. Круглый флаг — отдельный рисунок, а не обрезанный
прямоугольник: у Непала сохраняется форма полотнища, у Сингапура — полумесяц
со звёздами. Поэтому форму выбирает класс, а не `border-radius`. Если у кода
нет файла нужной формы, скрипт показывает другую форму и меняет класс.

В каждой форме набора 247 кодов. 37 из них построены из
[flag-icons](https://github.com/lipis/flag-icons) (лицензия MIT) и приведены
к палитре набора; их круглые версии вырезаны из прямоугольных. Уведомление
об авторстве лежит в `flags/index.json` компонента.

:::example {id="components/flag/shapes" label="Прямоугольный и круглый флаг"}
:::

### Размер

Высоту задаёт публичная переменная `--sf-flag-size`, ширина считается из
неё по пропорциям формы. По умолчанию прямоугольный флаг высотой со строку
текста ступени 1/2 (20 px, на телефоне и в компактной области 16), круглый —
со строку ступени 1 (24 px и 20). Свой размер берите из ступеней линейки,
например `var(--sf-text-height-1)`, и задайте переменную на элементе или в
своём слое. Прежнее имя `--sf-flag--size` ещё читается.

## Состояния

### Без картинки

Пока файл не загружен или код не задан, элемент держит размер и показывает
нейтральную подложку: строка не прыгает, когда картинка приходит.

## Доступность

- Без `data-alt` картинка получает `aria-hidden="true"` и пустой `alt`:
  экранный диктор её пропускает. Так правильно, когда название страны или
  код написаны рядом.
- `data-alt` с названием страны задавайте, только если картинка несёт смысл
  сама, например рядом с телефонным кодом.
- Флаг обозначает страну, а не язык: у одного языка много стран, в одной
  стране бывает несколько языков. Рядом с флагом пишите название страны, а в
  переключателе языка — название языка на этом языке (`lang` на подписи).
- Скругление и тонкая рамка следуют теме: рамка цвета
  `--sf-outline-variant` не даёт белым флагам слиться со страницей.

## JavaScript

Скрипт подключает флаги при загрузке страницы и флаги, добавленные позже.
Объект `SF.Flag` появляется вместе со скриптом компонента; Loader подключает
его, когда находит на странице `.sf-flag`. Событий компонент не отправляет.

- `SF.Flag.render(element)` — перерисовывает флаг. Смену `data-country` или
  формы скрипт сам не отслеживает: после неё вызовите `render`.
- `SF.Flag.mount(element)` и `SF.Flag.mountAll(root)` — подключают флаг или
  все флаги внутри `root` с учётом ленивой загрузки.

Имя `SF.flag` указывает на тот же объект.

```js
const flag = document.querySelector('#phone-country');
flag.dataset.country = 'de';
SF.Flag.render(flag);
```

## Переменные

### Настройка

Эти переменные — поверхность настройки компонента. Их имена стабильны: переименовать или убрать такую переменную можно только через журнал изменений, с предупреждением, как атрибут. Framework их не задаёт, поэтому значение можно поставить на сам компонент (`.sf-flag`) или на любого предка. Переменные действуют на спокойный вид; наведение, фокус, нажатие, недоступность и ошибка рисуются поверх, поэтому состояния остаются видны.

| Переменная | Что задаёт | По умолчанию |
|:---|:---|:---|
| `--sf-flag-size` | Высота флага, длина с лестницы (var(--sf-icon-size-3)); ширина следует пропорции формы. По умолчанию — собственный размер рисунка: 20 у прямоугольника (28×20), 24 у круга. | `var(--sf-icon-size-2)` |
| `--sf-flag-radius` | Радиус углов прямоугольника; круг остаётся круглым, если переменная не задана. | `var(--sf-radius--ui)` |
| `--sf-flag-outline-color` | Тонкая линия, которая отделяет белый флаг от белой страницы. | `var(--sf-outline-variant)` |
| `--sf-flag-outline-width` | Толщина этой линии, рисуется внутри края картинки. | `var(--sf-px)` |
| `--sf-flag-placeholder-color` | Заливка, которая держит место флага, пока его файл ещё грузится. | `var(--sf-surface-container)` |

```css
.sf-flag {
  --sf-flag-radius: 0;
}
```

### Устройство

Остальные переменные — внутренняя проводка компонента: модификаторы задают им значения, а части их читают. Их имена и устройство могут меняться в любом выпуске, поэтому проект их не задаёт. Значение по умолчанию — из базового правила блока (`.sf-flag`); переменную без него задают только модификаторы.

| Переменная | По умолчанию | Задаёт |
|:---|:---|:---|
| `--sf-flag--default-size` | не задана; задают модификаторы, например `.sf-flag--circle`: `var(--sf-text-height-1)` | `--sf-flag--height` |
| `--sf-flag--height` | `var(--sf-flag-size, var(--sf-flag--size, var(--sf-flag--default-size, var(--sf-text-height-1/2))))` | `vertical-align`, `height`, `block-size`, `width`, `inline-size` |
| `--sf-flag--outline-color` | `var(--sf-flag-outline-color, var(--sf-outline-variant))` | `outline` |
| `--sf-flag--outline-width` | `var(--sf-flag-outline-width, var(--sf-px))` | `outline`, `outline-offset` |
| `--sf-flag--radius` | `var(--sf-flag-radius, var(--sf-radius--ui))` | `border-radius` |
