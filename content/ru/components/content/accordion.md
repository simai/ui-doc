# Аккордеон

Аккордеон раскрывает и скрывает разделы содержимого под их заголовками.
Берите его, чтобы сократить длинную страницу с независимыми разделами —
вопросы и ответы, подробности, настройки, — не теряя структуры заголовков.
Критическое сообщение и единственный следующий шаг в аккордеон не прячьте.

## Разметка

Минимальную разметку показывает пример выше. Части вложены так:
`article.sf-accordion` → заголовок `sf-accordion-heading` → кнопка
`sf-accordion-trigger` с подписью `sf-accordion-title` и иконкой `sf-icon`,
затем панель `sf-accordion-content`.

- Заголовок — настоящий `<h2>`…`<h6>` того уровня, который нужен структуре
  страницы; CSS снимает с него отступы и начертание.
- Кнопка — нативный `<button type="button">` с `aria-expanded`. Скрипт
  связывает её с панелью: ставит `id`, `aria-controls`, а панели с
  `role="region"` — `aria-labelledby`.
- Закрытая панель получает атрибут `hidden` и класс `hidden`; открытая — без
  них. Начальное состояние задаёт разметка, дальше его ведёт скрипт.
- Иконку `sf-icon` скрипт заполняет сам: `chevron_right` или, у варианта с
  плюсом, `add` и `remove`.
- Скрипт подключает аккордеоны при загрузке страницы и вставленные позже.
  Разметку без кнопки `sf-accordion-trigger` он делает кликабельной целиком
  и ставит ей класс `sf-accordion--legacy`; писать его вручную не нужно.

## Варианты

### Поверхность

Без модификатора аккордеон — самостоятельная карточка с заливкой.
`sf-accordion--outline` оставляет фон прозрачным и обводит раздел контуром —
для аккордеона на уже заданной поверхности. `sf-accordion--flush` убирает
фон и скругление и оставляет только разделитель снизу — для плотных списков
внутри общего контейнера.

:::example {id="components/accordion/appearance" label="Поверхности аккордеона"}
:::

### Размер

Без класса размера у заголовка просторный отступ для страниц с текстом. В
плотном интерфейсе — в панели свойств или боковой колонке — поставьте
аккордеон на лестницу размеров классом `sf-accordion--size-1/3`,
`sf-accordion--size-1/2`, `sf-accordion--size-1`, `sf-accordion--size-2` или
`sf-accordion--size-3` на каждом `.sf-accordion`:

- заголовок ровно высотой с элемент управления этого размера — с поле или
  кнопку рядом — и растёт, только если длинный заголовок переносится;
- заголовок берёт кегль и высоту строки своего размера, шеврон высотой в
  строку;
- внутренний отступ заголовка по горизонтали равен отступу размера, и
  содержимое начинается под заголовком.

Размер не наследуется: вложенный аккордеон без класса размера остаётся
обычным. Класс размера задаёт отступы, поэтому свои значения переменных
отступов ставьте после него.

:::example {id="components/accordion/sizes" label="Аккордеон рядом с полями того же размера"}
:::

### Иконка

Шеврон смотрит в сторону у закрытого раздела и вниз у открытого; он
подходит меню, иерархии и последовательным шагам. `sf-accordion--plus-minus`
показывает плюс у закрытого раздела и минус у открытого — для вопросов и
подробностей, где смысл — показать или скрыть текст.

:::example {id="components/accordion/icon" label="Шеврон и плюс-минус"}
:::

### Один открытый раздел

По умолчанию разделы открываются независимо. Контейнер
`.sf-accordion-group` с `data-mode="single"` оставляет открытым один раздел:
открытие следующего закрывает предыдущий. Аккордеоны лежат прямыми
потомками контейнера.

:::example {id="components/accordion/single" label="Группа с одним открытым разделом"}
:::

### Одна секция

Одной секции раскрываться незачем. Единственный `.sf-accordion` в
`.sf-accordion-group` или секция с классом `sf-accordion--single` показывается
как обычный раздел: содержимое видно всегда, а заголовок — просто заголовок.
Вместо кнопки стоит элемент `span.sf-accordion-trigger` с атрибутом
`data-sf-accordion-static`, корень получает `sf-accordion--static`. Нет
стрелки, наведения и остановки `Tab`; линия под заголовком и высота шапки по
размеру остаются. Когда в группу добавляется вторая секция, кнопка
возвращается, и секция остаётся открытой; когда секций снова одна, она
снова обычный раздел. Группа, которая должна оставить одну секцию
раскрывающейся, например список, который заполнится позже, получает
`data-single-section="toggle"`.

:::example {id="components/accordion/single-section" label="Одна секция и группа с переключателем"}
:::

## Состояния

Наведение и нажатие заголовок показывает сам.

### Открыт

Открытый раздел: у кнопки `aria-expanded="true"`, у панели нет `hidden`.
Скрипт ставит самому аккордеону класс `active`, поворачивает шеврон и
рисует разделитель между заголовком и панелью.

:::example {id="components/accordion/state-open" label="Закрытый и открытый раздел"}
:::

### Фокус

При переходе клавишей Tab кольцо фокуса охватывает заголовок изнутри и не
обрезается на стыке с панелью; панель вместе с заголовком не
подсвечивается. В примере фокус показан классом `focus-visible`, который CSS
читает наравне с `:focus-visible`.

:::example {id="components/accordion/state-focus" label="Заголовок аккордеона в фокусе"}
:::

## Доступность

- Кнопка внутри заголовка даёт разделу роль, имя и состояние
  `aria-expanded`; раздел переключается по Enter и пробелу.
- Подпись заголовка коротко называет содержимое раздела.
- `role="region"` на панели ставьте, когда разделов немного: каждая такая
  панель становится ориентиром страницы.
- Каждый заголовок — отдельная точка Tab; стрелками разделы не
  переключаются.
- Шеврон зеркалится при письме справа налево. При системной настройке
  уменьшения движения поворот иконки не анимируется; в режиме высокой
  контрастности кольцо фокуса рисуется цветом текста.

## Классы

| Что | Классы |
|:---|:---|
| Блок | `sf-accordion` |
| Части | `sf-accordion-content`, `sf-accordion-heading`, `sf-accordion-title`, `sf-accordion-trigger` |
| Модификаторы | `sf-accordion--flush`, `sf-accordion--legacy`, `sf-accordion--outline`, `sf-accordion--plus-minus`, `sf-accordion--static` |
| Размеры | `sf-accordion--size-1`, `sf-accordion--size-1/2`, `sf-accordion--size-1/3`, `sf-accordion--size-2`, `sf-accordion--size-3` |

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Переменные

### Настройка

Эти переменные — поверхность настройки компонента. Их имена стабильны: переименовать или убрать такую переменную можно только через журнал изменений, с предупреждением, как атрибут. Framework их не задаёт, поэтому значение можно поставить на сам компонент (`.sf-accordion`) или на любого предка. Переменные действуют на спокойный вид; наведение, фокус, нажатие, недоступность и ошибка рисуются поверх, поэтому состояния остаются видны.

| Переменная | Что задаёт | По умолчанию |
|:---|:---|:---|
| `--sf-accordion-background-color` | Заливка секции в обычном виде; у outline и flush её нет, а наведение и нажатие сохраняют свою. | `var(--sf-surface-container)`; зависит от вида |
| `--sf-accordion-border-color` | Цвет рамки в виде outline и линии под секцией в виде flush. | `var(--sf-outline-variant)`; зависит от вида |
| `--sf-accordion-border-width` | Толщина этой рамки и линии, а также разделителя под шапкой открытой секции. | `var(--sf-px)`; зависит от вида |
| `--sf-accordion-radius` | Скругление углов секции; секция в виде flush остаётся прямоугольной. | `var(--sf-radius--surface)`; зависит от вида |
| `--sf-accordion-title-color` | Цвет заголовка секции в её шапке. | `var(--sf-on-surface)` |
| `--sf-accordion-content-color` | Цвет текста содержимого секции. | `var(--sf-on-surface-variant)` |
| `--sf-accordion-icon-color` | Цвет метки (шеврона или плюса и минуса) и значка перед заголовком; у недоступной секции свой. | `var(--sf-on-surface-variant)` |
| `--sf-accordion-divider-color` | Цвет линии под шапкой открытой секции и под шапкой единственной секции. | `var(--sf-outline-variant)` |

```css
.sf-accordion {
  --sf-accordion-radius: 0;
}
```

### Устройство

Остальные переменные — внутренняя проводка компонента: модификаторы задают им значения, а части их читают. Их имена и устройство могут меняться в любом выпуске, поэтому проект их не задаёт. Значение по умолчанию — из базового правила блока (`.sf-accordion`); переменную без него задают только модификаторы.

| Переменная | По умолчанию | Задаёт |
|:---|:---|:---|
| `--sf-accordion--background-color` | `var(--sf-accordion-background-color, var(--sf-surface-container))` | `background-color` |
| `--sf-accordion--border-color` | `var(--sf-accordion-border-color, var(--sf-outline-variant))` | `border`, `border-bottom`, `border-block-end` |
| `--sf-accordion--border-width` | `var(--sf-accordion-border-width, var(--sf-px))` | `border`, `border-bottom`, `border-block-end`, `height` |
| `--sf-accordion--content-padding` | `var(--sf-space-3)` | `padding` |
| `--sf-accordion--icon-size` | `var(--sf-text-height-1)` | `font-size`, `height`, `width` |
| `--sf-accordion--radius` | `var(--sf-accordion-radius, var(--sf-radius--surface))` | `border-end-end-radius`, `border-end-start-radius`, `border-start-end-radius`, `border-start-start-radius` |
| `--sf-accordion--text-height` | `var(--sf-text--height)` | `line-height` |
| `--sf-accordion--text-size` | `var(--sf-text--size)` | `font-size` |
| `--sf-accordion--trigger-min-block-size` | `auto` | `min-height`, `min-block-size` |
| `--sf-accordion--trigger-padding-block` | `var(--sf-space-2)` | `padding` |
| `--sf-accordion--trigger-padding-inline` | `var(--sf-space-3)` | `padding` |
