# Карточка

`.sf-card` собирает несколько блоков содержимого — заголовок, абзац, список,
действие — на своей поверхности: заливка страницы, тонкая граница цвета
`--sf-outline-variant` и скругление поверхности. У компонента нет своего
JavaScript.

## Разметка

Минимальную разметку показывает пример выше: `<div class="sf-card">` с блоками внутри.

- Блоки внутри стоят одной колонкой с одним промежутком — промежутком текста
  в ритме содержимого (`--sf-content--space-text`).
- Внешние отступы блоков снимаются: заголовок или абзац внутри не добавляют
  свой отступ страницы.
- Своей семантики у карточки нет. Если её содержимое — одна статья или одна
  ссылка, этот элемент ставят внутрь карточки, а не на неё.

Блок содержимого `content.card` рисуется этим компонентом
(`props.variant`: `default` или `plain`), а `content.grid` из карточек
раскладывает их по колонкам. См. [Блоки содержимого](/ru/guide/layouts/content-and-data/content-types/).

## Варианты

### Без рамки

`sf-card--plain` сохраняет колонку, но убирает поверхность: нет заливки,
границы и внутренних отступов. Подходит для сетки карточек, которой рамки не
нужны.

:::

## Доступность

В режиме принудительных цветов граница рисуется цветом `CanvasText`.
## Классы

| Что | Классы |
|:---|:---|
| Блок | `sf-card` |
| Модификаторы | `sf-card--plain` |

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Переменные

### Настройка

Эти переменные — поверхность настройки компонента. Их имена стабильны: переименовать или убрать такую переменную можно только через журнал изменений, с предупреждением, как атрибут. Framework их не задаёт, поэтому значение можно поставить на сам компонент (`.sf-card`) или на любого предка. Переменные действуют на спокойный вид; наведение, фокус, нажатие, недоступность и ошибка рисуются поверх, поэтому состояния остаются видны.

| Переменная | Что задаёт | По умолчанию |
|:---|:---|:---|
| `--sf-card-background-color` | Заливка карточки. | `var(--sf-surface-0)` |
| `--sf-card-color` | Цвет текста карточки. | `var(--sf-on-surface)` |
| `--sf-card-border-color` | Цвет границы карточки. | `var(--sf-outline-variant)` |
| `--sf-card-border-width` | Толщина границы карточки. | `var(--sf-px)` |
| `--sf-card-radius` | Скругление углов карточки. | `var(--sf-radius--surface)` |
| `--sf-card-padding-block` | Отступ над содержимым и под ним. | `var(--sf-space-2)` |
| `--sf-card-padding-inline` | Отступ слева и справа от содержимого. | `min(var(--sf-space-2), 8%)` |
| `--sf-card-gap` | Промежуток между блоками карточки. | `var(--sf-content--space-text)` |
| `--sf-card-title-size` | Размер заголовка внутри карточки — её названия. | `var(--sf-b6)` |
| `--sf-card-title-weight` | Насыщенность заголовка внутри карточки — её названия. | `var(--sf-text--font-weight-6)` |

```css
.sf-card {
  --sf-card-radius: 0;
}
```
