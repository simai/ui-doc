# Движок перелистывания

Движок перелистывания Framework (Swiper) сдвигает ряд слайдов по кнопкам,
клавишам, протяжкой и вызовам из скрипта. Это собственный движок Framework,
не внешняя библиотека: на нём работает слайдер. Движок не оформляет слайды и
не выбирает поведение за проект. Для готовых стрелок, точек и автопрокрутки
берите [слайдер](/ru/components/overlays-media/slider/).

## Разметка

Минимальную разметку показывает пример выше. Части вложены так: корень
`swiper` → лента `swiper-wrapper` → слайды `swiper-slide`.

- `swiper` обрезает ленту по своей ширине; `swiper-wrapper` выстраивает слайды
  в строку и сдвигается при перелистывании; каждый `swiper-slide` по
  умолчанию занимает всю ширину корня.
- Кнопки перелистывания — обычные кнопки Framework в любом месте страницы;
  движку их передают в параметрах. Кнопка, которой некуда вести, получает
  `disabled` и класс `swiper-button-disabled`: выходит из порядка Tab и
  рисуется своим видом недоступной кнопки; если фокус был на ней, он
  переходит на вторую кнопку.
- Промежуток между слайдами задаёт параметр `spaceBetween` в пикселях, а не
  отступы внутри слайда.
- Разметка сама не перелистывается: каждый корень создают явно через
  `new Swiper(root, options)`.

## Варианты

### Число видимых слайдов

Параметр `slidesPerView` задаёт, сколько слайдов видно сразу; дробное число
(2.2) показывает край следующего слайда. `breakpoints` меняет параметры по
ширине: ключи — минимальная ширина в пикселях. По умолчанию это ширина самой
ленты (`breakpointsBase: 'container'`): компонент следует ширине своего
места; `breakpointsBase: 'window'` берёт ширину окна. Движок перечитывает
`breakpoints`, когда ширина меняется, и отправляет события `breakpoint` и
`resize`.

## Доступность

- Корню дайте `role="region"` и доступное имя через `aria-label`, а
  `tabindex="0"` — если включено управление клавишами.
- Движок помечает слайды `role="group"` и именем «1 / 3»; слова задают
  `a11y.slideLabelMessage` (`{{index}}`, `{{slidesLength}}`),
  `a11y.itemRoleDescriptionMessage` и `a11y.slideRole`. `update()` считает
  имена заново: добавленный слайд называется «3 / 3», имя, которое написала
  страница, остаётся.
- Слайд вне видимой части движок делает `inert`: ссылки и кнопки в нём выходят
  из порядка фокуса. `a11y: false` оставляет всё это вызывающему коду.
- Кнопкам перелистывания нужны доступные имена: «Предыдущий слайд»,
  «Следующий слайд».
- При параметре `keyboard: true` стрелки влево и вправо перелистывают слайды
  там, где слушает `keyboard.el` (по умолчанию лента), с учётом направления
  письма; клавиша в поле остаётся полю.
- Мышь, палец и перо листают ленту протяжкой: дальше 15 % слайда или быстрым
  смахиванием — к соседнему слайду, иначе лента возвращается. Вертикальное
  движение прокручивает страницу, щелчок после протяжки не срабатывает, а поля
  и `.swiper-no-swiping` протяжку не начинают.
- При системной настройке уменьшения движения лента встаёт на место без
  сдвига, а автопрокрутка не запускается.

## JavaScript

`window.Swiper` — конструктор движка. Он появляется, когда скрипт компонента
выполнен; карусель Framework ждёт его сама.

Параметры:

| Параметр | Что задаёт |
|:---|:---|
| `slidesPerView` | число видимых слайдов, по умолчанию 1; дробное показывает край следующего |
| `spaceBetween` | промежуток между слайдами в пикселях |
| `breakpoints` | параметры по минимальной ширине ленты (или окна при `breakpointsBase: 'window'`) |
| `breakpointsBase` | `container` (по умолчанию) или `window` |
| `allowTouchMove` | `false` выключает протяжку |
| `simulateTouch` | `false` — мышь не тянет ленту, палец и перо тянут |
| `initialSlide` | номер первого показанного слайда, с нуля |
| `speed` | длительность сдвига в миллисекундах, по умолчанию 300 |
| `loop` | после последнего слайда перейти к первому |
| `keyboard` | `true` — перелистывание стрелками; `{el}` — где слушать клавиши |
| `a11y` | слова имён слайдов; `false` — движок не трогает доступность |
| `navigation` | `prevEl`, `nextEl` (элемент или селектор), `disabledClass` |
| `pagination` | `el`, `clickable`, `bulletElement`, `bulletClass`, `bulletActiveClass` — точки по числу слайдов; своего оформления у точек нет, его задают классы. `type: 'fraction'` пишет счётчик «2 / 12», `keyboard: true` делает точки одной остановкой Tab со стрелками, `Home` и `End` |
| `autoplay` | `{delay}` — перелистывать сам каждые `delay` миллисекунд |

Методы экземпляра: `slideNext()`, `slidePrev()`, `slideTo(index)`,
`update()` — после добавления или удаления слайдов,
`enable()` и `disable()`, `autoplay.start()` и `autoplay.stop()`,
`destroy()` — снимает обработчики и стили. Свойства `activeIndex` и `slides`
дают текущий слайд и список слайдов, `previousIndex` — слайд, который был
показан до последней смены. События подключает `on(name, listener)`:
`init`, `slideChange`, `transitionEnd`, `autoplayStart`, `autoplayStop`,
`breakpoint`, `resize`, `update`, `destroy`; обработчик получает экземпляр.

После изменения набора слайдов вызывайте `update()` у уже созданного
экземпляра — второй экземпляр поверх первого не создавайте.

:::

Создание движка с кнопками, промежутком и числом слайдов по ширине ленты:

```js
const swiper = new Swiper(document.querySelector('#gallery'), {
  keyboard: true,
  slidesPerView: 1,
  spaceBetween: 12,
  breakpoints: {640: {slidesPerView: 2}},
  navigation: {prevEl: '#gallery-prev', nextEl: '#gallery-next'},
});
swiper.on('slideChange', (instance) => console.log(instance.activeIndex));
```
