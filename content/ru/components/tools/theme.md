# Тема

Тема определяет светлое или тёмное оформление всего интерфейса. Без сохранённого
выбора Framework следует системной настройке пользователя; кнопка позволяет
явно переключить текущую схему.

## Особенности применения

Используйте нативную кнопку с классом `sf-theme-button`, доступным именем
«Тёмная тема» и `aria-pressed`. Framework синхронизирует состояние всех таких
кнопок, в том числе добавленных позднее, и не перемещает фокус.

Явный выбор сохраняется в cookie `sf-theme`. При отсутствии корректного
значения действует системная тема, которая обновляется вместе с
`prefers-color-scheme`. После изменения Framework отправляет событие
`sf-theme-change` с эффективной темой и выбранным режимом.

Если управление темой не требуется, задайте `SF_BOOT_CONFIG.theme = false` до
запуска Core. В этом режиме Theme не меняет классы и сохранённые настройки.

## Явный выбор и системная тема

Метод `SF.Loader.setTheme()` принимает только `system`, `light` или `dark`.
Значение `system` удаляет явное переопределение и возвращает управление
операционной системе. Для декларативного выбора задайте кнопкам короткий
атрибут `data-theme` с одним из этих значений; без атрибута кнопка остаётся
обычным переключателем.
