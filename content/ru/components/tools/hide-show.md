# Показ и скрытие

Компонент показывает и скрывает связанное содержимое по кнопкам и отражает
состояние для экранного диктора. Для простого раскрываемого блока сначала
рассмотрите нативные `details` и `summary`, для группы раскрываемых разделов —
аккордеон.

## Разметка

Минимальную разметку показывает пример выше: корень `sf-hide-show`, кнопки с
атрибутом `data-action` и содержимое с атрибутом `data-content` внутри него.

- `data-action` принимает `show`, `hide` или `toggle`. Кнопки и содержимое
  лежат внутри одного корня; вложенный `sf-hide-show` управляет только своими
  частями.
- Содержимых может быть несколько — все они показываются и скрываются вместе.
  Без `data-content` содержимым считаются все потомки корня, кроме кнопок.
- Состояние скрипт пишет в `data-state` корня: `shown` или `hidden`.
- У компонента нет своего CSS: скрытие задаёт нативный атрибут `hidden`, а
  раскладку — утилиты.

## Варианты

### Кнопки

Пара кнопок `show` и `hide` подходит, когда у действий разный текст: скрипт
прячет кнопку, действие которой уже выполнено, и переносит фокус на вторую.
Одна кнопка `toggle` переключает состояние и остаётся на месте.

:::

## Состояния

### Скрыто

Чтобы содержимое не показывалось с загрузки, задайте корню `data-state="hidden"`
или содержимому атрибут `hidden` — тогда содержимое не мелькает до запуска
скрипта.

:::example {id="components/hide-show/initial-hidden" label="Содержимое скрыто изначально"}
:::

## Доступность

- Каждая кнопка получает `aria-controls` со списком `id` содержимого и
  `aria-expanded` по текущему состоянию; содержимому без `id` скрипт задаёт
  его сам.
- Скрытое содержимое получает атрибут `hidden`: оно не видно и не читается
  экранным диктором.
- Когда кнопка пары прячется после нажатия, фокус переходит на вторую кнопку
  и не теряется.
- Текст кнопки называет действие или содержимое: «Показать условия», а не
  «Ещё».

## JavaScript

Скрипт компонента находит корни `.sf-hide-show` при загрузке страницы и в
добавленной позже разметке. Перед каждым изменением на корне возникает
всплывающее событие `sf-hide-show:change` с полями `action` (`show`, `hide`
или `toggle`), `hidden` и `shown` (новое состояние) в `detail`;
`preventDefault()` отменяет изменение.

:::example {id="components/hide-show/cancel" label="Отмена скрытия"}
:::

```js
document.querySelector('#filters').addEventListener('sf-hide-show:change', (event) => {
  if (event.detail.hidden && hasUnsavedChanges()) event.preventDefault();
});
```

Компонент регистрирует класс `HideShow`: `new HideShow(root).init()`
подключает корень вручную, методы `show()`, `hide()` и `toggle()` меняют
состояние с тем же событием. `SF.Loader.ready('HideShow', callback)` передаёт
класс после события `sf-loader-init`. Классы `sf-show`, `sf-hide` и
`sf-hide-show-content` — другие имена `data-action="show"`,
`data-action="hide"` и `data-content`.
