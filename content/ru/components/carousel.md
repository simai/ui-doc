## Когда использовать

- Используйте компонент, когда нужно: Последовательный просмотр нескольких материалов.
- Выберите вариант и размер по иерархии задачи, плотности интерфейса и доступному месту.
- Не скрывайте в отдельном слое информацию, необходимую для выполнения основной задачи.

## Варианты и состояния

Проверенные варианты, размеры и состояния собраны в примере. Переключитесь на
вкладку HTML, чтобы скопировать точную публичную разметку. Состояния задавайте
нативными атрибутами (`disabled`, `checked`, `aria-*`) и публичными классами
компонента; не повторяйте внутренние стили в CSS проекта.

## Доступность

При открытии слоя управляйте фокусом, обеспечьте закрытие с клавиатуры и верните фокус инициатору. Для медиаконтента добавьте понятные подписи и управление.

Проверьте видимый фокус, контраст, чтение экранным диктором и работу при
увеличении текста до 200% в контексте своего интерфейса.

## Технический контракт

- Loader-идентификатор: `carousel`.
- Поставка: SIMAI Framework 5.4.0.
- Источник истины: Framework Registry и ассеты `distr/component/carousel`.
- Подключение выполняет Loader после обнаружения публичных классов компонента;
  отдельный проектный CSS для примера не требуется.
