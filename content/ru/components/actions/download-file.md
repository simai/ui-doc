# Скачивание файла

Компонент оформляет ссылку на файл как отдельное действие и показывает рядом
название, размер и иконку скачивания.

## Особенности применения

Для доступного файла используйте ссылку `<a>` с настоящим `href`. Атрибут
`download` задаёт имя сохраняемого файла. Если размер не указан, JavaScript
Framework пытается получить `content-length` запросом `HEAD`; для внешнего
ресурса это зависит от его CORS-настроек. Надёжнее передавать известный размер
сразу.

Если адрес ещё неизвестен, используйте `<button>`: приложение обрабатывает
событие `sf-download-file:click` и само запускает подготовку файла. Не
подменяйте ссылку кнопкой, когда готовый `href` уже существует. Иконка является
декоративной, а доступное имя задаёт название файла или `aria-label`.

## Размеры

Компонент поддерживает размеры `1/3`, `1/2`, `1`, `2` и `3`. Они меняют
отступы, текст, расстояние между элементами и размер иконки.

## Подготовка файла приложением

Если файл формируется по запросу и готового адреса ещё нет, используйте кнопку.
Она отправляет `sf-download-file:click`; обработчик приложения подготавливает
ресурс и сообщает пользователю о результате. До появления настоящего адреса
компонент не притворяется ссылкой.

:::example {id="components/download-file/action" label="Результат"}
:::

## Недоступное состояние

Для недоступного действия используйте кнопку с `disabled` либо неинтерактивный
элемент с классом `disabled` и `aria-disabled="true"`. Не оставляйте действующий
`href`: состояние должно быть корректным ещё до загрузки JavaScript.
