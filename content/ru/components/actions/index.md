# Действия

Действие запускает что-то по нажатию. Выберите компонент по тому, как действие выглядит и где стоит.

| Задача | Что брать |
|:---|:---|
| Действие с подписью: «Сохранить», «Отмена» | [Кнопки](/ru/components/actions/buttons/) |
| Несколько связанных действий одной строкой | [Группа кнопок](/ru/components/actions/button-group/) |
| Действие значком без подписи: панель, строка таблицы | [Кнопки с иконкой](/ru/components/actions/icon-buttons/) |
| Одно главное действие поверх содержимого | [Плавающая кнопка](/ru/components/actions/fab/) |
| Закрыть окно, панель или уведомление | [Кнопка закрытия](/ru/components/actions/close/) |
| Скопировать значение в буфер | [Копирование](/ru/components/actions/clipboard/) |
| Скачать файл с именем и размером | [Скачивание файла](/ru/components/actions/download-file/) |

## Все компоненты раздела

- **[Кнопки](/ru/components/actions/buttons/)** — основные, вторичные и текстовые действия разных размеров и состояний.
- **[Группа кнопок](/ru/components/actions/button-group/)** — связанные действия одной строкой.
- **[Кнопки с иконкой](/ru/components/actions/icon-buttons/)** — компактные действия без видимой текстовой подписи.
- **[Плавающая кнопка](/ru/components/actions/fab/)** — главное контекстное действие поверх содержимого.
- **[Кнопка закрытия](/ru/components/actions/close/)** — стандартная кнопка закрытия панели, окна или уведомления.
- **[Копирование](/ru/components/actions/clipboard/)** — копирование значения в буфер обмена с понятной обратной связью.
- **[Скачивание файла](/ru/components/actions/download-file/)** — действие скачивания с информацией о файле.
