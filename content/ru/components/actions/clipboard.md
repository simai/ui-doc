# Копирование

:badge[sf-clipboard]{variant=tonal scheme=primary size=1/2} :badge[1.1.1]{variant=outline scheme=on-surface size=1/2}

Любая кнопка может положить в буфер обмена готовое значение или текст другого
элемента: команду, ключ, код заказа. Ставьте её рядом с текстом, который
читатель переносит в другое место, и не прячьте этот текст: его должно быть
можно выделить и вручную. Готовая кнопка с подписью и подсказкой —
[кнопка копирования](/ru/smart/actions/copy-button/); здесь — атрибуты для
своей кнопки и классы её оформления.

## Разметка

Минимальную разметку показывает пример выше: нативный
`<button type="button">` с иконкой `sf-icon` и атрибутом, который говорит,
что копировать. Служебный класс кнопке не нужен.

- `data-sf-copy` — само значение: `data-sf-copy="ЗК-2048"`.
- `data-sf-copy-target` — `#id` элемента, чей текст копируется целиком (у
  `<input>` и `<textarea>` берётся `value`, у блока кода — текст без номеров
  строк). Если заданы оба источника, копирование завершается ошибкой.
- Те же атрибуты работают на `sf-button` и `sf-button-icon`.
- Кнопке без видимого текста нужен `aria-label`, который называет, что
  копируется: «Копировать код заказа».
- Сообщения задают `data-success` и `data-error`; без них звучит
  «Скопировано». Для экранного диктора текст выводится в элемент из
  `data-status="#id"`, а без него — в созданную после кнопки невидимую
  область статуса.
- `data-duration` задаёт, через сколько миллисекунд иконка возвращается к
  исходной: от 1000 до 10000, по умолчанию 2000.

## Варианты

### Оформление

`sf-clipboard-surface` даёт кнопке собственную спокойную поверхность — для
кода и полей. Если кнопка копирования стоит среди других действий, оформите
её как [кнопку с иконкой](/ru/components/actions/icon-buttons/) или
[кнопку](/ru/components/actions/buttons/) с подписью и добавьте
`data-sf-copy`: поведение то же.

:::example {id="components/clipboard/appearance" label="Оформление"}
:::

### Размер

Размер кнопки с `sf-clipboard-surface` задают `sf-clipboard-1` (высота
контрола ступени `1/3`), `sf-clipboard-2` (ступень `1`, как без класса) и
`sf-clipboard-3` (ступень `2`). Кнопке, оформленной как `sf-icon-button` или
`sf-button`, размер задают классы этих компонентов.

:::example {id="components/clipboard/sizes" label="Размеры кнопки копирования"}
:::

### Положение

`sf-clipboard--overlay` • [справочник](#классы)

`sf-clipboard--overlay` прижимает кнопку к верхнему конечному углу блока с
текстом в несколько строк; блоку нужен `position: relative` (утилита
`relative`). Для одной строки — команды, кода, ссылки — кнопка стоит в потоке
после текста: строка `flex items-cross-center gap-1/2`, кнопка последней.

## Состояния

### Копирование

Пока идёт запись в буфер, скрипт ставит кнопке `aria-disabled="true"`:
повторное нажатие ничего не делает. После записи атрибут снимается.

Приглушённый вид такой кнопки (цвет недоступного, без отклика на наведение)
приходит со следующей парой SIMAI Framework; в этой паре кнопка с
`aria-disabled="true"` ещё откликается на наведение.

:::example {id="components/clipboard/state-pending" label="Копирование"}
:::

### Результат

После успеха иконка на 2 секунды меняется на `check`, а диктор вежливо
произносит текст из `data-success` («Скопировано» по умолчанию). При ошибке
иконка становится `error`, а над кнопкой появляется текст из `data-error`;
если браузер не дал записать в буфер, скрипт выделяет источник и
подсказывает «Выделено — нажмите Ctrl+C» (⌘C на Mac). Соседние элементы не
сдвигаются. Нажмите кнопки в примере: у второй нет источника, и она
показывает ошибку.

:::example {id="components/clipboard/state-result" label="Результат"}
:::

## Доступность

- Используйте нативный `<button>`: он получает фокус и срабатывает по Enter
  и пробелу.
- Доступное имя называет объект: «Копировать команду», а не «Копировать».
- Область статуса получает `role="status"`, `aria-live="polite"` и
  `aria-atomic="true"`: экранный диктор зачитывает результат.
- Имя кнопки без подписи показывает подсказка Framework при наведении и
  фокусе; атрибут `title` не нужен.
- Скопированный текст остаётся видимым и выделяемым на странице.
- В режиме высокой контрастности у кнопки появляется рамка, кольцо фокуса
  берёт системный цвет.
- Кнопка поверх блока стоит в конечном углу и зеркалится при письме справа
  налево.

## JavaScript

Скрипт подключает кнопки с `data-sf-copy` и `data-sf-copy-target` при
загрузке страницы и кнопки, добавленные позже. Объект `SF.Clipboard` даёт три функции:

- `SF.Clipboard.bind(button)` — подключает кнопку вручную;
- `SF.Clipboard.copy(button)` — копирует значение кнопки, как при нажатии;
- `SF.Clipboard.unbind(button)` — отключает кнопку и удаляет созданную
  область статуса.

Копирование идёт через `navigator.clipboard` на защищённой странице, а если
оно недоступно — через временное скрытое поле. Ту же запись без кнопки
делает функция `SF.copyText`.

Кнопка отправляет всплывающие события:

| Событие | Когда | `detail` |
|:---|:---|:---|
| `sf:copy-success` | значение записано в буфер | `method` — `native` или `legacy`; `text` — скопированный текст |
| `sf:copy-error` | значение не записано | `code` — `missing_source`, `missing_target`, `ambiguous_source`, `empty_source` или `denied` (браузер не дал записать) |

```js
document.addEventListener('sf:copy-success', (event) => {
  console.log('Скопировано:', event.detail.text);
});
```

Компонент регистрирует класс `Copy`, который собирает кнопку из параметров
(`text`, `copy`, `done`, `error`, `label`, `size`, `type`, `scheme`).
`SF.Loader` появляется к событию `sf-loader-init` на `window`;
`SF.Loader.ready('Copy', callback)` передаёт класс, когда он
зарегистрирован.

```js
const whenLoader = (run) => (window.SF?.Loader ? run() : window.addEventListener('sf-loader-init', run, {once: true}));

whenLoader(() => SF.Loader.ready('Copy', (Copy) => {
  const copy = new Copy({param: {copy: 'ЗК-2048', label: 'Копировать код заказа', done: 'Код заказа скопирован'}});
  document.querySelector('#order').append(copy.render());
}));
```

## Классы

| Что | Классы |
|:---|:---|
| Блок | `sf-clipboard` |
| Части | `sf-clipboard-1`, `sf-clipboard-2`, `sf-clipboard-3`, `sf-clipboard-fallback`, `sf-clipboard-holder`, `sf-clipboard-name`, `sf-clipboard-result`, `sf-clipboard-status`, `sf-clipboard-surface` |
| Модификаторы | `sf-clipboard--inline`, `sf-clipboard--overlay` |
| Размеры | `sf-clipboard--size-1`, `sf-clipboard--size-1/3`, `sf-clipboard--size-2` |

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Переменные

Компонент читает свои переменные, а модификаторы задают им значения; таблица показывает, из чего складывается вид. Переменные компонента — его внутренняя проводка, а не поверхность настройки: их имена и устройство могут меняться. Вид проекта меняют общие токены, а глубокий вид смарт-компонента — его шаблон (см. [Переменные компонента](/ru/guide/components/what-is/#переменные-компонента)). Значение по умолчанию — из базового правила блока (`.sf-clipboard`); переменную без него задают только модификаторы.

| Переменная | По умолчанию | Задаёт |
|:---|:---|:---|
| `--sf-clipboard--box` | не задана; задают модификаторы, например `.sf-clipboard--size-1/3:not(.sf-button):not(.sf-icon-button)`: `var(--sf-ui-1/3--control-height)` | `height`, `block-size`, `min-height`, `min-block-size`, `min-width`, `min-inline-size` |
| `--sf-clipboard--icon` | не задана; задают модификаторы, например `.sf-clipboard--size-1/3:not(.sf-button):not(.sf-icon-button)`: `var(--sf-text-height-1/3)` | `--sf-icon--font-size`, `--sf-icon--height`, `--sf-icon--width` |
