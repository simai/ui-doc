# Закрытие

Компонент показывает стандартный знак закрытия без зависимости от иконочного
шрифта. `sf-close` — декоративный знак, а не самостоятельная кнопка. Действие
создаётся нативной кнопкой `sf-icon-button` с вариантом `sf-icon-button--close`.

## Особенности применения

Используйте нативный `<button type="button">` и задавайте действие через
`aria-label`, например «Закрыть окно». Название закрываемого объекта помогает
пользователю экранного диктора отличить кнопку от других элементов закрытия.
Знак скрывается от accessibility tree; кнопка остаётся единственным владельцем
фокуса, состояний и действия. Само закрытие и возврат фокуса реализует Modal,
Alert, Toast или другой компонент-владелец.

## Размеры

Для интерактивной кнопки доступны общие с Icon Button размеры `1/3`, `1/2`, `1`,
`2` и `3`. Выбирайте их по окружающим элементам управления, а не только по
размеру крестика.

## Размеры знака

Сам декоративный знак поддерживает полную опубликованную шкалу `1/4`, `1/3`,
`1/2`, `1`, `2`, `3`, `4`, `5`, `6` и `7`. Увеличенные знаки предназначены для
специальной композиции; интерактивную область всё равно формирует компонент
действия.
