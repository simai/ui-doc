# Группа кнопок

Группа объединяет несколько связанных кнопок в один компактный элемент.
Framework соединяет соседние границы и сохраняет общий внешний UI-радиус, но
не меняет смысл и поведение вложенных кнопок.

## Особенности применения

Используйте обычную группу для близких по смыслу независимых действий.
Контейнеру задавайте доступное имя через `aria-label` или `aria-labelledby`;
каждая кнопка сохраняет нативное действие и отдельную точку Tab. Атрибут
`aria-pressed` нужен только настоящей двухпозиционной кнопке, а не для
единственного выбора из нескольких вариантов.

Для управляемого единственного выбора используйте Smart Button Group: он
создаёт `radiogroup`, переносит radio-семантику на нативные кнопки и управляет
одной точкой Tab. Роль `toolbar` выбирайте явно только для настоящей панели из
трёх и более часто используемых контролов вместе с полной клавиатурной моделью.

Скрипт Framework добавляет отсутствующую роль `group` и служебные классы
сегментов, но не перехватывает действия кнопок.

При переходе клавишей Tab индикатор фокуса показывается только у текущей
кнопки и выводится поверх общих границ группы, поэтому его контур не обрезается
соседними сегментами. Обычный клик сохраняет рабочий фокус без клавиатурного
индикатора.

## Вертикальная группа

Для вертикального расположения задайте контейнеру короткий публичный атрибут
`data-orientation="vertical"`. Кнопки займут общую ширину группы и сохранят
один внешний контур. Старый `aria-orientation` поддерживается как входной alias,
но generic `role="group"` не публикует неподходящую ARIA orientation.
