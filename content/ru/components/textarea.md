# Многострочное поле

Многострочное поле принимает комментарий, описание или другой свободный текст,
которому нужны переносы строк. Значением, клавиатурой, проверкой, отправкой и
сбросом управляет нативный `<textarea>`.

## Особенности применения

Всегда связывайте поле с видимой подписью: placeholder не заменяет доступное
имя. Задавайте число строк по ожидаемому объёму и разумный `maxlength`. Для
короткого значения используйте Input, а для форматированного текста или кода —
специализированный редактор.

По умолчанию пользователь может менять только высоту поля. Это сохраняет
адаптивную ширину контейнера. Стандартные utilities `resize-none`, `resize-y`,
`resize-x` и `resize` переопределяют режим, когда макет это явно допускает.

## Нативные параметры

`autocomplete`, `inputmode`, `minlength`, `maxlength`, `spellcheck` и `wrap`
остаются нативными параметрами `<textarea>` и помогают браузеру вводить и
проверять текст без отдельного JavaScript.

## Варианты оформления

`bordered` отделяет поле тонкой границей, `filled` — тональной поверхностью.
Поведение и состояния у вариантов одинаковы.

## Размеры

Размеры `1/3`, `1/2`, `1`, `2` и `3` согласованно меняют подпись, текст и
отступы. Число видимых строк задаётся отдельно через `rows`.

:::example {id="components/textarea/sizes" label="Результат"}
:::

## Состояния

Readonly остаётся фокусируемым и позволяет копировать текст. Disabled не
отправляется с формой. Ошибку отмечайте `aria-invalid="true"` и связывайте с
сообщением, которое объясняет способ исправления.

:::example {id="components/textarea/states" label="Результат"}
:::

## Изменение размера

Вертикальное изменение размера безопасно по умолчанию. `resize-none` подходит
для заранее рассчитанной области; горизонтальный и свободный режимы используйте
только внутри контейнера, способного принять новую ширину.

:::example {id="components/textarea/resize" label="Результат"}
:::

## Маска

Textarea поддерживает общий Mask-контракт Framework для редких многострочных
форматов. Для обычного свободного текста маска не нужна.
