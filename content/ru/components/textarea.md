# Многострочное поле

Многострочное поле предназначено для комментария, описания и другого текста,
которому требуется несколько строк. Базовый вариант — `bordered`, размер — `1`.

:::

## Особенности применения

Связывайте нативный `<textarea>` с видимой подписью. Заранее задавайте разумное
число строк и не используйте поле для коротких значений, которым подходит
обычный input.

## Варианты оформления

Доступны поле с границей `bordered` и поле на тональной поверхности `filled`.

:::example {id="components/textarea/variants" label="Результат"}
:::

## Размеры

Размеры `1/3`, `1/2`, `1`, `2` и `3` меняют подпись, отступы и текст поля.

:::example {id="components/textarea/sizes" label="Результат"}
:::

## Состояния

Используйте нативные `required` и `disabled`. Ошибку обозначайте классом
`error`, `aria-invalid="true"` и текстом, объясняющим способ исправления.
