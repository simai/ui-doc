# Спиннер

Спиннер сообщает, что операция выполняется, когда точный процент завершения
неизвестен.

## Варианты

`data-variant="arc"` показывает вращающуюся дугу, а `dots` — последовательность
точек. Для бесконечной операции задайте `data-infinite="true"`. Подпись задаётся
через `data-label`; оставляйте её пустой только при наличии понятного соседнего
текста.

Размеры `1/2`, `1`, `2` и `3` задаются классом `sf-loader--size-*`. Выбирайте
минимальный размер, который остаётся заметным в текущем контексте.

## Когда не использовать

- если известен процент выполнения — используйте
  [Progress Bar](/ru/components/progress-bar/);
- если загружается форма или карточка с предсказуемой геометрией — используйте
  [Skeleton](/ru/components/skeleton/);
- не показывайте спиннер для мгновенных локальных действий.

## Доступность

Свяжите индикатор с областью через `aria-busy="true"` и сообщите состояние в
доступном тексте или live region. После завершения удалите busy-состояние и сам
индикатор. Анимация не должна быть единственным сообщением о результате.

## Справочник

| Назначение | Контракт |
| --- | --- |
| Контейнер | `sf-loader-container` |
| Вариант | `data-variant="arc|dots"` |
| Бесконечная анимация | `data-infinite="true"` |
| Подпись | `data-label` |
| Loader ID | `spinner` |
| JavaScript class | `Spinner` |
