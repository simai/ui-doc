# Спиннер

Спиннер сообщает, что операция выполняется, когда точный процент завершения
неизвестен.

## Особенности применения

Используйте спиннер для короткого ожидания с неизвестной длительностью. Если
известен процент выполнения, выберите [индикатор прогресса](/ru/components/progress-bar/).
Для формы или карточки с предсказуемой геометрией лучше подходит
[скелетон](/ru/components/skeleton/).

Свяжите ожидающую область с состоянием `aria-busy="true"`. Подпись задаётся
через `data-label`; оставляйте её пустой только при наличии понятного соседнего
текста.

## Варианты и размеры

`data-variant="arc"` показывает вращающуюся дугу, а `dots` — последовательность
точек. Для бесконечной операции задайте `data-infinite="true"`.

Размеры `1/2`, `1`, `2` и `3` задаются классом `sf-loader--size-*`. Выбирайте
минимальный размер, который остаётся заметным в текущем контексте.
