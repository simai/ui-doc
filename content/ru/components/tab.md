# Вкладка

Отдельный элемент навигации внутри набора вкладок. Пример ниже исполняется тем же кодом, который доступен
во вкладках исходников.

> Низкоуровневый компонент одной вкладки. Для полного интерфейса переключения обычно удобнее компонент [«Вкладки»](/ru/components/tabs/).

## Когда использовать

- Используйте компонент, когда нужно: Отдельный элемент навигации внутри набора вкладок.
- Выберите вариант и размер по иерархии задачи, плотности интерфейса и доступному месту.
- Не применяйте его для несвязанных действий, которые не образуют путь или последовательность.

## Варианты и состояния

Проверенные варианты, размеры и состояния собраны в примере. Переключитесь на
вкладку HTML, чтобы скопировать точную публичную разметку. Состояния задавайте
нативными атрибутами (`disabled`, `checked`, `aria-*`) и публичными классами
компонента; не повторяйте внутренние стили в CSS проекта.

## Доступность

Используйте подходящие навигационные роли и `aria-current` или `aria-expanded` для текущего состояния. Все переходы должны оставаться доступными с клавиатуры.

Проверьте видимый фокус, контраст, чтение экранным диктором и работу при
увеличении текста до 200% в контексте своего интерфейса.

## Технический контракт

- Loader-идентификатор: `tab`.
- Поставка: SIMAI Framework 5.4.0.
- Источник истины: Framework Registry и ассеты `distr/component/tab`.
- Подключение выполняет Loader после обнаружения публичных классов компонента;
  отдельный проектный CSS для примера не требуется.
