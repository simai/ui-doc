# Вкладка

Компонент `sf-tab` связывает элементы списка в `nav` с секциями в
`sf-tab-content` и показывает одну секцию за раз.

## Особенности применения

Число пунктов и секций должно совпадать. Для нового интерфейса с готовыми
вариантами оформления используйте более современный компонент
[«Вкладки»](/ru/components/tabs/).
