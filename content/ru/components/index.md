# Компоненты

Готовые элементы интерфейса SIMAI Framework. Выберите задачу, откройте компонент
и скопируйте проверенную разметку из вкладки HTML в его примере. Loader сам
подключит необходимые стили и поведение.

## Как устроены примеры

Каждый пример исполняется прямо в документации и показывает только публичные
классы SIMAI Framework. Переключитесь на вкладку HTML или JavaScript, чтобы
скопировать тот же код, который формирует видимый результат.
