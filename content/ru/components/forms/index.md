# Формы и ввод

Поле формы принимает значение от человека и отправляет его с формой. Выберите поле по тому, что человек вводит или выбирает.

| Задача | Что брать |
|:---|:---|
| Строка текста: имя, почта, пароль | [Текстовые поля](/ru/components/forms/inputs/) |
| Текст в несколько строк | [Многострочное поле](/ru/components/forms/textarea/) |
| Несколько независимых отметок | [Флажок](/ru/components/forms/checkbox/) |
| Один вариант из нескольких видимых | [Радиокнопки](/ru/components/forms/radio/) |
| Включить или выключить настройку сразу | [Переключатель](/ru/components/forms/switch/) |
| Небольшое число, которое меняют по шагу | [Количество](/ru/components/forms/quantity/) |
| Число или границы диапазона на шкале | [Слайдер диапазона](/ru/components/forms/range-slider/) |
| Дата или период | [Календарь](/ru/components/forms/datepicker/) |
| Телефон с кодом страны | [Код страны](/ru/components/forms/country-code/) |
| Файлы | [Загрузка файлов](/ru/components/forms/file-upload/) |
| Одноразовый код из сообщения | [Код подтверждения](/ru/components/forms/verification/) |

## Все компоненты раздела

- **[Текстовые поля](/ru/components/forms/inputs/)** — однострочный ввод, подписи, подсказки и состояния проверки.
- **[Многострочное поле](/ru/components/forms/textarea/)** — ввод длинного свободного текста.
- **[Флажок](/ru/components/forms/checkbox/)** — независимый выбор одного или нескольких значений.
- **[Радиокнопки](/ru/components/forms/radio/)** — выбор одного значения из небольшой группы.
- **[Переключатель](/ru/components/forms/switch/)** — немедленное включение или выключение настройки.
- **[Количество](/ru/components/forms/quantity/)** — точное числовое значение с кнопками увеличения и уменьшения.
- **[Слайдер диапазона](/ru/components/forms/range-slider/)** — одно число или границы диапазона на шкале.
- **[Календарь](/ru/components/forms/datepicker/)** — ввод и выбор даты в календаре.
- **[Код страны](/ru/components/forms/country-code/)** — выбор телефонного кода страны.
- **[Загрузка файлов](/ru/components/forms/file-upload/)** — выбор и отправка одного или нескольких файлов.
- **[Код подтверждения](/ru/components/forms/verification/)** — ввод одноразового кода по отдельным позициям.
