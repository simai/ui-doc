# Кнопки с иконкой

Кнопка с иконкой выполняет компактное действие без видимой текстовой подписи.
Базовый вариант использует оформление `default`, схему `primary` и размер `1`.

## Особенности применения

Используйте нативный `<button type="button">` и обязательно задавайте понятное
`aria-label`. Вложенная декоративная иконка получает `aria-hidden="true"`.
Если действие нельзя однозначно узнать по общепринятой иконке, используйте
обычную кнопку с текстом.

## Варианты оформления

Доступны основной `default`, мягкий `tonal`, контурный `outline` и текстовый
`link` варианты. Используйте только сочетания со схемами `primary`,
`secondary` и `on-surface`, для которых в исходных стилях есть правила.

## Размеры

Размеры `1`, `2` и `3` одновременно меняют область кнопки и размер иконки.
Размер `1` используется по умолчанию.

:::example {id="components/icon-buttons/sizes" label="Результат"}
:::

## Состояния

Выбранное действие обозначается классом `active`, недоступное — нативным
атрибутом `disabled`. Состояние нельзя передавать только цветом: при выборе
добавляйте соответствующий `aria-pressed` или другой смысловой атрибут.

:::example {id="components/icon-buttons/states" label="Результат"}
:::

## Плотность

Модификаторы `tightness-low`, `tightness-high` и `tightness-highest` меняют
внутренние отступы выбранного размера.

:::example {id="components/icon-buttons/tightness" label="Результат"}
:::

## Скругление

Без модификатора кнопка использует системный радиус компактных элементов.
`radius-square` убирает скругление, а `radius-rounded` делает кнопку круглой.

:::
