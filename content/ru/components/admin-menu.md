# Боковая навигация администратора

Компонент организует постоянную боковую навигацию административного приложения:
название рабочей области, поиск, основные разделы, текущий пункт, счётчики и
служебные действия. Для обычного списка команд или ссылок используйте компонент
«Меню».

## Особенности применения

Используйте компонент внутри оболочки административной панели. Текущий раздел
отмечайте классом `active` и атрибутом `aria-current="page"`. Обычный компонент
отвечает за представление и локальное поведение; поиск по данным, пользовательские
настройки и сохранение состояния относятся к Smart Admin Menu.

В контейнере с естественной высотой все пункты остаются видимыми. Если оболочка
приложения ограничивает высоту, компонент автоматически оставляет доступные
пункты и добавляет действие для показа остальных.

## Ограниченная высота

В полноэкранной административной оболочке меню может занимать только доступную
высоту. Задайте высоту окружающему контейнеру системной утилитой и растяните
меню с панелью через `h-full`: компонент сам определит переполнение и покажет
действие для остальных пунктов.
