# Всплывающие сообщения

Всплывающее сообщение кратко показывает результат поверх интерфейса и не
блокирует дальнейшую работу пользователя.

## Особенности применения

Сообщение должно быть коротким. Не помещайте в автоматически исчезающий Toast
обязательный шаг или сведения, которые легко пропустить. Для постоянного текста
внутри страницы используйте
[уведомление](/ru/components/feedback/alerts/), а для подтверждения с обязательным
выбором — модальное окно.

Позицию, порядок и ограничение количества сообщений задаёт контейнер приложения:
сам Toast отвечает только за одно сообщение. Кнопка закрытия должна иметь
локализованное доступное имя.

## Смысловые варианты

Доступны `default`, брендовый `primary` и смысловые `success`, `warning`,
`error`. Выбирайте вариант по смыслу сообщения, а не только по желаемому цвету.

## Время жизни и объявления

По умолчанию Toast остаётся до явного закрытия. `data-duration` задаёт время в
миллисекундах; отсчёт приостанавливается, пока указатель или клавиатурный фокус
находится внутри сообщения. Для текста с действием оставляйте постоянный режим.

Динамический обычный результат объявляйте через `role="status"`, а срочную
ошибку — через `role="alert"`. Если сообщение уже присутствует при загрузке
страницы, live-region роль не нужна.

:::

## Действие и закрытие

Для одного короткого необязательного действия используйте `data-action`, для
закрытия — `data-close`. Совместимые `data-toast-action` и `data-toast-close`
оставлены только для прежней разметки. Бизнес-действие выполняет приложение;
Toast сообщает `sf-toast-action` и `sf-toast-close`.
