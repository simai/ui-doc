# Обратная связь и состояние

Обратная связь говорит человеку, что произошло и что идёт сейчас. Выберите компонент по тому, о чём и как громко нужно сказать.

| Задача | Что брать |
|:---|:---|
| Важное сообщение в тексте страницы | [Уведомления](/ru/components/feedback/alerts/) |
| Короткий итог действия, который уходит сам | [Всплывающие сообщения](/ru/components/feedback/toast/) |
| Статус, категория или счётчик рядом с объектом | [Бейджи](/ru/components/feedback/badges/) |
| Минимальный знак состояния | [Точка состояния](/ru/components/feedback/dot/) |
| Ход операции с известной долей | [Прогресс](/ru/components/feedback/progress-bar/), по участкам — [Шкала прогресса](/ru/components/feedback/progress-scale/) |
| Ожидание без известного срока | [Спиннер](/ru/components/feedback/spinner/) |
| Форма содержимого, пока данные грузятся | [Скелетон](/ru/components/feedback/skeleton/) |
| Пустое место или временная область | [Заполнитель](/ru/components/feedback/placeholder/) |

## Все компоненты раздела

- **[Уведомления](/ru/components/feedback/alerts/)** — важное сообщение внутри текущего контекста.
- **[Всплывающие сообщения](/ru/components/feedback/toast/)** — краткая неблокирующая обратная связь о результате действия.
- **[Бейджи](/ru/components/feedback/badges/)** — короткий статус, категория или счётчик рядом с объектом.
- **[Точка состояния](/ru/components/feedback/dot/)** — минимальный визуальный индикатор состояния.
- **[Прогресс](/ru/components/feedback/progress-bar/)** — ход операции с известной степенью завершения.
- **[Шкала прогресса](/ru/components/feedback/progress-scale/)** — прогресс, разделённый на наглядные участки.
- **[Спиннер](/ru/components/feedback/spinner/)** — ожидание операции с неизвестной длительностью.
- **[Скелетон](/ru/components/feedback/skeleton/)** — стабильная форма содержимого во время загрузки данных.
- **[Заполнитель](/ru/components/feedback/placeholder/)** — пустое состояние или временная область содержимого.
