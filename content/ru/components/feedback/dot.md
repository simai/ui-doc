# Точка состояния

Точка состояния — компактный неинтерактивный индикатор доступности,
активности или результата. Она подходит для строк списка и других мест, где
текстовый [бейдж](/ru/components/feedback/badges/) занял бы слишком много
места.

## Разметка

Минимальную разметку показывает пример выше: блок `sf-dot` с одной частью
`sf-dot-item` внутри.

- `sf-dot` — строчный контейнер с небольшим отступом вокруг точки; на нём
  размер и статус.
- `sf-dot-item` — сама точка. Без неё блок пуст.
- Без класса статуса точка окрашена основным цветом, без размера — ступенью
  `1`.

## Варианты

### Статус

Статус задаёт цвет точки: `sf-dot--primary` (основной цвет, он же цвет по
умолчанию), `sf-dot--info`, `sf-dot--success`, `sf-dot--warning`,
`sf-dot--error` и `sf-dot--neutral` для отсутствия статуса. Выбирайте статус
по реальному состоянию объекта.

:::example {id="components/dot/tones" label="Статусы точки"}
:::

### Размер

Четыре ступени — `sf-dot--size-1/3`, `sf-dot--size-1/2`, `sf-dot--size-1` и
`sf-dot--size-2` — меняют диаметр точки. Берите ступень текста, рядом с
которым стоит точка.

:::example {id="components/dot/overview" label="Размеры точки"}
:::

## Доступность

- Цвет не передаёт смысл сам по себе. Рядом с точкой нужна видимая подпись —
  тогда точка декоративна и получает `aria-hidden="true"`.
- Если видимой подписи нет, дайте блоку `role="img"` и доступное имя через
  `aria-label`, а `sf-dot-item` скройте через `aria-hidden="true"`.
- В режиме принудительных цветов точка рисуется системным цветом текста с
  контрастной обводкой.

:::

## Классы

| Что | Классы |
|:---|:---|
| Блок | `sf-dot` |
| Части | `sf-dot-item` |
| Модификаторы | `sf-dot--error`, `sf-dot--info`, `sf-dot--neutral`, `sf-dot--primary`, `sf-dot--success`, `sf-dot--warning` |
| Размеры | `sf-dot--size-1`, `sf-dot--size-1/2`, `sf-dot--size-1/3`, `sf-dot--size-2` |

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Переменные

Компонент читает свои переменные, а модификаторы задают им значения. Чтобы изменить вид, задайте переменную на элементе или в своём слое для всего проекта — CSS компонента менять не нужно. Значение по умолчанию — из базового правила блока (`.sf-dot`); переменную без него задают только модификаторы. Какие переменные публичный контракт, а какие служебные, Framework ещё уточняет.

| Переменная | По умолчанию | Задаёт |
|:---|:---|:---|
| `--sf-dot-item--background-color` | `var(--sf-primary)` | `background-color` |
| `--sf-dot-item--border-radius` | не задана; задают модификаторы, например `.sf-dot .sf-dot-item`: `var(--sf-radius-circle)` | `border-radius` |
| `--sf-dot-item--size` | `var(--sf-a8)` | `height`, `block-size`, `width`, `inline-size` |
