# Оглавление

Оглавление связывает видимые заголовки длинной страницы с якорными ссылками и
помогает быстро перейти к нужному разделу.

## Структура

Внешний контейнер получает класс `sf-outline`, список — `sf-outline__list`, а
каждая ссылка — `sf-outline__link`. Вложенный список повторяет тот же класс и
визуально показывает уровень заголовка.

Текущий раздел обозначается `aria-current="location"`. Для программной
синхронизации также поддерживается атрибут `data-sf-outline-active`.

## Доступность

- используйте `<nav>` с доступным именем;
- текст ссылки должен совпадать со смыслом целевого заголовка;
- не пропускайте уровни только ради внешнего отступа;
- `aria-current` должен находиться ровно на одной активной ссылке.

## Справочник

| Назначение | Контракт |
| --- | --- |
| Контейнер | `sf-outline` |
| Список | `sf-outline__list` |
| Ссылка | `sf-outline__link` |
| Активный пункт | `aria-current="location"` |
| Loader ID | `outline` |
