# Текстовые поля

Текстовое поле позволяет ввести короткое значение: имя, адрес, поисковый запрос
или другой однострочный текст.

## Когда использовать

Используйте `inputs` для однострочного ввода. Для длинного свободного текста
выберите [Textarea](/ru/components/textarea/), для числа с пошаговым изменением —
[Quantity](/ru/components/quantity/).

Подпись должна оставаться видимой и точно называть ожидаемое значение.
Placeholder дополняет подпись примером, но не заменяет её.

## Варианты

| Вариант | Класс | Назначение |
| --- | --- | --- |
| Bordered | `sf-input--bordered` | Универсальное поле с заметной границей |
| Filled | `sf-input--filled` | Поле на тональной поверхности |

Оба варианта поддерживают левую иконку, правое содержимое, обязательность,
подсказку, ошибку и disabled-состояние.

## Размеры и состояния

Поддерживаются размеры `1/3`, `1/2`, `1`, `2` и `3` через
`sf-input--size-*`. Размер `1` — основной и согласован с кнопками и другими
элементами управления.

- ошибку задавайте фактическому `<input>` классом `error` и
  `aria-invalid="true"`;
- свяжите сообщение об ошибке через `aria-describedby`;
- для недоступного поля используйте нативный `disabled`;
- обязательность выражайте атрибутом `required`, а звёздочку скрывайте от
  скринридера, если она дублирует семантику.

## Структура

| Часть | Класс |
| --- | --- |
| Контейнер | `sf-input` |
| Подпись | `sf-input-label` и `sf-input-text` |
| Обязательность | `sf-input-required` |
| Поле | `sf-input-field` |
| Левое содержимое | `sf-input-left` или `sf-icon` |
| Правое содержимое | `sf-input-right` |
| Подсказка | `sf-input-hint-text-wrap` |

## Доступность

- связывайте подпись и поле нативным `<label>` либо `for`/`id`;
- выбирайте подходящий `type` и `autocomplete`;
- не блокируйте вставку и менеджеры паролей;
- сообщение об ошибке должно объяснять способ исправления;
- проверяйте focus, клавиатуру, zoom и автозаполнение.

## Справочник

Loader ID — `inputs`. Компонент содержит CSS и JavaScript и подключается при
обнаружении `sf-input`. Программный класс `Inputs` используйте только для
динамического создания; статическая форма должна оставаться нативной разметкой.
