# Флажок

Флажок позволяет независимо включить параметр или выбрать несколько значений.
Нативный `<input type="checkbox">` остаётся источником состояния.

## Особенности применения

Вся видимая подпись должна находиться внутри связанного `<label>`. Не применяйте
флажок для единственного выбора из взаимоисключающих вариантов — для этого есть
радиокнопки. Если несколько флажков отвечают на один вопрос, объединяйте их
через `<fieldset>` и `<legend>` и явно сообщайте, что можно выбрать несколько
ответов. Не отмечайте варианты заранее без предметной причины.

## Группа значений

Каждый флажок в группе остаётся независимым и отправляет собственное значение.
Нативные `fieldset` и `legend` дают группе общее доступное имя.

## Состояния

Компонент синхронизирует обычное, выбранное и неопределённое состояния с
иконкой. Используйте `checked`, `disabled` и свойство `indeterminate`. В
декларативном примере свойство смешанного состояния инициализируется коротким
атрибутом `data-indeterminate`; при изменении состояния из приложения используйте
`SF.Checkbox.setState(input, state)`.

`indeterminate` означает, что выбрана часть связанных вариантов, но не создаёт
третьего отправляемого значения. Для ошибки добавьте класс `error`, нативный
`aria-invalid="true"` и понятное текстовое объяснение — одного цвета недостаточно.

:::

## Компактный размер

Кроме основного размера `1` исходные стили поддерживают компактный размер
`1/3`. Основной размер подходит для обычных форм; компактный — для плотных
повторяющихся списков и профессиональных интерфейсов.

:::

## Положение индикатора

По умолчанию индикатор расположен в логическом начале строки и автоматически
учитывает направление текста. Это предпочтительный вариант для форм. Положение
в конце поддерживается для строк, где такая композиция задана всем интерфейсом.
