# Флажок

Флажок позволяет независимо включить параметр или выбрать несколько значений.
Нативный `<input type="checkbox">` остаётся источником состояния.

## Особенности применения

Вся видимая подпись должна находиться внутри связанного `<label>`. Не применяйте
флажок для единственного выбора из взаимоисключающих вариантов — для этого есть
радиокнопки.

## Состояния

Компонент синхронизирует обычное, выбранное и неопределённое состояния с
иконкой. Используйте `checked`, `disabled` и свойство `indeterminate`; для ошибки
добавьте класс `error` и текстовое объяснение.
