# Уведомления

Уведомление выделяет важную информацию внутри страницы: подсказку, предупреждение,
сообщение об ошибке или подтверждение результата.

## Особенности применения

Для обычной подсказки используйте `sf-alert--clear`. Состояния `info`, `warning`,
`danger` и `success` выбирайте по смыслу сообщения, а не только по желаемому
цвету. Уведомление остаётся в потоке страницы; для краткого сообщения поверх
интерфейса используйте Toast.

Для динамически появившейся срочной ошибки подходит `role="alert"`, а для
спокойного обновления — `role="status"`. Не добавляйте live-region роль сообщению,
которое уже присутствует при первоначальной загрузке страницы. Заголовок и
пояснение используют одинаковый обычный размер текста; иерархию создаёт среднее
начертание заголовка.

## Смысловые роли

Роли `clear`, `info`, `warning`, `danger` и `success` задают смысл, цвет и
подходящую по умолчанию иконку. Декоративная иконка получает
`aria-hidden="true"`, потому что смысл уже сформулирован текстом.

## Варианты оформления

Заполненный `default` подходит самостоятельному заметному сообщению. Контурный
`outlined` спокойнее работает на фоне страницы. Плоский `flat` используйте
внутри поверхности, границы которой уже заданы окружающим контейнером. В одном
сценарии сохраняйте единый способ отделения уведомлений от окружения.

## Действия и закрытие

Уведомление может содержать одно короткое действие и отдельную кнопку закрытия.
В примере ниже кнопка «Скачать» сообщает о выборе, но оставляет уведомление на
месте. Кнопка с крестиком удаляет его из потока страницы. После закрытия пример
показывает результат и позволяет вернуть уведомление, поэтому сценарий можно
проверить несколько раз без перезагрузки страницы.

Обычная кнопка действия использует короткий атрибут `data-action="значение"`, а
кнопка закрытия — `data-close` и обязательное доступное имя. Компонент сообщает
о выборе через `sf-alert-action`, а перед удалением — через `sf-alert-close`.
Закрытие использует токены движения и отключает анимацию при
`prefers-reduced-motion`.

После удаления приложение переносит фокус только тогда, когда он находился
внутри уведомления. Атрибуты `data-alert-action`, `data-alert-close` и класс
`.sf-alert--close` остаются совместимыми aliases, но в новой разметке используйте
короткие формы.
