# Загрузка и зависимости Smart Components

1. Core сканирует DOM по тегам и другим условиям Loader-правил.
2. Правило `cl-*` добавляет Smart JavaScript и зависимости обычны
 компонентов.
3. Smart-класс регистрирует Custom Element.
4. При подключении к DOM элемент загружает шаблон и выполняет render-цикл.
5. Изменение наблюдаемы
 свойств запускает обновление элемента.

Общие события базового Smart-элемента всплывают и про
одят границу Shadow DOM:

| Событие | Момент |
|:---|:---|
| `sf-connected` | элемент подключён к DOM |
| `sf-disconnected` | элемент отключён от DOM |
| `sf-before-render` | началась отрисовка |
| `sf-after-render` | отрисовка завершена |
| `sf-updated` | элемент обновлён |
| `sf-props-change` | изменились наблюдаемые свойства |
{.table}

Компонент может добавлять собственные события и зависимости. И
 точный список
публикуется на его [reference-странице](/ru/smart-components/reference/), а не
переносится по аналогии с соседним компонентом.

При проверке сценария контролируйте отсутствие `404`, порядок регистрации,
повторное подключение/отключение, клавиатуру и возврат фокуса, а для данны
 —
пустое и ошибочное состояния.
