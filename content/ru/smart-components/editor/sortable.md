# Перетаскивание

`<sf-sortable>` позволяет переставлять элементы внутри списка, переносить их
между списками одной группы и копировать из библиотеки. Работает мышью, пером,
касанием и клавиатурой. Компонент только сообщает намерение событием
`sf-sortable-intent`: DOM и данные меняет приложение.

Идентификатор: `smart.sortable`, жизненный цикл — экспериментальный. Код
загружается по требованию, когда на странице появляется `sf-sortable`.

## Особенности применения

Элементы списка — потомки с `data-sf-sortable-item="<id>"`. Ручка
`data-sf-sortable-handle` ограничивает перетаскивание и служит целью касания;
без ручки перетаскивается весь элемент. Событие несёт итоговую позицию, поэтому
приложению не нужно пересчитывать индекс после удаления элемента из исходного
списка.

```js
document.addEventListener('sf-sortable-intent', (event) => {
  const {item, from, to, index, mode} = event.detail;
  // Применить к своей модели с ожидаемой ревизией; при отказе ничего не менять.
});
```

Список с `mode="copy"` работает как библиотека: элемент остаётся на месте, а на
холст редактора попадает его копия через `sf-composition-overlay accepts`.

## Атрибуты и события

| Атрибут | Назначение |
|---|---|
| `group` | имя группы, `^[a-z][a-z0-9-]{0,31}$` |
| `accepts` | дополнительные группы, которые список принимает |
| `mode` | `move` или `copy` |
| `orientation` | `vertical` или `horizontal` |
| `label` | имя списка для объявлений |

| Событие | Данные |
|---|---|
| `sf-sortable-intent` | `{item, from, to, index, mode}` |
| `sf-sortable-state` | `{state: 'picked' \| 'dropped' \| 'cancelled', item}` |

Внешние цели подключаются через `SF.Sortable.registerSortableDropTarget`.
Сеанс перетаскивания общий для всех Smart-компонентов страницы.

## Доступность

Пробел или Enter берут элемент, стрелки вверх и вниз меняют позицию, влево и
вправо переводят в соседний список или на внешнюю цель, Пробел или Enter кладут,
Escape или Tab отменяют. Каждый шаг объявляется на языке страницы. У краёв
прокручиваемой области включается автопрокрутка.
