# Редактор страниц

- [Оверлей редактора](/ru/smart-components/editor/composition-overlay/) — Рамки, подписи, панель действий, места вставки и дерево структуры поверх отрисованного Composition Document.
- [Перетаскивание](/ru/smart-components/editor/sortable/) — Перестановка, перенос между списками и копирование из библиотеки мышью, касанием и клавиатурой.
- [Inline-редактор](/ru/smart-components/editor/inline-editor/) — Правка текста заголовков и абзацев прямо на странице с сохранением модели content, а не HTML.
