# Reference Link

## Доступность

Перед использованием проверьте доступное имя, порядок фокуса, управление клавиатурой и объявление состояний. Сгенерированная API-страница подтверждает source-контракт, но не заменяет сценарный accessibility smoke.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-9fb0297bb5c2` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-reference-link>` |
| Назначение | Навигационная поверхность, которая связывает реальную цель перехода с компактной ссылкой. |
| Контракт | `smart.reference-link`, версия `1.0.0` |
| Поставка | выпуск Framework `ui-9fb0297bb5c2` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |
| Готовность | описан: манифест и сценарий есть, продуктовой приёмки нет |

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Назначение |
|:---|:---|:---|:---|:---|
| `appearance` | `string` | `card` | `card`, `plain` | card — ссылка в собственном блоке: рамка, заливка и отступы. plain — только ссылка шириной по тексту, для ссылки внутри того, что уже является блоком, — поля записи, ячейки таблицы, — где вторая рамка выглядит как элемент управления, которым значение не является. |
| `aria-label` | `string` | пусто | — | — |
| `disabled` | `boolean` | `false` | — | Отображает недоступную ссылку без фокуса и без перехода. |
| `href` | `string` | пусто | — | Реальное место навигации. Обязательно для доступной ссылки. |
| `icon` | `string` | `arrow_forward` | — | Имя декоративной иконки. Без атрибута отображается стрелка; пустое значение не рисует иконку — для ссылки, стоящей рядом со своей подписью. |
| `label` | `string` | пусто | — | Видимая подпись ссылки, описывающая место назначения. |
| `line` | `string` | пусто | пусто, `1/2`, `1`, `2` | Занимает строку текста этого размера формы как ссылка без карточки — для ячейки таблицы, чтобы строка сохраняла высоту элемента управления. |
| `size` | `string` | пусто | пусто, `1/2`, `1`, `2` | Размер формы: ссылка становится элементом управления этого размера — для ряда полей или ячейки таблицы. Пустое значение сохраняет отступы карточки. |
| `target` | `string` | `_self` | — | Нативная цель контекста просмотра. Укажите в имени, что навигация открывает новый контекст. |
| `template` | `string` | `default` | `default` | — |
| `text` | `string` | пусто | — | Компактный маршрут, источник или ссылка рядом с подписью. |

### Методы

| Метод | Аргументы | Возвращает | Назначение |
|:---|:---|:---|:---|
| `onClick()` | — | не описано | — |

### События

Своих событий нет; общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

### Доступность

- Доступное имя: рекомендуется.
- Клавиши: `Tab`.
- Фокус: Сохраняет видимый фокус на активном элементе управления.

### Минимальная разметка

```html
<sf-reference-link label="Installation guide" text="/start/install/" href="/start/install/"></sf-reference-link>
```
