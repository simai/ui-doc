# Аккордеон

`<sf-accordion>` — секции, которые открываются и закрываются по нажатию на
шапку. Он собирает разметку [аккордеона](/ru/components/content/accordion/)
из данных или из элементов `<details>`, написанных внутри: те же размеры,
виды, метки и единственная секция.

:::

## Разметка

Секции задаёт `items` — массив `{id, title, content, open, disabled, icon, badge}`:
в свойстве — массивом, в атрибуте — тем же массивом в JSON. `id` называет
секцию в методах и событии; без него секция получает имя по месту
(`section-1`, `section-2`…).

- `content` — только текст. Разметку внутри секции передайте слотом:
  `{"id": "help", "title": "Справка", "slot": "help"}` и дочерний элемент со
  `slot="help"`.
- Без `items` компонент берёт элементы `<details>` со `<summary>`, написанные
  внутри него.

## Варианты

### Вид

`appearance` выбирает вид: `default` — секции на заливке, `outline` — тонкая
рамка без заливки, `flush` — без заливки и скругления, секции разделены
линией; для панелей и списков.

:::example {id="smart-components/accordion/appearance" label="Виды default, outline и flush"}
:::

### Размер

Без `size` шапка просторная, как на странице с текстом. `size` ставит
ступень лестницы элементов управления: шапка ровно такой высоты, как
`sf-input` и `sf-button` того же размера, — для панелей рядом с полями.

:::example {id="smart-components/accordion/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Метка

`marker` выбирает, чем отмечена открытая секция: шевроном (по умолчанию) или
плюсом и минусом (`plus-minus`).

:::example {id="smart-components/accordion/marker" label="Шеврон и плюс-минус"}
:::

### Одна открытая секция

`single` оставляет открытой только одну секцию: открытие другой закрывает
прежнюю. Так удобно читать вопросы и ответы.

:::example {id="smart-components/accordion/single" label="Вопросы и ответы, single"}
:::

### Секции из разметки

Если в секции нужны ссылки, списки или поля, напишите `<details>` прямо
внутри `<sf-accordion>`: компонент оформит их так же, как секции из данных.

:::example {id="smart-components/accordion/markup" label="Секции из элементов details"}
:::

## Состояния

### Открыта, закрыта, недоступна

`open: true` открывает секцию сразу. `disabled: true` делает шапку
недоступной: секция не открывается, а клавиатура её пропускает.

:::example {id="smart-components/accordion/state-disabled" label="Открытая, закрытая и недоступная секции"}
:::

### Единственная секция

Если секция одна, это обычный раздел: содержимое видно, шапка не
переключает. `single-section="toggle"` оставляет её раскрывающейся — для
списка, который пополнится позже.

:::example {id="smart-components/accordion/single-section" label="Одна секция: обычная и раскрывающаяся"}
:::

## Применение

### Когда брать аккордеон

Аккордеон — для частей одного содержания, которые человек открывает по
очереди: группы полей записи, разделы настроек, вопросы и ответы. Чтобы
переключаться между разными видами одного объекта, берите
[Вкладки](/ru/smart-components/navigation/tabs/).

### Управление из кода и событие

`open(id)`, `close(id)` и `toggle(id)` открывают и закрывают секцию и
возвращают, изменилось ли что-нибудь; `isOpen(id)` отвечает, открыта ли она.
Каждое открытие и закрытие отправляет `sf-accordion:toggle` с `id`, `open` и
`source`: `user` — нажал человек, `method` — вызван метод. В режиме `single`
закрытая при этом секция отправляет своё событие следом.

```js
const faq = document.querySelector('sf-accordion');
faq.addEventListener('sf-accordion:toggle', (event) => {
  if (event.detail.open) history.replaceState(null, '', `#${event.detail.id}`);
});
faq.open(location.hash.slice(1));
```

## Доступность

- Шапка каждой секции — кнопка внутри заголовка уровня `heading-level`
  (по умолчанию 3) с `aria-expanded` и `aria-controls`.
- `Enter` и `Space` открывают и закрывают секцию; `↓` и `↑` переходят между
  шапками по кругу, `Home` и `End` — к первой и последней. Недоступная шапка
  пропускается.
- Пока секций шесть или меньше, содержимое каждой — область, названная её
  шапкой.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `single` — `boolean`, по умолчанию `false`. Открыта только одна секция: открытие другой закрывает прежнюю.
- `size` — `string`, по умолчанию пусто, значения: пусто, `1/3`, `1/2`, `1`, `2`, `3`. Ступень лестницы элементов управления: шапка ровно такой высоты, как элемент этой ступени, — как sf-input и sf-button того же размера. Без него — просторная шапка страницы с текстом.
- `appearance` — `string`, по умолчанию `default`, значения: `default`, `outline`, `flush`. default: заливка поверхности; outline: тонкая рамка без заливки; flush: без заливки и скругления, секции разделены линией — для панелей и списков.
- `marker` — `string`, по умолчанию `chevron`, значения: `chevron`, `plus-minus`. Чем отмечена открытая или закрытая секция: шевроном или плюсом и минусом.
- `single-section` — `string`, по умолчанию `static`, значения: `static`, `toggle`. Одна секция — обычный раздел: содержимое видно, заголовок не переключает; toggle оставляет её раскрывающейся — для списка, который пополнится позже.
- `heading-level` — `integer`, по умолчанию `3`, значения: от 2; до 6. Уровень заголовка каждой секции (role heading, aria-level).
- `items` — `array` из `object`, по умолчанию `[]`, например `[{"id":"main","title":"Основное","content":"Название и описание","open":true},{"id":"seo","title":"SEO","content":"Заголовок страницы","badge":"3"}]`. Секции [{id, title, content | slot, open?, disabled?, icon?, badge?}]: массив в свойстве, тот же массив в JSON в атрибуте. Без items элемент берёт `<details>`, написанные внутри.

### Методы

- `open(id: any)` — возвращает `boolean`. Открывает секцию с этим id; в режиме single открытая закрывается. sf-accordion-toggle приходит для каждой изменившейся секции, source method. Возвращает, изменилось ли что-нибудь.
- `close(id: any)` — возвращает `boolean`. Закрывает секцию с этим id. Возвращает, изменилось ли что-нибудь.
- `toggle(id: any)` — возвращает `boolean`. Открывает секцию, если она закрыта, и закрывает, если открыта. Возвращает, изменилось ли что-нибудь.
- `isOpen(id: string)` — возвращает `boolean`. Открыта ли секция с этим id. Единственная секция открыта всегда.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `sf-accordion-toggle` — `detail`: `{ id: any, open: boolean, source: any, section: object }`.
- `sf-accordion:toggle` — устаревший псевдоним события `sf-accordion-toggle`: приходит с тем же `detail`, подписывайтесь на `sf-accordion-toggle`.

### Доступность

- Доступное имя: внутренний.
- Клавиши: `Tab`, `Enter`, `Space`, `ArrowDown`, `ArrowUp`, `Home`, `End`.
- Фокус: Шапка каждой секции — нативная кнопка внутри заголовка (role heading, aria-level) с aria-expanded и aria-controls; Enter и Space открывают и закрывают секцию. ArrowDown и ArrowUp переходят между шапками по кругу, Home и End — к первой и последней; недоступная шапка — недоступная кнопка, её пропускают и в порядок Tab она не входит. Пока секций шесть или меньше, каждая панель — область, названная своей шапкой. Единственная секция — обычный заголовок, в порядке Tab ничего нет.

### Минимальная разметка

```html
<sf-accordion single items='[{"id":"main","title":"Основное","content":"Название и описание","open":true},{"id":"seo","title":"SEO","content":"Заголовок страницы"}]'></sf-accordion>
```
