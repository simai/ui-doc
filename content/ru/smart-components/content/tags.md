# Tags

`<sf-tag>` — декларативная проекция обычного компонента «Теги». Компонент
сохраняет его классы, токены и семантику, а также управляет выбранным состоянием
и намерением удалить значение. Жизненный цикл — экспериментальный.

## Особенности применения

Статический тег только сообщает данные. Тип `checkbox` создаёт одну нативную
кнопку-переключатель; остальные типы создают статическую поверхность и при
необходимости отдельную кнопку удаления. Переключение и удаление не совмещаются
в одном экземпляре. Компонент не обращается к сети и не принимает решений за
приложение.

Живой пример появится после включения точного runtime Tags в закреплённую
проекцию ассетов `ui-doc`. До этого страница описывает проверенный исходный
контракт и не подменяет его незакреплённым скриптом.

## Оси, вид и размеры

У тега три отдельные оси, и раньше все три записывались одним атрибутом `type`.

| Ось | Атрибут | Что задаёт | Значения |
|:---|:---|:---|:---|
| Что несёт | `kind` | содержимое тега | `checkbox`, `icon`, `default`, `color`, `avatar` |
| О чём сообщает | `status` | смысл из общего статусного словаря | пусто, `info`, `success`, `warning`, `error` |
| Как выглядит | `appearance` | вид на неизвестном фоне | `default`, `surface`, `ghost` |

Размер задаётся атрибутом `size`: ступень `1/3`, `1/2`, `1`, `2` или `3` общей
размерной шкалы. Плотность — атрибутом `spacing` (`compact`, `normal`,
`comfortable`, `spacious`), как у кнопок. Логический атрибут `inline` ставит тег
на строку другого элемента: без отступов сверху и снизу, с кнопкой удаления
высотой в строку. Атрибут `line` (`1/2`, `1`, `2`) делает то же для ячейки
таблицы: тег становится строчным, на размер меньше, и встаёт в строку текста
этого размера, поэтому строка таблицы не растёт. Подробнее — на странице
[Tags](/ru/components/content/tags/).

Прежнее имя `type` продолжает работать и считается устаревшим: оно читается как
`kind`, а его статусные значения — как `status`. Старое значение `quantity`
читается как `default`. В новой разметке берите имена осей.

## Содержимое

- `text` — видимая подпись;
- `count` — вспомогательное число для типа `default`;
- `icon` — имя декоративной иконки Framework;
- `color-class` — семантическая цветовая утилита маркера;
- `avatar-image-url`, `avatar-text`, `avatar-status` — данные аватара;
- `root-class` — дополнительные утилиты Framework на видимом корне.

Слоты `leading`, `text`, `count`, `avatar` и `close` позволяют заменить
соответствующую часть шаблона. Замена должна сохранять владельца действия:
декоративный маркер не входит в Tab-порядок, а слот удаления содержит ровно одну
нативную кнопку с доступным именем.

## Выбор

У тега `kind="checkbox"` (прежняя запись — `type="checkbox"`) атрибут `active` отражается в `aria-pressed`. Нажатие меняет
состояние и создаёт всплывающее событие `change` с `detail.active` и
`detail.component`. Атрибут `disabled` запрещает действие и его событие.

## Удаление

Атрибут `closable` включает отдельную кнопку удаления у статического тега; для
типов `icon`, `color` и `avatar` она включена по умолчанию. `close-label` задаёт
её доступное имя; по умолчанию это Remove, а на странице с `lang="ru"` — «Удалить». Успешное действие создаёт всплывающее событие `close` с
владельцем в `detail.component`. Для `checkbox` удаление всегда отключено.

## Интерактивный тег

Атрибут `interactive` (для всех типов, кроме `checkbox`) делает подпись тега
кнопкой, а кнопка удаления остаётся отдельной рядом. Используйте его, когда тег
что-то открывает, например меню фильтра: тег доступен по Tab, открывается Enter
или пробелом, а обработчик `click` на теге получает нажатия по подписи, но не по
кнопке удаления. Так устроены чипы фильтра в `<sf-table>`.

## Доступность

Видимый текст именует статическую подпись. Для переключателя можно уточнить имя
через `aria-label`, для удаления обязательно конкретное `close-label`. В
Tab-порядок входят только нативные действия. Фокус показывается при клавиатурной
навигации и остаётся различимым в режиме принудительных цветов.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-257f66def2b8` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-tag>` |
| Назначение | Компактные статические, выбираемые и удаляемые метки с одним явным владельцем взаимодействия. |
| Контракт | `smart.tags`, версия `1.1.0` |
| Поставка | выпуск Framework `ui-257f66def2b8` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |
| Готовность | принят в продукт |

### Атрибуты

- `template` — `string`, по умолчанию `default`, значения: `default`. Имя шаблона.
- `kind` — `string`, по умолчанию `checkbox`, значения: `checkbox`, `icon`, `default`, `color`, `avatar`. Содержимое тега: флажок, иконка, цвет, аватар или только подпись. Значение совместимости quantity также принимается и означает default.
- `status` — `string`, по умолчанию пусто, значения: пусто, `info`, `success`, `warning`, `error`. О чём сообщает тег, в общем словаре статусов. Оставьте пустым для тега, который ни о чём не сообщает.
- `appearance` — `string`, по умолчанию `default`, значения: `default`, `surface`, `ghost`. Внешний вид на основе нейтральной шкалы прозрачности, независимый от типа: surface сохраняет лёгкую заливку и границу, ghost не имеет ничего до наведения. Применяется только к нейтральным типам, потому что тег статуса передаёт смысл цветом.
- `size` — `string`, по умолчанию `1/2`, значения: `1/3`, `1/2`, `1`, `2`, `3`. Токен размера Framework: задаёт текст подписи и отступы по умолчанию.
- `line` — `string`, по умолчанию пусто, значения: пусто, `1/2`, `1`, `2`. Занимает строку текста этого размера формы как встроенный тег на размер меньше — для ячейки таблицы, чтобы строка сохраняла высоту элемента управления. Переопределяет size и inline.
- `spacing` — `string`, по умолчанию `normal`, значения: `compact`, `normal`, `comfortable`, `spacious`. Вертикальные отступы отдельного тега с теми же названиями, что у кнопок.
- `inline` — `boolean`, по умолчанию `false`. Размещается на строке текста другого элемента управления: без вертикальных отступов, с подписью вровень и кнопкой удаления высотой в строку. Хост может задать --sf-tag--line.
- `text` — `string`, по умолчанию пусто. Видимая подпись тега.
- `count` — `string`, по умолчанию пусто. Необязательный счётчик, отображаемый в теге по умолчанию.
- `icon` — `string`, по умолчанию пусто. Имя декоративной иконки Framework.
- `color-class` — `string`, по умолчанию пусто. Семантическая утилита фона Framework для цветового маркера.
- `avatar-image-url` — `string`, по умолчанию пусто. URL изображения аватара; доступной подписью остаётся видимый текст.
- `avatar-text` — `string`, по умолчанию пусто. Инициалы аватара на случай отсутствия изображения.
- `root-class` — `string`, по умолчанию пусто. Утилитарные классы Framework для видимого корневого элемента.
- `avatar-status` — `string`, по умолчанию пусто. Зарезервированное значение статуса аватара для совместимых шаблонов.
- `active` — `boolean`, по умолчанию `false`. Состояние выбора тега-флажка.
- `disabled` — `boolean`, по умолчанию `false`. Отключает интерактивные действия переключения и закрытия.
- `closable` — `boolean`, по умолчанию `false`. Показывает отдельное действие удаления; у тегов с иконкой, цветом и аватаром оно включено по умолчанию, у тега-флажка — только когда атрибут задан.
- `interactive` — `boolean`, по умолчанию `false`. Отображает подпись как кнопку рядом с действием удаления — для тегов, которые что-то открывают (например, меню фильтра-чипа); для тегов-флажков игнорируется.
- `aria-label` — `string`, по умолчанию пусто. Необязательное переопределение доступного имени для выбираемого тега.
- `close-label` — `string`, по умолчанию `Remove`. Доступное имя действия удаления. По умолчанию Remove, на русской странице — Удалить.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `kind` | `type` | работает и предупреждает | 2026-12-01 |
| `status` | `type` | работает и предупреждает | 2026-12-01 |
| `status="error"` | `status="danger"` | работает и предупреждает | 2026-12-01 |
| `status="error"` | `status="critical"` | работает и предупреждает | 2026-12-01 |
| `kind="default"` | `kind="quantity"` | работает и предупреждает | 2026-12-01 |

### Методы

- `onToggle()` — Переключает включённый тег-флажок и отправляет его новое активное состояние.
- `onClose()` — Отправляет намерение удаления для доступного закрываемого тега.

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `change` — `detail` не описан. Изменилось активное состояние тега-флажка.
- `close` — `detail` не описан. Удаление запрошено через отдельно названное действие закрытия.

### Доступность

- Доступное имя: обязательно.
- Клавиши: `Tab`, `Enter`, `Space`.
- Фокус: В порядок табуляции входят только нативные действия переключения и закрытия. Фокус видим при работе с клавиатуры, не меняет геометрию и безопасен для режима forced colors.

### Минимальная разметка

```html
<sf-tag type="default" text="Documentation"></sf-tag>
```
