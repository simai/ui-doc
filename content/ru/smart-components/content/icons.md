# Иконки

`<sf-icon>` выводит один символ Material Symbols по имени и сообщает Loader,
какие знаки шрифта загрузить. Внешний вид — размер, начертание, заливка,
толщина — задаётся атрибутами на общей шкале Framework. Элемент строится на
классах компонента [Иконки](/ru/components/content/icons/). Для иконки,
которую нажимают, берите
[Кнопки с иконкой](/ru/smart-components/actions/icon-buttons/).

## Применение

### Имя и загрузка

`icon` — имя символа из набора Material Symbols, например `home` или
`settings`. Loader отслеживает каждый `<sf-icon>` и загружает знаки шрифта,
нужные странице, в том числе после смены `icon`. Пока знак не загружен,
иконка сжата до нуля, и имя символа не мелькает текстом. Атрибут `loaded`
компонент ставит сам, когда знак готов; задавать его в разметке не нужно.

### Размер

`size` выбирает ступень шкалы размеров иконок: `1/4`, `1/3`, `1/2`, `1` —
`7`. Без `size` иконка получает размер ступени `3`. Рядом с подписью берите
ступень, которая совпадает с высотой строки текста.

### Счётчик и точка

- `badge-count` — счётчик на иконке: целое число больше `0`; `0` или пусто
  прячет бейдж.
- `badge-dot` — точка без числа: есть новое.
- `badge-cap` — порог, по умолчанию `99`: число больше порога показывается как
  `99+`.
- `badge-label` — свои слова вместо «непрочитанных» и «есть новое»: формы
  множественного числа через `|` с `{count}` на месте числа.

С бейджем иконка встаёт в обёртку `sf-badge-anchor` своего размера. Размер
бейджа следует `size`: от `1/4` до `2` рисуется точка, `3` и без `size` —
малый счётчик, `4` и `5` — средний, `6` и `7` — крупный. С `label` обёртка
становится изображением с именем «Почта, 3 непрочитанных»; без `label` фраза
звучит скрытым текстом. Устройство бейджа описано в разделе
[Бейдж на якоре](/ru/components/feedback/badges/#бейдж-на-якоре).

### Начертание и оси шрифта

- `type` — начертание: `outlined`, `rounded` или `sharp`. Без него
  действует начертание проекта из `SF_BOOT_CONFIG.icons.type`, а если оно не
  задано — `outlined`. Держите одно начертание во всём интерфейсе.
- `filled` включает заливку — например, для выбранного состояния.
- `weight` — толщина линии от `100` до `700` с шагом 100, по умолчанию `400`.
- `grade` (от `-50` до `200`) и `optical-size` (от `20` до `48`) — тонкая
  настройка осей шрифта; значения вне диапазона приводятся к границе.

```html
<sf-icon icon="star" filled weight="600" size="2"></sf-icon>
```

## Доступность

- Без `label` иконка декоративна и скрыта от экранного диктора
  (`aria-hidden="true"`). Так и нужно, когда смысл передаёт текст рядом или
  имя кнопки, в которой стоит иконка: не задавайте `label` иконке внутри
  уже названной кнопки.
- Самостоятельной иконке, которая сообщает смысл, задайте `label`: элемент
  получит `role="img"` и это доступное имя.
- Иконка не получает фокус и не реагирует на клавиатуру. Действие делайте
  кнопкой.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-bc1fb36ec8f1` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-icon>` |
| Назначение | Семантическая обёртка Material Symbol с точным отслеживанием в Loader, доступными декоративным и информативным режимами и геометрией из токенов. |
| Контракт | `smart.icon`, версия `1.1.4` |
| Поставка | выпуск Framework `ui-bc1fb36ec8f1` |
| [Жизненный цикл](/ru/guide/smart-components/connection/#готовность-компонента-к-использованию) | экспериментальный: API может меняться между выпусками |
| [Готовность](/ru/guide/smart-components/connection/#готовность-компонента-к-использованию) | описан: манифест и сценарий есть, продуктовой приёмки нет |
| Заготовка до прихода кода | нет: атрибут `data-sf-skeleton` не пишется; своего скелетона при загрузке данных нет ([Заготовка до прихода кода](/ru/guide/smart-components/states-and-loading/#заготовка-до-прихода-кода)) |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `icon` — `string`, по умолчанию пусто.
- `filled` — `boolean`, по умолчанию `false`.
- `weight` — `integer`, по умолчанию `400`, значения: от 100; до 700.
- `size` — `string`, по умолчанию пусто, значения: пусто, `1/4`, `1/3`, `1/2`, `1`, `2`, `3`, `4`, `5`, `6`, `7`.
- `type` — `string`, по умолчанию пусто, значения: пусто, `outlined`, `rounded`, `sharp`.
- `grade` — `integer`, по умолчанию `0`, значения: от -50; до 200.
- `optical-size` — `number`, по умолчанию `24`, значения: от 20; до 48.
- `label` — `string`, по умолчанию пусто.
- `badge-count` — `string`, по умолчанию пусто. Счётчик на иконке: целое число больше 0 показывается, 0 или пусто прячет бейдж. Больше badge-cap он показывается как порог с плюсом, например «99+»; точное число входит в доступное имя иконки («Почта, 3 непрочитанных») и во всплывающую подсказку бейджа. На якоре размера 1/3 или 1/2 счётчик рисуется точкой.
- `badge-dot` — `boolean`, по умолчанию `false`. Точка на иконке — отметка без числа: есть новое. Показывается, когда badge-count не задан; при заданном счётчике он рисуется точкой. Её текстовый эквивалент («есть новое» / «new» по умолчанию, другой задаёт badge-label) входит в доступное имя.
- `badge-cap` — `integer`, по умолчанию `99`, значения: от 1. Наибольший счёт, который рисуется числом; больший показывается как порог с плюсом, например «99+».
- `badge-label` — `string`, по умолчанию пусто. Слова, которые бейдж добавляет к доступному имени и к всплывающей подсказке вместо слов по умолчанию для языка страницы: для точки — весь текстовый эквивалент; для счёта — фраза в формах множественного числа через «|» (one|few|many для русского, one|other для английского) с {count} на месте числа.
- `loaded` — `boolean`, по умолчанию `false`. Точное подмножество, рисующее этот символ, на месте; синхронизируется из Loader, это не переключатель для автора

### Методы

Публичных методов нет.

### События

Своих событий нет; общие события базового элемента перечислены в главе [Жизненный цикл → Этапы](/ru/guide/smart-components/lifecycle/#этапы).

### Доступность

- Роль: изображение (`img`).
- Доступное имя: рекомендуется.
- Фокус: Иконка не интерактивна и никогда не попадает в порядок табуляции. Задавайте имя содержащему её элементу управления.

### Минимальная разметка

```html
<sf-icon icon="home"></sf-icon>
```
