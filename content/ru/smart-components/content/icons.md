# Icons

## Доступность

Перед использованием проверьте доступное имя, порядок фокуса, управление клавиатурой и объявление состояний. Сгенерированная API-страница подтверждает source-контракт, но не заменяет сценарный accessibility smoke.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-d34117c9f3f0` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-icon>` |
| Назначение | Семантическая обёртка Material Symbol с точным отслеживанием в Loader, доступными декоративным и информативным режимами и геометрией из токенов. |
| Контракт | `smart.icons`, версия `1.0.0` |
| Поставка | выпуск Framework `ui-d34117c9f3f0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |
| Готовность | описан: манифест и сценарий есть, продуктовой приёмки нет |

### Атрибуты

- `icon` — `string`, по умолчанию пусто.
- `loaded` — `boolean`, по умолчанию `false`.
- `filled` — `boolean`, по умолчанию `false`.
- `weight` — `number`, по умолчанию `400`.
- `size` — `string`, по умолчанию пусто, значения: пусто, `1/4`, `1/3`, `1/2`, `1`, `2`, `3`, `4`, `5`, `6`, `7`.
- `type` — `string`, по умолчанию пусто, значения: пусто, `outlined`, `rounded`, `sharp`, `shape`.
- `grade` — `number`, по умолчанию `0`, значения: от -50; до 200.
- `optical-size` — `number`, по умолчанию `24`, значения: от 20; до 48.
- `label` — `string`, по умолчанию пусто.

### Методы

Публичных методов нет.

### События

Своих событий нет; общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

### Доступность

- Роль: `img`, если задан label; скрыт, если декоративный.
- Доступное имя: рекомендуется.
- Фокус: Иконка не интерактивна и никогда не попадает в порядок табуляции. Задавайте имя содержащему её элементу управления.

### Минимальная разметка

```html
<sf-icon icon="home"></sf-icon>
```
