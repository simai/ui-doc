# Строка списка

`<sf-list-item>` описывает один вариант [Выпадающий список](/ru/smart-components/navigation/dropdown/):
машинное значение, подпись и вид строки — текст, иконка, флажок, аватар или
цветовой маркер. В Dropdown список, фокус, выбор и значение формы принадлежат
родительскому Dropdown. Тот же элемент служит общей строкой списка для
интерфейсов администрирования, чата и редакторов: вторая строка, выбор,
клавиатура и перестановка в `sf-sortable` — см. [Строка списка](#строка-списка).

## Применение

### Строка списка

Вне Dropdown `<sf-list-item>` — общая строка списка: писем, диалогов,
блоков редактора, записей. Высота однострочной строки равна высоте элемента
управления своего размера, места `leading`, `text` и `trailing` те же, что у
варианта Dropdown. В Dropdown эти возможности выключены, и варианты
выглядят как прежде.

| Атрибут | Что даёт |
|:---|:---|
| `supporting` или потомок `slot="supporting"` | Вторая строка под заголовком, на ступень лестницы меньше (строки 1/3 и 1/2 — 1/3; 1 — 1/2; 2 — 1; 3 — 2). Двухстрочная строка выше на эту строку. Виды `text`, `icon` и `checkbox`. |
| `interactive` | Строка, с которой работают: наведение, фокус с клавиатуры и `selected`, указатель-рука и событие `sf-list-item-activate` (`detail: {value, trigger}`) по щелчку или `Enter`. Щелчок по элементу управления внутри строки, например по действию в `trailing`, принадлежит этому элементу, а не строке. |
| `sortable-item="<id>"` | Строка — элемент окружающего `sf-sortable`: получает ручку перетаскивания перед содержимым и `data-sf-sortable-item` на своём блоке. |
| `pinned` | Строка списка, которая не двигается: без ручки и не элемент `sf-sortable`. Место ручки остаётся пустым, поэтому текст начинается там же, где у остальных строк. |

**Одна остановка `Tab` на список.** Интерактивные и перемещаемые строки —
одна остановка своего списка: ближайшего `sf-sortable`, `[role="listbox"]`,
`[role="list"]` или `[data-sf-list]`, иначе родителя строки. `Tab` попадает
на строку, где фокус был в последний раз, иначе на выбранную, иначе на
первую; стрелки вверх и вниз, `Home` и `End` переходят между строками и
пропускают недоступные. Элемент управления в `trailing` — своя остановка
`Tab`; чтобы остановка на списке осталась одна, дайте ему `tabindex="-1"` и
повторите действие другим путём, например контекстным меню строки.

**В `sf-sortable`.** Пробел или `Enter` берут строку, стрелки двигают, пробел
или `Enter` кладут — как у любого элемента списка; поэтому `Enter` не
активирует перемещаемую строку, это делает щелчок. Ручка видна на строке под
указателем и на строке с фокусом, на сенсорном экране — всегда; её место
сохраняется, и ничего не сдвигается. Хост, который перерисовывает список по
`sf-sortable-intent`, переставляет сами элементы `sf-list-item`.

### Место в разметке

Ставьте `<sf-list-item>` прямым потомком `<sf-dropdown>`. Dropdown читает
атрибуты пунктов до первой отрисовки и строит из них список. Пункт вне
Dropdown без `interactive` и `sortable-item` показывается статичной строкой:
без роли, фокуса и реакции на нажатие. Его нельзя использовать как кнопку,
ссылку или отдельный флажок.

### Значение и подпись

`value` — машинное значение, которое уходит в форму и в событие `change`
Dropdown; без `value` значением становится `text`. `text` — видимая подпись,
она же доступное имя варианта. `selected` отмечает вариант выбранным при
загрузке, `disabled` запрещает его выбор. `group` объединяет идущие подряд
пункты под одним заголовком.

### Вид строки

Вид строки задаёт атрибут `type`:

- `text` — только подпись, вид по умолчанию;
- `icon` — иконка из `icon` перед подписью;
- `checkbox` — флажок, который повторяет выбранное состояние;
- `avatar` — аватар из `avatar-image-url` с подписью из `avatar-title`
  (по умолчанию — `text`);
- `color` — цветовой маркер; цвет задаёт утилита фона в `color-class`,
  например `bg-error`.

Манифест называет эту ось `kind`, а `type` — прежним именем. Dropdown читает
у дочерних пунктов только `type`, поэтому внутри Dropdown вид строки задавайте
им.

`size` — ступень `1/3`, `1/2`, `1`, `2` или `3`. Без него пункт берёт размер
своего Dropdown.

```html
<sf-dropdown name="owner" label="Ответственный" placeholder="Выберите ответственного">
  <sf-list-item value="anna" type="avatar" text="Анна Белова" avatar-image-url="/team/anna.jpg"></sf-list-item>
  <sf-list-item value="ivan" type="avatar" text="Иван Петров" avatar-image-url="/team/ivan.jpg"></sf-list-item>
</sf-dropdown>
```

## Доступность

- В Dropdown каждый пункт получает `role="option"`, `aria-selected` и
  `aria-disabled`. Имя варианта — `text`; `aria-label` заменяет его, если
  подпись сокращена или неоднозначна.
- Клавиши принадлежат Dropdown: стрелки перемещают по вариантам, `Home` и
  `End` — к первому и последнему, `Enter` и пробел выбирают, `Escape`
  закрывает список.
- Иконка, аватар, цветовой маркер и флажок декоративны и не создают
  отдельных остановок `Tab`. Не кладите в пункт ссылки, кнопки и поля: у
  варианта списка может быть только одно действие — выбор.
- Цвет маркера не должен быть единственным различием между вариантами:
  подпись называет вариант словами.
- В строке списка роль у самого списка: выбранная строка получает
  `aria-current="true"`, недоступная — `aria-disabled="true"`. Фокус с
  клавиатуры рисуется внутренней рамкой строки.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| Назначение | Строка: вариант, который забирает `sf-dropdown`, или общая строка списка — дополнительная строка, строка с действием, элемент списка `sf-sortable`, закреплённая строка. |
| Контракт | `smart.list-item`, версия `1.2.3` |
| Поставка | выпуск Framework `ui-bc1fb36ec8f1` |
| [Жизненный цикл](/ru/guide/smart-components/connection/#готовность-компонента-к-использованию) | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `value` — `string`, по умолчанию пусто. id строки: машинное значение, которое читает родительский `sf-dropdown`, и id, который несёт её просьба open
- `kind` — `string`, по умолчанию `text`, значения: `text`, `icon`, `checkbox`, `avatar`, `color`. Содержимое элемента списка: простой текст, иконка, флажок, аватар или цвет.
- `size` — `string`, по умолчанию `1`, значения: `1/3`, `1/2`, `1`, `2`, `3`.
- `text` — `string`, по умолчанию пусто.
- `icon` — `string`, по умолчанию `person`.
- `disabled` — `boolean`, по умолчанию `false`.
- `color-class` — `string`, по умолчанию `bg-tertiary`.
- `avatar-image-url` — `string`, по умолчанию пусто.
- `avatar-title` — `string`, по умолчанию пусто. Заголовок строки аватаров; пусто — берётся text
- `supporting` — `string`, по умолчанию пусто. Вторая строка под заголовком
- `interactive` — `boolean`, по умолчанию `false`. Строка, с которой человек что-то делает: одна остановка Tab в своём списке, открывается нажатием или Enter
- `sortable-item` — `string`, по умолчанию пусто. id элемента строки в окружающем списке `sf-sortable`; рисует ручку перетаскивания
- `pinned` — `boolean`, по умолчанию `false`. Строка списка `sf-sortable`, которая не переносится: без ручки, её место сохраняется
- `checked` — `boolean`, по умолчанию `false`.
- `selected` — `boolean`, по умолчанию `false`.
- `aria-label` — `string`, по умолчанию пусто.

Свойство атрибута `value` называется `itemValue`.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `kind` | `type` | работает, отмечается в `SF.deprecations` | 2026-12-01 |

### Методы

Публичных методов нет.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components-2/names/). Общие события базового элемента перечислены в главе [Жизненный цикл → Этапы](/ru/guide/smart-components/lifecycle/#этапы).

- `sf-list-item-open` — `detail`: `{ id: string, trigger: any }`. Человек нажал на интерактивную строку или Enter на ней: open `{id}` словаря 1.1.5 §5, где id — это value
- `sf-list-item-activate` — `detail`: `{ value: string, trigger: any }`. По интерактивной строке щёлкнули или нажали Enter (не по элементу управления внутри неё и не Enter в строке списка sf-sortable, где Enter берёт строку для перемещения).

### Доступность

- Роль: нет (`none`).
- Доступное имя: обязательно.
- Клавиши: `ArrowDown`, `ArrowUp`, `Home`, `End`, `Enter`, `Space`, `Escape`.
- Фокус: Для пунктов фокусом владеет родительский Dropdown; отдельный предпросмотр не получает фокус; интерактивная или перемещаемая строка — перемещаемая остановка Tab своего списка, с внутренней рамкой фокуса.

### Минимальная разметка

```html
<sf-dropdown label="Статус"><sf-list-item value="open" text="Открыт"></sf-list-item><sf-list-item value="done" text="Готов"></sf-list-item></sf-dropdown>
```
