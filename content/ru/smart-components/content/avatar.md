# Аватар

`<sf-avatar>` показывает одного человека или одну организацию: фотографию,
инициалы или значок-заполнитель, при необходимости — состояние в сети или
отметку проверенного профиля. Элемент строится на классах компонента
[Аватары](/ru/components/content/avatars/); для готовых сочетаний аватаров со
ссылкой или группой есть [Аватары](/ru/smart-components/content/avatars/).

## Применение

### Что показывает аватар

Содержимое выбирается по порядку: изображение из `image-url`, затем текст из
`text`, затем инициалы, которые компонент берёт из `title` или из явно
заданного `aria-label`. Если нет ничего из этого, показывается значок
человека. Изображение декоративно: имя человека передаёт `aria-label`, а не
альтернативный текст картинки.

### Шаблоны

`template` выбирает раскладку:

- `default` — один аватар;
- `label` — аватар с подписью: `title` — имя, `description` — вторая строка.
  `no-wrap` обрезает обе строки многоточием вместо переноса;
- `card` — карточка: изображение, `title` и строка `meta` (или `description`)
  со значком `meta-icon`. `card-variant` задаёт пропорции изображения:
  `square` или `portrait`, а `image-alt` — его альтернативный текст.

### Размер и форма

`size` выбирает ступень от `1/4` до `3` (по умолчанию `1`). Рядом с подписью
в строке или в ячейке таблицы задайте `line` со значением `1/2`, `1` или `2`:
аватар займёт строку текста этого размера формы, и строка не станет выше.
`shape="square"` делает аватар квадратным — для организаций и проектов.

### Состояние

`status` добавляет индикатор в углу аватара: `online` и `offline` — точка
присутствия, `company` и `verified` — значок организации и проверенного
профиля. Индикатор декоративный, поэтому называйте состояние и в
`aria-label`. Слоты `online-indicator`, `company-badge` и `verified-badge`
заменяют соответствующий значок своим.

### Счётчик и точка

- `badge-count` — счётчик в верхнем конце аватара: целое число больше `0`;
  `0` или пусто прячет бейдж. Размер бейджа следует `size`: на `1/4`, `1/3` и
  `1/2` число рисуется точкой.
- `badge-dot` — точка без числа: есть новое.
- `badge-cap` — порог, по умолчанию `99`: число больше порога показывается как
  `99+`.
- `badge-label` — свои слова вместо «непрочитанных» и «есть новое»: формы
  множественного числа через `|` с `{count}` на месте числа.

Фраза добавляется к имени кнопки: «Анна Белова, 3 непрочитанных», и в имени
всегда точное число. Индикатор `status` остаётся в нижнем конце. Устройство
бейджа описано в разделе
[Бейдж на якоре](/ru/components/feedback/badges/#бейдж-на-якоре).

### Нажатие и создание из скрипта

В шаблонах `default` и `label` аватар — нативная кнопка. Своих событий у
элемента нет: открытие профиля или меню повесьте на обычный `click`.
`disabled` выключает кнопку.

```js
const avatar = await SF.createAsync('avatar', {
  text: 'АБ',
  ariaLabel: 'Анна Белова',
  status: 'online',
});
document.querySelector('.team').append(avatar);
avatar.addEventListener('click', () => openProfile('anna'));
```

## Доступность

- Аватар в шаблонах `default` и `label` — кнопка в порядке `Tab`. Задайте
  ей `aria-label` с именем человека; без него кнопка называется «Аватар» на
  русской странице и «Avatar» на остальных, а такое имя ничего не сообщает.
- Изображение и значки состояния скрыты от экранного диктора. Если состояние
  важно, включите его в имя: «Мария Козлова, в сети».
- В шаблоне `label` видимое имя в `title` и `aria-label` кнопки дублируют
  друг друга по смыслу — так и должно быть: кнопка получает имя, подпись
  остаётся текстом рядом.
- В шаблоне `card` кнопки нет; альтернативный текст изображения задаёт
  `image-alt`.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `size` — `string`, по умолчанию `1`, значения: `1/4`, `1/3`, `1/2`, `1`, `2`, `3`.
- `line` — `string`, по умолчанию пусто, значения: пусто, `1/2`, `1`, `2`. Занимает строку текста этого размера формы вместо высоты элемента управления — для аватара рядом с подписью в строке или ячейке таблицы.
- `shape` — `string`, по умолчанию `circle`, значения: `circle`, `square`.
- `image-url` — `string`, по умолчанию пусто.
- `image-alt` — `string`, по умолчанию пусто.
- `no-wrap` — `boolean`, по умолчанию `false`.
- `text` — `string`, по умолчанию пусто.
- `status` — `string`, по умолчанию `none`, значения: `none`, `online`, `offline`, `company`, `verified`.
- `heading` — `string`, по умолчанию пусто.
- `description` — `string`, по умолчанию пусто.
- `meta` — `string`, по умолчанию пусто.
- `meta-icon` — `string`, по умолчанию пусто.
- `card-variant` — `string`, по умолчанию `square`, значения: `square`, `portrait`.
- `disabled` — `boolean`, по умолчанию `false`.
- `badge-count` — `string`, по умолчанию пусто. Счётчик на аватаре: целое число больше 0 показывается, 0 или пусто прячет бейдж. Больше badge-cap он показывается как порог с плюсом, например «99+»; точное число входит в доступное имя аватара («Анна Белова, 3 непрочитанных») и во всплывающую подсказку бейджа. На якоре размера 1/3 или 1/2 счётчик рисуется точкой.
- `badge-dot` — `boolean`, по умолчанию `false`. Точка на аватаре — отметка без числа: есть новое. Показывается, когда badge-count не задан; при заданном счётчике он рисуется точкой. Её текстовый эквивалент («есть новое» / «new» по умолчанию, другой задаёт badge-label) входит в доступное имя.
- `badge-cap` — `integer`, по умолчанию `99`, значения: от 1. Наибольший счёт, который рисуется числом; больший показывается как порог с плюсом, например «99+».
- `badge-label` — `string`, по умолчанию пусто. Слова, которые бейдж добавляет к доступному имени и к всплывающей подсказке вместо слов по умолчанию для языка страницы: для точки — весь текстовый эквивалент; для счёта — фраза в формах множественного числа через «|» (one|few|many для русского, one|other для английского) с {count} на месте числа.
- `aria-label` — `string`, по умолчанию пусто. Пусто — текст на языке страницы (по-английски «Avatar»).
- `title` — `string`, по умолчанию пусто. Псевдоним с датой для `heading` до 2026-12-01.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `status="error"` | `status="danger"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `status="error"` | `status="critical"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
