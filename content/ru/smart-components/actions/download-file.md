# Download File

## Доступность

Перед использованием проверьте доступное имя, порядок фокуса, управление клавиатурой и объявление состояний. Сгенерированная API-страница подтверждает source-контракт, но не заменяет сценарный accessibility smoke.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-257f66def2b8` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-download-file>` |
| Назначение | Нативная загрузка файла или подготовка файла силами приложения. |
| Контракт | `smart.download-file`, версия `1.0.0` |
| Поставка | выпуск Framework `ui-257f66def2b8` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |
| Готовность | описан: манифест и сценарий есть, продуктовой приёмки нет |

### Атрибуты

- `template` — `string`, по умолчанию `default`, значения: `default`.
- `size` — `string`, по умолчанию `1`, значения: `1/3`, `1/2`, `1`, `2`, `3`. Существующая шкала размеров компонентов от компактного до крупного.
- `file-name` — `string`, по умолчанию `File.pdf`. Видимое имя файла и нативное имя для скачивания по умолчанию.
- `file-size` — `string`, по умолчанию пусто. Известный размер в удобочитаемом виде. Передавайте, если он доступен, чтобы не определять его.
- `icon` — `string`, по умолчанию `download`. Имя декоративной иконки.
- `href` — `string`, по умолчанию пусто. Реальное место ресурса; в доступном состоянии отрисовывает нативную ссылку (`a`).
- `download` — `boolean`, по умолчанию `false`. Применяет к ссылке нативную семантику скачивания.
- `disabled` — `boolean`, по умолчанию `false`. Отображает отключённую кнопку без действующего адреса перехода.
- `target` — `string`, по умолчанию `_blank`.
- `aria-label` — `string`, по умолчанию пусто.

### Методы

Публичных методов нет.

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `sf-download-file:click` — `detail` не описан. Отправляется один раз для доступного нативного места назначения или действия, которым владеет приложение.

### Доступность

- Доступное имя: рекомендуется.
- Клавиши: `Tab`.
- Фокус: Сохраняет видимый фокус на активном элементе управления.

### Минимальная разметка

```html
<sf-download-file file-name="Report.pdf" file-size="2.4 MB" href="/files/report.pdf" download></sf-download-file>
```
