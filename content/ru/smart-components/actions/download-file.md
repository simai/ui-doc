# Скачивание файла

`<sf-download-file>` показывает файл, который можно скачать: иконку, имя и
размер. С адресом он становится нативной ссылкой, без адреса — кнопкой, по
которой приложение само готовит файл. Оформление совпадает с обычным
компонентом [«Скачать файл»](/ru/components/actions/download-file/).

## Применение

### Ссылка на готовый файл

`href` с адресом файла рисует ссылку. С `download` браузер скачивает файл под
именем из `file-name`, а не открывает его. Без `download` ссылка открывается в
`target`, по умолчанию `_blank`, с `rel="noopener noreferrer"`.

`file-name` — видимое имя файла, по умолчанию `File.pdf`, поэтому задавайте
его всегда. `file-size` — размер, как его прочтёт человек: «2,4 МБ».
Если `file-size` пуст, компонент запрашивает адрес методом `HEAD` и
показывает размер из заголовка `Content-Length` в английских единицах;
передавайте размер сами, когда он известен.

### Файл, который готовит приложение

Без `href` компонент рисует кнопку. Нажатие отправляет событие
`sf-download-file:click`, и приложение собирает файл — отчёт, выгрузку,
архив. Пока файл не готов, показывайте это рядом или переключите элемент в
`disabled`.

`disabled` рисует недоступную кнопку без адреса, даже если `href` задан.
`icon` меняет иконку перед именем, `size` — размер по шкале `1/3`, `1/2`,
`1`, `2`, `3`.

### Событие `sf-download-file:click`

Событие отправляется с внутренней ссылки или кнопки и всплывает до
`document`. Его `event.detail`:

| Поле | Содержимое |
|:---|:---|
| `href` | адрес файла; у кнопки без адреса — пустая строка |
| `fileName` | имя файла |
| `download` | `true`, если задан `download` |

Недоступный элемент события не отправляет.

```js
document.addEventListener('sf-download-file:click', async (event) => {
  if (event.detail.href) return;
  const file = await buildReport();
  saveFile(file, event.detail.fileName);
});
```

## Доступность

- Доступное имя ссылки или кнопки складывается из имени и размера файла.
  `aria-label` заменяет его целиком: если задаёте его, включите в него имя
  файла, например «Скачать отчёт за квартал, PDF, 2,4 МБ».
- Ссылка и кнопка — одна остановка `Tab`; ссылка срабатывает по `Enter`,
  кнопка — по `Enter` и `Space`. Иконка скрыта от вспомогательных
  технологий.
- Ссылка без `download` открывает новую вкладку. Если это важно, скажите об
  этом в подписи рядом.
- Когда приложение готовит файл, сообщите о готовности или ошибке в области
  с `role="status"`: само нажатие ничего не объявляет.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| [Готовность](/ru/guide/smart-components/quality/#готовность-компонента-к-использованию) | описан: манифест и сценарий есть, продуктовой приёмки нет |
| Заготовка до прихода кода | нет: атрибут `data-sf-skeleton` не пишется; своего скелетона при загрузке данных нет ([Коробка до кода](/ru/guide/smart-components/first-paint/#коробка-до-кода)) |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `size` — `string`, по умолчанию `1`, значения: `1/3`, `1/2`, `1`, `2`, `3`. Существующая шкала размеров компонентов от компактного до крупного.
- `file-name` — `string`, по умолчанию `File.pdf`. Видимое имя файла и нативное имя для скачивания по умолчанию.
- `file-size` — `string`, по умолчанию пусто. Размер текстом (2,4 МБ); пусто при заданном href — размер спрашивается одним запросом HEAD
- `icon` — `string`, по умолчанию `download`. Имя декоративной иконки.
- `href` — `string`, по умолчанию пусто. Реальное место ресурса; в доступном состоянии отрисовывает нативную ссылку (`a`).
- `download` — `boolean`, по умолчанию `false`. Применяет к ссылке нативную семантику скачивания.
- `disabled` — `boolean`, по умолчанию `false`. Отображает отключённую кнопку без действующего адреса перехода.
- `target` — `string`, по умолчанию `_blank`.
- `aria-label` — `string`, по умолчанию пусто.

### Методы

Публичных методов нет.

### События

Все события приходят на сам элемент и всплывают. Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `sf-download-file-download` — `detail`: `{ href: string, fileName: string, download: boolean }`. download (словарь).
- `sf-download-file:click` — `detail`: `{ href?: string, fileName?: string, download?: boolean }`. Отправляется один раз для доступного нативного назначения или действия, которым управляет приложение, от отрисованного корня .sf-download-file; всплывает до хост-элемента, не с composed: true и не отменяемое.

### Доступность

- Роль: ссылка (`link`).
- Доступное имя: рекомендуется.
- Клавиши: `Tab`.
- Фокус: Сохраняет видимый фокус на активном элементе управления.

### Минимальная разметка

```html
<sf-download-file file-name="Report.pdf" file-size="2.4 MB" href="/files/report.pdf" download></sf-download-file>
```
