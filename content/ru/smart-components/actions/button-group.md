# Button Group

`<sf-button-group>` — группа кнопок, в которой выбран ровно один вариант: вид
списка, период отчёта, режим просмотра. Она собрана из
[Smart-кнопок](/ru/smart-components/actions/buttons/) и оформлена как обычная
[группа кнопок](/ru/components/actions/button-group/). Для независимых
действий, которые можно нажимать в любом сочетании, берите отдельные кнопки.

## Применение

### Варианты

Варианты передаются в `items` массивом JSON с полями `value`, `label`,
`icon`, `aria-label` и `disabled`; сегментированный вид читает ещё `count` и
`icon-only`. Короткая запись — строка, где варианты
разделены символом `|`, а части варианта — `::`: значение, подпись и флаги
через запятую, например `day::День|year::Год::disabled`. Флаг `icon=имя`
добавляет иконку. Значения в группе не повторяются: вариант с уже занятым
значением пропускается.

Выбранный вариант задаёт `value`. Группа без `value` ничего не выделяет.

### Вид и раскладка

Выбранная кнопка залита цветом из `scheme`, остальные остаются контурными
кнопками нейтрального цвета. `size` и `spacing` берут ту же шкалу, что
обычные кнопки. `orientation="vertical"` ставит кнопки столбцом и сообщает
ориентацию вспомогательным технологиям; стрелки по обеим осям работают в
любой ориентации.

:::example {id="smart-components/button-group/options" label="Результат"}
:::

`disabled` на `<sf-button-group>` отключает всю группу, флаг `disabled` у
варианта — только его.

### Сегментированный вид

`appearance="segmented"` рисует группу как сегментный переключатель:
утопленная дорожка, сегменты без рамок и плашка под выбранным. Поведение то
же. Плашка, размеры вровень с кнопками, числа, иконки, готовый переключатель
темы (`theme-switch`) и CSS-переменные — на странице
[Сегментный переключатель](/ru/smart-components/actions/segmented/).

### Скругление

`radius` — `default`, `square` или `rounded`, как у
[кнопок](/ru/smart-components/actions/buttons/); без атрибута — обычный радиус
элементов. В обычном виде радиус получают внешние углы группы, в
сегментированном — плашка и дорожка
([Скругление](/ru/smart-components/actions/segmented/#скругление)).

### В форме

С атрибутом `name` группа участвует в форме: отправляет `name=value`
выбранного варианта, сброс формы возвращает начальное значение, а группа с
`disabled` в отправку не входит
([пример](/ru/smart-components/actions/segmented/#в-форме)).

### Значение и событие `change`

Нажатие или стрелка выбирает вариант и отправляет всплывающее событие
`change`. Его `event.detail`:

| Поле | Содержимое |
|:---|:---|
| `previous` | значение до изменения; пустая строка, если выбора не было |
| `value` | новое значение; после `clear()` — пустая строка |
| `item` | данные выбранного варианта: `value`, `label`, `icon`, `disabled`; после `clear()` — `null` |
| `component` | элемент `<sf-button-group>` |

Группа хранит выбор только в атрибуте `value`; сохранить его и применить
выбранный вид — задача страницы. Методы `select(value)` и `clear()` меняют
выбор из кода и отправляют то же событие; повторный выбор текущего варианта и
выбор недоступного варианта ничего не меняют.

Группу можно создать из кода. `items` передавайте строкой: массив, переданный
в `SF.create`, превращается в значение через пробел.

```js
const group = await SF.createAsync('button-group', {
  ariaLabel: 'Период отчёта',
  items: 'day::День|week::Неделя|month::Месяц',
  value: 'week',
});
document.querySelector('#report-toolbar').append(group);
await group.whenRendered();

group.addEventListener('change', (event) => {
  loadReport({period: event.detail.value});
});
group.select('month');
```

## Доступность

- Группе нужно доступное имя: `aria-label` на `<sf-button-group>`. Подписи
  вариантов его не заменяют.
- Группа — один переключатель (`radiogroup`) с одной остановкой `Tab` на
  выбранном варианте. Стрелки и `Home`, `End` переходят по доступным
  вариантам по кругу и сразу выбирают их; недоступные варианты пропускаются.
- Вариант только с иконкой получает имя из поля `aria-label`; подпись `label`
  нужна и тогда, когда её не видно.
- Выбранный вариант отличается не только цветом: у него есть
  `aria-checked="true"`.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона.
- `items` — `array` из `object`, по умолчанию `[]`, например `[{"value":"list","label":"List","icon":"list"},{"value":"grid","label":"Grid","icon":"grid_view"}]`, `[{"value":"all","label":"Все","count":24},{"value":"light","label":"Светлые","count":17},{"value":"dark","label":"Тёмные","count":7}]`. Выбираемые элементы со стабильными полями value, label, icon, count, icon-only и disabled.
- `value` — `string`, по умолчанию пусто. Значение выбранного элемента.
- `name` — `string`, по умолчанию пусто. Имя поля формы: группа отправляет своё значение вместе с формой, сброс формы возвращает начальное значение, а отключённая группа в отправку не входит.
- `theme-switch` — `boolean`, по умолчанию `false`. Готовый переключатель темы: группа сама рисует три пункта только с иконками (`system`, `light`, `dark`) с подписями на языке страницы, выбирает предпочтение темы `SF.Loader` и следует за `sf-theme-change`; выбор вызывает `SF.Loader.setTheme`. `items` не используется.
- `size` — `string`, по умолчанию `1`, значения: `1/3`, `1/2`, `1`, `2`, `3`. Общий токен размера кнопки.
- `spacing` — `string`, по умолчанию `normal`, значения: `compact`, `normal`, `comfortable`, `spacious`. Общий семантический профиль внутренних отступов.
- `scheme` — `string`, по умолчанию `primary`, значения: `primary`, `secondary`, `on-surface`. Цветовая схема выбранной кнопки, а в сегментированном виде — плашки выбранного сегмента.
- `appearance` — `string`, по умолчанию `default`, значения: `default`, `segmented`. Вид группы. `default` собирает контурные кнопки в общий контур; `segmented` рисует утопленную дорожку с сегментами без рамок и плашкой под выбранным. Выбор, клавиатура и события одинаковы в обоих видах.
- `plate` — `string`, по умолчанию `scheme`, значения: `scheme`, `raised`. Плашка выбранного сегмента в сегментированном виде: заливка цвета схемы или приподнятая нейтральная поверхность с тенью.
- `full-width` — `boolean`, по умолчанию `false`. В сегментированном виде дорожка занимает ширину контейнера, а сегменты делят её поровну.
- `radius` — `string`, по умолчанию пусто, значения: пусто, `default`, `square`, `rounded`. Скругление углов, как у `sf-button`: пустое значение — обычный радиус элементов. В сегментированном виде плашка — сегмент размером с кнопку — получает радиус кнопки с тем же значением, а дорожка — его же плюс отступ (при `rounded` обе — «таблетки»).
- `orientation` — `string`, по умолчанию `horizontal`, значения: `horizontal`, `vertical`. Ориентация раскладки и навигации с клавиатуры.
- `disabled` — `boolean`, по умолчанию `false`. Отключает всю группу.
- `aria-label` — `string`, по умолчанию пусто. Доступное имя группы.
- `root-class` — `string`, по умолчанию пусто. Дополнительные классы корневого элемента группы.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |

| `spacing="compact"` | `tightness="low"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `spacing="comfortable"` | `tightness="high"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |

### Методы

- `select(value: string)` — возвращает `object`. Выбирает доступный элемент по значению.
- `clear()` — возвращает `object`. Сбрасывает текущий выбор.
- `focus()` — возвращает `object` | `null`. Переводит фокус на выбранный или первый доступный элемент.

### События

Все события приходят на сам элемент и всплывают. Общие события базового элемента перечислены в главе [Жизненный цикл → Этапы](/ru/guide/smart-components/lifecycle/#этапы).

- `change` — `detail`: `{ component: any, previous: string, value: string, item: object|null }`. Выбранное значение изменилось через select() или clear(); событие отправляется на хост-элементе, всплывает и с composed: true. Имя для привязки.
- `sf-button-group-change` — устаревший псевдоним события `change`: приходит с тем же `detail`, подписывайтесь на `change`.

### Доступность

- Роль: группа переключателей (`radiogroup`).
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`.
- Фокус: Используйте перемещаемый tabindex (roving tabindex) и внутренний индикатор focus-visible, который не перекрывает соседние сегменты.

### Минимальная разметка

```html
<sf-button-group aria-label="View" items='[{"value":"list","label":"List"},{"value":"grid","label":"Grid"}]' value="list"></sf-button-group>
```
