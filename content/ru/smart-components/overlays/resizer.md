# Изменение ширины

`<sf-resizer>` — ручка на краю панели, которая меняет её ширину. Ширину тянут
мышью, пером или касанием, меняют стрелками с клавиатуры и возвращают двойным
щелчком. Подходит для колонки меню, боковой панели и области списка рядом с
подробностями.

## Применение

### Панель и край

Ручка встаёт на внутренний конец (`inline-end`) своего родителя. Если панель —
не родитель, её задают селектором ближайшего предка в `target`. Ручка у
начала панели задаётся `edge="inline-start"`. Панель с `position: static`
ручка делает `relative`.

```html
<nav style="inline-size: var(--menu-width, 16rem)">
  …
  <sf-resizer min="13rem" max="24rem" property="--menu-width"
              storage-key="menu" label="Ширина меню"></sf-resizer>
</nav>
```

- `min` и `max` — пределы ширины в любых единицах CSS, токены тоже подходят;
  проценты считаются от родителя панели. По умолчанию `12rem` и `40rem`.
- `property` — CSS-переменная, в которую записывается ширина. Без неё ширина
  записывается в `inline-size` панели.
- `step` — шаг стрелок в пикселях, по умолчанию 16; с `Shift` шаг вчетверо
  больше.
- `disabled` — ручка видна, но ширину не меняет.

Ручка — полоса шириной 8px, которая наполовину выходит за край панели. Она
стоит на седьмой ступени слоёв (`z-index: 70`): выше позиционированного
содержимого панели — например, корня
[меню администратора](/ru/smart-components/composite/admin-menu/) на
шестой ступени — и ниже всплывающих слоёв страницы. У панели остаётся
`overflow: visible`: `overflow: auto` или `hidden` обрезает внешнюю половину
ручки. Прокрутку содержимого дают внутреннему элементу панели.

### Язык

Имя и подсказку ручки даёт общий язык страницы: ближайший `[lang]`, иначе
язык документа, иначе английский. В поставке два языка:

| Язык | Имя | Подсказка |
|:---|:---|:---|
| `ru` | Изменить ширину | Тяните или нажимайте стрелки; двойной щелчок возвращает ширину. |
| `en` | Resize | Drag, or use the arrow keys; a double click restores the width. |

`SF.language.use('en')` переключает язык, и ручка, которая уже стоит на
странице, переименовывается сразу, без перезагрузки. Другой язык добавляют
через общий реестр слов:

```js
SF.language.register('sf-resizer', 'de', {
  label: 'Breite ändern',
  hint: 'Ziehen oder Pfeiltasten.',
});
```

Имя из атрибута `label` при смене языка не меняется: его задал сайт. Как
устроен язык страницы — в главе [Язык интерфейса](/ru/guide/size-and-type/language/).

### Где хранится ширина

Сам компонент ничего не отправляет на сервер. Есть три уровня памяти:

1. Без `storage-key` и `value` ширина живёт до перезагрузки страницы.
2. С `storage-key` она — [персональный вид](/ru/guide/smart-components/view-preferences/)
   под ключом `sf-resizer/<storage-key>`: хранится в браузере, а если сайт
   подключил хранение настроек у пользователя (`SF.Preferences.useHost`), —
   ещё и у человека на сервере. Двойной щелчок её забывает.
3. Сайт с личными настройками без `SF.Preferences.useHost` слушает событие
   `sf-resize`, сохраняет ширину у человека при `phase: 'end'` и `'reset'` и
   при следующем открытии передаёт её в `value`. `value` важнее памяти
   браузера, поэтому ширина одна и та же на любом компьютере.

Выбирайте один способ. Сайт, который подключил `SF.Preferences.useHost`,
ставит ручке только `storage-key` и кладёт значение
`sf-resizer/<storage-key>` в блок `data-sf-preferences`, а без значения у
человека — `null` (см. [Подключение хранилища хоста](/ru/guide/smart-components/view-preferences/#подключение-хранилища-хоста)).

Событие `sf-resize` приходит с `{width, phase}`: `move` — во время
перетаскивания, `end` — после перетаскивания или нажатия клавиши, `reset` —
после возврата. Если окно стало уже, сохранённая ширина возвращается в
пределы.

Сохранённую ширину ручка ставит в первом кадре после того, как Loader
подключил элемент. До этого панель стоит в ширине по умолчанию из CSS, и
на медленном соединении её край может сдвинуться. Чтобы панель сразу была
в ширине человека, сервер, который знает его ширину, пишет её в разметку
панели:

```html
<nav class="app-menu" style="--menu-width: 352px">…</nav>
```

Без сервера страница ставит переменную сама, сразу после `core.js`:
`SF.Preferences` уже есть, а значение лежит под ключом
`sf-resizer/<storage-key>` в виде `{v: 1, width}` (ширина в пикселях):

```html
<script>
  const kept = SF.Preferences.read('sf-resizer/menu');
  if (kept?.width) document.querySelector('.app-menu')?.style.setProperty('--menu-width', `${kept.width}px`);
</script>
```

Скрипт стоит после разметки панели.

### Панель, которая на телефоне становится колонкой

На узком экране боковое меню обычно встаёт над содержимым во всю ширину, и
менять его ширину незачем. Ширину из переменной задавайте только от `md` в
CSS проекта, а ручку ниже `md` скрывайте тоже в CSS проекта: утилита
`hidden` на `<sf-resizer>` не действует, потому что собственный `display`
компонента стоит в слое компонентов, а он важнее слоя утилит
(см. [Утилиты и компоненты](/ru/guide/utilities/utilities-and-components/)).

```css
@layer project {
  @media (width >= 44rem) {
    .app-menu { inline-size: var(--menu-width, 16rem); }
  }
  @media (width < 44rem) {
    .app-menu sf-resizer { display: none; }
  }
}
```

### Тот же жест для других краёв: `SF.Resizer.attach`

Край, который не может быть элементом внутри панели, подключают к тому же
поведению функцией `SF.Resizer.attach(root, {handles, session})`. Так
устроены края столбцов таблицы. `handles` — селектор ручек внутри `root`
(ручки могут перерисовываться); `session(handle)` возвращает, что меняется:

```js
SF.Resizer.attach(table, {
  handles: '.column-edge',
  session: (edge) => ({
    measure: () => edge.closest('th').getBoundingClientRect().width,
    limits: () => ({min: 64, max: 480}),
    apply: (width) => width,
    commit: (width) => saveColumnWidth(edge, width),
    reset: () => resetColumnWidth(edge),
    direction: () => 1,
    step: 16,
  }),
});
```

Перетаскивание, клавиши, двойной щелчок, курсор и значение для доступности у
всех краёв одинаковые.

## Доступность

- Ручка — разделитель: `role="separator"`, она в порядке `Tab`, а её значение —
  ширина в пикселях между `min` и `max`.
- Доступное имя задаёт `label`; без него — «Изменить ширину» на языке
  страницы (см. [Язык](#язык)).
- Стрелки меняют ширину на шаг, `Home` и `End` ставят предел, `Enter`, пробел
  и двойной щелчок возвращают ширину из стилей страницы.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `min` — `string`, по умолчанию `12rem`. Наименьшая ширина — длина CSS (подходят токены и проценты от родителя панели).
- `max` — `string`, по умолчанию `40rem`. Наибольшая ширина — длина CSS.
- `property` — `string`, по умолчанию пусто. CSS-переменная панели, в которую записывается ширина; без неё ширина записывается в inline-size.
- `target` — `string`, по умолчанию пусто. Селектор ближайшего предка, который является панелью; без него — родитель.
- `edge` — `string`, по умолчанию `inline-end`, значения: `inline-end`, `inline-start`.
- `step` — `number`, по умолчанию `16`, значения: от 1. На сколько пикселей сдвигает стрелка; с Shift — на четыре шага.
- `storage-key` — `string`, по умолчанию пусто. Запоминает ширину в этом браузере как персональный вид под ключом `sf-resizer/<key>` (`SF.Preferences`); двойной щелчок её забывает.
- `label` — `string`. Доступное имя; по умолчанию «Изменить ширину» на языке страницы.
- `disabled` — `boolean`, по умолчанию `false`.
- `value` — `number`. Ширина в пикселях, которую хранит хост (личные настройки человека); она важнее памяти браузера.
- `aria-label` — `string`, по умолчанию пусто.

### Методы

Публичных методов нет.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components-2/names/). Общие события базового элемента перечислены в главе [Жизненный цикл → Этапы](/ru/guide/smart-components/lifecycle/#этапы).

- `sf-resizer-resize` — `detail`: `{ width: number, phase: any }`.
- `sf-resize` — устаревший псевдоним события `sf-resizer-resize`: приходит с тем же `detail`, подписывайтесь на `sf-resizer-resize`.

### Персональный вид

Ключ `sf-resizer/<storage-key>`; версия формата — `v: 1`. В столбце «Для первой отрисовки» «да» значит, что сервер может положить поле в блок `data-sf-preferences` страницы.

| Поле | Тип | Пишет | Для первой отрисовки | Что в нём |
|:---|:---|:---|:---|:---|
| `width` | `integer` | `sf-resizer` | да | Ширина, до которой человек дотянул панель, в пикселях CSS; при применении ограничивается `min` и `max`. |

### Доступность

- Роль: separator.
- Доступное имя: рекомендуется.
- Клавиши: `ArrowLeft`, `ArrowRight`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`.
- Фокус: Ручка в порядке Tab, с role separator, aria-orientation vertical и aria-valuenow/min/max в пикселях. Стрелки меняют ширину на шаг (с Shift — на четыре), Home и End ставят предел, Enter, пробел и двойной щелчок возвращают ширину из стилей страницы.

### Минимальная разметка

```html
<nav style="inline-size: var(--menu-width, 16rem)"><sf-resizer min="13rem" max="24rem" property="--menu-width" storage-key="menu" label="Menu width"></sf-resizer></nav>
```
