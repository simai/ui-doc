# Popover

`<sf-popover>` открывает небольшую поверхность рядом с кнопкой: фильтр,
настройки поля, список того, что можно добавить. Компонент держит состояние
открытия, закрывает поверхность по `Escape` и нажатию снаружи и возвращает
фокус на кнопку. Для меню действий над объектом берите
[Context Menu](/ru/smart-components/navigation/context-menu/), для выбора
значения в форме — [Dropdown](/ru/smart-components/navigation/dropdown/),
для задачи, которая требует внимания целиком, —
[модальное окно](/ru/smart-components/overlays/modal/).

## Применение

### Кнопка и поверхность

Внутрь `<sf-popover>` ставят два элемента: кнопку со `slot="trigger"` и
поверхность со `slot="content"`. Компонент не переносит их: оба остаются там,
где написаны, поэтому их может рисовать любой шаблон. Нажатие в любом месте
кнопки открывает и закрывает поверхность, нажатия внутри поверхности
принадлежат её содержимому.

Поверхность получает фон, радиус, тень и собственную прокрутку, когда
содержимое выше доступного места. Отступы внутри задаёт содержимое.

### Положение и ширина

`placement` задаёт, от какого края кнопки открывается поверхность:
`bottom-end` (по умолчанию), `bottom-start`, `top-start`, `top-end`,
`inline-start` или `inline-end`. Логические значения отражаются при письме
справа налево. Без `width` поверхность берёт ширину самой длинной строки;
задайте `width`, например `width="20rem"`, если в поверхности список
строк разной длины.

Поверхность стоит в потоке рядом с кнопкой и не выносится в верхний слой
страницы. Предок с `overflow: hidden` обрежет её, поэтому оставляйте под
кнопкой место или открывайте поверхность в другую сторону.

### Открытие и закрытие

Атрибут `open` показывает поверхность и отражает её состояние: его можно
читать и ставить. `show()`, `close()` и `toggle(force)` делают то же из кода
и возвращают новое состояние. При открытии отправляется событие
`sf-popover-open`, при закрытии — `sf-popover-close`; в обоих
`event.detail.open` содержит новое состояние.

По умолчанию поверхность закрывается по `Escape` и по нажатию за её
пределами. `dismissible="false"` отключает оба способа — тогда страница
закрывает поверхность сама, вызывая `close()`, например после шага мастера.

```js
const popover = document.querySelector('sf-popover');
const trigger = popover.querySelector('[slot="trigger"]');

popover.addEventListener('sf-popover-open', () => {
  trigger.setAttribute('aria-expanded', 'true');
  popover.querySelector('[slot="content"] input')?.focus();
});
popover.addEventListener('sf-popover-close', () => {
  trigger.setAttribute('aria-expanded', 'false');
  applyFilter();
});
```

## Доступность

- Поверхности нужно доступное имя: `label` на `<sf-popover>` передаётся ей
  как `aria-label`. Роль поверхности по умолчанию — `dialog`.
- Кнопке нужно доступное имя. Состояние `aria-expanded` компонент ей не
  ставит: задайте его в обработчиках событий, как в примере кода.
- При открытии фокус остаётся на кнопке. Если пользователь работает в
  поверхности с клавиатуры, переведите фокус на её первое поле. После
  закрытия фокус возвращается на кнопку.
- `Escape` закрывает поверхность. Если `dismissible="false"`, в поверхности
  должна быть своя кнопка закрытия.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона.
- `open` — `boolean`, по умолчанию `false`. Показана ли поверхность. Отражается в атрибуте, поэтому потребитель может читать и задавать его.
- `placement` — `string`, по умолчанию `bottom-end`, значения: `bottom-start`, `bottom-end`, `top-start`, `top-end`, `inline-start`, `inline-end`. От какого угла триггера отображается поверхность.
- `label` — `string`, по умолчанию пусто. Доступное имя поверхности. Поверхность с ролью, но без имени объявляется как безымянная.
- `role` — `string`, по умолчанию `dialog`, значения: `dialog`, `menu`, `listbox`, `group`. Чем является поверхность. Роль передаётся поверхности, в которую она рисует, поэтому меню команд сохраняет стрелки и перемещаемый фокус этого компонента.
- `width` — `string`, по умолчанию пусто. Собственная ширина. Без неё поверхность принимает ширину самой длинной строки, и список имён получается широким и неровным.
- `dismissible` — `boolean`, по умолчанию `true`. Esc и нажатие снаружи закрывают её. Потребитель, который сам обрабатывает эти действия, отключает это и вызывает close(), когда решит.

### Методы

- `toggle(force?: boolean)` — возвращает `boolean`. Открыть или закрыть; логическое значение задаёт одно из состояний принудительно.
- `show()` — возвращает `boolean`. Открыть.
- `close()` — возвращает `boolean`. Закрыть.
- `returnFocus()` — возвращает `null`. Вернуть фокус на триггер.

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `sf-popover-open` — `detail` не описан. Поверхность открылась.
- `sf-popover-close` — `detail` не описан. Поверхность закрылась.
