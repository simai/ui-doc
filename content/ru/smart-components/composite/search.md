# Поиск по сайту

`<sf-search>` — поиск по сайту SIMAI: окно с крупным скруглённым полем и
отдельной карточкой результатов под ним, над лёгким затемнением. Его
открывает кнопка в шапке и клавиши `Command/Control+K` и `/`. На телефоне
это экран целиком: поле сверху и стрелка назад. Результаты даёт сайт —
статическим JSON-индексом, своей функцией или подключённым источником;
компонент не знает, что именно он ищет.

## Разметка

В разметке — тег `<sf-search>`, кнопка-вызов внутри и источник
результатов (`index` или `provider`). Разметку целиком показывает
[Разметка в шапке](#разметка-в-шапке).

- Дочерние элементы без атрибута `slot` (слот `trigger`) открывают окно по
  нажатию. Кнопка — разметка самой страницы, поэтому шапка выглядит
  одинаково до прихода кода и после.
- Кнопку в другом месте страницы называет `for` — её `id`, или несколько
  через пробел.
- `index` — адрес статического индекса; `provider` — функция, которая
  отвечает на запрос. Подробно — в разделе [Данные](#данные).

## Варианты

### Кнопка, похожая на поле

[Кнопка](/ru/smart-components/actions/buttons/) со схемой
`on-surface-variant`, подписью в начале (`text-position="start"`) и
сочетанием клавиш в конце (`shortcut="mod+k"`) читается как поле поиска.

:::example {id="smart-components/search/field" label="Кнопка во всю ширину с подсказкой клавиш"}
:::

### Значок на узком экране

Кнопка-иконка занимает меньше места в шапке телефона. `keys="false"` убирает
подвал с подсказками клавиш, `popular="false"` — частые запросы.

:::example {id="smart-components/search/icon" label="Значок без подсказок клавиш и частых запросов"}
:::

### Только результаты

Каждый блок окна — настройка, по умолчанию включённая. Выключите лишнее для
маленького сайта: здесь нет фильтров (`scopes`), недавних запросов
(`recent`), быстрых действий (`actions`) и строки пути (`path`).

:::example {id="smart-components/search/quiet" label="Окно без фильтров, недавних, действий и пути"}
:::

### Подключённый источник

Источник, который сам объявляет свои возможности: здесь окно показывает ещё и
строку «Возможно, вы искали…» и, на широком экране, панель предпросмотра. Как
его подключить — в разделе [Свой источник результатов](#свой-источник-результатов).

## Применение

### Разметка в шапке

```html
<sf-search index="/search-index.json">
  <sf-button icon-start="search" text="Поиск" appearance="tonal" scheme="on-surface" radius="rounded"></sf-button>
</sf-search>
```

Кнопка-вызов в другом месте страницы:

```html
<sf-icon-button id="search-button" icon="search" aria-label="Поиск"></sf-icon-button>
<sf-search for="search-button" index="/search-index.json"></sf-search>
```

### Что показывает окно

На пустом поле — недавние запросы, частые запросы кнопками и быстрые
действия. С запросом — кнопки-фильтры, затем результаты под подписями своих
групп, совпадения подсвечены.

| Настройка | Блок |
|:---|:---|
| `scopes` | кнопки-фильтры: «Все», затем по одной на группу результатов, с числом |
| `recent` | недавние запросы, у каждого кнопка удаления, и «Очистить» |
| `popular` | частые запросы на пустом поле и под пустым результатом |
| `actions` | результаты, которые выполняют команду, с подсказкой клавиш |
| `path` | строка пути под названием результата |
| `keys` | подвал: ↑↓ — выбрать, ↵ — открыть, esc — очистить или закрыть |

Пока ждём первый ответ, карточка говорит «Ищем…»; ошибка — «Поиск сейчас
недоступен»; пустой ответ — «Ничего не нашлось по «…»».

### Данные

`index` — адрес JSON-файла. Встроенный источник читает его один раз и
находит записи, у которых в названии, пути или тексте есть каждое слово
запроса без учёта регистра: сначала название, которое начинается с запроса,
затем то, что его содержит, затем остальные.

```json
{
  "groups": [
    {"id": "pages", "label": "Страницы"},
    {"id": "components", "label": "Компоненты"},
    {"id": "actions", "label": "Действия"}
  ],
  "popular": ["таблица", "тема", "кнопка"],
  "items": [
    {"group": "pages", "title": "Таблица в рамке", "path": "Утилиты › Таблицы", "href": "/utilities/table/", "icon": "table", "text": "рамка прокрутка"},
    {"group": "components", "title": "sf-button", "path": "Смарт-компонент", "href": "/smart/button/", "icon": "widgets"},
    {"group": "actions", "title": "Сменить тему", "path": "Команда", "action": "theme", "icon": "contrast", "shortcut": "⇧⌘L"}
  ]
}
```

Индексом служит и просто массив записей. `url` записи читается как `href`;
`path` может быть списком — его части соединяются знаком ›.

`provider` — свойство: функция, обычно асинхронная, которая отвечает на
запрос. Так устроены примеры на этой странице.

```js
document.querySelector('sf-search').provider = async (query, {scope, signal}) => {
  const response = await fetch(`/api/search?q=${encodeURIComponent(query)}`, {signal});
  return response.json(); // {groups, items, popular}
};
```

- При открытии окна функция получает пустой запрос: ответьте быстрыми
  действиями (записи с `action`) и `popular`.
- Затем она вызывается, когда человек перестал печатать (через 120 мс);
  предыдущий вызов отменяется через `signal`.
- `scope` — нажатый фильтр, только подсказка: отвечайте всеми группами,
  чтобы числа на фильтрах оставались верными. По фильтру компонент отбирает
  сам.
- Запись: `id`, `group`, `title`, `path`, `href` или `action`, `icon` (имя
  Material Symbols), `shortcut` (подсказка у действия), `text` (по нему ищет
  статический индекс, на экране его нет).

### Свой источник результатов

Поиск спрашивает результаты через порт `simai.search-port` 1.0.0. `index` и
`provider` — два встроенных источника того же порта. Поиск на сервере
подключают методом `connectPort`: подключённый источник заменяет оба.

Живой пример — в разделе [Подключённый источник](#подключённый-источник).

```js
search.connectPort({
  port: 'simai.search-port',
  version: '1.0.0',
  capabilities: ['scopes', 'recent', 'popular', 'actions', 'preview', 'spelling'],
  async raise(intent, payload, {signal} = {}) {
    if (intent === 'query.change') {
      const data = await askServer(payload, signal);
      return {answer: 'applied', sequence: payload.sequence, data};
    }
    return {answer: 'unavailable', reason: 'intent-unknown'};
  },
});
```

`raise` отвечает одним конвертом: `{answer, reason?, text?, data?, sequence?}`,
где `answer` — `applied`, `refused` или `unavailable`. Чтения (`query.change`,
`result.preview`) называют свой `sequence`, а ответ на устаревший запрос
отбрасывается. Каждое обращение и ответ объявляются событием `sf-search-intent`.

| Обращение | Когда | Возможность |
| --- | --- | --- |
| `query.change` | Набор, фильтр, выбранный запрос, исправление, пустой запрос при открытии | не нужна |
| `result.open` | Выбрана страница; при отказе окно остаётся открытым и говорит почему | не нужна |
| `action.run` | Выбрана команда | `actions` |
| `recent.forget`, `recent.clear` | Удалён запрос, очищен список | `recent` |
| `result.preview` | Человек стоит на строке, и в окне есть место для панели | `preview` |

Возможность говорит, что умеет источник, а настройка — что нужно странице. Блок
рисуется, только если источник объявил возможность и настройка не выключена:
настройкой нельзя включить то, чего источник не умеет.

У панели предпросмотра и строки «Возможно, вы искали…» настроек нет: их включает
сам источник, объявив `preview` и `spelling`. Панели нужно окно браузера шириной
от 60rem, и окно поиска с ней становится шире. Исправление только предлагается:
выбрать его — обычный новый запрос, сам запрос поиск не меняет.

| Источник | Объявляет | Где недавние запросы |
| --- | --- | --- |
| `index` | `scopes`, `recent`, `popular`, `actions` | В настройках вида пользователя |
| `provider` | `scopes`, `recent`, `popular`, `actions` | В настройках вида пользователя |
| Нет ни того, ни другого | Ничего: поле, результаты и клавиатура | Нигде |
| Подключённый | Что сам объявит | У источника, `recent-key` не читается |

### Выбор результата

`Enter` открывает выбранный результат, нажатие — нажатый. Окно закрывается,
запрос записывается в недавние, а страница получает `sf-search-navigate` с
`{id, href, action, query, group}`. Если страница его не отменила, браузер
переходит по `href`. Результат-действие несёт `action` без `href`: его
выполняет страница. Примеры на этой странице отменяют переход и пишут
выбор под кнопкой.

```js
search.addEventListener('sf-search-navigate', (event) => {
  if (event.detail.action === 'theme') {
    event.preventDefault();
    toggleTheme();
  }
});
```

### Клавиши вызова

`shortcut` перечисляет клавиши, открывающие окно, через пробел: `mod` — это
`Command` на Mac и `Control` в других системах (подходят обе), одиночная
печатная клавиша (`/`) действует только вне текстового поля. По умолчанию —
`mod+k /`; пустое значение отключает клавиши. Если на странице несколько
поисков, дайте каждому свои клавиши. В примерах на этой странице клавиши
выключены, чтобы не спорить с поиском самого сайта документации.

### Недавние запросы

Запрос попадает в недавние, когда открыт один из его результатов. Недавние
запросы — личная настройка вида: они хранятся через `SF.Preferences` под
ключом `sf-search/<recent-key>` (`recent-key` по умолчанию `site`) — в
браузере это `localStorage` `sf-pref:sf-search/site`, а сервер, который
хранит настройки пользователя, держит их у себя. Дайте каждому поиску сайта
свой ключ. Пустой `recent-key` или браузер, который запрещает хранение,
оставляют их только на время жизни страницы.

### Окно и слои

Открытое окно — слой общего стека слоёв SIMAI Framework, как
[Модальное окно](/ru/smart-components/overlays/modal/) и
[Боковая панель](/ru/smart-components/overlays/drawer/): `Escape` и `Tab`
получает только верхний слой, а страница не прокручивается, пока окно
открыто. Внутри `[data-sf-overlay-container]` окно остаётся в этом блоке и
не блокирует страницу — так устроены примеры на этой странице.

`open()`, `close({reason})` и `toggle()` делают то же из кода. События
`sf-search-open` и `sf-search-close` можно отменить; `sf-search-opened` и
`sf-search-closed` сообщают, что это произошло. `detail.reason` закрытия —
`close`, `escape`, `outside` или `api`.

### Внешний вид

| Переменная | Что меняет |
|:---|:---|
| `--sf-search-inline-size` | ширину окна (36rem) |
| `--sf-search-inset-block-start` | расстояние от верха окна браузера (4rem) |
| `--sf-search-background` | фон поля и карточки |
| `--sf-search-scrim-color` | затемнение |
| `--sf-search-mark-color` | заливку совпавшего текста |
| `--sf-search-radius` | скругление карточки результатов |
| `--sf-search-list-max-block-size` | наибольшую высоту карточки |

Сайты SIMAI не переопределяют значения SIMAI Framework своими: переменные
нужны уровням самого SIMAI Framework — теме и области.

## Доступность

- Открытое окно — модальный диалог с именем из `label` (по умолчанию «Поиск
  по сайту»).
- Поле — `combobox`: стрелки двигают выбор по результатам, а фокус остаётся
  в поле. Результаты — `listbox` с вариантами под подписями групп. Вежливая
  живая область сообщает, сколько результатов найдено.
- Кнопка-вызов получает `aria-haspopup="dialog"`, `aria-expanded`,
  `aria-controls`, пока окно открыто, и `aria-keyshortcuts`.
- Крестик в поле делает то же, что `Escape`: очищает заполненное поле и
  оставляет фокус, а пустое окно закрывает. Нажатие на затемнение тоже
  закрывает окно.

| Клавиша | Что делает |
|:---|:---|
| `Command/Control+K`, `/` | открывают окно; в открытом окне выделяют текст поля |
| `↓` `↑` | двигают выбор |
| `Enter` | открывает выбранный результат; недавний запрос ставит в поле |
| `Escape` | очищает заполненное поле; пустое окно закрывает и возвращает фокус |
| `Tab` | ходит только по кнопкам окна |

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-d6292bd6fc34` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-search>` |
| Назначение | Поиск по сайту в окне: крупное скруглённое поле и отдельная карточка результатов под ним на светлой подложке, открывается кнопкой или клавишей (Command/Control+K, /), на телефоне — лист во весь экран. Панель спрашивает хост через `simai.search-port` и рисует то, на что он объявил себя способным: результаты по группам, фильтры, недавние и частые запросы, команды, исправление и предпросмотр рядом со списком. | Заготовка до прихода кода | нет: атрибут `data-sf-skeleton` не пишется; своего скелетона при загрузке данных нет ([Коробка до кода](/ru/guide/smart-components/first-paint/#коробка-до-кода)) |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `index` — `string`, по умолчанию пусто. Адрес статического JSON-индекса (массив записей или `{groups, items, popular}`); встроенный хост индекса читает его один раз и ищет запрос без учёта регистра, объявляя `scopes`, `recent`, `popular` и `actions`. Не читается, если отвечает `provider` или подключённый порт
- `for` — `string`, по умолчанию пусто. `id` элемента страницы, или несколько через пробел, который открывает окно по нажатию; другой способ — слот `trigger`
- `shortcut` — `string`, по умолчанию `mod+k /`. Клавиши, открывающие окно, через пробел: `mod` — Command или Control (Command на Mac, Control в других системах; подходят обе); одиночная печатная клавиша (`/`) действует только вне текстового поля; пусто — клавиш нет
- `label` — `string`. Доступное имя окна; если не задано — «Поиск по сайту» или «Site search» на языке страницы
- `placeholder` — `string`. Заполнитель поля; если не задан — «Найти на сайте» или «Search the site» на языке страницы
- `scopes` — `boolean`, по умолчанию `true`. Кнопки-фильтры над результатами, когда есть запрос: «все» и по одной на группу результатов, с числом результатов. Пожелание поверх возможности `scopes`: если хост её не объявил, кнопок нет, и настройкой нельзя включить то, чего хост не умеет
- `recent` — `boolean`, по умолчанию `true`. Недавние запросы на пустом поле, у каждого кнопка удаления, и кнопка очистки (`recent.forget`, `recent.clear`). Пожелание поверх возможности `recent`: запросы — данные хоста, поэтому если он её не объявил, блока нет
- `recent-key` — `string`, по умолчанию `site`. Имя, под которым встроенные хосты (`index`, `provider`) хранят недавние запросы этого человека, — личная настройка вида (ключ `SF.Preferences` `sf-search/<recent-key>`, в браузере `localStorage` `sf-pref:sf-search/<recent-key>`); дайте каждому поиску сайта своё; пусто — только на время жизни страницы. Подключённый хост хранит свои, и ключ тогда не читается
- `popular` — `boolean`, по умолчанию `true`. Частые запросы кнопками на пустом поле и под пустым результатом, из данных (`popular`). Пожелание поверх возможности `popular`: если хост её не объявил, блока нет
- `actions` — `boolean`, по умолчанию `true`. Результаты, которые выполняют команду вместо перехода на страницу (kind `action`, с необязательной подсказкой клавиш): группа быстрых действий на пустом поле и своя группа среди результатов, выполняются через `action.run`. Пожелание поверх возможности `actions`: нет возможности — нет командных строк
- `path` — `boolean`, по умолчанию `true`. Путь результата второй строкой под названием. Собственная настройка панели: где стоит результат, говорит поле самого результата, поэтому возможность источника за ней не стоит
- `keys` — `boolean`, по умолчанию `true`. Подвал с клавишами: стрелки — выбрать, Enter — открыть, Escape — очистить или закрыть. Собственная настройка панели: клавиши принадлежат панели, поэтому возможность источника за ней не стоит
- `provider` — `object`, по умолчанию `null`. Простой путь: асинхронная функция `(query, {scope, signal})`, которая отвечает `{groups: [{id, label}], items: [{id, group, title, path, href | action, icon, shortcut}], popular: [text]}`; вызывается и для пустого запроса (быстрые действия и частые запросы). Встроенный хост `simai.search-port` оборачивает её и объявляет `scopes`, `recent`, `popular` и `actions`; хост, подключённый через `connect-port`, отвечает вместо неё. Только свойство

### Методы

- `open()` — возвращает `object`. Открывает окно с пустым полем; отказ, если страница отменила `sf-search-open`.
- `close(reason: any)` — возвращает `object`. Закрывает окно; отказ, если оно уже закрыто или страница отменила `sf-search-close`.
- `toggle()` — возвращает `object`. Открывает окно, если оно закрыто, и закрывает, если открыто.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `sf-search-open` — ничего не передаёт. Окно вот-вот откроется: просьба, которую страница может отменить
- `sf-search-opened` — ничего не передаёт. Окно открылось, и фокус в его поле
- `sf-search-close` — `detail`: `{ reason: any }`. Окно вот-вот закроется, и почему: кнопка закрытия в поле или стрелка назад (`close`), Escape на пустом поле (`escape`), нажатие на затемнение (`outside`) или действие и выбранный результат (`api`)
- `sf-search-closed` — `detail`: `{ reason: any }`. Окно закрылось, и почему
- `sf-search-navigate` — `detail`: `{ id: string, href: string, action: string, query: string, group: string }`. Выбран результат (Enter или нажатие): окно закрылось, запрос записан; страница, которая переходит сама или выполняет действие, отменяет событие, иначе браузер переходит по `href`. Результат-действие несёт `action` и не несёт `href`
- `sf-search-intent` — `detail`: `{ intent: any, payload: object, answer: object }`. Единственное событие порта (`simai.search-port`: его называет каждое обращение): панель отправила обращение, и вот что вернулось, каким бы ни был ответ, — `applied`, `refused`, `unavailable` и ответы, которые панель даёт сама. Страница может наблюдать за обменом, не вмешиваясь в него

### Доступность

- Роль: диалог (`dialog`).
- Доступное имя: внутренний.
- Клавиши: Command/Control+K или `/` вне текстового поля открывают окно, Стрелки вниз и вверх двигают выбор по результатам; Enter открывает выбранный, Escape очищает поле, а на пустом поле закрывает окно и возвращает фокус.
- Фокус: Открытое окно ставит фокус в своё поле, держит Tab внутри, пока оно верхний слой, и при закрытии возвращает фокус туда, где он был (на кнопку).

<sf-search index="/search-index.json"><sf-button icon-start="search" text="Поиск" appearance="tonal" scheme="on-surface" radius="rounded"></sf-button></sf-search>
