# Список писем

`<sf-mail-letters>` — письма человека в редакторе писем: поиск по названию,
порядок и то, что предлагает строка, — «Открыть» и под ⋯ копия, переименование
и удаление. Элемент не хранит писем и ничего не делает сам: он сообщает, что
выбрал человек, а письма передаёт и меняет приложение.

Компонент поставляется пакетом `larena` из репозитория `simai/ui-pro`
(SIMAI Pro, папка `components/`), а не выпуском Framework. Лицензия пакета —
PolyForm Small Business 1.0.0 или PolyForm Noncommercial 1.0.0, по запросу —
коммерческая лицензия SIMAI; в составе Larena — лицензия Larena. Как
подключить пакет — в разделе
[Подключение смарт-компонентов](/ru/guide/smart-components/page/#подключение-к-странице).

## Разметка

В разметке — только тег; письма передаёт скрипт свойством `letters`.

- Письмо — `{id, title, at, blocks}`. `at` — момент изменения, а не фраза:
  строка сама пишет «5 минут назад» на языке страницы. `blocks` — число блоков,
  строка сама подбирает форму слова: «1 блок», «4 блока», «7 блоков».
- `current` называет письмо, открытое в редакторе.

## Варианты

### Порядок

`order` — `changed`, сначала изменённые, или `title`, по названию с сортировкой
по языку страницы. Список порядка внутри элемента записывает этот атрибут сам.

## Состояния

### Ничего не найдено

`query` — поиск по названию; поле внутри элемента записывает его, пока человек
печатает. Если по запросу ничего нет, элемент говорит «Ничего не найдено».

:::example {id="smart-components/mail-letters/nothing-found" label="Поиск без результата"}
:::

### Пусто

Если писем нет совсем, элемент говорит «Писем пока нет» и оставляет кнопку
«Новое письмо». Это разные состояния, и человек видит, какое из них его.

:::example {id="smart-components/mail-letters/empty" label="Писем ещё нет"}
:::

## Применение

### Данные и события

Всё, что делает человек, приходит событиями; письмо меняет приложение и передаёт
новый список в `letters`:

- `sf-mail-letters-open` — `{id}`, нажали «Открыть»;
- `sf-mail-letters-copy` — `{id}`, «Копия» под ⋯;
- `sf-mail-letters-rename` — `{id}`, «Переименовать» под ⋯; новое название
  спрашивает приложение;
- `sf-mail-letters-delete` — `{ids: [id], id}`, «Удалить» под ⋯; подтверждает и
  удаляет приложение;
- `sf-mail-letters-create` — «Новое письмо».

```js
const list = document.querySelector('sf-mail-letters');
list.letters = await api.letters();
list.addEventListener('sf-mail-letters-open', (event) => {
  openLetter(event.detail.id);
  list.setAttribute('current', event.detail.id);
});
list.addEventListener('sf-mail-letters-delete', async (event) => {
  if (await confirmDelete(event.detail.id)) list.letters = await api.remove(event.detail.id);
});
```

### Открытое письмо

Строка письма из `current` отмечена, говорит «открыто сейчас» словами, а не
только цветом, и не предлагает «Открыть».

### Поиск и порядок

Второго поля поиска или списка порядка рядом не рисуют: приложение задаёт те же
`query` и `order` атрибутами или действиями `search {query}` и `sort {order}`.
Неизвестный порядок действие отклоняет с ответом `refused unknown`.

## Доступность

- Порядок `Tab`: сначала панель — поиск, порядок, «Новое письмо», — затем у каждой
  строки «Открыть» и ⋯.
- Меню строки — `sf-context-menu` со своей клавиатурой.
- Имя кнопки ⋯ называет письмо: «Действия с письмом: <название>», поэтому две
  строки не звучат одинаково.

### Атрибуты

- `template` — `string`, по умолчанию `default`, значения: `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `query` — `string`, по умолчанию пусто. Поиск по названию; поле внутри элемента записывает его, пока человек печатает.
- `order` — `string`, по умолчанию `changed`, значения: `changed`, `title`. `changed` (сначала новые) или `title` (по названию, с сортировкой по языку страницы); список порядка внутри элемента записывает его сам.
- `current` — `string`, по умолчанию пусто. Письмо, открытое в редакторе: его строка отмечена, говорит «открыто сейчас» и не предлагает «Открыть».
- `letters` — `array` из `object`, по умолчанию `[]`. Письма, по одной строке: `{id, title, at, blocks}`. `at` — момент изменения письма; строка записывает его («5 минут назад») и число блоков («4 блока») на языке страницы.

### Методы

- `search(query: string)` — возвращает `object`. Ищет, как поле: задаёт `query`.
- `sort(order: any)` — возвращает `object`. Упорядочивает строки, как список порядка; `refused unknown` для порядка, отличного от `changed` и `title`.
- `choose(action: any, id: any)` — возвращает `object`. Делает то же, что строка или панель: отправляет `open`, `copy`, `rename`, `delete` или `create`; `refused current` при открытии уже открытого письма.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `sf-mail-letters-open` — `detail`: `{ id: any }`. Открыть это письмо: `{id}`. Текущее письмо не предлагается.
- `sf-mail-letters-copy` — `detail`: `{ id: any }`. Сделать копию этого письма: `{id}`.
- `sf-mail-letters-rename` — `detail`: `{ id: any }`. Переименовать это письмо: `{id}`. Новое название спрашивает хост.
- `sf-mail-letters-delete` — `detail`: `{ ids: array, id: any }`. Удалить это письмо: `{ids: [id], id}`. Подтверждает и удаляет хост.
- `sf-mail-letters-create` — ничего не передаёт. Запрошено новое письмо.

### Доступность

- Роль: список.
- Доступное имя: внутренний.
- Клавиши: `Tab`, `Enter`, `Space`.
- Фокус: Сначала панель — поиск, порядок, «Новое письмо», — затем в порядке Tab у каждой строки «Открыть» и ⋯; меню — `sf-context-menu` со своей клавиатурой. Кнопка ⋯ называется «Действия с письмом: <название>», поэтому две строки не звучат одинаково. Строка открытого письма говорит «открыто сейчас» словами, а не только цветом, и не предлагает «Открыть».
