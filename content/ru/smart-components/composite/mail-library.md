# Библиотека блоков письма

`<sf-mail-library>` — блоки, которые можно добавить в письмо, по группам
назначения, с чипами категорий, поиском по названию и описанию и вариантами шапки
и подвала. Строка сообщает, что выбрал человек, а куда вставить блок, решает
приложение: сам элемент письмо не меняет.

Компонент поставляется пакетом `larena` из репозитория `simai/ui-pro`
(SIMAI Pro, папка `components/`), а не выпуском Framework. Лицензия пакета —
PolyForm Small Business 1.0.0 или PolyForm Noncommercial 1.0.0, по запросу —
коммерческая лицензия SIMAI; в составе Larena — лицензия Larena. Как
подключить пакет — в разделе
[Подключение смарт-компонентов](/ru/guide/smart-components/page/#подключение-к-странице).

## Разметка

В разметке — только тег; блоки передаёт скрипт свойствами на языке человека.

- `groups` — `{id, title}`, группы в порядке показа. Строка, чьей группы здесь
  нет, не показывается.
- `items` — `{type, title, purpose, icon, group, sample}`, блоки по одной строке;
  `sample` необязателен.
- `places` — места, которые есть в каждом письме: `{family, title, current, items}`.

## Варианты

### Категория

`category` — `all` или `id` одной группы; чипы над списком переключают его сами.
Пока выбрана категория, раздел шапки и подвала скрыт: категория — про содержание.
`id`, которого нет среди групп, показывает все группы, поэтому устаревший фильтр
не оставит список пустым.

:::example {id="smart-components/mail-library/category" label="Выбрана категория «Товары»"}
:::

### Одна группа

Чипы рисуются, только если групп больше одной.

## Состояния

### Ничего не найдено

`query` — слова поиска; поле внутри элемента записывает его, пока человек
печатает. Блок находится по названию, назначению и типу. Группа, в которой не
осталось строк, не рисуется; если не осталось ничего, элемент говорит «Ничего не
найдено».

## Применение

### Данные и события

- `sf-mail-library-add` — `{type}`, строка добавляет свой блок;
- `sf-mail-library-replace` — `{family, type}`, выбран другой вариант шапки или
  подвала. Заменяет приложение — одним шагом, который можно отменить, — и передаёт
  новый `current` обратно в `places`.

```js
const library = document.querySelector('sf-mail-library');
library.groups = [{id: 'basics', title: 'Основа'}, {id: 'commerce', title: 'Товары'}];
library.items = [
  {type: 'heading', title: 'Заголовок', purpose: 'Главная мысль письма', icon: 'title', group: 'basics'},
  {type: 'price', title: 'Цена', purpose: 'Цена и старая цена', icon: 'sell', group: 'commerce'},
];
library.addEventListener('sf-mail-library-add', (event) => addBlock(event.detail.type));
library.addEventListener('sf-mail-library-replace', (event) => {
  replaceVariant(event.detail.family, event.detail.type);
  library.places = currentPlaces();
});
```

### Шапка и подвал

Вариант из `current` отмечен галочкой и не предлагается повторно: нажатие на него
ничего не сообщает. Раздел виден только при категории «Все».

### Действия

Приложение может сделать то же, что человек: `search {query}`, `filter {category}`,
`add {type}` и `replace {family, type}`. Неизвестный блок или вариант отклоняется
ответом `refused unknown`, текущий вариант — ответом `refused current`.

## Доступность

- Порядок `Tab`: поле поиска, чипы, затем каждая строка — обычная кнопка; `Enter`
  и `Space` добавляют блок или меняют вариант.
- Выбранный чип и текущий вариант отмечены `aria-pressed="true"`.
- Группа — `role="group"` с названием. Имя кнопки — её же слова, название и
  назначение блока, затем действие, поэтому голосовая команда с названием блока до
  неё доходит.

### Атрибуты

- `template` — `string`, по умолчанию `default`, значения: `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `query` — `string`, по умолчанию пусто. Слова поиска; поле внутри элемента записывает их, пока человек печатает. Блок находится по названию, назначению и типу.
- `category` — `string`, по умолчанию `all`. `all` или `id` одной группы, как задал бы её чип. `id`, которого нет ни у одной группы, показывает все, поэтому устаревший фильтр не оставит библиотеку пустой.
- `items` — `array` из `object`, по умолчанию `[]`. Блоки, которые может принять письмо, по одной строке: `{type, title, purpose, icon, group, sample?}`, словами человека. Строка, чьей группы нет в `groups`, не показывается.
- `groups` — `array` из `object`, по умолчанию `[]`. Группы в порядке показа: `{id, title}`. Если их больше одной, над строками рисуются чипы «Все» и по одному на группу.
- `places` — `array` из `object`, по умолчанию `[]`. Места, которые есть в каждом письме («Шапка», «Подвал»), и их варианты: `{family, title, current, items: [{type, title, purpose, icon}]}`. Текущий вариант отмечен и не предлагается снова; видны только при «Все».

### Методы

- `search(query: string)` — возвращает `object`. Ищет, как поле: задаёт `query` и сразу фильтрует.
- `filter(category: string)` — возвращает `object`. Показывает одну группу или все, как её чип.
- `add(type: any)` — возвращает `object`. Добавляет блок, как его строка: отправляет `add {type}`; `refused unknown`, если такого блока нет.
- `replace(family: any, type: any)` — возвращает `object`. Выбирает вариант места, как его строка: отправляет `replace {family, type}`; `refused current` для варианта, который сейчас в письме.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `sf-mail-library-add` — `detail`: `{ type: any }`. Выбран блок, который нужно добавить: `{type}`. Хост добавляет его туда, куда решит; сам элемент письмо не меняет.
- `sf-mail-library-replace` — `detail`: `{ family: any, type: any }`. Выбран другой вариант места: `{family, type}`. Блок заменяет хост; вариант, который сейчас в письме, ничего не сообщает.

### Доступность

- Роль: группа (`group`).
- Доступное имя: внутренний.
- Клавиши: `Tab`, `Enter`, `Space`.
- Фокус: Сначала поле поиска, затем чипы категорий (`sf-button` с `aria-pressed`, в группе «Категория»), затем каждая строка — обычная кнопка; Enter или пробел добавляют её блок или заменяют вариант. Группа — `role=group` с именем по её названию, а сам текст названия скрыт от чтения с экрана, чтобы не звучать дважды. Доступное имя строки — её же слова, название и назначение блока, затем действие; строка варианта говорит «сейчас в письме» для текущего и несёт `aria-pressed`. Значки — украшение.
