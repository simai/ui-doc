# Составные компоненты

- [Admin Menu](/ru/smart-components/composite/admin-menu/) — Даёт административному приложению боковую навигацию с вложенными разделами, поиском, компактным режимом и настройкой пунктов.
- [Представление свойств](/ru/smart-components/composite/property-view/) — Показывает и правит поля одного объекта по разделам и областям, сохраняя область одной ревизией через приложение.
- [Page Header](/ru/smart-components/composite/page-header/) — Показывает в начале страницы администрирования путь, заголовок, число записей, отметку избранного и главные действия.
