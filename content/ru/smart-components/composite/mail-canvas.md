# Холст письма

`<sf-mail-canvas>` — холст редактора писем: готовое письмо в рамке, которая ничего
не запускает, переключатель ширины над ним, две заметки о письме («устарел» и
«тяжёлое») и `sf-composition-overlay` сверху — рамки, панель действий и дерево для
клавиатуры. Элемент не знает письма и рендерера: приложение передаёт отрисованный
HTML и данные о нём, а элемент сообщает, что сделал человек.

Компонент поставляется пакетом `larena` из репозитория `simai/ui-pro`
(SIMAI Pro, папка `components/`), а не выпуском Framework. Лицензия пакета —
PolyForm Small Business 1.0.0 или PolyForm Noncommercial 1.0.0, по запросу —
коммерческая лицензия SIMAI; в составе Larena — лицензия Larena. Как
подключить пакет — в разделе
[Подключение смарт-компонентов](/ru/guide/smart-components/page/#подключение-к-странице).

## Применение

### Данные

```js
canvas.setAttribute('mark-attribute', 'data-ui-mail-block');
canvas.setAttribute('box-attribute', 'data-ui-mail-box');
canvas.setAttribute('paper', '.email');
canvas.widths = [
  {value: '600', label: 'Компьютер 600', icon: 'desktop_windows', frame: 680},
  {value: '375', label: 'Телефон 375', icon: 'smartphone'},
  {value: '320', label: 'Узкий 320', icon: 'phone_iphone'},
];
canvas.setAttribute('width', '600');
canvas.items = [
  {id: 'b1', label: 'Шапка · Логотип'},
  {id: 'b2', label: 'Заголовок'},
];
canvas.actions = [{id: 'up', label: 'Выше'}, {id: 'remove', label: 'Удалить'}];
canvas.setAttribute('selected', 'b2');
canvas.html = renderedLetter;
```

| Настройка | Что значит |
|:---|:---|
| `html` | письмо строкой; свойство (атрибут читается, пока свойство не записано) |
| `mark-attribute` | атрибут, которым в письме помечен блок, по умолчанию `data-block`; значение — `id` пункта |
| `box-attribute` | атрибут коробки внутри блока: её заливает оттенок и обводит оверлей; пусто — сам блок |
| `paper` | селектор бумаги письма внутри рамки: тень у неё, когда рамка шире письма |
| `widths`, `width` | ширины `{value, label, icon, frame, icon-only, aria-label}` и текущая; `frame` — ширина рамки, если она отличается от `value` |
| `selected` | выбранный блок; пусто — ничего не выбрано |
| `stale` | заметка «предпросмотр устарел»; картинка остаётся прежней |
| `weight` | `{bytes, max}` в килобайтах — предупреждение о весе; пусто — заметки нет |
| `items` | что есть в письме для оверлея: `{id, label, kind, parent, editable, rect}` |
| `actions` | панель действий выбранного блока: `{id, label}`, до 16 |
| `accepts` | группы `sf-sortable`, которые можно бросать на письмо, через пробел |
| `overlay-target` | `id` оверлея, поставленного хостом в другом месте страницы |

`widths` и подписи к ним — данные хоста: что на телефоне кнопка только с иконкой
(`icon-only`), решает он. Подпись рамки, заметки и имена слоя — слова элемента в
`lang/`, на языке страницы.

### Письмо — недоверенное содержимое

У рамки `sandbox="allow-same-origin"` и больше ничего: скрипт в письме не
запускается и не достаёт до страницы, а страница читает письмо, чтобы измерить и
отметить его. Это проверяется пробой. Метка в письме считается блоком, только если
её `id` есть в `items`: письмо не может подсунуть хосту чужой выбор.

Стиль письма, в том числе фон и отступы коробки блока, — дело хоста: это часть
`html`. Элемент добавляет в документ рамки один свой лист: указатель над блоком,
оттенки наведения и выбора, тень бумаги. Значения берутся из токенов страницы
(`--sf-paper-hover`, `--sf-paper-select`) — у них значения светлой темы в обеих
темах, потому что письмо всегда светлое. Выбор блока письмо не перезагружает.

### Последняя хорошая картинка

Пустой `html` ничего не меняет, рамка не очищается. Пока следующий документ не
загрузился, видна прежняя картинка, у элемента стоит `data-sf-drawing`. `stale`
только показывает заметку: хост, у которого письмо не отрисовалось, просто не
передаёт новый `html`. Прокрутка сохраняется при перерисовке и при смене ширины.
Очистить холст можно, передав пустой документ строкой.

### События

| Событие | Когда | `detail` |
|:---|:---|:---|
| `sf-mail-canvas-select` | щелчок по блоку или мимо, дерево оверлея; пустой `id` — ничего не выбрано | `{ids, id}` |
| `sf-mail-canvas-hover` | указатель перешёл на другой блок; пустой `id` — ни на какой | `{id}` |
| `change` | сменили ширину; элемент уже применил её сам | `{value, previous}` |
| `sf-mail-canvas-apply` | действие панели | `{action, scope, ids}` |
| `sf-mail-canvas-insert` | «+» на письме или бросок из `accepts` | `{parent, slot, index, item, from, mode}` |
| `sf-mail-canvas-move` | перенос узла ручкой оверлея | `{ids, id, parent, position, slot}` |
| `sf-mail-canvas-edit` | правка текста на письме; отменяемое, при отмене текст возвращается | `{id, value, previous}` |
| `sf-mail-canvas-draw` | новое письмо загружено, рамка ещё не измерена | `{}` |

На `draw` хост может поправить документ через `canvas.frameDocument`: высота рамки
считается уже после этого. Свои события оверлея продолжают всплывать; слушать
нужно события элемента.

### Действия

| Действие | Что делает | Ответ |
|:---|:---|:---|
| `select {id}` | как щелчок по блоку; без `id` снимает выбор | `applied`; `refused unknown` |
| `set-width {value}` | как кнопка ширины | `applied`; `refused unknown`, `unchanged` |
| `reveal {id}` | показывает блок на холсте; без `id` — выбранный | `applied`; `refused unknown`, `unchanged` |
| `refresh` | заново измеряет рамку и обновляет оверлей, например после `transform` на предке | `applied` |

Геттеры: `canvas.frame` — рамка, `canvas.frameDocument` — документ в ней,
`canvas.overlay` — оверлей, для `setDropFilter`, `setMessages`,
`setInsertionTarget` и `edit`.

### Оверлей и `contain` у предка

`sf-composition-overlay` рисует фиксированным слоем. Если у предка есть `contain:
layout` (например `[data-sf-drawer-container]` у `sf-drawer`, а значит и `main` с
docked-панелями), предок становится опорным блоком этого слоя, и все рамки съезжают
на расстояние от начала страницы до предка. Это пробел Framework
(simai/ui-source#58, открыт), элемент его не лечит и не скрывает.

Пока он открыт, в таком месте страницы оверлей ставит хост — вне такого предка:

```html
<main>
  <sf-mail-canvas overlay-target="canvas-overlay"></sf-mail-canvas>
</main>
<section aria-label="Слой редактора над письмом">
  <sf-composition-overlay id="canvas-overlay" label="Предпросмотр"></sf-composition-overlay>
</section>
```

С `overlay-target` своего оверлея в разметке нет: элемент подключает к рамке
оверлей хоста, передаёт ему узлы, действия и выбор и пересылает его события как
свои. Если такого `id` на странице нет, в консоли предупреждение, а элемент найдёт
оверлей при следующей отрисовке. Без `overlay-target` оверлей стоит в разметке
элемента, и это верно, только пока у предков нет `contain: layout`.

## Доступность

Сначала переключатель ширины, затем дерево оверлея; рамка и ссылки письма в порядок
Tab не входят. Клавиши дерева и панели — у `sf-composition-overlay` (см. его
документацию): стрелки, Home и End, Enter к панели или правке, Escape. После щелчка
по письму те же клавиши работают и внутри рамки. Заметка о весе — строка состояния.
У рамки и слоя есть имена на языке страницы.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `html` — `string`, по умолчанию пусто. Готовое письмо, строка, которую показывает рамка. Пусто — остаётся последняя хорошая картинка.
- `selected` — `string`, по умолчанию пусто. Выбранный блок; пусто — ничего не выбрано.
- `width` — `string`, по умолчанию пусто. Текущая ширина, по value; пусто или неизвестно — первая из widths. Когда человек нажимает ширину, элемент меняет её сам.
- `stale` — `boolean`, по умолчанию `false`. Говорит, что картинка устарела; картинка остаётся.
- `accepts` — `string`, по умолчанию пусто. Группы sf-sortable, чьи элементы можно бросать на письмо, через пробел (accepts оверлея).
- `mark-attribute` — `string`, по умолчанию `data-block`. Атрибут, которым в письме помечен блок; его значение — id пункта. Имя вида data-.
- `box-attribute` — `string`, по умолчанию пусто. Атрибут, которым внутри блока помечена его коробка: коробку заливает оттенок и обводит оверлей. Пусто — сам блок. Имя вида data-.
- `paper` — `string`, по умолчанию пусто. Селектор бумаги письма внутри рамки: бумага отбрасывает тень, когда рамка шире письма. Иначе тень отбрасывает рамка.
- `overlay-target` — `string`, по умолчанию пусто. id оверлея sf-composition-overlay, поставленного хостом в другом месте страницы, вне предка с contain (simai/ui-source#58). Пусто — оверлей стоит в разметке самого элемента.
- `widths` — `array` из `object`, по умолчанию `[]`. Предлагаемые ширины, в форме sf-button-group: {value, label, icon, icon-only, aria-label}. value — ширина письма; frame — ширина рамки в пикселях, если она отличается от value. Пусто — переключателя нет, и рамка занимает всю область.
- `weight` — `object`, по умолчанию `{}`. Насколько тяжёл HTML письма, {bytes, max} в килобайтах, когда он приближается к порогу обрезки. Пусто — заметки нет.
- `items` — `array` из `object`, по умолчанию `[]`. Что есть в письме для оверлея и что считается блоком: {id, label, kind, parent, editable, rect}. Метка в письме, чьего id здесь нет, блоком не считается.
- `actions` — `array` из `object`, по умолчанию `[]`. Панель действий выбранного блока: до 16 {id, label}, с собственной проверкой оверлея.

### Методы

- `select(id: any)` — возвращает `object`. Выбирает блок, как нажатие; без id снимает выбор; refused unknown для блока не из items.
- `setWidth(value: string)` — возвращает `object`. Переключает ширину, как её кнопка; refused unknown для ширины, которой нет в предложенных, unchanged, если она уже выбрана.
- `reveal(id: any)` — возвращает `object`. Показывает блок на холсте, без id — выбранный; refused unknown, unchanged, если он уже виден.
- `refresh()` — возвращает `object`. Заново измеряет рамку и обновляет оверлей после изменения, о котором никто не сообщает (transform на предке).

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `sf-mail-canvas-select` — `detail`: `{ ids: array, id: any }`. Выбран этот блок: {ids, id}. Пустой id — ничего не выбрано.
- `sf-mail-canvas-hover` — `detail`: `{ id: any }`. Указатель над этим блоком: {id}. Пустой id — ни над каким.
- `change` — `detail`: `{ value: string, previous: string }`. Теперь используется эта ширина: {value, previous}.
- `sf-mail-canvas-apply` — `detail`: `{ action: string, scope: any, ids: array }`. Для этого блока выбрано это действие панели: {action, scope, ids}.
- `sf-mail-canvas-insert` — `detail`: `{ parent: any, slot: string, index: integer, item?: string, from?: string, mode?: any }`. Попросили блок в этом месте: {parent, slot, index, item, from, mode}.
- `sf-mail-canvas-move` — `detail`: `{ ids: array, id: any, parent: any, position: number, slot: string }`. Переместить этот блок в это место: {ids, id, parent, position, slot}.
- `sf-mail-canvas-edit` — `detail`: `{ id: any, value: string, previous: string }`. Теперь текст этого узла такой: {id, value, previous}. При отмене текст возвращается.
- `sf-mail-canvas-draw` — ничего не передаёт. В рамке новое письмо, ещё не измеренное.

### Доступность

- Роль: область (`region`).
- Доступное имя: внутренний.
- Клавиши: `Tab`, `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`, `Home`, `End`, `Enter`, `Escape`.
- Фокус: Переключатель ширины, затем дерево оверлея. Рамка и ссылки письма в порядок Tab не входят. У рамки и слоя есть имена на языке страницы.

### Минимальная разметка

```html
<sf-mail-canvas id="canvas"></sf-mail-canvas> <script>canvas.items = [{id: 'b1', label: 'Заголовок'}]; canvas.html = '<p data-block="b1">Письмо</p>';</script>
```
