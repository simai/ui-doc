# Page Header

`<sf-page-header>` — шапка страницы административного приложения. В ней
собраны путь к странице, заголовок, число записей, отметка «в избранном» и
главное действие. Путь передаётся в слот `path` (обычно `<sf-breadcrumbs>`),
действия — в слот `actions`.

Компонент не хранит избранное: по нажатию на звезду он сообщает событие, а
состояние `star` задаёт страница по ответу сервера. Заголовок оформлен
четвёртой ступенью заголовков, отдельно его стилизовать не нужно.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-9fb0297bb5c2` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-page-header>` |
| Назначение | Шапка страницы администратора: путь, заголовок, счётчик, звезда избранного, отметка установки и главное действие. Используется вместе с sf-admin-menu. |
| Контракт | `smart.page-header`, версия `1.0.0` |
| Поставка | выпуск Framework `ui-9fb0297bb5c2` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |
| Готовность | описан: манифест и сценарий есть, продуктовой приёмки нет |

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Назначение |
|:---|:---|:---|:---|:---|
| `heading` | `string` | пусто | — | Заголовок страницы. |
| `count` | `string` | пусто | — | Сколько записей на странице; пустое значение не выводит счётчик. В меню администратора итогов нет, поэтому они выводятся здесь. |
| `level` | `string` | `site` | `site`, `install` | install отмечает страницу, общую для всех сайтов. |
| `star` | `string` | пусто | пусто, `off`, `on` | Пустое значение не рисует звезду; off и on рисуют её в соответствующем состоянии. |
| `root-class` | `string` | пусто | — | — |

### Методы

Публичных методов нет.

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

| Событие | `detail` | Когда |
|:---|:---|:---|
| `sf-page-header-star` | `{ on: boolean }` | Пользователь нажал на звезду. Отменяемое: элемент, который ждёт собственного ответа, отменяет событие и сам задаёт star. |

### Доступность

- Роль: содержимое баннера (`banner`); заголовок — `h1`.
- Доступное имя: заголовок (`heading`).
- Клавиши: `Tab reaches the star and the actions`, `Enter or Space toggles the star`.
- Фокус: Звезда — нативная кнопка в sf-icon-button с aria-pressed и подписью, которая говорит, что произойдёт при нажатии.

### Минимальная разметка

```html
<sf-page-header heading="Каталог решений" count="448" star="off"><sf-breadcrumbs slot="path"><sf-breadcrumbs-item href="/">simai.ru</sf-breadcrumbs-item><sf-breadcrumbs-item href="/data">Данные</sf-breadcrumbs-item></sf-breadcrumbs><sf-button slot="actions" icon-start="add">Создать</sf-button></sf-page-header>
```
