# Редактор содержимого

`<sf-content-editor>` — режим «Содержимое» редактора страниц SIMAI: страница
набирается одним потоком, как в обычном текстовом редакторе. Элемент ничего не
хранит: он правит свою копию документа и после каждого изменения отправляет
событие `change` с новым документом, а сохраняет приложение.

Компонент поставляется пакетом `larena` из репозитория `simai/ui-pro`
(SIMAI Pro, папка `components/`), а не выпуском Framework. Лицензия пакета —
PolyForm Small Business 1.0.0 или PolyForm Noncommercial 1.0.0, по запросу —
коммерческая лицензия SIMAI; в составе Larena — лицензия Larena. Как
подключить пакет — в разделе
[Подключение смарт-компонентов](/ru/guide/smart-components/page/#подключение-к-странице).

## Применение

### Данные

```js
editor.document = {
  schema: 'simai.composition.document', schema_version: 1, id: 'guide', profile: 'structured-content',
  root: {id: 'root', type: 'content.document', data: {title: 'Как начать'}, slots: {default: [
    {id: 'p1', type: 'content.paragraph', data: {content: [{type: 'text', value: 'Первая строка'}]}},
  ]}},
};
editor.addEventListener('change', (event) => save(event.detail.document));
```

Документ — Composition Document с профилем `structured-content`. Новый объект в
`document` начинает правку заново; документ, который редактор сам отправил в
`change` и приложение вернуло, узнаётся, и курсор остаётся на месте.

`kinds` — какие виды блоков предлагают меню «/» и «+», по id: `paragraph`,
`heading-2`, `heading-3`, `list`, `ordered-list`, `quote`, `alert`, `details`,
`steps`, `table`, `figure`, `code`, `divider`, `tabs`, `card`, `grid`, `html`.
Пусто — первые тринадцать.

`editor-manifests` — манифесты редактора для своих типов блоков приложения или
вместо манифеста Framework: из них строится форма параметров блока.

### Набор

- Enter делит блок на два; после заголовка и заметки новая строка — обычный
  текст. Enter в пустом пункте выводит из списка, в пустой последней строке
  цитаты или заметки — из блока.
- Backspace в начале строки соединяет её с предыдущей; в начале заголовка
  превращает его в текст, в начале первого пункта — в абзац перед списком.
  Delete в конце абзаца забирает следующий.
- Markdown в начале пустой строки меняет вид: `## `, `### `, `- `, `1. `,
  `> `, ```` ``` ````, `---`.
- «/» в пустой строке открывает список видов; набранные буквы его сужают,
  стрелки выбирают, Enter применяет, Esc закрывает.
- Выделение текста показывает панель [`sf-inline-editor`](/ru/smart-components/editor/inline-editor/):
  жирный, курсив, код, ссылка (⌘B, ⌘I, ⌘E, ⌘K). Пока курсор просто стоит,
  панели нет.
- ↑ и ↓ на первой и последней строке переходят в соседнее поле; ⌥↑ ⌥↓
  двигают блок; ⌘D дублирует.
- В таблице Tab идёт по ячейкам и после последней добавляет строку; Enter —
  ячейка ниже. В коде Tab вставляет два пробела, ⌘Enter выходит из блока. В
  шаге Enter делает следующий шаг, Shift+Enter — абзац внутри шага.
- Вставка из Word или с сайта становится блоками: абзацы, заголовки, списки,
  цитаты, жирный, курсив, безопасные ссылки; стили и скрипты не проходят. Одна
  строка вставляется в место курсора.
- ⌘Z и ⇧⌘Z — история всего документа.

### Блоки как выбор

Esc в поле выбирает его блок. Стрелки выбирают соседний, Shift расширяет
выбор, ⌥↑ ⌥↓ двигают, Enter возвращает к набору, Backspace удаляет, ⌘D
дублирует, ⌘C и ⌘X копируют блоки целиком, ⌘A выбирает все. Esc при
выбранных блоках снимает выбор и отправляет `sf-content-editor-leave`:
редактор страниц по нему возвращается к макету.

### Поле слева и меню блока

У блока под указателем слева появляются «+» и ручка. «+» предлагает вид
нового блока после этого (пустой абзац превращается сам). Щелчок по ручке
открывает меню блока — параметры, «Превратить в», строки и столбцы таблицы,
выше, ниже, дублировать, удалить; перетаскивание ручки переносит блок.

### Параметры блока

Форма параметров строится из манифеста редактора для типа блока и
открывается тихой кнопкой справа вверху блока или из меню ручки. В документ
записывается только значение, отличное от значения по умолчанию. У картинки в
форме есть ещё адрес: файлов редактор не загружает.

### Неизвестные блоки

Блок типа, которого редактор не знает, показывается закрытой карточкой с
именем типа и хранится без изменений: его можно только переместить или
удалить целиком.

### События

| Событие | Когда | `detail` |
|:---|:---|:---|
| `change` | любое изменение документа | `{document, reason}` |
| `sf-content-editor-select` | выбор блоков изменился | `{ids}` |
| `sf-content-editor-leave` | Esc при выбранных блоках | `{}` |

`reason`: `typing`, `split`, `merge`, `insert`, `convert`, `remove`, `move`,
`duplicate`, `paste`, `params`, `table`, `row`, `history`.

### Действия

| Действие | Что делает | Ответ |
|:---|:---|:---|
| `edit {id}` | ставит курсор в блок, без id — в первый | `applied`; `refused unknown` |
| `select {ids}` | выбирает блоки одного потока | `applied`; `refused unknown`, `not-siblings` |
| `insert {kind, after}` | делает блок вида после блока или в конце | `applied`; `refused unknown` |
| `undo`, `redo` | шаг истории | `applied`; `refused empty` |

## Доступность

Одна остановка Tab — поле, в котором печатали последним. Каждое поле —
подписанный `role="textbox"`; список «/» — `listbox`, на который поле
указывает через `aria-activedescendant`. Что произошло (вставлено, удалено,
перемещено, выбран блок), говорит строка состояния.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `label` — `string`. Доступное имя блоков страницы.
- `document` — `object`, по умолчанию `null`. Страница: Composition Document профиля structured-content. Новый документ начинает правку заново; документ, который редактор сам отправил в `change`, узнаётся и сохраняется.
- `kinds` — `array`, по умолчанию `[]`. Виды, которые предлагают меню «/» и «+» слева, по id (paragraph, heading-2, heading-3, list, ordered-list, quote, alert, details, steps, table, figure, code, divider, tabs, card, grid, html). Пусто — первые тринадцать.
- `editor-manifests` — `array` из `object`, по умолчанию `[]`. Манифесты редактора для собственных типов блоков хоста или вместо манифеста Framework для типа: из них строится форма параметров блока.

### Методы

- `edit(id: any)` — возвращает `object`. Ставит курсор в блок, без id — в первый; `refused unknown` для блока, которого нет на странице.
- `select(ids: array)` — возвращает `object`. Выбирает блоки, как Esc и Shift со стрелками; `refused unknown`, `not-siblings`.
- `insert(kind: any, after: any)` — возвращает `object`. Делает блок предложенного вида после блока или в конце страницы; `refused unknown`.
- `undo()` — возвращает `object`. Шаг назад, как ⌘Z; `refused empty`, если отменять нечего.
- `redo()` — возвращает `object`. Шаг вперёд, как ⇧⌘Z; `refused empty`.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `change` — `detail`: `{ document: object, reason: string }`. Страница изменилась: `{document, reason}`. Документ сохраняет хост.
- `sf-content-editor-select` — `detail`: `{ ids: array }`. Выбраны эти блоки: `{ids}`; пусто, если ни одного.
- `sf-content-editor-leave` — ничего не передаёт. Esc при выбранных блоках: человек просит выйти из текста.

### Доступность

- Роль: группа (`group`).
- Доступное имя: внутренний.
- Клавиши: `Tab`, `Enter`, `Backspace`, `ArrowUp`, `ArrowDown`, `Alt+ArrowUp`, `Alt+ArrowDown`, `Escape`, `Meta+Z`.
- Фокус: Одна остановка Tab — поле, в котором печатали последним. Esc выбирает его блок; стрелки выбирают другие, Enter возвращает к набору. Список «/» объявляется через aria-activedescendant; что изменилось, говорит строка состояния.

### Минимальная разметка

```html
<sf-content-editor id="page"></sf-content-editor> <script>page.document = doc; page.addEventListener('change', (e) => save(e.detail.document));</script>
```
