# Pagination

Компонент отображает именованную навигацию по страницам, но не загружает данные и
не придумывает URL. Приложение передаёт `current`, `total` и `page-size`, слушает
события и обновляет свой источник данных.

## Минимальная разметка

```html
<sf-pagination
  aria-label="Страницы результатов поиска"
  current="2"
  total="96"
  page-size="10"
  top="false"
  bottom="false"
  show-page-size="false"
></sf-pagination>
```

## Доступность

Видимый корень — `nav` с доступным именем. Номера образуют список, текущая
страница одна и получает `aria-current="page"`. Многоточие не является кнопкой.
Tab достигает только доступных действий, а общий `focus-visible` контракт
Framework показывает фокус при клавиатурной навигации и в forced-colors.

## Границы композиции

Верхнее «Показать ещё», выбор размера страницы и нижние пакетные действия
сохранены для совместимости и включаются отдельными параметрами. Они не входят в
минимальный контракт пагинации. Количество выбранных строк всегда передаёт
приложение через `selected-count`; компонент не читает состояние соседней таблицы.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-ec56cef08625` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-pagination>` |
| Назначение | Навигация по коллекции, разбитой на пронумерованные страницы, на основе источника данных. |
| Контракт | `smart.pagination`, версия `1.0.1` |
| Поставка | выпуск Framework `ui-ec56cef08625` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |
| Готовность | принят в продукт |

### Атрибуты

- `template` — `string`, по умолчанию `default`, значения: `default`. Имя шаблона.
- `top` — `boolean`, по умолчанию `true`. Показывает совместимый блок «показать ещё».
- `middle` — `boolean`, по умолчанию `true`. Показывает навигацию по страницам и сводку по коллекции.
- `bottom` — `boolean`, по умолчанию `true`. Разрешает совместимый раздел пакетных действий.
- `top-class` — `string`, по умолчанию пусто. Утилитарные классы Framework для раздела «показать ещё».
- `main-class` — `string`, по умолчанию пусто. Утилитарные классы Framework для раздела навигации.
- `bottom-class` — `string`, по умолчанию пусто. Утилитарные классы Framework для раздела пакетных действий.
- `aria-label` — `string`, по умолчанию `Result pages`. Доступное имя навигационного ориентира (landmark).
- `pages-label` — `string`, по умолчанию `Pages:`. Видимая подпись перед элементами управления страницами.
- `page-label` — `string`, по умолчанию `Page`. Доступный префикс для действия с номером страницы.
- `previous-label` — `string`, по умолчанию `Previous page`. Доступное имя действия перехода на предыдущую страницу.
- `next-label` — `string`, по умолчанию `Next page`. Доступное имя действия перехода на следующую страницу.
- `last-label` — `string`, по умолчанию `Last`. Видимая подпись совместимого действия перехода на последнюю страницу.
- `total-label` — `string`, по умолчанию `Total:`. Видимая подпись для общего количества элементов.
- `selected-label` — `string`, по умолчанию `Selected:`. Видимая подпись для количества выбранных элементов.
- `selected-count` — `integer`, по умолчанию `0`, значения: от 0. Количество выбранных элементов, ограниченное диапазоном от нуля до общего количества.
- `show-more-text` — `string`, по умолчанию `Show more`. Подпись совместимого действия «показать ещё».
- `current` — `integer`, по умолчанию `1`, значения: от 1. Текущий номер страницы, начиная с единицы.
- `total` — `integer`, по умолчанию `10`, значения: от 0. Неотрицательное общее число элементов.
- `page-size` — `integer`, по умолчанию `10`, значения: от 1. Положительное число элементов на странице.
- `page-sizes` — `string`, по умолчанию `10,20,30,40`. Варианты размера страницы — положительные числа через запятую.
- `show-page-size` — `boolean`, по умолчанию `true`. Показывает выбор размера страницы для непустой коллекции.
- `page-size-label` — `string`, по умолчанию `Per page:`. Видимая и доступная подпись выбора размера страницы.
- `show-actions` — `boolean`, по умолчанию `true`. Показывает групповые действия, если они переданы.
- `actions` — `string`, по умолчанию пусто. Определения совместимых пакетных действий, разделённые вертикальной чертой.
- `action` — `string`, по умолчанию пусто. Значение выбранного группового действия.
- `action-apply-text` — `string`, по умолчанию `Apply`. Подпись кнопки применения пакетного действия.
- `show-action-for-all` — `boolean`, по умолчанию `false`. Показывает совместимый переключатель «все элементы».
- `action-for-all` — `boolean`, по умолчанию `false`. Текущее значение переключателя «все элементы».
- `action-for-all-label` — `string`, по умолчанию `For all`. Подпись переключателя «все элементы».
- `actions-label` — `string`, по умолчанию `Action for the selected records`. Доступное имя селектора пакетного действия.
- `action-choose-label` — `string`, по умолчанию `Choose an action`. Placeholder селектора пакетного действия, отображаемый, пока действие не выбрано.
- `actions-region-label` — `string`, по умолчанию `Actions for the selected`. Доступное имя панели, которая появляется, пока строки отмечены.
- `clear-selection-label` — `string`, по умолчанию `Clear the selection`. Доступное имя и подсказка элемента управления, сбрасывающего выделение.
- `count-known` — `boolean`, по умолчанию `true`. Известно ли количество записей. Хост, который не считает каждый ответ, задаёт false, и представление предлагает подсчитать количество вместо того, чтобы показывать его.
- `can-count` — `boolean`, по умолчанию `false`. Может ли хост подсчитать количество по запросу. Без этого представление ничего не предлагает и ничего не запрашивает.
- `counting` — `boolean`, по умолчанию `false`. Счётчик загружается; вместо числа отображается короткое ожидание.
- `has-next` — `boolean`, по умолчанию `false`. Существует ли следующая страница. Определяет переход вперёд и «Показать ещё», когда общее количество не передано.
- `show-count-label` — `string`, по умолчанию `Show the number`. Текст элемента управления, который запрашивает у хоста количество.
- `counting-label` — `string`, по умолчанию `Counting`. Доступное имя короткого ожидания, которое отображается, пока загружается счётчик.
- `first-label` — `string`, по умолчанию `First`. Доступное имя и подсказка элемента управления, переходящего на первую страницу.
- `page-field-label` — `string`, по умолчанию `Page:`. Подпись поля для номера страницы.
- `show-more-busy` — `boolean`, по умолчанию `false`. Отмечает кнопку «Показать ещё» как занятую, пока хост загружает следующую порцию; она отключена и показывает индикатор загрузки.

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `sf-action-apply` — `detail` не описан.
- `sf-action-change` — `detail` не описан.
- `sf-action-for-all-change` — `detail` не описан.
- `sf-count-request` — `detail` не описан.
- `sf-page-change` — `detail` не описан.
- `sf-page-size-change` — `detail` не описан.
- `sf-selection-clear` — `detail` не описан.
- `sf-show-more` — `detail` не описан.

### Доступность

- Роль: навигация (`navigation`).
- Доступное имя: обязательно.
- Клавиши: `Tab`.
- Фокус: Tab переходит только к включённым нативным действиям. Фокус использует общее оформление focus-visible только для клавиатуры и остаётся видимым в режиме forced colors; пропущенные страницы не получают фокус.
