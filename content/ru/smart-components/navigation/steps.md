# Steps

`<sf-steps>` показывает этапы процесса, который проходят по порядку:
оформление заказа, публикация, мастер настройки. Пройденные этапы отмечены
галочкой, текущий выделен. Компонент собирает разметку обычного
[шага](/ru/components/navigation/step/) из строки или массива.

## Применение

### Этапы и текущий этап

`items` перечисляет этапы через `|`; после `::` идут флаги, например
`Публикация::disabled`. Можно передать и массив объектов с полями `label` и
`disabled`. `current` — номер текущего этапа, считая с нуля; этапы перед
ним отмечаются пройденными.

`error-step` отмечает этап с ошибкой — номер, тоже с нуля. Такой этап
получает иконку ошибки вместо галочки. `size` — `1/2` или `1`,
`separator-icon` меняет разделитель между этапами.

:::example {id="smart-components/steps/error" label="Результат"}
:::

### Переход по этапам

Каждый доступный этап — кнопка. Нажатие делает этап текущим и отправляет
всплывающее событие `sf-step-change` с `detail.previous`, `detail.current`
(номера с нуля), `detail.item` — данными этапа и `detail.items` — всеми
этапами. Недоступный этап не нажимается. Если переход назад или вперёд
нельзя разрешить без проверки — например, пока форма этапа не заполнена, —
отметьте следующие этапы `disabled` и снимайте флаг по мере прохождения.

`goToStep(index)` переходит из кода и отправляет то же событие,
`onStepChange(handler)` передаёт обработчику номер нового этапа первым
аргументом. Кнопки «Назад» и «Далее» рядом с этапами задаёт страница.

```js
const steps = document.querySelector('sf-steps');
steps.onStepChange((current) => showPanel(current));

document.querySelector('#next').addEventListener('click', () => {
  if (validateCurrentPanel()) steps.goToStep(Number(steps.getAttribute('current')) + 1);
});
```

## Доступность

- Группе этапов нужно доступное имя: `aria-label` на `<sf-steps>`. По
  умолчанию на русской странице она называется «Шаги».
- Каждый этап — нативная кнопка: `Tab` останавливается на ней, `Enter` и
  `Space` нажимают её. Недоступный этап выпадает из порядка `Tab`.
- Текущий этап отмечен `aria-current="step"`. К имени пройденного этапа
  добавляется «Завершено», к имени этапа с ошибкой — «Ошибка». Слова
  берутся из языка страницы; `completed-label` и `error-label` заменяют их.
- Иконки и разделители скрыты от вспомогательных технологий: состояние
  передаёт имя кнопки, а не цвет.

### Атрибуты

- `size` — `string`, по умолчанию `1`.
- `items` — `string`, по умолчанию `[]`.
- `current` — `number`, по умолчанию `0`.
- `error-step` — `string`, по умолчанию пусто.
- `separator-icon` — `string`, по умолчанию `chevron_right`.
- `aria-label` — `string`, по умолчанию `Steps`.
- `completed-label` — `string`, по умолчанию `Completed`.
- `error-label` — `string`, по умолчанию `Error`.
- `root-class` — `string`, по умолчанию пусто.

### Методы

- `setState()`
- `goToStep()`
- `onStepChange()`

### События

Все события приходят на сам элемент и всплывают. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `sf-step-change` — `detail` не описан.

### Доступность

- Роль: группа (`group`).
- Доступное имя: обязательно.
- Клавиши: `Tab`, `Enter`, `Space`.
- Фокус: Каждая доступная нативная кнопка шага остаётся доступной с клавиатуры и использует общий индикатор `focus-visible`. Текущий шаг передаёт `aria-current=step`; статусы завершения и ошибки включены в доступные имена.

### Минимальная разметка
