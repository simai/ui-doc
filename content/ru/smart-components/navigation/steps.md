# Steps

## Минимальная разметка

```html
<sf-steps
  aria-label="Этапы публикации"
  completed-label="Завершено"
  error-label="Ошибка"
  items="Черновик|Проверка|Публикация"
></sf-steps>
```

## Доступность

Корень рендерится как именованная группа, а каждый доступный шаг — как нативная
кнопка `type="button"`. Enter и Space работают нативно; отключённый шаг получает
`disabled` и исключается из Tab-порядка. Текущий шаг использует
`aria-current="step"`.

Всегда локализуйте `aria-label`, `completed-label` и `error-label`: последние
два значения добавляются к доступному имени завершённого или ошибочного шага.
Иконки и разделители декоративны и не заменяют текст состояния. Приложение
остаётся владельцем перехода, валидации и основного управления «Назад/Далее».

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-6d2bf151e3c8` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

### Атрибуты

- `size` — `string`, по умолчанию `1`.
- `items` — `string`, по умолчанию `[]`.
- `current` — `number`, по умолчанию `0`.
- `error-step` — `string`, по умолчанию пусто.
- `separator-icon` — `string`, по умолчанию `chevron_right`.
- `aria-label` — `string`, по умолчанию `Steps`.
- `completed-label` — `string`, по умолчанию `Completed`.
- `error-label` — `string`, по умолчанию `Error`.
- `root-class` — `string`, по умолчанию пусто.

### Методы

- `setState()`
- `goToStep()`
- `onStepChange()`

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `sf-step-change` — `detail` не описан.

### Доступность

- Роль: группа (`group`).
- Доступное имя: обязательно.
- Клавиши: `Tab`, `Enter`, `Space`.
- Фокус: Каждая доступная нативная кнопка шага остаётся доступной с клавиатуры и использует общий индикатор `focus-visible`. Текущий шаг передаёт `aria-current=step`; статусы завершения и ошибки включены в доступные имена.
