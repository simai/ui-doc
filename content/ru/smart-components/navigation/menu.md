# Меню

`<sf-menu>` — навигация по сайту, разделу или кабинету: вложенные разделы,
текущая страница, ветки, которые открываются и закрываются. Оно собирает
разметку [меню](/ru/components/navigation/menu/) из данных или из вложенного
списка ссылок, написанного внутри.

## Разметка

Пункты задаёт `items` — массив `{id, label, href, icon, badge, current,
disabled, open, children}`: в свойстве — массивом, в атрибуте — тем же
массивом в JSON. `children` — вложенные пункты; пункт с ними — ветка.

- Без `items` меню читает вложенный список `<ul><li><a>`, написанный внутри.
- `label` называет навигацию (`aria-label` её `<nav>`).

## Варианты

### Строка

`orientation="horizontal"` ставит первый уровень в строку, а ветки открываются
панелями под ней (глубже — сбоку). Если строка не помещается по ширине, она
становится кнопкой «Меню», которая открывает те же ссылки колонкой;
`collapse` управляет этим: `auto`, `always` или `none`.

:::example {id="smart-components/menu/horizontal" label="Строка с панелями"}
:::

### Дерево документации

`appearance="documentation-tree"` — дерево без рамок с отступом на каждом
уровне, как оглавление документации.

:::example {id="smart-components/menu/documentation-tree" label="Дерево документации"}
:::

### Компактная полоса

`appearance="compact"` — полоса значков первого уровня: слова остаются в
имени ссылки, ветки не открываются.

:::example {id="smart-components/menu/compact" label="Полоса значков"}
:::

### Меню из разметки

Вложенный список ссылок внутри `<sf-menu>` работает и без скриптов, а
компонент добавляет к нему раскрытие веток и клавиатуру.

:::example {id="smart-components/menu/markup" label="Меню из списка ссылок"}
:::

## Состояния

### Текущая страница и недоступный пункт

`current` называет `id` пункта текущей страницы: его ссылка получает
`aria-current="page"`. `current-from-location` находит его по адресу
страницы. `disabled: true` делает пункт недоступным.

## Применение

### Когда брать меню

Меню — для навигации: шапки сайта, боковой панели, оглавления. Для действий
над выбранным объектом берите
[Контекстное меню](/ru/smart-components/navigation/context-menu/), для
навигации административного приложения —
[Меню администратора](/ru/smart-components/composite/admin-menu/).

### Переходы и события

Перед переходом по ссылке приходит `sf-menu-navigate` с `id`, `href` и
`item`. Его можно отменить: `preventDefault()` останавливает переход, и
приложение, которое само меняет страницы, показывает нужную. Нажатие с
клавишей-модификатором или средней кнопкой событие не отправляет.
`sf-menu-toggle` сообщает, что ветка открылась или закрылась.

Прежние имена `sf-menu:navigate` и `sf-menu:toggle` приходят с тем же
`detail` до 2026-12-01; отмена перехода действует для обоих имён. Каждое
обращение к прежнему имени записывается в `SF.deprecations`.

`open(id)`, `close(id)`, `toggle(id)`, `isOpen(id)` и `closeAll()` управляют
ветками из кода. Открыть, закрыть и переключить ветку можно и объектом:
`open({id})`. Они отвечают `{outcome: 'applied'}`, если что-то изменилось, и
`{outcome: 'refused', reason}`, если нет: `unknown` — такой ветки нет,
`compact` — вид compact ветки не открывает, `disabled` — пункт недоступен,
`already` — ветка уже в этом состоянии.

```js
const menu = document.querySelector('sf-menu');
menu.addEventListener('sf-menu-navigate', (event) => {
  event.preventDefault();
  router.go(event.detail.href);
});
```

## Доступность

- Меню — `<nav>` с именем из `label`, из настоящих ссылок; у каждой ветки —
  кнопка с `aria-expanded` и `aria-controls`. Ветка, которая сама является
  страницей, показывает в строке ссылку и кнопку рядом.
- `Tab` обходит ссылки и кнопки по порядку, `Enter` и `Space` открывают и
  закрывают ветку, `Escape` закрывает самую глубокую открытую панель и
  возвращает фокус на её кнопку. В колонке панелей нет: её группы на `Escape`
  не закрываются, и клавиша остаётся странице.
- Это шаблон навигации WAI-ARIA, а не меню приложения: роли `menu` у него нет.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `orientation` — `string`, по умолчанию `vertical`, значения: `vertical`, `horizontal`. vertical: колонка, ветки которой открываются на месте; horizontal: первый уровень в строку, каждая ветка — панель под ним (глубже — сбоку), размещённая геометрией Framework.
- `appearance` — `string`, по умолчанию `default`, значения: `default`, `documentation-tree`, `compact`. Виды класса menu: default; documentation-tree — дерево без рамок с отступом на каждом уровне; compact — полоса значков первого уровня, слова которых остаются в имени ссылки, а ветки не открываются. Оба последних — колонки.
- `current-from-location` — `boolean`, по умолчанию `false`. Без current текущей страницей считается пункт, ссылка которого ведёт на location.pathname (завершающая косая черта и index.html не важны); переходы по истории учитываются.
- `collapse` — `string`, по умолчанию `auto`, значения: `auto`, `always`, `none`. auto: строка, которая не помещается по ширине, становится кнопкой, открывающей те же ссылки колонкой, и снова строкой, когда ширина вернулась; always: кнопка при любой ориентации; none: никогда.
- `label` — `string`, по умолчанию пусто. Имя навигации (aria-label её `<nav>`); если не задано — aria-label элемента или `<nav>`, написанного внутри.
- `toggle-label` — `string`. Слова кнопки, которой становится свёрнутое меню; если не задано — «Меню» / «Menu» на языке страницы.
- `current` — `string`, по умолчанию пусто. id элемента текущей страницы; с `current-from-location` решает адрес страницы
- `aria-label` — `string`, по умолчанию пусто.
- `items` — `array` из `object`, по умолчанию `[]`, например `[{"id":"about","label":"О компании","href":"/about/"},{"id":"catalog","label":"Каталог","children":[{"id":"solutions","label":"Решения","href":"/catalog/solutions/"}]},{"id":"contacts","label":"Контакты","href":"/contacts/","badge":"3"}]`. Пункты [{id, label, href?, icon?, badge?, current?, disabled?, open?, children?}]: массив в свойстве, тот же массив в JSON в атрибуте. Без items элемент читает вложенный `<ul><li><a>`, написанный внутри.

### Методы

- `open(id: any)` — возвращает `boolean`. Открывает ветку с этим id. В строке закрываются панели, которые не над ней. sf-menu-toggle приходит для каждой изменившейся ветки, source method. Возвращает, изменилось ли что-нибудь.
- `close(id: any)` — возвращает `boolean`. Закрывает ветку с этим id; в строке закрываются и панели внутри неё. Возвращает, изменилось ли что-нибудь.
- `toggle(id: any)` — возвращает `boolean`. Открывает ветку, если она закрыта, и закрывает, если открыта. Возвращает, изменилось ли что-нибудь.
- `closeAll()` — возвращает `boolean`. Закрывает открытые панели строки и панель кнопки свёрнутого меню; группы колонки сохраняют состояние. Возвращает, изменилось ли что-нибудь.
- `isOpen(id: string)` — возвращает `boolean`. Открыта ли ветка с этим id.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `sf-menu-navigate` — `detail`: `{ id: any, href: string, item: object }`.
- `sf-menu-toggle` — `detail`: `{ id: any, open: boolean, source: any, item: object|null }`.
- `sf-menu:navigate` — устаревший псевдоним события `sf-menu-navigate`: приходит с тем же `detail`, подписывайтесь на `sf-menu-navigate`.
- `sf-menu:toggle` — устаревший псевдоним события `sf-menu-toggle`: приходит с тем же `detail`, подписывайтесь на `sf-menu-toggle`.

### Доступность

- Роль: навигация (`navigation`).
- Доступное имя: рекомендуется.
- Клавиши: `Tab`, `Enter`, `Space`, `Escape`.
- Фокус: `<nav>` с именем из label, из нативных ссылок; у каждой ветки — нативная кнопка с aria-expanded и aria-controls; ветка, которая сама является страницей, показывает в строке ссылку и кнопку рядом. Tab обходит ссылки и кнопки по порядку; Enter и Space открывают и закрывают ветку; Escape закрывает только самую глубокую открытую панель — сначала ту, в которой фокус, иначе панель кнопки свёрнутого меню, — и возвращает фокус на её кнопку, держа общую отметку открытой поверхности, чтобы панель или окно позади уступили. Когда фокус покидает строку, её панели закрываются. Ссылка текущей страницы несёт aria-current="page". Роли menu нет.

### Минимальная разметка

```html
<sf-menu label="Разделы" orientation="horizontal" items='[{"id":"about","label":"О компании","href":"/about/"},{"id":"catalog","label":"Каталог","children":[{"id":"solutions","label":"Решения","href":"/catalog/solutions/"}]}]'></sf-menu>
```
