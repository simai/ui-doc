# Элемент дерева

`<sf-tree-item>` — один пункт [дерева](/ru/smart-components/navigation/tree/):
папка с вложенными пунктами, файл или ссылка на раздел. Пункты ставят внутрь
`<sf-tree>`: дерево даёт им общий порядок фокуса, клавиатуру и выбор.
Оформление совпадает с обычным [пунктом дерева](/ru/components/navigation/tree-item/).

## Применение

> **`sf-tree-item` 1.1.0.** С выпуска `ui-363de49bdfa8` пункт следует
> стандарту смарт-компонентов 2.0. Внутри `<sf-tree>` пункт читается один
> раз как данные и убирается: строки рисует само дерево, той же классовой
> разметкой. Отдельно от дерева пункт рисует свою строку и, раскрытый, —
> вложенные пункты. Прежние имена работают до 2026-12-01. Справочник API
> ниже собран из выпуска, на котором построен сайт.

### Подпись и ссылка

`label` — подпись пункта; без неё подписью служит текст внутри
`<sf-tree-item>`. Прежнее `text` работает как `label` до 2026-12-01.
`href` делает подпись ссылкой, `target` и `rel` переходят на неё. `value` —
код пункта: его получает строка как `data-value`, и его несут события.

### Папка или файл

`kind` — `folder` (по умолчанию) или `file`; прежнее `type` работает до
2026-12-01. Папка с вложенными `<sf-tree-item>` получает кнопку раскрытия и
иконку открытой или закрытой папки, файл — иконку документа и никогда не
раскрывается. Дерево с файлами удобнее передавать данными, как в
[примере Дерево](/ru/smart-components/navigation/tree/#пункты-данными).

`open-icon` и `closed-icon` заменяют иконки папки, `chevron-open-icon` и
`chevron-closed-icon` — стрелку раскрытия. `icon="false"` убирает иконку
пункта: так выглядит дерево разделов, а не файлов, как в примере. Значки
строки — символы шрифта значков (`<i class="sf-icon">`), а не элементы
`<sf-icon>`.

### Состояние

`open` раскрывает ветвь. `selected` отмечает выбранный пункт, если дерево
разрешает выбор. `active` выделяет пункт текущей страницы и ставит ему
`aria-current="page"`. `disabled` выключает пункт: он не раскрывается, его
ссылка не рисуется, а нажатие ничего не делает.

### Действия и события

Действия отвечают исходом: `{outcome: "applied"}` или `{outcome: "refused"}`
с причиной `leaf` у файла или пункта без вложенных и `disabled` у
выключенного.

| Действие | Что делает |
|:---|:---|
| `expand()` | раскрывает ветвь |
| `collapse()` | сворачивает ветвь |
| `toggleOpen()` | раскрывает свёрнутую ветвь и сворачивает раскрытую |
| `activate()` | то же, что `Enter` на листе: открывает ссылку или отправляет `sf-tree-item-open` |
| `focusItem()` | переводит фокус на строку пункта |

Прежние методы `open()`, `close()` и `toggle()` убраны: `open` теперь —
значение ветви, свойство, и методом быть не может. Вместо `item.open()`
пишите `item.expand()` или `item.open = true`.

| Событие | Когда | `event.detail` | Прежнее имя (до 2026-12-01) |
|:---|:---|:---|:---|
| `sf-tree-item-open` | нажата подпись или `Enter` на листе без ссылки | `id`, `value` | `sf-tree-item-click` с `{item, value, originalEvent}` |
| `sf-tree-item-toggle` | ветвь раскрыта или свёрнута | `id`, `open`, `value` | имя прежнее; элемента в `detail` больше нет — это `event.target` |

`onToggle(handler)` передаёт обработчику новое состояние первым аргументом.
Внутри `<sf-tree>` слушайте события дерева — `sf-tree-open` и
`sf-tree-toggle`, см. [Дерево](/ru/smart-components/navigation/tree/#события).

```js
const section = document.querySelector('sf-tree-item[value="reports"]');
section.onToggle((open) => {
  if (open) loadReports();
});
section.expand();
```

## Доступность

- Пункт — элемент дерева (`treeitem`), его доступное имя — подпись.
- Фокус между пунктами переводит дерево стрелками; на странице `Tab`
  останавливается на одном пункте дерева. Кнопка раскрытия и ссылка внутри
  пункта не получают отдельной остановки `Tab`.
- Кнопка раскрытия сообщает `aria-expanded`. Её подписи по умолчанию — из
  файлов слов на языке страницы («Развернуть» и «Свернуть»); другие задают
  `open-label` и `close-label`.
- Недоступный пункт сообщает `aria-disabled="true"`, пункт текущей страницы —
  `aria-current="page"`.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `label` — `string`, по умолчанию пусто. Имя узла; без него — собственный текст узла
- `href` — `string`, по умолчанию пусто.
- `target` — `string`, по умолчанию пусто.
- `rel` — `string`, по умолчанию пусто.
- `kind` — `string`, по умолчанию `folder`, значения: `folder`, `file`. Тип элемента дерева: папка или файл.
- `value` — `string`, по умолчанию пусто. id узла: `data-value` его строки, id, который несут его события
- `disabled` — `boolean`, по умолчанию `false`.
- `open-icon` — `string`, по умолчанию `folder_open`.
- `closed-icon` — `string`, по умолчанию `folder`.
- `icon` — `boolean`, по умолчанию `true`. false скрывает значок папки или файла
- `chevron-open-icon` — `string`, по умолчанию `keyboard_arrow_down`.
- `chevron-closed-icon` — `string`, по умолчанию `chevron_right`.
- `open-label` — `string`. Имя шеврона, пока ветка закрыта
- `close-label` — `string`. Имя шеврона, пока ветка открыта
- `item-class` — `string`, по умолчанию пусто. Классы рамки строки
- `container-class` — `string`, по умолчанию пусто. Классы линии строки
- `name-class` — `string`, по умолчанию пусто. Классы имени строки
- `open` — `boolean`, по умолчанию `false`. Ветка открыта
- `selected` — `boolean`, по умолчанию `false`.
- `active` — `boolean`, по умолчанию `false`. Узел — текущая страница: `aria-current`
- `text` — `string`, по умолчанию пусто. Псевдоним с датой для `label` до 2026-12-01.
- `items-data` — `array` из `object`, по умолчанию `[]`. Дети узла как данные (форма записи `sf-tree`); иначе один раз читаются дети, написанные внутри

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `kind` | `type` | работает, отмечается в `SF.deprecations` | 2026-12-01 |

### Методы

- `expand()` — возвращает `object`. Открывает ветку; отказ для файла, листа или выключенного узла
- `collapse()` — возвращает `object`. Закрывает ветку
- `toggleOpen()` — возвращает `object`. Открывает закрытую ветку, закрывает открытую
- `activate()` — возвращает `object`. Что делает Enter на листе: переходит по его ссылке или отправляет open
- `focusItem()` — возвращает `object`. Переводит фокус на строку узла
- `setOpen(open?: boolean)` — возвращает `object`. Открывает или закрывает ветку и отправляет sf-tree-item-toggle; ничего не делает для файла, листа, отключённого пункта или неизменного состояния.
- `open()` — возвращает `object`. То же, что setOpen(true).
- `close()` — возвращает `object`. То же, что setOpen(false).
- `toggle()` — возвращает `object`. Переключает состояние открытия через setOpen.
- `onToggle(handler: function, options?: object|boolean)` — возвращает `object`. Добавляет обработчик sf-tree-item-toggle; обработчик вызывается с (open, detail, event). Обработчик, не являющийся функцией, игнорируется.

### События

Все события приходят на сам элемент и всплывают. Общие события базового элемента перечислены в главе [Жизненный цикл → Этапы](/ru/guide/smart-components/lifecycle/#этапы).

- `sf-tree-item-open` — `detail`: `{ id: string, value: string }`. Нажатие на имя или Enter на листе без ссылки: open `{id}` словаря 1.1.5 §5
- `sf-tree-item-toggle` — `detail`: `{ id: string, open: boolean, value: string }`. Ветка открылась или закрылась (словарь §5 toggle); DOM-имя `sf-tree-item-toggle` не изменилось
- `sf-tree-item-click` — `detail`: `{ component: object, tagName: string, template: string, item: object, value: string, originalEvent: object|null }`.

### Доступность

- Роль: элемент дерева (`treeitem`).
- Доступное имя: обязательно.
- Клавиши: `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`, `Home`, `End`, `Enter`, `Space`.
- Фокус: Дерево управляет перемещаемым фокусом (roving focus); раскрытие, фокус и выбор независимы.
