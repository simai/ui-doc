# Dropdown

## Имя, подпись и пояснение

`name` — машинное имя отправляемого значения, а `label` — видимая подпись
поля. Они не дублируют друг друга. `placeholder` показывает приглашение к
выбору, но не заменяет подпись. `search-placeholder` относится только к поиску
внутри раскрытого списка.

Для обычной формы передавайте видимый `label`. В текущем контракте Dropdown
также принимает `aria-label`; задавайте ему тот же локализованный смысл, если
адаптеру требуется отдельное доступное имя корневого элемента.

```html
<sf-dropdown
  name="view"
  label="Представление"
  aria-label="Представление"
  placeholder="Выберите представление">
  <sf-list-item value="all" text="Все элементы"></sf-list-item>
  <sf-list-item value="active" text="Активные"></sf-list-item>
</sf-dropdown>
```

В компактной панели инструментов подпись можно скрыть только визуально,
сохранив её для вспомогательных технологий. Это решается композицией панели и
не вводит другой вариант вызова Dropdown.

## Группы в списке

Пункт может сказать, откуда он: `group` в данных или атрибут `group` у
`sf-list-item`. Пункты с одинаковым `group`, идущие подряд, рисуются под одним
заголовком. Так длинный список читается кусками, а не строками, и название
места не повторяется в каждой строке.

## Сетка пунктов

`layout="grid"` раскладывает пункты по нескольку в ряд, `columns` задаёт
сколько. Сетка высотой в несколько рядов и дальше прокручивается — сто двадцать
значков по шесть в ряд это двадцать рядов, а двадцать рядов — снова колонка;
высоту меняет токен `--sf-dropdown--grid-height`. В сетке пункт показывает свою картинку, а его подпись остаётся именем
для поиска и подсказкой при наведении. Это единственный способ смотреть сотню
значков: колонкой их никто не долистает.

## Свой триггер

Собственный триггер Dropdown — это поле: рамка, текст выбранного, шеврон. Там,
где список нужен за другим управляющим элементом — за «+» в шапке группы, за
кнопкой со значком, — передайте его в `slot="trigger"`. Компонент отдаёт такому
триггеру только нажатие, которое открывает список: как он выглядит, решает тот,
кто его передал. Список в этом случае берёт свою ширину, а не ширину кнопки.

## Доступность

Сохраняйте доступное имя, порядок фокуса, управление клавиатурой и объявление
состояний. Не используйте один `placeholder` вместо `label`. Сгенерированная
API-страница подтверждает source-контракт, но не заменяет сценарную проверку
доступности.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-ec56cef08625` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-dropdown>` |
| Назначение | Доступный элемент одиночного или множественного выбора с поиском по вариантам и необязательным выводом в портал. |
| Контракт | `smart.dropdown`, версия `1.2.0` |
| Поставка | выпуск Framework `ui-ec56cef08625` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |
| Готовность | описан: манифест и сценарий есть, продуктовой приёмки нет |

### Атрибуты

- `appearance` — `string`, по умолчанию `outlined`, значения: `filled`, `outlined`. Вид выпадающего списка: поле с заливкой или с контуром.
- `aria-label` — `string`, по умолчанию пусто.
- `columns` — `string`, по умолчанию `6`. Сколько вариантов помещается в строку в раскладке-сетке. В списке игнорируется.
- `disabled` — `boolean`, по умолчанию `false`.
- `label` — `string`, по умолчанию пусто.
- `layout` — `string`, по умолчанию `list`, значения: `list`, `grid`. Раскладка вариантов. В списке — один вариант в строке; в сетке — несколько в строке, и только так можно просмотреть сотню символов: их столбец никто не прокручивает до конца. В сетке вариант показывает изображение, а текст сохраняется как имя для поиска и подсказки при наведении.
- `mode` — `string`, по умолчанию `select`, значения: `tag`, `select`.
- `multiple` — `boolean`, по умолчанию `false`. Разрешает несколько значений с сохранением порядка выбора при сериализации. В режиме тегов множественный выбор включён по умолчанию.
- `name` — `string`, по умолчанию пусто. Имя нативного поля формы для выбранного машинного значения.
- `options` — `array`, по умолчанию `[]`. Варианты, переданные данными вместо дочерних `sf-list-item`: `[{text, value, type?, size?, icon?, selected?, disabled?, colorClass?, avatarImageUrl?, avatarTitle?, ariaLabel?, group?}]`. Строка или число используется и как подпись, и как значение. Родитель, отрисовывающий этот выпадающий список из шаблона, передаёт варианты так, потому что захват дочерних элементов означает их удаление, и родитель уже не сможет вернуть изменённый список. Идущие подряд варианты с одинаковым `group` выводятся под одним заголовком, чтобы длинный список показывал, откуда взят каждый его фрагмент, а не повторял это в каждой строке.
- `placeholder` — `string`, по умолчанию пусто.
- `portal` — `boolean`, по умолчанию `true`. Привязывает всплывающее окно с помощью общего позиционирования Framework (`SF.Position`): нативный верхний слой, переворот, сдвиг и высота, ограниченная окном просмотра. Включено по умолчанию; `portal="false"` оставляет список в потоке.
- `required` — `boolean`, по умолчанию `false`.
- `search` — `boolean`, по умолчанию `true`.
- `search-placeholder` — `string`, по умолчанию `Placeholder`.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`.
- `template` — `string`, по умолчанию `default`, значения: `default`.
- `value` — `string`, по умолчанию пусто. Выбранное машинное значение или список значений через запятую при множественном выборе.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `appearance` | `type` | работает и предупреждает | 2026-12-01 |
| `size="1/2"` | `size="1/3"` | работает и предупреждает | 2026-12-01 |
| `size="2"` | `size="3"` | работает и предупреждает | 2026-12-01 |

### Методы

- `openDropdown()`
- `closeDropdown()`
- `toggleDropdown()`

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `change` — `detail` не описан. Выбор изменился; событие отправляется на элементе. Имя для привязки.
- `sf-dropdown:change` — прежнее имя `change`, приходит с тем же `detail`; подписывайтесь на `change`.

### Доступность

- Роль: кнопка (`button`) со всплывающим списком (`listbox`).
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowDown`, `ArrowUp`, `Home`, `End`, `Enter`, `Space`, `Escape`.
- Фокус: Переключатель — основная остановка Tab. Клавиши со стрелками открывают список и перемещают по доступным вариантам; Home и End перемещают в пределах списка; Enter или Space выбирают; Escape закрывает список и возвращает фокус на переключатель; Tab закрывает список и продолжает нативный обход. Поле поиска сохраняет нативное поведение Home и End при редактировании текста.

### Минимальная разметка

```html
<sf-dropdown label="Статус" name="status" placeholder="Выберите статус"><sf-list-item value="open" text="Открыт"></sf-list-item><sf-list-item value="done" text="Готов"></sf-list-item></sf-dropdown>
```
