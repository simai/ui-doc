# Выпадающий список

`<sf-dropdown>` — поле выбора одного или нескольких значений из раскрывающегося
списка с поиском. Берите его, когда вариантов больше, чем удобно показать
[радиокнопками](/ru/components/forms/radio/) или
[флажками](/ru/components/forms/checkbox/), или когда значения нужно
показать тегами.

## Применение

### Имя, подпись и пояснение

`name` — машинное имя отправляемого значения, `label` — видимая подпись поля;
они не дублируют друг друга. `placeholder` приглашает к выбору, но не заменяет
подпись. `search-placeholder` относится только к полю поиска внутри раскрытого
списка; без атрибута в нём слово на языке страницы — «Поиск», по-английски
«Search».

`aria-label` на `<sf-dropdown>` заменяет видимую подпись в доступном имени.
Задавайте его, только если адаптеру нужно отдельное имя, и с тем же
локализованным смыслом, что у `label`. В компактной панели инструментов подпись
можно скрыть только визуально — это решается композицией панели, а не другим
вызовом Dropdown.

### Группы в списке

Пункт может сказать, откуда он: поле `group` в данных `options` или атрибут
`group` у `sf-list-item`. Идущие подряд пункты с одинаковым `group` рисуются
под одним заголовком, поэтому длинный список читается кусками, а название
места не повторяется в каждой строке.

:::

### Сетка пунктов

`layout="grid"` раскладывает пункты по нескольку в ряд, `columns` задаёт
сколько. Сетка выше нескольких рядов прокручивается; её высоту задаёт токен
`--sf-dropdown--grid-height`. Ячейка сетки высотой с поле того же размера,
что и список, а сетка за собственным триггером шириной ровно в свои колонки.
В сетке пункт показывает свою картинку, а
подпись остаётся именем для поиска и подсказкой при наведении. Так удобно
выбирать из сотни значков: колонкой их не долистать.

### Свой триггер

Собственный триггер Dropdown — поле: рамка, текст выбранного, шеврон. Там, где
список нужен за другим управляющим элементом — за «+» в шапке группы, за
кнопкой со значком, — передайте его в `slot="trigger"`. Компонент отдаёт такому
триггеру только нажатие, которое открывает список; как триггер выглядит, решает
тот, кто его передал. Список в этом случае берёт свою ширину, а не ширину
кнопки.

:::

### Несколько значений

При `multiple` у каждого пункта в списке есть чекбокс: по нему видно, что
выбрано, а не только по цвету строки. Пункт со своей картинкой — значком,
цветом или аватаром — показывает её на месте чекбокса.

### Список внутри панели или окна

Открытый список сам отвечает на `Escape`. Пока он открыт, на корне страницы
стоит общая отметка `data-sf-popover-open`, и боковая панель, модальное окно
или панель записи этот `Escape` пропускают. Первое нажатие закрывает только
список, второе — панель или окно за ним.

### Значение и событие `change`

Свойство `value` возвращает выбранное машинное значение строкой. При
`multiple` значения перечислены через запятую, без выбора это пустая строка.
Присваивание `value` принимает строку или массив строк и выбирает пункты с
этими значениями. Кнопки очистки нет: из кода присвойте `value = ''`;
событие `change` при этом не приходит. Присвоенный массив `options`
перерисовывает список и сохраняет выбранное значение, если такой вариант в
нём есть.

Выбор пункта и удаление тега отправляют всплывающее событие `change`. Его
`event.detail`:

| Поле | Содержимое |
|:---|:---|
| `value` | значение нажатого пункта; при удалении тега — пустая строка |
| `label` | подпись нажатого пункта; при удалении тега — пустая строка |
| `values` | массив всех выбранных значений после изменения |
| `item` | данные нажатого пункта; при удалении тега — `null` |
| `root` | элемент `<sf-dropdown>` |
| `multiple` | `true`, если разрешён выбор нескольких значений |

Устаревшее имя `sf-dropdown:change` приходит вместе с `change` и с тем же
`detail`; подписывайтесь на `change`.

`root` — живой элемент, а не данные, поэтому `detail` — не JSON:
`JSON.stringify(event.detail)` падает на циклической структуре. Берите нужные
поля — `value`, `label` и `values` — и записывайте или отправляйте их:

```js
field.addEventListener('change', (event) => {
  const {value, label, values, multiple} = event.detail;
  save(multiple ? values : value);
});
```

Полное значение после изменения дают `event.detail.values` и
`event.target.value`. Повторный выбор уже выбранного пункта `change` не
отправляет, а при `multiple` снимает выбор пункта и отправляет `change`.

Событие `change` на элементе отправляет только сам компонент: нативный
`change` своего поля поиска он останавливает. Слушатель на предке, например
на форме, слышит и `change` других полей, поэтому проверяет `event.target`.

Свойство `selectedOptions` возвращает данные выбранных пунктов — те же, что
приходят в `event.detail.item`. Свойство `triggerText` возвращает подписи
выбранных пунктов через запятую, как их показывает поле; при `mode="tag"`
оно пустое, потому что выбранное показывают теги.

```js
const view = document.querySelector('sf-dropdown[name="view"]');
view.addEventListener('change', (event) => {
  applyView(event.detail.values);
});
view.value = 'archived';
```

## Доступность

- Каждому Dropdown нужно доступное имя: видимый `label` или `aria-label`.
  Один `placeholder` имени не даёт.
- Триггер — одна остановка `Tab`. Стрелки открывают список и перемещают по
  пунктам, `Home` и `End` — к первому и последнему, `Enter` и `Space`
  выбирают, `Escape` закрывает список и возвращает фокус на триггер. Внутри
  боковой панели или модального окна это нажатие закрывает только список.
- Поле поиска в списке сохраняет обычное поведение `Home` и `End` при
  редактировании текста.
- Свой триггер в `slot="trigger"` должен быть кнопкой с доступным именем: у
  кнопки со значком — `aria-label`.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `appearance` — `string`, по умолчанию `outlined`, значения: `filled`, `outlined`. Вид выпадающего списка: поле с заливкой или с контуром.
- `columns` — `number`, по умолчанию `6`. Сколько вариантов помещается в строку в раскладке-сетке. В списке игнорируется.
- `disabled` — `boolean`, по умолчанию `false`.
- `label` — `string`, по умолчанию пусто.
- `layout` — `string`, по умолчанию `list`, значения: `list`, `grid`. Раскладка вариантов. В списке — один вариант в строке; в сетке — несколько в строке, и только так можно просмотреть сотню символов: их столбец никто не прокручивает до конца. В сетке вариант показывает изображение, а текст сохраняется как имя для поиска и подсказки при наведении.
- `mode` — `string`, по умолчанию `select`, значения: `tag`, `select`.
- `multiple` — `boolean`, по умолчанию `false`. Разрешает несколько значений с сохранением порядка выбора при сериализации. В режиме тегов множественный выбор включён по умолчанию.
- `name` — `string`, по умолчанию пусто. Имя нативного поля формы для выбранного машинного значения.
- `placeholder` — `string`, по умолчанию пусто.
- `portal` — `boolean`, по умолчанию `true`. Привязывает всплывающее окно с помощью общего позиционирования Framework (`SF.Position`): нативный верхний слой, переворот, сдвиг и высота, ограниченная окном просмотра. Включено по умолчанию; `portal="false"` оставляет список в потоке.
- `required` — `boolean`, по умолчанию `false`.
- `search` — `boolean`, по умолчанию `true`.
- `search-placeholder` — `string`. Пусто — текст на языке страницы (по-английски «Search»).
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`.
- `value` — `string`, по умолчанию пусто. Выбранное машинное значение или список значений через запятую при множественном выборе.
- `aria-label` — `string`, по умолчанию пусто.
- `options` — `array`, по умолчанию `[]`. Варианты, переданные данными вместо дочерних `sf-list-item`: `[{text, value, type?, size?, icon?, selected?, disabled?, colorClass?, avatarImageUrl?, avatarTitle?, ariaLabel?, group?}]`. Строка или число используется и как подпись, и как значение. Родитель, отрисовывающий этот выпадающий список из шаблона, передаёт варианты так, потому что захват дочерних элементов означает их удаление, и родитель уже не сможет вернуть изменённый список. Идущие подряд варианты с одинаковым `group` выводятся под одним заголовком, чтобы длинный список показывал, откуда взят каждый его фрагмент, а не повторял это в каждой строке.
- `inherited-value` — `string`, по умолчанию пусто. Значение варианта (при множественном выборе — значения через запятую), к которому поле возвращается, пока ничего не выбрано. Подписи этих вариантов показаны как наследуемые — цветом подсказки и с меткой «наследуется», никогда как выбор: значение формы остаётся пустым. Когда что-то выбрано, кнопка сброса возвращает сюда. Только в режиме выбора; в режиме тегов не рисуется.
- `inherited-text` — `string`, по умолчанию пусто. Слова метки, которая видна, пока действует наследуемое значение. Если не задано — на языке страницы («наследуется», «inherited»).
- `reset-label` — `string`, по умолчанию пусто. Доступное имя кнопки, которая возвращает поле к наследуемому значению. Если не задано — на языке страницы («Сбросить к наследуемому», «Reset to inherited»).

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `appearance` | `type` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `size="1/2"` | `size="1/3"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `size="2"` | `size="3"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |

### Методы

- `openDropdown()` — возвращает `object`. Открывает список вариантов, если элемент управления не отключён и ещё не открыт. Возвращает элемент.
- `closeDropdown()` — возвращает `object`. Закрывает список вариантов и очищает текст поиска. Возвращает элемент.
- `toggleDropdown()` — возвращает `object`. Закрывает список, если он открыт, иначе открывает. Возвращает элемент.
- `resetToInherited()` — возвращает `boolean`. Возвращает поле к наследуемому значению, как кнопка сброса: отправляет отменяемое sf-field-reset, затем очищает собственное значение и ставит фокус на элемент управления. Возвращает, был ли сброс (false — если нет наследуемого или собственного значения, если поле недоступно или только для чтения, или событие отменили).

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `change` — `detail`: `{ value: string, label: string, values: array, item: object, multiple: boolean }`. Выбор изменился; событие отправляется на элементе. Имя для привязки.
- `sf-field-reset` — `detail`: `{ tag: string, value: string, inheritedValue: string, name: string }`. Человек нажал сброс к наследуемому значению. Событие признака field-inherit@1: одно имя для всех полей семейства, поэтому форма слышит их все сразу и различает по detail.tag. Отправляется до очистки поля и отменяемо: preventDefault сохраняет значение. Если не отменено, поле очищается, сообщает об этом обычным change, снова показывает наследуемое значение и забирает фокус.
- `sf-dropdown:change` — устаревший псевдоним события `change`: приходит с тем же `detail`, подписывайтесь на `change`.
- `sf-field:reset` — устаревший псевдоним события `sf-field-reset`: приходит с тем же `detail`, подписывайтесь на `sf-field-reset`.

### Доступность

- Роль: поле со списком (`combobox`).
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowDown`, `ArrowUp`, `Home`, `End`, `Enter`, `Space`, `Escape`.
- Фокус: Кнопка раскрытия — основная остановка Tab. Стрелки открывают список и двигают по доступным вариантам; Home и End переходят по списку; Enter или Space выбирает; Escape закрывает и возвращает фокус на кнопку; Tab закрывает и продолжает обычный обход. В поле поиска Home и End работают как при обычной правке текста. После сброса к наследуемому значению фокус возвращается на элемент управления; пока значение наследуется, элемент несёт его в aria-description, а видимая метка скрыта через aria-hidden.

### Минимальная разметка

```html
<sf-dropdown label="Статус" name="status" placeholder="Выберите статус"><sf-list-item value="open" text="Открыт"></sf-list-item><sf-list-item value="done" text="Готов"></sf-list-item></sf-dropdown>
```
