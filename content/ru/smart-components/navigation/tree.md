# Дерево

`<sf-tree>` показывает вложенный список: папки и файлы, разделы сайта,
категории каталога. Ветви раскрываются и сворачиваются, пункты выбираются
мышью и клавиатурой. Каждый пункт — [Элемент дерева](/ru/smart-components/navigation/tree-item/);
оформление совпадает с обычным [деревом](/ru/components/navigation/tree/).
Для короткого плоского списка берите обычный список, для пути к текущей
странице — [Хлебные крошки](/ru/smart-components/navigation/breadcrumbs/).

## Применение

> **`sf-tree` 2.0.** С выпуска `ui-363de49bdfa8` дерево следует стандарту
> смарт-компонентов 2.0: события называются глаголами словаря, выбор —
> `one` и `many`, а записи рисуются строками на классах. Прежние имена
> событий и значений работают до 2026-12-01 — приходят следом за новыми и
> отмечаются в `SF.deprecations`. Примеры на этой странице пока написаны
> прежними именами. Справочник API ниже собран из выпуска, на котором
> построен сайт.

### Пункты из разметки

Пункты — дочерние `<sf-tree-item>`, вложенные друг в друга так же, как ветви
дерева. Дерево читает их один раз при подключении как данные и убирает;
дальше оно рисует записи само. Подпись, ссылку, тип и состояние пункта
задают его атрибуты — они описаны на странице
[Элемент дерева](/ru/smart-components/navigation/tree-item/).

### Пункты данными

Свойство `items` принимает массив записей. Поля записи: `id`, `label`,
`value`, `href`, `target`, `rel`, `kind` (`folder` или `file`), `open`,
`selected`, `active`, `disabled`, `icon`, `open-icon`, `closed-icon`,
`chevron-open-icon`, `chevron-closed-icon`, `open-label`, `close-label`,
`revision` и `children` — массив вложенных записей. Поля в camelCase
(`openIcon`) и прежнее `type` тоже читаются. Код записи — `id`, иначе
`value`, иначе её место в дереве. Задавайте `items` после регистрации тега.

### Строки на классах и длинные деревья

Дерево рисует записи плоско — строками той же классовой разметки, что у
[обычного дерева](/ru/components/navigation/tree/)
(`.sf-tree-item[role=treeitem][data-value]`, `.sf-tree-item-container`,
`.sf-tree-item-name`), с `aria-level`, `aria-setsize` и `aria-posinset`.
Внутри дерева нет элементов `<sf-tree-item>`, а значки — символы шрифта
значков, а не `<sf-icon>`.

- Строки связаны с записями по `id`. Новый `items`, в котором изменилась
  одна запись, переписывает только её строку, на месте; раскрытость ветвей
  переживает новый `items`.
- Если видимых записей больше 300, рисуются только строки в поле зрения
  ближайшей прокрутки с запасом, а событие `sf-tree-window {first, last}`
  говорит, какие нарисованы. Дерево из 2 000 узлов рисуется за один кадр.
- Код страницы, который искал внутри дерева элементы `sf-tree-item`, ищет
  строки `.sf-tree-item[data-value]`.

### Выбор

`selection` задаёт, что делает нажатие на пункт:

| Значение | Нажатие |
|:---|:---|
| `none` (по умолчанию) | открывает пункт: его ссылку или событие `sf-tree-open` |
| `one` | выбирает один пункт |
| `many` | переключает выбор каждого пункта отдельно |

Прежние `single` и `multiple` работают как `one` и `many` до 2026-12-01.
Значение `selected` — код текущего пункта, `selected-ids` — все выбранные
при `many`, по порядку записей. Изначальный выбор задают атрибутом
`selected` у пункта или полем `selected: true` у записи.

### События

| Событие | Когда | `event.detail` | Прежнее имя (до 2026-12-01) |
|:---|:---|:---|:---|
| `sf-tree-open` | нажата подпись пункта или `Enter` на листе без ссылки | `id`, `value` | `sf-tree-item-click` |
| `sf-tree-select` | выбор изменился | `ids` — весь выбор, `id` — нажатый пункт, `selected` | `sf-tree-selection-change` |
| `sf-tree-toggle` | ветвь раскрыта или свёрнута | `id`, `open`, `value` | `sf-tree-item-toggle` |
| `sf-tree-move` | на пункт отпустили записи из списка (`accept-records`) | `ids`, `parent`, `before`, `source` | `sf-tree-records-drop` |
| `sf-tree-attach` | на пункт отпустили файлы (`accept-files`) | `files`, `parent` | `sf-tree-files-drop` |
| `sf-tree-window` | изменилось окно длинного дерева | `first`, `last` | — |

События приходят на `<sf-tree>`. В `detail` — только данные: код записи, а
не элемент. Прежнее имя приходит следом за новым с прежним `detail`, где
`item` — элемент строки. `onToggle(handler)` слушает `sf-tree-toggle` и
передаёт обработчику элемент строки первым аргументом.

```js
const tree = document.querySelector('sf-tree[selection="one"]');

tree.addEventListener('sf-tree-select', (event) => {
  saveTarget(event.detail.id);
});

tree.addEventListener('sf-tree-toggle', (event) => {
  if (event.detail.open) loadChildren(event.detail.id);
});

await customElements.whenDefined('sf-tree');
tree.items = await fetchFolders();
```

### Действия

`expand({id})` и `collapse({id})` раскрывают и сворачивают ветвь,
`focusEntry({id})` переводит фокус на пункт и сначала рисует его, если окно
его не держит. Каждое действие отвечает исходом: `{outcome: "applied"}` или
`{outcome: "refused"}` — для неизвестного кода, листа или выключенного
пункта.

### Перетаскивание на узел

Дерево может принимать на узел то, что на него перетащили, — например, в
файловом менеджере. Само оно ничего не перемещает и не загружает: оно
сообщает, что и куда отпустили, а дальше действует приложение. Узел, над
которым сейчас перетаскивают, подсвечивается.

- `accept-records` — узел принимает записи, перетащенные из списка, например
  строки [таблицы](/ru/smart-components/content/table/) с `drag-rows`. После
  отпускания приходит `sf-tree-move` с `{ids, parent, before, source}`:
  `ids` — записи, `parent` — узел, `source` — откуда их взяли. Это просьба
  переместить; переносит записи хост.
- `accept-files` — узел принимает файлы с компьютера; приходит
  `sf-tree-attach` с `{files, parent}` — просьба приложить файлы к узлу.

### Начальный вид

Пока записи не пришли, дерево показывает скелетон, выведенный из снимка
примера: полоски на месте подписей, той же высоты, что готовые строки.
Записи, которые приходят позже, объявлены в манифесте
(`"presentation": {"skeleton": {"late": ["items"]}}`); см.
[Первый кадр и ленивая загрузка](/ru/guide/smart-components/first-paint/).

## Доступность

- Дереву нужно доступное имя: `aria-label` или `aria-labelledby` на
  `<sf-tree>`. Это атрибуты хоста, а не настройки; роль всегда `tree`.
- Дерево — одна остановка `Tab`. Стрелки вверх и вниз переходят по видимым
  пунктам, `Home` и `End` — к первому и последнему. Стрелка вправо раскрывает
  ветвь, а у раскрытой переходит к первому вложенному пункту; стрелка влево
  сворачивает ветвь или переходит к родителю. Набор букв переводит фокус к
  пункту, подпись которого с них начинается.
- `Enter` раскрывает ветвь, а на листе открывает его ссылку или отправляет
  `sf-tree-open`; `Space` выбирает пункт при `selection="one"` или `many`.
  Фокус и выбор независимы: стрелки двигают фокус, не меняя выбор.
- Кнопка раскрытия ветви подписана словами из файлов слов на языке
  страницы: «Развернуть» и «Свернуть». Другие подписи задают `open-label` и
  `close-label` у пункта или записи. До `sf-tree` 2.0 подпись по умолчанию
  была английской, поэтому примеры задают её явно.
- При выборе пункты сообщают `aria-selected`, а при `selection="many"`
  дерево сообщает и `aria-multiselectable`.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `selection` — `string`, по умолчанию `none`, значения: `none`, `one`, `many`. Что делает нажатие: none открывает запись (или переходит по её ссылке), one выбирает одну запись, many переключает каждую
- `accept-records` — `boolean`, по умолчанию `false`. Запись принимает записи, перетащенные из списка (application/x-sf-records+json)
- `accept-files` — `boolean`, по умолчанию `false`. Запись принимает файлы, перетащенные с компьютера
- `selected` — `string`, по умолчанию пусто. id текущей записи (§18.2); при `selection` many — последней нажатой
- `aria-label` — `string`, по умолчанию пусто.
- `items` — `array` из `object`, по умолчанию `[]`. Дерево как данные: записи с детьми; иначе один раз читаются дети `sf-tree-item`, написанные внутри. id записи — id, иначе value, иначе её место
- `selected-ids` — `array`, по умолчанию `[]`. Выбранные id в порядке записей, при `selection` many (§18.2)

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `selection="one"` | `selection="single"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `selection="many"` | `selection="multiple"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |

### Методы

- `expand(id: any)` — возвращает `object`. Открывает ветку; отказ для неизвестного id, листа или выключенной записи
- `collapse(id: any)` — возвращает `object`. Действие collapse.
- `focusEntry(id: any)` — возвращает `object`. Переводит фокус на запись, сначала нарисовав её, если окно её не показывает
- `onToggle(handler: function, options?: object|boolean)` — возвращает `object`. Добавляет обработчик sf-tree-toggle от любого пункта дерева; обработчик вызывается с (item, detail, event).

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `sf-tree-open` — `detail`: `{ id: any, value: string }`. Нажатие на имя записи или Enter на листе без ссылки (словарь 1.1.5 §5 open)
- `sf-tree-select` — `detail`: `{ ids: array, id: any, selected: boolean }`. Выбор изменился: ids — весь выбор, id — нажатая запись, selected — выбрана ли она теперь (словарь §5 select)
- `sf-tree-toggle` — `detail`: `{ id: any, open: boolean, value: string }`. Ветка открылась или закрылась (словарь §5 toggle)
- `sf-tree-move` — `detail`: `{ ids: array, parent: any, before: any, source: string }`. Записи, перетащенные из списка, сброшены на запись: просьба перенести их в неё (словарь §5 move); дерево само ничего не переносит
- `sf-tree-attach` — `detail`: `{ files: array, parent: any }`. На запись перетащили файлы: просьба прикрепить их туда (словарь §5 attach); дерево само ничего не загружает
- `sf-tree-window` — `detail`: `{ first: number, last: number }`. При более чем 300 видимых записях — какие из них нарисованы (§18.4)
- `sf-tree-selection-change` — устаревший псевдоним события `sf-tree-select`: приходит с тем же `detail`, подписывайтесь на `sf-tree-select`.
- `sf-tree-records-drop` — устаревший псевдоним события `sf-tree-move`: приходит с тем же `detail`, подписывайтесь на `sf-tree-move`.
- `sf-tree-files-drop` — устаревший псевдоним события `sf-tree-attach`: приходит с тем же `detail`, подписывайтесь на `sf-tree-attach`.
- `sf-tree-item-click` — устаревший псевдоним события `sf-tree-open`: приходит с тем же `detail`, подписывайтесь на `sf-tree-open`.
- `sf-tree-item-toggle` — устаревший псевдоним события `sf-tree-toggle`: приходит с тем же `detail`, подписывайтесь на `sf-tree-toggle`.

### Доступность

- Роль: дерево (`tree`).
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`, `Home`, `End`, `Enter`, `Space`, поиск по первым буквам.
- Фокус: В порядке табуляции страницы находится один видимый элемент дерева; стрелки перемещают перемещаемый фокус независимо от выделения.
