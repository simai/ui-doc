# Smart-вкладки

`<sf-tabs>` создаёт доступную группу вкладок из краткой строки, слотов или
структурированных данных и использует оформление обычного компонента «Вкладки».

## Особенности применения

У каждой группы должно быть доступное имя через `aria-label` или
`aria-labelledby`. Пункты задают строкой `items`, разделяя их символом `|`, либо
методом `setData()`. Содержимое связывают с пунктами слотами `panel-0`,
`panel-1` и далее. Компонент сам поддерживает `role`, `aria-selected`,
`aria-controls`, единственную позицию в Tab-порядке и переключение стрелками.

Иконки пункта задавайте логическими полями `icon-start` и `icon-end`. Например,
`Обзор::icon-start=home|Настройки::icon-start=settings`. Старые поля
`icon-left` и `icon-right` продолжают работать для ранее сохранённых данных.

## Недоступные, иконочные и вертикальные вкладки

Флаг `disabled` в строке пункта исключает его из навигации. `variant="icons"`
создаёт компактные пункты с доступными именами, а `type="vertical"` меняет
ориентацию вместе с направлением клавиатурного управления.

:::

## Оформление

`type="underline"`, `type="pills"` и `type="full"` выбирают ту же геометрию,
что соответствующие классы обычных вкладок. `scheme` меняет оформление кнопок;
доступны, в частности, `default`, `outline` и `link`.

:::example {id="components/tabs/smart-appearance" label="Результат"}
:::

## Вложенные вкладки

Каждый `<sf-tabs>` управляет только собственными непосредственными пунктами.
Поэтому вложенная группа сохраняет независимые выбор, фокус и панели.

:::

## Данные и пользовательское представление пункта

`setData()` принимает массивы `tabs` и `panels`. У пункта можно задать
дескриптор Smart-компонента; внешняя обёртка вкладки остаётся единственным
владельцем доступного имени и клавиатурного фокуса, а вложенное представление
работает как декоративное содержимое.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-d34117c9f3f0` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-tabs>` |
| Назначение | Smart-компонент Tabs из SIMAI Framework. |
| Контракт | `smart.tabs`, версия `1.0.0` |
| Поставка | выпуск Framework `ui-d34117c9f3f0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |
| Готовность | описан: манифест и сценарий есть, продуктовой приёмки нет |

### Атрибуты

- `template` — `string`, по умолчанию `default`, значения: `default`.
- `type` — `string`, по умолчанию `null`.
- `size` — `string`, по умолчанию `1`.
- `variant` — `string`, по умолчанию `buttons`.
- `scheme` — `string`, по умолчанию `default`. Встроенный вид кнопки: `default`, `outline` или `link`. Это не выбор семантического цвета. Пользовательские шаблоны могут трактовать его по-своему.
- `top-position` — `string`, по умолчанию `start`.
- `active-index` — `number`, по умолчанию `0`.
- `items` — `string`, по умолчанию `[]`.
- `root-class` — `string`, по умолчанию пусто.
- `top-class` — `string`, по умолчанию пусто.
- `panel-class` — `string`, по умолчанию пусто.

### Методы

- `getData()`
- `setData()`
- `setItems()`
- `setPanels()`
- `setState()`
- `goTo()`
- `onTabChange()`

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `sf-tab-change` — `detail` не описан.

### Доступность

- Роль: список вкладок (`tablist`).
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `Enter`, `Space`.
- Фокус: Встроенные текстовые вкладки и вкладки с иконкой используют одну доступную нативную точку табуляции и связанные панели. Стрелки навигации учитывают ориентацию и RTL, пропускают отключённые вкладки, переходят по кругу, переносят фокус и активируют вкладку. Перпендикулярные стрелки и клавиши вложенных виджетов обрабатываются локально. Дескриптор пользовательского компонента вкладки отвечает только за отображение: его именованная обёртка остаётся единственной точкой табуляции, а отрисованный Smart-компонент инертен.

### Минимальная разметка

```html
<sf-tabs></sf-tabs>
```
