# Toast

## Доступность

Перед использованием проверьте доступное имя, порядок фокуса, управление клавиатурой и объявление состояний. Сгенерированная API-страница подтверждает source-контракт, но не заменяет сценарный accessibility smoke.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-9fb0297bb5c2` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-toast>` |
| Назначение | Временное всплывающее уведомление с семантическими ролями, необязательным действием, безопасной паузой времени показа и закрытием. |
| Контракт | `smart.toast`, версия `1.0.0` |
| Поставка | выпуск Framework `ui-9fb0297bb5c2` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |
| Готовность | описан: манифест и сценарий есть, продуктовой приёмки нет |

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Назначение |
|:---|:---|:---|:---|:---|
| `status` | `string` | `neutral` | `neutral`, `info`, `success`, `warning`, `error` | О чём сообщает сообщение, в общем словаре статусов. Также принимаются значения default и primary; они означают neutral и info. |
| `icon` | `string` | пусто | — | Необязательное имя декоративной иконки. |
| `title` | `string` | пусто | — | Короткий заголовок результата. |
| `supporting-text` | `string` | пусто | — | Краткий вспомогательный текст обычного размера основного текста. |
| `action-text` | `string` | пусто | — | Видимая подпись единственного необязательного действия. |
| `action` | `string` | `action` | — | Стабильное значение действия, передаваемое в sf-toast-action. |
| `closable` | `boolean` | `true` | — | Отображает явно названное действие закрытия. |
| `close-label` | `string` | `Close message` | — | Локализованное доступное имя действия закрытия. |
| `duration` | `number` | `0` | от 0 | Явное время жизни в миллисекундах. Ноль оставляет сообщение до закрытия. |
| `role` | `string` | пусто | пусто, `status`, `alert` | Роль живой области только для динамически вставляемой обратной связи. |
| `root-class` | `string` | пусто | — | — |

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `status` | `type` | работает и предупреждает | 2026-12-01 |
| `status="error"` | `status="danger"` | работает и предупреждает | 2026-12-01 |
| `status="error"` | `status="critical"` | работает и предупреждает | 2026-12-01 |
| `status="neutral"` | `status="default"` | работает и предупреждает | 2026-12-01 |
| `status="info"` | `status="primary"` | работает и предупреждает | 2026-12-01 |

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

| Событие | `detail` | Когда |
|:---|:---|:---|
| `sf-toast-action` | не описан | Отправляется один раз при активации необязательного доступного действия. |
| `sf-toast-close` | не описан | Отправляется один раз, перед тем как закрытие по токену удалит владельца уведомления. |

### Доступность

- Доступное имя: внутренний.
- Клавиши: `Tab`.
- Фокус: Нативные действия используют `focus-visible`; уведомление с таймером приостанавливается, пока фокус внутри него.

### Минимальная разметка

```html
<sf-toast type="success" title="Saved" supporting-text="Your changes are available." role="status" close-label="Close message"></sf-toast>
```
