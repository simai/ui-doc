# Toast

`<sf-toast>` показывает одно короткое сообщение о результате действия:
статус, заголовок, пояснение, необязательное действие и кнопку закрытия. Для
постоянного текста внутри страницы берите
[уведомление](/ru/components/feedback/alerts/), для выбора, без которого
работу не продолжить, — модальное окно.

## Применение

### Статус

`status` принимает общий словарь статусов: `neutral`, `info`, `success`,
`warning`, `error`. Выбирайте его по смыслу сообщения, а не по желаемому цвету.
Иконку статус не добавляет: её задаёт атрибут `icon`.

### Время жизни

По умолчанию сообщение остаётся до закрытия. `duration` задаёт время жизни в
миллисекундах; отсчёт приостанавливается, пока указатель или фокус находится
внутри сообщения. Сообщение с действием оставляйте без `duration`: пользователь
должен успеть его выполнить.

```html
<sf-toast status="success" title="Ссылка скопирована" duration="5000" role="status" close-label="Закрыть сообщение"></sf-toast>
```

### Действие и закрытие

`action-text` показывает одну кнопку действия, `action` — машинное значение,
которое приходит в событии. Нажатие отправляет `sf-toast-action` с
`detail.action`; закрытие отправляет `sf-toast-close` и удаляет элемент.
Бизнес-действие выполняет приложение.

```js
const toast = document.querySelector('sf-toast');
toast.onAction((action) => {
  if (action === 'undo') restoreFile();
});
toast.onClose(() => console.log('Сообщение закрыто'));
```

`closable="false"` убирает кнопку закрытия; закрыть такое сообщение может
только таймер или метод `close()`.

### Размещение

Toast отвечает за одно сообщение. Позицию на экране, порядок и число
одновременно показанных сообщений задаёт контейнер приложения.

## Доступность

- Сообщению, которое вставляется динамически, задайте `role="status"` для
  обычного результата и `role="alert"` для срочной ошибки. Сообщению, которое
  есть на странице с первой загрузки, живая роль не нужна.
- `close-label` задаёт доступное имя кнопки закрытия; по умолчанию оно
  английское, поэтому на русской странице передавайте перевод.
- Не помещайте в исчезающее сообщение обязательный шаг или сведения, которые
  легко пропустить: таймер приостанавливается при фокусе и наведении, но не
  ждёт, пока пользователь доберётся до сообщения.
- Кнопки действия и закрытия — нативные кнопки в обычном порядке `Tab`.

### Атрибуты

- `status` — `string`, по умолчанию `neutral`, значения: `neutral`, `info`, `success`, `warning`, `error`. О чём сообщает сообщение, в общем словаре статусов. Также принимаются значения default и primary; они означают neutral и info.
- `icon` — `string`, по умолчанию пусто. Необязательное имя декоративной иконки.
- `title` — `string`, по умолчанию пусто. Короткий заголовок результата.
- `supporting-text` — `string`, по умолчанию пусто. Краткий вспомогательный текст обычного размера основного текста.
- `action-text` — `string`, по умолчанию пусто. Видимая подпись единственного необязательного действия.
- `action` — `string`, по умолчанию `action`. Стабильное значение действия, передаваемое в sf-toast-action.
- `closable` — `boolean`, по умолчанию `true`. Отображает явно названное действие закрытия.
- `close-label` — `string`, по умолчанию `Close message`. Локализованное доступное имя действия закрытия.
- `duration` — `number`, по умолчанию `0`, значения: от 0. Явное время жизни в миллисекундах. Ноль оставляет сообщение до закрытия.
- `role` — `string`, по умолчанию пусто, значения: пусто, `status`, `alert`. Роль живой области только для динамически вставляемой обратной связи.
- `root-class` — `string`, по умолчанию пусто.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `status` | `type` | работает и предупреждает | 2026-12-01 |
| `status="error"` | `status="danger"` | работает и предупреждает | 2026-12-01 |
| `status="error"` | `status="critical"` | работает и предупреждает | 2026-12-01 |
| `status="neutral"` | `status="default"` | работает и предупреждает | 2026-12-01 |
| `status="info"` | `status="primary"` | работает и предупреждает | 2026-12-01 |

### Методы

- `close()`
- `setState()`
- `onAction()`
- `onClose()`

### События

Все события приходят на сам элемент и всплывают. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `sf-toast-action` — `detail` не описан. Отправляется один раз при активации необязательного доступного действия.
- `sf-toast-close` — `detail` не описан. Отправляется один раз, перед тем как закрытие по токену удалит владельца уведомления.

### Доступность

- Доступное имя: внутренний.
- Клавиши: `Tab`.
- Фокус: Нативные действия используют `focus-visible`; уведомление с таймером приостанавливается, пока фокус внутри него.

### Минимальная разметка

```html
<sf-toast type="success" title="Saved" supporting-text="Your changes are available." role="status" close-label="Close message"></sf-toast>
```
