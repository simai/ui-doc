# Шкала прогресса

`<sf-progress-scale>` показывает известную долю выполненного шкалой из десяти
делений. Берите её, когда точность до процента не нужна и ход удобнее читать
крупными шагами: заполненность профиля, этапы подготовки, занятое место.
Элемент строится на классах компонента
[Шкала прогресса](/ru/components/feedback/progress-scale/); для плавного хода
загрузки подходит [Прогресс](/ru/smart-components/feedback/progress-bar/).

## Применение

### Значение и деления

`value` — доля выполненного в процентах, от `0` до `100`; значения вне
диапазона приводятся к границе. Шкала закрашивает деления с округлением
вверх до десятка: при `41` закрашено пять делений из десяти. Точное значение
остаётся в подписи и в `aria-valuenow`.

`show-text` (по умолчанию включён) показывает значение в процентах под
шкалой; `show-text="false"` оставляет одну шкалу.

### Статус и размер

`status` сообщает смысл из общего словаря: `neutral` (по умолчанию), `info`,
`success`, `warning`, `error`. Компонент не выводит статус из процента:
предупреждение о почти занятом диске задаёт приложение, как во втором
примере. `size` — ступень `1/3`, `1/2`, `1`, `2` или `3`. В ячейке таблицы
или в ряду полей задайте `line` (`1/2`, `1`, `2`): шкала и значение встанут в
одну строку текста этого размера формы.

### Обновление из скрипта

Меняйте `value` или вызывайте `setProgress(n)`: шкала обновляется без
перерисовки. `getProgress()` возвращает текущее значение числом.

```js
const scale = document.querySelector('sf-progress-scale');
scale.setProgress(completedSteps * 20);
```

## Доступность

- Шкала — `role="progressbar"` со значениями от `0` до `100`. Задайте
  `label` — доступное имя: что измеряет шкала.
- `value-text` заменяет число словами, если процент сам по себе ничего не
  сообщает: «Занято 90%, осталось 2 ГБ».
- Цвет статуса не должен быть единственным сигналом: предупреждение
  называйте в `value-text` или в тексте рядом.
- Шкала не получает фокус и не объявляет изменения сама. О важном переходе —
  например, о заполнении до конца — сообщите отдельным текстом с
  `role="status"`.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `size` — `string`, по умолчанию `1`, значения: `1/3`, `1/2`, `1`, `2`, `3`.
- `line` — `string`, по умолчанию пусто, значения: пусто, `1/2`, `1`, `2`. Занимает строку текста этого размера формы — для ячейки таблицы или ряда полей, чтобы строка сохраняла высоту элемента управления.
- `value` — `number`, по умолчанию `0`, значения: от 0; до 100; шаблон `^(?:100|[1-9]?[0-9])(?:\.[0-9]+)?$`.
- `show-text` — `boolean`, по умолчанию `true`.
- `status` — `string`, по умолчанию `neutral`, значения: `neutral`, `info`, `success`, `warning`, `error`. О чём сообщает индикатор прогресса, в общем словаре статусов. Также принимается значение primary; оно означает neutral.
- `label` — `string`, по умолчанию пусто.
- `value-text` — `string`, по умолчанию пусто.
- `aria-label` — `string`, по умолчанию пусто.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `status` | `tone` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `status="error"` | `status="danger"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `status="error"` | `status="critical"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `status="neutral"` | `status="primary"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |

### Методы

- `chunk(done: number, total: number)` — возвращает `object`. Действие chunk.
- `getProgress()` — возвращает `number`. Возвращает значение как число, ограниченное диапазоном 0..100; нечисловое значение читается как 0.
- `setProgress(nextValue: number|string)` — возвращает `object`. Устанавливает атрибут value; null или undefined удаляет его.

### События

Своих событий нет; общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

### Доступность

- Роль: индикатор прогресса (`progressbar`).
- Доступное имя: обязательно.
- Фокус: Progress Scale не интерактивен и не входит в порядок фокуса.

### Минимальная разметка

```html
<sf-progress-scale label="Подготовка проекта" value="40"></sf-progress-scale>
```
