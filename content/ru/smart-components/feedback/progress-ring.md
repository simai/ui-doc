# Кольцо прогресса

`<sf-progress-ring>` показывает значение от 0 до 100 кольцом размером с
элемент управления: в панели инструментов, в боковой полосе, вокруг аватара.
Для длинной задачи в теле страницы берите
[Прогресс](/ru/smart-components/feedback/progress-bar/), а там, где сказать
можно только «идёт работа», — [Спиннер](/ru/smart-components/feedback/spinner/).

## Разметка

В разметке — один тег: `<sf-progress-ring>` с `label` и `value`. Значение и
доступное имя задаёт страница.

- `value` — проценты, число от 0 до 100; значения вне диапазона приводятся к
  границе.
- `label` — доступное имя: что именно выполняется. Без него кольцо называет
  `aria-label` на самом теге.
- `value-text` — значение словами («3 из 5 файлов»); экранный диктор читает
  его вместо процента.
- `show-text` показывает процент в середине кольца.
- Слот `content` занимает середину вместо процента. Его место — кольцо без
  линии и зазора, по 2 px с каждой стороны, поэтому картинка не касается
  линии: аватар на ступень меньше кольца (`size="1/2"` в кольце `1`,
  `size="1"` в кольце `2`) заполняет середину точно.

## Варианты

### Размер

`size` — ступень общей лестницы: `1/2`, `1` (по умолчанию) и `2`. На каждой
ступени кольцо занимает габарит кнопки со значком или аватара того же
размера, поэтому стоит в одной строке с ними.

:::example {id="smart-components/progress-ring/sizes" label="Три ступени размера"}
:::

### Статус

`status` сообщает смысл из общего словаря: `neutral` (по умолчанию), `info`,
`success`, `warning`, `error`. Кольцо не выводит статус из значения: порог
«с 80 % — предупреждение» — дело страницы, она и задаёт `status`.

:::example {id="smart-components/progress-ring/statuses" label="Пять статусов"}
:::

### Счётчик и мера

`meter` говорит, что кольцо показывает величину в известных границах —
занятую долю квоты, а не ход задачи: роль становится `meter` вместо
`progressbar`.

:::example {id="smart-components/progress-ring/meter" label="Квота и аватар в середине"}
:::

## Состояния

### Значение неизвестно

`indeterminate` показывает, что работа идёт, а доля неизвестна: по кольцу
бежит дуга спиннера, и значение не называется.

:::example {id="smart-components/progress-ring/indeterminate" label="Подготовка без известной доли"}
:::

## Применение

### Значение из скрипта

Меняйте `value` по ходу работы — кольцо перерисовывает заливку и обновляет
`aria-valuenow`. Действие `chunk({done, total})` показывает часть работы:
`value` становится долей `done` от `total` в процентах (`total` по умолчанию
100) и отвечает `applied` или `refused`.

```js
const ring = document.querySelector('sf-progress-ring');
for (const [index, file] of files.entries()) {
  await upload(file);
  ring.chunk({done: index + 1, total: files.length});
}
ring.setAttribute('status', 'success');
ring.setAttribute('value-text', 'Файлы загружены');
```

### Кольцо вокруг картинки

Кольцо вокруг аватара показывает долю и оставляет картинку на месте: кольцо
несёт роль и значение, а содержимое слота стоит рядом с ним, поэтому у
картинки остаётся своё имя. Кольцо внутри кнопки называет кнопка — дайте ей
имя, в котором есть и значение.

```html
<button type="button" class="account" aria-label="Анна Ким, использовано 62 % лимита">
  <sf-progress-ring value="62" meter label="Использовано">
    <sf-avatar slot="content" size="1/2" text="АК"></sf-avatar>
  </sf-progress-ring>
</button>
```

### Внешний вид

Открытые переменные: `--sf-progress-ring-size`,
`--sf-progress-ring-line-width` (2 px), `--sf-progress-ring-gap` (2 px),
`--sf-progress-ring-fill-color`, `--sf-progress-ring-track-color` и
`--sf-progress-ring-color` — цвет процента. Ноль — допустимое значение линии
и зазора. Заливка переходит между значениями плавно и стоит неподвижно при
системной настройке уменьшения движения, как и дуга неопределённого
ожидания.

## Доступность

- Кольцо несёт роль `progressbar`, а с `meter` — `meter`, вместе с
  `aria-valuemin="0"`, `aria-valuemax="100"` и текущим `aria-valuenow`. При
  `indeterminate` значения нет.
- `label` — доступное имя: что выполняется. `value-text` читается вместо
  процента.
- Кольцо не получает фокус и не слушает клавиши. Если кольцо стоит в кнопке,
  имя даёт кнопка.
- О завершении или ошибке сообщите отдельно — текстом с `role="status"` или
  [Уведомлением](/ru/smart-components/feedback/alert/): экранный диктор не
  объявляет каждое изменение значения.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Лестница элементов управления: на каждой ступени кольцо занимает габарит `sf-icon-button` или `sf-avatar` того же размера.
- `value` — `number`, по умолчанию `0`, значения: от 0; до 100; шаблон `^(?:100|[1-9]?[0-9])(?:\.[0-9]+)?$`. Проценты, от 0 до 100; значения вне диапазона приводятся к границе.
- `status` — `string`, по умолчанию `neutral`, значения: `neutral`, `info`, `success`, `warning`, `error`. О чём говорит значение, словами общего словаря статусов; решает страница (порог — её дело), кольцо само статус из значения не выводит.
- `indeterminate` — `boolean`, по умолчанию `false`. Значение неизвестно: по кольцу бежит дуга спиннера, и значение не называется.
- `meter` — `boolean`, по умолчанию `false`. Кольцо показывает величину в известных границах (занятую квоту), а не ход задачи: роль `meter` вместо `progressbar`.
- `show-text` — `boolean`, по умолчанию `false`. Показывает процент в середине; содержимое слота занимает его место, если задано.
- `label` — `string`, по умолчанию пусто. Доступное имя; без него кольцо называет `aria-label` на самом теге.
- `value-text` — `string`, по умолчанию пусто. Значение словами («3 из 5 файлов»); читается вместо процента.
- `aria-label` — `string`, по умолчанию пусто.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `status="error"` | `status="danger"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `status="error"` | `status="critical"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |

### Методы

- `chunk(done: number, total: number)` — возвращает `object`. Действие chunk.

### События

Своих событий нет; общие события базового элемента перечислены в главе [Жизненный цикл → Этапы](/ru/guide/smart-components/lifecycle/#этапы).

### Доступность

- Роль: мера (`meter`).
- Доступное имя: обязательно.
- Фокус: Кольцо прогресса не интерактивно и никогда не входит в порядок обхода фокусом.

### Минимальная разметка

```html
<sf-progress-ring label="Использовано" value="62" meter></sf-progress-ring>
```
