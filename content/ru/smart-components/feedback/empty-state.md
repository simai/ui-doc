# Пустое состояние

`<sf-empty-state>` — то, что список, панель или страница показывает, когда
показать нечего. Одна причина — один вид: значок, заголовок, пояснение и, если
нужно, действие.

## Применение

### Причина

| `kind` | Значок | Заголовок и текст по умолчанию |
|:---|:---|:---|
| `no-data` (по умолчанию) | `inbox` | «Пока ничего нет» / «Здесь появятся записи, когда они будут» |
| `nothing-found` | `search_off` | «Ничего не найдено» / «Попробуйте изменить запрос или фильтры» |
| `no-access` | `lock` | «Нет доступа» / «Обратитесь к администратору» |
| `error` | `error` | «Не удалось загрузить» / «Попробуйте ещё раз» и кнопка «Повторить» |

Тексты по умолчанию следуют языку страницы. `icon`, `title` и `text`
заменяют их, когда причина конкретнее: «Машин пока нет», «Создайте первую».

### Размер и место

- `size="1/2"` — внутри таблицы или панели;
- `size="1"` — по умолчанию;
- `size="2"` — целая страница.

От размера зависят значок, роль заголовка, текст и промежутки. Ширина — не
больше 28rem, её меняет переменная `--sf-empty-state-max-inline-size`.

`heading-level` (от 2 до 6, по умолчанию 3) ставит заголовок на нужный
уровень структуры страницы: на целой странице это обычно 2, в панели — 3
или 4. Вид заголовка от уровня не зависит.

### Действия

Действия передают в слот `actions` — любые `sf-button` — или свойством
`actions` со списком `[{id, text, appearance}]`. Кнопки из свойства рисуются в
размере компонента и сообщают `sf-empty-state-action` с `{id}`. У
`kind="error"` без своих действий есть «Повторить» (`id: retry`).

```html
<sf-empty-state kind="nothing-found" size="1/2" heading-level="4"></sf-empty-state>
<sf-empty-state kind="error" id="failed"></sf-empty-state>
<script>
  failed.addEventListener('sf-empty-state-action', (event) => {
    if (event.detail.id === 'retry') reload();
  });
</script>
```

## Доступность

- «Ничего не найдено» и ошибка объявляются вежливо (`role="status"`): человек
  с экранным диктором узнаёт, что поиск ничего не дал или загрузка не удалась.
  Остальные причины не объявляются.
- Заголовок — настоящий заголовок уровня `heading-level`, поэтому состояние
  видно в оглавлении страницы.
- Значок декоративный.

Раздел собран из манифеста компонента выпуска `ui-7606ca8693c1` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

### Атрибуты

- `kind` — `string`, по умолчанию `no-data`, значения: `no-data`, `nothing-found`, `no-access`, `error`. Причина: от неё зависят значок, заголовок и текст по умолчанию, а у error — действие «Повторить».
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. 1/2 — внутри таблицы или панели, 2 — для целой страницы; от размера зависят значок, роль заголовка, текст и промежутки.
- `icon` — `string`, по умолчанию пусто.
- `title` — `string`, по умолчанию пусто.
- `text` — `string`, по умолчанию пусто.
- `heading-level` — `string`, по умолчанию `3`, значения: `2`, `3`, `4`, `5`, `6`. Уровень заголовка в структуре страницы; его вид зависит от размера.
- `root-class` — `string`, по умолчанию пусто.
- `template` — `string`, по умолчанию `default`.

### Методы

Публичных методов нет.

### События

Все события приходят на сам элемент и всплывают. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `sf-empty-state-action` — `detail`: `{ id: string }`. Человек нажал одно из действий (retry — у ошибки без собственных действий).

### Доступность

- Роль: status.
- Доступное имя: внутренний.
- Клавиши: `Tab`, `Enter`, `Space`.
- Фокус: Заголовок — настоящий заголовок уровня heading-level; nothing-found и error объявляются вежливо (role=status), остальные — нет; значок декоративный; действия — обычные кнопки в порядке Tab.

### Минимальная разметка

```html
<sf-empty-state kind="nothing-found" size="1/2" heading-level="4"></sf-empty-state>
```
