# Подсказка «?»

`<sf-help-mark>` — знак «?» рядом с подписью, который открывает короткое
пояснение. Открывается только нажатием — мышью, пальцем, `Enter` или пробелом;
наведение его не открывает. Второе нажатие, `Escape` или щелчок мимо
закрывают пояснение.

## Применение

### Когда подсказка «?», а когда всплывающая подсказка

| | [Всплывающая подсказка](/ru/smart-components/feedback/tooltip/) | Подсказка «?» |
|:---|:---|:---|
| Для чего | короткое имя кнопки-иконки: «Удалить», «Копировать» | пояснение: что значит поле или настройка |
| Как открывается | наведением или фокусом, исчезает сама | нажатием, остаётся, пока её не закроют |
| На сенсорном экране | не работает | работает |
| Ссылки внутри | нельзя | можно |

### Содержание

- `text` — пояснение; вместо него можно передать слот `content` со ссылками или
  списком.
- `title` — короткая строка заголовка над пояснением.
- `size` — `1/3`, `1/2` (по умолчанию) или `1`. У подписи поля берите
  `1/3`: это самый низкий знак, но и он выше строки подписи, поэтому строка
  с подписью становится чуть выше.
- `placement` — `auto` (по умолчанию: снизу, с переворотом, если места нет),
  `top`, `bottom`, `start`, `end`.

Ширина пояснения — не больше 20rem. При открытии и закрытии приходят события
`sf-help-mark-open` и `sf-help-mark-close`.

```html
<label for="solution-code">Код решения</label>
<sf-help-mark label="Подробнее: код решения" title="Код решения" size="1/3"
              text="Уникальное имя модуля латиницей, например simai.billing."></sf-help-mark>
<input id="solution-code" name="code">
```

Знак стоит рядом с подписью, а не внутри `<label>`: внутри подписи он стал бы
её элементом управления, и нажатие на текст подписи открывало бы пояснение
вместо перехода в поле.

## Доступность

- `label` — доступное имя кнопки, по умолчанию «Подробнее». Называйте, о чём
  пояснение: «Подробнее: код решения».
- Кнопка сообщает `aria-expanded`; при открытии текст пояснения вежливо
  объявляется для чтения с экрана, фокус остаётся на кнопке.
- Если в пояснении есть ссылка или другой элемент управления, `Tab` с кнопки
  переходит в пояснение, а пояснение закрывается, когда фокус уходит и с
  кнопки, и из него. Без таких элементов `Tab` идёт дальше, а пояснение
  остаётся открытым до `Escape`, повторного нажатия или щелчка мимо.

### Атрибуты

- `text` — `string`, по умолчанию пусто. Пояснение; вместо него слот `content` принимает ссылки или списки.
- `title` — `string`, по умолчанию пусто.
- `label` — `string`, по умолчанию пусто. Доступное имя кнопки; по умолчанию «Подробнее». Лучше назвать, о чём пояснение («Подробнее: код решения»).
- `size` — `string`, по умолчанию `1/2`, значения: `1/3`, `1/2`, `1`.
- `placement` — `string`, по умолчанию `auto`, значения: `auto`, `top`, `bottom`, `start`, `end`.
- `root-class` — `string`, по умолчанию пусто.
- `template` — `string`, по умолчанию `default`.

### Методы

- `open()` — возвращает `object`. Открывает пояснение.
- `close()` — возвращает `object`. Закрывает пояснение.

### События

Все события приходят на сам элемент и всплывают. Общие события базового элемента перечислены в главе [Жизненный цикл → Этапы](/ru/guide/smart-components/lifecycle/#этапы).

- `sf-help-mark-open` — `detail`: `{  }`. Пояснение открыто.
- `sf-help-mark-close` — `detail`: `{  }`. Пояснение закрыто.

### Доступность

- Роль: кнопка (`button`).
- Доступное имя: рекомендуется.
- Клавиши: `Enter`, `Space`, `Escape`, `Tab`.
- Фокус: Кнопка с aria-expanded и aria-controls; нажатие открывает пояснение, и оно вежливо объявляется. Escape, повторное нажатие или щелчок мимо закрывают его, фокус остаётся на кнопке. Пояснение со ссылкой или элементом управления идёт в порядке фокуса сразу за кнопкой и закрывается, когда фокус уходит с обоих.

### Минимальная разметка

```html
<sf-help-mark label="Подробнее: код решения" text="Уникальное имя модуля латиницей."></sf-help-mark>
```
