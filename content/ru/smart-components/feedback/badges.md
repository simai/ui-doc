# Бейджи

`<sf-badge>` показывает короткую пометку рядом с объектом: статус записи,
категорию, версию, число новых событий. Пометку не нажимают. Элемент
строится на классах компонента [Бейджи](/ru/components/feedback/badges/);
для метки, которую выбирают или удаляют, берите
[Теги](/ru/smart-components/content/tags/).

## Применение

### Вид, цвет и статус

У пометки три отдельные оси:

| Ось | Атрибут | Значения |
|:---|:---|:---|
| Насколько заметна | `appearance` | `main` — плотная заливка, `tonal` — спокойная, `outline` — контур |
| Какой цветовой роли | `scheme` | `neutral`, `primary`, `secondary`, `tertiary`, `on-surface` |
| О чём сообщает | `status` | `info`, `success`, `warning`, `error` |

`status` сильнее `scheme`: пометка со статусом окрашивается по статусу.
Цветовую роль берите для категорий, статус — для состояния объекта, и не
передавайте состояние одним цветом — текст пометки называет его словами.

### Размер

`size` — ступень `1/3` (по умолчанию), `1/2` или `1`. В строке таблицы или
в ряду полей задайте `line` (`1/2`, `1`, `2`): пометка займёт строку текста
этого размера формы, и строка не станет выше.

### Иконки

`icon` ставит иконку перед текстом; `icon-position="end"` переносит её за
текст. Для двух иконок сразу есть `icon-start` и `icon-end`. Слоты `text`,
`icon-start` и `icon-end` заменяют части своей разметкой.

```html
<sf-badge appearance="tonal" scheme="primary" icon="schedule" text="2 дня"></sf-badge>
```

## Доступность

- Пометка — текст, она не получает фокус и не реагирует на клавиатуру.
- Видимый текст читается как есть. Если он понятен только из контекста —
  число «3», сокращение «β», — задайте `aria-label` с полным смыслом: «3
  ошибки». Тогда экранный диктор читает `aria-label` вместо видимого текста.
- Пометка без текста и без `aria-label` скрыта от экранного диктора: так
  ведёт себя точка или одна иконка. Сообщите то же самое текстом рядом.
- Иконки декоративны.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-466d8f260e58` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-badge>` |
| Назначение | Короткая неинтерактивная метка статуса, категории, версии или количества рядом с объектом, отрисованная в заданном размере, виде и цветовой роли или статусе. Не добавляет поведения клавиатуры или указателя. |
| Контракт | `smart.badge`, версия `1.1.3` |
| Поставка | выпуск Framework `ui-466d8f260e58` |
| [Жизненный цикл](/ru/guide/smart-components/quality/#готовность-компонента-к-использованию) | экспериментальный: API может меняться между выпусками |
| [Готовность](/ru/guide/smart-components/quality/#готовность-компонента-к-использованию) | описан: манифест и сценарий есть, продуктовой приёмки нет |
| Заготовка до прихода кода | нет: атрибут `data-sf-skeleton` не пишется; своего скелетона при загрузке данных нет ([Коробка до кода](/ru/guide/smart-components/first-paint/#коробка-до-кода)) |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `size` — `string`, по умолчанию `1/3`, значения: `1/3`, `1/2`, `1`.
- `line` — `string`, по умолчанию пусто, значения: пусто, `1/2`, `1`, `2`. Занимает строку текста этого размера формы — для ячейки таблицы или ряда полей, чтобы строка сохраняла высоту элемента управления.
- `appearance` — `string`, по умолчанию `main`, значения: `main`, `tonal`, `outline`. Вид значка: наиболее заметная заливка, более спокойная тональная или контур.
- `scheme` — `string`, по умолчанию `neutral`, значения: `neutral`, `primary`, `secondary`, `tertiary`, `on-surface`. Какой смысловой цвет берёт бейдж. Слово статуса здесь тоже работает и попадает на ось status.
- `status` — `string`, по умолчанию пусто, значения: пусто, `info`, `success`, `warning`, `error`. О чём сообщает бейдж, в общем словаре статусов. Также принимается значение danger; оно означает error.
- `text` — `string`, по умолчанию пусто.
- `icon` — `string`, по умолчанию пусто.
- `icon-start` — `string`, по умолчанию пусто.
- `icon-end` — `string`, по умолчанию пусто.
- `icon-position` — `string`, по умолчанию `start`, значения: `start`, `end`.
- `aria-label` — `string`, по умолчанию пусто.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `appearance` | `type` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `status` | `scheme` — только значения `info`, `success`, `warning`, `error` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `icon-start` | `icon-left` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `icon-end` | `icon-right` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `status="error"` | `status="danger"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |
| `status="error"` | `status="critical"` | работает, отмечается в `SF.deprecations` | 2026-12-01 |

### Методы

Публичных методов нет.

### События

Своих событий нет; общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

### Доступность

- Роль: нет (`none`).
- Доступное имя: рекомендуется.
- Фокус: Значок — статические метаданные, в порядок табуляции не входит.

### Минимальная разметка

```html
<sf-badge></sf-badge>
```
