# Badges

## Доступность

Перед использованием проверьте доступное имя, порядок фокуса, управление клавиатурой и объявление состояний. Сгенерированная API-страница подтверждает source-контракт, но не заменяет сценарный accessibility smoke.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-257f66def2b8` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-badge>` |
| Назначение | Smart-компонент Badges из SIMAI Framework. |
| Контракт | `smart.badges`, версия `1.0.0` |
| Поставка | выпуск Framework `ui-257f66def2b8` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |
| Готовность | описан: манифест и сценарий есть, продуктовой приёмки нет |

### Атрибуты

- `template` — `string`, по умолчанию `default`, значения: `default`.
- `size` — `string`, по умолчанию `1/3`, значения: `1/3`, `1/2`, `1`.
- `line` — `string`, по умолчанию пусто, значения: пусто, `1/2`, `1`, `2`. Занимает строку текста этого размера формы — для ячейки таблицы или ряда полей, чтобы строка сохраняла высоту элемента управления.
- `appearance` — `string`, по умолчанию `main`, значения: `main`, `tonal`, `outline`. Вид значка: наиболее заметная заливка, более спокойная тональная или контур.
- `status` — `string`, по умолчанию пусто, значения: пусто, `info`, `success`, `warning`, `error`. О чём сообщает бейдж, в общем словаре статусов. Также принимается значение danger; оно означает error.
- `text` — `string`, по умолчанию пусто.
- `icon` — `string`, по умолчанию пусто.
- `icon-start` — `string`, по умолчанию `null`.
- `icon-end` — `string`, по умолчанию `null`.
- `icon-position` — `string`, по умолчанию `start`, значения: `start`, `end`.
- `aria-label` — `string`, по умолчанию пусто.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `appearance` | `type` | работает и предупреждает | 2026-12-01 |
| `status` | `scheme` | работает и предупреждает | 2026-12-01 |
| `icon-start` | `icon-left` | работает и предупреждает | 2026-12-01 |
| `icon-end` | `icon-right` | работает и предупреждает | 2026-12-01 |
| `status="error"` | `status="danger"` | работает и предупреждает | 2026-12-01 |
| `status="error"` | `status="critical"` | работает и предупреждает | 2026-12-01 |
| `status="error"` | `status="danger"` | работает и предупреждает | 2026-12-01 |
