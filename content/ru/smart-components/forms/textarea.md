# Многострочное поле

`<sf-textarea>` — многострочное поле для комментариев, описаний и другого
свободного текста. Оно собирает разметку
[многострочного поля](/ru/components/forms/textarea/) из атрибутов. Для
короткого значения в одну строку берите
[Input](/ru/smart-components/forms/inputs/).

## Применение

### Подпись, подсказка и пример ввода

`label` — видимая подпись поля, `hint` — постоянное пояснение под ним,
`placeholder` — пример ожидаемого текста. Placeholder исчезает, как только
пользователь начинает печатать, поэтому подпись и подсказку он не заменяет.
`required` ставит звёздочку у подписи и делает обязательным нативное поле.

### Высота и длина текста

`rows` задаёт начальную высоту в строках, по умолчанию три. Пользователь
может растянуть поле по вертикали. `maxlength` и `minlength` ограничивают
длину текста средствами браузера; сообщите ограничение в `hint`, как в примере.

### Высота по тексту

`auto-grow` делает высоту поля равной его тексту: поле начинается с
`min-rows` строк (по умолчанию одна), растёт по строке и после `max-rows`
остаётся этой высоты и прокручивается внутри. Без `max-rows` предела нет;
`max-rows` меньше `min-rows` считается равным `min-rows`. При удалении текста
поле уменьшается. `rows` с `auto-grow` не действует, и поле не растягивают
вручную. Одна строка равна высоте `sf-input` или `sf-button` того же размера.
`Enter` переносит строку: отправка по `Enter` — поведение окна чата, а не поля.

:::example {id="smart-components/textarea/auto-grow" label="Поле по высоте текста"}
:::

### Вид и размер

`appearance` выбирает вид поля: `bordered` — с рамкой, `filled` — с заливкой,
`flush` — без своего блока, внутри составного элемента. `size` выбирает
ступень размерной шкалы: `1/2`, `1` или `2`; берите ступень остальных полей
формы.

### Без рамки

`appearance="flush"` — поле внутри составного элемента, например строки ввода
сообщения, где рамку, фон, тень и фокус рисует общий блок. У поля нет своей
границы, фона, тени, скругления, боковых отступов, ручки изменения размера и
своего кольца фокуса — ни при наведении, ни при нажатии, ни при фокусе с
клавиатуры. Текст остаётся на размерной шкале: отступ сверху и снизу равен
отступу поля с рамкой вместе с её линией, поэтому одна строка равна высоте
`sf-input` или `sf-button` того же размера, а каждая следующая добавляет
высоту строки этого размера. `auto-grow`, `min-rows` и `max-rows` работают как
у других видов.

Фокус показывает составной блок через `:has(:focus-visible)` — поле само его
не рисует, как в примере. Назовите поле: `label` или `aria-label`. В режиме
высокой контрастности поле сохраняет системный контур фокуса.

:::example {id="smart-components/textarea/flush" label="Поле без рамки в строке ввода сообщения"}
:::

### Ошибка и только чтение

`invalid` вместе с `error-message` показывает ошибку: сообщение встаёт на
место подсказки и связывается с полем. `readonly` оставляет текст доступным
для чтения и копирования, `disabled` выключает поле и исключает его из
отправки формы. Вместо строк подсказки и ошибки можно передать разметку в
слоты `hint` и `error`.

### Значение в форме и события

Внутри `<sf-textarea>` лежит обычный `<textarea>` с переданным `name`, поэтому
текст попадает в `FormData` и отправку формы, а браузер проверяет `required`
и длину перед отправкой. Свойство `value` элемента читает и задаёт текущий
текст.

`input` приходит при каждом изменении текста, `change` — когда пользователь
покинул изменённое поле. Оба — нативные события внутреннего `<textarea>`,
всплывают через `<sf-textarea>`, `detail` у них нет; текст читайте из
`event.target.value`.

```js
const comment = document.querySelector('sf-textarea[name="comment"]');
comment.addEventListener('input', (event) => {
  counter.textContent = `${event.target.value.length} из 500`;
});
comment.value = 'Черновик ответа';
```

## Доступность

- Задайте видимую подпись в `label`: она связана с полем и даёт ему доступное
  имя. Один `placeholder` имени не даёт.
- Подсказка и сообщение об ошибке связаны с полем через `aria-describedby`;
  при `invalid` поле получает `aria-invalid` и `aria-errormessage`.
- Поле — обычная остановка `Tab`; `Enter` переносит строку, а не отправляет
  форму.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`.
- `appearance` — `string`, по умолчанию `bordered`, значения: `bordered`, `filled`, `flush`. Вид поля: блок с рамкой, с заливкой или `flush` — без своего блока, внутри составного элемента, который сам рисует блок и фокус.
- `label` — `string`, по умолчанию пусто.
- `required` — `boolean`, по умолчанию `false`.
- `placeholder` — `string`, по умолчанию пусто.
- `autocomplete` — `string`, по умолчанию пусто.
- `inputmode` — `string`, по умолчанию пусто, значения: пусто, `none`, `text`, `tel`, `url`, `email`, `numeric`, `decimal`, `search`.
- `minlength` — `number`.
- `maxlength` — `number`.
- `spell-check` — `boolean`, по умолчанию `true`.
- `wrap` — `string`, по умолчанию `soft`, значения: `soft`, `hard`.
- `hint` — `string`, по умолчанию пусто.
- `name` — `string`, по умолчанию пусто.
- `rows` — `number`, по умолчанию `3`.
- `auto-grow` — `boolean`, по умолчанию `false`. Поле растёт по тексту между min-rows и max-rows, а после max-rows прокручивается внутри. Где поддерживается, работает CSS field-sizing, в остальных браузерах — запасной скрипт; rows при этом не учитывается.
- `min-rows` — `number`, по умолчанию `1`. С auto-grow: наименьшее число строк в поле. Одна строка — высота поля ввода того же размера.
- `max-rows` — `number`. С auto-grow: наибольшее число строк, после которого поле прокручивается внутри. Не задано — без предела; значение меньше min-rows считается равным min-rows.
- `disabled` — `boolean`, по умолчанию `false`.
- `readonly` — `boolean`, по умолчанию `false`.
- `invalid` — `boolean`, по умолчанию `false`.
- `error-message` — `string`, по умолчанию пусто.
- `mask` — `boolean`, по умолчанию `false`.
- `mask-pattern` — `string`, по умолчанию пусто.
- `mask-options` — `string`, по умолчанию пусто.
- `value` — `string`, по умолчанию пусто.
- `spellcheck` — `boolean`, по умолчанию `true`. Псевдоним с датой для `spell-check` до 2026-12-01.
- `error` — `boolean`, по умолчанию `false`. Псевдоним с датой для `invalid` до 2026-12-01.
- `inherited-value` — `string`, по умолчанию пусто. Значение, к которому поле возвращается, пока у него нет своего. Показано как наследуемое — цветом подсказки и с меткой «наследуется» под полем, никогда как значение: значение формы остаётся пустым. Когда у поля появилось своё значение, кнопка сброса возвращает сюда.
- `inherited-text` — `string`, по умолчанию пусто. Слова метки, которая видна, пока действует наследуемое значение. Если не задано — на языке страницы («наследуется», «inherited»).
- `reset-label` — `string`, по умолчанию пусто. Доступное имя кнопки, которая возвращает поле к наследуемому значению. Если не задано — на языке страницы («Сбросить к наследуемому», «Reset to inherited»).

### Методы

- `setState(nextState: object)` — возвращает `boolean`. Применяет disabled, error или invalid, errorMessage и value к внутреннему textarea и заново синхронизирует семантику поля; установка value отправляет input. Возвращает false, если textarea не отрисован.
- `resetToInherited()` — возвращает `boolean`. Возвращает поле к наследуемому значению, как кнопка сброса: отправляет отменяемое sf-field:reset, затем очищает собственное значение и ставит фокус на элемент управления. Возвращает, был ли сброс (false — если нет наследуемого или собственного значения, если поле недоступно или только для чтения, или событие отменили).

### События

Все события приходят на сам элемент и всплывают. Общие события базового элемента перечислены в главе [Жизненный цикл → Этапы](/ru/guide/smart-components/lifecycle/#этапы).

- `change` — `detail`: `null`. Значение зафиксировано; нативное событие всплывает от внутреннего textarea, который является его целью.
- `input` — `detail`: `null`. Значение изменилось при вводе; нативное событие всплывает от внутреннего textarea, который является его целью.
- `sf-field:reset` — `detail`: `{ value?: string, inheritedValue?: string, name?: string }`. Человек нажал сброс к наследуемому значению. Отправляется до очистки поля и отменяемо: preventDefault сохраняет значение. Если не отменено, поле очищается, сообщает об этом обычным change, снова показывает наследуемое значение и забирает фокус.

### Доступность

- Роль: текстовое поле (`textbox`).
- Доступное имя: обязательно.
- Клавиши: `Tab`, обычная правка многострочного текста.
- Фокус: Фокус на активном элементе управления остаётся видимым. После сброса к наследуемому значению фокус возвращается на элемент управления; пока значение наследуется, элемент несёт его в aria-description, а видимая метка скрыта через aria-hidden.

### Минимальная разметка

```html
<sf-textarea label="Comment" name="comment" rows="4" maxlength="500"></sf-textarea>
```
