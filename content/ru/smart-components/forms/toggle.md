# Toggle

**Заменён переключателем.** Карта переноса — на странице
[Toggle](/ru/components/forms/toggle/). Компонент остаётся рабочим
для уже написанной разметки и уедет в следующей мажорной версии.

## Доступность

Перед использованием проверьте доступное имя, порядок фокуса, управление клавиатурой и объявление состояний. Сгенерированная API-страница подтверждает source-контракт, но не заменяет сценарный accessibility smoke.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-d34117c9f3f0` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-toggle>` |
| Назначение | Smart-компонент Toggle из SIMAI Framework. |
| Контракт | `smart.toggle`, версия `1.0.0` |
| Поставка | выпуск Framework `ui-d34117c9f3f0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |
| Готовность | описан: манифест и сценарий есть, продуктовой приёмки нет |

### Атрибуты

- `size` — `string`, по умолчанию `1`, значения: `1`, `2`. Токен размера кнопки-переключателя.
- `kind` — `string`, по умолчанию `simple`, значения: `simple`, `icon`, `short`. Содержимое переключателя: ничего, иконка или короткая подпись.
- `label` — `string`, по умолчанию пусто.
- `icon` — `string`, по умолчанию пусто.
- `checked` — `boolean`, по умолчанию `false`.
- `disabled` — `boolean`, по умолчанию `false`.
- `name` — `string`, по умолчанию пусто.
- `value` — `string`, по умолчанию пусто.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `kind` | `type` | работает и предупреждает | 2026-12-01 |

### Методы

- `getInputElement()`
- `setChecked()`
- `setDisabled()`
- `setState()`
- `onChange()`
- `onFocus()`
- `onBlur()`

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `change` — `detail` не описан. Изменилось нажатое состояние; нативное событие всплывает от внутреннего флажка, который является его целью. Имя для привязки.

### Доступность

- Роль: переключатель (`switch`).
- Доступное имя: обязательно.
- Клавиши: `Tab`, `Space`.
- Фокус: Сохраняет видимый фокус на активном элементе управления.

### Минимальная разметка

```html
<sf-toggle></sf-toggle>
```
