# Переключатель

`<sf-switch>` — переключатель настройки, которая начинает действовать сразу
после нажатия. Он собирает разметку
[переключателя](/ru/components/forms/switch/) из атрибутов.

:::

## Разметка

Минимальную разметку показывает пример выше: один тег `<sf-switch>` с
атрибутами.

- Название обязательно: видимое в `label` или, если подпись выводит страница,
  в `aria-label`. Пояснение задаёт `description`; вместо строк можно передать
  разметку в слоты `label` и `description`.
- Чтобы значение уходило с формой, задайте `name` и `value`.
- Внутри компонент рисует обычный `<input type="checkbox" role="switch">` с
  этими `name` и `value`; дорожка и бегунок — его оформление.

## Варианты

### Подпись и пояснение

`label` называет настройку, `description` поясняет, что она меняет, `help`
выводит рядом с подписью значок с указанным именем; экранный диктор значок не
читает. Если подпись выводит сама страница — например, панель записи
печатает её рядом с переключателем, — не задавайте `label`, а передайте
`aria-label`: имя попадёт на нативный input, и подпись не напечатается
дважды. При видимой подписи `aria-label` не действует.

:::example {id="smart-components/switch/labels" label="Подпись, пояснение, значок и подпись страницы"}
:::

### Размер

`size` выбирает ступень размерной шкалы: `1/2`, `1` или `2`. Берите ступень
полей и кнопок той же формы.

:::example {id="smart-components/switch/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Длина дорожки

Для плотного списка настроек дорожку укорачивает класс `sf-switch--short`,
переданный в `root-class`.

:::example {id="smart-components/switch/track" label="Обычная и короткая дорожка"}
:::

## Состояния

### Включён

`checked` включает переключатель. Атрибут следует за положением: после
нажатия он появляется или снимается.

:::example {id="smart-components/switch/state-checked" label="Выключен и включён"}
:::

### Недоступен

`disabled` запрещает менять положение; недоступный переключатель не попадает
в отправку формы.

:::example {id="smart-components/switch/state-disabled" label="Недоступный выключенный и включённый"}
:::

## Применение

### Когда брать переключатель

Переключатель — для настройки, которая начинает действовать сразу. Подпись
называет состояние или возможность — «Уведомления», «Компактный режим», — а
не команду «Включить» или «Выключить»: положение переключателя уже говорит,
включена ли настройка. Если значение уходит с формой только после
подтверждения, берите [Флажок](/ru/smart-components/forms/checkbox/).

### Значение в форме

Включённый переключатель попадает в `FormData` и отправку формы,
выключенный — нет. Сброс формы возвращает положение, заданное атрибутом
`checked` в разметке.

### Применение настройки и событие `change`

Нажатие отправляет нативное событие `change` внутреннего input; оно
всплывает через `<sf-switch>`, `detail` у него нет. Новое положение читайте из
`event.target.checked` и применяйте настройку сразу.

`setChecked()` и `setDisabled()` меняют положение и доступность из кода,
события `change` при этом нет. Если сохранить настройку не удалось, верните
переключатель в прежнее положение.

```js
const compact = document.querySelector('sf-switch[name="compact"]');
compact.addEventListener('change', async (event) => {
  const enabled = event.target.checked;
  try {
    await saveSetting('compact', enabled);
  } catch {
    compact.setChecked(!enabled);
  }
});
```

## Доступность

- Переключателю нужно название: видимое в `label` или, если подпись выводит
  страница, `aria-label`, который попадает на внутренний input.
- Внутренний input с `role="switch"` сообщает экранному диктору, что это
  переключатель, и его положение — «вкл.» или «выкл.».
- Каждый переключатель — отдельная остановка `Tab`; `Space` меняет положение.
- Бегунок скрыт от вспомогательных технологий: положение передаёт input.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Токен размера переключателя.
- `label` — `string`, по умолчанию пусто.
- `description` — `string`, по умолчанию пусто.
- `help` — `string`, по умолчанию пусто.
- `disabled` — `boolean`, по умолчанию `false`.
- `name` — `string`, по умолчанию пусто.
- `value` — `string`, по умолчанию `on`. Что отправляет включённый переключатель; без значения — "on", как у родного флажка (simai/ui-source#38).
- `checked` — `boolean`, по умолчанию `false`.
- `aria-label` — `string`, по умолчанию пусто. Доступное имя переключателя без видимой подписи — например, в панели записи, которая сама выводит подпись.
- `inherited-value` — `string`, по умолчанию пусто. Включён ли переключатель, пока у него нет своего значения: true/on или false/off. Бегунок стоит в указанном положении, приглушённо, с меткой «наследуется», а флажок ничего не отправляет. Когда атрибут задан, выбранное человеком «выкл.» хранится как checked="false" — собственное значение, — а отсутствие `checked` означает наследуемое состояние; кнопка сброса возвращает к нему.
- `inherited-text` — `string`, по умолчанию пусто. Слова метки, которая видна, пока действует наследуемое значение. Если не задано — на языке страницы («наследуется», «inherited»).
- `reset-label` — `string`, по умолчанию пусто. Доступное имя кнопки, которая возвращает поле к наследуемому значению. Если не задано — на языке страницы («Сбросить к наследуемому», «Reset to inherited»).

### Методы

- `getInputElement()` — возвращает `object` | `null`. Возвращает внутренний нативный input (.sf-switch input[type="checkbox"]) или null до отрисовки.
- `setChecked(nextValue?: boolean)` — возвращает `object`. Устанавливает свойство и состояние checked внутреннего input; не отправляет change.
- `setDisabled(nextValue?: boolean)` — возвращает `object`. Устанавливает или снимает disabled на хост-элементе и внутреннем input.
- `setState(nextState: object)` — возвращает `object`. Применяет checked и disabled к внутреннему input и отражает их в атрибутах хост-элемента; до отрисовки использует базовый setState.
- `onChange(handler: function, options?: object|boolean)` — возвращает `object`. Добавляет обработчик нативного события change, которое всплывает от внутреннего input.
- `onFocus(handler: function, options?: object|boolean)` — возвращает `object`. Добавляет обработчик focusin на хост-элементе.
- `onBlur(handler: function, options?: object|boolean)` — возвращает `object`. Добавляет обработчик focusout на хост-элементе.
- `resetToInherited()` — возвращает `boolean`. Возвращает поле к наследуемому значению, как кнопка сброса: отправляет отменяемое sf-field-reset, затем очищает собственное значение и ставит фокус на элемент управления. Возвращает, был ли сброс (false — если нет наследуемого или собственного значения, если поле недоступно или только для чтения, или событие отменили).

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components-2/names/). Общие события базового элемента перечислены в главе [Жизненный цикл → Этапы](/ru/guide/smart-components/lifecycle/#этапы).

- `change` — `detail`: `null`. Изменилось состояние «включено»; нативное событие всплывает от внутреннего флажка, который является его целью.
- `sf-field:reset` — `detail`: `{ value?: string, inheritedValue?: string, name?: string }`. Человек нажал сброс к наследуемому значению. Отправляется до очистки поля и отменяемо: preventDefault сохраняет значение. Если не отменено, поле очищается, сообщает об этом обычным change, снова показывает наследуемое значение и забирает фокус.

### Доступность

- Роль: переключатель (`switch`).
- Доступное имя: обязательно.
- Клавиши: `Tab`, `Space`.
- Фокус: Фокус на активном элементе управления остаётся видимым. После сброса к наследуемому значению фокус возвращается на элемент управления; пока значение наследуется, элемент несёт его в aria-description, а видимая метка скрыта через aria-hidden.
