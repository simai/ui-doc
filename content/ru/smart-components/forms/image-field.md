# Поле изображения

`<sf-image-field>` — поле формы для одного изображения: логотипа, обложки,
картинки в блоке. Оно показывает миниатюру с именем и размером файла, кнопки
«Заменить…» и «Убрать» и принимает файл, перетащенный на поле. Загружает
файл приложение: компонент только передаёт выбранный `File`.

## Разметка

Минимальная разметка — тег с `label`, `name` и, если изображение уже есть,
`value`.

- `value` — изображение в форме файла `{value, label, mime, size, href}`:
  `value` — код у приложения, `label` — имя файла (оно же `alt` миниатюры),
  `mime` — тип, `size` — байты или готовый текст, `href` — адрес картинки. В
  атрибуте — тот же объект в JSON или просто адрес.
- Выбранный файл уходит с формой под именем `name` через встроенный файловый
  input.
- `accept` ограничивает, что предлагает окно выбора и что принимается
  перетаскиванием; по умолчанию `image/*`.

## Варианты

### Пустое поле

Пока изображения нет, поле показывает `empty-text` («Изображение не выбрано»
по умолчанию) и кнопку «Выбрать…».

:::example {id="smart-components/image-field/empty" label="Пустое поле обложки"}
:::

### Размер

`size` выбирает ступень полей формы: `1/2`, `1` или `2`.

:::example {id="smart-components/image-field/sizes" label="Размеры 1/2, 1 и 2"}

## Состояния

### Ошибка

`invalid` (или `error`) и `error-message` показывают ошибку вместо пояснения.
`required` не даёт отправить форму без изображения.

:::example {id="smart-components/image-field/state-error" label="Обязательное поле с ошибкой"}
:::

### Недоступно и только для чтения

`disabled` показывает изображение с недоступными кнопками, `readonly` — без
кнопок; перетаскивание в обоих случаях не принимается.

:::example {id="smart-components/image-field/state-disabled" label="Недоступное поле и поле только для чтения"}
:::

## Применение

### Когда брать поле изображения

Поле изображения — для значения, которое является одной картинкой. Для
нескольких файлов, списка передачи и прогресса берите
[Загрузку файлов](/ru/smart-components/forms/file-upload/).

### Загрузка и события

Когда человек выбрал или перетащил файл, приходит `sf-image-field:select` с
`file`: приложение загружает его и затем задаёт сохранённое значение через
`setValue()`. «Убрать» отправляет `sf-image-field:remove` с прежним
значением; файлы, которых нет в `accept`, отбрасываются с событием
`sf-image-field:reject`. Каждое изменение сопровождают `input` и `change` с
`value`, `file`, `source` и `name`.

```js
const logo = document.querySelector('sf-image-field[name="logo"]');
logo.addEventListener('sf-image-field:select', async (event) => {
  try {
    const stored = await upload(event.detail.file);
    logo.setValue(stored);
  } catch {
    logo.setError('Не удалось загрузить файл');
  }
});
```

## Доступность

- Поле — группа, названная `label` (без него — «Изображение»), с пояснением
  или ошибкой в описании.
- «Заменить…», «Убрать» и «Выбрать…» — настоящие кнопки с именами,
  называющими файл: «Заменить изображение «logo.png»».
- Область перетаскивания не получает фокус. После удаления фокус переходит
  на «Выбрать…»; выбор, удаление и отклонённый файл объявляются вежливо.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `name` — `string`, по умолчанию пусто. Имя, под которым выбранный файл уходит с формой через встроенный файловый input.
- `label` — `string`, по умолчанию пусто. Подпись над изображением; называет группу. Без неё группа называется «Изображение» / Image.
- `hint` — `string`, по умолчанию пусто. Пояснение под полем; слот `hint` принимает разметку вместо строки.
- `accept` — `string`, по умолчанию `image/*`. Что предлагает окно выбора файла и что принимается перетаскиванием: `.ext`, `type/*` или `type/sub` через запятую.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Размер поля: 1/2, 1 или 2, как у любого поля формы.
- `meta` — `string`, по умолчанию пусто. Строка под именем; по умолчанию — размеры изображения после загрузки и его размер («450×300 · 2 КБ»).
- `empty-text` — `string`, по умолчанию пусто. Слова пустого поля; по умолчанию «Изображение не выбрано» / No image chosen.
- `required` — `boolean`, по умолчанию `false`. В поле должно быть изображение: встроенный input обязателен, пока поле пустое, поэтому форма без изображения не отправится.
- `disabled` — `boolean`, по умолчанию `false`. Видно, но не меняется: кнопки недоступны, перетаскивание не принимается.
- `readonly` — `boolean`, по умолчанию `false`. Видно без кнопок; перетаскивание не принимается.
- `invalid` — `boolean`, по умолчанию `false`. Состояние ошибки: край и сообщение окрашены цветом ошибки, у группы aria-invalid.
- `error-message` — `string`, по умолчанию пусто. Ошибка, которая видна вместо пояснения, пока поле с ошибкой; слот `error` принимает разметку вместо строки.
- `aria-label` — `string`, по умолчанию пусто. Доступное имя группы, когда подпись внутри поля не выводится: форма, которая печатает подпись рядом (рендереры полей Framework), называет поле без второй видимой подписи.
- `error` — `boolean`, по умолчанию `false`. Состояние ошибки; то же, что invalid.
- `value` — `object`, по умолчанию `null`. Изображение в форме файла `{value, label, mime, size, href, file?}` или null; атрибут принимает адрес или эту форму в JSON

### Методы

- `clear()` — возвращает `object`. Очищает поле из кода; то же, что setValue(null). Возвращает элемент.
- `choose()` — возвращает `boolean`. Открывает окно выбора файла, как «Заменить…» и «Выбрать…». Возвращает false, если поле недоступно или только для чтения.
- `removeImage()` — возвращает `boolean`. Убирает изображение, как человек кнопкой «Убрать»: приходят input, change и sf-image-field-detach, фокус переходит на «Выбрать…». Возвращает, было ли что убирать.
- `takeFile(file: object, source: string)` — возвращает `boolean`. Принимает File, как если бы его выбрал человек (source input, drop или другой, названный хостом): миниатюра показывает его по object URL, приходят input, change и sf-image-field-attach. Файл, которого нет в accept, вместо этого отклоняется. Возвращает, принят ли файл.
- `setError(message: string)` — возвращает `object`. Показывает сообщение об ошибке и состояние ошибки или убирает оба пустым сообщением. Записывает error-message и invalid. Возвращает элемент.
- `setValue(value: object|string|null)` — возвращает `object`. Задаёт изображение из кода — в форме файла или адресом; null очищает поле. Событий не отправляет: значение из кода — не изменение. Возвращает элемент.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components-2/names/). Общие события базового элемента перечислены в главе [Жизненный цикл → Этапы](/ru/guide/smart-components/lifecycle/#этапы).

- `change` — `detail`: `{ value: object|null, file: object|null, source: any, name: string }`. Изображение выбрали, перетащили или убрали: один раз на каждое изменение, сделанное человеком, CustomEvent на элементе со значением, File и именем в форме. Собственное change встроенного input наружу не выходит.
- `input` — `detail`: `{ value: object|null, file: object|null, source: any, name: string }`. Отправляется при каждом изменении, перед ним, с тем же detail — как нативный файловый input отправляет input и change вместе.
- `sf-image-field-attach` — `detail`: `{ files: array, file: object, source: any, value: object, name: string }`. Файл выбран или перетащен: File для загрузки. Хост загружает его и задаёт сохранённое значение. Имя по стандарту simai.smart-component 1.3.8 (словарь 1.1.5 §9.1); `sf-image-field:select` отправляется после него с тем же detail до 2026-12-01 (aliases.json).
- `sf-image-field-detach` — `detail`: `{ value: object, name: string }`. Человек убрал изображение; detail несёт значение, которое было. Имя по стандарту simai.smart-component 1.3.8 (словарь 1.1.5 §9.1); `sf-image-field:remove` отправляется после него с тем же detail до 2026-12-01 (aliases.json).
- `sf-image-field-rejected` — `detail`: `{ files: array, accept: string, source: string }`. Файлы, которых нет в списке accept, пропущены — системный диалог их бы и не предложил; об этом вежливо сообщается. Имя по стандарту simai.smart-component 1.3.8 (словарь 1.1.5 §9.1); `sf-image-field:reject` отправляется после него с тем же detail до 2026-12-01 (aliases.json).
- `sf-image-field:select` — устаревший псевдоним события `sf-image-field-attach`: приходит с тем же `detail`, подписывайтесь на `sf-image-field-attach`.
- `sf-image-field:remove` — устаревший псевдоним события `sf-image-field-detach`: приходит с тем же `detail`, подписывайтесь на `sf-image-field-detach`.
- `sf-image-field:reject` — устаревший псевдоним события `sf-image-field-rejected`: приходит с тем же `detail`, подписывайтесь на `sf-image-field-rejected`.

### Доступность

- Роль: группа (`group`).
- Доступное имя: рекомендуется.
- Клавиши: `Tab`, `Enter`, `Space`.
- Фокус: Группа, названная подписью поля и описанная пояснением или ошибкой. «Заменить…», «Убрать» и «Выбрать…» — настоящие кнопки с именами того, на что они действуют («Заменить изображение «logo.png»»); alt миниатюры — имя файла. Область перетаскивания не получает фокус, поэтому не становится ни остановкой, ни ловушкой. После удаления фокус переходит на «Выбрать…». Выбор, удаление и отклонённый файл объявляются вежливым статусом.

### Минимальная разметка

```html
<sf-image-field label="Логотип" name="logo" value='{"value":"42","label":"logo.png","mime":"image/png","size":2048,"href":"/upload/logo.png"}'></sf-image-field>
```
