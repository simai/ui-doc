# Код страны

`<sf-country-code>` — телефонное поле с кнопкой выбора страны: флаг и код
страны стоят перед номером, а маска подстраивается под выбранную страну. Оно
собирает разметку [кода страны](/ru/components/forms/country-code/) из
атрибутов. Для телефона без выбора страны хватит
[поля ввода](/ru/smart-components/forms/inputs/) с маской.

## Применение

### Подпись и подсказка

`label` — видимая подпись поля. Без `label` строки подписи нет вовсе, и
пустая строка над полем не остаётся. Если подпись выводит сама страница —
например, панель записи печатает её рядом с полем, — передайте `aria-label`:
имя попадёт на нативное поле номера, и подпись не напечатается дважды. При
видимой подписи `aria-label` не действует. `hint` — пояснение под полем,
`placeholder` — пример номера в пустом поле. `required` делает номер
обязательным.

### Выбор страны и фиксированный код

`iso2` задаёт начальную страну двухбуквенным кодом, `dial-code` — телефонным
кодом. По умолчанию пользователь может сменить страну кнопкой с флагом.
`multi-country="false"` оставляет страну фиксированной: список не создаётся,
код остаётся перед номером.

:::example {id="components/country-code/smart-modes" label="Результат"}
:::

### Маска номера

`use-mask="true"` включает маску номера. Маска берётся из данных выбранной
страны и меняется вместе с ней; `use-country-masks="false"` отключает маски
стран, и тогда действует общий шаблон из `mask-pattern`. Маска помогает
вводить номер, но существование номера не проверяет: это задача приложения и
сервера.

### Размер

`size` выбирает ступень размерной шкалы: `1/2`, `1` или `2`. Подпись, поле и
подсказка сохраняют одну структуру на всех ступенях.

:::example {id="components/country-code/smart-sizes" label="Результат"}
:::

### Значение в форме

Номер хранит обычный `<input type="tel">` с переданными `name`, `form` и
`required`, поэтому он попадает в `FormData`, проходит нативную проверку
обязательности, а сброс формы возвращает исходные номер и страну.

:::example {id="components/country-code/smart-form" label="Результат"}
:::

### Свой набор стран

Свойство `countries` принимает массив объектов с полями `iso2`, `code` или
`dialCode`, `label` и необязательным `maskPattern`. Для известных кодов ISO
пропущенные поля дополняются встроенным справочником. `max-items` ограничивает
число стран в списке. Присваивайте свойство после регистрации элемента —
`await customElements.whenDefined('sf-country-code')`.

:::example {id="components/country-code/smart-countries" label="Результат"}
:::

### Флаги и язык

Флаг по умолчанию — символ эмодзи страны. `flag-base` задаёт папку с
изображениями флагов: компонент берёт из неё файл `<iso2>.svg`.

Названия стран и собственные подписи поля следуют языку страницы: на
странице с `lang="ru"` — русские, на любой другой — английские. `locale="ru"`
или `locale="en"` задаёт язык явно.

### Оформление

`root-class` добавляет корню утилиты Framework: поверхность, отступы и радиус
контейнера меняются без своих стилей, а само поле сохраняет системный радиус.

:::example {id="components/country-code/smart-customization" label="Результат"}
:::

### Состояние из кода и событие `change`

Когда номер или страна зафиксированы, нативное событие `change` внутреннего
поля всплывает через `<sf-country-code>`; `detail` у него нет. Номер
читайте из `event.target.value`, а страну и код — из свойства `state`:
`value`, `iso2`, `dialCode`, `open` и `disabled`.

`setState()` принимает те же поля: `iso2` меняет страну и сохраняет местную
часть номера, `value` заменяет номер, `open` открывает список. Смена номера
или страны из `setState()` тоже отправляет `change`.

```js
const phone = document.querySelector('sf-country-code[name="phone"]');
phone.addEventListener('change', () => {
  const {value, iso2, dialCode} = phone.state;
  savePhone({value, iso2, dialCode});
});
phone.setState({iso2: 'KZ'});
```

## Доступность

- Задайте видимую подпись в `label`: компонент связывает её с полем номера.
  Если подпись выводит страница, передайте `aria-label`.
- Кнопка с флагом открывает список стран с одиночным выбором. Стрелки, `Home`,
  `End` и набор первых букв перемещают по списку, не меняя номер; `Enter` или
  `Space` выбирают страну, `Escape` закрывает список без выбора. В обоих
  случаях фокус возвращается на кнопку.
- `Tab` выходит из компонента и не удерживается в списке. Недоступное поле
  список не открывает.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`.
- `label` — `string`, по умолчанию пусто.
- `required` — `boolean`, по умолчанию `false`. Нативное обязательное поле телефона; одного префикса страны недостаточно для выполнения требования.
- `name` — `string`, по умолчанию пусто. Нативное имя поля ввода, используемое `FormData` и отправкой формы.
- `hint` — `string`, по умолчанию пусто.
- `placeholder` — `string`.
- `disabled` — `boolean`, по умолчанию `false`.
- `locale` — `string`, по умолчанию пусто. Язык названий стран и собственных текстов поля: `ru` или `en`. Если не задан, следует языку страницы: русский на русской странице, иначе английский.
- `use-mask` — `boolean`, по умолчанию `false`.
- `use-country-masks` — `boolean`, по умолчанию `true`.
- `show-code` — `boolean`, по умолчанию `true`.
- `mask-style` — `string`, по умолчанию `native`.
- `multi-country` — `boolean`, по умолчанию `true`.
- `iso2` — `string`, по умолчанию пусто.
- `dial-code` — `string`, по умолчанию пусто.
- `mask-pattern` — `string`, по умолчанию пусто.
- `flag-base` — `string`, по умолчанию пусто.
- `lazy-flags` — `boolean`, по умолчанию `true`.
- `show-mask-placeholder` — `boolean`, по умолчанию `false`.
- `mask-placeholder-char` — `string`, по умолчанию `_`.
- `max-items` — `number`, по умолчанию `0`.
- `value` — `string`, по умолчанию пусто.
- `open` — `boolean`, по умолчанию `false`.
- `aria-label` — `string`, по умолчанию пусто. Доступное имя поля телефона без видимой подписи.

### Методы

- `setState(nextState?: object)` — возвращает `boolean`. Применяет disabled, open (или active), value, iso2 и dialCode к отрисованному полю; установка value отправляет нативные input и change от внутреннего input. Возвращает true, если применено, и false до отрисовки.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components-2/names/). Общие события базового элемента перечислены в главе [Жизненный цикл → Этапы](/ru/guide/smart-components/lifecycle/#этапы).

- `change` — `detail`: `null`. Номер телефона или страна зафиксированы; нативное событие всплывает от внутреннего input, который является его целью. detail не передаётся. Имя для привязки.
- `input` — `detail`: `null`.

### Доступность

- Роль: текстовое поле (`textbox`).
- Доступное имя: рекомендуется.
- Клавиши: `Tab`, `Enter`, `Space`, `Escape`, `ArrowDown`, `ArrowUp`, `Home`, `End`, поиск по первым буквам.
- Фокус: Кнопка кода страны открывает список с одиночным выбором (`listbox`). Стрелки, Home, End и поиск по первым буквам перемещают фокус, не меняя телефон; Enter/Space подтверждают выбор, Escape отменяет. При закрытии подтверждением или по Escape фокус возвращается на кнопку; Tab уводит фокус без ловушки. Отключённые поля не открываются.
