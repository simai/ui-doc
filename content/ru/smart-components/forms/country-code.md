# Smart-код страны

`<sf-country-code>` создаёт телефонное поле из атрибутов или данных JavaScript
и использует оформление и поведение обычного компонента «Код страны».

## Особенности применения

Всегда задавайте понятную видимую подпись через `label`. Компонент сам связывает
её с нативным `input[type="tel"]`, создаёт кнопку выбора и одиночный `listbox`,
поддерживает клавиатуру и возвращает фокус после подтверждения или отмены.
Атрибуты `name`, `form` и `required` сохраняют нативную семантику формы.

## Выбор и фиксированный код

По умолчанию пользователь может менять страну. `multi-country="false"`
оставляет заданный `iso2` или `dial-code` фиксированным и не создаёт список.
Текущее значение, страну, код, открытое и недоступное состояния можно прочитать
через свойство `state` и изменить методом `setState()`.

## Размеры

Атрибут `size` принимает `1/2`, `1` и `2`. Все варианты используют
типографические токены Framework и сохраняют одинаковую структуру подписи,
поля и подсказки.

## Работа в форме

Значение участвует в `FormData`, нативной проверке и reset. Сброс возвращает
исходные номер и страну. Компонент не проверяет существование международного
номера: серверная проверка и бизнес-валидация остаются задачей приложения.

:::example {id="components/country-code/smart-form" label="Результат"}
:::

## События

Когда номер или страна зафиксированы, нативное событие `change` всплывает от внутреннего поля до `sf-country-code`. Это общее имя для всех полей значения; подписывайтесь на него.

## Язык

Названия стран и собственные подписи поля (доступное имя, сообщение о
незаполненном номере) берутся на языке страницы: на странице с `lang="ru"` —
русские, на любой другой — английские. Атрибут `locale="ru"` или `locale="en"`
задаёт язык явно.

## Собственный набор стран

Свойство `countries` принимает локальный массив объектов с `iso2`, `code` или
`dialCode`, `label` и необязательным `maskPattern`. Для известных ISO пропущенные
данные дополняются встроенным справочником. Перед присваиванием дождитесь
регистрации элемента через `customElements.whenDefined()`.

:::example {id="components/country-code/smart-countries" label="Результат"}
:::

## Оформление

`root-class` добавляет корню обычные утилиты Framework. Так можно менять
поверхность, отступы и общий радиус без копирования внутренних классов и без
абсолютных CSS-размеров; геометрия самого поля продолжает использовать
системный UI-радиус.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-257f66def2b8` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

### Атрибуты

- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`.
- `label` — `string`, по умолчанию `Label`.
- `required` — `boolean`, по умолчанию `false`. Нативное обязательное поле телефона; одного префикса страны недостаточно для выполнения требования.
- `name` — `string`, по умолчанию пусто. Нативное имя поля ввода, используемое `FormData` и отправкой формы.
- `form` — `string`, по умолчанию пусто. Необязательный id нативной формы-владельца, если поле находится вне её.
- `hint` — `string`, по умолчанию пусто.
- `value` — `string`, по умолчанию пусто.
- `placeholder` — `string`, по умолчанию `+7(___)___-__-__`.
- `disabled` — `boolean`, по умолчанию `false`.
- `open` — `boolean`, по умолчанию `false`.
- `locale` — `string`, по умолчанию пусто. Язык названий стран и собственных текстов поля: `ru` или `en`. Если не задан, следует языку страницы: русский на русской странице, иначе английский.
- `use-mask` — `boolean`, по умолчанию `false`.
- `use-country-masks` — `boolean`, по умолчанию `true`.
- `show-code` — `boolean`, по умолчанию `true`.
- `mask-style` — `string`, по умолчанию `native`.
- `multi-country` — `boolean`, по умолчанию `true`.
- `iso2` — `string`, по умолчанию пусто.
- `dial-code` — `string`, по умолчанию пусто.
- `mask-pattern` — `string`, по умолчанию пусто.
- `flag-base` — `string`, по умолчанию пусто.
- `lazy-flags` — `boolean`, по умолчанию `true`.
- `show-mask-placeholder` — `boolean`, по умолчанию `false`.
- `mask-placeholder-char` — `string`, по умолчанию `_`.
- `max-items` — `number`, по умолчанию `0`.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `size="1/2"` | `size="1/3"` | работает и предупреждает | 2026-12-01 |
| `size="2"` | `size="3"` | работает и предупреждает | 2026-12-01 |

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `change` — `detail` не описан. Значение телефона или страна зафиксированы; нативное событие всплывает от внутреннего поля ввода, которое является его целью. Имя для привязки.

### Доступность

- Доступное имя: рекомендуется.
- Клавиши: `Tab`, `Enter`, `Space`, `Escape`, `ArrowDown`, `ArrowUp`, `Home`, `End`, `Typeahead`.
- Фокус: Кнопка кода страны открывает список с одиночным выбором (`listbox`). Стрелки, Home, End и поиск по первым буквам перемещают фокус, не меняя телефон; Enter/Space подтверждают выбор, Escape отменяет. При закрытии подтверждением или по Escape фокус возвращается на кнопку; Tab уводит фокус без ловушки. Отключённые поля не открываются.

```html
<sf-country-code></sf-country-code>
```
