# Форматированный текст

`<sf-rich-text>` — поле формы для текста с оформлением: абзацы, заголовки
второго–четвёртого уровня, полужирный, курсив, ссылки, маркированные и
нумерованные списки и цитаты. Над текстом — панель кнопок, есть отмена и
повтор. Значение поля — HTML из небольшого набора тегов, и ничего сверх него.
Для простого текста без оформления берите
[многострочное поле](/ru/smart-components/forms/textarea/).

## Применение

### Значение

Значение — строка HTML из тегов `p`, `h2`, `h3`, `h4`, `strong`, `em`,
`a`, `ul`, `ol`, `li`, `blockquote` и `br`.

- У ссылки остаётся только `href`, и только с адресом `https:`, `mailto:`,
  `tel:` или путём на сайте (`/ru/guide/`). Ссылка с другим адресом
  становится обычным текстом.
- Другие теги снимаются, их текст остаётся; `script`, `style` и похожие
  убираются вместе с содержимым. `b` и `i` становятся `strong` и `em`.
- Текст вне блока попадает в `p`. Пустое поле даёт пустую строку, а не
  `<p></p>`.
- Входящее значение тоже очищается: поле не доверяет тому, что пришло с
  сервера, и показывает только разрешённую разметку.

Сервер всё равно проверяет значение при сохранении: очистка в браузере
защищает человека за экраном, а не хранилище.

:::

### Панель и клавиши

Кнопки панели: абзац и заголовки 2–4, полужирный, курсив, ссылка,
маркированный и нумерованный список, цитата, отмена и повтор.

- `Ctrl`/`Cmd`+`B` и `I` — полужирный и курсив, `Ctrl`/`Cmd`+`K` — ссылка;
- `Ctrl`/`Cmd`+`Z` — отмена, `Ctrl`/`Cmd`+`Shift`+`Z` или `Ctrl`+`Y` —
  повтор;
- ссылку правят в небольшом поле под панелью: `Enter` применяет адрес,
  `Escape` закрывает поле.

Вставка и перетаскивание тоже очищаются: из Word и веб-страниц остаётся
только разрешённое оформление, простой текст делится на абзацы по пустым
строкам.

### Ошибка, только чтение и отключение

`required` требует непустой текст, `invalid` и `error-message` показывают
ошибку под полем. `readonly` оставляет текст доступным для чтения и
выделения, `disabled` отключает поле целиком и не отправляет его с формой.

### Значение в форме и события

Поле участвует в форме как `sf-textarea`: `name` и `value` уходят с формой,
`form.reset()` возвращает исходное значение.

- `input` приходит один раз на каждое изменение — ввод, вставку, кнопку
  панели, отмену или повтор — уже после очистки;
- `change` приходит, когда фокус ушёл из поля целиком и значение
  изменилось; переходы между панелью, полем ссылки и текстом уходом не
  считаются;
- значение, заданное из кода, сброс формы и восстановление браузером событий
  не отправляют.

```js
const field = document.querySelector('sf-rich-text[name="body"]');
field.addEventListener('change', () => save(field.value));
```

## Доступность

- Задайте видимую подпись в `label`; без неё назовите поле через
  `aria-label`.
- Панель — одна остановка `Tab`: стрелки, `Home` и `End` ходят по кнопкам,
  следующий `Tab` переводит в текст. `Tab` в тексте уводит из поля, а не
  вставляет табуляцию.
- Кнопки оформления сообщают своё состояние через `aria-pressed`; кнопка,
  которая сейчас не применима (заголовок внутри списка), остаётся
  достижимой и отмечена `aria-disabled`.
- Контраст текста и кнопок — не ниже AA в светлой и тёмной теме.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Лестница размеров поля, как у sf-textarea: рамка, отступы и текст того же размера; кнопки панели на ступень ниже.
- `appearance` — `string`, по умолчанию `bordered`, значения: `bordered`, `filled`. Вид поля: блок с рамкой или с заливкой — те же два вида, что у sf-textarea.
- `label` — `string`, по умолчанию пусто. Видимое имя поля; оно называет область правки. Без него имя даёт aria-label хоста.
- `required` — `boolean`, по умолчанию `false`. Форма не отправляется, пока значение пустое (value-missing).
- `placeholder` — `string`, по умолчанию пусто. Показывается, пока в поле нет текста; озвучивается как aria-placeholder.
- `hint` — `string`, по умолчанию пусто. Строка под полем; она описывает область правки.
- `name` — `string`, по умолчанию пусто. Имя, под которым значение уходит с формой.
- `rows` — `number`, по умолчанию `6`. Наименьшее число строк в области текста; она растёт вместе с текстом.
- `max-rows` — `number`. Наибольшее число строк, после которого текст прокручивается внутри. Не задано — без предела; значение меньше rows считается равным rows.
- `disabled` — `boolean`, по умолчанию `false`. Не редактируется, не получает фокус и не отправляется с формой; так же действует отключённый fieldset.
- `readonly` — `boolean`, по умолчанию `false`. Текст читается и выделяется, но не меняется; панель отключена, значение отправляется с формой.
- `invalid` — `boolean`, по умолчанию `false`. Решение страницы: вид ошибки и aria-invalid, под полем — error-message.
- `error-message` — `string`, по умолчанию пусто. Показывается вместо подсказки, пока поле с ошибкой.
- `value` — `string`, по умолчанию пусто. HTML из набора p, h2, h3, h4, strong, em, a[href], ul, ol, li, blockquote, br; href только https:, mailto:, tel: или путь на сайте. Очищается при задании и при правке; пустая строка, когда текста нет.
- `aria-label` — `string`, по умолчанию пусто.

### Методы

- `runCommand(command: string)` — возвращает `boolean`. Выполняет команду панели над текущим выделением: paragraph, heading-2, heading-3, heading-4, bold, italic, link (открывает поле ссылки), bulleted-list, numbered-list, quote, undo, redo. Результат очищается, попадает в историю отмены и сообщается событием input. Возвращает, выполнена ли команда (false, пока поле отключено или только для чтения).
- `undo()` — возвращает `boolean`. Возвращает на одно очищенное состояние назад и сообщает input; false, если отменять нечего.
- `redo()` — возвращает `boolean`. Переходит на одно очищенное состояние вперёд и сообщает input; false, если повторять нечего.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `input` — `detail`: `null`. Текст изменился при правке: ввод, вставка или перетаскивание, команда панели, отмена или повтор; один раз на изменение, после очистки значения. Нативное событие всплывает от области правки, которая является его целью.
- `change` — `detail`: `null`. Значение зафиксировано: человек ушёл из поля со значением, отличным от прежнего; нативное Event от области правки, как у textarea при уходе из него.

### Доступность

- Роль: текстовое поле (`textbox`).
- Доступное имя: обязательно.
- Клавиши: Tab приводит на панель (одна остановка), затем в текст; Tab в тексте уводит из поля, ArrowLeft, ArrowRight, Home и End переходят между кнопками панели, Mod+B и Mod+I включают и выключают полужирный и курсив, Mod+K открывает поле ссылки, Mod+Z отменяет, Mod+Shift+Z и Mod+Y повторяют, Enter в поле ссылки применяет адрес, Escape закрывает поле.
- Фокус: Рамка рисует кольцо фокуса, пока текст в фокусе с клавиатуры; щелчок в текст кольца не рисует. Команды панели сохраняют курсор и выделение в тексте; поле ссылки при открытии забирает фокус и при закрытии возвращает курсор в текст.

### Минимальная разметка

```html
<sf-rich-text label="Page text" name="body" value="<p>Hello</p>"></sf-rich-text>
```
