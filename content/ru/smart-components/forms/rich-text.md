# Форматированный текст

`<sf-rich-text>` — поле формы для текста с оформлением: абзацы, заголовки
2–4, полужирный, курсив, ссылки, маркированные и нумерованные списки и
цитаты, с панелью инструментов, отменой и повтором. Значение поля — HTML
только этого набора. Для простого текста берите
[Многострочное поле](/ru/smart-components/forms/textarea/), для одной
строки — [Текстовые поля](/ru/smart-components/forms/inputs/).

## Разметка

В разметке — один тег с `label`, `name` и начальным `value`:
`<sf-rich-text label="Текст страницы" name="body" value="<p>…</p>">`.

- `label` — видимое имя; оно называет область редактирования. Без него имя
  даёт `aria-label` на теге.
- `name` — имя, под которым форма отправляет значение.
- `value` — начальное значение и то, что возвращает сброс формы.
- `placeholder` — текст, пока поле пустое; `hint` — строка под полем.

## Варианты

### Вид

`appearance` — две коробки [Многострочного поля](/ru/smart-components/forms/textarea/):
`bordered` (по умолчанию) — в рамке, `filled` — с заливкой.

:::example {id="smart-components/rich-text/appearance" label="В рамке и с заливкой"}
:::

### Размер

`size` — ступень лестницы полей: `1/2`, `1` (по умолчанию) или `2`. Рамка,
отступы и текст — как у Многострочного поля того же размера, кнопки панели
— на ступень меньше.

:::

## Состояния

### Обязательное

`required` не даёт отправить форму, пока значение пустое (`value-missing`).
Пустое поле показывает `placeholder`.

:::example {id="smart-components/rich-text/required" label="Пустое обязательное поле с заполнителем"}
:::

### Ошибка

`invalid` — решение страницы: поле получает вид ошибки и `aria-invalid`, а
`error-message` встаёт на место подсказки.

:::example {id="smart-components/rich-text/invalid" label="Ошибка с сообщением"}
:::

### Только чтение

`readonly` — текст читают и выделяют, но не меняют; панель недоступна, а
значение отправляется с формой.

:::example {id="smart-components/rich-text/readonly" label="Только чтение"}
:::

### Недоступно

`disabled` — поле нельзя изменить, оно не получает фокус и не отправляется
с формой. Так же действует недоступный `fieldset`.

:::example {id="smart-components/rich-text/disabled" label="Недоступное поле"}
:::

## Применение

### Значение

Значение — строка HTML, в которой есть только

`p h2 h3 h4 strong em a[href] ul ol li blockquote br`

- Из атрибутов остаётся только `href` у `<a>`, и только для адресов
  `https:`, `mailto:`, `tel:` и пути на сайте (`/docs/a`). Схема
  проверяется без управляющих символов и пробелов, поэтому `java\tscript:`
  не проходит; `//host` и `/\host` уводят с сайта и тоже не остаются. Ссылка
  с отброшенным `href` становится своим текстом.
- Любой другой элемент снимается, его текст остаётся. `script`, `style` и
  другие контейнеры, содержимое которых не текст для читателя (`template`,
  `iframe`, `svg`, `math`, медиа), уходят вместе с содержимым. Блочный
  элемент (`div`, `section`, `h1`, ячейка таблицы, `pre`) по-прежнему
  отделяет свой текст от соседей.
- `b` и `i` становятся `strong` и `em`; так же — `span` с полужирным или
  курсивным стилем. Это формы, в которых приходит вставка из текстового
  редактора.
- Текст вне блока оборачивается в `p`; список держит только пункты, соседние
  списки одного вида сливаются, списки могут быть вложенными.
- Пустых блоков нет. Поле без текста имеет значение `""`, а не `<p></p>`.

:::example {id="smart-components/rich-text/cleaned" label="Значение не из набора очищается при загрузке"}
:::

Значению не доверяют: начальное значение (атрибут и свойство), каждая
вставка и перетаскивание и область редактирования после каждой правки
проходят одну и ту же очистку. Сервер обязан очистить полученное ещё раз по
тому же набору: запрос может написать кто угодно.

### Поле в форме

`<sf-rich-text>` — элемент формы: форма отправляет очищенный HTML под
`name`, а `form`, `validity`, `checkValidity()`, `reportValidity()` и
`setCustomValidity(message)` работают как у нативного поля.

:::example {id="smart-components/rich-text/form" label="Обязательное поле в форме: отправка показывает значение"}
:::

### Свойства, действия и события

- `value` — текущий очищенный HTML. Запись очищает переданное и не
  отправляет ни `input`, ни `change`.
- `runCommand(command)` — команда панели над выделением: `paragraph`,
  `heading-2`, `heading-3`, `heading-4`, `bold`, `italic`, `link`,
  `bulleted-list`, `numbered-list`, `quote`, `undo`, `redo`.
- `undo()` и `redo()` — шаг собственной истории поля.
- `input` — текст изменился: набор, вставка, перетаскивание, команда, отмена
  или повтор; один раз на изменение, после очистки, из области
  редактирования.
- `change` — человек ушёл из поля с изменённым значением.

Значение, заданное из кода, сброс формы и восстановление формы браузером
событий не отправляют.

```js
const field = document.querySelector('sf-rich-text');
field.addEventListener('change', () => saveDraft(field.value));
field.runCommand('heading-2');
```

### Высота

`rows` — сколько строк поле показывает как минимум (по умолчанию 6); поле
растёт вместе с текстом. `max-rows` — сколько строк до того, как текст
начнёт прокручиваться внутри.

### Внешний вид

Открытые переменные — набор Многострочного поля под именем этого
компонента: `--sf-rich-text-background-color`,
`--sf-rich-text-border-color`, `--sf-rich-text-color`,
`--sf-rich-text-radius`, `--sf-rich-text-padding-inline`,
`--sf-rich-text-padding-block` и `--sf-rich-text-invalid-border-color`.
Цвета — роли темы, в светлой и тёмной.

## Доступность

- Область редактирования — `role="textbox"` с `aria-multiline="true"`,
  названа `label`, описана подсказкой или ошибкой, с `aria-required`,
  `aria-readonly`, `aria-disabled`, `aria-invalid` и `aria-placeholder`.
- Панель — `role="toolbar"` с именем «Форматирование» и одной остановкой
  `Tab`. Кнопки сообщают `aria-pressed`, если переключают, и
  `aria-keyshortcuts`, если у них есть сочетание. Кнопка, которая сейчас не
  может действовать (отмена без истории, заголовок внутри списка), —
  `aria-disabled` и остаётся доступной для фокуса.
- `Tab` в тексте уводит из поля и никогда не вставляет табуляцию.

| Клавиша | Что делает |
|:---|:---|
| `Tab` | панель (одна остановка), затем текст, затем выход из поля |
| `←` `→`, `Home`, `End` на панели | соседняя, первая и последняя кнопка |
| `Enter` или `Пробел` на панели | нажимает кнопку |
| `Ctrl+B` / `Cmd+B` | полужирный |
| `Ctrl+I` / `Cmd+I` | курсив |
| `Ctrl+K` / `Cmd+K` | окно ссылки: `Enter` применяет, `Escape` закрывает |
| `Ctrl+Z` / `Cmd+Z` | отменить |
| `Ctrl+Shift+Z` / `Cmd+Shift+Z`, `Ctrl+Y` | повторить |
