# Количество

`<sf-quantity>` — поле для числа, которое меняют по шагам: количество,
сумма, целое свойство. Оно собирает разметку
[поля количества](/ru/components/forms/quantity/) и добавляет границы, шаг,
клавиатуру и формат числа языка страницы.

## Пример

:::example {id="smart-components/quantity/overview" label="Количество от 1 до 99"}
:::

## Разметка

Минимальная разметка — тег с `label`, `name` и, при необходимости, `value`,
`min` и `max`.

- `value` пишется с точкой (`2567.5`); в поле число показано по правилам
  языка страницы — на русской странице с запятой и разделителем тысяч.
- Форма получает значение из скрытого input с именем `name`: с точкой и без
  разделителей (`2567.50`), что бы ни было видно в поле.
- Подпись выводит `label` (или слот `label`), пояснение — `hint`. Если подпись
  печатает страница, задайте `aria-label`.

## Варианты

### Размер

`size` выбирает ступень полей формы: `1/2`, `1` или `2`.

:::example {id="smart-components/quantity/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Границы и шаг

`min` и `max` задают границы: на границе кнопка недоступна, а введённое
число за границей подтягивается к ней. `step` — на сколько меняют значение
«−», «+» и стрелки, `page-step` — клавиши `PageUp` и `PageDown` (по
умолчанию десять шагов). `grouping="false"` пишет цифры подряд — для года
или кода.

:::example {id="smart-components/quantity/bounds" label="Шаг 5 и год без разделителя"}
:::

### Знаки после запятой

Число знаков после запятой берётся из `step` (у `0.25` их два); `precision`
задаёт его явно. Без знаков после запятой десятичный разделитель ввести
нельзя.

:::example {id="smart-components/quantity/decimals" label="Вес с шагом 0,25 и сумма с копейками"}
:::

### Наследуемое значение

`inherited-value` — число, которое действует, пока у поля нет своего, —
например, значение родительского раздела. Оно видно в пустом поле цветом
подсказки с меткой «наследуется», но не попадает в форму. Когда у поля
появилось своё число, кнопка сброса возвращает к наследуемому.

:::example {id="smart-components/quantity/inherited" label="Пустое поле с наследуемым значением"}
:::

## Состояния

### Ошибка

`invalid` (или `error`) и `error-message` показывают ошибку вместо пояснения;
поле получает `aria-invalid`.

:::example {id="smart-components/quantity/state-error" label="Ошибка с сообщением"}
:::

### Недоступно и только для чтения

`disabled` — значение видно, но не меняется и не отправляется с формой.
`readonly` — значение видно и отправляется, но кнопки и клавиши его не
меняют.

:::example {id="smart-components/quantity/state-disabled" label="Недоступное поле и поле только для чтения"}
:::

## Применение

### Когда брать поле количества

Поле количества — для числа, которое удобно менять по шагам и у которого
есть границы. Для значения, которое выбирают перетаскиванием по шкале,
берите [Слайдер диапазона](/ru/smart-components/forms/range-slider/), для
произвольного числа без кнопок — [Текстовые поля](/ru/smart-components/forms/inputs/)
с `inputmode="decimal"`.

### Значение и события

Свойство `value` возвращает число или `null`. Событие `input` приходит, пока
значение меняется: при вводе — каждый раз, когда текст читается как другое
число, при нажатии кнопки или клавиши — на каждом шаге. Событие `change`
приходит один раз на изменение: после ввода (по `Enter` или уходу из поля),
после нажатия кнопки (одно на всё удержание) или клавиши. В `detail` обоих —
`value`, `text`, `name` и `source`.

`setValue()`, `clear()`, `stepUp()` и `stepDown()` меняют число из кода
без событий; `setError()` показывает или снимает ошибку.

```js
const count = document.querySelector('sf-quantity[name="count"]');
count.addEventListener('change', (event) => {
  updateTotal(event.detail.value);
});
```

## Доступность

- Поле — `spinbutton` с `aria-valuenow`, `aria-valuemin`, `aria-valuemax` и
  `aria-valuetext` в формате языка страницы; его называет `label` или
  `aria-label`.
- `↑` и `↓` меняют значение на шаг, `PageUp` и `PageDown` — на десять
  шагов, `Home` и `End` переходят к границам, `Enter` сохраняет ввод, `Escape`
  отменяет его.
- «−» и «+» — настоящие кнопки с именами «Уменьшить значение» и «Увеличить
  значение»; имена меняют `decrement-label` и `increment-label`.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `name` — `string`, по умолчанию пусто. Имя в форме: скрытый input отправляет значение с точкой и без разделителей (`2567.50`), что бы ни было видно в поле. У самого поля имени нет.
- `label` — `string`, по умолчанию пусто. Подпись над полем; называет spinbutton. Слот `label` принимает разметку вместо строки.
- `hint` — `string`, по умолчанию пусто. Пояснение под полем; слот `hint` принимает разметку вместо строки.
- `placeholder` — `string`, по умолчанию пусто. Видно в пустом поле.
- `min` — `number`. Нижняя граница: на ней «−» недоступна, Home переходит к ней, введённое значение ниже неё при сохранении поднимается до неё. Пусто — границы нет; без неё или если она меньше нуля, можно ввести минус.
- `max` — `number`. Верхняя граница: на ней «+» недоступна, End переходит к ней, введённое значение выше неё при сохранении опускается до неё. Пусто — границы нет.
- `step` — `number`, по умолчанию `1`. На сколько меняют значение «−», «+», ArrowUp и ArrowDown. Положительное число; всё остальное считается 1. Его знаки после запятой — знаки поля, если `precision` не задаёт иное.
- `page-step` — `number`. На сколько меняют значение PageUp и PageDown; пусто — десять шагов.
- `precision` — `integer`, значения: от 0; до 20. Знаки после запятой — видимые и хранимые; пусто — берутся из `step` (у 0.25 их два). Без них десятичный разделитель ввести нельзя.
- `grouping` — `boolean`, по умолчанию `true`. Разделяет тысячи по правилам языка страницы («2 567»); `grouping="false"` пишет цифры подряд — для года или кода.
- `locale` — `string`, по умолчанию пусто. Язык, на котором число читается и пишется; если не задан — язык страницы (`lang`), поэтому на русской странице десятичный разделитель — запятая.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Размер поля: 1/2, 1 или 2, как у любого поля формы.
- `required` — `boolean`, по умолчанию `false`. В поле должно быть число: поле обязательно, поэтому форма не отправится, пока оно пустое.
- `disabled` — `boolean`, по умолчанию `false`. Видно, но не меняется: поле и обе кнопки недоступны, скрытый input не отправляется.
- `readonly` — `boolean`, по умолчанию `false`. Видно, но не меняется: поле только для чтения, кнопки недоступны, клавиши не меняют значение.
- `invalid` — `boolean`, по умолчанию `false`. Состояние ошибки: край и сообщение окрашены цветом ошибки, у поля aria-invalid.
- `error-message` — `string`, по умолчанию пусто. Ошибка, которая видна вместо пояснения, пока поле с ошибкой; слот `error` принимает разметку вместо строки.
- `decrement-label` — `string`. Доступное имя «−». Если не задано — на языке страницы («Уменьшить значение», «Decrease value»).
- `increment-label` — `string`. Доступное имя «+». Если не задано — на языке страницы («Увеличить значение», «Increase value»).
- `aria-label` — `string`, по умолчанию пусто. Доступное имя spinbutton, когда подпись внутри поля не выводится: форма, которая печатает подпись рядом (рендереры полей Framework), называет поле без второй видимой подписи.
- `error` — `boolean`, по умолчанию `false`. Состояние ошибки; то же, что invalid.
- `value` — `string`, по умолчанию пусто. Число в поле, записанное с точкой (`2567.5`); пусто — числа нет. Свойство возвращает число или null и принимает число, текст числа или null. Округляется до знаков поля. Заданное из кода, событий не отправляет.
- `inherited-value` — `string`, по умолчанию пусто. Значение, к которому поле возвращается, пока у него нет своего числа, — значение по умолчанию из родительской настройки. Видно в пустом поле цветом подсказки с меткой «наследуется», никогда как значение: значение формы остаётся пустым. Когда у поля появилось своё число, кнопка сброса возвращает сюда.
- `inherited-text` — `string`, по умолчанию пусто. Слова метки, которая видна, пока действует наследуемое значение. Если не задано — на языке страницы («наследуется», «inherited»).
- `reset-label` — `string`, по умолчанию пусто. Доступное имя кнопки, которая возвращает поле к наследуемому значению. Если не задано — на языке страницы («Сбросить к наследуемому», «Reset to inherited»).

### Методы

- `clear()` — возвращает `object`. Очищает поле из кода; то же, что setValue(null). Возвращает элемент.
- `stepUp(count: number)` — возвращает `object`. Увеличивает значение на `count` шагов (по умолчанию 1) в пределах границ, как stepUp() нативного поля. Событий не отправляет. Возвращает элемент.
- `stepDown(count: number)` — возвращает `object`. Уменьшает значение на `count` шагов (по умолчанию 1) в пределах границ. Событий не отправляет. Возвращает элемент.
- `setError(message: string)` — возвращает `object`. Показывает сообщение об ошибке и состояние ошибки или убирает оба пустым сообщением. Записывает error-message и invalid. Возвращает элемент.
- `setValue(value: number|string|null)` — возвращает `object`. Задаёт число из кода: число, текст числа с точкой или null — нет значения. Округляется до знаков поля, но не подтягивается к границам. Событий не отправляет: значение из кода — не изменение. Возвращает элемент.
- `resetToInherited()` — возвращает `boolean`. Возвращает поле к наследуемому значению, как кнопка сброса: сначала sf-field-reset (отменяемое), затем input и change. Возвращает, был ли сброс.
- `getInputElement()` — возвращает `object` | `null`. Возвращает текстовое поле spinbutton или null до отрисовки.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `change` — `detail`: `{ value: number|null, text: string, name: string, source: any }`. Значение сохранено: один раз на каждое изменение, сделанное человеком, — сохранение введённого текста (Enter или уход из поля), нажатие кнопки (одно на всё удержание), клавиша, сброс. CustomEvent на элементе; собственное change поля наружу не выходит. Сохранение, которое только переписывает текст, событий не отправляет.
- `input` — `detail`: `{ value: number|null, text: string, name: string, source: any }`. Значение сдвинулось: при вводе — каждый раз, когда текст читается как другое число; на каждом шаге кнопки или клавиши; перед каждым change, значение которого ещё не сообщалось. detail тот же, что у change.
- `sf-field-reset` — `detail`: `{ tag: string, value: string, inheritedValue: string, name: string }`. Человек нажал сброс к наследуемому значению. Событие признака field-inherit@1: одно имя для всех полей семейства, поэтому форма слышит их все сразу и различает по detail.tag. Отправляется до очистки поля и отменяемо: preventDefault сохраняет значение. Если не отменено, поле очищается, сообщает об этом обычным change, снова показывает наследуемое значение и забирает фокус.
- `sf-field:reset` — устаревший псевдоним события `sf-field-reset`: приходит с тем же `detail`, подписывайтесь на `sf-field-reset`.

### Доступность

- Роль: числовое поле.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowUp`, `ArrowDown`, `PageUp`, `PageDown`, `Home`, `End`, `Enter`, `Escape`.
- Фокус: Одна остановка Tab: текстовое поле с ролью spinbutton, названное подписью (aria-labelledby) или aria-label, с aria-valuenow, aria-valuemin, aria-valuemax и aria-valuetext в формате страницы, описанное пояснением или ошибкой. ArrowUp/ArrowDown меняют на шаг, PageUp/PageDown — на десять шагов, Home/End переходят к границам, если они есть, Enter сохраняет, Escape отменяет ввод. «−» и «+» — настоящие кнопки с именами «Уменьшить значение» / «Увеличить значение», вне порядка Tab, как в шаблоне APG; они управляют полем и недоступны на границах; нажатие указателем не забирает фокус у поля. Фокус от указателя не рисует кольцо, фокус с клавиатуры — рисует.

### Минимальная разметка

```html
<sf-quantity label="Количество" name="count" value="2" min="0" max="99"></sf-quantity>
```
