# Код подтверждения

`<sf-code-input>` — поле одноразового кода из сообщения, приложения-генератора
или письма. Оно собирает разметку
[поля кода подтверждения](/ru/components/forms/verification/): код хранит
один обычный input, а ячейки его показывают.

## Пример

:::example {id="smart-components/code-input/overview" label="Шесть цифр из сообщения"}
:::

## Разметка

Минимальная разметка — тег с `label` и `name`.

- Значение формы — один нативный input с именем `name` и
  `autocomplete="one-time-code"`, поэтому автозаполнение браузера и WebOTP
  вставляют код целиком.
- Ввод заполняет следующую ячейку, `Backspace` возвращается и стирает,
  вставленный код заполняет все ячейки.
- `hint` подсказывает, сколько символов и откуда код.

## Варианты

### Длина и символы

`length` — сколько символов в коде, от 1 до 12. `mode="numeric"` (по
умолчанию) принимает цифры и открывает цифровую клавиатуру,
`mode="alphanumeric"` — латинские буквы и цифры. Остальное при вводе и
вставке отбрасывается.

:::example {id="smart-components/code-input/length-mode" label="Четыре цифры и восемь букв и цифр"}
:::

### Размер

`size` выбирает ступень полей формы: `1/2`, `1` или `2`.

:::example {id="smart-components/code-input/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Вид

`appearance="bordered"` (по умолчанию) делит ячейки рамкой,
`appearance="filled"` ставит их на тоновую заливку; в фокусе ячейки получают
рамку.

:::example {id="smart-components/code-input/appearance" label="Виды bordered и filled"}
:::

### Скрытый код

`mask` показывает каждый символ точкой; поле становится полем пароля, и
экранный диктор не читает код вслух.

:::example {id="smart-components/code-input/mask" label="Код, скрытый точками"}
:::

## Состояния

### Ошибка

Когда приложение отклонило код, задайте `invalid` и `error-message`: ячейки
и сообщение окрашиваются цветом ошибки, поле получает `aria-invalid`.
Снимает состояние тоже приложение.

:::example {id="smart-components/code-input/state-error" label="Отклонённый код"}
:::

### Недоступно и только для чтения

`disabled` запрещает ввод и не отправляет значение; `readonly` показывает
код без правки.

:::example {id="smart-components/code-input/state-disabled" label="Недоступное поле и поле только для чтения"}
:::

## Применение

### Когда брать поле кода

Поле кода — для одноразового кода, который человек получил и вводит или
вставляет. PIN-код или пароль, который человек придумывает сам, вводят в
[текстовое поле](/ru/smart-components/forms/inputs/) с `input-type="password"`.

### Проверка кода и события

Когда заполнены все ячейки, приходит `sf-code-input:complete` с `value` —
один раз на каждый целый код. Компонент сам форму не отправляет и код не
проверяет: проверяет приложение. Обычные события `input` и `change` всплывают
от внутреннего input без `detail`.

```js
const code = document.querySelector('sf-code-input[name="code"]');
code.addEventListener('sf-code-input:complete', async (event) => {
  const ok = await verify(event.detail.value);
  code.toggleAttribute('invalid', !ok);
  if (!ok) code.setAttribute('error-message', 'Код не подошёл');
});
```

## Доступность

- Группа ячеек и поле названы `label` (или `aria-label`).
- Каждый раз, когда курсор переходит в другую ячейку, вежливая строка
  сообщает её место: «цифра 3 из 6», для буквенно-цифрового кода — «символ».
- `←` и `→` переходят между ячейками, `Home` и `End` — к первой и последней,
  `Backspace` и `Delete` стирают.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `length` — `number`, по умолчанию `6`. Сколько символов в коде, от 1 до 12; по ячейке на символ.
- `default-value` — `string`, по умолчанию пусто. Код, к которому возвращает сброс формы; поле начинается с него, если value нет.
- `name` — `string`, по умолчанию пусто. Имя нативного input в форме; его значение и есть значение формы.
- `mode` — `string`, по умолчанию `numeric`, значения: `numeric`, `alphanumeric`. numeric: цифры и цифровая клавиатура; alphanumeric: латинские буквы и цифры. Остальное при вводе и вставке отбрасывается; нативный pattern требует ровно length символов режима.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень лестницы полей формы, как у sf-input: ячейки и их текст.
- `appearance` — `string`, по умолчанию `bordered`, значения: `bordered`, `filled`. bordered: ячейки разделены рамкой; filled: ячейки на тоновой заливке, которые получают рамку, пока код в фокусе.
- `label` — `string`, по умолчанию пусто. Видимая подпись; называет группу и поле.
- `hint` — `string`, по умолчанию пусто. Текст под ячейками: сколько символов и откуда код.
- `required` — `boolean`, по умолчанию `false`. Форма требует целый код.
- `disabled` — `boolean`, по умолчанию `false`.
- `readonly` — `boolean`, по умолчанию `false`.
- `invalid` — `boolean`, по умолчанию `false`. Код отклонён: ячейки и пояснение окрашены цветом ошибки, у поля aria-invalid. Задаёт и снимает хост.
- `error-message` — `string`, по умолчанию пусто. Показывается вместо пояснения, пока поле с ошибкой, и служит aria-errormessage поля.
- `mask` — `boolean`, по умолчанию `false`. Каждый символ показан точкой; поле становится полем пароля, поэтому экранный диктор не читает код вслух.
- `value` — `string`, по умолчанию пусто. Код. Заданный атрибутом, он управляемый: атрибут следует за вводом человека. Приводится к режиму и длине.
- `aria-label` — `string`, по умолчанию пусто. Имя группы и поля, когда видимой подписи нет.
- `error` — `boolean`, по умолчанию `false`. Прежнее имя invalid, по-прежнему действует.

### Методы

- `getInputElement()` — возвращает `object` | `null`. Возвращает внутренний нативный input или null до отрисовки.
- `focus(options?: object)` — возвращает `null`. Ставит фокус на нативный input.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components-2/names/). Общие события базового элемента перечислены в главе [Жизненный цикл → Этапы](/ru/guide/smart-components/lifecycle/#этапы).

- `input` — `detail`: `null`. Код изменился при вводе, вставке или автозаполнении; нативное событие всплывает от внутреннего input, который является его целью, со значением, уже приведённым к режиму и длине. detail нет.
- `change` — `detail`: `null`. Код сохранён: поле потеряло фокус с кодом, отличным от того, что был при получении фокуса. Отправляется один раз от внутреннего input. detail нет.
- `sf-code-input-completed` — `detail`: `{ value: string }`. Факт завершения (стандарт 1.3.8 §8): в каждой ячейке есть символ, после правки человека; один раз на каждый целый код, после его события input. Элемент сам форму не отправляет.
- `sf-code-input:complete` — устаревший псевдоним события `sf-code-input-completed`: приходит с тем же `detail`, подписывайтесь на `sf-code-input-completed`.

### Доступность

- Роль: группа (`group`).
- Доступное имя: обязательно.
- Клавиши: `Tab`, `Backspace`, `Delete`, `ArrowLeft`, `ArrowRight`, `Home`, `End`.
- Фокус: Группа (role group) и единственный нативный input названы подписью, без неё — aria-label. Input описан вежливой строкой, которая называет ячейку курсора — «цифра 3 из 6», «digit 3 of 6», «символ» или «character» для буквенно-цифрового кода — на языке страницы и повторяется при каждом переходе курсора в другую ячейку; затем пояснением или сообщением об ошибке. Ввод заполняет ячейку курсора и идёт дальше, Backspace стирает ячейку перед курсором и возвращается, стрелки, Home и End переходят между ячейками, щелчок ставит курсор в нажатую ячейку. Ячейки скрыты через aria-hidden; символы идут слева направо и на странице с письмом справа налево.

### Минимальная разметка

```html
<sf-code-input label="Код из сообщения" name="code" hint="Мы отправили шесть цифр на +7 900 000-00-00"></sf-code-input>
```
