# Выбор из поиска

`<sf-lookup>` — поле формы, в котором выбирают людей или объекты из поиска:
человек набирает имя, видит строки с аватаром, именем и подписью и выбирает
одно значение или несколько. Выбранное показано плашками, каждую можно убрать.
Ищет сайт: компонент сам ничего не загружает. Для короткого постоянного списка
без поиска берите [выпадающий список](/ru/smart-components/navigation/dropdown/).

## Применение

### Значение

- Одно значение — `{value, label}` или `null`.
- Несколько (`multiple`) — список `{value, label}` в порядке выбора; пустой
  список, когда ничего не выбрано.
- У элемента могут быть `caption` (подпись) и `avatar` (`{src}` или
  `{initials}`); выбранный элемент хранит их, поэтому плашке не нужен
  повторный запрос.
- С формой уходят только значения: одно или по записи на каждое. Подписи не
  отправляются.

Это то же значение, что у поля-справочника в
[карточке свойств](/ru/smart-components/composite/property-view/).

### Одно значение

Без `multiple` выбор сразу становится значением и закрывает список; в поле
видна подпись выбранного и кнопка очистки.

:::example {id="smart-components/lookup/single" label="Одно значение из списка: выбор закрывает список"}
:::

### Поиск на стороне сайта

Сайт отвечает через свойство `provider` — функцию, обычно асинхронную;
пример подключения — в конце раздела.

- Пока набрано меньше `min-length` (по умолчанию 2) символов, список
  подсказывает, сколько набрать, и ничего не спрашивает.
- После паузы `debounce` (120 мс) вызывается `provider`; предыдущий вызов
  отменяется через `signal`, а опоздавший ответ отбрасывается.
- `{items}` — строки или «Ничего не найдено»; `{status: 'unavailable'}` —
  нейтральная строка «Поиск недоступен» без причины; ошибка — строка ошибки и
  кнопка «Повторить».
- «Показать ещё» появляется только при `nextCursor`; ровно `max-results`
  строк ещё не значит, что есть продолжение.
- `exclude` убирает значения из каждого ответа — например, самого человека
  или уже добавленных участников; фильтрует компонент.
- `options` — короткий список целиком: по нему ищет сам компонент, без
  `provider`.

### Предел числа

`max-items` ограничивает число выбранных при `multiple`. Выбор сверх предела
не молча игнорируется: под списком появляется строка «Не больше 3».

### Ошибка и только чтение

`required` не даёт отправить форму без выбора, `invalid` и `error-message`
показывают ошибку под полем. `readonly` показывает значение и отправляет его
с формой, но без кнопок удаления; `disabled` отключает поле целиком.

:::

### События

- `input`, затем `change` — значение изменил человек: выбор, удаление плашки,
  `Backspace` в пустом поле поиска. `detail` — `{value, item, action}`, где
  `action` — `added`, `removed` или `replaced`.
- Набор текста событием значения не считается; значение из кода, сброс формы
  и восстановление браузером событий не отправляют.

### Подключение поиска

```js
const lookup = document.querySelector('sf-lookup[name="members"]');
lookup.provider = async (query, {cursor, limit, signal}) => {
  const response = await fetch(`/api/people?q=${encodeURIComponent(query)}&limit=${limit}`, {signal});
  return response.json(); // {items, nextCursor} или {status: 'unavailable'}
};
```

## Доступность

- Поле поиска — `combobox` с `aria-expanded`, `aria-controls` и
  `aria-activedescendant`; список — `listbox`, строки — `option` с
  `aria-selected`.
- Стрелки ходят по строкам, `Home` и `End` — к первой и последней, `Enter`
  выбирает, первый `Escape` закрывает список, второй очищает запрос,
  `Backspace` в пустом поле убирает последнюю плашку.
- Строка состояния — поиск, «ничего не найдено», ошибка, предел — объявляется
  вежливо (`role="status"`).
- Рамка, высота и текст совпадают с [полем ввода](/ru/smart-components/forms/inputs/)
  того же размера.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Лестница размеров поля, как у sf-input: рамка, отступы и текст того же размера; плашки стоят на строке текста поля, картинки строк — на ступень ниже.
- `appearance` — `string`, по умолчанию `bordered`, значения: `bordered`, `filled`. Вид поля: блок с рамкой или с заливкой — те же два вида, что у sf-input.
- `label` — `string`, по умолчанию пусто. Видимое имя поля; оно называет поле поиска и список. Без него имя даёт aria-label хоста.
- `placeholder` — `string`, по умолчанию пусто. Показывается в поле поиска, пока оно пустое.
- `hint` — `string`, по умолчанию пусто. Строка под полем; она описывает поле поиска.
- `name` — `string`, по умолчанию пусто. Имя в форме: одна запись с выбранным значением или по записи на каждое при multiple. Отправляются только значения, подписи никогда.
- `multiple` — `boolean`, по умолчанию `false`. Несколько значений — плашки в порядке выбора; после выбора список остаётся открытым. Без него выбор становится значением и закрывает список.
- `max-items` — `number`, по умолчанию `0`. Только с multiple: наибольшее число выбранных (49 для группы). Выбор сверх предела отклоняется с видимой строкой; 0 — без предела.
- `min-length` — `number`, по умолчанию `2`. Наименьшее число символов, с которым спрашивается provider; меньше — список показывает подсказку и ничего не спрашивает. По options ищется при любой длине.
- `max-results` — `number`, по умолчанию `20`. Предел, с которым спрашивается provider, и наибольшее число строк одного ответа.
- `debounce` — `number`, по умолчанию `120`. Сколько миллисекунд поле ждёт после последней клавиши, прежде чем спросить provider, как sf-search.
- `maxlength` — `number`, по умолчанию `0`. Наибольшее число символов в поле поиска (80 для simai.chat); 0 — без предела.
- `required` — `boolean`, по умолчанию `false`. Форма не отправляется, пока ничего не выбрано (value-missing).
- `disabled` — `boolean`, по умолчанию `false`. Не ищет, не меняется, не получает фокус и не отправляется с формой; так же действует отключённый fieldset.
- `readonly` — `boolean`, по умолчанию `false`. Выбранное показывается и отправляется, но не меняется: нет поиска и кнопок удаления.
- `invalid` — `boolean`, по умолчанию `false`. Решение страницы: вид ошибки и aria-invalid, под полем — error-message.
- `error-message` — `string`, по умолчанию пусто. Показывается вместо подсказки, пока поле с ошибкой.
- `aria-label` — `string`, по умолчанию пусто.
- `options` — `array`, по умолчанию `[]`. Короткий список целиком, [{value, label, caption?, avatar?}]: поиск по нему идёт на месте, provider не спрашивается. Свойство или остров data-sf-settings.
- `exclude` — `array`, по умолчанию `[]`. Значения, исключённые из каждого ответа и из options (сам человек, текущие участники); фильтрует компонент. Свойство или остров data-sf-settings.
- `provider` — `object`, по умолчанию `null`. Поиск: async-функция (query, {cursor, limit, signal}), отвечающая {items: [{value, label, caption?, avatar?: {src} | {initials}}], nextCursor?} или {status: 'unavailable'}; брошенная ошибка или отклонённое обещание — состояние ошибки. Предыдущий вызов прерывается через signal, его опоздавший ответ отбрасывается. Только свойство.
- `value` — `object`, по умолчанию `null`. Одно значение: {value, label} или null. Несколько: список {value, label} в порядке выбора, [], когда ничего не выбрано. Выбранный элемент хранит подпись и аватар. Значение из кода (или атрибут value как JSON; одиночное значение ищется в options) событий не отправляет.

### Методы

- `search(query: string)` — возвращает `boolean`. Ставит запрос в поле поиска и ищет его, как при наборе, сразу (без паузы), открывая список. Возвращает false, пока поле отключено или только для чтения.
- `retry()` — возвращает `boolean`. Повторяет последний вызов provider с тем же запросом и курсором, как кнопка «Повторить». Возвращает false, если повторять нечего.
- `close()` — возвращает `boolean`. Закрывает список и прерывает идущий поиск; запрос остаётся.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `input` — `detail`: `{ value: object, item: object, action: string }`. Значение изменилось: выбор, удаление плашки, Backspace в пустом поле поиска. Отправляется перед change с тем же detail; собственный input поля поиска наружу не выходит.
- `change` — `detail`: `{ value: object, item: object, action: string }`. Значение изменил человек, один раз на выбор или удаление, как у select: detail.value — новое значение, detail.item — выбранный или убранный элемент, detail.action — added, removed или replaced. Значение из кода, сброс формы и восстановление событий не отправляют.

### Доступность

- Роль: поле со списком (`combobox`).
- Доступное имя: обязательно.
- Клавиши: Набор текста запускает поиск; ArrowDown открывает список и идёт вниз, ArrowUp — вверх, Home и End — к краям, пока список открыт, Enter выбирает активную строку; в поле с одним значением закрывает список, Escape закрывает список, второй Escape очищает запрос, Backspace в пустом поле поиска убирает последнюю плашку, Tab проходит по кнопкам удаления плашек и уводит из поля.
- Фокус: Пока список открыт, фокус остаётся в поле поиска; активная строка сообщается через aria-activedescendant. Рамка рисует кольцо фокуса, пока поле в фокусе с клавиатуры; щелчок в поле кольца не рисует. Удаление плашки возвращает фокус в поле поиска.

### Минимальная разметка

```html
<sf-lookup label="Members" name="members" multiple max-items="49"></sf-lookup>
<script>document.querySelector('sf-lookup').provider = async (query, {cursor, limit, signal}) => (await fetch(`/api/people?q=${encodeURIComponent(query)}&limit=${limit}`, {signal})).json();</script>
```
