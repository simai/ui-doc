# Checkbox

## Название варианта и пояснение

`name` — машинное имя отправляемого поля, `value` — его машинное значение,
`label` — видимое название варианта, `description` — дополнительное пояснение.
`help` задаёт справочную иконку, а не заменяет название.

```html
<sf-checkbox
  name="notifications"
  value="email"
  label="Уведомления по почте"
  description="Отправлять важные изменения на рабочий адрес">
</sf-checkbox>
```

Для нескольких связанных флажков общее название вопроса задавайте снаружи
через нативные `<fieldset>` и `<legend>`. Каждый компонент при этом сохраняет
собственный `label`.

## Доступность

Перед использованием проверьте доступное имя, порядок фокуса, управление клавиатурой и объявление состояний. Сгенерированная API-страница подтверждает source-контракт, но не заменяет сценарный accessibility smoke.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-257f66def2b8` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

### Атрибуты

- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Токен размера чекбокса.
- `label` — `string`, по умолчанию пусто.
- `description` — `string`, по умолчанию пусто.
- `help` — `string`, по умолчанию пусто.
- `position` — `string`, по умолчанию `start`, значения: `start`, `end`. Логическое расположение индикатора относительно текста.
- `root-class` — `string`, по умолчанию пусто.
- `checked` — `boolean`, по умолчанию `false`.
- `disabled` — `boolean`, по умолчанию `false`.
- `indeterminate` — `boolean`, по умолчанию `false`. Смешанное визуальное состояние чекбокса, обобщающего связанные варианты.
- `name` — `string`, по умолчанию пусто.
- `value` — `string`, по умолчанию пусто.
- `error` — `boolean`, по умолчанию `false`. Недопустимое состояние; нативное поле ввода публикует `aria-invalid`.
- `aria-label` — `string`, по умолчанию пусто. Доступное имя чекбокса без видимой подписи.

### Методы

- `getInputElement()`
- `isChecked()` — возвращает `boolean`. Возвращает текущее нативное состояние checked.
- `setChecked()`
- `setIndeterminate()`
- `setDisabled()`
- `setBooleanStateAttribute()`
- `setState()`
- `onChange()`
- `onFocus()`
- `onBlur()`

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `change` — `detail` не описан. Изменилось состояние checked; нативное событие всплывает от внутреннего флажка, который является его целью.

### Доступность

- Доступное имя: обязательно.
- Клавиши: `Tab`, `Space`.
- Фокус: Сохраняет видимый фокус на активном элементе управления.

### Минимальная разметка

```html
<sf-checkbox></sf-checkbox>
```
