# Radio

## Название варианта и группы

`name` объединяет варианты в одну машинную группу, `value` задаёт значение
варианта, `label` — его видимое название, `description` — пояснение. Общее
название вопроса не повторяйте в каждом Radio: размещайте группу внутри
`<fieldset>` с `<legend>`.

```html
<fieldset>
  <legend>Способ публикации</legend>
  <sf-radio name="publish" value="now" label="Сейчас" checked></sf-radio>
  <sf-radio name="publish" value="later" label="По расписанию"></sf-radio>
</fieldset>
```

## Доступность

Перед использованием проверьте доступное имя, порядок фокуса, управление клавиатурой и объявление состояний. Сгенерированная API-страница подтверждает source-контракт, но не заменяет сценарный accessibility smoke.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-257f66def2b8` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

### Атрибуты

- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Токен размера переключателя (radio).
- `label` — `string`, по умолчанию пусто.
- `description` — `string`, по умолчанию пусто.
- `help` — `string`, по умолчанию пусто.
- `checked` — `boolean`, по умолчанию `false`.
- `disabled` — `boolean`, по умолчанию `false`.
- `name` — `string`, по умолчанию пусто.
- `value` — `string`, по умолчанию пусто.
- `error` — `boolean`, по умолчанию `false`.

### Методы

- `getInputElement()`
- `setChecked()`
- `setDisabled()`
- `setState()`
- `onChange()`
- `onFocus()`
- `onBlur()`

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `change` — `detail` не описан. Выбор изменился; нативное событие всплывает от внутренней радиокнопки, которая является его целью. Имя для привязки.

### Доступность

- Роль: радиокнопка (`radio`).
- Доступное имя: обязательно.
- Клавиши: `Tab`, `Arrow keys`, `Space`.
- Фокус: Сохраняет видимый фокус на активном элементе управления.

### Минимальная разметка

```html
<sf-radio></sf-radio>
```
