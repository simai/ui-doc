# Smart-загрузка файлов

`<sf-file-upload>` создаёт зону выбора из атрибутов или данных JavaScript и
использует оформление и поведение обычного компонента «Загрузка файлов».

## Особенности применения

Smart-компонент не загружает файлы и не добавляет их в нативный `FormData`.
Читайте сохранённые объекты `File` через `getItems()` или обработчики
`onFileAdd()` и `sf-file-upload:select`, проверяйте их в приложении и передавайте
своим транспортом. `accept` управляет подсказкой системного окна, а `multiple`
разрешает выбрать несколько файлов; серверная проверка остаётся обязательной.

## Выбор файлов

Тексты зоны задаются атрибутами `link-text`, `text` и `supporting-text`.
Если `supporting-text` не указан, компонент выводит `formats`, а при его
отсутствии формирует подпись из `accept`. Если не задано ни то ни другое,
строки с форматами нет: компонент не знает, какие файлы принимает поле, и не
называет форматы за хоста. Иконку можно заменить атрибутом
`icon`; нейтральное значение по умолчанию — `upload_file`.

Атрибут `size` принимает `1/2`, `1` и `2`. Размер меняет зону
выбора и строки файлов как единую композицию, используя токены Framework.

## Состояния и действия

`setItems()` принимает элементы с именем, размером, прогрессом и состоянием
`process`, `done` или `error`. Методы `removeItem()` и `clear()` управляют
локальным списком. Действия пользователя отправляют события удаления и повтора,
но не вмешиваются в запрос приложения.

:::example {id="components/file-upload/smart-states" label="Результат"}
:::

## События

Выбор файлов вызывает `change` — общее имя для всех полей значения. События `sf-file-upload:*` описывают отдельные шаги загрузки и остаются отдельными событиями, а не прежними именами `change`.

## Недоступное состояние

Атрибут `disabled` отключает системный выбор и перенос файлов, сохраняет список
и синхронизирует доступность вложенных действий.

:::example {id="components/file-upload/smart-disabled" label="Результат"}
:::

## Оформление

`root-class` добавляет корню обычные утилиты Framework. Так можно менять
поверхность, отступы и радиус зоны без копирования внутренних классов и без
абсолютных CSS-размеров. Вложенные кнопки сохраняют системный UI-радиус.

## Справочник API

Раздел собран из манифеста компонента выпуска `ui-6d2bf151e3c8` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `search-placeholder` — `searchPlaceholder`. Свойство атрибута `template` называется `templateName`.

| | |
|:---|:---|
| Тег | `<sf-file-upload>` |
| Назначение | Smart-компонент File Upload из SIMAI Framework. |
| Контракт | `smart.file-upload`, версия `1.0.0` |
| Поставка | выпуск Framework `ui-6d2bf151e3c8` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |
| Готовность | описан: манифест и сценарий есть, продуктовой приёмки нет |

### Атрибуты

- `template` — `string`, по умолчанию `default`, значения: `default`.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`.
- `icon` — `string`, по умолчанию `upload_file`.
- `link-text` — `string`, по умолчанию `Click to upload`.
- `text` — `string`, по умолчанию `or drag and drop`.
- `formats` — `string`, по умолчанию пусто. Строка форматов под действием. Если не задана, выводится из `accept`; пуста, если не задано ни то ни другое: компонент не называет форматы, которые не может знать.
- `supporting-text` — `string`, по умолчанию пусто. Вспомогательная строка; по умолчанию берётся из formats.
- `accept` — `string`, по умолчанию пусто.
- `multiple` — `boolean`, по умолчанию `false`.
- `disabled` — `boolean`, по умолчанию `false`.
- `aria-label` — `string`, по умолчанию пусто.

Прежние имена:

| Имя | Прежнее имя | Состояние | Убирается после |
|:---|:---|:---|:---|
| `size="1/2"` | `size="1/3"` | работает и предупреждает | 2026-12-01 |
| `size="2"` | `size="3"` | работает и предупреждает | 2026-12-01 |

- `getItems()`

- `setItems()`
- `clear()`

### События

Все события приходят на сам элемент, всплывают и проходят границу Shadow DOM. Общие события базового элемента описаны в разделе [Загрузка и готовность](/ru/guide/smart-components/lifecycle/).

- `change` — `detail` не описан. Файлы выбраны; нативное событие всплывает от внутреннего поля ввода файла.
- `sf-file-upload:select` — `detail` не описан. Выбраны файлы для загрузки.
- `sf-file-upload:file-add` — `detail` не описан. Файл добавлен в список.
- `sf-file-upload:file-error` — `detail` не описан. Ошибка загрузки файла.
- `sf-file-upload:file-complete` — `detail` не описан. Файл загружен.
- `sf-file-upload:complete` — `detail` не описан. Все файлы обработаны.
- `sf-file-upload:remove` — `detail` не описан. Файл удалён из списка.
- `sf-file-upload:retry` — `detail` не описан. Повторена загрузка файла с ошибкой.

### Доступность

- Роль: кнопка (`button`).
- Доступное имя: рекомендуется.
- Клавиши: `Tab`, `Enter`, `Space`.
- Фокус: Включённая зона перетаскивания владеет фокусом выбора файлов; вложенные действия над файлами сохраняют нативную активацию. Используйте focus-visible и настоящий контур в режиме forced colors. Отключённые элементы управления выходят из порядка табуляции; повторное включение восстанавливает заданный tabindex.
