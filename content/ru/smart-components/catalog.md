# Каталог Smart Components

## Типы

- **Smart-компонент** добавляет состояние и интерактивное поведение базовому
  компоненту.
- **Комплексный Smart-компонент** объединяет несколько компонентов и
  Smart-компонентов в законченный пользовательский сценарий.

Тип берётся из `kind` закреплённого source manifest. В опубликованном справочнике
как комплексный сейчас представлен
[Admin Menu](/ru/smart-components/reference/admin-menu/).
Его низкоуровневый `component.admin-menu` является внутренней визуальной
зависимостью и поэтому не показывается в каталоге базовых компонентов.

| Статус | Количество | Значение |
|:---|---:|:---|
| Готов к использованию | 7 | Контракт прошёл текущую продуктовую приёмку |
| Доступен для проверки | 34 | Loader зарегистрирован, требуется сценарная приёмка |
| Заблокирован | 9 | Исходники есть, но Loader-правило отсутствует |

Готовы: `buttons`, `datepicker`, `icon-buttons`, `icons`, `inputs`, `pagination`
и `table`.

Заблокированы: `drawer`, `editor`, `fab`, `file-preview`, `flags`, `form`,
`link`, `list` и `rating`. Их страницы опубликованы для прозрачности API и
исходников, но до добавления Loader-правил эти элементы нельзя рекомендовать
как штатно подключаемые.

[Полный справочник](/ru/smart-components/reference/) содержит все 50 записей и
для каждой показывает теги, Loader-статус, зависимости, поставляемые ассеты,
атрибуты, свойства, методы и события. Каталог генерируется из закреплённой пары
UI и Smart-исходников.
