# Системная полоса

Есть состояния, которые важны на любой странице продукта: лицензия
кончается, диск почти заполнен, сайт клиента не отвечает, ночью плановые
работы. О них говорит полоса над шапкой. Она показывает самое серьёзное
сообщение, ведёт к исправлению одной кнопкой, а остальные сообщения
открывает списком «Ещё N». Полоса стоит, пока жива причина.

## Пример

Выберите, что прислал сервер: полоса покажет самое серьёзное сообщение и
перекрасится по нему. «Ещё 3» открывает остальные, «Прочитано» убирает
предупреждение.

:::

## Когда брать

| Что случилось | Где сказать |
|:---|:---|
| Касается всего продукта или сервера и требует действия: лицензия, диск, сайт не отвечает | Полоса над шапкой |
| Касается одной страницы или раздела: раздел только для чтения, фильтр скрыл записи | [Уведомление](/ru/smart/feedback/alert/) в начале страницы |
| Ответ на нажатие человека: сохранено, не отправлено | [Всплывающее сообщение](/ru/smart/feedback/toast/) |
| Что было за день, кто что сделал | Центр уведомлений в меню админки |

Полоса живёт, пока живёт причина: диск заполнен — полоса стоит. Согласие на
cookie в полосу не кладут. Как выбрать между всеми местами для сообщения —
в рецепте [Какое сообщение выбрать](/ru/recipes/which-message/).

## Варианты

### Плановые работы

О плановых работах предупреждают заранее, сведениями. После «Прочитано»
полоса скрывается на сутки, а за час до начала работ возвращается сама и
больше не скрывается. Нажмите «Прочитано», затем переведите часы.

## Состояния

Каждое состояние — та же полоса с другим списком. Пока сервер не прислал
список, полосы нет: она встаёт над шапкой и не сдвигает то, что под ней.

- **Всё в порядке.** Список пуст — полосы нет, места она не занимает.
  Отдельного «всё хорошо» не показывают.
- **Первый кадр.** Сервер печатает список в странице, поэтому полоса есть
  сразу. Если список приходит позже, полоса появляется и объявляется
  голосом.
- **Не удалось узнать состояние.** Полосу не рисуют: сбой загрузки — не
  состояние продукта. Запись — в журнал страницы.

| Отметка | «Прочитано» | «Отметить, что видели» |

## Из чего собрано

| Часть | Компонент | Как задано |
|:---|:---|:---|
| Полоса над шапкой во всю ширину, сильная заливка | [Системная полоса](/ru/smart/feedback/alert-bar/) | `size="1/2"` в админке, `size="1"` на сайте; `label` — имя области |
| Самое серьёзное сообщение первым | [Системная полоса](/ru/smart/feedback/alert-bar/) | `items[].level`: `error` → `warning` → `info`, новое первым по `time` |
| Кнопка действия и «Прочитано» | [Системная полоса](/ru/smart/feedback/alert-bar/) | `action: {label, href}`, `acknowledge: {label: 'Прочитано'}`; кнопки пониженной высоты |
| «Ещё N» | [Системная полоса](/ru/smart/feedback/alert-bar/) | появляется сама, когда сообщений больше одного |
| Ошибку нельзя скрыть | [Системная полоса](/ru/smart/feedback/alert-bar/) | у `level: 'error'` нет «Прочитано» и крестика, только «Свернуть» |
| Скрыть плановые работы на сутки | страница | по `sf-alert-bar-acknowledge` запомнить срок: сутки, но не позже часа до начала |
| Переключатель в примере | [Сегментный переключатель](/ru/smart/actions/segmented/) | только для показа состояний |

## Доступность

- Полоса — область с именем «Важные уведомления» (`label`). При загрузке
  страницы она не читается.
- Появившееся позже объявляется: новая ошибка — сразу, остальное —
  вежливо. Фокус полоса не забирает.
- Путь клавиатуры: кнопка действия → «Прочитано» → «Ещё N» → «Свернуть».
  Enter и пробел нажимают; Esc закрывает список «Ещё N» и возвращает фокус
  на кнопку.
- Уровень читается словом («Ошибка», «Предупреждение»), а не только цветом.

## Как делать

- **Одна полоса на продукт.** Несколько сообщений — одна полоса с самым
  серьёзным и «Ещё N», а не стопка полос.
- **Полоса — не ответ на нажатие.** «Сохранено» и «Не отправлено» —
  всплывающим сообщением; полоса только о состоянии продукта.
- **Ошибку не прячут.** Пока диск заполнен, полоса стоит; её можно только
  свернуть.

## Копия для ИИ

```html
<!-- Рецепт SIMAI Framework «Системная полоса», выпуск ui-994f9db407fa.
Правила:
1. sf-alert-bar — только состояние всего продукта, требующее действия; стоит, пока жива причина. Страница — sf-alert, ответ на нажатие — sf-toast.
2. Одна полоса над шапкой; size="1/2" в админке, size="1" на сайте; label="Важные уведомления".
3. items: {id, level: error|warning|info, text, source, time, action: {label, href}, acknowledge: {label: 'Прочитано'}}. Первым — самое серьёзное, остальные в «Ещё N».
4. У ошибки нет acknowledge: её можно только свернуть.
5. Плановые работы: по sf-alert-bar-acknowledge скрыть до min(сейчас + 24 ч, начало − 1 ч); с часа до начала — показывать без acknowledge.
6. Текст — что случилось и чем грозит; кнопка — глагол действия. Без «!» и кодов ошибок. -->
<sf-alert-bar id="system-bar" size="1/2" label="Важные уведомления"></sf-alert-bar>
<script type="module">
  const HOUR = 3600000;
  const bar = document.querySelector('#system-bar');
  const start = Date.parse('2026-11-16T02:00:00+03:00');
  const hiddenUntil = Number(localStorage.getItem('work-hidden-until') || 0);
  const soon = Date.now() >= start - HOUR;
  const work = {id: 'work', level: 'info', text: '16 ноября с 02:00 до 03:00 МСК плановые работы: панель будет недоступна.'};
  bar.items = [
    {id: 'disk', level: 'error', text: 'Диск заполнен на 98 %: сайты перестанут сохранять файлы и базы.', source: 'Сервер', action: {label: 'Освободить место', href: '/server/disk'}},
    {id: 'licence', level: 'warning', text: 'Лицензия SIMAI Pro заканчивается 30 ноября.', action: {label: 'Продлить', href: '/licence'}, acknowledge: {label: 'Прочитано'}},
    ...(soon ? [work] : Date.now() >= hiddenUntil ? [{...work, acknowledge: {label: 'Прочитано'}}] : []),
  ];
  bar.addEventListener('sf-alert-bar-acknowledge', (event) => {
    if (event.detail?.id === 'work') localStorage.setItem('work-hidden-until', String(Math.min(Date.now() + 24 * HOUR, start - HOUR)));
  });
</script>
```

## Где используется

- Панель сервера SIMAI Pro — лицензия, диск, сайт не отвечает.
- Админка Larena — лицензия, пробный период, плановые работы.
- Сайты клиентов — обслуживание и отключение, `size="1"`.

## Что ещё в пути

> **Так и останется.** Список «Ещё N» раскрывается под полосой, в потоке
> страницы, и сдвигает её вниз — так он и останется. Панель поверх
> страницы — это центр уведомлений, другой инструмент: его берут, когда
> событий много и их читают позже.
