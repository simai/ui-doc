# Первый кадр страницы

Страница админки, почты или чата открывается за доли секунды или за
несколько секунд — по сети и по объёму. Человек должен сразу видеть, где
что будет, а не белый экран, и не терять место, на которое уже смотрит.
Меню печатает сервер — оно есть в первом кадре. Список и плитки стоят
скелетами ровно на месте будущих данных. Кнопка, которая обновляет данные,
показывает работу сама.

## Пример

Выберите скорость сети: пример повторит загрузку раздела «Новости».
Меню на месте с первого кадра, скелеты списка и плиток заменяются
данными без прыжков. «Обновить» показывает работу на самой кнопке.

## Когда брать

| Если | Так |
|:---|:---|
| Известна форма будущих данных: строки, плитки, карточки | Скелет на их месте |
| Загрузка иногда дольше 0,3 секунды | Скелет с первого кадра |
| Данные приходят частями | Каждая часть заменяет свой скелет |
| Меню и шапку печатает сервер | Без скелета: они есть в первом кадре |
| Кнопка запустила действие | Работа на кнопке — `loading` |
| Малое место без формы: значок файла, строка «Готовим файл…» | Спиннер с подписью |

Никогда — спиннер на всю страницу или раздел: форма страницы не видна,
после загрузки всё прыгает, и человек не знает, сколько ждать.

Если загрузка дольше 10 секунд, под скелетом появляется строка о том, что
происходит: «Загружаем 12 400 записей, это займёт около минуты».

## На телефоне

Меню уходит в кнопку, список занимает всю ширину; скелет тот же. Откройте
пример во весь экран и выберите ширину телефона.

## Плотность

В админке список — в компактной плотности: скелет берёт ту же высоту
строк, что и данные, и уменьшается вместе с ними.

:::example {id="recipes/first-paint/density" label="Плотность" preview=sandbox}
:::

## Тексты

- Скелет ничего не пишет: «Загрузка…» не нужна, форма говорит сама.
- Спиннер отдельно — с подписью мелким текстом цвета пояснения: «Готовим
  файл…».
- Долго, больше 10 секунд, — строка под скелетом: «Загружаем 12 400
  записей, это займёт около минуты».

## Из чего собрано

| Часть | Компонент | Как задано |
|:---|:---|:---|
| Меню | [Меню](/ru/smart/navigation/menu/) | печатает сервер в первом кадре; скелетом не рисуется |
| Скелет списка — сам список в загрузке | [Список](/ru/smart/content/list/) | `loading`; данные — `items`, затем снять `loading` |
| Скелет плитки — одна фигура размером с плитку | [Скелет](/ru/smart/feedback/skeleton/) | `kind="rounded"`, `width="100%"`, `height` — высота плитки (`var(--sf-e1)`) |
| Пульс | [Скелет](/ru/smart/feedback/skeleton/) | `animation="pulse"` (по умолчанию) |
| Кнопка в работе | [Кнопка](/ru/smart/actions/buttons/) | `loading` |
| Спиннер в малом месте | [Спиннер](/ru/smart/feedback/spinner/) | `size="1/2"`, `label` и подпись рядом |
| Пусто и ошибка | [Пустое состояние](/ru/smart/feedback/empty-state/) | `kind="first-use"`, `kind="error"` |

## Доступность

- Область, которая грузится, отмечена как занятая; скелет скрыт от
  чтения.
- Когда данные пришли, ничего не объявляется, фокус остаётся, где был.
- Кнопка в работе объявляет, что идёт работа; спиннер — область статуса с
  подписью.
- При «меньше движения» в системе пульс останавливается.

## Как делать

:::example {id="recipes/first-paint/do-dont" label="Как делать" preview=sandbox}
:::

- **Скелет — ровно место данных.** Сколько строк и какой высоты придёт,
  столько и стоит в скелете.
- **Меню не грузят скелетом.** Сервер печатает его сразу; скелет строками
  — только для меню, которое приходит отдельным запросом.
- **Работа кнопки — на кнопке.** Не всплывающее «Обновляем…» и не спиннер
  рядом.

## Копия для ИИ

```html
<!-- Рецепт SIMAI Framework «Первый кадр страницы», выпуск ui-994f9db407fa.
Правила:
1. Меню и шапку печатает сервер в первом кадре; скелетом меню не рисовать.
2. Список — sf-list loading с первого кадра; данные — items, затем снять loading.
3. Плитки и карточки — sf-skeleton kind="rounded" width="100%" height="var(--sf-e1)" на месте каждой плитки; область с aria-busy="true", скелет aria-hidden.
4. Действие кнопки — sf-button loading. sf-spinner с подписью — только в малом месте без формы. Никогда спиннер на всю страницу или раздел.
5. Дольше 10 секунд — строка под скелетом, что происходит и сколько ждать. -->
<sf-menu label="Разделы админки" appearance="navigation" current="news"></sf-menu>
<div id="tiles" aria-busy="true">
  <div class="news-tile" aria-hidden="true">
    <sf-skeleton kind="text" size="2" width="40%"></sf-skeleton>
    <sf-skeleton kind="text" size="1/2" width="70%"></sf-skeleton>
  </div>
</div>
<sf-list id="news" loading label="Новости"></sf-list>
<script type="module">
  const news = document.querySelector('#news');
  const answer = await fetch('/api/news').then((response) => response.json());
  news.items = answer.items;
  news.removeAttribute('loading');
</script>
```

## Где используется

- Админка Larena — разделы, списки, обзор.
- Почта и чат SIMAI Pro — список писем и диалогов.

## Что ещё в пути

> **Что ещё в пути.** В следующей версии SIMAI Framework список в загрузке
> будет рисовать скелет ровно по форме строк — с местом значка и второй
> строкой. Сейчас список в загрузке чуть ниже, чем строки с данными.
