# Долгая операция

Работа на сервере идёт от минуты до часов: импорт товаров, резервная копия,
создание сайта, сборка документации, рассылка. Человек должен видеть, что
она идёт и не зависла, знать, сколько осталось, уйти со страницы и
вернуться, поставить на паузу там, где это правда возможно. В конце — итог
честно: «с ошибками» — не успех, первые ошибки сразу и полный отчёт.

## Пример

Выберите, что происходит. Кнопки в карточке настоящие, и страница отвечает
на них, как ответит сервер: «Пауза» ставит паузу, «Свернуть» уводит ход в
панель в углу экрана, «Отменить» останавливает.

## Когда брать

| Если | Так |
|:---|:---|
| Работа на сервере, от секунд до часов, с шагами или «N из M» | Этот рецепт: [Ход выполнения](/ru/smart/feedback/progress-run/) на странице работы |
| Человек ушёл с этой страницы, а работа идёт дальше | «Свернуть» — ход переходит в панель в углу экрана (`look="notice"`); в конце — всплывающее сообщение, которое называет работу |
| Несколько работ в таблице: копии, рассылки | `look="row"` в ячейке строки — тонкая полоса и «62 % · 3 мин» |
| Работа мешает всему продукту: обслуживание, обновление | Ещё и [полоса над шапкой](/ru/smart/feedback/alert-bar/) с кнопкой «Подробнее» |
| Объём работы ещё неизвестен | Тот же ход без `total`: полоса бежит, потом та же полоса заполняется |

Не берите этот рецепт, когда:

- загружаются файлы и доля каждого известна — это [Загрузка файлов с
  прогрессом](/ru/recipes/progress/file-upload-progress/);
- шаги делает сам человек по порядку — это [Шаги](/ru/smart/navigation/steps/);
- задачи человека идут в любом порядке — это [Первые
  шаги](/ru/recipes/progress/onboarding-checklist/);
- результат готовится пару минут и шагов не видно — это пустое состояние
  «готовится» из [Пустого раздела](/ru/recipes/progress/empty-state/);
- кнопка работает одну-три секунды — ей хватит своего `loading`.

Блокирующее окно поверх страницы, «только процент» без «N из M» и
отдельные значки состояния рядом с карточкой не берите: ход и так говорит,
что происходит.

## Состояния

Каждое состояние — тот же компонент. Сервер печатает карточку сразу с
шагами и кнопками, и она держит высоту: отдельная заготовка загрузки не
нужна.

:::example {id="recipes/long-job/states" label="Состояния" preview=sandbox}
:::

Пока связи нет, «Пауза» и «Отменить» не работают: команда не дойдёт до
сервера. Последний ход остаётся на экране, сверху — что проверить.

## На телефоне

Карточка занимает всю ширину колонки, кнопки переносятся строкой под ход.
Панель «в углу» на телефоне становится панелью внизу почти во всю ширину.
Имена файлов переносятся целиком, а не посреди слова. Откройте пример во
весь экран и выберите ширину телефона.

## Плотность

В админке ход — в компактной плотности: `data-sf-density="compact"` на
корне экрана опускает текст, строки шагов и промежутки на ступень. Слева
обычная, справа компактная — тот же компонент.

## Тексты

| Где | Так | Не так |
|:---|:---|:---|
| Заголовок | Работа и её предмет: «Импорт товаров из «Прайс_ноябрь.xlsx»», «Резервная копия shop.test» | «Операция», «Задача №4812», «Пожалуйста, подождите» |
| Ход | «4 812 из 12 000 товаров · 40 %», «осталось ≈ 6 мин» | только «40 %»; «осталось 5 мин 47 с» |
| Итог с ошибками | «18 строк не загружены — исправьте их и повторите неудачные» | «Успешно завершено» при ошибках |
| Неудача | Причина и что сделать: «Не хватает места на диске: освободите 2 ГБ и повторите» | «Ошибка 500», «Что-то пошло не так» |
| Сообщение в конце | Называет работу: «Импорт товаров: готово с ошибками» | «Готово» |

## Из чего собрано

| Часть | Компонент | Как задано |
|:---|:---|:---|
| Заголовок и подпись | [Ход выполнения](/ru/smart/feedback/progress-run/) | `label` — работа словами человека, `caption` — где и когда, `heading-level` — уровень в оглавлении |
| Полоса, «N из M · %», «осталось ≈» | [Ход выполнения](/ru/smart/feedback/progress-run/) | `value`, `total`, `unit` (формы через `\|`), `remaining` в миллисекундах или расчёт по скорости |
| Счётчики одной строкой | [Ход выполнения](/ru/smart/feedback/progress-run/) | свойство `counters`: `{id, label, value, status, zero}` |
| Шаги и журнал шага | [Ход выполнения](/ru/smart/feedback/progress-run/) | свойство `steps`; метод `step({id, state, value})`, журнал — `chunk({text, step})` |
| Пауза, отмена, свернуть | [Ход выполнения](/ru/smart/feedback/progress-run/) | `pausable` — только где работа правда встаёт; `cancelable`, `minimizable` |
| Итог: результат, первые ошибки, отчёт | [Ход выполнения](/ru/smart/feedback/progress-run/) | `run-state`, `result-text`, `errors`, `errors-total`, `retryable`, `hideable`; событие `sf-progress-run-report` |
| Панель в углу | правило страницы | `look="notice"` в своём контейнере у края экрана; «Свернуть» и «Развернуть» меняют вид |
| Сообщение в конце | [`SF.notify`](/ru/guide/functions/actions/notify/) | `status` по итогу; успех уходит сам, «с ошибками» и ошибка ждут, пока их закроют |

Панель в углу — сборка страницы, а не часть SIMAI Framework: место, тень
и стопку из нескольких работ решает продукт.

## Доступность

- Карточка — область с именем из `label`; заголовок — настоящий заголовок
  уровня `heading-level`, он есть в оглавлении страницы.
- Полоса — индикатор хода с именем работы; на паузе диктор слышит «на
  паузе»; пока объём неизвестен, значения у полосы нет.
- Смену состояния — пауза, готово, с ошибками, не удалось — страница
  объявляет своей вежливой областью (`role="status"`), как в примере.
  Проценты на каждом шаге не объявляются.
- Журнал шага читается по запросу и сам не говорит.
- Путь клавиатуры: заголовок → «Пауза» → «Отменить» → «Свернуть» →
  «Вывод». После «Свернуть» фокус переходит на «Развернуть» в панели в
  углу; это делает страница.
- Состояние читается словом, а не только цветом полосы; «с ошибками» —
  цвет предупреждения, зелёный — только при настоящем успехе.

## Как делать

:::example {id="recipes/long-job/do-dont" label="Как делать"}
:::

- **Итог — честный.** «С ошибками» — предупреждение с числом ошибок,
  первыми из них и «Повторить неудачные», а не зелёное «Готово».
- **Пауза — только настоящая.** Кнопку «Пауза» ставьте, где сервер правда
  останавливает работу; иначе её нажмут и будут ждать зря.
- **Человек не заперт.** Работа идёт без него: свернуть в угол, уйти со
  страницы, вернуться. Окно поверх страницы, которое не даёт работать, не
  нужно.

## Копия для ИИ

Скопируйте блок целиком: в нём разметка хода и правила, по которым его
собирают.

```html
<!-- Рецепт SIMAI Framework «Долгая операция», выпуск ui-1ed6b6c9a040.
Правила:
1. Работа на сервере — sf-progress-run на странице работы: label — работа словами человека, caption — где и когда.
2. Ход: value и total в единицах работы, unit — формы через «|»; remaining в мс или расчёт по скорости. Объём неизвестен — без total: полоса бежит, потом та же полоса заполняется.
3. Шаги — свойство steps {id, title, state waiting|running|done|failed|skipped}; один шаг меняет метод step({id, state, value}).
4. pausable — только где сервер правда ставит работу на паузу; cancelable, minimizable; события sf-progress-run-pause/-resume/-cancel — просьбы: run-state ставит страница.
5. Итог: run-state done|partial|failed|cancelled; «с ошибками» — partial с errors (первые 5), errors-total и retryable, не done.
6. «Свернуть» (sf-progress-run-minimize) — страница показывает look="notice" в своей панели в углу; «Развернуть» (sf-progress-run-expand) — обратно. Панель в углу — сборка страницы.
7. В конце, если человек ушёл со страницы, — SF.notify, который называет работу; успех уходит сам, «с ошибками» и ошибка ждут закрытия.
8. Смену состояния страница объявляет своей областью role="status". Админка — data-sf-density="compact". -->
<div data-sf-density="compact">
  <sf-progress-run id="import-run" label="Импорт товаров из «Прайс_ноябрь.xlsx»" caption="Каталог «Электроника» · запущено в 14:02"
    value="4812" total="12000" unit="товар|товара|товаров" cancelable pausable minimizable retryable hideable>
    <script type="application/json" data-sf-settings>
      {"steps": [
        {"id": "read", "title": "Чтение файла", "state": "done", "duration": 8200},
        {"id": "write", "title": "Запись товаров", "state": "running"},
        {"id": "images", "title": "Картинки", "state": "waiting"}
      ],
      "counters": [
        {"id": "added", "label": "Добавлено", "value": 3610},
        {"id": "updated", "label": "Обновлено", "value": 1202},
        {"id": "errors", "label": "{n} ошибка|{n} ошибки|{n} ошибок", "value": 0, "status": "error", "zero": "ошибок нет"}
      ]}
    </script>
  </sf-progress-run>
  <p class="sr-only" role="status" id="import-live"></p>
</div>
<script type="module">
  const run = document.querySelector('#import-run');
  const live = document.querySelector('#import-live');
  run.addEventListener('sf-progress-run-pause', async () => { await api.pause(); run.setAttribute('run-state', 'paused'); live.textContent = 'Импорт на паузе'; });
  run.addEventListener('sf-progress-run-resume', async () => { await api.resume(); run.setAttribute('run-state', 'running'); });
  run.addEventListener('sf-progress-run-cancel', async () => { await api.cancel(); run.setAttribute('run-state', 'cancelled'); });
  run.addEventListener('sf-progress-run-minimize', () => run.setAttribute('look', 'notice')); // страница переносит его в свою панель в углу
  run.addEventListener('sf-progress-run-expand', () => run.setAttribute('look', 'full'));
  api.onProgress((p) => { run.setAttribute('value', String(p.done)); run.step({id: 'write', state: 'running', value: p.done, total: p.total}); });
</script>
```

| Продукт | Экран |
|:---|:---|
