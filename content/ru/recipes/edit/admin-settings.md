# Страница настроек админки

Раздел настроек сайта в админке Larena или Pro. Каждый раздел — своя
страница: в меню разделы стоят строками колонки «Сайт», на странице —
одна форма `sf-form` и одна полоса «Сохранить / Отмена» внизу. Форма сама
показывает, откуда значение, занимает «Сохранить» на время сохранения,
пишет «Сохранено в 14:35» и спрашивает «Уйти без сохранения?», если
человек уходит с несохранёнными правками.

## Пример

Смените часовой пояс: под полем появится «Своё для simai.ru · у всех
сайтов: Москва, UTC+3» и «Вернуть общее». Язык закрыт выше — под полем
причина. Включите режим обслуживания и нажмите «Сохранить»: страница
спросит, что это изменит. «Посмотреть» в полосе сверху показывает, что
увидят посетители, «Опубликовать» — публикует.

## Когда брать

- Настройки уровня: сайт берёт значение «Все сайты», пока не задаст своё.
- Изменения сохраняют вместе, одной кнопкой; у части значений есть
  последствия, о которых нужно спросить.

Настройки вида экрана — плотность, колонки — открывайте
[Меню настроек](/ru/smart/navigation/settings/). Личные настройки
человека — в рецепте [Профиль](/ru/recipes/edit/profile/).

## Откуда значение

Помечаются только два случая — строкой под полем:

- **своё значение сайта** — «Своё для simai.ru · у всех сайтов: Москва,
  UTC+3» и тихая кнопка «Вернуть общее»: она ставит общее значение и
  отправляет `sf-form-reset-field` (страница может отменить);
- **закрыто выше** — поле только для чтения, под ним причина: «Закрыто на
  уровне «Все сайты»: менять может администратор установки».

Значение, взятое сверху, ничем не помечено — так страница не пестрит. Над
формой одна строка уровня: «Изменения — для сайта simai.ru». Слова строки
даёт настройка `origin` формы, уровень поля — `origin` описания поля:
`{value}` — общее значение, `{locked, reason}` — закрыто.

## Сохранение

- «Сохранить» стоит в липкой полосе внизу формы (`footer="sticky"`), одна на
  страницу.
- Страница забирает сохранение (`preventDefault()` у `sf-form-submit`) и
  ставит `busy`: «Сохранить» показывает загрузку, «Отмена» ждёт, поля только
  для чтения. В событии — `value` и `inherited`, ключи полей со значением
  сверху.
- Ответ сервера: `saved()` — «Сохранено в 14:35» в строке состояния до
  следующей правки; ошибки полей — `setErrors({errors})`; нет связи —
  `busy = false` и уведомление с «Повторить», правки остаются в форме.
- Опасное значение (режим обслуживания, отключение кода для входа)
  спрашивает перед сохранением: окно-вопрос `sf-modal size="question"` с
  `sf-confirm status="danger"`, последствие словами, «Сохранить» и «Отмена».

## Публикация

Изменения, которые видят посетители, сначала видят только администраторы.
Пока они не опубликованы, сверху стоит пункт [Полосы состояний](/ru/smart/feedback/alert-bar/):
текст, «Посмотреть» (окно с [Подтверждением изменения](/ru/smart/actions/confirm-change/),
«было → станет») и «Опубликовать».

## Уход без сохранения

С `guard` форма сама спрашивает «Уйти без сохранения?», когда человек
нажимает ссылку меню или пути, а в форме есть несохранённые правки:
«Не сохранять» (красная) уводит и возвращает форму к сохранённому,
«Продолжить правку» (тихая, на ней фокус) оставляет. Закрытие вкладки
спрашивает браузер. Свой маршрутизатор спрашивает через `confirmLeave()`.

## Без права менять

Пункт полосы «Только чтение: …» и форма `readonly` с причиной
(`readonly-reason`): без «Изменить» и «Сохранить», значения как текст.

## Из чего собрано

| Часть | Компонент | Как задано |
|:---|:---|:---|
| Рамка админки | `sf-admin-shell` (пакет SIMAI Admin) | `width="read"`; разделы настроек — строки колонки «Сайт» в `sf-admin-menu` |
| Заголовок и путь | [Заголовок страницы](/ru/smart/composite/page-header/) | `heading` — название раздела; путь: сайт → «Настройки сайта» |
| Форма | [Форма](/ru/smart/forms/form/) | `labels="start"`, `footer="sticky"`, `guard`; `origin` — слова строки; у поля `origin: {value}` или `{locked, reason}`; адрес почты — `propertyType: "email"` |
| Опасное значение | [Модальное окно](/ru/smart/overlays/modal/), [Подтверждение](/ru/smart/actions/confirm/) | `size="question"`; `sf-confirm appearance="window" status="danger"` |
| Публикация | [Полоса состояний](/ru/smart/feedback/alert-bar/), [Подтверждение изменения](/ru/smart/actions/confirm-change/) | пункт `level: "info"`, `action` «Посмотреть», `acknowledge` «Опубликовать» |
| Нет связи | [Уведомление](/ru/smart/feedback/toast/) | `status="error"`, действие «Повторить» |

## Доступность

- Строка «откуда значение» — `role="status"`: появившись после правки, она
  звучит.
- Пока идёт сохранение, форма `aria-busy="true"`, «Сохранить» объявляет
  загрузку.
- В вопросе «Уйти без сохранения?» фокус на «Продолжить правку»: случайный
  Enter не теряет правки.
- Форма только для чтения говорит причину текстом, а не серыми полями.

## Копия для ИИ

```html
<!-- Рецепт SIMAI Framework «Страница настроек админки».
Правила:
1. Раздел настроек — своя страница: sf-admin-shell width="read", разделы — строки колонки «Сайт» в sf-admin-menu.
2. Одна sf-form на страницу: labels="start" footer="sticky" guard; слова уровня — origin {own, above}.
3. У поля со значением уровня выше — origin {value: <общее>}; закрытое выше — origin {locked: true, reason}.
4. sf-form-submit: preventDefault(), опасное значение — вопрос sf-modal size="question" + sf-confirm status="danger"; затем form.busy = true; ответ — form.saved() | form.setErrors({errors}) | form.busy = false и уведомление «Повторить».
5. Неопубликованное — пункт sf-alert-bar: action «Посмотреть» (sf-confirm-change в окне), acknowledge «Опубликовать».
6. Без права — пункт полосы и sf-form readonly readonly-reason="…". -->
<sf-form labels="start" footer="sticky" guard label="Основное">
  <script type="application/json" data-sf-settings>
    {"origin": {"own": "Своё для simai.ru", "above": "у всех сайтов"},
     "fields": [
       {"key": "name", "label": "Название сайта", "propertyType": "string", "required": true},
       {"key": "from", "label": "Адрес отправителя", "propertyType": "email", "required": true},
       {"key": "tz", "label": "Часовой пояс", "propertyType": "choice", "template": "dropdown",
        "options": [{"value": "msk", "label": "Москва, UTC+3"}, {"value": "ekb", "label": "Екатеринбург, UTC+5"}],
        "origin": {"value": "msk"}},
       {"key": "lang", "label": "Язык сайта", "propertyType": "choice", "template": "dropdown",
        "options": [{"value": "ru", "label": "Русский"}, {"value": "en", "label": "English"}],
        "origin": {"locked": true, "reason": "Закрыто на уровне «Все сайты»."}}],
     "value": {"name": "SIMAI", "from": "noreply@simai.ru", "tz": "ekb", "lang": "ru"}}
  </script>
</sf-form>
```
