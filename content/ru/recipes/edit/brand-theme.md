# Оформление: цвет и тема

Владелец сайта выбирает фирменный цвет и тему — светлую, тёмную или как
в системе — и сразу видит на образце, как будет выглядеть сайт. Сам сайт
меняется только по «Сохранить»: пока человек пробует цвета, посетители
видят прежние.

## Пример

Экран «Оформление» в админке Larena. Выберите «Логотип» — образец справа
окрасится сразу, светлый цвет получит тёмный текст. Под кнопками
появится напоминание, что сайт ещё не изменился. Нажмите «Сохранить».
Включите «Сервер ответит ошибкой», чтобы увидеть отказ.

## Когда брать

| Если | Так |
|:---|:---|
| Владелец сайта задаёт фирменный цвет и тему | Этот рецепт: экран «Оформление» с полем цвета, темой и образцом |
| Быстро выбрать цвет прямо в шапке | Кружок цвета `variant="theme"`: только цвет, без подписи и темы |
| Посетителю — тема и цвет для себя | [Меню настроек](/ru/smart/navigation/settings/) со строками «Тема» и «Цвет» |
| Цвет метки или серии графика | Обычное [Поле цвета](/ru/smart/forms/color/), не этот рецепт |

## На телефоне

Откройте первый пример в ширине телефона. Поле, тема и кнопки встают
столбиком, образец — под ними. Окно выбора цвета на телефоне открывается
листом снизу.

## Тексты

- Подписи — «Фирменный цвет» и «Тема сайта»; темы — «Светлая», «Тёмная»,
  «Как в системе».
- Готовые цвета названы: «Синий SIMAI», «Логотип».
- Пока не сохранено: «Есть несохранённые изменения: на сайте пока прежнее
  оформление».
- Сохранено: «Оформление сохранено: сайт обновлён».
- Отказ говорит, что видят посетители: «Сайт показывает прежние цвета —
  нажмите «Сохранить» ещё раз».

## Из чего собрано

| Часть | Компонент | Как задано |
|:---|:---|:---|
| Фирменный цвет | [Поле цвета](/ru/smart/forms/color/) | `variant="brand"`; `swatches` — цвета продукта; `target` — образец, тема строится на нём сразу; `clearable` — вернуть цвет SIMAI |
| Тема сайта | [Сегментный переключатель](/ru/smart/actions/segmented/) | «Светлая», «Тёмная», «Как в системе»; меняет только образец |
| Образец | разметка страницы | шапка на `--sf-brand` и `--sf-on-brand`, обложка и кнопки — цвета темы |
| Сохранить | [Кнопка](/ru/smart/actions/buttons/) | главная первой; «Вернуть цвет SIMAI» — `appearance="ghost"` `scheme="on-surface"`; при сохранении — `loading` |
| Напоминание и итог | строка с `role="status"` | под кнопками |
| Ошибка | [Сообщение](/ru/smart/feedback/alert/) | `status="error"` |

## Доступность

Путь с клавиатуры:

1. Tab: поле цвета — Enter открывает окно выбора; готовые цвета —
   стрелками, Enter выбирает; Escape закрывает окно и возвращает фокус.
2. Тема — одна остановка Tab, стрелки меняют вариант.
3. «Сохранить», «Вернуть цвет SIMAI». Напоминание и итог объявляются
   сами.

| Что | Что слышит человек с экранным диктором | Откуда |
|:---|:---|:---|
| Поле | «Фирменный цвет, Синий SIMAI» | `label`, название из `swatches` |
| Тема | «Тема сайта, Как в системе, выбрано» | `aria-labelledby` |
| Образец | «Образец сайта» | `aria-label` |
| Напоминание | «Есть несохранённые изменения…» | `role="status"` |

## Как делать

:::example {id="recipes/brand-theme/do-dont" label="Как делать" preview=sandbox}
:::

- **Образец — сразу, сайт — по «Сохранить».** Пока человек пробует
  цвета, посетители видят прежнее оформление.
- **Админка остаётся в своих цветах.** Тема ложится только на образец,
  чтобы кнопки админки не меняли цвет под рукой.
- **Цвет текста на фирменном цвете выбирает ядро.** Светлому цвету —
  тёмный текст, тёмному — белый.

## Копия для ИИ

```html
<!-- Рецепт SIMAI Framework «Оформление: цвет и тема», выпуск ui-1ed6b6c9a040.
Правила:
1. Фирменный цвет — sf-input-color variant="brand" с label, swatches (цвета продукта с названиями), target="#<образец>" и clearable.
2. Тема сайта — sf-segmented «Светлая / Тёмная / Как в системе» с подписью; меняет класс theme-dark / theme-light только у образца.
3. Образец меняется сразу; сам сайт — только по «Сохранить». Пока не сохранено — строка role="status" «Есть несохранённые изменения: на сайте пока прежнее оформление».
4. Шапка образца — на --sf-brand и --sf-on-brand; текст на фирменном цвете не задавать руками.
5. Кнопки: «Сохранить» первой (loading при сохранении), «Вернуть цвет SIMAI» — appearance="ghost" scheme="on-surface"; промежуток gap-1/3.
6. Ошибка — sf-alert status="error": выбранное остаётся, сайт прежний.
7. Админка — data-sf-density="compact"; её собственные цвета не меняются. -->
<div data-sf-density="compact">
  <sf-input-color variant="brand" label="Фирменный цвет" name="brand" value="#0b57d0" swatches="#0b57d0|Синий SIMAI, #e8a33d|Логотип" target="#sample" clearable></sf-input-color>
  <sf-segmented aria-label="Тема сайта" name="theme" value="system" items='[{"value":"light","label":"Светлая"},{"value":"dark","label":"Тёмная"},{"value":"system","label":"Как в системе"}]'></sf-segmented>
  <div class="flex flex-wrap gap-1/3">
    <sf-button text="Сохранить"></sf-button>
    <sf-button text="Вернуть цвет SIMAI" appearance="ghost" scheme="on-surface"></sf-button>
  </div>
  <p role="status"></p>
  <div id="sample" aria-label="Образец сайта">…</div>
</div>
```
