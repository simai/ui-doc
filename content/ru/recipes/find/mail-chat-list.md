# Список писем и диалогов

Входящие письма и беседы, разложенные по дням. Человек сразу видит, кто
писал, о чём, что не прочитано и что ждёт ответа. Внизу — «Показать
ещё», а пока список грузится, строки стоят заготовкой своего размера.

## Пример

Почта SIMAI. Нажмите на строку — письмо откроется справа, а число
непрочитанных у строки пропадёт. «Показать ещё» внизу подгрузит прошлую
неделю. «⋯» у строки открывает действия: «Прочитано», «В архив»,
«Удалить».

| Если | Так |

| Письма с колонками — рассылки, отчёты | Таблица; низ — рецепт «Низ списка» |

## На телефоне

Откройте первый пример в ширине телефона. Остаётся только список,
письмо открывается своей страницей. Строки не переносятся: длинная тема
обрезается, число непрочитанных стоит у края.

## Плотность

Почта и чат Pro на компьютере — компактные: строки ниже, аватар меньше,
текст мельче. На телефоне — обычная плотность.

## Тексты

- Первая строка — кто писал: имя человека или название компании.
- Вторая — тема и начало письма: «Договор поставки на декабрь — пришлю
  после обеда».
- Дни — словами: «Сегодня», «Вчера», дальше дата.
- Ждёт ответа — короткая метка «Ждёт».
- Пусто — «Во входящих пусто»; ошибка — «Не удалось загрузить письма.
  Сервер почты не ответил. Письма на месте».

## Из чего собрано

| Часть | Компонент | Как задано |
|:---|:---|:---|
| Список | [Список](/ru/smart/content/list/) | `group-by="day"`, `sticky-headings`, `no-wrap`; `selected` — открытое письмо |
| Аватар | [Аватар](/ru/smart/content/avatar/) | поле строки `avatar`: `{text: "АБ"}` — инициалы на оттенке, `{icon: "smart_toy"}` — бот, `shape: "square"` — компания или рассылка |
| Отправитель и тема | [Список](/ru/smart/content/list/) | `text` — отправитель, `supporting` — тема и начало письма |
| Непрочитанные | [Список](/ru/smart/content/list/) | `count` — число в конце строки; ждёт ответа — `badge` «Ждёт»; закреплённое — `pinned` |
| Действия строки | [Список](/ru/smart/content/list/) | `actions`: «Прочитано», «В архив», «Удалить» (`destructive`) |
| Показать ещё | [Список](/ru/smart/content/list/) | `has-more` и событие `sf-list-load-more` |
| Первый кадр | [Список](/ru/smart/content/list/) | `loading` — строки заготовкой |
| Переписка | [Лента](/ru/smart/content/list-feed/) | сообщения открытой беседы |

## Доступность

Путь с клавиатуры:

1. Список — одна остановка Tab; стрелки вверх и вниз — по строкам, Enter
   открывает письмо.
2. Shift+F10 или клавиша меню открывает действия строки; «⋯» — для мыши
   и касания.
3. По заголовкам дней «Сегодня», «Вчера» можно прыгать клавишей
   заголовков.
4. После «Показать ещё» фокус остаётся на месте, новые строки
   объявляются.

| Что | Что слышит человек с экранным диктором | Откуда |
|:---|:---|:---|
| Строка | «Анна Белова, Договор поставки на декабрь — пришлю после обеда, 3 непрочитанных» | `text`, `supporting`, `count` |
| Открытое письмо | «текущее» | `selected` |
| Подгрузка | «Загружено ещё 4 письма» | список |

## Как делать

:::example {id="recipes/mail-chat-list/do-dont" label="Как делать" preview=sandbox}
:::

- **Непрочитанное — полужирным именем отправителя.** Число в конце —
  только у бесед, где новых больше одного; цвет один не говорит.
- **Время — по дням.** Заголовки «Сегодня», «Вчера» заменяют дату в
  каждой строке.
- **Первый кадр — строки, а не крутилка.** Заготовка того же размера не
  сдвигает список, когда приходят письма.

## Копия для ИИ

```html
<!-- Рецепт SIMAI Framework «Список писем и диалогов», выпуск ui-994f9db407fa.
Правила:
1. Список писем и бесед — sf-list group-by="day" sticky-headings no-wrap; сообщения одной беседы — sf-list-feed, не этот список.
2. Строка: text — отправитель, supporting — тема и начало письма, date — время (идёт в группы по дням), avatar — {text: инициалы} или {icon, shape: "square"} для компаний и ботов.
3. Непрочитанное: полужирное имя отправителя; count — только у бесед, где новых больше одного. Ждёт ответа — badge {text: "Ждёт", tone: "warning"}; закреплённое — pinned.
4. Действия строки — actions: Прочитано, В архив, Удалить (destructive: true).
5. Подгрузка — has-more и sf-list-load-more; первый кадр — loading; пусто — empty-text; ошибка — sf-empty-state kind="error".
6. Почта и чат на компьютере — data-sf-density="compact"; на телефоне только список, письмо — своей страницей. -->
<div data-sf-density="compact">
  <sf-list id="inbox" label="Входящие" group-by="day" sticky-headings no-wrap has-more></sf-list>
</div>
<script>
  const inbox = document.getElementById('inbox');
  inbox.items = [
    {id: 'm2', text: 'Анна Белова', supporting: 'Договор поставки на декабрь — пришлю после обеда', avatar: {text: 'АБ'}, count: 3, date: '2026-11-15T11:20:00'},
    {id: 'm3', text: 'Ассистент Pro', supporting: 'Нужен ответ по заявке № 4417', avatar: {icon: 'smart_toy'}, badge: {text: 'Ждёт', tone: 'warning'}, date: '2026-11-15T09:05:00'}];
  inbox.actions = [{id: 'read', text: 'Прочитано', icon: 'drafts'}, {id: 'archive', text: 'В архив', icon: 'archive'}, {id: 'delete', text: 'Удалить', icon: 'delete', destructive: true}];
  inbox.addEventListener('sf-list-load-more', () => { /* подгрузить прошлые письма */ });
</script>
```
