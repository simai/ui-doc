# Низ списка

Под списком человек видит, сколько всего записей и где он сейчас, и
переходит дальше. Как переходить, зависит от списка: в админке — поле
номера страницы, в каталоге — номера-ссылки, в ленте — «Показать ещё».

## Пример

Заказы магазина в админке. Перейдите на другую страницу стрелкой или
впишите номер в поле. «По 20» меняет размер страницы и возвращает на
первую. Переключите вид над списком, чтобы сравнить низ каталога и ленты.

## Когда брать

| Список | Низ |
|:---|:---|
| Таблица или список в админке, число записей известно | Одна строка: «41–60 из 240 · По 20 ▾ · ‹ [3] из 12 ›», вид `field` |
| Каталог, поиск по сайту | Номера-ссылки `numbers`: ссылки `?page=` от сервера работают и без скрипта; до семи мест, на телефоне пять |
| Число страниц неизвестно | «Назад / Далее», вид `arrows`, `count-known="false"` и `has-next` |
| Сервер отдаёт страницы курсором, без последней | «В начало · Дальше», вид `cursor` |
| Лента, письма, комментарии | «Показать ещё», вид `more` — отдельно, не в одной строке со стрелками |
| Карточка записи или статья | Не низ списка, а [Соседний документ](/ru/smart/navigation/pager/): «‹ 3 из 240 ›» или «предыдущая / следующая» |

## На телефоне

Откройте пример в ширине телефона. Строка админки не помещается в одну
строку и встаёт в две: сверху диапазон «1–20 из 340» и «По 20», снизу
переход по страницам по центру. Номера каталога сокращаются до пяти мест,
«Показать ещё» стоит по центру.

## Тексты

- Диапазон — простой строкой: «41–60 из 240», без слова «Всего».
- Оценка — с тильдой: «~12 000»; точное число — по кнопке «Показать
  число».
- Размер страницы — «По 20», меню «По 10, По 20, По 50, По 100».
- Ошибка подгрузки называет, что не пришло: «Не удалось загрузить ещё 20
  писем», кнопка «Повторить».

## Из чего собрано

| Часть | Компонент | Как задано |
|:---|:---|:---|
| Диапазон | строка страницы | «41–60 из 240» тихим цветом, цифры одной ширины |
| Размер страницы | [Кнопка](/ru/smart/actions/buttons/) | `appearance="ghost"` `scheme="on-surface"` с `menu`; выбор — событие `sf-button-select`, страница возвращается на первую |
| Переход | [Пагинация](/ru/smart/navigation/pagination/) | `appearance` по списку, `total`, `page-size`, `current`; с заданным `appearance` пагинация рисует только переход — диапазон и размер страницы стоят рядом своими частями |
| Показать ещё | [Пагинация](/ru/smart/navigation/pagination/) | `appearance="more"`; пока грузится — `show-more-busy`; событие `sf-pagination-load-more` |
| Пусто | [Пустой раздел](/ru/smart/feedback/empty-state/) | `kind="nothing-found"`; низа нет |
| Строка на телефоне | правило страницы | переход — отдельной строкой по центру, `flex-basis: 100%` |

## Доступность

Путь с клавиатуры:

1. После последней строки списка: «По 20» — Enter открывает меню, стрелки
   и Enter выбирают; дальше «В начало», «Назад», поле страницы, «Далее»,
   «В конец».
2. В поле страницы — число и Enter. Неверное число возвращает текущую
   страницу.
3. После перехода фокус остаётся на нажатой кнопке; после «Показать ещё»
   — переходит на первую новую строку.

| Что | Что слышит человек с экранным диктором | Откуда |
|:---|:---|:---|
| Переход | навигация «Страницы заказов» | `aria-label` |
| Номер страницы | «Страница 5, текущая» | пагинация |
| Погасшая «Назад» | «Предыдущая страница, недоступно» | пагинация |
| Размер | «По 20, меню» | кнопка с `menu` |

## Как делать

:::example {id="recipes/list-bottom/do-dont" label="Как делать" preview=sandbox}
:::

- **Кнопки на краях гаснут, а не пропадают.** Ряд не меняет ширину, и
  палец не промахивается.
- **Пусто — без низа.** Диапазон «0 из 0» и погасшие стрелки ничего не
  говорят; пустое состояние говорит, что делать.
- **Номера каталога — ссылками.** Поисковики и люди без скрипта
  переходят по `?page=`.

## Где используется

| Продукт | Экран |
|:---|:---|
| Larena, админка | заказы, страницы, пользователи — поле страницы или курсор |
| Сайты и магазины на Larena и Битрикс | каталог и поиск — номера-ссылки |
| SIMAI Pro, почта и чат | список писем — «Показать ещё» |

## Что ещё в пути

В таблице [Представления данных](/ru/pro/admin/table/) низ одной строкой —
диапазон, размер и переход — рисует сама таблица. В простом списке его
собирают из частей, как на этой странице: пагинация отвечает только за
переход.

> **Появится в следующей версии.** Кнопки «В начало · Назад» и «Далее · В
> конец» у поля страницы получат промежуток, как у остальных кнопок;
> сейчас они стоят вплотную.
