# Панель над списком

Над длинным списком записей стоит одна панель. По ней человек находит
запись по названию, отбирает по условиям, выбирает колонки, возвращается к
своему сохранённому виду, переключает таблицу и список и создаёт запись.
Частое «Добавить товар» — одним нажатием, редкие «Добавить раздел» и
«Загрузить из файла» — в меню той же кнопки.

## Пример

Наберите в поиске «пуэр», откройте фильтр или колонки, выберите
сохранённый вид в кнопке «Все товары». Переключатель над примером
показывает, как панель и таблица выглядят в других состояниях.

:::example {id="recipes/list-toolbar/overview" label="Товары" preview=sandbox log="sf-button-select sf-settings-change sf-settings-reset sf-view-table-apply" log_console=true log_open=false}
:::

Таблица — компонент [Представление данных](/ru/pro/admin/table/) набора Pro:
своя панель у неё выключена (`toolbar="false"`), панель над ней собирает
страница.

## Когда брать

| Если | Так |
|:---|:---|
| Записей больше, чем помещается на экран, и их ищут | Поиск и фильтр |
| Человек возвращается к своим выборкам | Сохранённые виды — кнопка с меню после фильтра и колонок |
| Создают записи двух-трёх видов, один из них частый | «Добавить …» с меню |
| Записей до двадцати | Хватит поиска; фильтр и колонки лишние |
| Поиск по всему продукту | Поиск в шапке, не над списком |
| Выбраны строки | Вместо панели — строка выбора: [Выбор строк и общие действия](/ru/recipes/remove/bulk-actions/) |

## На телефоне

На телефоне — только список. Поиск занимает всю строку; фильтр, колонки и
«Добавить» — значками, их панели открываются шторкой снизу. Откройте пример
во весь экран и выберите ширину телефона.

## Тексты

- **Подсказка поиска** — по чему ищет: «Найти по названию или артикулу».
- **Главная кнопка** — что создаёт: «Добавить товар»; в меню — «Добавить
  раздел», «Загрузить из файла».
- **Сохранённый вид** — именем человека: «Мои черновики», «Нет на складе».
- **Пустой поиск** — что не нашлось и что сделать: «Ничего не нашлось.
  Уберите условие фильтра».

## Из чего собрано

| Часть | Компонент | Как задано |
|:---|:---|:---|
| Поиск — залитое поле | [Текстовое поле](/ru/smart/forms/inputs/) | `appearance="filled"` `icon-start="search"` `input-type="search"`, `aria-label` |
| Фильтр: «Применить (N)» и «Сбросить» | [Настройки](/ru/smart/navigation/settings/) | `look="panel"` `apply="button"`; кнопка внутри — вход |
| Колонки: отметка, порядок, закрепление, поиск; применяются сразу | [Настройки](/ru/smart/navigation/settings/) | `look="panel"` `search`, пункт `type: 'fields'` |
| Сохранённые виды — после фильтра и колонок | [Кнопка](/ru/smart/actions/buttons/) | `menu`; выбранный вид — в `text`; «Сохранить как вид…» последним |
| Таблица или список | [Сегментный переключатель](/ru/smart/actions/segmented/) | меняет `layout` таблицы; выбор хранится в виде |
| «Добавить товар» с меню | [Кнопка](/ru/smart/actions/buttons/) | `split`, `menu` — редкие действия |
| Таблица | [Представление данных](/ru/pro/admin/table/) | `toolbar="false"`, `quick-actions`, `row-actions-visible="hover"` |
| Промежутки | страница | кнопки группы через 8 (`gap-1/3`), группы через 16 (`gap-1`) |

## Доступность

- Поле поиска с именем «Поиск по товарам»; результат объявляется: «Найдено
  12 товаров».
- «Добавить товар» с меню — две остановки Tab: действие и стрелка меню;
  стрелка сообщает, что открывает меню.
- Переключатель вида — группа переключателей, стрелки ← →.
- Панели открываются кнопкой; Esc закрывает и возвращает фокус на кнопку.
- Путь клавиатуры: поиск → фильтр → колонки → виды → вид списка →
  «Добавить» → стрелка меню → таблица.

## Как делать

- **Одна главная кнопка на панели.** Остальные — с рамкой; редкое создание
  — в меню главной.
- **Виды — по имени.** Кнопка показывает имя текущего вида, а не «Виды».
- **Кнопки одной группы — через 8, группы — через 16.** Поиск, настройки
  списка и создание — три группы.

## Где используется

- Списки записей в админке Larena: товары, новости, страницы.
- Таблицы SIMAI Pro.

## Что ещё в пути

> **Что ещё в пути.** Меню действий строки сейчас открывается в компактной
> плотности, даже когда таблица в обычной; в следующей версии SIMAI
> Framework оно будет того же размера, что и таблица. Своя панель
> представления данных пока рисует поиск и настройки по-своему, поэтому в
> рецепте она выключена.
