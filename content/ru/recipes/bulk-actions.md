# Выбор строк и общие действия

В списке записей, в таблице или в письмах человек отмечает строки и
делает с ними одно действие: опубликовать, снять с публикации, удалить.
Как только выбрана хотя бы одна строка, панель над списком сменяется
строкой «Выбрано N» с действиями выбора. У самой строки — до трёх частых
значков и «⋯» для остального. Перед тем, что нельзя быстро вернуть, —
вопрос с залитой красной кнопкой; после — «Удалено 3 новости» с
«Отменить».

## Пример

Отметьте две-три новости: над таблицей появится строка «Выбрано N».
«Снять с публикации» — обратимо и без вопроса, «Удалить» спросит, а после
ответа покажет «Отменить».

:::example {id="recipes/bulk-actions/overview" label="Новости" preview=sandbox log="sf-view-table-select sf-confirm-answer sf-modal-closed" log_console=true log_open=false}

Таблица — компонент [Представление данных](/ru/pro/admin/table/) набора Pro.
Строку «Выбрано N» собирает страница по событию выбора.

## Когда брать

| Если | Так |
|:---|:---|
| Одно и то же делают с многими записями: опубликовать, перенести, удалить | Флажки строк и строка «Выбрано N» |
| Записей много и их выбирают поиском или фильтром | То же, «выбрать все» в шапке таблицы |
| У строки одно–три частых действия | Значки в строке, остальное — в «⋯» |
| Действие одно и всегда со всеми: «Очистить корзину» | Кнопка над списком, без выбора |
| Выбор — это ответ формы: кому отправить | Поле выбора, а не таблица |
| Личное и обратимое: свой вид, свой фильтр | Без вопроса, только «Вернуть» — [Удаление](/ru/recipes/delete/) |

## На телефоне

На телефоне — только список. Выбор — флажком или долгим нажатием; строка
«Выбрано N» встаёт над списком, действия уходят под неё. Вопрос — окном.

## Тексты

| Место | Так | Не так |
|:---|:---|:---|
| Строка выбора | «Выбрано 3» · «Снять выбор» | «3 элемента отмечено» |
| Вопрос | «Удалить 3 новости?» | «Вы уверены?» |
| Последствие | «Они пропадут с сайта и из поиска. Вернуть можно 30 дней из корзины.» | «Действие необратимо!» |
| Кнопка | «Удалить 3 новости» / «Отмена» | «Да» / «Нет» |
| После | «Удалено 3 новости» · «Отменить» | «Операция выполнена успешно» |

## Из чего собрано

| Часть | Компонент | Как задано |
|:---|:---|:---|
| Флажок строки и «выбрать все» в шапке | [Представление данных](/ru/pro/admin/table/) | выбор встроен; событие `sf-view-table-select` с `ids` |
| Строка «Выбрано N» на месте панели | страница | по `sf-view-table-select`: число, «Снять выбор», действия через 8 |
| Действия выбора — кнопки с рамкой; опасное последним | [Кнопка](/ru/smart/actions/buttons/) | `appearance="outline"` `scheme="on-surface"`; «Удалить» — `status="danger"` |
| У строки до трёх значков, остальное в «⋯» | [Представление данных](/ru/pro/admin/table/) | `quick-actions`, `row-actions-visible="always"` |
| Вопрос: залитая «Удалить», тихая «Отмена», фокус на «Отмене» | [Окно](/ru/smart/overlays/modal/) и [Подтверждение](/ru/smart/actions/confirm/) | `sf-modal size="question" initial-focus="safe"`, внутри `sf-confirm status="danger" destructive appearance="window"` |
| После — «Удалено N» с «Отменить» | [`SF.notify`](/ru/guide/functions/actions/notify/) | `action: {label: 'Отменить'}` |

## Доступность

- Таблица — одна остановка Tab: ↑↓ по строкам, пробел отмечает строку,
  Shift+F10 или клавиша меню открывают меню строки.
- Флажок строки читается с её названием: «Выбрать „Осенняя распродажа“».
- Число выбранных объявляется: «Выбрано 3».
- Вопрос: фокус на «Отмене», Enter и пробел не удаляют, Esc — отмена;
  после ответа фокус возвращается на кнопку действия.

## Как делать

- **Действия выбора — с рамкой, не залитые.** Залитая главная кнопка на
  экране одна; «Удалить» — с рамкой опасного цвета и последней.
- **Вопрос называет, что удалится.** «Удалить 3 новости?» и «Удалить
  3 новости» на кнопке, а не «Вы уверены?» и «Да».
- **После действия выбор снимается.** Строка «Выбрано N» уходит, панель
  возвращается.

## Копия для ИИ

```html
<!-- Рецепт SIMAI Framework «Выбор строк и общие действия», выпуск ui-994f9db407fa.
Правила:
1. Таблица Pro sf-view-table toolbar="false" quick-actions="edit,view" row-actions-visible="always"; bulkActions не задавать — строку выбора собирает страница.
2. По sf-view-table-select (detail.ids): ids.length > 0 — панель над списком скрыть, показать строку «Выбрано N» · «Снять выбор» (ghost on-surface) и действия через 8: обычные — outline on-surface, «Удалить» — outline status="danger" последней.
3. Обратимое (снять с публикации) — без вопроса, SF.notify с «Вернуть».
4. Удаление — sf-modal size="question" initial-focus="safe" с sf-confirm status="danger" destructive appearance="window": question «Удалить N новостей?», consequence — что пропадёт и можно ли вернуть, accept-text «Удалить N новостей».

  <div class="flex items-cross-center gap-1/3"><span id="selected-count" class="weight-5" aria-live="polite"></span><sf-button appearance="ghost" scheme="on-surface" text="Снять выбор"></sf-button></div>
  <div class="flex flex-wrap gap-1/3">

  table.addEventListener('sf-view-table-select', (event) => {
```

## Где используется

- Списки записей в админке Larena: новости, товары, страницы.
- Таблицы SIMAI Pro.
- Письма в почте — архив, прочитано, удалить.

## Что ещё в пути

> **Что ещё в пути.** Строку «Выбрано N» представление данных будет
> рисовать само; пока её собирает страница, а свои действия выбора у
> таблицы не задают — они рисуются тремя залитыми кнопками. В отмеченном
> флажке строки сейчас не видна галочка. Одно меню строки для всех списков
> и клавиатура меню строки появятся в следующей версии SIMAI Framework.
