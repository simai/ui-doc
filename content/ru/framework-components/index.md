# Компоненты

В поставке `5.4.0` зарегистрировано **58 обычных компонентов**. Для каждого
сформирована source-backed страница с Loader-правилом, ассетами, зависимостями,
CSS-селекторами и переменными, исходным примером и требованиями доступности.

- [Архитектура и выбор](/ru/framework-components/introduction/) — границы компонентов,
  утилит и Smart Components.
- [Подключение](/ru/framework-components/connection/) — фактические пути и работа Loader.
- [Каталог](/ru/framework-components/catalog/) — состав и статусы текущей поставки.
- [Справочник](/ru/framework-components/reference/) — все 58 подробных страниц.
- [Примеры](/ru/framework-components/examples/) — как проверять сценарий в браузере.

Страница справочника является полным каталогом; вручную поддерживаемый
сокращённый список не используется, чтобы названия не расходились с Loader.
