# Слоты и порядок элементов

Слот — именованное место внутри элемента, куда разрешено помещать дочерние узлы. Список допустимых слотов задаёт тип. Порядок элементов внутри слота равен порядку в JSON-массиве, поэтому отдельное поле сортировки не требуется.

## Когда применять

Проверяйте слоты, когда элемент содержит несколько смысловых областей. Для простого контейнера обычно достаточно `default`; колонки используют область `columns`. Не придумывайте имя слота по виду HTML — сверяйтесь с manifest типа.

## Пример

```json
{
  "id": "grid",
  "type": "layout.columns",
  "props": {"columns": 2},
  "slots": {"columns": [
    {"id": "left", "type": "content.paragraph", "data": {"content": [{"type": "text", "value": "Фильтры"}]}},
    {"id": "right", "type": "content.paragraph", "data": {"content": [{"type": "text", "value": "Товары"}]}}
  ]}
}
```
