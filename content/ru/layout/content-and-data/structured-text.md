# Структурированный текст без HTML

Текст хранится как небольшое дерево: обычный текст, ссылка и отметки `strong`, `em` или `code`. Framework экранирует содержимое перед выводом. Благодаря этому редактору не приходится принимать произвольный HTML.

## Когда применять

Используйте структурированный текст для заголовков и абзацев, которые редактирует человек, система управления сайтом или ИИ. Готовый HTML нужен только как результат renderer, а не как исходные данные.

## Пример

```json
{"id":"lead","type":"content.paragraph","data":{"content":[
  {"type":"text","value":"Откройте "},
  {"type":"link","href":"/catalog/","children":[{"type":"strong","children":[{"type":"text","value":"каталог"}]}]}
]}}
```
Разрешены `http`, `https`, `mailto`, `tel`, относительные пути и якоря. Исполняемые и файловые схемы отклоняются.
