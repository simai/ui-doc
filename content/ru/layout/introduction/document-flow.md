# Как макет превращается в HTML

Преобразование идёт по одному проверяемому пути: JSON читается, проверяется, приводится к устойчивому виду и только затем превращается в HTML. Каждый этап возвращает понятные ошибки, поэтому неверный документ не попадает на страницу молча.

## Когда применять

Этот порядок нужен в редакторе, при публикации и в автоматической сборке. Проверяйте документ до сохранения или публикации, а digest используйте, чтобы понимать, изменилось ли его нормализованное содержимое.

## Пример

Studio передаёт документ в `SF.Composition.validate()`. После успешной проверки `normalize()` создаёт стабильный JSON и SHA-256 digest. Затем `render()` возвращает HTML, список ресурсов и сведения для интерактивного поведения. Встроенный инспектор показывает все результаты рядом, чтобы разработчик видел причину ошибки и итоговую разметку.
