# Значения и шкалы

Значение — последняя смысловая часть модификатора. Оно задаёт размер, цвет,
направление, выравнивание или другое допустимое состояние CSS-свойства.

```html
<div class="p-4 bg-surface-container text-center"></div>
```

В примере `4`, `surface-container` и `center` — значения.

## Типы значений

| Тип | Примеры | Назначение |
|:---|:---|:---|
| Размерные | `0`, `px`, `a4`, `c2`, `full`, `screen` | Размеры, интервалы и ограничения |
| Соразмерные | `1/4`, `1/3`, `1/2`, `1`–`12` | Семантические шкалы интерфейса и текста |
| Процентные | `25`, `50`, `75`, `100` | Доли ширины, высоты и позиции |
| Цветовые | `primary`, `surface-container`, `error` | Текст, фон, границы и оформление |
| Направления | `row`, `column`, `left`, `top` | Поток, позиционирование, фон |
| Выравнивание | `start`, `center`, `end`, `between` | Flex, Grid и текст |
| Бинарные и именные | `auto`, `none`, `hidden`, `visible` | Режимы CSS-свойств |
| Угловые | числовые значения шкалы поворота | Поворот, наклон и градиенты |

## Направления

Направление может быть значением или параметром модификатора.

| Обозначение | Значение |
|:---|:---|
| `x`, `y` | горизонтальная или вертикальная ось |
| `top`, `bottom`, `left`, `right` | физическая сторона |
| `inline`, `block` | строчная или блочная ось |
| `inline-start`, `inline-end` | начало или конец строки с учётом LTR/RTL |
| `main`, `cross` | основная или поперечная ось Flex/Grid |

## Выравнивание

| Значение | Назначение |
|:---|:---|
| `start`, `end` | начало или конец с учётом направления и оси |
| `center` | центр |
| `between`, `around`, `evenly` | распределение свободного пространства |
| `stretch` | растяжение по доступной области |
| `baseline` | выравнивание по базовой линии текста |
| `left`, `right`, `justify` | физическое выравнивание или текст |

```html
<div class="flex content-main-between items-center"></div>
<p class="text-center md:text-start"></p>
```

## Какую шкалу использовать

- Для точного размера используйте [базовую шкалу](/ru/fundamentals/sizes/size-scale/) `a0`–`i9`.
- Для ритма интерфейса используйте семантическую шкалу `space-*`, описанную в [дизайн-токенах](/ru/fundamentals/design-tokens/).
- Для оформления выбирайте семантические [цветовые роли](/ru/fundamentals/colors-and-themes/), а не фиксированный тон палитры.
- Для текста используйте [типографические роли и шкалы](/ru/fundamentals/typography-system/).

Не каждое значение поддерживается каждой утилитой. Точный набор допустимых
вариантов указан на странице соответствующей группы [утилит](/ru/utilities/).
