# Сокращения свойств

Большинство утилит используют читаемые имена, но у часто повторяющихся
CSS-свойств есть устойчивые сокращения.

| Сокращение | CSS-свойство или группа | Примеры |
|:---|:---|:---|
| `bg` | `background` | `bg-primary`, `bg-cover` |
| `border` | `border` | `border-primary`, `border-none` |
| `color` | `color` | `color-on-surface` |
| `gap` | `gap` | `gap-2`, `gap-x-4` |
| `h` | `height` | `h-full`, `h-c2` |
| `m` | `margin` | `m-2`, `m-auto`, `m-inline-start-auto` |
| `o` | `opacity` | `o-50` |
| `p` | `padding` | `p-2`, `p-inline-start-1` |
| `w` | `width` | `w-full`, `w-f0` |
| `z` | `z-index` | `z-8`, `z--1` |

Название класса является публичным контрактом конкретной группы утилит, а не
механическим сокращением любого CSS-свойства. Перед использованием проверяйте
точный синтаксис в разделе [«Утилиты»](/ru/utilities/).
