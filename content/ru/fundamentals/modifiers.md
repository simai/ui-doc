# Модификаторы

Модификатор — CSS-класс, который применяет одно небольшое правило к элементу.
Классы можно сочетать, добавлять им адаптивные условия и состояния.

```html
<button class="p-1 bg-primary color-on-primary hover:bg-primary md:p-2">
    Сохранить
</button>
```

## Общая схема

```text
{условие:}{ограничение-}{свойство}-{параметр-}{значение}
```

Не все части обязательны:

| Часть | Пример | Что означает |
|:---|:---|:---|
| Условие | `md:`, `hover:` | Когда действует правило |
| Ограничение | `min-`, `max-` | Нижняя или верхняя граница свойства |
| Свойство | `w`, `p`, `bg`, `color` | Какое CSS-свойство меняется |
| Параметр | `x`, `top`, `inline-start` | Ось, сторона или угол |
| Значение | `c2`, `4`, `primary`, `auto` | Какое значение применяется |

Примеры разбора:

- `md:p-x-4`: от `720px` задать горизонтальный внутренний отступ `4`;
- `hover:bg-primary`: при наведении изменить фон;
- `max-w-screen`: ограничить максимальную ширину размером viewport;
- `radius-top-2`: применить радиус `2` к верхним углам.

## Классы без имени свойства

Если значение однозначно определяет CSS-свойство, используется короткая форма:

- `static`, `relative`, `absolute` — позиционирование;
- `block`, `flex`, `grid`, `hidden` — отображение;
- `sans`, `serif`, `mono` — семейство шрифта.

## Частые сокращения

| Сокращение | CSS-свойство или группа | Примеры |
|:---|:---|:---|
| `bg` | `background` | `bg-primary`, `bg-cover` |
| `color` | `color` | `color-on-surface` |
| `gap` | `gap` | `gap-2`, `gap-x-4` |
| `h`, `w` | `height`, `width` | `h-full`, `w-f0` |
| `m`, `p` | `margin`, `padding` | `m-auto`, `p-2` |
| `o` | `opacity` | `o-50` |
| `z` | `z-index` | `z-8`, `z--1` |

Сокращение является частью публичного контракта конкретной утилиты. Не
составляйте имя механически: точный синтаксис проверяйте в разделе
[«Утилиты»](/ru/utilities/).

## Параметры: оси, стороны и углы

Параметр уточняет область действия свойства и идёт сразу после его имени.

| Параметр | Что означает | Пример |
|:---|:---|:---|
| `x`, `y` | горизонтальная или вертикальная ось | `gap-x-2`, `overflow-y-auto` |
| `top`, `bottom`, `left`, `right` | физическая сторона | `p-bottom-1` |
| `inline`, `block` | обе стороны строчной или блочной оси | `m-inline-2`, `m-block-2` |
| `inline-start`, `inline-end` | начало или конец строки с учётом LTR/RTL | `p-inline-start-1` |
| `main`, `cross` | основная или поперечная ось Flex/Grid | `content-main-between` |
| сочетание сторон | угол | `radius-top-inline-end-2` |

Для интерфейсов с разными направлениями письма используйте логические
`inline-*` и `block`, когда смысл связан с направлением чтения.

## Минимум и максимум

Префикс `min-` или `max-` ограничивает свойство: `min-w-0`, `min-w-fit`,
`max-w-full`, `max-w-screen`. Он стоит перед именем свойства, тогда как
значение находится после него.

```text
max-w-screen
│   │ └──── значение
│   └────── свойство
└────────── ограничение
```

## Практические правила

- Начинайте с базового класса и добавляйте условия только при необходимости.
- Используйте логические направления для интерфейсов, поддерживающих LTR и RTL.
- Выбирайте семантические токены вместо случайных точных значений.
- Проверяйте допустимые значения и варианты на странице конкретной утилиты.
