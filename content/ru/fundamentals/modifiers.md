# Модификаторы

Модификатор — CSS-класс, который применяет одно небольшое правило к элементу.
Классы можно сочетать, добавлять им адаптивные условия и состояния.

```html
<button class="p-1 bg-primary color-on-primary hover:bg-primary md:p-2">
    Сохранить
</button>
```

## Общая схема

```text
{условие:}{ограничение-}{свойство}-{параметр-}{значение}
```

Не все части обязательны:

| Часть | Пример | Что означает |
|:---|:---|:---|
| Условие | `md:`, `hover:` | Когда действует правило |
| Ограничение | `min-`, `max-` | Нижняя или верхняя граница свойства |
| Свойство | `w`, `p`, `bg`, `color` | Какое CSS-свойство меняется |
| Параметр | `x`, `top`, `inline-start` | Ось, сторона или угол |
| Значение | `c2`, `4`, `primary`, `auto` | Какое значение применяется |

Примеры разбора:

- `md:p-x-4`: от `720px` задать горизонтальный внутренний отступ `4`;
- `hover:bg-primary`: при наведении изменить фон;
- `max-w-screen`: ограничить максимальную ширину размером viewport;
- `radius-top-2`: применить радиус `2` к верхним углам.

## Классы без имени свойства

Если значение однозначно определяет CSS-свойство, используется короткая форма:

- `static`, `relative`, `absolute` — позиционирование;
- `block`, `flex`, `grid`, `hidden` — отображение;
- `sans`, `serif`, `mono` — семейство шрифта.
