Дополнительно доступны `--sf-0: 0rem`, `--sf-px: 1px` и
`--sf-auto: auto`.

## Пример

```css
.project-card {
    inline-size: var(--sf-f0); /* 160px */
    padding: var(--sf-c2);     /* 24px */
    gap: var(--sf-b2);         /* 12px */
}
```

Размерные примитивы не заменяют семантические токены. Если значение относится
к устойчивой роли интерфейса, создайте переменную с понятным назначением и
сошлитесь в ней на примитив.
