# Архитектура

SIMAI Framework помогает собирать интерфейсы из готовых уровней. Нижние уровни
задают общий внешний вид. Следующие добавляют структуру и поведение. Верхний
уровень даёт законченную часть страницы.

Не нужно проходить всю цепочку для каждого элемента. Выбирайте самый простой
уровень, который полностью решает задачу.

Токены — это общие именованные значения цветов, размеров и типографики. Core —
базовая часть Framework, которая применяет эти значения и общие стили.

```text
Токены и Core
  → утилиты
    → компоненты
      → Smart-компоненты
        → сложные Smart-компоненты
          → блоки
```

## Шесть уровней Framework

| Уровень | Что он добавляет | Когда использовать |
|:---|:---|:---|
| Токены и Core | Общие значения и базовые стили | Когда нужен единый визуальный язык |
| Утилиты | Короткие CSS-классы, каждый из которых меняет одно свойство | Когда нужно настроить отступ, размер, расположение или оформление |
| Компоненты | Готовую структуру и оформление элемента, например кнопки или поля ввода | Когда элемент должен выглядеть и собираться одинаково |
| Smart-компоненты | Готовое интерактивное поведение и состояние | Когда элемент должен реагировать на пользователя или данные |
| Сложные Smart-компоненты | Совместную работу нескольких интерактивных элементов | Когда один пользовательский сценарий состоит из нескольких компонентов |
| Блоки | Законченную часть страницы со своим назначением, настройками и подключением данных | Когда такую часть можно повторно использовать целиком |

Для простого интерфейса обычно достаточно токенов, утилит и компонентов.
Smart-компонент нужен, когда появляется интерактивное поведение. Блок выбирают,
когда готовую часть страницы нужно использовать как единое целое.

## Как работают Smart-компоненты

Smart-компонент — готовый интерактивный элемент. Он принимает настройки и
данные, показывает их, меняет своё состояние и реагирует на действия
пользователя. О важных действиях он сообщает приложению с помощью событий.
Например, событие может сообщить, что пользователь выбрал значение или закрыл
окно.

Loader — встроенный загрузчик SIMAI Framework. Он находит используемые
компоненты и сам подключает нужные стили (CSS) и сценарии (JavaScript). Точные
настройки, состояния и события описаны на странице конкретного компонента.

## Где заканчивается SIMAI Framework

SIMAI Framework отвечает за внешний вид и поведение интерфейса. Приложение
отвечает за страницы, данные, права доступа и бизнес-операции. Framework можно
использовать в системе управления сайтом или другом веб-проекте, но он не
заменяет само приложение.
