# Архитектура

SIMAI Framework даёт несколько уровней готовности: от общего визуального языка
до законченного блока интерфейса. Выбирайте самый простой уровень, который
полностью решает задачу; проходить всю цепочку для каждого элемента не нужно.

```text
Токены и Core
  → утилиты
    → компоненты
      → Smart-компоненты
        → комплексные Smart-компоненты
          → блоки
```

## Что делает каждый уровень

| Уровень | Что он добавляет | Когда использовать |
|:---|:---|:---|
| Токены и Core | Цвета, размеры, типографику, темы и базовые условия | Когда нужен общий визуальный язык |
| Утилиты | Одно небольшое правило компоновки или оформления | Когда достаточно изменить отдельное свойство |
| Компоненты | Повторяемую структуру элемента интерфейса | Когда элемент должен выглядеть и собираться одинаково |
| Smart-компоненты | Состояние, поведение, события и программный контракт | Когда элементу нужен управляемый жизненный цикл |
| Комплексные Smart-компоненты | Согласованную работу нескольких интерактивных элементов | Когда один пользовательский сценарий объединяет несколько компонентов |
| Блоки | Законченную часть интерфейса со смыслом, настройками и точками подключения данных | Когда представление можно использовать как самостоятельную единицу |

Простой интерфейс может использовать только токены, утилиты и обычные
компоненты. Smart нужен, когда появляются состояние, события или управляемый
жизненный цикл. Блок нужен, когда часть интерфейса получает собственный смысл,
настройки и контракт подключения.

## Smart runtime

Текущая поставка использует общий `smart-base.js` и стандартные Custom Elements.
Публичный контракт Smart-компонента состоит из имени элемента, атрибутов,
состояний, методов и событий. Loader подключает объявленные CSS- и JavaScript-
модули, а базовый класс обеспечивает регистрацию, обновление и освобождение
ресурсов при удалении элемента.

Это декларативный runtime для компонентов, а не новый аналог React или Vue. Он
не берёт на себя маршрутизацию приложения, доступ к данным и бизнес-операции.
Конкретные атрибуты, события и готовность проверяйте на странице компонента и в
его manifest.

## Где заканчивается Framework

SIMAI Framework отвечает за фронтенд-представление и поведение блока. Страницы,
данные, права доступа и бизнес-операции принадлежат приложению, CMS или другому
потребителю Framework.

## Действующий контракт и развитие

Публичные классы, токены и API определяются точной установленной поставкой,
registry и страницами справочника. Архитектурное направление может быть шире
текущего runtime. Новая возможность становится доступной только после
реализации, сборки, проверки совместимости и обновления документации.
