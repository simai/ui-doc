# Условия действия

Условие указывает, когда модификатор должен применяться. Оно ставится перед
классом и отделяется двоеточием.

```text
{условие}:{модификатор}
```

## Адаптивные условия

Префиксы `sm:`, `md:`, `lg:` и `xl:` включают правило начиная с заданной
ширины. Например, `md:flex` действует от `720px`. Полная таблица приведена в
[контрольных точках](/ru/fundamentals/breakpoints/).

```html
<div class="block md:flex lg:gap-4"></div>
```

## Условия состояния

Префиксы `hover:`, `focus:` и `active:` применяют правило в соответствующем
псевдоклассе.

```html
<button class="bg-primary hover:bg-primary focus:border-primary active:bg-primary">
    Действие
</button>
```

Набор сгенерированных условий зависит от группы утилит. Например, цветовые
утилиты имеют варианты состояния шире, чем часть геометрических утилит.
Проверяйте доступные варианты на странице конкретной утилиты.

## Правило по умолчанию

Класс без условия действует во всём диапазоне ширин и во всех состояниях, пока
его не переопределяет более подходящее правило.
