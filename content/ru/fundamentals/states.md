# Условия состояния

| Префикс | CSS-состояние | Назначение |
|:---|:---|:---|
| `hover:` | `:hover` | Наведение указателя |
| `focus:` | `:focus` | Получение фокуса |
| `active:` | `:active` | Момент активации или нажатия |
{.table}

```html
<button class="
    bg-primary
    hover:bg-primary
    focus:border-primary
    active:bg-primary
">
    Сохранить
</button>
```

Для цветовых ролей классы состояний автоматически обращаются к связанным
токенам. Например, `active:bg-primary` использует
`--sf-primary-active`, а `hover:bg-primary` — `--sf-primary-hover`.

## Доступность

- Не удаляйте видимый фокус без равноценной замены.
- Состояние не должно различаться только цветом: для критичного действия
  добавляйте форму, текст, иконку или другое заметное изменение.
- `hover` не работает как основной способ взаимодействия на сенсорном
  устройстве; базовое состояние должно оставаться понятным.
- Сначала задавайте обычный класс, затем состояние: `bg-primary
  hover:bg-primary`.

Не каждая группа утилит генерирует все три префикса. Доступность варианта
проверяется в справочнике соответствующей [утилиты](/ru/utilities/).
