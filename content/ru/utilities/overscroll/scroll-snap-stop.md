# Ограничитель прокрутки

Классы `snap-always` и `snap-normal` задают `scroll-snap-stop` — может ли
быстрая прокрутка проскочить элемент с привязкой. Берите `snap-always` для
пошаговых лент и слайдов, где нельзя пропустить шаг.

## Пример

Прокрутите ленты резким движением — свайпом на тачпаде или пальцем.
Карточки шириной во всю ленту; с `snap-normal` лента может пролететь
несколько карточек, с `snap-always` останавливается на следующей.

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `snap-normal` | `scroll-snap-stop: normal` | — |
| `snap-always` | `scroll-snap-stop: always` | — |

Условия ([что это](/ru/guide/utilities/conditions/)): ширина экрана — нет; состояния — нет.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

### Выбор

| Класс | Быстрая прокрутка |
| :--- | :--- |
| `snap-normal` | может проскочить элемент — поведение по умолчанию |
| `snap-always` | останавливается на каждом элементе |

Класс ставят на элементы вместе с классом выравнивания:

```html
<div class="flex overflow-auto snap-x snap-mandatory">
  <section class="snap-start snap-always shrink-none w-full">Шаг 1</section>
  <section class="snap-start snap-always shrink-none w-full">Шаг 2</section>
</div>
```

## Ограничения

- Классы действуют только на элементы с выравниванием привязки внутри
  контейнера с типом привязки.
- Прокрутка колёсиком мыши идёт шагами и обычно не проскакивает элементы;
  разница видна на тачпаде и сенсорном экране.
- `snap-always` в длинной ленте заставляет листать по одному элементу.
  Для каталога или галереи оставьте `snap-normal`.
- У семейства нет префиксов ширины экрана и состояния.
