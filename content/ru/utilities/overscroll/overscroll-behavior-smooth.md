# Плавность прокрутки

Классы `scroll-smooth` и `scroll-auto` задают `scroll-behavior`: прокручивает
ли браузер область плавно или сразу ставит её на место, когда прокрутку
запускает переход по якорю или скрипт. Базовые стили Framework уже делают
прокрутку плавной у каждого элемента, поэтому чаще нужен `scroll-auto` —
чтобы её отключить.

## Пример

Нажмите «Вниз на 75%» в обеих областях: скрипт прокручивает их одинаково, а
счётчик показывает, сколько заняла прокрутка.

:::example {id="utilities/overscroll/overscroll-behavior-smooth" label="Мгновенная и плавная прокрутка"}
:::

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `scroll-smooth` | `scroll-behavior: smooth` | — |
| `scroll-auto` | `scroll-behavior: auto` | — |

Условия ([что это](/ru/guide/utilities/conditions/)): ширина экрана — нет; состояния — нет.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

### Когда отключать плавность

Плавная прокрутка помогает понять, куда перешла страница по ссылке
оглавления. Мгновенная лучше там, где скрипт часто ставит область в нужное
место: лента сообщений, которая держится у последнего сообщения, журнал,
длинная таблица с переходом к строке.

```html
<div class="max-h-f4 overflow-auto scroll-auto">
  <!-- лента, которую скрипт держит внизу -->
</div>
```

### Страница целиком

Для перехода по якорям страницы класс ставят на корневой элемент:

```html
<html class="scroll-auto">
```

`scroll-smooth` возвращает плавность там, где её отключили выше.

## Ограничения

- Класс не меняет прокрутку колёсиком, клавишами и жестами: её плавность
  задают браузер и система.
- Скрипт, который передаёт `behavior` в `scrollTo` или `scrollIntoView`,
  выбирает поведение сам, и класс на него не действует.
- Плавная прокрутка не отключается сама при системной настройке уменьшения
  движения (`prefers-reduced-motion`). Для таких пользователей задайте
  `scroll-behavior: auto` в стилях проекта по медиазапросу
  `prefers-reduced-motion: reduce`.
- У семейства нет префиксов ширины экрана и состояния.
