# Внутренний отступ прокрутки

Классы `scroll-p*` задают `scroll-padding` — поле внутри прокручиваемой
области, которое браузер учитывает, когда прокручивает к элементу: по
якорной ссылке, через `scrollIntoView` или при привязке прокрутки. Берите
их на контейнер, если зазор нужен всем его элементам сразу, — например, под
закреплённой шапкой страницы.

## Пример

Прокрутите обе ленты вбок. Без класса карточки привязываются вплотную к
краю ленты; с `scroll-pl-4` на ленте — с полем в начале строки.

## Применение

### Отступ на контейнере или на элементе

`scroll-padding` ставят на прокручиваемую область, и он действует для всех её
элементов. [Внешний отступ прокрутки](/ru/utilities/overscroll/scroll-margin/)
ставят на отдельный элемент. Для страницы с закреплённой шапкой проще один
класс на корневом элементе:

```html
<html class="scroll-pt-8">
```

### Стороны и шкала

| Шаблон | Сторона |
| :--- | :--- |
| `scroll-p-{значение}` | все стороны |
| `scroll-pt-{значение}`, `scroll-pb-{значение}` | сверху, снизу |
| `scroll-py-{значение}` | сверху и снизу |
| `scroll-pl-{значение}`, `scroll-pr-{значение}` | в начале и в конце строки |
| `scroll-px-{значение}` | в начале и в конце строки |

Основная шкала — шаги отступов `0`, `1/4`, `1/3`, `1/2`, `1` … `8`
(токены `--sf-space-*`, они растут на широких экранах). Расширенная шкала —
размерные токены `a0` … `i9` с точным значением, в том числе отрицательные
классы `-scroll-p-*`; стороны строки в ней названы
`scroll-p-inline-start-*` и `scroll-p-inline-end-*`, классов `scroll-py-*` и
`scroll-px-*` в ней нет.

```html
<div class="overflow-auto snap-x snap-mandatory scroll-p-inline-start-c6">…</div>
```

## Ограничения

- `scroll-pl-*` и `scroll-pr-*` задают логические стороны
  (`scroll-padding-inline-start` и `-end`), а не левую и правую: при письме
  справа налево они меняются местами.
- Поле действует только при прокрутке к элементу; на раскладку содержимого
  оно не влияет. Для полей внутри блока берите
  [внутренние отступы](/ru/utilities/indents/padding/).
- У семейства нет префиксов ширины экрана и состояния.
