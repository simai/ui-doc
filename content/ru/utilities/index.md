# Утилиты

Утилиты — короткие CSS-классы для одной конкретной задачи. Например, `flex`
включает гибкий макет, `gap-3` добавляет промежутки, а `text-center` выравнивает
текст. Их можно соединять прямо в `class` без отдельного CSS-файла.

На странице каждой утилиты сначала показан результат, затем доступные классы и
готовый HTML. Общие правила префиксов, состояний и шкал объясняются в
[основах оформления](/ru/guide/fundamentals/).

## Как выбрать класс

1. Откройте группу по задаче, которую решаете.
2. Посмотрите результат в блоке «Пример».
3. Скопируйте класс или HTML из этой же страницы.
4. При необходимости добавьте `hover:`, `focus:` или адаптивный префикс,
   например `md:`. Страница показывает только те варианты, которые реально
   поставляются Framework.
