# Смешивание цветов

:badge[mix-blend-mode]{type=main scheme=on-surface size=1}

Утилиты `mix-blend-*` определяют, как цвет элемента смешивается с уже
нарисованным фоном. Это удобно для декоративных слоёв, изображений и текста
поверх цветной области.

## Пример

Одинаковые фигуры выглядят по-разному из-за режима смешивания.

:::example {id="utilities/filters/mix-blend-mode" label="Режимы смешивания"}
:::

## Часто используемые режимы

| Класс | Результат |
|:---|:---|
| `mix-blend-normal` | Обычное отображение без смешивания |
| `mix-blend-multiply` | Затемняет пересечение цветов |
| `mix-blend-screen` | Осветляет пересечение цветов |
| `mix-blend-overlay` | Усиливает контраст фона |
| `mix-blend-difference` | Показывает разницу между цветами |

```html
<span class="mix-blend-multiply">Декоративный слой</span>
```

Результат зависит от содержимого под элементом. Для отдельной области
смешивания добавьте родителю [`isolate`](/ru/utilities/layout/isolation/).
