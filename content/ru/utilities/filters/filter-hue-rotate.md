# Вращение оттенка элемента

Классы `hue-rotate-*` поворачивают оттенок всех цветов элемента на угол в
градусах. Берите их для цветовых вариантов одной иллюстрации или декоративного
эффекта при наведении.

## Пример

### Углы

Положительные углы поворачивают оттенок в одну сторону, классы с минусом — в другую. `hue-rotate-0` оставляет цвета как есть.

:::example {id="utilities/filters/filter-hue-rotate" label="Углы поворота"}
:::

### При наведении

Наведите указатель на изображение: оттенки сдвигаются на 180°.

:::example {id="utilities/filters/filter-hue-rotate-hover" label="hover:hue-rotate-180"}
:::

## Применение

### Углы

Угол в градусах записан в имени класса: `hue-rotate-0`, `hue-rotate-15`,
`hue-rotate-30`, `hue-rotate-60`, `hue-rotate-90`, `hue-rotate-180`.
Отрицательный угол пишется с минусом в начале: `-hue-rotate-15`,
`-hue-rotate-30`, `-hue-rotate-60`, `-hue-rotate-90`.

```html
<img class="hue-rotate-90" src="illustration.svg" alt="Иллюстрация">
<img class="-hue-rotate-60" src="illustration.svg" alt="Иллюстрация">
```

Поворот меняет оттенок, но не яркость и насыщенность: серые и чёрно-белые
участки остаются прежними.

## Ограничения

- На элементе действует один класс фильтра. Каждый класс семейств фильтра
  (`blur-*`, `brightness-*`, `contrast-*`, `grayscale`, `hue-rotate-*`,
  `invert`, `saturate-*`, `sepia`) задаёт свойство `filter` целиком и
  сбрасывает функции остальных семейств, поэтому из `blur-small grayscale`
  остаётся только тот класс, чьё правило стоит в CSS позже. Чтобы сложить два
  фильтра, поставьте второй класс на обёртку.
- Класс с `hover:` тоже задаёт фильтр целиком: при наведении он заменяет
  фильтр элемента, а не добавляется к нему.
- Любое значение, в том числе `hue-rotate-0`, создаёт у элемента новый контекст
  наложения и содержащий блок для потомков с `position: fixed`.
- Поворот оттенка не учитывает тему: цвета, подобранные под светлую и тёмную
  тему, после поворота могут потерять контраст.
