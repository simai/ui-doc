# Размер фона

Классы `bg-auto`, `bg-cover`, `bg-contain` и `bg-size-*` задают
`background-size`: в каком масштабе рисуется фоновое изображение. Берите
`bg-cover` для обложек во весь блок, `bg-contain` — чтобы картинка поместилась
целиком, `bg-size-*` — для точной ширины плитки или значка.

## Пример

### Ключевые слова

`bg-auto` рисует картинку в её собственном размере, `bg-cover` заполняет
элемент и обрезает лишнее, `bg-contain` помещает картинку целиком и оставляет
пустые поля.

:::example {id="utilities/background/background-size" label="bg-auto, bg-cover и bg-contain"}
:::

### Проценты и шкала

`bg-size-{процент}` задаёт ширину картинки в процентах от ширины элемента,
`bg-size-{ступень}` — ширину по шкале размеров. Высота подстраивается под
пропорции картинки.

:::example {id="utilities/background/background-size-scale" label="bg-size-25 … bg-size-100, bg-size-e0, bg-size-f0"}
:::

## Применение

### Как выбрать

| Класс | Что делает |
| :--- | :--- |
| `bg-auto` | собственный размер картинки — значение браузера по умолчанию |
| `bg-cover` | заполняет элемент целиком, края картинки обрезаются |
| `bg-contain` | картинка видна целиком, по краям остаются поля |
| `bg-size-0` … `bg-size-100` | ширина в процентах от ширины элемента |
| `bg-size-a0` … `bg-size-i9` | ширина по шкале размеров |

### Обложка

```html
<div class="bg-cover bg-center h-f8"
     style="background-image: url(/images/cover.jpg)"></div>
```

### Плитка узора

Размер из шкалы задаёт шаг плитки независимо от размера файла:

```html
<div class="bg-repeat bg-size-c6" style="background-image: url(/images/tile.svg)"></div>
```

### Ширина экрана

С префиксом ширины класс действует от указанной ширины и шире:
`bg-contain md:bg-cover` показывает картинку целиком на узком экране и
заполняет блок на широком.

## Ограничения

- `bg-size-*` задаёт одно значение — ширину; отдельной высоты у классов нет.
- Шкала `bg-size-a0` … `bg-size-i9` задана в `rem` и растёт вместе с кеглем.
- У семейства нет префиксов состояния.
