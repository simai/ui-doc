# Одновременное выравнивание по двум осям

Классы `start-start` … `end-end` уходят из SIMAI Framework (C212 (2)): они рисуют, как рисовали,
до 2027-01-01, а первое использование на странице Loader записывает в
`SF.deprecations`. В новой разметке их не берите.

Пишите два класса: выравнивание по основной оси `content-main-*` и по поперечной `items-cross-*`, например `content-main-center items-cross-center` вместо `center-center`. См. [Выравнивание по основной оси](/ru/utilities/grid-and-flexbox-utilities/justify-content/).

Прежние имена классов этого модуля и что писать вместо них — в руководстве [Как обновить проект](/ru/guide/connection/updating/#прежние-имена-классов).

Условия ([что это](/ru/guide/utilities/conditions/)): ширина экрана — `sm:`, `md:`, `lg:`, `xl:`, `xxl:`; состояния — нет. Например: `sm:start-start`.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.
