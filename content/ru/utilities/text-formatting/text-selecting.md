# Выделение текста

## Таблица классов

| Класс | Значение |
|:--|:--|
| `.select-none` | Запрет выделения |
| `.select-text` | Обычное выделение текста |
| `.select-all` | Выделение всего содержимого при клике |
| `.select-auto` | Поведение по умолчанию браузера |
