# Положение элемента по оси Z

Классы `z-*` задают порядок перекрытия: из позиционированных элементов,
которые лежат друг на друге, сверху оказывается тот, у кого ступень больше.
Берите их для своих наложений внутри блока — значка поверх карточки,
закреплённой полосы над содержимым.

## Пример

Три слоя стоят в одном позиционированном блоке. Сверху — `z-2`, под ним
`z-1`, ниже всех — `z-0`, хотя в разметке он последний.

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `z-auto` | `z-index: auto` | — |
| `z--1` | `z-index: var(--sf-z-index--1)` | — |
| `z-1` | `z-index: var(--sf-z-index-1)` | — |
| `z-2` | `z-index: var(--sf-z-index-2)` | — |
| `z-3` | `z-index: var(--sf-z-index-3)` | — |
| `z-4` | `z-index: var(--sf-z-index-4)` | — |
| `z-5` | `z-index: var(--sf-z-index-5)` | — |
| `z-6` | `z-index: var(--sf-z-index-6)` | — |
| `z-7` | `z-index: var(--sf-z-index-7)` | — |
| `z-8` | `z-index: var(--sf-z-index-8)` | — |
| `z-9` | `z-index: var(--sf-z-index-9)` | — |
| `z-0` | `z-index: var(--sf-z-index-0)` | — |

Условия ([что это](/ru/guide/utilities/conditions/)): ширина экрана — `sm:`, `md:`, `lg:`, `xl:`, `xxl:`; состояния — нет. Например: `sm:z-auto`.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Переменные

Классы читают эти токены темы. Изменённый токен меняет все места, где он используется, — классы, компоненты и тему; задайте его в теме проекта, а не на отдельном элементе. Все токены — на странице [Все токены](/ru/guide/colour/all-tokens/).

| Переменная | Значение по умолчанию |
|:---|:---|
| `--sf-z-index--1` | `-1` |
| `--sf-z-index-1` | `10` |
| `--sf-z-index-2` | `20` |
| `--sf-z-index-3` | `30` |
| `--sf-z-index-4` | `40` |
| `--sf-z-index-5` | `50` |
| `--sf-z-index-6` | `60` |
| `--sf-z-index-7` | `70` |
| `--sf-z-index-8` | `80` |
| `--sf-z-index-9` | `90` |
| `--sf-z-index-0` | `0` |

## Применение

### Поднять элемент над соседями

Ставьте класс на позиционированный элемент (`relative`, `absolute`,
`fixed`, `sticky`) или на элемент flex- и grid-раскладки.

```html
<div class="relative">
  <img src="product.jpg" alt="Кресло «Уют»">
  <span class="absolute top-0 inline-end-0 z-1">Скидка 20 %</span>
</div>
```

### Опустить под содержимое

`z--1` кладёт элемент под соседей в том же контексте наложения, например
декоративную подложку за текстом.

### Ограничить слои блоком

Ступени сравниваются только внутри одного контекста наложения. Поставьте
[`isolate`](/ru/utilities/layout/isolation/) на блок, чтобы слои внутри него
не спорили со слоями страницы.

## Ограничения

- У статичного элемента вне flex- и grid-раскладки `z-index` не действует.
- Ступень не поднимает элемент выше его контекста наложения: потомок блока с
  `z-1` не встанет над соседом этого блока с `z-2`.
