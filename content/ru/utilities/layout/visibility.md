# Видимость элемента

Классы `visible` и `invisible` задают свойство `visibility`. Невидимый элемент
не рисуется и не отвечает на клик, но занимает своё место, поэтому соседние
элементы не сдвигаются. Берите их, когда элемент скрывают и показывают без
перестройки раскладки.

В каждом образце второй блок несёт класс из подписи. Для сравнения третий образец —
[`hidden`](/ru/utilities/layout/display/), который убирает элемент вместе с
его местом.

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `visible` | `visibility: visible` | — |
| `invisible` | `visibility: hidden` | — |

Условия ([что это](/ru/guide/utilities/conditions/)): ширина экрана — `sm:`, `md:`, `lg:`, `xl:`, `xxl:`; состояния — нет. Например: `sm:visible`.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

### Скрыть, не сдвигая соседей

`invisible` оставляет место элемента пустым: подходит для мест, где раскладка
не должна прыгать, — например, для кнопки, которая появляется после выбора.

```html
<button type="button" class="invisible">Сохранить</button>
```

### Показать на части экранов

`visible` отменяет `invisible`. С префиксом ширины класс действует от
указанной ширины и шире:

```html
<div class="invisible md:visible">Виден от ширины md</div>
```

### Выбор между invisible, hidden и sr-only

- `invisible` — элемента не видно, место сохраняется.
- [`hidden`](/ru/utilities/layout/display/) — элемента не видно, места нет.
- [`sr-only`](/ru/utilities/interactivity/sr-only/) — элемента не видно, но
  программы экранного доступа его читают.

## Ограничения

- `invisible` скрывает элемент и от программ экранного доступа, и от
  клавиатуры: фокус на него не попадает.
- Потомок с `visible` внутри родителя с `invisible` остаётся видимым.
- У семейства нет префиксов состояния: `hover:visible` и подобные классы не
  существуют.
