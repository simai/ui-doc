# Положение маркера списка

Классы задают, где стоит маркер пункта списка: снаружи области текста
(`list-outside`) или внутри неё (`list-inside`). Берите `list-inside`, когда
список стоит в узком блоке без отступа слева.

## Пример

Фон показывает область списка. У `list-inside` маркер входит в первую строку,
и перенесённая строка начинается под маркером.

:::

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `list-inside` | `list-style-position: inside` | — |
| `list-outside` | `list-style-position: outside` | — |

Условия ([что это](/ru/guide/utilities/conditions/)): ширина экрана — нет; состояния — нет.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

По умолчанию маркер снаружи, а у `ul` есть отступ под него. С `list-inside`
отступ можно убрать:

```html
<ul class="list-inside p-0">
  <li>Пункт в узкой колонке</li>
</ul>
```

## Ограничения

- С `list-inside` перенесённые строки начинаются под маркером, а не под
  текстом: для длинных пунктов оставьте `list-outside`.
- У семейства нет префиксов ширины экрана и состояний.
