# Стиль маркера списка

Классы задают вид маркера пункта списка: точку (`list-disc`), номер
(`list-decimal`) или его отсутствие (`list-none`). Берите `list-none` для
списков, которые оформлены как меню, теги или карточки.

## Пример

Класс меняет маркер независимо от тега: в примере `ol` с точками и `ul` с
номерами.

:::

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `list-none` | `list-style-type: none` | — |
| `list-disc` | `list-style-type: disc` | — |
| `list-decimal` | `list-style-type: decimal` | — |

Условия ([что это](/ru/guide/utilities/conditions/)): ширина экрана — нет; состояния — нет.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

Выбирайте тег по смыслу: `ol`, когда важен порядок, `ul` — когда нет. Класс
меняет только вид маркера.

```html
<ul class="list-none p-0 flex gap-2">
  <li>Главная</li>
  <li>Каталог</li>
</ul>
```

`list-none` не убирает отступ под маркер: снимите его классом `p-0`.

## Ограничения

- Safari с VoiceOver не объявляет список с `list-style-type: none` списком.
  Если это важно, добавьте `role="list"` к `ul` или `ol`.
- У семейства нет префиксов ширины экрана и состояний.
