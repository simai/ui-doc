# Обработка пробелов

Классы задают свойство `white-space`: сливаются ли подряд идущие пробелы,
сохраняются ли переводы строк из разметки и переносится ли строка по ширине
блока. Берите их для адресов, стихов, кода и текста, введённого
пользователем.

## Пример

В разметке каждого образца — одинаковый текст с лишними пробелами, переводом
строки и отступом второй строки.

:::

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `wrap-none` | `white-space: nowrap` | — |
| `pre` | `white-space: pre` | — |
| `pre-line` | `white-space: pre-line` | — |
| `pre-wrap` | `white-space: pre-wrap` | — |
| `whitespace-normal` | `white-space: normal` | — |

Условия ([что это](/ru/guide/fundamentals/conditions/)): ширина экрана — нет; состояния — нет.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

| Класс | Пробелы | Переводы строк | Перенос по ширине |
|:---|:---|:---|:---|
| `whitespace-normal` | сливаются | становятся пробелом | есть |
| `wrap-none` | сливаются | становятся пробелом | нет |
| `pre` | сохраняются | сохраняются | нет |
| `pre-line` | сливаются | сохраняются | есть |
| `pre-wrap` | сохраняются | сохраняются | есть |

Текст, который ввёл пользователь — комментарий, адрес, — показывайте с
`pre-line` или `pre-wrap`, чтобы сохранить его переводы строк:

```html
<p class="pre-line">{{ comment }}</p>
```

## Ограничения

- `wrap-none` и `pre` не переносят строку: длинная строка выходит за блок.
  Добавьте прокрутку `overflow-auto` или обрезку `truncate`.
- Отступы в начале строк в разметке тоже сохраняются у `pre` и `pre-wrap`:
  начинайте текст с начала строки.
- У семейства нет префиксов ширины экрана и состояний.
