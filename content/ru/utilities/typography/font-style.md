# Стиль шрифта

Класс `italic` делает текст наклонным, `italic-none` возвращает прямое
начертание. Берите их, когда наклон — оформление, а не смысловое выделение.

## Пример

`italic-none` снимает наклон, который браузер даёт тегу `em`.

:::

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `italic` | `font-style: italic` | — |
| `italic-none` | `font-style: normal` | — |

Условия ([что это](/ru/guide/fundamentals/conditions/)): ширина экрана — нет; состояния — нет.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

Для смыслового выделения пишите `<em>`: браузер сам покажет его наклонным,
а программы чтения с экрана поймут, что это выделение. Классы оставьте для
оформления:

```html
<p class="italic color-on-surface-variant">Подпись к иллюстрации</p>
<em class="italic-none weight-7">Выделение жирным вместо наклона</em>
```

## Ограничения

- Если у шрифта нет наклонного начертания, браузер наклоняет прямое
  искусственно.
- У семейства нет префиксов ширины экрана и состояний.
