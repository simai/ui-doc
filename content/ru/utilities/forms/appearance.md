# Сброс стиля

Класс `appearance-none` задаёт `appearance: none`: браузер перестаёт рисовать
элемент формы по-своему — без стрелки у списка, без системной рамки у поля
поиска, без галочки у флажка. Берите его, когда элемент оформляется
целиком классами Framework.

## Пример

Слева элементы в оформлении браузера, справа — с `appearance-none` и
собственной рамкой. У флажка пропадает и галочка: отметку рисует только ваше
оформление.

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `appearance-none` | `appearance: none` | — |

Условия ([что это](/ru/guide/utilities/conditions/)): ширина экрана — нет; состояния — нет.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

После сброса элемент выглядит как обычный блок: рамку, отступы, фон и цвет
текста задают классы.

```html
<select class="appearance-none w-full p-x-2 p-y-1 border border-outline radius-ui bg-surface color-on-surface">
  <option>Москва</option>
  <option>Казань</option>
</select>
```

Списку без стрелки стоит вернуть признак раскрытия — например, значок справа
от поля. Флажку и переключателю после сброса нужны свои стили для
отмеченного, фокусного и недоступного состояния.

## Ограничения

- Класс один и не имеет пары, возвращающей оформление браузера, и префиксов
  ширины экрана или состояния.
- Сброс убирает и видимые признаки состояния — галочку, точку, стрелку. Без
  замены пользователь не видит, что выбрано.
- Цвет отметки, заданный через [`accent-*`](/ru/utilities/forms/accent-color/),
  на элемент с `appearance-none` не действует.
