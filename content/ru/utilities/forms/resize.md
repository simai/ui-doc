# Изменение размера

Классы `resize-*` задают свойство `resize`: можно ли растянуть элемент за
правый нижний угол и в каком направлении. Берите их для текстовых областей и
блоков с прокруткой.

## Пример

### Текстовая область

Тяните за угол в правом нижнем углу поля. Под каждым полем — класс.

:::example {id="utilities/forms/resize" label="resize, resize-x, resize-y, resize-none"}
:::

### Блок

Обычный блок растягивается, только если у него задан `overflow` со значением,
отличным от `visible`. Без него угла нет.

:::example {id="utilities/forms/resize-block" label="resize на блоке с overflow-auto и без него"}
:::

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `resize-none` | `--sf-resize: none; resize: var(--sf-resize)` | — |
| `resize-y` | `--sf-resize: vertical; resize: var(--sf-resize)` | — |
| `resize-x` | `--sf-resize: horizontal; resize: var(--sf-resize)` | — |
| `resize` | `--sf-resize: both; resize: var(--sf-resize)` | — |

Условия ([что это](/ru/guide/utilities/conditions/)): ширина экрана — нет; состояния — нет.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

| Класс | Направление |
| :--- | :--- |
| `resize` | по обеим осям |
| `resize-y` | только по высоте |
| `resize-x` | только по ширине |
| `resize-none` | растягивать нельзя |

Текстовую область в форме обычно оставляют растягиваемой по высоте: ширину
задаёт сетка формы.

```html
<textarea class="resize-y w-full" rows="4"></textarea>
```

Класс записывает выбранное значение в переменную `--sf-resize` на самом
элементе и читает его оттуда.

## Ограничения

- Блоку, кроме класса, нужен [`overflow-*`](/ru/utilities/layout/overflow/)
  со значением `auto`, `hidden` или `scroll`; у `textarea` он уже есть.
- Элемент с `resize-x` или `resize` можно растянуть шире родителя. Ограничьте
  ширину классом `max-w-*`.
- Угол для растягивания мышью есть не во всех мобильных браузерах.
- Префиксов ширины экрана и состояния у семейства нет.
