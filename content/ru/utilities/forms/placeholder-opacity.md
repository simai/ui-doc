# Прозрачность placeholder

Утилиты `placeholder-opacity-*` управляют прозрачностью текста placeholder.

## Классы

| Класс | Значение |
|:--|:--|
| `.placeholder-opacity-0 ... .placeholder-opacity-9` | `opacity: 0 ... 0.9` |
| `.placeholder-opacity-full` | `opacity: 1` |
