# Высота

Классы высоты задают свойство `height`. Берите их, когда элементу нужна
определённая высота: точная из шкалы размеров, доля родителя с заданной
высотой, высота по содержимому или высота окна просмотра.

## Пример

### Шкала размеров

Классы `h-a0` … `h-i9` берут значение из шкалы размеров: буква — группа,
цифра — шаг внутри неё. Под каждым столбиком — класс, который задаёт его высоту.

:::example {id="utilities/sizes/height" label="Высота по шкале размеров"}
:::

### Доли родителя

Дробь — доля высоты родителя. Доля действует, только когда у родителя задана
высота: здесь у пунктирной рамки — `h-f0`.

:::example {id="utilities/sizes/height-fractions" label="Доли высоты родителя"}
:::

### По содержимому

Во флекс-ряду элемент с `h-auto` растягивается на высоту ряда. `h-fit`,
`h-min` и `h-max` задают высоту по содержимому, и элемент не растягивается.

:::example {id="utilities/sizes/height-content" label="h-auto, h-fit, h-min и h-max"}
:::

### Доли окна

`h-screen-1/4` … `h-screen-3/4` — доли высоты окна просмотра. Меняйте высоту
окна: столбики меняются вместе с ней.

:::example {id="utilities/sizes/height-screen" label="Доли высоты окна"}
:::

### Ширина экрана

С префиксом ширины класс действует от указанной ширины и шире. Меняйте ширину
окна просмотра: с ширины `md` полоса становится выше, с ширины `xl` — ещё выше.

:::example {id="utilities/sizes/height-responsive" label="Высота по ширине экрана"}
:::

## Применение

### Как выбрать значение

- Точная высота элемента интерфейса — полосы, иконки, превью — класс шкалы
  размеров, например `h-d6`. Значения шагов — на странице
  [Шкала размеров](/ru/guide/fundamentals/size-scale/).
- Высота внутри блока с заданной высотой — доли `h-1/2` … `h-5/6` или `h-full`.
- Высота по содержимому — `h-auto`, значение по умолчанию. `h-fit`, `h-min`
  и `h-max` нужны там, где высота иначе растягивается: во флекс- и
  грид-раскладке.
- `h-min` и `h-max` — основные имена; `h-content-min` и `h-content-max` дают
  те же значения.

```html
<div class="h-f0">
  <div class="h-1/2">Половина высоты родителя</div>
</div>
```

### Высота окна

`h-screen` равна высоте окна просмотра (`100vh`), `h-screen-1/2` и другие
доли — части этой высоты. На мобильных браузерах высота окна меняется, когда
появляется и скрывается адресная строка. `h-screen-small`, `h-screen-large` и
`h-screen-dynamic` берут малую, большую и текущую высоту окна (`svh`, `lvh`,
`dvh`) из переменных темы; в браузере без поддержки этих единиц значение —
высота окна.

```html
<section class="h-screen-dynamic">Первый экран</section>
```

Если содержимое может оказаться выше окна, задайте не высоту, а минимальную
высоту — [`min-h-screen`](/ru/utilities/sizes/min-height/).

### Высота по ширине экрана

```html
<div class="h-d6 md:h-e6">Баннер</div>
```

## Ограничения

- Доля родителя (`h-1/2`, `h-full`) не действует, если высота родителя не
  задана: тогда элемент получает высоту по содержимому.
- Высота включает внутренние отступы и рамку: Framework задаёт всем элементам
  `box-sizing: border-box`.
- Содержимое выше заданной высоты выходит за элемент. Чтобы его прокручивать
  или обрезать, добавьте класс [переполнения](/ru/utilities/layout/overflow/).
- У семейства нет префиксов состояния и отрицательных значений.
