# Максимальная высота

Классы максимальной высоты задают свойство `max-height`: элемент растёт по
содержимому, но не выше заданного значения. Берите их для прокручиваемых
списков, панелей и выпадающих меню, которые не должны выходить за предел.

## Пример

### Шкала размеров

Классы `max-h-a0` … `max-h-i9` берут предел из шкалы размеров. Список выше
предела прокручивается — для этого рядом стоит `overflow-auto`.

:::example {id="utilities/sizes/max-height" label="Предел по шкале размеров"}
:::

### Высота родителя и ноль

Пунктирная рамка — родитель с высотой `h-e6`. Без предела список выходит за
родителя, с `max-h-full` — прокручивается внутри него. `max-h-0` с
`overflow-hidden` скрывает содержимое полностью.

:::example {id="utilities/sizes/max-height-full" label="max-h-full и max-h-0"}
:::

### Ширина экрана

С префиксом ширины класс действует от указанной ширины и шире. Меняйте ширину
окна просмотра: с ширины `md` список становится выше.

## Применение

### Как выбрать значение

- Прокручиваемый список или панель — предел из шкалы размеров вместе с
  `overflow-auto`.
- Блок внутри родителя с заданной высотой — `max-h-full`.
- Блок, который не должен быть выше окна, например содержимое диалога, —
  `max-h-screen`.
- `max-h-min`, `max-h-max` и `max-h-fit` ограничивают высоту высотой
  содержимого: там, где высота иначе растягивается, например во флекс- и
  грид-раскладке.
- `max-h-px` и `max-h-0` сжимают элемент до одного пикселя и до нуля.

```html
<ul class="max-h-f0 overflow-auto">
  <li>…</li>
</ul>

<div class="max-h-screen overflow-auto">Содержимое диалога</div>
```

### Предел по ширине экрана

```html
<div class="max-h-e0 md:max-h-f0 overflow-auto">…</div>
```

## Ограничения

- Предел не прокручивает и не обрезает содержимое сам: без класса
  [переполнения](/ru/utilities/layout/overflow/) содержимое выходит за
  элемент.
- `max-h-full` не действует, если высота родителя не задана.
- `max-h-screen` — высота окна (`100vh`). На мобильных браузерах она может
  быть больше видимой области, пока показана адресная строка.
- Минимальная высота сильнее предела.
- У семейства нет префиксов состояния и отрицательных значений.
