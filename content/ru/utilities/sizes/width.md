# Ширина

Классы ширины задают свойство `width`. Берите их, когда элементу нужна
определённая ширина: точная из шкалы размеров, доля родителя, ширина по
содержимому или ширина окна просмотра.

## Пример

### Шкала размеров

Классы `w-a0` … `w-i9` берут значение из шкалы размеров: буква — группа,
цифра — шаг внутри неё. Над каждой полосой — класс, который задаёт её ширину.

:::example {id="utilities/sizes/width" label="Ширина по шкале размеров"}
:::

### Доли родителя

Дробь — доля ширины родителя: пятые, шестые и двенадцатые доли складываются в
ряды колонок.

:::example {id="utilities/sizes/width-fractions" label="Доли ширины родителя"}
:::

### Проценты

`w-1` … `w-99` задают ширину в процентах от родителя с шагом в один процент.

:::example {id="utilities/sizes/width-percent" label="Ширина в процентах"}
:::

### По содержимому

Пунктирная рамка — родитель. `w-auto` занимает всю его ширину, `w-fit` и
`w-max` равны длине текста, `w-min` — самому длинному слову.

:::example {id="utilities/sizes/width-content" label="w-auto, w-fit, w-min и w-max"}
:::

### Ширина экрана

С префиксом ширины класс действует от указанной ширины и шире. Меняйте ширину
окна просмотра: на узком экране полоса во всю ширину, с ширины `md` — половина,
с ширины `xl` — треть.

:::example {id="utilities/sizes/width-responsive" label="Ширина по ширине экрана"}
:::

## Применение

### Как выбрать значение

- Точная ширина элемента интерфейса — иконки, аватара, поля, колонки
  фиксированной ширины — класс шкалы размеров, например `w-e8`. Значения шагов
  — на странице [Шкала размеров](/ru/guide/fundamentals/size-scale/).
- Колонки в ряду — доли: `w-1/2`, `w-1/3`, `w-3/12`. `w-1/1` и `w-full`
  дают одно и то же значение.
- Произвольный процент — `w-1` … `w-99`; для всей ширины — `w-full`.
- Ширина по тексту — `w-fit`: элемент не шире содержимого и не шире родителя.
  `w-max` выводит текст одной строкой и выходит за родителя, если текст длиннее.
- `w-auto` возвращает ширину по умолчанию, например, чтобы отменить значение
  с меньшей ширины экрана.

```html
<div class="flex">
  <aside class="w-3/12">Меню</aside>
  <main class="w-9/12">Содержимое</main>
</div>

<img class="w-d6 h-d6" src="avatar.png" alt="">
```

### Ширина окна

`w-screen` равна ширине окна просмотра. `w-screen-small`,
`w-screen-large` и `w-screen-dynamic` берут малую, большую и текущую ширину
окна (`svw`, `lvw`, `dvw`) из переменных темы; в браузере без поддержки этих
единиц значение — ширина окна.

### Ширина по ширине экрана

Базовый класс задаёт ширину на узком экране, класс с префиксом — от указанной
ширины и шире.

```html
<div class="w-full md:w-1/2 xl:w-1/3">Карточка</div>
```

## Ограничения

- Ширина включает внутренние отступы и рамку: Framework задаёт всем элементам
  `box-sizing: border-box`.
- Доли и проценты считаются от ширины родителя. У строчного элемента ширина
  не действует — сделайте его блочным, например классом `inline-block`.
- Внутри окна с вертикальной полосой прокрутки `w-screen` шире области
  страницы и даёт горизонтальную прокрутку.
- У семейства нет префиксов состояния и отрицательных значений.
