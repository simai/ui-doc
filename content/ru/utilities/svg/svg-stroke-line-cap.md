# Концы обводки (Line Cap)

Классы задают `stroke-linecap`.

| Класс | Значение |
|:--|:--|
| `.linecap-butt` | `stroke-linecap: butt;` |
| `.linecap-round` | `stroke-linecap: round;` |
| `.linecap-square` | `stroke-linecap: square;` |
