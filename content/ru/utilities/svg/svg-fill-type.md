# Тип заливки

Классы `fill-nonzero` и `fill-evenodd` задают `fill-rule` — правило, по которому
браузер решает, что внутри фигуры. Берите `fill-evenodd`, чтобы вложенный
контур стал отверстием, а не закрасился.

## Пример

### Правила

Квадрат с вложенным квадратом и пятиконечная звезда, нарисованная одним контуром.

:::

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `fill-nonzero` | `fill-rule: nonzero` | — |
| `fill-evenodd` | `fill-rule: evenodd` | — |

Условия ([что это](/ru/guide/fundamentals/conditions/)): ширина экрана — нет; состояния — нет.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

### Какое правило выбрать

| Класс | Что закрашивает |
| :--- | :--- |
| `fill-nonzero` | всё, что окружено контуром, с учётом направления обхода — значение по умолчанию |
| `fill-evenodd` | области, окружённые нечётным числом контуров: вложенный контур становится отверстием |

```html
<svg class="svg-4 fill-primary fill-evenodd" viewBox="0 0 120 120" aria-hidden="true">
  <path d="M10 10h100v100h-100z M40 40h40v40h-40z"/>
</svg>
```

Свойство наследуется: класс на `<svg>` действует на все фигуры внутри.

## Ограничения

- У семейства нет префиксов ширины экрана и состояния.
