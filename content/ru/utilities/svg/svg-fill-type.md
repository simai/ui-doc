# Тип заливки

!rtags[fill]


Классы задают `fill-rule` у SVG-пути.

| Класс | Значение |
|:--|:--|
| `.fill-nonzero` | `fill-rule: nonzero;` |
| `.fill-evenodd` | `fill-rule: evenodd;` |

## Синтаксис

`fill-{nonzero|evenodd}`
