# Размер SVG-изображений

Классы `svg-*` задают `width` и `height` по текстовой шкале токенов.

Поддерживаемые значения: `svg-1/4`, `svg-1/3`, `svg-1/2`, `svg-1` ... `svg-12`.

## Синтаксис

`svg-{1/4|1/3|1/2|1..12}`
