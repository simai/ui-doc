# Внешний отступ

:badge[margin]{type=main scheme=on-surface size=1} :badge[margin-ext]{type=tonal scheme=neutral size=1} :badge[sm]{type=tonal scheme=neutral size=1} :badge[md]{type=tonal scheme=neutral size=1} :badge[lg]{type=tonal scheme=neutral size=1} :badge[xl]{type=tonal scheme=neutral size=1} :badge[xxl]{type=tonal scheme=neutral size=1}

Модификаторы `margin` управляют пространством вокруг элемента. Базовая шкала
использует токены шага `--sf-space-*`, а расширенная — фиксированные токены
системы размеров `--sf-a0` … `--sf-i9`.

## Таблица классов

| Класс                 | Значение                                |
|:----------------------|:----------------------------------------|
| `m-{n}` | `margin: var(--sf-space-{n});` |
| `-m-{n}` | `margin: calc(-1 * var(--sf-space-{n}));` |
| `m-top-{n}` | `margin-top: var(--sf-space-{n});` |
| `m-bottom-{n}` | `margin-bottom: var(--sf-space-{n});` |
| `m-inline-{n}` | `margin-inline: var(--sf-space-{n});` |
| `m-block-{n}` | `margin-block: var(--sf-space-{n});` |
| `m-inline-start-{n}` | `margin-inline-start: var(--sf-space-{n});` |
| `m-inline-end-{n}` | `margin-inline-end: var(--sf-space-{n});` |
| отрицательные варианты | те же классы с префиксом `-` и `calc(-1 * …)` |

Где `{n}` ∈ `0, 1/4, 1/3, 1/2, 1, 2, 3, 4, 5, 6, 7, 8`. Для
неотрицательных классов также доступно значение `auto`, например `m-auto` и
`m-inline-start-auto`.

### Фиксированная шкала размеров

| Класс | Значение |
|:---|:---|
| `m-{token}` | `margin: var(--sf-{token});` |
| `m-top-{token}` / `m-bottom-{token}` | Отступ по физической вертикальной стороне |
| `m-inline-start-{token}` / `m-inline-end-{token}` | Отступ по логической inline-стороне |
| отрицательные варианты | Те же классы с префиксом `-` |

`{token}` — значение от `a0` до `i9`, например `m-a4`, `m-e2` или
`-m-inline-end-b3`. Для расширенной шкалы нет сокращений `m-inline-*` и
`m-block-*`: они поддерживаются только базовой шкалой `--sf-space-*`.

## Синтаксис

Использование: `{контрольная точка}:{модификатор}` или просто `{модификатор}`

- Контрольная точка *(необязательный параметр)*: применяет модификатор начиная с определённого размера экрана (`sm`, `md`, `lg`, `xl`, `xxl`). Если не указана, действует для всех размеров.
- Модификатор *(обязательный параметр)*: классы базовой или фиксированной шкалы,
  перечисленные выше, а также поддерживаемые отрицательные варианты.

## Пример использования

```html
<div class="m-1/2">Отступ со всех сторон 1/2</div>
<div class="m-top-4 m-inline-start-1">Отступ сверху и по направлению письма</div>
<div class="m-inline-3">Отступ по inline-оси</div>
<div class="m-block-2">Отступ по block-оси</div>
<div class="-m-bottom-2">Отрицательный отступ снизу</div>
<div class="m-e2">Фиксированный отступ по токену --sf-e2</div>
```

## Адаптивность

Чтобы применять отступ с определённого брейкпоинта, добавьте префикс контрольной точки:

```html
<div class="md:m-4">
  <!-- Начиная с md отступ var(--sf-space-4) -->
</div>
```

## Направление, варианты и ограничения

- `inline-start` и `inline-end` автоматически меняют физическую сторону в
  LTR/RTL; `top` и `bottom` от направления письма не зависят.
- В принятой версии Core есть известное ограничение: если локальный контейнер
  `dir="rtl"` вложен в страницу с `dir="ltr"` (или наоборот), физические
  селекторы совместимости могут применить обе inline-стороны. Для направления всей страницы
  логические классы работают ожидаемо; дефект вложенного направления передан в
  Core и не скрывается обходным примером.
- У семей `margin` и `margin-ext` есть адаптивные варианты `sm`, `md`, `lg`,
  `xl` и `xxl`. Префикс ставится перед отрицательным классом: `md:-m-1`.
  Запись `-md:m-1` неверна. Варианты состояния `hover`, `focus` и `active`
  не выпускаются.
- Публичных псевдонимов у классов нет. Префикс `-` обозначает отрицательное
  значение, а не отдельный state-вариант.
