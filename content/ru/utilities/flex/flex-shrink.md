# Сжимаемость

Классы `shrink` и `shrink-none` задают `flex-shrink`: может ли флекс-элемент
стать меньше своего базового размера, когда элементы не помещаются в
контейнер. Берите `shrink-none` для иконок, аватаров, кнопок и других
элементов, размер которых нельзя менять.

## Пример

### shrink и shrink-none

Три элемента шириной `w-f0` вместе шире контейнера. С `shrink` они сжимаются
поровну; элемент с `shrink-none` сохраняет ширину, и сжимаются только соседи.

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `shrink` | `flex-shrink: 1` | — |
| `shrink-none` | `flex-shrink: 0` | — |

Условия ([что это](/ru/guide/fundamentals/conditions/)): ширина экрана — `sm:`, `md:`, `lg:`, `xl:`, `xxl:`; состояния — нет. Например: `sm:shrink`.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

### Как выбрать

- `shrink` — элемент может сжаться. Это значение по умолчанию у флекс-элементов;
  класс нужен, чтобы вернуть сжатие, отменённое на другой ширине экрана.
- `shrink-none` — элемент не становится меньше своего базового размера.

### Иконка рядом с длинным текстом

```html
<div class="flex gap-1 items-cross-center">
  <img class="shrink-none w-d0 h-d0" src="avatar.png" alt="">
  <span class="min-w-0">Длинное имя пользователя, которое переносится</span>
</div>
```

## Ограничения

- Флекс-элемент по умолчанию не сжимается уже своего самого длинного слова или
  картинки. Чтобы он мог стать уже содержимого, добавьте `min-w-0` (а в
  `flex-col` — `min-h-0`).
- Класс действует только на прямого потомка флекс-контейнера.
