# Базисный размер

Классы `basis-*` задают `flex-basis` — исходный размер флекс-элемента вдоль
основной оси: долей контейнера, процентом или ключевым словом. Берите их, когда
элементы строки должны делить ширину в заданной пропорции.

## Пример

### Доли

Доля считается от ширины контейнера. Подпись над образцом — классы элементов
строки.

:::

### Проценты

`basis-1` … `basis-100` задают процент ширины контейнера с шагом в один процент.

:::example {id="utilities/flex/flex-basis-percent" label="basis-10, basis-25, basis-50, basis-75, basis-100"}
:::

### auto, 0 и px

С `grow` оба элемента забирают свободное место. При `basis-auto` они
начинают с ширины своего текста, поэтому длинный остаётся шире; при `basis-0`
начинают с нуля и получают поровну.

:::example {id="utilities/flex/flex-basis-auto" label="basis-auto, basis-0 и basis-px"}
:::

### Ширина экрана

С префиксом ширины класс действует от указанной ширины и шире. Меняйте ширину
окна просмотра: на узком экране элементы идут по одному в строку, с ширины `md`
— по два, а во втором образце с ширины `lg` — по четыре.

:::example {id="utilities/flex/flex-basis-responsive" label="Базис по ширине экрана"}
:::

## Применение

### Как выбрать

- Доли `basis-1/2` … `basis-11/12` — для раскладок по колонкам: половины, трети,
  четверти, шестые и двенадцатые части.
- Проценты `basis-1` … `basis-100` — когда нужной доли нет в шкале.
- `basis-auto` — размер берётся из `width` или из содержимого.
- `basis-0` вместе с `grow` делит свободное место поровну, не глядя на
  содержимое; то же делает [`flex-1`](/ru/utilities/flex/flexibility/).
- `basis-full` и `basis-1/1` — вся ширина контейнера: элемент занимает
  отдельную строку в контейнере с переносом.

### Колонки с переносом

Базис работает вместе с `flex-wrap`: элементы с `basis-full` встают по одному,
а с префиксом ширины — по несколько в строку.

```html
<div class="flex flex-wrap">
  <div class="basis-full md:basis-1/2 lg:basis-1/3">Карточка</div>
  <div class="basis-full md:basis-1/2 lg:basis-1/3">Карточка</div>
  <div class="basis-full md:basis-1/2 lg:basis-1/3">Карточка</div>
</div>
```

## Ограничения

- Базис — исходный размер, а не итоговый. Если `flex-shrink` разрешает сжатие,
  а места не хватает, элемент станет уже; если `flex-grow` разрешает рост —
  шире. Сумма долей вместе с `gap` больше ширины контейнера, поэтому элементы с
  `basis-1/2` и промежутком между ними сжимаются.
- Во флекс-контейнере с `flex-col` базис задаёт высоту, а не ширину.
- `basis-0` не делает элемент уже его минимального содержимого: длинное слово
  или картинка удерживают ширину.
