# Размер маски

Классы этой группы задают `mask-size` — размер изображения маски относительно
элемента. Берите их, чтобы маска вписалась в элемент, заполнила его или
растянулась по нему.

## Пример

### Размеры

Маска в форме листа без повтора, по центру. Пунктирная рамка показывает границы элемента с маской.

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `mask-auto` | `mask-size: auto` | — |
| `mask-cover` | `mask-size: cover` | — |
| `mask-contain` | `mask-size: contain` | — |
| `mask-full` | `mask-size: 100% 100%` | — |

Условия ([что это](/ru/guide/fundamentals/conditions/)): ширина экрана — нет; состояния — нет.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

Классы маски не задают саму маску: изображение маски (`mask-image`) задаётся
в CSS проекта, как в примерах на этой странице.

### Какой размер выбрать

| Класс | Что делает |
| :--- | :--- |
| `mask-auto` | собственный размер изображения — значение по умолчанию |
| `mask-contain` | вписывает целиком, сохраняя пропорции |
| `mask-cover` | заполняет элемент, сохраняя пропорции; лишнее обрезается |
| `mask-full` | растягивает на всю ширину и высоту, пропорции не сохраняются |

```html
<div class="mask-repeat-none mask-center mask-contain">…</div>
```

## Ограничения

- У семейства нет префиксов ширины экрана и состояния.
