# Режим маски

Классы `mask-alpha`, `mask-luminance` и `mask-source` задают `mask-mode` — какая
составляющая изображения маски управляет видимостью элемента. Берите
`mask-luminance`, когда маска нарисована чёрным и белым, а не прозрачностью.

## Пример

### Режимы

Маска — непрозрачный градиент от чёрного к белому. Пунктирная рамка показывает границы элемента с маской.

## Классы

| Класс | CSS | Значения |
|:---|:---|:---|
| `mask-alpha` | `mask-mode: alpha` | — |
| `mask-luminance` | `mask-mode: luminance` | — |
| `mask-source` | `mask-mode: match-source` | — |

Условия ([что это](/ru/guide/utilities/conditions/)): ширина экрана — нет; состояния — нет.

Классы и переменные собраны из CSS выпуска и обновляются вместе с ним.

## Применение

Классы маски не задают саму маску: изображение маски (`mask-image`) задаётся
в CSS проекта, как в примерах на этой странице.

### Какой режим выбрать

| Класс | Элемент виден там, где маска |
| :--- | :--- |
| `mask-alpha` | непрозрачна |
| `mask-luminance` | светлая; чёрный скрывает, белый показывает |
| `mask-source` | по типу источника: для изображения и градиента — как `mask-alpha`, для элемента `<mask>` SVG — по его [типу маски](/ru/utilities/mask/mask-type/); значение по умолчанию |

```html
<div class="mask-luminance">…</div>
```

## Ограничения

- Классы задают свойство без префикса `-webkit-`: браузер, который знает
  маску только с префиксом, режим не применяет.
- У семейства нет префиксов ширины экрана и состояния.
