# Тип маски

`mask-type` задает, какой канал использовать для вычисления маски.

## Таблица классов

| Класс                | Значение              |
|:---------------------|:----------------------|
| .mask-type-alpha     | mask-type: alpha;     |
| .mask-type-luminance | mask-type: luminance; |
