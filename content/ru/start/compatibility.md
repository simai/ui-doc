# Совместимость и обновление

Эта редакция документации описывает SIMAI Framework `5.4`. В проекте всегда
фиксируйте точную версию подключённы
 файлов.

## Что должно иметь одну версию

- Core;
- каталог утилит;
- компоненты;
- Smart Components, если они используются.

Не соединяйте `core.js` одной версии с CSS или компонентами другой. Для CDN
указывайте тег в URL. При локальном размещении копируйте весь каталог `distr`
из одной поставки.

## Порядок обновления

1. Прочитайте список изменений новой версии.
2. Обновите копию `distr` или тег в CDN URL.
3. Очистите кеш приложения и браузера, если URL файлов не изменился.
4. Проверьте основные страницы в Network и Console.
5. Проверьте адаптивные состояния, темы, клавиатурный фокус и интерактивные
   компоненты.
6. Зафиксируйте новый номер версии в конфигурации проекта.

Для крупного обновления сначала выполните эти шаги на тестовом окружении.
