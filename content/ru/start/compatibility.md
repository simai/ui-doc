# Совместимость и обновление

Документация описывает базовую версию **SIMAI Framework 5.4.0**. Текущая
сборка использует проверяемую пару-кандидат, а не плавающие ветки.

## Закреплённая пара документации

| Часть | Ревизия |
|:---|:---|
| Идентификатор совместимости | `simai-framework-5.4.0-candidate-2742ed22-b57afb30` |
| UI Core, утилиты и компоненты | `2742ed22730b3f37cd26ab72c03621637a464ee0` |
| Smart Components | `b57afb30c9b790212afcf451e16ae6e27a5ab6af` |
| Сводный реестр контрактов | `8fea5eb45d8cf0464774ad29c34abe1547d9ce63` |
| Статус | кандидат; `production_ready: false` |

Статус кандидата означает, что состав зафиксирован и пригоден для проверки
документации, но ещё не объявлен production-релизом. После приёмки пара должна
получить опубликованные неизменяемые теги; сама версия останется `5.4.0` до
реализации рекомендаций по развитию.

## Что обновляется вместе

- `core.css`, `core.js` и весь каталог `distr`;
- Loader-реестр правил;
- каталог `smart`, если проект использует Smart Components;
- lock или запись о версии в проекте.

Не соединяйте Core одной ревизии с правилами, CSS или JavaScript другой.

## Порядок обновления

1. Выберите опубликованную совместимую пару или подтверждённый кандидат для
   тестового окружения.
2. Полностью замените `distr` и, при необходимости, `smart`.
3. Обновите неизменяемые URL или lock проекта.
4. Проверьте Network и Console, основные страницы, темы и адаптивные состояния.
5. Выполните клавиатурный и accessibility smoke интерактивных компонентов.
6. Только после приёмки перенесите ту же пару в рабочее окружение.
