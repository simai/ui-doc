# Загрузчик

Загрузчик в
одит в `core.js`. Он анализирует разметку страницы, определяет
используемые утилиты и компоненты, разрешает и
 зависимости и подключает
необ
одимые CSS- и JavaScript-файлы.

## Настройка пути

Задайте базовый URL каталога `distr` до подключения `core.js`:

```html
<script>
  window.sfPath = '/assets/simai-framework/distr';
</script>
<script src="/assets/simai-framework/distr/core/js/core.js"></script>
```

Из этого пути загрузчик формирует адреса каталогов:

- `${sfPath}/utility` — CSS-утилиты;
- `${sfPath}/component` — компоненты.

Для Smart Components можно отдельно задать `window.sfSmartPath` до загрузки
Core.

## Как проис
одит загрузка

1. Core создаёт экземпляр `window.SF.Loader`.
2. Загрузчик получает реестр правил `SF.RuleLoader`.
3. Начальная разметка проверяется по именам классов, атрибутам и тегам.
4. Для найденного правила добавляются его зависимости.
5. CSS и JavaScript каждого модуля подключаются один раз.
6. `MutationObserver` отслеживает добавленную и изменённую разметку, поэтому
   модули могут подгружаться после первого отображения страницы.

Правило описывает имя и тип модуля, наличие CSS и JavaScript, признаки в
разметке и зависимости. Реестр поставляется вместе с Framework; редактировать
его в прикладном проекте обычно не требуется.

## Явное подключение модуля

Если модуль нельзя определить по разметке заранее, укажите его имя в атрибуте
`sf-asset`:

```html
<div sf-asset="dropdown"></div>
```

Загрузчик прочитает значение атрибута и добавит соответствующий модуль в
очередь. Имя должно совпадать с записью в `SF.RuleLoader`.

## События

| Событие | Где слушать | Когда возникает |
|:---|:---|:---|
| `sf-loader-init` | `window` | создан `SF.Loader` |
| `sf-loader-ready` | `window` | начальная загрузка завершена |
| `&lt;name&gt;:ready` | `window` | зарегистрирован компонент `&lt;name&gt;` |
| `component:ready` | `document` | зарегистрирован любой компонент |
{.table}

Подпишитесь до подключения `core.js`, если событие нужно поймать при первом
запуске:

```html
<script>
  window.addEventListener('sf-loader-ready', () => {
    console.log('SIMAI Framework готов');
  });
</script>
```

Событие `sf-loader-init` передаёт экземпляр загрузчика в `event.detail.loader`.
`component:ready` передаёт имя компонента в `event.detail.name`.

## Диагностика

В консоли браузера проверьте наличие экземпляра:

```js
window.SF?.Loader
```

Если модуль не загрузился:

1. проверьте `window.sfPath` и ответы Network;
2. убедитесь, что имя есть в `SF.RuleLoader`;
3. проверьте разметку или значение `sf-asset`;
4. дождитесь `sf-loader-ready`;
5. исключите кеширование файлов от другой версии Framework.

Загрузчик работает в браузере. PHP-, Laravel- или Битрикс-обёртка для него не
нужна: серверу достаточно корректно публиковать каталог `distr`.
