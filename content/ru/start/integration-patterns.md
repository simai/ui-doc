# Интеграция в веб-проект

SIMAI Framework работает в браузере, поэтому способ интеграции одинаков для
разных backend: приложение публикует каталог `distr`, а основной шаблон
подключает Core.

## Общий рецепт

1. Выберите [CDN или локальные файлы](/ru/start/installation/).
2. Подключите `core.css` в `head`.
3. Перед `core.js` задайте `window.sfPath`.
4. Размещайте разметку и классы Framework в шаблонах приложения.
5. Проверьте загрузку на публичном URL приложения.

## Что настраивает приложение

| Задача | Ответственность интеграции |
| --- | --- |
| Публикация файлов | Публичный URL, MIME-типы и кеширование |
| Версия | Один зафиксированный тег или набор локальных файлов |
| Шаблоны | Подключение Core в общем layout и классы в HTML |
| Обновление | Одновременная замена `distr` и номера версии |
| Проверка | Network, Console, адаптивность и клавиатурный фокус |

## Laravel, Larena, Bitrix и другие стеки

В Laravel и Larena подключение обычно размещают в основном Blade-layout, а
`distr` публикуют в `public/assets`. В 1С-Битрикс пути можно добавить через
шаблон сайта или менеджер ресурсов. В статическом проекте достаточно обычных
тегов `link` и `script`.

Backend-обёртка для загрузчика не требуется: обнаружение утилит и компонентов
происходит в браузере. Если asset pipeline меняет публичный путь, передайте
результирующий URL через `window.sfPath`.
