# Лента

:badge[sf-list-feed]{variant=tonal scheme=primary size=1/2} :badge[1.1.1]{variant=outline scheme=on-surface size=1/2}

Лента — прокручиваемая колонка записей, которую читают от новой записи внизу:
переписка, комментарии к задаче, история действий, журнал, ход выполнения
задачи. Она держит место чтения: ранняя история добавляется сверху, не сдвигая
читаемое, а новая запись тянет колонку вниз, только если человек уже был внизу
или это его собственная запись.

Список, с которым что-то делают (открыть, переименовать, действия строки), —
[Список](/ru/smart/content/list/). Лента ничего не загружает и ничего не
решает: каждая просьба уходит событием, а что такое запись и как она выглядит,
решает хост.

## Разметка

В разметке — тег с доступным именем; высоту ленте даёт контейнер. Сам тег —
`display: contents`, а колонка `.sf-list-feed` растягивается во
flex-контейнере (`flex: 1`) и прокручивается внутри:

```html
<div style="display: flex; flex-direction: column; block-size: 32rem">
  <sf-list-feed label="Комментарии">
    <div slot="empty">Комментариев пока нет</div>
  </sf-list-feed>
</div>
```

```js
const feed = document.querySelector('sf-list-feed');
feed.setItems({items: await api.comments(taskId), options: {hasMore: true}});
```

Запись — обычные данные. Лента читает `id` (обязательный постоянный ключ),
`author`, `own`, `growing`, `revision`, `wait` (`delayed`, `stopped`,
`network`, `none`), `error` (`{reason, message}`), а для отрисовки и
объявления по умолчанию — `author-name` и `text`. Остальные поля — для
функции отрисовки хоста.

Слот `empty` показывается вместо колонки, пока записей нет.

## Состояния

### Пусто

Пока записей нет, вместо колонки виден слот `empty`.

:::example {id="smart-components/list-feed/state-empty" label="Пусто"}
:::

### Запись пишется

Ответ, который приходит по частям, — поток: у записи `growing: true`, пока
другая сторона её пишет, и каждая часть — новый `upsert()` с более длинным
текстом. Пока запись растёт, у неё `aria-busy`, и она не объявляется.

:::example {id="smart-components/list-feed/state-growing" label="Запись пишется"}
:::

## Поведение

### Ранняя история

При `has-more` вверху видна кнопка «Показать предыдущие», а верх колонки один
раз просит предыдущие записи: приходит `sf-list-feed-load-more` с
`{direction: 'before', before}`, где `before` — `id` первой показанной записи.
Ответ передайте `prependItems({items, options: {hasMore}})`: записи встают сверху, а
читаемое не сдвигается. Если загрузить не удалось, вызовите
`earlierFailed()`, и кнопка снова нажимается.

```js
feed.addEventListener('sf-list-feed-load-more', async (event) => {
  const page = await api.comments(taskId, {before: event.detail.before});
  feed.prependItems({items: page.items, options: {hasMore: page.hasMore}});
});
```

### Новые и изменившиеся записи

`upsert({item})` добавляет запись в конец или перерисовывает её на месте:
элемент записи остаётся тем же, и фокус на кнопке внутри растущей записи не
сбрасывается. `upsert({item: saved, options: {replaces: localKey}})` заменяет
запись с местным ключом ответом сервера, не меняя её места. `changes` задаёт,
как сравнивать две записи одного `id`: `content` (по умолчанию — поля и
`view`) или `revision` (хост повышает её с каждым изменением).

Кнопка «К последней записи» возвращает вниз и переносит туда фокус; то же
делает `scrollToLatest({options: {instant, focus}})`. `isAtLatest()` отвечает, виден ли
конец ленты.

### Своя отрисовка записи

Свойство `renderItem(entry, context)` возвращает узел, строку (она выводится
как текст) или `null`. В `context` — `view`, `previous`, `next`, `first`,
`last` (начало и конец серии одного автора), `own`, `growing`, `index`,
`document` и `feed`. Без функции лента выводит имя автора над первой записью
серии и текст — только текст, никогда разметку: хост, у которого есть HTML,
рисует и очищает его сам.

:::example {id="smart-components/list-feed/custom-render" label="Записи"}
:::

Рисовальщик может опираться на классы `.sf-list-feed__item` с модификаторами
`--own`, `--first`, `--last` (серии) и `--end` (последняя запись).

### События потока

Растущая запись сообщает о себе событиями: `sf-list-feed-begun` — пришла,
`sf-list-feed-chunk` — изменилась и перерисована, затем ровно одно из
`sf-list-feed-completed`, `sf-list-feed-failed` (`{id, reason, message}`) и
`sf-list-feed-cancelled`. `cancel(id)` перестаёт рисовать рост сразу; сказать
другой стороне остановиться — дело хоста.

### Методы

Каждый метод, кроме `isAtLatest()`, отвечает исходом: `{outcome: 'applied'}`
или `{outcome: 'refused', reason}`.

| Метод | Что делает |
|:---|:---|
| `setItems({items, options: {hasMore}})` | Заменить ленту и показать её конец; ничего из неё не объявляется. |
| `prependItems({items, options: {hasMore}})` | Ранняя история сверху, не сдвигая читаемое; завершает запрос. |
| `upsert({item, view?, options: {replaces?}})` | Добавить в конец или перерисовать на месте. |
| `setView({id, view})` | Дописать в `view` показанной записи. |
| `detach(id)` | Снять одну запись; её поток кончается `cancelled`. |
| `cancel(id)` | Перестать рисовать растущую запись. |
| `redraw(id?)` | Нарисовать заново одну запись или все. |
| `requestEarlier()` | Попросить ранние записи, как кнопка. Отказ `loading`, `no-more`, `prevented`. |
| `earlierFailed()` | Хост не смог загрузить: кнопка снова нажимается. |
| `scrollToLatest({options: {instant, focus}})` | К последней записи; с `focus` фокус переходит на неё. |
| `announce(text)` | Сказать один раз через вежливую живую область (до 240 символов). |

## Доступность

- Прокручиваемая область — одна остановка `Tab` с именем из `label` (по
  умолчанию «Лента» на русской странице и «Feed» на остальных).
- Внутри — журнал (`role="log"`) с выключенным `aria-live`; что нового,
  говорит одна вежливая живая область. При `live="polite"` (по умолчанию)
  законченная чужая запись объявляется один раз; `live="off"` оставляет
  объявления хосту — метод `announce()`. Свойство `announceItem(entry,
  context)` задаёт, что сказать о записи.
- Из записи в фокусе `↑` и `↓` ведут к соседней, `Home` и `End` — к первой и
  последней загруженной; `↑` на первой просит ранние записи. Клавиши на
  собственных кнопках записи остаются их.
- Плавная прокрутка следует `prefers-reduced-motion`.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `changes` | строка | `content` | `content`, `revision` | Как сравниваются две записи с одним `id`. |
| `has-more` | да/нет | нет | — | Есть ранняя история: видна кнопка «Раньше», а достижение верха её просит. |
| `label` | строка | — | — | Доступное имя области; пустое — «Лента» на языке страницы. |
| `live` | строка | `polite` | `polite`, `off` | polite — законченная чужая запись объявляется один раз. off — объявляет приложение через `announce()` или никто. |
| `items` | список: объект | `[]` | — | Записи в порядке показа, сначала старые; обычные данные, у каждой есть `id`. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | `default` | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `setItems(args: object)` | объект | Заменяет всю ленту и показывает её конец. Её содержимое не объявляется. |
| `prependItems(args: object)` | объект | Ранняя история сверху, без сдвига читаемого; завершает запрос ранней истории. |
| `upsert(args: object)` | объект | Добавляет запись в конец или обновляет её на месте; перерисовывает, только если изменилось то, что она показывает. |
| `setView(args: object)` | объект | Дописывает в `view` уже показанной записи. |
| `detach(args: object\|string)` | объект | Снимает одну запись; её поток заканчивается как отменённый. `remove()` остаётся браузерным. |
| `cancel(args: object\|string)` | объект | Сразу перестаёт рисовать растущую запись; поток заканчивается как отменённый. |
| `redraw(args?: object\|string)` | объект | Рисует заново одну запись или все, когда изменились собственные данные функции отрисовки. |
| `requestEarlier()` | объект | Просит раннюю историю, как кнопка и достижение верха; пока запрос не завершён — ничего. |
| `earlierFailed()` | объект | Приложение не смогло загрузить раннюю историю: кнопку снова можно нажать. |
| `scrollToLatest(args?: object)` | объект | Прокручивает к последней записи; с `focus` фокус переходит на неё. |
| `announce(args: object\|string)` | объект | Говорит один раз через вежливую живую область ленты (обрезается до 240 символов). |
| `isAtLatest()` | да/нет | Виден ли конец ленты. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-list-feed-load-more` | `{ direction?: any, before: any }` | Запрошена более ранняя история: `{direction: before, before}`. Отмена события — то же, что `earlierFailed()`. |
| `sf-list-feed-begun` | `{ id: any }` | Пришла растущая запись. |
| `sf-list-feed-chunk` | `{ id: any, revision?: string }` | Растущая запись изменилась и перерисована на месте. |
| `sf-list-feed-completed` | `{ id: any }` | Сообщение перестало расти целиком. |
| `sf-list-feed-failed` | `{ id: any, reason: string, message: string }` | Сообщение перестало расти с ошибкой: `{id, reason, message}`. |
| `sf-list-feed-cancelled` | `{ id: any }` | Поток остановлен: `cancel`, остановленное ожидание, снятая запись или замена ленты. |
