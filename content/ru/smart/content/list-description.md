# Список сведений

:badge[sf-list-description]{variant=tonal scheme=primary size=1/2} :badge[1.1.0]{variant=outline scheme=on-surface size=1/2}

Показывает факты парами «подпись — значение»: сводку сайта, сведения о
сервере, шапку записи, параметры задания, данные лицензии. Значение может
быть ссылкой, моноширинным путём с кнопкой копирования, со значком состояния
и строкой пояснения. Список только показывает то, что у страницы уже есть:
ничего не загружает и не сохраняет.

Править значения на месте — [Свойства записи](/ru/pro/admin/property-view/).

## Разметка

Строки передайте JSON-блоком, который печатает сервер, или свойством
`items`:

```html
<sf-list-description label="Сведения о сайте">
  <script type="application/json" data-sf-settings>
    {"items": [
      {"label": "Адрес", "value": "demo-static.test", "href": "https://demo-static.test/"},
      {"label": "Корень сайта", "value": "/var/www/demo-static/public", "mono": true, "copy": true},
      {"label": "Сертификат", "value": "Действует до 12 декабря", "status": "success",
       "hint": "Let's Encrypt, продлевается сам"}
    ]}
  </script>
</sf-list-description>
```

Поля строки:

| Поле | | Значение |
|:---|:---|:---|
| `label` | обязательно | Подпись; строка без неё не показывается. |
| `value` | | Значение, всегда текст, не разметка: число пишется как есть, список — через запятую. |
| `id` | | Имя строки; приходит в событии ссылки. |
| `mono` | | Моноширинный шрифт: путь, хеш, ключ. |
| `copy` | | Кнопка копирования после значения. |
| `href` | | Значение становится ссылкой. |
| `status` | | `success`, `warning`, `error` или `info` — значок состояния перед значением; `neutral` или пусто — без значка. |
| `hint` | | Строка пояснения под значением. |

Подписи стоят в своей колонке шириной по самой длинной подписи, но не шире
`--sf-list-description-label-width` (40 %); значения — рядом, с одной линии.
`label` элемента — имя списка для экранного диктора, если над списком нет
заголовка. Без строк список ничего не рисует.

## Варианты

### Раскладка

`layout` • по умолчанию `auto` • [справочник](#атрибуты)

`columns` — всегда две колонки, `stacked` — подпись над значением, `auto` —
колонки, а в колонке уже 24rem (телефон, узкая боковая панель) подпись над
значением.

:::example {id="smart-components/list-description/layout" label="Раскладка" preview=sandbox}
:::

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

`1/2` — для боковой панели, `1` — обычный, `2` — крупный. От размера зависят
подпись, значение, пояснение и высота строки: строка в одну линию высотой с
поле того же размера.

:::example {id="smart-components/list-description/sizes" label="Размеры 1/2, 1 и 2" preview=sandbox}
:::

### Линии между строками

`dividers` • по умолчанию выключено • [справочник](#атрибуты)

Тонкая линия между строками — для длинного списка или списка в таблице
настроек.

:::example {id="smart-components/list-description/dividers" label="Без линий и с линиями" preview=sandbox}
:::

### Длинные значения

`overflow` • по умолчанию `wrap` • [справочник](#атрибуты)

`wrap` переносит длинное значение на новые строки — путь и хеш тоже, страницу
они не раздвигают. `truncate` держит значение в одну строку с многоточием:
целиком оно видно во всплывающей подсказке и разворачивается на месте, пока
стоит в фокусе — после нажатия или `Tab`.

:::example {id="smart-components/list-description/overflow" label="Перенос и многоточие" preview=sandbox}
:::

## Поведение

### Ссылка и копирование

Нажатие на значение-ссылку сначала отправляет
`sf-list-description-navigate` с `{id, href}`. Это просьба: страница с
маршрутизатором отменяет событие и переходит сама; без отмены браузер
переходит по `href`. Нажатие с клавишей-модификатором или средней кнопкой
открывает ссылку в другом месте и ничего не спрашивает. В примере в начале
страницы событие отменено и показано в журнале.

Кнопка копирования — [Кнопка копирования](/ru/smart/actions/copy-button/) на
ступень меньше списка, по центру первой строки значения; высоту строки она не
увеличивает.

```js
const facts = document.querySelector('sf-list-description');
facts.addEventListener('sf-list-description-navigate', (event) => {
  event.preventDefault();
  router.go(event.detail.href);
});
```

## Доступность

- Внутри — список определений `dl`: подпись — `dt`, значение — `dd`.
  Экранный диктор называет число пар и связывает значение с подписью.
- С `label` список — группа с этим именем.
- Состояние произносится словом перед значением, значок — только картинка.
- Кнопка копирования называется «Скопировать: подпись».
- Сам список фокус не берёт: `Tab` проходит по ссылкам, кнопкам копирования
  и обрезанным значениям; `Enter` открывает ссылку или копирует.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `label` | строка | пусто | — | Имя списка для экранного диктора, если над ним нет заголовка, который его называет. |
| `size` | строка | `1` | `1/2`, `1`, `2` | Размер списка: от него зависят подпись, значение, пояснение и высота строки. `1/2` — для боковой панели. |
| `layout` | строка | `auto` | `auto`, `columns`, `stacked`, `grid` | `columns` — подписи в своей колонке (шириной по самой длинной подписи, до `--sf-list-description-label-width`), значения рядом; `stacked` — каждая подпись над своим значением; `auto` — колонки, а в колонке уже 24rem (телефон) — друг над другом; `grid` — сводка под заголовком записи: подпись над значением, столько колонок шириной 11rem, сколько помещается, но не больше `columns`, каждое значение в одну строку с многоточием и полным текстом в `title`. |
| `columns` | строка | `4` | `1`, `2`, `3`, `4` | При `layout="grid"` — наибольшее число колонок (столько, сколько помещается по 11rem). |
| `dividers` | да/нет | нет | — | Тонкая линия между строками. |
| `overflow` | строка | `wrap` | `wrap`, `truncate` | Значение длиннее колонки: `wrap` переносит его на новые строки в любом месте, так что путь и хеш тоже переносятся; `truncate` держит его в одну строку с многоточием, а целиком значение видно в подсказке под указателем и пока оно в фокусе. |
| `empty-text` | строка | — | — | Что показывает пункт без значения, если у пункта нет своих слов `empty`; если не задано — «Не указан» (Not set). |
| `heading-level` | целое число | `3` | от 2; до 6 | Уровень заголовков разделов в структуре страницы. |
| `items` | список | `[]` | — | Сведения по порядку, каждое — `{label, value, id?, hint?, mono?, numeric?, copy?, href?, status?, badge?, help?, empty?, action?}`, и разделы `{type: "section", label, id?, action?}`, которые открывают раздел записи. Свойство или JSON-остров, который печатает сервер. `value` — текст (число пишется как есть, цифрами одной ширины); у пустого значения (ни текста, ни значка) показывается `empty` пункта или `empty-text`, и тогда нет ни ссылки, ни кнопки копирования, ни статуса. `mono` пишет значение моноширинным шрифтом (путь, хеш, ключ), `numeric` — цифрами одной ширины (сумма), `copy` добавляет кнопку копирования (видна всегда), `href` делает значение ссылкой, `status` ставит перед ним иконку статуса (`success`, `warning`, `error`, `info`; `neutral` или `none` ничего не рисуют; `none` со значком — значок единственная метка), `badge` рисует `sf-badge` в строке значения (`{text, status \| scheme, icon?}`), `hint` — строка под значением, `help` ставит метку справки (`sf-help-mark`) после подписи, `action` — одну кнопку-ссылку после значения, у пустого значения — и «Указать» (`{label, event?, href?}`; нажатие запрашивает `apply`, а с `href` — `navigate`). Подпись раздела — его заголовок уровня `heading-level`, действие стоит в конце его шапки. Все подписи записи с разделами делят одну колонку. Пункт без подписи пропускается. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

Публичных методов нет.

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-list-description-navigate` | `{ id: string, href: string }` | Человек нажал ссылку значения или ссылку действия (действие с `href`); в событии `{id, href}`. Это запрос: страница отменяет его, чтобы перейти сама (роутер); не отменили — браузер переходит по `href`. Нажатие с клавишей-модификатором или средней кнопкой открывает ссылку в другом месте и ничего не спрашивает. |
| `sf-list-description-apply` | `{ action: string, scope: string, ids: array, id: string, kind: string }` | Человек нажал кнопку действия пункта или раздела без `href`: `action` — событие действия (`edit`, если оно не названо), `ids` и `id` — идентификатор пункта или раздела, `kind` — `item` или `section`. Страница выполняет действие (открывает форму, диалог) и задаёт список заново. |
