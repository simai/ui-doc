# Справочная ссылка

:badge[sf-reference-link]{type=tonal scheme=primary size=1/2} :badge[1.0.5]{type=outline scheme=on-surface size=1/2}

Справочная ссылка ведёт на реальный адрес и показывает рядом короткую справку:
путь, источник, номер документа. Берите её, когда читателю важно видеть, куда
он перейдёт. Для обычной ссылки в тексте и для действия без адреса она не
нужна.

То же на классах — [Справочная ссылка](/ru/components/content/reference-link/):
элемент строится на классах этого компонента; для статической разметки без
JavaScript.

## Разметка

Ссылке нужны подпись и адрес:

```html
<sf-reference-link label="Руководство" text="ui.simai.io/ru/guide/" href="https://ui.simai.io/ru/guide/"></sf-reference-link>
```

`label` — видимый текст ссылки; называйте в нём место назначения, а не
действие. `text` — справка рядом: путь, домен, номер раздела. `href`
обязателен для доступной ссылки: без него подпись выводится текстом без
перехода. Слоты `label` и `text` заменяют подпись и справку разметкой.

`target` задаёт окно перехода, по умолчанию `_self`. Для другого окна
компонент сам добавляет `rel="noopener noreferrer"`.

## Варианты

### Без рамки

`appearance` выбирает вид:

- `card` — ссылка в собственной рамке с фоном и отступами, вид по умолчанию;
- `plain` — одна ссылка шириной в свой текст. Берите её внутри того, что
  уже является рамкой: поля карточки записи, ячейки таблицы.

:::example {id="smart-components/reference-link/plain" label="Виды card и plain"}
:::

### Иконка

`icon` — значок перед подписью, по умолчанию стрелка `arrow_forward`. Пустой
`icon=""` убирает значок — для ссылки рядом с собственной подписью.

:::example {id="smart-components/reference-link/icon" label="Стрелка, свой значок и без значка"}
:::

### Размер

`size` (`1/2`, `1`, `2`) делает ссылку элементом формы этого размера — для
ряда полей.

:::example {id="smart-components/reference-link/sizes" label="Размеры 1/2, 1 и 2"}
:::

### По строке текста

`line` (`1/2`, `1`, `2`) ставит ссылку без рамки на строку текста этого
размера — для ячейки таблицы, чтобы строка не стала выше.

:::example {id="smart-components/reference-link/line" label="Ссылка в строках текста трёх размеров"}
:::

## Состояния

### Недоступна

`disabled` выводит подпись без ссылки: элемент не получает фокус, а нажатия
на нём гасятся. Адрес при этом не нужен — не оставляйте `href` у ссылки,
которая никуда не ведёт.

:::example {id="smart-components/reference-link/state-disabled" label="Недоступная ссылка без адреса"}
:::

## Поведение

### Нажатие

`onClick(handler)` подписывает обработчик на обычное событие `click`; своих
событий у компонента нет.

## Доступность

- Доступное имя ссылки — `label`. Справка из `text` стоит рядом и в имя не
  входит; если без неё ссылку не понять, задайте `aria-label`, который
  объединяет оба смысла.
- Ссылке в новом окне задайте `aria-label`, который об этом сообщает, как во
  втором примере: «Исходный код, откроется в новой вкладке».
- Значок декоративен и скрыт от экранного диктора.
- Ссылка — одна остановка `Tab`, переход — `Enter`. Недоступная ссылка в
  порядок `Tab` не входит и отмечена `aria-disabled="true"`.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `appearance` | строка | `card` | `card`, `plain` | card — ссылка в собственном блоке: рамка, заливка и отступы. plain — только ссылка шириной по тексту, для ссылки внутри того, что уже является блоком, — поля записи, ячейки таблицы, — где вторая рамка выглядит как элемент управления, которым значение не является. |
| `disabled` | да/нет | нет | — | Отображает недоступную ссылку без фокуса и без перехода. |
| `href` | строка | пусто | — | Реальное место навигации. Обязательно для доступной ссылки. |
| `icon` | строка | `arrow_forward` | — | Нет атрибута — стрелка; пусто — без значка |
| `label` | строка | пусто | — | Видимая подпись ссылки, описывающая место назначения. |
| `line` | строка | пусто | пусто, `1/2`, `1`, `2` | Занимает строку текста этого размера формы как ссылка без карточки — для ячейки таблицы, чтобы строка сохраняла высоту элемента управления. |
| `size` | строка | пусто | пусто, `1/2`, `1`, `2` | Размер формы: ссылка становится элементом управления этого размера — для ряда полей или ячейки таблицы. Пустое значение сохраняет отступы карточки. |
| `target` | строка | `_self` | — | Нативная цель контекста просмотра. Укажите в имени, что навигация открывает новый контекст. |
| `text` | строка | пусто | — | Компактный маршрут, источник или ссылка рядом с подписью. |
| `aria-label` | строка | пусто | — | — |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `onClick(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик click на хост-элементе. |
