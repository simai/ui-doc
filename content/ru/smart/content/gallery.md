# Галерея

:badge[sf-gallery]{variant=tonal scheme=primary size=1/2} :badge[1.1.11]{variant=outline scheme=on-surface size=1/2}

Галерея показывает упорядоченный набор материалов — изображения, карточки,
макеты — слайдером на странице и в окне на весь экран, и оба вида держат одно
текущее положение. Она собрана из [смарт-слайдера](/ru/smart/forms/slider/) и
[модального окна](/ru/smart/overlays/modal/); для ленты без увеличения
достаточно одного слайдера.

## Разметка

Каждый значимый дочерний элемент с `slot="slide"` — один материал;
`heading` называет галерею:

```html
<sf-gallery heading="Проект">
  <img slot="slide" src="/photos/1.jpg" alt="Фасад">
  <img slot="slide" src="/photos/2.jpg" alt="Холл">
</sf-gallery>
```

Пробелы и комментарии между материалами не считаются. Составную карточку —
изображение, подпись, ссылку — держите в одном корневом элементе, например
`figure`: галерея не собирает карточку из соседних элементов.

Подпись и альтернативный текст принадлежат содержимому. Компонент не
придумывает их по имени файла: у каждого изображения должен быть свой `alt`.

## Варианты

### Без модального окна

`lightbox="false"` оставляет галерею в потоке страницы, без модального окна.
Так делайте, когда увеличение не нужно или материалы уже занимают крупную
область. `inline="false"`, наоборот, убирает встроенный слайдер, если окно
включено: галерея открывается только в модальном окне из скрипта.

## Поведение

### Галерея из ссылок

Готовую сетку миниатюр не нужно переписывать в `<sf-gallery>`. Отметьте
ссылки одинаковым `data-sf-gallery`: нажатие на любую из них открывает
модальную галерею из всех ссылок группы, начиная с нажатой. Источник
берётся из `data-sf-src`, `href` или вложенного изображения, подпись — из
`data-caption`, `title` или `alt` изображения.

:::example {id="components/gallery/delegated" label="Сетка ссылок"}
:::

Параметры такой галереи задаются на ссылках с префиксом:
`data-sf-gallery-loop`, `data-sf-gallery-width`, `data-sf-gallery-title` и
другие имена атрибутов галереи.

### Слайдер и модальное окно

`arrows`, `dots`, `thumbs` и `loop` меняют способ листания, не меняя набор
материалов; `space-between` и `speed` — расстояние между слайдами и скорость
перехода. Модальное окно настраивается атрибутами галереи с теми же именами,
что у модального окна: `heading` (прежнее имя — `title`), `text`,
`show-header`, `show-close`, `close-on-esc`, `close-on-overlay`, `position`,
`fullscreen`, `width`, `height`. Внешний вид частей задают
`lightbox-class` (прежнее имя — `root-class`), `inline-class`,
`slide-class` и классы частей окна — утилитами Framework.

### Текущее положение и события

Положение нумеруется с единицы. Атрибут `current` задаёт начальный материал;
`goTo(n)`, `next()` и `prev()` переходят к другому, `open(n)` открывает
модальное окно на нужном материале, `close()` и `toggle()` закрывают и
переключают его. Нажатие на материал во встроенном слайдере открывает окно
на этом материале.

Смена материала отправляет `change`, открытие и закрытие окна —
`sf-gallery-opened` и `sf-gallery-closed` (прежние имена — `sf-change`,
`sf-open` и `sf-button-close` — приходят с тем же `detail`). Все три всплывают; в
`event.detail` приходят `current` и `total`, а у `change` ещё `previous` и
`from` — откуда пришла смена: `inline`, `lightbox` или `api`.

```js
const gallery = document.querySelector('sf-gallery');
gallery.addEventListener('change', (event) => {
  counter.textContent = `${event.detail.current} из ${event.detail.total}`;
});
gallery.open(3);
```

Вложенные слайдеры не хранят своего положения: не исправляйте его через их
API, а вызывайте методы галереи. `getInlineSlider()`, `getLightboxSlider()`
и `getModal()` возвращают вложенные элементы для чтения их состояния.

## Доступность

- Задайте `heading`: он становится заголовком модального окна и называет
  диалог. По умолчанию заголовок английский — «Gallery».
- Материал встроенного слайдера, который открывает окно, получает роль кнопки
  и попадает в порядок `Tab`; `Enter` и пробел открывают окно на нём. Его
  имя — текст материала, поэтому у изображения нужен содержательный `alt`, а
  у карточки — подпись.
- В модальном окне фокус остаётся внутри, `Escape` закрывает окно, если не
  задан `close-on-esc="false"`. Листают стрелки слайдера, у которых есть
  свои доступные имена.
- Для галереи из ссылок отмечайте именно ссылки, а не изображения: ссылка
  доступна с клавиатуры, изображение — нет.
- При системной настройке уменьшения движения слайды сменяются без анимации.

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `open(args?: object\|number)` | объект | Переходит к указанному слайду (нумерация с единицы), если передан индекс, устанавливает open и открывает модальное окно лайтбокса. Возвращает тег. |
| `close()` | объект | Снимает open и закрывает модальное окно лайтбокса. Возвращает тег. |
| `toggle(args?: object\|number)` | объект | Вызывает close(), если открыто, иначе open(index). Возвращает тег. |
| `goTo(args: object\|number)` | объект | Переходит к слайду с номером от 1; номер больше числа слайдов заменяется последним. Отправляет `change`, если слайд сменился. Возвращает тег. |
| `next()` | объект | goTo(current + 1); останавливается на последнем слайде. Возвращает тег. |
| `prev()` | объект | goTo(current - 1); останавливается на первом слайде. Возвращает тег. |
| `getModal()` | объект или пусто | Возвращает sf-modal лайтбокса или null, если его нет. |
| `getInlineSlider()` | объект или пусто | Возвращает встроенный sf-slider или null до отрисовки. |
| `getLightboxSlider()` | объект или пусто | Возвращает sf-slider лайтбокса или null, если его нет. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `{ previous: number, current: number, total: number, from: "api" \| "inline" \| "lightbox" }` | — |
| `sf-gallery-opened` | `{ current: number, total: number }` | — |
| `sf-gallery-closed` | `{ current: number, total: number }` | — |
