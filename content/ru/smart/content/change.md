# Изменение

:badge[sf-change]{variant=outline scheme=on-surface size=1/2} :badge[1.2.5]{variant=outline scheme=on-surface size=1/2}

Изменение показывает, каким значение поля было и каким стало:
«Собран → Передан в доставку». Старое значение набрано тихим цветом, новое —
цветом текста и полужирным. Бейджей и зачёркивания нет: две «коробки» в
строке — шум, а зачёркнутое читается как ошибка или удаление. Пустое
значение — слово «пусто». Берите его в событии хронологии, в колонке
«Изменение» журнала, в уведомлении и в истории версий.

## Разметка

Одно поле — значения в `before` и `after`, название поля — в `label`:

```html
<p>Анна Котова изменила статус
  <sf-change label="Статус" before="Собран" after="Передан в доставку"></sf-change></p>
```

Несколько полей одного обновления — список `{label, before, after}` в
`changes`: в атрибуте — JSON, из скрипта — свойством. Число показывается
текстом, `null` и пустая строка — словом «пусто».

```html
<sf-change layout="list"
  changes='[{"label":"Вес","before":"4,2 кг","after":"4,6 кг"},
            {"label":"Склад","before":"Москва-Север","after":"Москва-Юг"}]'></sf-change>
```

Если сказать нечего, элемент ничего не рисует и получает атрибут
`data-empty`.

## Варианты

### В строке

`layout` • по умолчанию `inline` • [справочник](#атрибуты)

`inline` ставит пару внутрь предложения. Стрелка приклеена к первому слову
нового значения и не остаётся в конце строки одна. Короткое значение —
число с единицей «4,6 кг», телефон, имя — стоит в строке целиком, длиннее —
переносится, как обычный текст, и не выходит за край. Название поля
печатается только с `show-label` («Ответственный: …») — в ячейке таблицы и
в уведомлении; в предложении, где поле уже названо, оно лишнее.

:::example {id="smart-components/change/inline" label="В предложении и с названием поля" preview=sandbox}
:::

### Списком

`layout` • по умолчанию `inline` • [справочник](#атрибуты)

`list` — несколько полей одного обновления: колонка названий шириной в
самое длинное и пары рядом. Когда места меньше 24rem, название стоит над
своей парой.

:::example {id="smart-components/change/list" label="Четыре поля одного обновления" preview=sandbox}
:::

### Длинный текст

`reveal` • по умолчанию `auto` • [справочник](#атрибуты)

Значение длиннее 80 знаков в предложение не ставится: кнопка «Показать
изменения» раскрывает на месте два блока, подписанные «Было» и «Стало»,
а «Скрыть изменения» убирает их. `reveal="none"` всегда показывает пару в
строке.

:::example {id="smart-components/change/long" label="Раскрытие и пара в строке" preview=sandbox}
:::

## Доступность

- Стрелка — картинка (`aria-hidden`). Между значениями стоит скрытое слово,
  и экранный диктор слышит «Собран на Передан в доставку».
- Список — список описаний (`dl`): название — термин, пара — описание.
- Кнопка раскрытия сообщает, открыты ли блоки (`aria-expanded`), и
  называет их (`aria-controls`); блоки подписаны словами «Было» и «Стало».
- Пустое значение читается словом «пусто».

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `before` | строка | пусто | — | Значение, каким было, текстом. Пусто читается «пусто». Только атрибут (C279): `element.before` — собственный метод браузера `ChildNode`, поэтому скрипт и остров `data-sf-settings` сервера передают общий список `changes` (одно изменение — список из одного); остров пропускает `before` с предупреждением в консоли. |
| `after` | строка | пусто | — | Значение, каким стало, текстом. Пусто читается «пусто». Только атрибут (C279): `element.after` — собственный метод браузера `ChildNode`, поэтому скрипт и остров `data-sf-settings` сервера передают общий список `changes` (одно изменение — список из одного); остров пропускает `after` с предупреждением в консоли. |
| `label` | строка | пусто | — | Название поля («Статус»). Перед парой печатается только с `show-label`; в `layout="list"` термином служит название каждого изменения. |
| `show-label` | да/нет | нет | — | Печатать «Статус: » перед парой — в ячейке таблицы, в уведомлении; в предложении, где поле уже названо, не нужно. |
| `layout` | строка | `inline` | `inline`, `list` | `inline` — «Собран → Передан в доставку» внутри предложения, стрелка не отрывается от нового значения; `list` — список описаний: колонка названий и пары, уже 24rem название стоит над парой. |
| `reveal` | строка | `auto` | `auto`, `none` | `auto` — в `layout="inline"` значение длиннее 80 знаков в предложение не ставится: кнопка «Показать изменения» раскрывает на месте два блока, «Было» и «Стало»; `none` — всегда пара в строке. |
| `changes` | список | `[]` | — | Изменения одного обновления, каждое `{label, before, after}`, для `layout="list"`: свойство, JSON-блок от сервера или атрибут `changes` в JSON. Число показывается текстом, `null` и пустая строка — словом «пусто». В `layout="inline"` без `before` и `after` парой становится первое изменение. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.
`before` и `after` — только атрибутом; из скрипта — свойство `changes`.
