# Теги

:badge[sf-tag]{variant=tonal scheme=primary size=1/2} :badge[1.3.5]{variant=outline scheme=on-surface size=1/2}

Тег показывает одну короткую метку: категорию, выбранное значение, фильтр или
статус. Он может быть статичным, переключаться нажатием и предлагать отдельную
кнопку удаления. Для неинтерактивной пометки рядом с объектом проще
[Бейджи](/ru/smart/feedback/badges/).

То же на классах — [Теги](/ru/components/content/tags/): элемент строится на
классах этого компонента; для статической разметки без JavaScript.

## Разметка

Тегу нужна подпись:

```html
<sf-tag text="Дизайн"></sf-tag>
```

`text` — видимая подпись. Слоты `leading`, `text`, `count`, `avatar` и
`close` заменяют соответствующую часть своей разметкой; декоративная часть
при этом не должна попадать в порядок `Tab`, а слот `close` содержит ровно
одну нативную кнопку с доступным именем.

## Варианты

### Содержимое

`kind`, `count`, `icon` • [справочник](#атрибуты)

`kind` выбирает содержимое и поведение:

- `checkbox` — переключатель с флажком, вид по умолчанию;
- `default` — подпись и необязательное число `count`;
- `icon` — значок из `icon` перед подписью;
- `color` — цветной маркер; цвет задаёт утилита фона в `color-class`;
- `avatar` — аватар из `avatar-image-url` или инициалы из `avatar-text`.

:::example {id="smart-components/tags/kinds" label="Пять значений kind"}
:::

### Статус

`status` • [справочник](#атрибуты)

`status` сообщает смысл из общего словаря: `info`, `success`, `warning`,
`error`; без него тег нейтральный.

:::example {id="smart-components/tags/status" label="Статус"}
:::

### Вид

`appearance` • по умолчанию `default` • [справочник](#атрибуты)

`appearance` задаёт вид нейтрального тега на незнакомом фоне: `default`,
`surface` — лёгкая заливка с границей, `ghost` — фон появляется только при
наведении. Статусному тегу вид не нужен: смысл несёт его цвет.

:::example {id="smart-components/tags/appearance" label="Виды default, surface и ghost"}
:::

### Размер

`size` • по умолчанию `1/2` • [справочник](#атрибуты)

`size` — ступень `1/3`, `1/2`, `1`, `2` или `3`, по умолчанию `1/2`. Кнопка
удаления везде держится строки подписи и не делает тег выше: её область
нажатия остаётся 24 на 24 пикселя, а сам крестик растёт вместе с размером
тега.

:::example {id="smart-components/tags/sizes" label="Размеры от 1/3 до 3"}
:::

### Плотность

`spacing` • по умолчанию `normal` • [справочник](#атрибуты)

`spacing` (`compact`, `normal`, `comfortable`, `spacious`) меняет
вертикальные отступы, как у кнопок.

:::example {id="smart-components/tags/spacing" label="Четыре значения spacing"}
:::

### Счётчик и удаление

`count`, `closable`, `icon` • [справочник](#атрибуты)

`count` — число после подписи у тега `default`. `closable` добавляет
отдельную кнопку удаления. У тегов `icon`, `color` и `avatar` она есть по
умолчанию — `closable="false"` её убирает; у `checkbox` и `default` она
появляется только с `closable`.

:::example {id="smart-components/tags/count-close" label="Счётчик и удаление"}
:::

### В строке

`inline`, `line` • [справочник](#атрибуты)

`inline` ставит тег на строку другого элемента управления: без вертикальных
отступов. В ячейке таблицы задайте `line` (`1/2`, `1`, `2`): тег станет на
ступень меньше и уместится в строку текста этого размера, поэтому строка
таблицы не вырастет.

:::example {id="smart-components/tags/inline" label="В строке"}
:::

## Поведение

### Выбор

Тег `kind="checkbox"` — кнопка-переключатель. Нажатие меняет `active` и
отправляет всплывающее событие `change`; в `event.detail.active` — новое
состояние, сам тег — `event.target`.

```js
document.querySelector('.filters').addEventListener('change', (event) => {
  if (event.target.localName !== 'sf-tag') return;
  applyFilter(event.target.getAttribute('text'), event.detail.active);
});
```

### Удаление

Нажатие на кнопку удаления отправляет всплывающее событие `sf-tag-close`; `event.detail` пустой, сам тег — `event.target`. Тег
не исчезает: убирает его приложение, когда удаление принято.

```js
tags.addEventListener('sf-tag-close', (event) => {
  removeValue(event.target.getAttribute('text'));
  event.target.remove();
});
```

Так устроен второй ряд [примера](#пример): крестик убирает тег, а фокус
переходит на ближайший тег с кнопкой.

Методы `onToggle()` и `onClose()` выполняют те же действия из скрипта:
переключают тег или отправляют событие удаления.

### Тег, который что-то открывает

`interactive` (у всех видов, кроме `checkbox`) делает подпись кнопкой, а
кнопка удаления остаётся рядом отдельной. Так устроены чипы фильтра: подпись
открывает меню условия, крестик убирает фильтр. Обработчик `click` на теге
получает нажатия по подписи; нажатие на крестик приходит как `sf-tag-close`.

## Доступность

- Статичный тег — текст, он не получает фокус. В порядок `Tab` входят
  только нативные кнопки: переключатель, подпись интерактивного тега и
  кнопка удаления.
- Переключатель передаёт состояние через `aria-pressed`. Его имя — видимая
  подпись; `aria-label` уточняет её, если подпись сокращена.
- Кнопке удаления нужно конкретное имя: «Удалить: Казань», а не просто
  «Удалить». Передайте его в `close-label`; по умолчанию кнопка называется
  «Удалить» на русской странице и «Remove» на остальных.
- `Enter` и пробел нажимают кнопку в фокусе. Фокус виден при клавиатурной
  навигации и не меняет размеров тега.
- После удаления тега переведите фокус на соседний тег или на поле, в
  котором выбирают значение.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `kind` | строка | `checkbox` | `checkbox`, `icon`, `default`, `color`, `avatar` | Содержимое тега: флажок, иконка, цвет, аватар или только подпись. Значение `quantity` тоже принимается и означает `default`. |
| `status` | строка | пусто | пусто, `info`, `success`, `warning`, `error` | Цвет по смыслу, например `success` или `error`. Пусто — обычный тег. |
| `appearance` | строка | `default` | `default`, `surface`, `ghost` | Внешний вид на основе нейтральной шкалы прозрачности, независимый от типа: surface сохраняет лёгкую заливку и границу, ghost не имеет ничего до наведения. Применяется только к нейтральным типам, потому что тег статуса передаёт смысл цветом. |
| `size` | строка | `1/2` | `1/3`, `1/2`, `1`, `2`, `3` | Размер: от него зависят размер текста и отступы. |
| `line` | строка | пусто | пусто, `1/2`, `1`, `2` | Тег высотой в строку текста этого размера и на размер меньше, для ячейки таблицы, чтобы строка не стала выше. Важнее `size` и `inline`. |
| `spacing` | строка | `normal` | `compact`, `normal`, `comfortable`, `spacious` | Вертикальные отступы отдельного тега с теми же названиями, что у кнопок. |
| `inline` | да/нет | нет | — | Тег на строке текста другого поля: без отступов сверху и снизу, кнопка удаления высотой в строку. Высоту строки можно задать через `--sf-tag--line`. |
| `text` | строка | пусто | — | Видимая подпись тега. |
| `count` | строка | пусто | — | Текст счётчика после подписи: число или ограниченное, например 99+. |
| `icon` | строка | пусто | — | Имя декоративной иконки Framework. |
| `color-class` | строка | пусто | — | Цвет маркера классом фона, например `bg-primary`. |
| `avatar-image-url` | строка | пусто | — | URL изображения аватара; доступной подписью остаётся видимый текст. |
| `avatar-text` | строка | пусто | — | Инициалы аватара на случай отсутствия изображения. |
| `avatar-status` | строка | пусто | — | Статус аватара для собственных шаблонов; встроенный шаблон его не рисует. |
| `disabled` | да/нет | нет | — | Отключает интерактивные действия переключения и закрытия. |
| `closable` | да/нет | нет | — | Нет атрибута — удаляемый для видов icon, color и avatar, но не для checkbox и default; есть — удаляемый для любого вида. |
| `interactive` | да/нет | нет | — | Отображает подпись как кнопку рядом с действием удаления — для тегов, которые что-то открывают (например, меню фильтра-чипа); для тегов-флажков игнорируется. |
| `close-label` | строка | — | — | Доступное имя действия удаления. По умолчанию Remove, на русской странице — Удалить. |
| `active` | да/нет | нет | — | Выбран тег-флажок; тег переключает его и сообщает об этом через `change`. |
| `aria-label` | строка | пусто | — | Необязательное переопределение доступного имени для выбираемого тега. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона. |
| `root-class` | строка | пусто | — | Свои CSS-классы для элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `onToggle()` | — | Переключает включённый тег-флажок и отправляет его новое активное состояние. |
| `onClose()` | — | Отправляет намерение удаления для доступного закрываемого тега. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `{ active: boolean }` | Изменилось активное состояние тега-флажка. |
| `sf-tag-close` | пустой объект | — |
