# Группа тегов

:badge[sf-tag-group]{variant=outline scheme=on-surface size=1/2} :badge[1.2.1]{variant=outline scheme=on-surface size=1/2}

Группа тегов собирает ряд [тегов](/ru/smart/content/tags/): выбранные
значения, которые можно убрать, фильтры над списком, теги в ячейке таблицы
или в карточке, теги статьи. Промежутки, одну строку с «+N», клавиши и
смысл «список» для экранного диктора держит группа; страница пишет только
сами теги. Для выбора из двух–пяти вариантов берите
[Сегментный переключатель](/ru/smart/actions/segmented/).

## Пример

Уберите город крестиком или клавишей `Delete`: группа сообщает об этом,
страница удаляет тег. Код — на вкладке JavaScript.

:::example {id="smart-components/tag-group/overview" label="Выбранные города" log="sf-tag-close" log_console=true log_open=false}
:::

## Разметка

Внутри группы — обычные `<sf-tag>` страницы. Группа их не рисует заново и не
переносит, а называет ряд и раскладывает его.

```html
<sf-tag-group aria-label="Города">
  <sf-tag kind="default" closable text="Москва" close-label="Удалить Москва"></sf-tag>
  <sf-tag kind="default" closable text="Казань" close-label="Удалить Казань"></sf-tag>
</sf-tag-group>
```

- `aria-label` — имя ряда для экранного диктора: что это за теги.
- Тег убирает страница. Крестик и `Delete` присылают `sf-tag-close` от
  тега, страница удаляет элемент:

```js
group.addEventListener('sf-tag-close', (event) => event.target.remove());
```

## Варианты

### Раскладка

`layout` • по умолчанию `row` • [справочник](#атрибуты)

| Значение | Когда брать |
|:---|:---|
| `row` | Фильтры, ячейка таблицы, карточка: ряд в одну строку. Теги не сжимаются; те, что не поместились, уходят из строки, а последним стоит «+N». Первый тег виден всегда. |
| `wrap` | Форма: все теги на виду, ряд переносится на следующие строки. |

Между тегами 4 px по горизонтали и по вертикали. «+N» открывает панель со
скрытыми тегами; их крестики и флажки работают так же, как в строке.

:::example {id="smart-components/tag-group/layout" label="Одна строка и перенос" preview=inline}
:::

### Выбор фильтров

`selection` • по умолчанию `none` • [справочник](#атрибуты)

Для тегов-фильтров (`kind="checkbox"`) группа держит выбор:

| Значение | Когда брать |
|:---|:---|
| `none` | Каждый тег сам по себе; группа выбор не держит. |
| `one` | Выбран один фильтр: выбор тега снимает выбор с остальных, повторное нажатие снимает и его. |
| `many` | Фильтры выбираются в любом наборе. |

Тег узнаётся по `key`, без него — по тексту. Свойство `selected` — ключ
выбранного тега (при `many` — первого), `selectedIds` — ключи всех выбранных
по порядку. Выбор человека приходит событием `sf-tag-group-select` с
`detail` `{ids, id, selected}`: весь выбор, нажатый тег и выбран ли он
теперь.

:::example {id="smart-components/tag-group/selection" label="Один фильтр и несколько" log="sf-tag-group-select" log_console=true log_open=false}
:::

## Поведение

### Клавиатура

Ряд — одна остановка `Tab`: в порядок фокуса входит тот тег, на котором
человек стоял последним.

| Клавиша | Что делает |
|:---|:---|
| `←`, `→` | Предыдущий и следующий тег и «+N»; на странице справа налево — наоборот |
| `Home`, `End` | Первый и последний тег |
| `Delete`, `Backspace` | Убирает тег, на котором стоит фокус, если его можно убрать; фокус переходит к соседу |
| `Enter`, `Space` | Нажимает тег: выбирает фильтр, открывает «+N» |
| `Escape` | Закрывает панель «+N» и возвращает фокус на «+N» |

## Доступность

- Группа — список (`role="list"`), каждый тег — его пункт. Имя списку даёт
  `aria-label`: «Выбранные города», «Фильтры заказов».
- У крестика по умолчанию имя «Удалить» без названия тега. Дайте каждому
  тегу `close-label` с названием («Удалить Москва»), чтобы экранный диктор
  различал крестики.
- `Delete` и `Backspace` убирают тег и переводят фокус к соседнему тегу.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `layout` | строка | `row` | `row`, `wrap` | `row` — одна строка: фильтры, ячейка таблицы, карточка; теги, которые не поместились, уходят из строки, и «+N» открывает их во всплывающей панели; `wrap` — ряд переносится, все теги на виду (форма). |
| `selection` | строка | `none` | `none`, `one`, `many` | Для тегов-фильтров (`kind="checkbox"`): `none` — каждый тег сам по себе; `one` — выбран один тег (выбор тега снимает выбор с остальных, выбранный можно снять); `many` — выбирается любой набор. При `one` и `many` группа сообщает выбор событием `sf-tag-group-select`. |
| `selected` | строка | пусто | — | Ключ выбранного тега (его `key`, иначе текст); при `selection="many"` — первого выбранного. Запись выбирает этот тег и снимает выбор с остальных. |
| `aria-label` | строка | пусто | — | Доступное имя ряда, которое произносится вместе со списком: что это за теги — «Города» или «Фильтры». Рекомендуется; вместо него `aria-labelledby` берёт имя из заголовка. |
| `selected-ids` | список | `[]` | — | Ключи выбранных тегов в порядке ряда. Запись выбирает эти теги и снимает выбор с остальных (при `selection="one"` — только первый). |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

Публичных методов нет.

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-tag-group-select` | `{ ids: array, id: any, selected: boolean }` | Человек выбрал или снял тег-фильтр ряда (`selection` `one` или `many`): `ids` — весь выбор, `id` — нажатый тег, `selected` — выбран ли он теперь. |
