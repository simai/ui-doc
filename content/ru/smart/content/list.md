# Список

:badge[sf-list]{type=tonal scheme=primary size=1/2} :badge[1.1.0]{type=outline scheme=on-surface size=1/2}

`<sf-list>` — список, с которым что-то делают: беседы, письма, шаблоны,
файлы, участники, версии. Строки строятся из данных — название и тихая вторая
строка; список показывает, какая строка открыта, собирает действия строк в
одно меню, переименовывает на месте и просит следующую страницу. Список
ничего не загружает и не сортирует: порядок строк — порядок хоста, каждая
просьба уходит событием.

Строка списка — [Строка списка](/ru/smart/content/list-item/)
(`sf-list-item`). Колонку записей, которую читают от новой записи внизу,
показывает [Лента](/ru/smart/content/list-feed/).

## Разметка

В разметке — тег с доступным именем; строки передаёт скрипт:

```html
<sf-list label="Письма" renamable></sf-list>
```

```js
const list = document.querySelector('sf-list');
list.actions = [
  {id: 'copy', text: 'Копировать', icon: 'content_copy'},
  {id: 'delete', text: 'Удалить', icon: 'delete', destructive: true},
];
list.setItems(await api.letters(), {hasMore: true});
```

Строка — обычные данные `{id, text, supporting?, icon?, date?, group?,
disabled?, actions?}`: `text` — название, `supporting` — вторая строка,
`date` — дата записи для групп по дням, `group` — ключ группы. Поле `actions`
строки сужает общие действия списком `id` или убирает их значением `false`.

Слот `empty` заменяет пустое состояние целиком.

## Варианты

### Группы по дням

`group-by="day"` делит строки по календарному дню `date` в часовом поясе
читателя: «Сегодня», «Вчера», день недели, дата. В полночь читателя группы
перерисовываются.

:::example {id="smart-components/list/group-day" label="Беседы по дням"}
:::

### Группы по ключу

`group-by="key"` делит строки по полю `group` в порядке `groups`
(`[{key, text}]`). Ключ, которого нет в `groups`, идёт последним, его
заголовок — сам ключ. `heading-level` задаёт уровень заголовков групп в
структуре страницы (по умолчанию `3`).

:::example {id="smart-components/list/group-key" label="Файлы по группам"}
:::

### Размер

`size` — ступень строк на лестнице размеров: `1/2`, `1` (по умолчанию) или
`2`, как у `sf-list-item`. Кнопка «⋯» и поле переименования берут ту же
ступень.

:::example {id="smart-components/list/sizes" label="Ступени 1/2, 1 и 2"}
:::

## Поведение

### Открытая строка

Нажатие или `Enter` на строке отправляет `sf-list-open` с `{id, trigger}`,
где `trigger` — `pointer` или `keyboard`. Какая строка открыта, решает хост:
он записывает её `id` в `selected`. Открытая строка получает
`aria-current` и оттенок.

```js
list.addEventListener('sf-list-open', (event) => {
  openLetter(event.detail.id);
  list.selected = event.detail.id;
});
```

### Действия строки

`actions` — действия строки в одном меню на весь список,
`[{id, text, icon?, destructive?}]`; при `renamable` первым в меню стоит
«Переименовать». Выбранное действие приходит событием `sf-list-apply` с
`{action, scope: 'entry', ids}`. Убрать строку после удаления —
`detach(id)`: фокус с неё переходит к соседней.

### Переименование

При `renamable` строку переименовывают на месте: `F2` или пункт меню
открывают поле, `Enter` сохраняет, `Escape` отменяет. Новое название видно
сразу и приходит событием `sf-list-rename` с `{id, text}`; отмена события
возвращает старое. Если сохранить не удалось, верните прежнее название через
`upsert()`.

### Следующая страница

`has-more` говорит, что есть продолжение: видна кнопка «Показать ещё», а
когда конец списка близко, список сам просит следующую страницу событием
`sf-list-load-more` с `{direction: 'after', after}`, где `after` — `id`
последней строки. Ответ передайте `appendItems(items, {hasMore})`; если
загрузить не удалось — `moreFailed()`, и список попросит снова.

:::example {id="smart-components/list/more" label="Версии с продолжением"}
:::

### Методы

Каждый метод отвечает исходом: `{outcome: 'applied'}` или
`{outcome: 'refused', reason}`.

| Метод | Что делает |
|:---|:---|
| `setItems(items, {hasMore})` | Весь список и есть ли продолжение; завершает запрос страницы. |
| `appendItems(items, {hasMore})` | Следующая страница после показанных строк. |
| `upsert(item)` | Новая строка в начало или изменившаяся на своём месте. |
| `detach(id)` | Убрать строку. |
| `rename(id)` | Начать переименование, как `F2`. Отказ `not-renamable`, `unknown`, `disabled`. |
| `openMenu(id)` | Открыть действия строки, как «⋯» и `Shift+F10`. Отказ `no-actions`, `unknown`. |
| `requestMore()` | Попросить следующую страницу. Отказ `loading`, `no-more`, `prevented`. |
| `moreFailed()` | Страница не загрузилась: «Показать ещё» и конец списка просят снова. |

## Доступность

- Весь список — одна остановка `Tab`: строка, на которой были последней,
  иначе открытая, иначе первая. Стрелки, `Home` и `End` ходят между
  строками через все группы, `Enter` открывает строку.
- `Shift+F10` или клавиша контекстного меню открывают действия строки.
  Кнопка «⋯» не отдельная остановка `Tab`: с клавиатуры до действий доходят
  через `Shift+F10`, мышью — нажатием.
- `F2` открывает поле переименования и переносит в него фокус; после
  `Enter` или `Escape` фокус возвращается на строку.
- Без групп список назван `label` (по умолчанию «Список» на русской странице и
  «List» на остальных). С группами вся рамка — группа с именем `label`, а
  строки каждой группы — список, названный её заголовком.
- Открытая строка отмечена `aria-current`, а не только оттенком.

Собран из манифеста компонента выпуска `ui-98143c0a0728` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |
| `selected` | строка | пусто | — | `id` открытой строки: `aria-current` и оттенок открытой строки. Управляется хостом: нажатие просит open `{id}`, хост записывает значение. |
| `group-by` | строка | `none` | `none`, `day`, `key` | none — один список. day — по календарному дню даты каждой строки в часовом поясе читателя («Сегодня», «Вчера», день недели, дата). key — по группе каждой строки в порядке `groups`. |
| `renamable` | да/нет | нет | — | Строки переименовываются на месте: F2 и пункт «Переименовать» в меню; событие rename `{id, text}` сообщает новое название. |
| `has-more` | да/нет | нет | — | Есть следующая страница: видна кнопка «Показать ещё», а когда конец списка близко, список её просит. |
| `loading` | да/нет | нет | — | Первая страница в пути: вместо слов видна форма строк. |
| `size` | строка | `1` | `1/2`, `1`, `2` | Ступень строк на лестнице размеров (размер `sf-list-item`); «⋯» и поле переименования берут ту же. |
| `label` | строка | — | — | Доступное имя списка; пустое — «Список» на языке страницы. |
| `heading-level` | целое число | `3` | от 2; до 6 | Уровень заголовков групп в структуре страницы. |
| `empty-text` | строка | — | — | Заголовок пустого состояния (`sf-empty-state` no-data); слот `empty` заменяет состояние целиком. |
| `items` | список: объект | `[]` | — | Строки в порядке хоста: `{id, text, supporting?, icon?, avatar?, date?, group?, count?, badge?, pinned?, disabled?, actions?}`. |
| `groups` | список | `[]` | — | Для `group-by` key: группы по порядку, `[{key, text}]`; ключ, которого нет в списке, идёт последним, его заголовок — сам ключ. |
| `actions` | список | `[]` | — | Действия строки в общем меню после «Переименовать»: `[{id, text, icon?, destructive?}]`. Выбранное действие уходит событием apply `{action, scope: entry, ids}`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `setItems(items: array, options: object)` | объект | Весь список и есть ли продолжение, вместе; завершает запрос страницы. |
| `appendItems(items: array, options: object)` | объект | Следующая страница после показанных строк; завершает запрос страницы. |
| `upsert(item: object)` | объект | Новая строка в начало или изменившаяся на своём месте. |
| `detach(id: any)` | объект | Убирает одну строку; фокус с неё переходит к соседней. |
| `rename(id: any)` | объект | Начинает переименование строки на месте, как F2. |
| `openMenu(id: any)` | объект | Открывает действия строки, как её «⋯» и Shift+F10. |
| `requestMore()` | объект | Просит следующую страницу, как конец списка и кнопка «Показать ещё»; пока запрос в пути, ничего не делает. |
| `moreFailed()` | объект | Следующую страницу загрузить не удалось: «Показать ещё» и конец списка просят снова. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-list-open` | `{ id: any, trigger: any }` | Запрошено открытие строки (словарь open): нажатие или Enter; хост открывает её и записывает `selected`. |
| `sf-list-apply` | `{ action: string, scope: any, ids: array }` | Выбрано одно из действий строки: `{action, scope: entry, ids}` (словарь apply). |
| `sf-list-rename` | `{ id: any, text: string }` | Строка переименована на месте; новое название видно сразу. Отмените событие, чтобы вернуть прежнее. |
| `sf-list-load-more` | `{ direction: any, after: any }` | Запрошена следующая страница: конец списка близко или нажата «Показать ещё»: `{direction: after, after}`. Отмена события — то же, что `moreFailed()`. |
