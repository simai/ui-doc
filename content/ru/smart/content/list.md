# Список

:badge[sf-list]{variant=outline scheme=on-surface size=1/2} :badge[1.25.0]{variant=outline scheme=on-surface size=1/2}

Список — для того, с чем что-то делают: беседы, письма, шаблоны, файлы,
участники, версии. Строки строятся из данных — название и тихая вторая строка;
список показывает, какая строка открыта, собирает действия строк в одно меню,
переименовывает на месте и просит следующую страницу. Загружает и сортирует
строки сайт: порядок строк — его порядок, а каждая просьба уходит событием.

Строка списка — [Строка списка](/ru/smart/content/list-item/)
(`sf-list-item`). Колонку записей, которую читают от новой записи внизу,
показывает [Лента](/ru/smart/content/list-feed/).

## Разметка

В разметке — тег с доступным именем; строки передаёт скрипт:

```html
<sf-list label="Письма" renamable></sf-list>
```

```js
const list = document.querySelector('sf-list');
list.actions = [
  {id: 'copy', text: 'Копировать', icon: 'content_copy'},
  {id: 'delete', text: 'Удалить', icon: 'delete', destructive: true},
];
list.setItems({items: await api.letters(), options: {hasMore: true}});
```

Строка — обычные данные `{id, text, supporting?, icon?, date?, group?,
disabled?, actions?}`: `text` — название, `supporting` — вторая строка,
`date` — дата записи для групп по дням, `group` — ключ группы. Поле `actions`
строки сужает общие действия списком `id` или убирает их значением `false`.

Слот `empty` заменяет пустое состояние целиком.

## Варианты

### Группы по дням

`group-by` • по умолчанию `none` • [справочник](#атрибуты)

`group-by="day"` делит строки по календарному дню `date` в часовом поясе
читателя: «Сегодня», «Вчера», день недели, дата. В полночь читателя группы
перерисовываются.

:::example {id="smart-components/list/group-day" label="Беседы по дням"}
:::

### Группы по ключу

`group-by`, `groups`, `heading-level` • [справочник](#атрибуты)

`group-by="key"` делит строки по полю `group` в порядке `groups`
(`[{key, text}]`). Ключ, которого нет в `groups`, идёт последним, его
заголовок — сам ключ. `heading-level` задаёт уровень заголовков групп в
структуре страницы (по умолчанию `3`).

:::example {id="smart-components/list/group-key" label="Файлы по группам"}
:::

### Заголовок группы

`sf-group-heading` • классы, без скрипта

Заголовок группы рисуют сам список, хронология, панель уведомлений и лента
переписки. Своей страницы у него нет: он живёт только внутри списка. В своей
разметке без скрипта берите классы:

- `sf-group-heading` — слова группы размером текста строк, полужирные, рядом
  может стоять тихая дата `sf-group-heading-date`; над заголовком отступ, над
  первым — нет;
- `sf-group-heading--size-1/2` и `sf-group-heading--size-2` — для списка
  другой ступени: слова размером его строк, дата на ступень меньше;
- `sf-group-heading--sticky` — заголовок остаётся на виду, пока список
  прокручивается;
- `sf-group-heading--divider` — разделитель дней в переписке: слова по центру
  между двумя тонкими линиями, у разметки `role="separator"`.

Заголовку дайте `role="heading"` и `aria-level` по месту на странице.

:::example {id="smart-components/list/group-heading" label="Заголовок группы на классах"}
:::

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

## Поведение

### Открытая строка

Нажатие или `Enter` на строке отправляет `sf-list-open` с `{id, trigger}`,
где `trigger` — `pointer` или `keyboard`. Какая строка открыта, решает хост:
он записывает её `id` в `selected`. Открытая строка получает
`aria-current` и оттенок.

```js
list.addEventListener('sf-list-open', (event) => {
  openLetter(event.detail.id);
  list.selected = event.detail.id;
});
```

Откройте письмо щелчком или стрелками и `Enter`: журнал покажет
`sf-list-open`, а строка станет открытой.

:::example {id="smart-components/list/open" label="Открытое письмо" preview=sandbox log="sf-list-open" log_console=true log_open=false}
:::

### Действия строки

`actions` — действия строки в одном меню на весь список,
`[{id, text, icon?, destructive?}]`; при `renamable` первым в меню стоит
«Переименовать». Выбранное действие приходит событием `sf-list-apply` с
`{action, scope: 'entry', ids}`. Убрать строку после удаления —
`detach(id)`: фокус с неё переходит к соседней.

Откройте «⋯» у строки или нажмите `Shift+F10` и выберите «Удалить»: страница
уберёт строку.

:::example {id="smart-components/list/actions" label="Действия с файлами" preview=sandbox log="sf-list-apply" log_console=true log_open=false}
:::

### Переименование

При `renamable` строку переименовывают на месте: `F2` или пункт меню
открывают поле, `Enter` сохраняет, `Escape` отменяет. Новое название видно
сразу и приходит событием `sf-list-rename` с `{id, text}`; отмена события
возвращает старое. Если сохранить не удалось, верните прежнее название через
`upsert()`.

Выберите папку и нажмите `F2`: в примере пустое название не сохраняется и
возвращается прежнее.

:::example {id="smart-components/list/rename" label="Переименование папки" preview=sandbox log="sf-list-rename" log_console=true log_open=false}
:::

### Следующая страница

Конец списка — [пагинация](/ru/smart/navigation/pagination/#показать-ещё)
`sf-pagination` с `appearance="more"` сразу после него: кнопка «Показать
ещё», строка «Показано X из Y», загрузка по кнопке или сама при прокрутке
(`load="button"` или `load="auto"`). Нажатие присылает
`sf-pagination-load-more`; следующую порцию передайте списку
`appendItems({items})`, а пагинации — новое `current`.

:::example {id="smart-components/list/more" label="Версии" log="sf-pagination-load-more" log_open=false}
:::

### Методы

Каждый метод отвечает исходом: `{outcome: 'applied'}` или
`{outcome: 'refused', reason}`.

| Метод | Что делает |
|:---|:---|
| `setItems({items, options: {hasMore}})` | Весь список и есть ли продолжение; завершает запрос страницы. |
| `appendItems({items, options: {hasMore}})` | Следующая страница после показанных строк. |
| `upsert({item})` | Новая строка в начало или изменившаяся на своём месте. |
| `detach(id)` | Убрать строку. |
| `rename(id)` | Начать переименование, как `F2`. Отказ `not-renamable`, `unknown`, `disabled`. |
| `openMenu(id)` | Открыть действия строки, как «⋯» и `Shift+F10`. Отказ `no-actions`, `unknown`. |

## Доступность

- Весь список — одна остановка `Tab`: строка, на которой были последней,
  иначе открытая, иначе первая. Стрелки, `Home` и `End` ходят между
  строками через все группы, `Enter` открывает строку.
- `Shift+F10` или клавиша контекстного меню открывают действия строки.
  Кнопка «⋯» не отдельная остановка `Tab`: с клавиатуры до действий доходят
  через `Shift+F10`, мышью — нажатием.
- `F2` открывает поле переименования и переносит в него фокус; после
  `Enter` или `Escape` фокус возвращается на строку.
- Без групп список назван `label` (по умолчанию «Список» на русской странице и
  «List» на остальных). С группами вся рамка — группа с именем `label`, а
  строки каждой группы — список, названный её заголовком.
- Открытая строка отмечена `aria-current`, а не только оттенком.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `selected` | строка | пусто | — | `id` открытой строки: `aria-current` и оттенок открытой строки. Управляется приложением: нажатие просит open `{id}`, приложение записывает значение. |
| `group-by` | строка | `none` | `none`, `day`, `key` | none — один список. day — по календарному дню даты каждой строки в часовом поясе читателя («Сегодня», «Вчера», день недели, дата). key — по группе каждой строки в порядке `groups`. |
| `selection` | строка | `none` | `none`, `many` | Выбор нескольких строк. `many` — флажок в начале каждой строки: виден под указателем и на строке в фокусе, а когда что-то выбрано — на всех строках; тогда нажатие на строку выбирает её (Enter по-прежнему открывает), Shift — диапазон, пробел на строке в фокусе выбирает её, на телефоне выбирают долгим нажатием (меню строки остаётся на её «⋯»). Панель выбора — `sf-bulk-actions` внизу списка с действиями из `selection-actions`; её × и Escape снимают выбор. Выбор — это `value-chosen` и событие `select`. |
| `renamable` | да/нет | нет | — | Строки переименовываются на месте: F2 и пункт «Переименовать» в меню; событие rename `{id, text}` сообщает новое название. |
| `loading` | да/нет | нет | — | Первая страница загружается: три строки-скелетона размера списка, каждая высотой со строку, которая её заменит (строка подписи, пока строк не было, затем форма показанных строк вместе с местом иконки или аватара в начале, чтобы заголовок начинался там, где будет), слова — пульсирующие полосы первой отрисовки ядра (C130, C136, C148 (1)). |
| `leading` | строка | `auto` | `auto`, `none`, `icon`, `avatar` | Начальное место, которое строки-скелетоны держат при загрузке, с первого кадра: `auto` берёт форму строк, которые список уже показывал (пока не показывал — ничего); `icon` держит место иконки (квадрат линии строки, скругление элемента управления); `avatar` держит собственный блок sf-avatar ступени списка (высота элемента управления, пока у строк есть вторая строка, иначе линия строки), круг (квадрат, если показанные строки были такими); `none` места не держит. Так список, строки которого будут с иконками или аватарами, начинает полосу заголовка с первого кадра там, где будет заголовок. Влияет только на скелетон: строки рисуют то, что несут их пункты (C130, C148 (1)). |
| `lines` | строка | `auto` | `auto`, `1`, `2` | Число строк в строках-скелетонах при загрузке, с первого кадра: `auto` берёт строки, которые список уже показывал (пока не показывал — строку подписи); `1` держит однострочные строки (высота строки, аватар на линию строки); `2` держит строки со второй строкой (строка подписи, аватар высотой элемента управления). Так первая строка-скелетон однострочного списка высотой с его строки, а полоса заголовка — там, где будет заголовок, что бы ни говорил `leading`. Влияет только на скелетон: строки рисуют то, что несут их пункты (C130). |
| `size` | строка | `1` | `1/2`, `1`, `2` | Размер строк, как у `sf-list-item`; «⋯» и поле переименования того же размера. |
| `no-wrap` | да/нет | нет | — | Полный текст каждой строки — её всплывающая подсказка (`title`), обрезан он или нет. Заголовок строки и её вторая строка занимают по одной строке и обрезаются в конце многоточием с этой настройкой и без неё (C148 (5)); обрезанная строка сама показывает полный текст в подсказке, а для экранного диктора полный текст остаётся в строке. Оставлено для списков, которые её задают. |
| `divided` | да/нет | нет | — | Линия с отступом под каждой строкой, кроме последней в группе, от текста строки до края списка под «⋯» (`divided` у sf-list-item, C148 (4)); без неё у строк нет линий, а группы различаются заголовками (C40). |
| `time-format` | строка | `none` | `none`, `auto`, `relative`, `exact` | Время строки в её конце, из даты пункта, рисует sf-time (C40) без своей подсказки и остановки Tab (строка — единственная остановка списка): на линии заголовка двустрочной строки, над счётчиком и значком (конечная колонка sf-list-item, C148 (2)), шрифтом и приглушённым цветом подписи, основным цветом у непрочитанной строки. `none` (по умолчанию) — без времени. `auto` — под заголовком дня (`group-by` `day`) время на часах («11:20»), потому что день называет заголовок; в остальных местах — без групп, по ключу, в закреплённой группе — `auto` у sf-time («28 минут назад», «11:20», «вчера, 19:40», «5 ноября»). `relative` — всегда относительное. `exact` — время на часах под заголовком дня, дата и время в остальных местах. Значения — `time-format` у sf-list-timeline плюс `none`. |
| `label` | строка | — | — | Доступное имя списка; пустое — «Список» на языке страницы. |
| `heading-level` | целое число | `3` | от 2; до 6 | Уровень заголовков групп в структуре страницы. |
| `sticky-headings` | да/нет | нет | — | Заголовки групп остаются на виду при прокрутке списка, под ними сплошной фон места. |
| `rows-window` | строка | `auto` | `auto`, `off` | `auto`: до 1 000 записей (строк и заголовков группированного списка) все строки остаются в документе, строки длинного списка (от 100) рисуются с `content-visibility`, поэтому до них доходят поиск по странице и печать браузера; от 1 000 (или от `rows-window-from`) рисуются видимые записи и две распорки на остальное. `off` — все строки остаются в документе при любой длине. |
| `rows-window-from` | число | `1000` | — | Длина, начиная с которой `rows-window="auto"` рисует только видимые записи: по умолчанию 1 000; список задаёт свою — целое число больше 0. |
| `accept-files` | да/нет | нет | — | Весь список принимает файлы, перетащенные с компьютера: папка, чат, вложения. Пока файлы держат над ним, общая на странице подложка перетаскивания говорит «Отпустите, чтобы загрузить в «{label}»»; бросок просит приложение действием `attach`. По умолчанию выключено. |
| `empty-text` | строка | — | — | Заголовок пустого состояния (`sf-empty-state` no-data); слот `empty` заменяет состояние целиком. |
| `items` | список: объект | `[]` | — | Строки в порядке приложения: `{id, text, supporting?, icon?, avatar?, date?, group?, count?, badge?, pinned?, disabled?, actions?}`. |
| `groups` | список | `[]` | — | Для `group-by` key: группы по порядку, `[{key, text}]`; ключ, которого нет в списке, идёт последним, его заголовок — сам ключ. |
| `actions` | список | `[]` | — | Действия строки в общем меню после «Переименовать»: `[{id, text, icon?, destructive?}]`. Выбранное действие уходит событием apply `{action, scope: entry, ids}`. |
| `selection-actions` | список | `[]` | — | При `selection` `many` — действия панели выбора в форме `sf-bulk-actions` `[{id, text, icon?, status?, confirm?, undo?}]`: до трёх кнопками, остальные в «⋯», опасное — последним и с вопросом. Выбранное действие уходит как `apply` с `{action, scope: selection, ids}`. |
| `chosen` | список | `[]` | — | При `selection` `many` — идентификаторы выбранных строк в порядке списка. Страница может записать его (списком id), чтобы выбрать строки; строка, ушедшая из списка, уходит и из выбора. Это не `selected` — так называется одна открытая строка. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `setItems(args: object)` | объект | Весь список и есть ли продолжение, вместе; завершает запрос страницы. |
| `appendItems(args: object)` | объект | Следующая страница после показанных строк; завершает запрос страницы. |
| `upsert(args: object)` | объект | Новая строка в начало или изменившаяся на своём месте. |
| `detach(args: object\|string)` | объект | Убирает одну строку; фокус с неё переходит к соседней. |
| `rename(args: object\|string)` | объект | Начинает переименование строки на месте, как F2. |
| `openMenu(args: object\|string)` | объект | Открывает действия строки, как её «⋯» и Shift+F10. |
| `clearSelection()` | объект | Снимает выбор со всех строк (`selection` `many`) и отправляет `select`. Отказ (`empty`), если ничего не выбрано. |
| `toggleChosen(args: object)` | объект | Выбирает строку или снимает с неё выбор, как нажатие, когда строки уже выбирают; `range` выбирает все строки от последней нажатой (Shift). Отказ, если `selection` не `many`, строка неизвестна или недоступна. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-list-open` | `{ id: any, trigger: "pointer" \| "keyboard" }` | Запрошено открытие строки: нажатие или Enter; приложение открывает её и записывает `selected`. |
| `sf-list-apply` | `{ action: string, scope: "entry" \| "selection", ids: array }` | Выбрано одно из действий строки: `{action, scope: entry, ids}`; или действие панели выбора (`selection` `many`): `{action, scope: selection, ids}` с выбранными строками. |
| `sf-list-rename` | `{ id: any, text: string }` | Строка переименована на месте; новое название видно сразу. Отмените событие, чтобы вернуть прежнее. |
| `sf-list-attach` | `{ files: array, skipped: array }` | На список перетащили файлы (`accept-files`): просьба прикрепить их сюда; `skipped` называет пропущенные папки. Сам список ничего не загружает. |
| `sf-list-select` | `{ chosen: array, count: number, total: number }` | Выбор изменился (`selection` `many`): идентификаторы выбранных строк, их число и число строк. Имя события в DOM — `sf-list-select`. |
