# Аватары

:badge[sf-avatar-group]{variant=outline scheme=on-surface size=1/2} :badge[1.5.3]{variant=outline scheme=on-surface size=1/2}

Аватары — готовые сочетания: человек с источником, группа с остатком, аватар с
двумя строками подписи, аватар профиля. Для одного аватара, аватара с подписью
и карточки берите [Аватар](/ru/smart/content/avatar/) — у него есть имя для
экранного диктора и полный набор размеров.

То же на классах — [Аватары](/ru/components/content/avatars/): аватары,
группа, подпись и карточка в статической разметке без JavaScript.

## Разметка

Сочетание выбирает `template`, остальное — атрибуты этого шаблона:

```html
<sf-avatar-group template="user" name="Анна Белова" source="simai.ru"></sf-avatar-group>
```

- `user` — изображение из `image-url`, имя из `name` и источник из `source`
  со значком ссылки;
- `group` — ряд аватаров из `avatars` и счётчик остатка из `avatars-more`;
- `label` — аватар из `avatar-url` с двумя строками: `label-text` и
  `label-second-text`;
- `profile` — изображение профиля с отметкой проверки;
- `default` — один аватар из `image-url`; `active` добавляет точку
  присутствия, `check` — отметку.

Шаблоны `default`, `group`, `label` и `profile` пишут классы
`sf-avatar-round`, `sf-avatar--image`, `sf-avatar-cir`, `sf-avatar-check`,
`sf-avatar-profile`, которых нет в таблицах стилей выпуска: аватары в них
выводятся без формы и размера. Шаблон `user` выводит изображение и текст
обычной разметкой. Одиночный аватар и аватар с подписью стройте на
`<sf-avatar>`.

## Поведение

### Данные одним атрибутом

Значения можно передать по одному атрибуту или целиком: `fields` принимает JSON с теми же полями в camelCase или snake_case
(`imageUrl`, `label_text`, `avatars`), `property` — JSON с размерами
(`roundSize`, `labelSize`, `profileSize`). Атрибут сильнее поля из JSON.
Размеры принимают ступени шкалы: `1/4`, `1/3`, `1/2`, `2`, `3`.

```html
<sf-avatar-group template="group"
  avatars='[{"imageUrl": "/team/anna.jpg"}, {"imageUrl": "/team/ivan.jpg"}]'
  avatars-more="5"></sf-avatar-group>
```

## Доступность

- Изображения во всех шаблонах декоративны (`alt=""`): человека называет
  видимый текст — `name` в шаблоне `user`, `label-text` в шаблоне `label`.
- Аватары шаблонов `default`, `group` и `label` — кнопки без доступного
  имени, и задать его атрибутом нельзя. Если аватар должен открывать профиль,
  используйте `<sf-avatar>` с `aria-label`.
- Счётчик остатка в шаблоне `group` — текст кнопки; рядом с группой
  сообщите словами, сколько участников всего.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `fields` | строка | пусто | — | JSON-текст полей, которые принимают и атрибуты ниже (imageUrl, avatarUrl, avatarSize, active, check, name, source, labelText, labelSecondText, avatars, avatarsMore); атрибут важнее своего поля. |
| `property` | строка | пусто | — | JSON-текст размеров, которые принимают и атрибуты `round-size`, `label-size` и `profile-size`. |
| `image-url` | строка | пусто | — | Картинка шаблонов default, user и profile. |
| `avatar-url` | строка | пусто | — | Картинка шаблона label. |
| `avatar-size` | строка | пусто | — | Ступень размера аватара в шаблонах default и user (1/4…3; прежние слова tiny, small, big и extra_big ещё читаются). |
| `check` | да/нет | нет | — | Рисует отметку «проверено» на аватаре шаблона по умолчанию. |
| `name` | строка | пусто | — | Имя человека в шаблоне user. |
| `source` | строка | пусто | — | Строка под именем в шаблоне user, со значком ссылки: откуда человек. |
| `label-text` | строка | пусто | — | Заголовок шаблона label. |
| `label-second-text` | строка | пусто | — | Строка под заголовком в шаблоне label. |
| `avatars-more` | строка | пусто | — | Люди, которых группа представляет сверх списка аватаров: число прибавляется к «+N» (и к имени группы «Участники: N»); без списка за ним «+N» — текст. Короткий текст вместо числа рисуется как есть. |
| `round-size` | строка | пусто | — | Ступень размера аватаров в шаблоне `group` (и в шаблоне по умолчанию, если задана). Аватары перекрываются на 4 px до размера `1` и на 8 px на `2` и `3`; вырез между ними — кольцо точки присутствия, 2 px с `1/2` (C132). |
| `label-size` | строка | пусто | — | Ступень размера аватара в шаблоне label. |
| `profile-size` | строка | пусто | — | Ступень размера аватара шаблона profile: 2 или 3 (прежние слова small и big ещё читаются). |
| `active` | да/нет | нет | — | Рисует отметку «в сети» на аватаре шаблона по умолчанию; если заданы обе, побеждает check (проверено). |
| `avatars` | список | `[]` | — | Люди группы (C152 (6)): у каждого картинка (поверх инициалов), инициалы (`text`), имя — оно называет аватар, даёт инициалы и оттенок и показывается в подсказке, — статус присутствия (`online`, `away`) и названный оттенок. Показываются до четырёх; если людей больше, пятое место — «+N», кнопка, которая открывает список всех. Атрибут принимает список и как текст JSON. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.
