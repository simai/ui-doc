# Аватары

:badge[sf-avatar-group]{variant=tonal scheme=primary size=1/2} :badge[1.2.0]{variant=outline scheme=on-surface size=1/2}

Аватары — готовые сочетания: человек с источником, группа с остатком, аватар с
двумя строками подписи, аватар профиля. Для одного аватара, аватара с подписью
и карточки берите [Аватар](/ru/smart/content/avatar/) — у него есть имя для
экранного диктора и полный набор размеров.

То же на классах — [Аватары](/ru/components/content/avatars/): аватары,
группа, подпись и карточка в статической разметке без JavaScript.

## Разметка

Сочетание выбирает `template`, остальное — атрибуты этого шаблона:

```html
<sf-avatar-group template="user" name="Анна Белова" source="simai.ru"></sf-avatar-group>
```

- `user` — изображение из `image-url`, имя из `name` и источник из `source`
  со значком ссылки;
- `group` — ряд аватаров из `avatars` и счётчик остатка из `avatars-more`;
- `label` — аватар из `avatar-url` с двумя строками: `label-text` и
  `label-second-text`;
- `profile` — изображение профиля с отметкой проверки;
- `default` — один аватар из `image-url`; `active` добавляет точку
  присутствия, `check` — отметку.

Шаблоны `default`, `group`, `label` и `profile` пишут классы
`sf-avatar-round`, `sf-avatar--image`, `sf-avatar-cir`, `sf-avatar-check`,
`sf-avatar-profile`, которых нет в таблицах стилей выпуска: аватары в них
выводятся без формы и размера. Шаблон `user` выводит изображение и текст
обычной разметкой. Одиночный аватар и аватар с подписью стройте на
`<sf-avatar>`.

## Поведение

### Данные одним атрибутом

Значения можно передать по одному атрибуту или целиком: `fields` (прежнее
имя — `data`) принимает JSON с теми же полями в camelCase или snake_case
(`imageUrl`, `label_text`, `avatars`), `property` — JSON с размерами
(`roundSize`, `labelSize`, `profileSize`). Атрибут сильнее поля из JSON.
Размеры принимают ступени шкалы (`1/4`, `1/3`, `1/2`, `2`, `3`) или имена
`tiny`, `small`, `big`, `extra_big`.

```html
<sf-avatar-group template="group"
  avatars='[{"imageUrl": "/team/anna.jpg"}, {"imageUrl": "/team/ivan.jpg"}]'
  avatars-more="5"></sf-avatar-group>
```

## Доступность

- Изображения во всех шаблонах декоративны (`alt=""`): человека называет
  видимый текст — `name` в шаблоне `user`, `label-text` в шаблоне `label`.
- Аватары шаблонов `default`, `group` и `label` — кнопки без доступного
  имени, и задать его атрибутом нельзя. Если аватар должен открывать профиль,
  используйте `<sf-avatar>` с `aria-label`.
- Счётчик остатка в шаблоне `group` — текст кнопки; рядом с группой
  сообщите словами, сколько участников всего.

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.
