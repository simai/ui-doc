# Часть страницы по адресу

:badge[sf-include]{variant=tonal scheme=primary size=1/2} :badge[1.0.4]{variant=outline scheme=on-surface size=1/2}

Часть страницы по адресу подгружает то, что сервер сайта отдаёт отдельно: блок
новостей, список, собранный на сервере, нижнюю часть страницы, которую стоит
загрузить, только когда человек до неё долистает. Она заменяет прежние классы
`ajax`, `ajaxload` и `lazy-load`.

## Пример

:::example {id="smart-components/include/overview" label="Новости с адреса и часть страницы с компонентами"}
:::

Верхний блок — новости с адреса, нижний — часть страницы с компонентами
внутри: они запускаются сами.

## Разметка

Части нужен только адрес:

```html
<sf-include src="/parts/news/"></sf-include>
```

`src` — адрес части. Он считается от страницы, как у ссылки. Новый `src`
загружает новую часть на место прежней; пустой `src` ничего не запрашивает, и
остаётся заготовка. Свою заготовку на время загрузки кладут в слот
`placeholder`:

```html
<sf-include src="/parts/news/">
  <div slot="placeholder"><p>Загружаем новости…</p></div>
</sf-include>
```

## Состояния

### Загрузка

По умолчанию на время загрузки компонент рисует
[скелетон](/ru/smart/feedback/skeleton/) из `lines` строк: от 1 до
20, по умолчанию 3, последняя короче; без адреса компонент так и держит
заготовку. Заготовка из слота `placeholder` заменяет скелетон.

Заготовка возвращается и при повторной загрузке. Если высота части известна,
задайте её переменной `--sf-include-min-block-size`, чтобы страница не
сдвигалась, когда часть придёт.

:::example {id="smart-components/include/state-loading" label="Заготовка из четырёх строк"}
:::

### Ошибка

Сбой сети, отказ CORS или ответ вне 200–299 показывают одну строку: иконку,
сообщение «Не удалось загрузить эту часть страницы.» и кнопку «Повторить»,
которая вызывает `refresh()`.

:::example {id="smart-components/include/state-error" label="Адрес не ответил"}
:::

## Поведение

### Момент загрузки

`load` задаёт, когда идёт запрос:

- `now` (по умолчанию) — сразу, как элемент оказался на странице;
- `view` — один раз, когда блок подходит к экрану ближе чем на 200 px. Там,
  где браузер не умеет следить за видимостью, часть загружается сразу.

```html
<sf-include src="/parts/news/"></sf-include>
<sf-include src="/parts/reviews/" load="view"></sf-include>
```

### Что вставляется

Ответ читается как текст и вставляется как HTML; у целого документа берётся
`<body>`.

- **Скрипты не выполняются.** Код в `<script>`, обработчики вроде `onclick`
  и адреса `javascript:` убираются. Остаётся только JSON с настройками
  (`<script type="application/json" data-sf-settings>`): из него читают
  данные компоненты части. Поведение переносите в компоненты, а не в скрипты
  части.
- **Компоненты запускаются.** Смарт-компоненты, компоненты на классах и
  утилиты в части загружаются и рисуются так же, как в остальной странице.
- **Это не очистка HTML.** Часть — собственная разметка сайта. HTML из
  недоверенного источника пропустите через `SF.sanitizeHtml`.

### Запрос

Компонент делает `fetch(src)` с `credentials: 'same-origin'` и заголовком
`Accept: text/html`. Адрес своего сайта загружается с cookie страницы, чужой —
только если его сервер разрешает это по CORS, и без cookie. Запрос всегда один:
новый `src` или `refresh()` отменяет прежний, удаление элемента — тоже. Кто
может видеть часть, решает сервер: он отдаёт разметку или отказывает статусом.

### Повтор

`refresh()` загружает часть заново и возвращает обещание с итогом:
`{outcome: 'applied'}`, `{outcome: 'refused', reason}` с причиной `no-src`,
`network` или `http`, либо `{outcome: 'cancelled'}`, если загрузку сменила
новая или элемент убран. Кнопка страницы запускает его без кода:
`data-sf-action="<id>.refresh"`.

### События

- `sf-include-loaded` — `{src, status}`: часть уже на странице, слушатель
  находит её внутри элемента.
- `sf-include-load-failed` — `{src, status, reason}`: `reason` — `network`
  (`status` равен `null`) или `http` (`status` — код ответа сервера).

```js
document.querySelector('#news').addEventListener('sf-include-load-failed', (event) => {
  console.warn('Новости не загрузились', event.detail.status);
});
```

## Доступность

- Пока часть загружается, у области стоит `aria-busy="true"`.
- Сообщение об ошибке находится в вежливой области состояния: программа
  чтения с экрана объявит его.
- Если фокус был на кнопке «Повторить», при повторной загрузке он остаётся в
  области компонента.
- Заголовки и ориентиры части должны продолжать структуру страницы: часть
  встаёт в документ как обычная разметка.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `src` | строка | пусто | — | Адрес части: страница собственного сервера сайта, которая отвечает HTML. По умолчанию тот же источник; другой — только если его сервер разрешает это по CORS. Новый адрес загружает новую часть; пустой ничего не запрашивает, и остаётся заготовка. |
| `load` | строка | `now` | `now`, `view` | Когда загружается часть: `now` — сразу, как элемент оказался на странице; `view` — один раз, когда он подходит к экрану ближе чем на 200 px (через IntersectionObserver; без него — сразу). |
| `lines` | целое число | `3` | от 1; до 20 | Сколько строк текста рисует скелетон, пока часть загружается, если страница не дала свою заготовку. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `refresh()` | объект | Загружает `src` заново сразу, что бы ни говорил `load`. Отвечает `applied`, когда часть пришла; `refused {reason: no-src \| network \| http}`, когда адреса нет или загрузка не удалась; `cancelled`, когда её сменила новая загрузка (другой `src`, ещё один `refresh`) или элемент убран. Его вызывает кнопка «Повторить» в состоянии ошибки. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-include-loaded` | `{ src: string, status: number }` | Часть пришла и стоит на странице: `src` — адрес, как он задан, `status` — HTTP-статус. Отправляется после вставки разметки, так что слушатель находит её внутри элемента. |
| `sf-include-load-failed` | `{ src: string, status: number\|null, reason: "network" \| "http" }` | Часть не пришла: `reason` — `network` (запрос не прошёл или другой источник отказал по CORS; `status` равен `null`) или `http` (сервер ответил вне 200–299; `status` — его код). Элемент показывает ошибку с «Повторить». |
