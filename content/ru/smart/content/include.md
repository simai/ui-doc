# Часть страницы по адресу

`<sf-include>` вставляет в страницу часть, которую сервер сайта отдаёт по
адресу: блок новостей, список, собранный на сервере, нижнюю часть страницы,
которую стоит загрузить, только когда человек до неё долистает. Компонент
заменяет прежние классы `ajax`, `ajaxload` и `lazy-load`.

## Пример

Верхний блок — новости с адреса, нижний — часть страницы с компонентами
внутри: они запускаются сами.

### Заготовка и ошибка

Без адреса компонент держит заготовку из `lines` строк. Если адрес не
ответил, на месте части появляются сообщение и кнопка «Повторить».

## Применение

### Адрес и момент загрузки

`src` — адрес части. Он считается от страницы, как у ссылки. Новый `src`
загружает новую часть на место прежней; пустой `src` ничего не запрашивает, и
остаётся заготовка.

`load` задаёт, когда идёт запрос:

- `now` (по умолчанию) — сразу, как элемент оказался на странице;
- `view` — один раз, когда блок подходит к экрану ближе чем на 200 px. Там,
  где браузер не умеет следить за видимостью, часть загружается сразу.

```html
<sf-include src="/parts/news/"></sf-include>
<sf-include src="/parts/reviews/" load="view"></sf-include>
```

### Заготовка на время загрузки

По умолчанию на время загрузки компонент рисует
[скелетон](/ru/smart/feedback/skeleton/) из `lines` строк: от 1 до
20, по умолчанию 3, последняя короче. Свою заготовку кладут в слот
`placeholder`:

```html
<sf-include src="/parts/news/">
  <div slot="placeholder"><p>Загружаем новости…</p></div>
</sf-include>
```

Заготовка возвращается и при повторной загрузке. Если высота части известна,
задайте её переменной `--sf-include-min-block-size`, чтобы страница не
сдвигалась, когда часть придёт.

### Что вставляется

Ответ читается как текст и вставляется как HTML; у целого документа берётся
`<body>`.

- **Скрипты не выполняются.** Код в `<script>`, обработчики вроде `onclick`
  и адреса `javascript:` убираются. Остаётся только JSON с настройками
  (`<script type="application/json" data-sf-settings>`): из него читают
  данные компоненты части. Поведение переносите в компоненты, а не в скрипты
  части.
- **Компоненты запускаются.** Смарт-компоненты, компоненты на классах и
  утилиты в части загружаются и рисуются так же, как в остальной странице.
- **Это не очистка HTML.** Часть — собственная разметка сайта. HTML из
  недоверенного источника пропустите через `SF.sanitizeHtml`.

### Запрос

Компонент делает `fetch(src)` с `credentials: 'same-origin'` и заголовком
`Accept: text/html`. Адрес своего сайта загружается с cookie страницы, чужой —
только если его сервер разрешает это по CORS, и без cookie. Запрос всегда один:
новый `src` или `refresh()` отменяет прежний, удаление элемента — тоже. Кто
может видеть часть, решает сервер: он отдаёт разметку или отказывает статусом.

### Ошибка и повтор

Сбой сети, отказ CORS или ответ вне 200–299 показывают одну строку: иконку,
сообщение «Не удалось загрузить эту часть страницы.» и кнопку «Повторить»,
которая вызывает `refresh()`.

`refresh()` загружает часть заново и возвращает обещание с итогом:
`{outcome: 'applied'}`, `{outcome: 'refused', reason}` с причиной `no-src`,
`network` или `http`, либо `{outcome: 'cancelled'}`, если загрузку сменила
новая или элемент убран. Кнопка страницы запускает его без кода:
`data-sf-action="<id>.refresh"`.

### События

- `sf-include-loaded` — `{src, status}`: часть уже на странице, слушатель
  находит её внутри элемента.
- `sf-include-load-failed` — `{src, status, reason}`: `reason` — `network`
  (`status` равен `null`) или `http` (`status` — код ответа сервера).

```js
document.querySelector('#news').addEventListener('sf-include-load-failed', (event) => {
  console.warn('Новости не загрузились', event.detail.status);
});
```

## Доступность

- Пока часть загружается, у области стоит `aria-busy="true"`.
- Сообщение об ошибке находится в вежливой области состояния: программа
  чтения с экрана объявит его.
- Если фокус был на кнопке «Повторить», при повторной загрузке он остаётся в
  области компонента.
- Заголовки и ориентиры части должны продолжать структуру страницы: часть
  встаёт в документ как обычная разметка.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто.
- `root-style` — `string`, по умолчанию пусто.
- `src` — `string`, по умолчанию пусто. Адрес части: страница собственного сервера сайта, которая отвечает HTML. По умолчанию тот же источник; другой — только если его сервер разрешает это по CORS. Новый адрес загружает новую часть; пустой ничего не запрашивает, и остаётся заготовка.
- `load` — `string`, по умолчанию `now`, значения: `now`, `view`. Когда загружается часть: `now` — сразу, как элемент оказался на странице; `view` — один раз, когда он подходит к экрану ближе чем на 200 px (через IntersectionObserver; без него — сразу).
- `lines` — `integer`, по умолчанию `3`, значения: от 1; до 20. Сколько строк текста рисует скелетон, пока часть загружается, если страница не дала свою заготовку.

### Методы

- `refresh()` — возвращает `object`. Загружает `src` заново сразу, что бы ни говорил `load` (слово словаря `refresh`: перечитывает). Отвечает `applied`, когда часть пришла; `refused {reason: no-src | network | http}`, когда адреса нет или загрузка не удалась; `cancelled`, когда её сменила новая загрузка (другой `src`, ещё один `refresh`) или элемент убран. Его вызывает кнопка «Повторить» в состоянии ошибки.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `sf-include-loaded` — `detail`: `{ src: string, status: number }`. Часть пришла и стоит на странице: `src` — адрес, как он задан, `status` — HTTP-статус. Отправляется после вставки разметки, так что слушатель находит её внутри элемента.
- `sf-include-load-failed` — `detail`: `{ src: string, status: number|null, reason: any }`. Часть не пришла: `reason` — `network` (запрос не прошёл или другой источник отказал по CORS; `status` равен `null`) или `http` (сервер ответил вне 200–299; `status` — его код). Элемент показывает ошибку с «Повторить».

### Доступность

- Роль: нет (`none`).
- Доступное имя: внутренний.
- Клавиши: `Tab` доходит до «Повторить» в состоянии ошибки., `Enter` или `Space` нажимает «Повторить»..
- Фокус: Фокус с «Повторить» на время повторной загрузки переходит на область (`tabindex -1`) и не падает на страницу; при новой ошибке он переходит на новую кнопку «Повторить».

### Минимальная разметка

```html
<sf-include src="/parts/news/" load="view"></sf-include>
```
