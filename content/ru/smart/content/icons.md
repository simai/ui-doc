# Иконки

:badge[sf-icon]{variant=tonal scheme=primary size=1/2} :badge[1.1.6]{variant=outline scheme=on-surface size=1/2}

Иконка выводит один символ Material Symbols по имени, а загружается только
нужная часть шрифта. Размер, начертание, заливка и толщина задаются атрибутами
на общей шкале SIMAI Framework. Для иконки, которую нажимают, берите [Кнопки с
иконкой](/ru/smart/actions/icon-buttons/).

То же на классах — [Иконки](/ru/components/content/icons/): элемент
строится на классах этого компонента; для статической разметки без
JavaScript.

## Разметка

Иконке нужно только имя символа:

```html
<sf-icon icon="home"></sf-icon>
```

`icon` — имя символа из набора Material Symbols, например `home` или
`settings`. Самостоятельной иконке, которая сообщает смысл, задайте `label`
(см. [Доступность](#доступность)).

## Варианты

### Семейство

`type` — начертание: `outlined`, `rounded` или `sharp`. Без него действует
начертание проекта из `SF_BOOT_CONFIG.icons.type`, а если оно не задано —
`outlined`. Держите одно начертание во всём интерфейсе.

:::example {id="smart-components/icons/families" label="outlined, rounded и sharp"}
:::

### Начертание

`weight` — толщина линии от `100` до `700` с шагом 100, по умолчанию `400`.

:::example {id="smart-components/icons/weights" label="Толщина линии от 100 до 700"}
:::

### Заливка

`filled` включает заливку — например, для выбранного состояния.

```html
<sf-icon icon="star" filled weight="600" size="2"></sf-icon>
```

:::example {id="smart-components/icons/fill" label="Контурная и залитая иконка"}
:::

### Размер

`size` выбирает ступень шкалы размеров иконок: `1/4`, `1/3`, `1/2`, `1` —
`7`. Без `size` иконка получает размер ступени `3`. Рядом с подписью берите
ступень, которая совпадает с высотой строки текста.

:::example {id="smart-components/icons/sizes" label="Размеры от 1/4 до 7"}
:::

### Оси шрифта

`grade` (от `-50` до `200`) и `optical-size` (от `20` до `48`) — тонкая
настройка осей шрифта; значения вне диапазона приводятся к границе.

:::example {id="smart-components/icons/axes" label="Крайние значения grade и optical-size"}
:::

### Счётчик и точка

- `badge-count` — счётчик на иконке: целое число больше `0`; `0` или пусто
  прячет бейдж.
- `badge-dot` — точка без числа: есть новое.
- `badge-cap` — порог, по умолчанию `99`: число больше порога показывается как
  `99+`.
- `badge-label` — свои слова вместо «непрочитанных» и «есть новое»: формы
  множественного числа через `|` с `{count}` на месте числа.

С бейджем иконка встаёт в обёртку `sf-badge-anchor` своего размера. Размер
бейджа следует `size`: от `1/4` до `2` рисуется точка, `3` и без `size` —
малый счётчик, `4` и `5` — средний, `6` и `7` — крупный. С `label` обёртка
становится изображением с именем «Почта, 3 непрочитанных»; без `label` фраза
звучит скрытым текстом. Устройство бейджа описано в разделе
[Бейдж на якоре](/ru/components/feedback/badges/#бейдж-на-якоре).

:::example {id="smart-components/icons/badge" label="badge-count, badge-dot, badge-cap и badge-label на иконках"}
:::

## Поведение

### Загрузка знаков

Loader отслеживает каждый `<sf-icon>` и загружает знаки шрифта, нужные
странице, в том числе после смены `icon`. Пока знак не загружен, иконка
сжата до нуля, и имя символа не мелькает текстом. Атрибут `loaded`
компонент ставит сам, когда знак готов; задавать его в разметке не нужно.

## Доступность

- Без `label` иконка декоративна и скрыта от экранного диктора
  (`aria-hidden="true"`). Так и нужно, когда смысл передаёт текст рядом или
  имя кнопки, в которой стоит иконка: не задавайте `label` иконке внутри
  уже названной кнопки.
- Самостоятельной иконке, которая сообщает смысл, задайте `label`: элемент
  получит `role="img"` и это доступное имя.
- Иконка не получает фокус и не реагирует на клавиатуру. Действие делайте
  кнопкой.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `icon` | строка | пусто | — | — |
| `filled` | да/нет | нет | — | — |
| `weight` | целое число | `400` | от 100; до 700 | — |
| `size` | строка | пусто | пусто, `1/4`, `1/3`, `1/2`, `1`, `2`, `3`, `4`, `5`, `6`, `7` | — |
| `type` | строка | пусто | пусто, `outlined`, `rounded`, `sharp` | — |
| `grade` | целое число | `0` | от -50; до 200 | — |
| `optical-size` | число | `24` | от 20; до 48 | — |
| `label` | строка | пусто | — | — |
| `badge-count` | строка | пусто | — | Счётчик на иконке: целое число больше 0 показывается, 0 или пусто прячет бейдж. Больше badge-cap он показывается как порог с плюсом, например «99+»; точное число входит в доступное имя иконки («Почта, 3 непрочитанных») и во всплывающую подсказку бейджа. На якоре размера 1/3 или 1/2 счётчик рисуется точкой. |
| `badge-dot` | да/нет | нет | — | Точка на иконке — отметка без числа: есть новое. Показывается, когда badge-count не задан; при заданном счётчике он рисуется точкой. Её текстовый эквивалент («есть новое» / «new» по умолчанию, другой задаёт badge-label) входит в доступное имя. |
| `badge-cap` | целое число | `99` | от 1 | Наибольшее число на значке; большее показывается с плюсом, например «99+». |
| `badge-label` | строка | пусто | — | Слова значка для экранного диктора и подсказки. Для точки — фраза целиком, например «есть новое». Для числа — формы через «\|» с `{count}` на месте числа, например `{count} новое\|{count} новых\|{count} новых`. |
| `loaded` | да/нет | нет | — | Точное подмножество, рисующее этот символ, на месте; синхронизируется из Loader, это не переключатель для автора. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.
