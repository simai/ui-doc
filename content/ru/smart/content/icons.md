# Иконки

:badge[sf-icon]{variant=outline scheme=on-surface size=1/2} :badge[1.4.4]{variant=outline scheme=on-surface size=1/2}

Иконка выводит один символ Material Symbols по имени, а загружается только
нужная часть шрифта. Размер, семейство, заливка и толщина задаются атрибутами
на общей шкале SIMAI Framework. Для иконки, которую нажимают, берите [Кнопки с
иконкой](/ru/smart/actions/icon-buttons/).

То же на классах — [Иконки](/ru/components/content/icons/): элемент
строится на классах этого компонента; для статической разметки без
JavaScript.

## Разметка

Иконке нужно только имя символа:

```html
<sf-icon icon="home"></sf-icon>
```

`icon` — имя символа из набора Material Symbols, например `home` или
`settings`. Самостоятельной иконке, которая сообщает смысл, задайте `label`
(см. [Доступность](#доступность)).

## Варианты

### Толщина

`weight` • по умолчанию `400` • [справочник](#атрибуты)

`weight` — толщина линии от `100` до `700` с шагом 100, по умолчанию `400`.

:::example {id="smart-components/icons/weights" label="Толщина линии от 100 до 700"}
:::

### Заливка

`filled` • [справочник](#атрибуты)

`filled` включает заливку — например, для выбранного состояния.

```html
<sf-icon icon="star" filled weight="600" size="2"></sf-icon>
```

:::example {id="smart-components/icons/fill" label="Контурная и залитая иконка"}
:::

### Цвет

`class="color-*"` • [Цвет иконки: три роли](/ru/guide/colour/colour-roles/#цвет-иконки-три-роли)

Иконка берёт цвет текста вокруг. Свой цвет задайте утилитой `color-*` на
самой иконке или на предке. Ролей у иконки три, по весу текста рядом:

- `color-on-surface` — иконка несёт смысл наравне с текстом: в заголовке, в
  пункте меню;
- `color-on-surface-variant` — служебная иконка: ручка перетаскивания,
  «закрыть», подсказка;
- `color-on-surface-disabled` — элемент недоступен.

Внутри окрашенной кнопки или поля иконка берёт цвет их текста.

:::example {id="smart-components/icons/colour" label="Три роли цвета иконки"}
:::

### Размер

`size` • [справочник](#атрибуты)

`size` выбирает ступень шкалы размеров иконок: `1/4`, `1/3`, `1/2`, `1` —
`7`. Без `size` иконка получает размер ступени `3`. Рядом с подписью берите
ступень, которая совпадает с высотой строки текста.

:::example {id="smart-components/icons/sizes" label="Размеры от 1/4 до 7"}
:::

### Оси шрифта

`grade`, `optical-size` • [справочник](#атрибуты)

`grade` (от `-50` до `200`) и `optical-size` (от `20` до `48`) — тонкая
настройка осей шрифта; значения вне диапазона приводятся к границе.

:::example {id="smart-components/icons/axes" label="Оси шрифта"}
:::

### Счётчик и точка

`badge-count`, `badge-dot`, `badge-cap` • [справочник](#атрибуты)

- `badge-count` — счётчик на иконке: целое число больше `0`; `0` или пусто
  прячет бейдж.
- `badge-dot` — точка без числа: есть новое.
- `badge-cap` — порог, по умолчанию `99`: число больше порога показывается как
  `99+`.
- `badge-label` — свои слова вместо «непрочитанных» и «есть новое»: формы
  множественного числа через `|` с `{count}` на месте числа.

С бейджем иконка встаёт в обёртку `sf-badge-anchor` своего размера. Размер
бейджа следует `size`: от `1/4` до `2` рисуется точка, `3` и без `size` —
малый счётчик, `4` и `5` — средний, `6` и `7` — крупный. С `label` обёртка
становится изображением с именем «Почта, 3 непрочитанных»; без `label` фраза
звучит скрытым текстом. Устройство бейджа описано в разделе
[Бейдж на якоре](/ru/components/feedback/badges/#бейдж-на-якоре).

:::

## Поведение

### Загрузка знаков

Загрузчик Framework отслеживает каждый `<sf-icon>` и загружает знаки шрифта, нужные
странице, в том числе после смены `icon`. Пока знак не загружен, иконка
сжата до нуля, и имя символа не мелькает текстом. Атрибут `loaded`
компонент ставит сам, когда знак готов; задавать его в разметке не нужно.

## Доступность

- Без `label` иконка декоративна и скрыта от экранного диктора
  (`aria-hidden="true"`). Так и нужно, когда смысл передаёт текст рядом или
  имя кнопки, в которой стоит иконка: не задавайте `label` иконке внутри
  уже названной кнопки.
- Самостоятельной иконке, которая сообщает смысл, задайте `label`: элемент
  получит `role="img"` и это доступное имя.
- Иконка не получает фокус и не реагирует на клавиатуру. Действие делайте
  кнопкой.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `icon` | строка | пусто | — | Имя значка в Material Symbols (home, mail, star); у шрифта значков запрашивается только этот значок. |
| `filled` | да/нет | нет | — | Рисует залитую форму значка (ось FILL шрифта в 1); выключено — контур. |
| `weight` | целое число | `400` | от 100; до 700 | Толщина линии по оси wght шрифта, от 100 до 700 шагом 100. Без настройки значок берёт насыщенность окружающего текста — обычную рядом с текстом, среднюю рядом со средней подписью (у кнопки, вкладки), — а обычное и среднее начертание приходят одним запросом; любое другое значение рисует 400. |
| `size` | строка | пусто | пусто, `1/4`, `1/3`, `1/2`, `1`, `2`, `3`, `4`, `5`, `6`, `7` | Ступень значка. В области (или на иконке) с `data-sf-icon-scale="ladder"` размер — ступень лестницы интерфейса её хоста: `1/3`, `1/2`, `1`, `2`, `3` рисуют 16, 20, 24, 28, 36 на компьютере и ступенью ниже на телефоне и в компактной области, как кнопка, поле или строка того же размера; `4`…`7` — крупные значки пустых состояний (28, 32, 36, 40, на телефоне ступенью ниже). В остальных местах до 2027-01-01 отвечает старая шкала иконок: `1/4`, `1/3`, `1/2`, `1`, `2`, `3` рисуют 12, 12, 14, 16, 20, 24 (отмечается в `SF.deprecations` с именем по лестнице; запись журнала `value-icon-size-ladder`). Пусто — размер, который даёт окружающий компонент (`--sf-icon--font-size`), иначе 24 (на телефоне 20), ступень `1`. |
| `mirror` | строка | `auto` | `auto`, `on`, `off` | Поворот в части справа налево (`dir="rtl"`): `auto` поворачивает значки, которые указывают вдоль строки (стрелки, шевроны, отправка, ответ, отмена и повтор, списки и отступы, открыть в новой вкладке, вход и выход), `on` — любой значок, `off` — никакой. Часы, галочки, медиа и логотипы при `auto` остаются как нарисованы. |
| `type` | строка | пусто | пусто, `outlined` | Стиль шрифта значков: outlined — единственное семейство, которое поставляет Framework. rounded и sharp — прежние значения до 2027-01-01 и рисуют outlined. |
| `grade` | целое число | `0` | от -50; до 200 | Ось GRAD шрифта, от -50 до 200: более тонкая настройка насыщенности, которая не меняет ширину значка. Без настройки — 0 в светлой теме и -25 в тёмной (светлый цвет на тёмном читается жирнее). |
| `optical-size` | число | `24` | от 20; до 48 | Ось opsz шрифта, от 20 до 48: рисунок, настроенный для этого размера в px. Без настройки следует размеру значка (20 до 20 px, затем размер, не больше 48). |
| `label` | строка | пусто | — | Доступное имя. Задано — значок становится картинкой с этим именем (role img). Пусто — значок украшение и скрыт от вспомогательных технологий. |
| `badge-count` | строка | пусто | — | Счётчик на иконке: целое число больше 0 показывается, 0 или пусто прячет бейдж. Больше badge-cap он показывается как порог с плюсом, например «99+»; точное число входит в доступное имя иконки («Почта, 3 непрочитанных») и во всплывающую подсказку бейджа. На якоре размера 1/3 или 1/2 счётчик рисуется точкой. |
| `badge-dot` | да/нет | нет | — | Точка на иконке — отметка без числа: есть новое. Показывается, когда badge-count не задан; при заданном счётчике он рисуется точкой. Её текстовый эквивалент («есть новое» / «new» по умолчанию, другой задаёт badge-label) входит в доступное имя. |
| `badge-cap` | целое число | `99` | от 1 | Наибольшее число на значке; большее показывается с плюсом, например «99+». |
| `badge-label` | строка | пусто | — | Слова значка для экранного диктора и подсказки. Для точки — фраза целиком, например «есть новое». Для числа — формы через «\|» с `{count}` на месте числа, например `{count} новое\|{count} новых\|{count} новых`. |
| `loaded` | да/нет | нет | — | Точное подмножество, рисующее этот символ, на месте; синхронизируется из загрузчика, это не переключатель для автора. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.
