# Аккордеон

:badge[sf-accordion]{variant=tonal scheme=primary size=1/2} :badge[1.1.6]{variant=outline scheme=on-surface size=1/2}

Аккордеон делит одно содержание на секции, которые открываются и закрываются
по нажатию на шапку: группы полей записи, разделы настроек, вопросы и ответы.
Секции задают данными или элементами `<details>`; размеры, виды, метки и режим
одной открытой секции — те же, что у аккордеона на классах. Чтобы
переключаться между разными видами одного объекта, берите
[Вкладки](/ru/smart/navigation/tabs/).

То же на классах — [Аккордеон](/ru/components/content/accordion/): для
статической разметки без JavaScript.

## Разметка

Секции задаёт `items` — массив `{id, title, content, open, disabled, icon, badge}`:
в свойстве — массивом, в атрибуте — тем же массивом в JSON.

```html
<sf-accordion items='[{"id":"main","title":"Основное","content":"Название и описание."}]'></sf-accordion>
```

`id` называет секцию в методах и событии; без него секция получает имя по
месту (`section-1`, `section-2`…).

- `content` — только текст. Разметку внутри секции передайте слотом:
  `{"id": "help", "title": "Справка", "slot": "help"}` и дочерний элемент со
  `slot="help"`.
- Без `items` компонент берёт элементы `<details>` со `<summary>`, написанные
  внутри него, и оформляет их так же, как секции из данных. Так пишут
  секции, в которых нужны ссылки, списки или поля:

```html
<sf-accordion>
  <details open>
    <summary>Секция из разметки</summary>
    <p>Содержимое со <a href="#">ссылкой</a>.</p>
  </details>
</sf-accordion>
```

## Варианты

### Поверхность

`appearance` выбирает вид: `default` — секции на заливке, `outline` — тонкая
рамка без заливки, `flush` — без заливки и скругления, секции разделены
линией; для панелей и списков.

:::example {id="smart-components/accordion/appearance" label="Виды default, outline и flush"}
:::

### Размер

Без `size` шапка просторная, как на странице с текстом. `size` ставит
ступень лестницы элементов управления: шапка ровно такой высоты, как
`sf-input` и `sf-button` того же размера, — для панелей рядом с полями.

:::example {id="smart-components/accordion/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Иконка

`marker` выбирает, чем отмечена открытая секция: шевроном (по умолчанию) или
плюсом и минусом (`plus-minus`).

:::example {id="smart-components/accordion/marker" label="Шеврон и плюс-минус"}
:::

### Один открытый раздел

`single` оставляет открытой только одну секцию: открытие другой закрывает
прежнюю. Так удобно читать вопросы и ответы.

:::example {id="smart-components/accordion/single" label="Вопросы и ответы, single"}
:::

### Одна секция

Если секция одна, это обычный раздел: содержимое видно, шапка не
переключает. `single-section="toggle"` оставляет её раскрывающейся — для
списка, который пополнится позже.

:::example {id="smart-components/accordion/single-section" label="Одна секция: обычная и раскрывающаяся"}
:::

## Состояния

### Открыт

`open: true` открывает секцию сразу; остальные секции закрыты, пока их не
откроют.

:::example {id="smart-components/accordion/state-open" label="Открытая и закрытая секции"}
:::

### Недоступен

`disabled: true` делает шапку недоступной: секция не открывается, а
клавиатура её пропускает.

:::example {id="smart-components/accordion/state-disabled" label="Обычная и недоступная секции"}
:::

## Поведение

### Управление из кода и событие

`open(id)`, `close(id)` и `toggle(id)` открывают и закрывают секцию и
возвращают, изменилось ли что-нибудь; `isOpen(id)` отвечает, открыта ли она.
Каждое открытие и закрытие отправляет `sf-accordion:toggle` с `id`, `open` и
`source`: `user` — нажал человек, `method` — вызван метод. В режиме `single`
закрытая при этом секция отправляет своё событие следом.

```js
const faq = document.querySelector('sf-accordion');
faq.addEventListener('sf-accordion:toggle', (event) => {
  if (event.detail.open) history.replaceState(null, '', `#${event.detail.id}`);
});
faq.open(location.hash.slice(1));
```

## Доступность

- Шапка каждой секции — кнопка внутри заголовка уровня `heading-level`
  (по умолчанию 3) с `aria-expanded` и `aria-controls`.
- `Enter` и `Space` открывают и закрывают секцию; `↓` и `↑` переходят между
  шапками по кругу, `Home` и `End` — к первой и последней. Недоступная шапка
  пропускается.
- Пока секций шесть или меньше, содержимое каждой — область, названная её
  шапкой.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `single` | да/нет | нет | — | Открыта только одна секция: открытие другой закрывает прежнюю. |
| `size` | строка | пусто | пусто, `1/3`, `1/2`, `1`, `2`, `3` | Высота шапки как у поля и кнопки того же размера, например `1`. Без него — просторная шапка страницы с текстом. |
| `appearance` | строка | `default` | `default`, `outline`, `flush` | default: заливка поверхности; outline: тонкая рамка без заливки; flush: без заливки и скругления, секции разделены линией — для панелей и списков. |
| `marker` | строка | `chevron` | `chevron`, `plus-minus` | Чем отмечена открытая или закрытая секция: шевроном или плюсом и минусом. |
| `single-section` | строка | `static` | `static`, `toggle` | Одна секция — обычный раздел: содержимое видно, заголовок не переключает; toggle оставляет её раскрывающейся — для списка, который пополнится позже. |
| `heading-level` | целое число | `3` | от 2; до 6 | Уровень заголовка каждой секции (role heading, aria-level). |
| `items` | список: объект | `[]` | например `[{"id":"main","title":"Основное","content":"Название и описание","open":true},{"id":"seo","title":"SEO","content":"Заголовок страницы","badge":"3"}]` | Секции [{id, title, content \| slot, open?, disabled?, icon?, badge?}]: массив в свойстве, тот же массив в JSON в атрибуте. Без items элемент берёт `<details>`, написанные внутри. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `open(id: any)` | да/нет | Открывает секцию с этим id; в режиме single открытая закрывается. sf-accordion-toggle приходит для каждой изменившейся секции, source method. Возвращает, изменилось ли что-нибудь. |
| `close(id: any)` | да/нет | Закрывает секцию с этим id. Возвращает, изменилось ли что-нибудь. |
| `toggle(id: any)` | да/нет | Открывает секцию, если она закрыта, и закрывает, если открыта. Возвращает, изменилось ли что-нибудь. |
| `isOpen(id: string)` | да/нет | Открыта ли секция с этим id. Единственная секция открыта всегда. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-accordion-toggle` | `{ id: any, open: boolean, source: any, section: object }` | — |
