# Предпросмотр файла

:badge[sf-file-preview]{variant=tonal scheme=primary size=1/2} :badge[1.1.5]{variant=outline scheme=on-surface size=1/2}

Предпросмотр файла показывает один уже выбранный или прикреплённый файл:
значок или миниатюру, имя, размер и две кнопки — скачать и удалить. Выбирают и
загружают файлы в [Загрузке файлов](/ru/smart/forms/file-upload/).

То же на классах — [Предпросмотр файла](/ru/components/content/file-preview/):
элемент строится на классах этого компонента; для статической разметки без
JavaScript.

## Разметка

Строке нужны имя и размер файла:

```html
<sf-file-preview file-name="Отчёт за квартал.pdf" file-size="1,2 МБ"></sf-file-preview>
```

`file-name` — видимое имя файла (прежнее имя атрибута — `name`),
`file-size` — размер готовым текстом («1,2 МБ»); компонент его не
вычисляет. `href` — адрес файла для скачивания. Слева показывается значок
из `icon` (по умолчанию `description`) или миниатюра.

## Варианты

### Миниатюра

`kind` решает, что стоит слева:

- `auto` — миниатюра, если `mime-type` начинается с `image/` или адрес
  (`image-url`, затем `href`, затем имя файла) оканчивается расширением
  изображения; иначе значок;
- `image` — всегда миниатюра из `image-url`, а без него — из `href`;
- `icon` — всегда значок.

Для адреса без расширения, например `data:` или адреса хранилища, задайте
`kind="image"` явно.

:::

### Поверхность

`surface` добавляет строке фон — для файла, который стоит отдельно, а не в
списке.

### Действия

`download-action="false"` и `remove-action="false"` убирают одну кнопку,
`actions="false"` — обе.

### Компактный

`compact` оставляет только ведущий значок высотой со строку списка:
изображение или расширение файла в плитке. Для файла в ячейке таблицы.

## Поведение

### Скачивание и удаление

Нажатие на кнопку отправляет всплывающее событие с возможностью отмены:
`sf-file-preview:download` или `sf-file-preview:remove`. В `event.detail`:

| Поле | Содержимое |
|:---|:---|
| `action` | `download` или `remove` |
| `value` | данные файла: `fileName`, `fileSize`, `icon`, `href`, `type`, `mimeType`, `imageUrl`, `target` |

Если событие скачивания не отменено и задан `href`, компонент сам переходит
по адресу: при `download` (по умолчанию) браузер сохраняет файл под именем из
`file-name`, при `download="false"` открывает его в окне из `target`
(по умолчанию `_blank`). Удаление — только намерение: строку убирает
приложение, когда удаление подтверждено.

```js
const file = document.querySelector('sf-file-preview');
file.onRemove(async (event) => {
  if (await api.deleteAttachment(event.detail.value.href)) file.remove();
});
file.onDownload((event) => {
  event.preventDefault();
  api.downloadAttachment(event.detail.value);
});
```

### Данные файла

`getValue()` возвращает те же данные, что приходят в `event.detail.value`.

## Доступность

- Пока у строки есть кнопки, она — группа (`role="group"`), названная именем
  файла; `aria-label` заменяет это имя.
- Кнопки названы «Скачать файл» и «Удалить файл» на русской странице и
  «Download file», «Remove file» на остальных. В списке из нескольких файлов
  такие имена одинаковы: передайте в `download-label` и `remove-label` имя с
  названием файла, как в примере.
- Значок и миниатюра декоративны; файл называет видимый текст.
- После удаления строки верните фокус на соседний файл или на поле выбора
  файлов: удалённая кнопка фокуса не сохранит.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `file-name` | строка | `File` | — | — |
| `file-size` | строка | пусто | — | Размер файла в виде текста, например 12 KB. |
| `icon` | строка | `description` | — | — |
| `href` | строка | пусто | — | — |
| `kind` | строка | `auto` | `auto`, `icon`, `image` | Что показывает превью: иконку, само изображение или то, что подходит файлу. |
| `mime-type` | строка | пусто | — | — |
| `image-url` | строка | пусто | — | — |
| `surface` | да/нет | нет | — | — |
| `download` | да/нет | да | — | — |
| `target` | строка | `_blank` | — | — |
| `actions` | да/нет | да | — | — |
| `download-action` | да/нет | да | — | — |
| `remove-action` | да/нет | да | — | — |
| `disabled` | да/нет | нет | — | — |
| `download-label` | строка | — | — | Пусто — текст на языке страницы (по-английски «Download file»). |
| `remove-label` | строка | — | — | Пусто — текст на языке страницы (по-английски «Remove file»). |
| `compact` | да/нет | нет | — | Только ведущий значок высотой со строку списка: изображение или расширение файла в плитке. Для файла в ячейке таблицы. |
| `aria-label` | строка | пусто | — | Пусто — текст на языке страницы (по-английски «File»). |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `getValue()` | объект | Возвращает текущий идентификатор файла и значение для отображения. |
| `setOpen()` | объект | Действия остаются видимыми при любом значении. |
| `toggleOpen()` | объект | Действия остаются видимыми при любом значении. |
| `onDownload()` | объект | Регистрирует обработчик события скачивания. |
| `onRemove()` | объект | Регистрирует обработчик события удаления. |

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-file-preview-download` | `{ id: string, action: string, value: object }` | — |
| `sf-file-preview-detach` | `{ id: string, action: string, value: object }` | — |
