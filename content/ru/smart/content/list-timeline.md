# Хронология

:badge[sf-list-timeline]{variant=tonal scheme=primary size=1/2} :badge[1.0.2]{variant=outline scheme=on-surface size=1/2}

Короткая история, которую читают сверху: последние действия на сервере,
журнал аудита, история записи, страница уведомлений, история заданий.
События стоят на вертикальной линии, у каждого отметка состояния, заголовок,
время, автор и строка текста; события одного дня собраны под заголовком дня.
В конце — кнопка «Показать ещё».

Ленту, которую читают от новой записи внизу — переписку, журнал вывода, —
показывайте [Лентой](/ru/smart/content/list-feed/).

## Разметка

События передайте JSON-блоком, который печатает сервер, или свойством
`items`, в том порядке, в каком их показывать:

```html
<sf-list-timeline has-more>
  <script type="application/json" data-sf-settings>
    {"items": [
      {"id": "backup", "time": "2026-10-27T11:58:00+03:00", "status": "success",
       "title": "Копия demo.test создана", "actor": "Планировщик",
       "text": "1,2 ГБ, хранится 30 дней"},
      {"id": "update", "time": "2026-10-27T09:05:00+03:00", "icon": "system_update_alt",
       "title": "Панель обновлена", "href": "/updates/"}
    ]}
  </script>
</sf-list-timeline>
```

Поля события:

| Поле | | Значение |
|:---|:---|:---|
| `id` | обязательно | Имя события; событие с уже встреченным `id` не показывается. |
| `title` | обязательно | Что произошло. |
| `time` | | Момент в ISO 8601 со смещением (`2026-10-27T11:58:00+03:00`) или в миллисекундах. Событие без времени входит в день предыдущего. |
| `status` | | `success`, `warning`, `error` или `info` — цвет отметки; по умолчанию `neutral`. |
| `icon` | | Значок на отметке вместо точки: `add_circle`, `system_update_alt`. |
| `actor` | | Кто это сделал; стоит рядом со временем. |
| `text` | | Строка под заголовком. |
| `href` | | Заголовок становится ссылкой. |

Порядок задаёт хост, список не сортирует. Новые сверху, как в истории, и
старые сверху, как в журнале, группируются одинаково: подряд идущие события
одного дня стоят под одним заголовком.

## Варианты

### Группы по дням

`group` • по умолчанию `day` • [справочник](#атрибуты)

`day` — заголовок на каждый день в часовом поясе читателя: «Сегодня»,
«Вчера», день недели в пределах недели, дальше дата. `none` — один список;
тогда `label` даёт ему имя для экранного диктора. `heading-level` — уровень
заголовков дней в структуре страницы, по умолчанию `3`.

:::example {id="smart-components/list-timeline/group" label="По дням и одним списком" preview=sandbox}
:::

### Время

`time-format`, `now` • по умолчанию `relative` • [справочник](#атрибуты)

`relative` — «2 минуты назад», `exact` — точное время «11:58», а без групп
по дням — с датой. Точные дата и время всегда есть в подсказке под
указателем.

`now` — момент, от которого считаются относительное время и дни. Без него
список берёт часы читателя и сам обновляет время раз в минуту, а дни — в
полночь. В примерах на этой странице `now` задан, чтобы дни не уезжали.

:::example {id="smart-components/list-timeline/time-format" label="Относительное и точное время" preview=sandbox}
:::

### Плотность

`density` • по умолчанию `normal` • [справочник](#атрибуты)

`normal` — текст переносится целиком, между событиями зазор. `compact` —
событие в одну строку высотой с поле того же размера, текст обрезается
многоточием.

:::example {id="smart-components/list-timeline/density" label="Обычная и плотная" preview=sandbox}
:::

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

`1/2` — для боковой панели, `1` — обычный, `2` — крупный. От размера зависят
заголовок, время, текст и отметка.

:::example {id="smart-components/list-timeline/sizes" label="Размеры 1/2, 1 и 2" preview=sandbox}
:::

## Состояния

### Нет событий

`empty-text` • по умолчанию «Событий пока нет» • [справочник](#атрибуты)

Без событий список показывает одну тихую строку.

:::example {id="smart-components/list-timeline/empty" label="Пустая хронология" preview=sandbox}
:::

### Загрузка следующей страницы

`has-more`, `loading` • [справочник](#атрибуты)

С `has-more` после последнего события стоит кнопка «Показать ещё». Пока
`loading`, кнопка показывает загрузку и больше ничего не спрашивает.

:::example {id="smart-components/list-timeline/more" label="Кнопка «Показать ещё»" preview=sandbox}
:::

В примере в начале страницы кнопка работает: следующие события
дописываются в конец, а кнопка исчезает.

## Поведение

### Следующая страница

Нажатие на «Показать ещё» отправляет `sf-list-timeline-load-more` с
`{direction: 'after', after}`, где `after` — `id` последнего показанного
события. Хост ставит `loading`, дописывает следующую страницу в `items` и
снимает `has-more`, когда страниц больше нет.

```js
const timeline = document.querySelector('sf-list-timeline');
timeline.addEventListener('sf-list-timeline-load-more', async (event) => {
  timeline.loading = true;
  const page = await loadEvents({after: event.detail.after});
  timeline.items = [...timeline.items, ...page.items];
  timeline.hasMore = page.hasMore;
  timeline.loading = false;
});
```

### Ссылка в заголовке

Нажатие на заголовок-ссылку сначала отправляет `sf-list-timeline-navigate`
с `{id, href}`. Это просьба: страница с маршрутизатором отменяет событие и
переходит сама; без отмены браузер переходит по `href`. В примере в начале
страницы ссылка у события «Панель обновлена».

## Доступность

- Заголовки дней — заголовки уровня `heading-level`; события дня —
  упорядоченный список с именем по заголовку.
- Состояние произносится словом, отметка — только картинка.
- Время — элемент `time` с точным моментом.
- Список не объявляет новые события сам: если новое событие нужно прочитать
  вслух, хост объявляет его сам.
- Фокус список не берёт: `Tab` проходит по ссылкам и кнопке «Показать ещё»;
  `Enter` открывает ссылку, `Enter` или `Пробел` нажимают кнопку.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `label` | строка | пусто | — | Имя списка для экранного диктора, когда события не собраны по дням и над списком нет заголовка, который его называет. |
| `group` | строка | `day` | `day`, `none` | `day` — события под заголовком своего дня в часовом поясе читателя («Сегодня», «Вчера», день недели в пределах недели, дальше дата), дни в порядке событий; `none` — один список. |
| `time-format` | строка | `relative` | `relative`, `exact` | `relative` — «5 минут назад», «вчера»; `exact` — время «14:32», а без групп по дням — с датой. Точные дата и время всегда видны в подсказке под указателем и записаны в `datetime`. |
| `now` | строка | пусто | — | Момент, от которого считаются относительное время и дни, ISO 8601; пусто — часы читателя, и тогда список обновляет время раз в минуту и дни в полночь. |
| `density` | строка | `normal` | `normal`, `compact` | `normal` — текст переносится целиком, между событиями зазор; `compact` — событие в одну строку высотой с поле того же размера, текст в одну строку. |
| `size` | строка | `1` | `1/2`, `1`, `2` | Размер хронологии: от него зависят заголовок события, время, автор, текст, заголовки дней и отметка. `1/2` — для боковой панели. |
| `heading-level` | целое число | `3` | от 2; до 6 | Уровень заголовков дней в структуре страницы. |
| `has-more` | да/нет | нет | — | Есть ещё события: после последнего стоит кнопка «Показать ещё», её нажатие отправляет `sf-list-timeline-load-more`. |
| `loading` | да/нет | нет | — | Следующая страница загружается: кнопка показывает загрузку и больше ничего не спрашивает. |
| `empty-text` | строка | — | — | Тихая строка, когда событий нет; без атрибута — «Событий пока нет» на русской странице и «No events yet» на остальных. |
| `items` | список | `[]` | — | События в том порядке, в каком их показывать (новые сверху, как в истории, или старые сверху, как в журнале), каждое `{id, title, time?, text?, actor?, status?, icon?, href?}`. `time` — дата и время ISO 8601 со смещением или миллисекунды. `status` (`success`, `warning`, `error`, `info`; по умолчанию `neutral`) красит отметку, `icon` ставит на неё значок вместо точки, `href` делает заголовок ссылкой. Свойство или JSON-блок, который печатает сервер; хост дописывает в него следующую страницу. Событие без `id` или `title` или с уже встреченным `id` пропускается. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

Публичных методов нет.

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-list-timeline-navigate` | `{ id: string, href: string }` | Человек нажал заголовок-ссылку события. Это просьба: страница с маршрутизатором отменяет событие и переходит сама; без отмены браузер переходит по `href`. Нажатие с клавишей-модификатором или средней кнопкой открывает ссылку в другом месте и ничего не спрашивает. |
| `sf-list-timeline-load-more` | `{ direction: string, after: string }` | Человек нажал «Показать ещё»: `direction` — `after`, `after` — `id` последнего показанного события. Хост ставит `loading`, дописывает следующую страницу в `items` и снимает `has-more`, когда страниц больше нет. |
