# Поле изображения

:badge[sf-input-image]{variant=tonal scheme=primary size=1/2} :badge[1.5.1]{variant=outline scheme=on-surface size=1/2}

Поле изображения принимает одно изображение в форме: логотип, обложку,
картинку в блоке. Оно показывает миниатюру с именем и размером файла, кнопки
«Заменить…» и «Убрать» и принимает файл, перетащенный на поле; загружает файл
приложение. Для нескольких файлов, списка передачи и прогресса берите
[Загрузку файлов](/ru/smart/forms/file-upload/).

## Разметка

Минимальная разметка — тег с `label`, `name` и, если изображение уже есть,
`value`:

```html
<sf-input-image label="Логотип" name="logo" value="/media/logo.svg"></sf-input-image>
```

- `value` — изображение в форме файла `{value, label, mime, size, href}`:
  `value` — код у приложения, `label` — имя файла (оно же `alt` миниатюры),
  `mime` — тип, `size` — байты или готовый текст, `href` — адрес картинки. В
  атрибуте — тот же объект в JSON или просто адрес.
- Выбранный файл уходит с формой под именем `name` через встроенный файловый
  input.
- `accept` ограничивает, что предлагает окно выбора и что принимается
  перетаскиванием; по умолчанию `image/*`.

## Поведение

### Загрузка и события

Когда человек выбрал или перетащил файл, приходит `sf-input-image-attach` с
`file`: приложение загружает его и затем задаёт сохранённое значение через
`setValue()`. «Убрать» отправляет `sf-input-image-detach` с прежним
значением; файлы, которых нет в `accept`, отбрасываются с событием
`sf-input-image-rejected`. Каждое изменение сопровождают `input` и `change` с
`value`, `file`, `source` и `name`.

```js
const logo = document.querySelector('sf-input-image[name="logo"]');
logo.addEventListener('sf-input-image-attach', async (event) => {
  try {
    const stored = await upload(event.detail.file);
    logo.setValue(stored);
  } catch {
    logo.setError({message: 'Не удалось загрузить файл'});
  }
});
```

## Доступность

- Поле — группа, названная `label` (без него — «Изображение»), с пояснением
  или ошибкой в описании.
- «Заменить…», «Убрать» и «Выбрать…» — настоящие кнопки с именами,
  называющими файл: «Заменить изображение «logo.png»».
- Область перетаскивания не получает фокус. После удаления фокус переходит
  на «Выбрать…»; выбор, удаление и отклонённый файл объявляются вежливо.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `name` | строка | пусто | — | Имя, под которым выбранный файл уходит с формой через встроенный файловый input. |
| `label` | строка | пусто | — | Подпись над изображением; называет группу. Без неё группа называется «Изображение» / Image. |
| `hint` | строка | пусто | — | Пояснение под полем; слот `hint` принимает разметку вместо строки. |
| `accept` | строка | `image/*` | — | Что предлагает окно выбора файла и что принимается перетаскиванием: `.ext`, `type/*` или `type/sub` через запятую. |
| `max-size` | число | `0` | — | Наибольший размер файла в байтах; 0 — без предела. Больший файл не принимается, об этом говорится под полем (причина size) — то же имя, что у sf-file-upload. |
| `min-width` | число | `0` | — | Наименьшая ширина картинки в пикселях; 0 — без предела. Картинка читается до того, как её взять, и более узкая сообщается под полем (причина min-width). |
| `min-height` | число | `0` | — | Наименьшая высота картинки в пикселях; 0 — без предела (причина min-height). |
| `size` | строка | `1` | `1/2`, `1`, `2` | Размер поля: 1/2, 1 или 2, как у любого поля формы. |
| `layout` | строка | `row` | `row`, `preview` | Как стоит поле. row: миниатюра, имя, размер и кнопки в одну строку — для форм, настроек и узких панелей. preview: картинка в рамке и под ней та же строка шириной с картинку (не уже, чем нужно имени и кнопкам) — для обложки, аватара, логотипа или фото товара. Кнопки никогда не кладутся поверх картинки. |
| `shape` | строка | `square` | `square`, `circle` | Форма миниатюры и рамки: circle — для человека, square — для вещи. |
| `aspect` | строка | пусто | — | Соотношение сторон рамки просмотра и рамки редактора: «16/9», «1/1», «1.91/1». Пусто — у круга 1/1, иначе собственное соотношение картинки (16/9, пока она не загрузилась). |
| `fit` | строка | `cover` | `cover`, `contain` | cover: картинка заполняет рамку, точка фокуса остаётся в ней (фото, обложка); contain: картинка вписывается целиком (логотип). Картинка никогда не растягивается. |
| `sources` | строка | `device` | — | Откуда может прийти картинка, список через запятую или пробел: device (выбор файла), library (библиотека страницы: поле присылает library, а страница вызывает setValue()), url (адрес, набранный в поле). Один источник — «Выбрать…» / «Заменить…» ведут туда; несколько — «Заменить ▾» открывает их меню. |
| `library-label` | строка | пусто | — | Слова пункта библиотеки в меню, «Из письма»; по умолчанию «Из библиотеки». |
| `edit` | строка | пусто | — | Что человек может править на картинке, список через запятую или пробел: crop (рамка в `aspect`, с увеличением и положением), focus (точка фокуса). «Изменить» открывает редактор в окне поверх страницы (sf-modal; уже md — на весь экран); «Готово» пишет crop {aspect, zoom, x, y} и focus {x, y} в значение, «Отмена», Escape, затемнение и × оставляют его как было, и фокус возвращается на «Изменить». Оригинал никогда не обрезается. |
| `alt` | строка | `none` | `none`, `field`, `required` | Описание картинки внутри поля: field показывает «Описание изображения» и «Декоративная»; required ещё и не даёт отправить форму, пока описание не написано или картинка не отмечена декоративной. Значение несёт alt и decorative. |
| `meta` | строка | пусто | — | Строка под именем; по умолчанию — размеры изображения после загрузки и его размер («450×300 · 2 КБ»). |
| `empty-text` | строка | пусто | — | Слова пустого поля; по умолчанию «Изображение не выбрано» / No image chosen. |
| `required` | да/нет | нет | — | В поле должна быть картинка: без неё форма не отправляется, а пустое поле пишет под собой «Выберите изображение.», когда фокус уходит или форма проверяется. У обязательного поля нет кнопки удаления. |
| `disabled` | да/нет | нет | — | Показывается и не меняется: без заливки, линия и текст выключенного, как у sf-input; кнопки выключены, перетаскивание и вставка отклоняются. |
| `readonly` | да/нет | нет | — | Показывается без кнопок, краем служит линия области, как у sf-input только для чтения; перетаскивание и вставка отклоняются. |
| `invalid` | да/нет | нет | — | Состояние ошибки: край и сообщение окрашены цветом ошибки, у группы aria-invalid. |
| `error-message` | строка | пусто | — | Ошибка, которая видна вместо пояснения, пока поле с ошибкой; слот `error` принимает разметку вместо строки. |
| `aria-label` | строка | пусто | — | Доступное имя группы, когда подпись внутри поля не выводится: форма, которая печатает подпись рядом (рендереры полей Framework), называет поле без второй видимой подписи. |
| `error` | да/нет | нет | — | Состояние ошибки; то же, что invalid. |
| `uploader` | объект | `null` | — | Передача файла страницей, свойство — тот же договор, что у загрузчика sf-file-upload: async-функция (file, {signal, onProgress, value}), отвечающая сохранённым значением ({value, href} или id). С ней поле отправляет каждый взятый файл и показывает передачу на картинке: кольцо с долей, которую сообщает onProgress(done, total), и «Отменить»; при неудаче — сообщение брошенной ошибки под полем и «Повторить». Пока передача идёт, форма не отправляется. Без неё приложение само загружает File из событий и вызывает setValue(). |
| `value` | объект | `null` | — | Картинка в форме файла {value, label, mime, size, href, file?} плюс то, что поле знает о картинке: width, height, alt, decorative, focus {x, y} и crop {aspect, zoom, x, y} — каждое, только если есть. null, когда пусто; атрибут принимает адрес или ту же форму в JSON. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `clear()` | объект | Очищает поле из кода; то же, что setValue(null). Возвращает тег. |
| `choose()` | да/нет | Открывает системный выбор файла, как «Выбрать…» и «Заменить…» с источником «устройство». Возвращает false, если поле выключено или только для чтения. |
| `removeImage()` | да/нет | Убирает картинку, как кнопка удаления: приходят input, change и sf-input-image-detach, фокус переходит на «Выбрать…»; обязательное поле после этого сообщает, что оно пустое. Возвращает, была ли картинка. |
| `takeFile(args: object)` | да/нет | Берёт File, как будто человек его выбрал (источник input, drop, paste или другой, названный приложением): проходят проверки (accept, max-size, min-width, min-height), миниатюра показывает файл по object URL, приходят input, change и sf-input-image-attach; отклонённый файл вместо этого сообщается под полем и в rejected. С min-width или min-height картинка сначала читается, и ответ — обещание результата. |
| `setError(args: object)` | объект | Показывает сообщение об ошибке и состояние ошибки или убирает оба пустым сообщением. Записывает error-message и invalid. Возвращает тег. |
| `setValue(value: object\|string\|null)` | объект | Задаёт изображение из кода — в форме файла или адресом; null очищает поле. Событий не отправляет: значение из кода — не изменение. Возвращает тег. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `{ value: object\|null, file: object\|null, source: "input" \| "drop" \| "paste" \| "url" \| "alt" \| "edit" \| "remove" \| "upload" \| "cancel", name: string }` | Картинку выбрали, перетащили, вставили, взяли по адресу, описали, отредактировали или убрали: один раз на каждое изменение, сделанное человеком, CustomEvent на компоненте со значением, File и именем в форме (source говорит, как именно). С загрузчиком change (source upload) приходит ещё и после завершённой передачи, и тогда значение несёт сохранённый id; отменённая передача присылает source cancel. Собственные change системного поля и внутренних полей наружу не выходят. |
| `input` | `{ value: object\|null, file: object\|null, source: "input" \| "drop" \| "paste" \| "url" \| "alt" \| "edit" \| "remove" \| "upload" \| "cancel", name: string }` | Приходит с каждым изменением, сделанным человеком, перед change и с тем же detail, как обычное поле файла присылает input и change вместе; при вводе описания — на каждую клавишу. |
| `sf-input-image-attach` | `{ files: array, file: object, source: "input" \| "drop" \| "paste", value: object, name: string }` | Файл выбран или перетащен: File для загрузки. Приложение загружает его и задаёт сохранённое значение. |
| `sf-input-image-detach` | `{ value: object, name: string }` | Человек убрал изображение; detail несёт значение, которое было. |
| `sf-input-image-rejected` | `{ files: array, rejected: array, accept: string, source: string }` | Файлы, которые поле не взяло, — у каждого причина и слова под полем: rejected [{file, name, reason, message}], reason — type \| empty \| size \| min-width \| min-height \| unreadable \| count (файлы после первого при перетаскивании). Прежнее имя sf-image-field:reject приходит с тем же detail до 2026-12-01. |
| `sf-input-image-library` | `{ value: object\|null, name: string }` | Человек выбрал «Из библиотеки» (источник library): страница открывает свою библиотеку — «Файлы» Larena, картинки письма — и вызывает setValue() с картинкой. |
