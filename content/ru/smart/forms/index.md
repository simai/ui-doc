# Формы и ввод

Поле формы принимает значение от человека и отправляет его с формой. Выберите поле по тому, что человек вводит или выбирает.

| Что нужно от человека | Что брать |
|:---|:---|
| Строка текста: имя, почта, пароль, адрес сайта | [Текстовое поле](/ru/smart/forms/inputs/) |
| Текст в несколько строк: комментарий, описание | [Многострочное поле](/ru/smart/forms/textarea/) |
| Текст с заголовками, списками и ссылками | [Форматированный текст](/ru/smart/forms/rich-text/) |
| Небольшое число, которое меняют по шагу | [Количество](/ru/smart/forms/quantity/) |
| Число или две границы на шкале с пределами | [Слайдер диапазона](/ru/smart/forms/range-slider/) |
| Один вариант из нескольких видимых | [Радиокнопки](/ru/smart/forms/radio/), с пояснением и иконкой — [Выбор карточками](/ru/smart/forms/input-choice/) |
| Несколько независимых отметок | [Флажок](/ru/smart/forms/checkbox/) |
| Включить или выключить настройку сразу | [Переключатель](/ru/smart/forms/switch/) |
| Человек или объект из длинного списка | [Выбор из поиска](/ru/smart/forms/lookup/) |
| Дата, время или период | [Календарь](/ru/smart/forms/datepicker/) |
| Телефон с кодом страны | [Код страны](/ru/smart/forms/country-code/) |
| Одноразовый код из сообщения | [Код подтверждения](/ru/smart/forms/code-input/) |
| Цвет | [Цвет](/ru/smart/forms/color/) |
| Файлы или одно изображение | [Загрузка файлов](/ru/smart/forms/file-upload/), [Поле изображения](/ru/smart/forms/image-field/) |

## Все компоненты раздела

- [Текстовое поле](/ru/smart/forms/inputs/) — Принимает одну строку — имя, почту, пароль, телефон или адрес — с подписью, подсказкой, ошибкой и маской ввода.
- [Количество](/ru/smart/forms/quantity/) — Даёт набрать число или поменять его кнопками «−» и «+» в заданных границах и по шагу.
- [Многострочное поле](/ru/smart/forms/textarea/) — Принимает текст в несколько строк — комментарий, описание, отзыв — с подписью, подсказкой и ошибкой.
- [Форматированный текст](/ru/smart/forms/rich-text/) — Даёт написать текст с заголовками, списками, ссылками и цитатами; значение — HTML из небольшого разрешённого набора.
- [Выбор из поиска](/ru/smart/forms/lookup/) — Даёт найти и выбрать людей или объекты по имени из поиска, на который отвечает сайт; выбранное видно плашками.
- [Флажок](/ru/smart/forms/checkbox/) — Даёт отметить один или несколько независимых вариантов и отправляет отмеченные значения с формой.
- [Радиокнопки](/ru/smart/forms/radio/) — Даёт выбрать ровно один вариант из видимой группы и отправляет его значение с формой.
- [Выбор карточками](/ru/smart/forms/input-choice/) — Даёт выбрать один вариант или несколько из карточек с названием, пояснением и иконкой.
- [Переключатель](/ru/smart/forms/switch/) — Включает или выключает настройку сразу после нажатия, без отдельного подтверждения.
- [Слайдер контента](/ru/smart/forms/slider/) — Показывает последовательность слайдов со стрелками, точками и миниатюрами.
- [Слайдер диапазона](/ru/smart/forms/range-slider/) — Выбирает одно значение или две границы перетаскиванием ручки по шкале с известными пределами.
- [Календарь](/ru/smart/forms/datepicker/) — Выбирает дату, дату со временем, время суток или период — во всплывающем окне у поля или прямо на странице.
- [Код страны](/ru/smart/forms/country-code/) — Принимает телефон с выбором страны: флаг, код и маска номера; номер уходит с формой.
- [Код подтверждения](/ru/smart/forms/code-input/) — Принимает одноразовый код из сообщения, приложения или письма: ячейки, вставка целиком и автозаполнение.
- [Цвет](/ru/smart/forms/color/) — Выбирает цвет системной палитрой или из цветов продукта и возвращает к унаследованному цвету.
- [Генератор темы](/ru/smart/forms/theme-generator/) — Строит тему SIMAI Framework из одного цвета: восемь тональных палитр, предпросмотр и применение к странице или её участку.
- [Загрузка файлов](/ru/smart/forms/file-upload/) — Даёт выбрать или перетащить файлы и показывает их список, прогресс и ошибки передачи.
- [Поле изображения](/ru/smart/forms/image-field/) — Даёт выбрать одно изображение: миниатюра, имя и размер файла, замена, удаление и перетаскивание.
