# Флажок

`<sf-checkbox>` — флажок для независимого выбора: каждый вариант отмечают или
снимают отдельно от остальных. Для одного варианта из нескольких берите
[Радиокнопки](/ru/smart/forms/radio/), для настройки, которая действует сразу, —
[Переключатель](/ru/smart/forms/switch/).

То же на классах — [Флажок](/ru/components/forms/checkbox/): `<sf-checkbox>`
собирает его разметку из атрибутов.

## Разметка

Флажку нужно название варианта и, для формы, имя и значение:

```html
<sf-checkbox name="terms" value="accepted" label="Принимаю условия"></sf-checkbox>
```

`label` — видимое название варианта. Без видимой подписи, например у флажка
выбора строки в таблице, имя задаёт `aria-label`. Вместо строк `label` и
`description` можно передать разметку в одноимённые слоты.

## Варианты

### Размер

`size` выбирает ступень размерной шкалы: `1/2`, `1` или `2`.

:::example {id="smart-components/checkbox/sizes" label="Размеры флажка"}
:::

### Состав

`description` — пояснение под названием. Название и пояснение стоят внутри
одного `<label>` с флажком, поэтому щелчок по тексту тоже переключает
вариант. `help` выводит рядом с названием значок с указанным именем; он скрыт
от экранного диктора, поэтому то, что важно прочитать, пишите в
`description`.

:::example {id="smart-components/checkbox/composition" label="Название, пояснение и значок"}
:::

### Положение индикатора

`position="end"` ставит флажок после текста, в конце строки; по умолчанию
(`start`) он стоит в начале.

:::example {id="smart-components/checkbox/position" label="Флажок в начале и в конце строки"}
:::

## Состояния

### Отмечен

`checked` отмечает флажок. Атрибуты `checked` и `indeterminate` на элементе
следуют за состоянием флажка.

:::example {id="smart-components/checkbox/state-checked" label="Неотмеченный и отмеченный"}
:::

### Смешанное

`indeterminate` показывает флажок, который обобщает группу, где отмечена
только часть вариантов. Это только вид: значения он не меняет, а щелчок
пользователя снимает смешанное состояние. Итоговое состояние такого флажка
считает приложение — в примере ниже по изменению любого варианта.

:::example {id="smart-components/checkbox/select-all" label="Флажок «Все столбцы» в смешанном состоянии"}
:::

### Недоступен

`disabled` отключает флажок в любом состоянии отметки.

:::example {id="smart-components/checkbox/state-disabled" label="Недоступные флажки"}
:::

### Ошибка

`invalid` показывает недопустимое состояние и ставит `aria-invalid` на
внутренний флажок; `error` — прежнее имя этого атрибута. Текст ошибки
компонент не выводит: разместите его рядом с группой и свяжите с ней через
`aria-describedby`.

:::example {id="smart-components/checkbox/state-error" label="Флажок с ошибкой"}
:::

## Поведение

### Группа вариантов

Связанные флажки объединяйте в `<fieldset>`: общий вопрос пишется в
`<legend>`, а каждый флажок сохраняет своё название. Одинаковое `name` у
флажков группы (`notifications[]` в примере) собирает отмеченные значения в
один список при отправке формы.

### Значение в форме

Внутри `<sf-checkbox>` лежит обычный `<input type="checkbox">` с переданными
`name` и `value`, поэтому отмеченный флажок попадает в `FormData` и отправку
формы без дополнительного кода. Без `value` отмеченный флажок отправляет
`on`, как нативный. Сброс формы возвращает состояние, заданное атрибутом
`checked` в разметке.

### Состояние из кода и событие `change`

Отметка пользователем отправляет нативное событие `change` внутреннего
флажка; оно всплывает через `<sf-checkbox>`, `detail` у него нет. Состояние
читайте из `event.target.checked` или методом `isChecked()`.

`setChecked()`, `setIndeterminate()` и `setDisabled()` меняют состояние из
кода и события `change` не отправляют. Элемент, созданный через
`SF.createAsync`, готов к таким вызовам после вставки на страницу и
`whenRendered()`.

```js
const terms = await SF.createAsync('checkbox', {
  name: 'terms',
  value: 'accepted',
  label: 'Принимаю условия',
  onChange: (event) => submit.toggleAttribute('disabled', !event.target.checked),
});
form.append(terms);
await terms.whenRendered();
terms.setChecked(false);
```

## Доступность

- Каждому флажку нужно доступное имя: видимый `label` или, если подписи нет,
  `aria-label` — например, у флажка выбора строки в таблице. Имя попадает на
  внутренний флажок.
- Каждый флажок — отдельная остановка `Tab`; `Space` отмечает и снимает его.
  Фокус виден на самом флажке.
- Общий вопрос группы задаёт `<legend>`: экранный диктор читает его перед
  первым вариантом.
- Смешанное состояние экранный диктор объявляет как «частично отмечено».

## Справочник

Собран из манифеста компонента выпуска `ui-e7b79c3a9e05` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |
| `size` | строка | `1` | `1/2`, `1`, `2` | Токен размера чекбокса. |
| `label` | строка | пусто | — | — |
| `description` | строка | пусто | — | — |
| `help` | строка | пусто | — | — |
| `position` | строка | `start` | `start`, `end` | Логическое расположение индикатора относительно текста. |
| `disabled` | да/нет | нет | — | — |
| `name` | строка | пусто | — | — |
| `value` | строка | `on` | — | Что отправляет отмеченный флажок; без значения — "on", как у родного флажка (стандарт 1.3.8 §17.1, пункт 2). |
| `invalid` | да/нет | нет | — | Показанное состояние ошибки: вид ошибки и `aria-invalid` на родном поле ввода. |
| `checked` | да/нет | нет | — | — |
| `indeterminate` | да/нет | нет | — | Смешанное визуальное состояние чекбокса, обобщающего связанные варианты. |
| `aria-label` | строка | пусто | — | Доступное имя чекбокса без видимой подписи. |
| `error` | да/нет | нет | — | Прежнее имя `invalid`: псевдоним с датой до 2026-12-01 (aliases.json, стандарт 1.3.8 §17.2). |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `getInputElement()` | объект или пусто | Возвращает внутренний нативный input флажка или null до отрисовки. |
| `isChecked()` | да/нет | Возвращает текущее нативное состояние checked. |
| `setChecked(nextValue?: boolean\|string)` | объект | Устанавливает состояние checked в атрибуте хост-элемента и во внутреннем input через setState(). Возвращает элемент. |
| `setIndeterminate(nextValue?: boolean\|string)` | объект | Устанавливает состояние indeterminate в атрибуте хост-элемента и во внутреннем input через setState(). Возвращает элемент. |
| `setDisabled(nextValue?: boolean\|string)` | объект | Устанавливает состояние disabled в атрибуте хост-элемента и во внутреннем input через setState(). Возвращает элемент. |
| `setBooleanStateAttribute(name: string, value: boolean)` | пусто | Добавляет указанный атрибут хост-элемента как пустой атрибут, когда value истинно, и удаляет его в противном случае. |
| `setState(nextState?: object)` | объект | Применяет checked, indeterminate и disabled и к атрибуту хост-элемента, и к внутреннему input; остальные ключи передаются в базовый setState как атрибуты хост-элемента. Возвращает элемент. |
| `onChange(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик change на хост-элементе. Возвращает элемент. |
| `onFocus(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик focusin на хост-элементе. Возвращает элемент. |
| `onBlur(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик focusout на хост-элементе. Возвращает элемент. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `null` | Изменилось состояние checked; нативное событие всплывает от внутреннего флажка, который является его целью. detail не передаётся. |
