# Флажок

:badge[sf-checkbox]{variant=outline scheme=on-surface size=1/2} :badge[1.6.2]{variant=outline scheme=on-surface size=1/2}

Флажок даёт независимый выбор: каждый вариант отмечают или снимают отдельно от
остальных. Для одного варианта из нескольких берите
[Радиокнопки](/ru/smart/forms/radio/), для настройки, которая действует сразу,
— [Переключатель](/ru/smart/forms/switch/).

То же на классах — [Флажок](/ru/components/forms/checkbox/): `<sf-checkbox>`
собирает его разметку из атрибутов.

## Разметка

Флажку нужно название варианта и, для формы, имя и значение:

```html
<sf-checkbox name="terms" value="accepted" label="Принимаю условия"></sf-checkbox>
```

`label` — видимое название варианта. Без видимой подписи, например у флажка
выбора строки в таблице, имя задаёт `aria-label`. Вместо строк `label` и
`description` можно передать разметку в одноимённые слоты.

## Варианты

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

`size` выбирает ступень размерной шкалы: `1/2`, `1` или `2`.

:::example {id="smart-components/checkbox/sizes" label="Размеры флажка"}
:::

### Состав

`description`, `help` • [справочник](#атрибуты)

`description` — пояснение под названием. Название и пояснение стоят внутри
одного `<label>` с флажком, поэтому щелчок по тексту тоже переключает
вариант. `help` ставит после названия знак «?» с пояснением, которое нужно не всем:
оно открывается по нажатию, а знак называется по подписи («Подробнее: …»).

:::example {id="smart-components/checkbox/composition" label="Название, пояснение и знак «?»"}
:::

### Положение индикатора

`position` • по умолчанию `start` • [справочник](#атрибуты)

`position="end"` ставит флажок после текста, в конце строки; по умолчанию
(`start`) он стоит в начале.

:::example {id="smart-components/checkbox/position" label="Положение индикатора"}
:::

## Состояния

### Отмечен

`checked`, `indeterminate` • [справочник](#атрибуты)

`checked` отмечает флажок. Атрибуты `checked` и `indeterminate` на элементе
следуют за состоянием флажка.

:::example {id="smart-components/checkbox/state-checked" label="Неотмеченный и отмеченный"}
:::

### Смешанное

`controls`, `indeterminate` • [справочник](#атрибуты)

Флажок, который обобщает группу, получает в `controls` id своих флажков
через пробел. Своё состояние он считает сам: отмечен, когда отмечены все,
смешанный, когда только часть, пустой, когда ни одного. Нажатие отмечает
все или снимает все, если все были отмечены, и каждый изменённый флажок
присылает `change`. Кода страницы для этого не нужно.

`indeterminate` — только вид смешанного состояния для флажка без
`controls`: значения он не меняет, а щелчок снимает его.

:::example {id="smart-components/checkbox/select-all" label="Смешанное"}
:::

### Недоступен

`disabled` • [справочник](#атрибуты)

`disabled` отключает флажок в любом состоянии отметки.

:::example {id="smart-components/checkbox/state-disabled" label="Недоступные флажки"}
:::

### Ошибка

`invalid` • [справочник](#атрибуты)

`invalid` показывает недопустимое состояние и ставит `aria-invalid` на
внутренний флажок. Текст ошибки
компонент не выводит: разместите его рядом с группой и свяжите с ней через
`aria-describedby`.

:::example {id="smart-components/checkbox/state-error" label="Флажок с ошибкой"}
:::

## Поведение

### Группа вариантов

Связанные флажки объединяйте в `<fieldset>`: общий вопрос пишется в
`<legend>`, а каждый флажок сохраняет своё название. Одинаковое `name` у
флажков группы (`notifications[]` в примере) собирает отмеченные значения в
один список при отправке формы.

### Значение в форме

Внутри `<sf-checkbox>` лежит обычный `<input type="checkbox">` с переданными
`name` и `value`, поэтому отмеченный флажок попадает в `FormData` и отправку
формы без дополнительного кода. Без `value` отмеченный флажок отправляет
`on`, как нативный. Сброс формы возвращает состояние, заданное атрибутом
`checked` в разметке.

### Состояние из кода и событие

Отметка пользователем отправляет нативное событие `change` внутреннего
флажка; оно всплывает через `<sf-checkbox>`, `detail` у него нет. Состояние
читайте из `event.target.checked` или методом `isChecked()`.

`setChecked()`, `setIndeterminate()` и `setDisabled()` меняют состояние из
кода и события `change` не отправляют. Элемент, созданный через
`SF.createAsync`, готов к таким вызовам после вставки на страницу и
`whenRendered()`.

```js
const terms = await SF.createAsync('checkbox', {
  name: 'terms',
  value: 'accepted',
  label: 'Принимаю условия',
  onChange: (event) => submit.toggleAttribute('disabled', !event.target.checked),
});
form.append(terms);
await terms.whenRendered();
terms.setChecked(false);
```

В примере флажок создан из скрипта: отметка открывает кнопку «Продолжить»
по событию `change`, а снятие отметки из кода события не отправляет, поэтому
кнопку закрывает сама страница.

:::example {id="smart-components/checkbox/from-code" label="Флажок из скрипта" preview=sandbox log="change" log_open=false}
:::

## Доступность

- Каждому флажку нужно доступное имя: видимый `label` или, если подписи нет,
  `aria-label` — например, у флажка выбора строки в таблице. Имя попадает на
  внутренний флажок.
- Каждый флажок — отдельная остановка `Tab`; `Space` отмечает и снимает его.
  Фокус виден на самом флажке.
- Общий вопрос группы задаёт `<legend>`: экранный диктор читает его перед
  первым вариантом.
- Смешанное состояние экранный диктор объявляет как «частично отмечено».

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/2`, `1`, `2` | Размер флажка: чем больше число, тем крупнее. |
| `label` | строка | пусто | — | — |
| `description` | строка | пусто | — | — |
| `help` | строка | пусто | — | Пояснение за кнопкой «?» (sf-help-mark) после текста подписи: через --sf-space-1/4 после последнего слова подписи, на её последней строке, если подпись переносится (и при position end); нажатие на кнопку открывает пояснение и никогда не меняет элемент. В слот help можно положить своё sf-help-mark. |
| `position` | строка | `start` | `start`, `end` | Логическое расположение индикатора относительно текста. |
| `controls` | строка | пусто | — | Родительский флажок (C165 (2)): id флажков, за которые он отвечает, через пробел (как `aria-controls`). Своё состояние он вычисляет по ним — отмечен, когда отмечены все, частично, когда некоторые, не отмечен, когда ни одного, — и следит за их изменениями; нажатие отмечает все или снимает все, если все были отмечены, и каждый изменённый присылает `change`, как при нажатии. Недоступный флажок учитывается в состоянии и не меняется: нажатие отмечает те, что можно изменить, или снимает их, если все они были отмечены. Внутренний `input` получает `aria-controls`. Пусто — обычный флажок. |
| `disabled` | да/нет | нет | — | — |
| `name` | строка | пусто | — | — |
| `value` | строка | `on` | — | Что отправляет отмеченный флажок; без значения — "on", как у родного флажка. |
| `invalid` | да/нет | нет | — | Показанное состояние ошибки: вид ошибки и `aria-invalid` на родном поле ввода. |
| `error-message` | строка | пусто | — | Текст под элементом, пока он в состоянии ошибки, цветом ошибки: что не так, как это говорят все поля семейства (`sf-input`, `sf-input-choice`); он описывает родной элемент управления. Без `invalid` ничего не рисуется. |
| `checked` | да/нет | нет | — | — |
| `indeterminate` | да/нет | нет | — | Смешанное визуальное состояние чекбокса, обобщающего связанные варианты. |
| `aria-label` | строка | пусто | — | Доступное имя чекбокса без видимой подписи. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `getInputElement()` | объект или пусто | Возвращает флажок внутри тега или `null`, пока он не нарисован. |
| `isChecked()` | да/нет | Возвращает, отмечен ли флажок. |
| `setChecked(nextValue?: boolean\|string)` | объект | Отмечает флажок или снимает отметку. Возвращает тег. |
| `setIndeterminate(nextValue?: boolean\|string)` | объект | Ставит или снимает промежуточное состояние «частично отмечен». Возвращает тег. |
| `setDisabled(nextValue?: boolean\|string)` | объект | Делает флажок недоступным или снова доступным. Возвращает тег. |
| `setBooleanStateAttribute(name: string, value: boolean)` | пусто | Добавляет указанный атрибут тега как пустой атрибут, когда value истинно, и удаляет его в противном случае. |
| `setState(nextState?: object)` | объект | Задаёт сразу `checked`, `indeterminate` и `disabled`; другие ключи становятся атрибутами тега. Возвращает тег. |
| `onChange(handler: function, options?: object\|boolean)` | объект | Подписывает на `change` у тега. Возвращает тег. |
| `onFocus(handler: function, options?: object\|boolean)` | объект | Подписывает на `focusin` у тега. Возвращает тег. |
| `onBlur(handler: function, options?: object\|boolean)` | объект | Подписывает на `focusout` у тега. Возвращает тег. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `null` | Флажок отмечен или отметка снята; `detail` нет. |
