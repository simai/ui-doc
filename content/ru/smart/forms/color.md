# Цвет

:badge[sf-input-color]{variant=outline scheme=on-surface size=1/2} :badge[1.19.4]{variant=outline scheme=on-surface size=1/2}

Поле цвета даёт выбрать цвет и показывает его образцом и кодом. По нажатию
открывается окно цвета SIMAI Framework: палитра с названиями цветов, цвета,
которые у продукта уже есть, недавние свои цвета и «Своё» — для любого
другого цвета. Берите поле для цвета метки, серии графика, оформления сайта,
а в шапке сайта и на экране «Оформление» — для фирменного цвета, из которого
строится тема.

## Разметка

Полю нужна подпись, а для формы — имя поля:

```html
<sf-input-color name="accent" label="Цвет акцента" value="blue"></sf-input-color>
```

`label` — подпись над полем, как у других полей формы, она же имя для
экранного диктора. Где подписи над полем нет (строка таблицы, панель), имя
задайте атрибутом `aria-label`. `value` — выбранный цвет: название цвета
палитры (`blue`, `green`) или код своего цвета `#rrggbb`. Короткую запись
`#rgb` поле читает и хранит полной, в нижнем регистре.

## Варианты

### Вид

`appearance` • по умолчанию `bordered` • [справочник](#атрибуты)

Вид задаёт, чем ограничен образец цвета: тонкой рамкой (`bordered`, по
умолчанию), рамкой поля (`outlined`) или ничем (`plain`). Цвет всегда
остаётся внутри рамки, поэтому три вида отличаются только краем.

:::example {id="smart-components/color/appearance" label="Виды образца"}
:::

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

Размер — ступень шкалы полей `1/3`, `1/2`, `1`, `2` или `3`: берите ту же,
что у полей рядом, чтобы цвет встал с ними по одной линии.

:::example {id="smart-components/color/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Палитра и свой цвет

`palette`, `custom` • по умолчанию оба `true` • [справочник](#атрибуты)

Окно открывается на палитре: цвета SIMAI Framework с названиями. Цвет палитры хранится названием (`blue`), одинаковым на любом
языке, а оттенок подбирает тема: в тёмной теме тот же «Синий» светлее.
Поэтому метка, раскрашенная цветом палитры, читается в обеих темах.

«Своё» открывает выбор любого цвета: поле насыщенности и яркости, полосу
оттенка, пипетку (где её даёт браузер) и строку кода — вид кода (Hex, RGB,
HSL или HSB) и сам код. Свой цвет попадает в «Недавние свои цвета».

`custom="false"` оставляет только палитру — так выбирают цвет метки или
серии графика, где свой цвет не нужен. `palette="false"` убирает палитру,
и окно сразу открывает «Своё».

:::example {id="smart-components/color/palette" label="Только палитра и палитра со своим цветом"}
:::

### Цвета продукта

`swatches` • [справочник](#атрибуты)

Первой строкой в окне встают цвета, которые у продукта уже есть: человек
выбирает готовый цвет, а не подбирает его на глаз. Цвета перечисляются через
запятую, каждый как `#hex`, `#hex|Название` или название цвета палитры:
`#3375d9|Синий, green|Зелёный`. Название может состоять из нескольких слов.

В примере каждая серия графика получает цвет из своего поля: выберите цвет
продукта или свой, и столбцы этой серии перекрасятся.

:::example {id="smart-components/color/swatches" label="Цвета серий графика" preview=sandbox}
:::

### Прозрачность

`alpha` • по умолчанию `false` • [справочник](#атрибуты)

С `alpha` у своего цвета появляются полоса прозрачности и поле
непрозрачности в процентах, а значение может быть `#rrggbbaa`. Образец
полупрозрачного цвета делится пополам: слева тот же цвет без прозрачности,
справа — цвет как есть поверх шахматки. Так и бледный цвет показывает свой
оттенок.

Без `alpha` полупрозрачный код теряет прозрачность и сохраняет цвет.

:::example {id="smart-components/color/alpha" label="Цвет с прозрачностью"}
:::

### Цвет темы

`variant` • по умолчанию `field` • [справочник](#атрибуты)

`variant="theme"` — только кружок текущего цвета, как в шапке сайта. Он
открывает то же окно, без текста. Пока цвет ведут, тема пересобирается из
него, и сайт сразу показывает человеку свой цвет. Выбор закрепляется, когда
цвет выбран.

С `clearable` рядом с кружком встаёт вторая кнопка — «Вернуть исходный
цвет темы»: тема возвращается к тому цвету, который был у страницы до поля, — цвету SIMAI
Framework, если сайт не задал свой.

:::example {id="smart-components/color/theme" label="Цвет темы в шапке сайта"}
:::

### Фирменный цвет

`variant`, `target` • [справочник](#атрибуты)

`variant="brand"` — поле для экрана настроек «Оформление». Под ним строками
идёт то, что человеку надо знать о цвете: текст на кнопке плохо читается,
цвет похож на цвет ошибки или почти серый, кнопки получат более светлый или
тёмный оттенок. Тема пересобирается так же, как у кружка.

Фирменный цвет двигает четыре палитры темы и заливку шапки и обложки
(`--sf-brand`, `--sf-on-brand`); цвета статусов — ошибка, предупреждение,
успех, сведения — за ним не идут. `target` — CSS-селектор участка, на
который кладётся тема, например превью на экране настроек, чтобы сама
админка сохранила свои цвета. Без `target` тема ложится на всю страницу.
Значение `theme` и `brand` — всегда код, без прозрачности.

Как строятся палитры из одного цвета — в главе
[Палитры](/ru/guide/colour/palettes/#как-строятся-палитры-из-одного-цвета).

## Состояния

### Унаследованный цвет

`value`, `inherited-value`, `clearable` • [справочник](#атрибуты)

Пока ничего не выбрано, действует цвет, который пришёл сверху — от темы или
от родительской настройки; его задаёт `inherited-value`, а `value` остаётся
пустым. Унаследованный цвет поле показывает с подписью «наследуется», а не
как значение: «не задано» и «задан тот же цвет» различаются, и при смене
темы следует за ней только первое.

С `clearable` в поле, рядом с выбранным цветом, стоит значок возврата
«Вернуть унаследованный», а у фирменного цвета (`variant="brand"`) —
«Вернуть цвет SIMAI». Это такой же значок внутри поля, как очистка и «глаз»
у текстовых полей: без подложки, в покое цветом пояснения, при наведении
цветом текста; кольцо фокуса с клавиатуры — вокруг значка. Кнопка возврата
у кружка темы (`variant="theme"`) стоит вне поля и остаётся кнопкой с
подложкой. Перед возвратом приходит отменяемое событие
`sf-field-reset`: `preventDefault()` сохраняет выбранный цвет. Из кода то же
делает `clear()`.

:::example {id="smart-components/color/state-inherited" label="Унаследованный цвет"}
:::

### Ошибка

`invalid`, `error-message`, `hint` • [справочник](#атрибуты)

`hint` — пояснение под полем. С `invalid` рамка и линия под полем
окрашиваются цветом ошибки, а вместо пояснения встаёт `error-message`.

:::example {id="smart-components/color/state-invalid" label="Пояснение и ошибка"}
:::

### Недоступно

`disabled` • [справочник](#атрибуты)

Недоступное поле показывает цвет, но окно не открывается.

## Поведение

### Окно цвета

Окно открывают нажатием на образец или клавишами `Enter` и `Space`, когда
поле в фокусе. Стрелки, `Home` и `End` переходят по цветам, `Enter` и
`Space` выбирают цвет, `Escape` закрывает окно без выбора. Выбор цвета
палитры или цвета продукта закрывает окно сразу. Попробуйте в примере
раздела [Палитра и свой цвет](#палитра-и-свой-цвет).

Слова на образце (`choose-label`) и на кнопке возврата (`clear-label`)
следуют языку страницы; задайте их явно, если нужны другие.

### Значение и события

Пока человек ведёт цвет — тянет по полю оттенка или полосе, — элемент на
каждом шаге отправляет всплывающее событие `input`. Когда цвет закреплён —
выбран цвет палитры или продукта, отпущена полоса, оставлено поле кода или
нажат `Enter`, нажат возврат к унаследованному, — элемент один раз
отправляет `change`. У обоих событий одинаковый `event.detail`:

| Поле | Содержимое |
|:---|:---|
| `value` | название цвета палитры или код; пустая строка — снова действует унаследованный |
| `name` | значение атрибута `name` |
| `theme`, `variables`, `css`, `checks` | у `theme` и `brand` с цветом: тема, её переменные, правило CSS под `:root` и строки проверки цвета |

Пример раздела [Фирменный цвет](#фирменный-цвет) пишет эти события в журнал.
`setValue(value)` задаёт цвет так же, как человек, и отправляет `change`,
если цвет изменился; `clear()` — то же, что `setValue('')`.

### Значение в форме

С атрибутом `name` элемент кладёт в форму скрытое поле с этим именем. Его
значение — выбранный цвет, а пока действует унаследованный — пустая строка,
поэтому форма передаёт «не задано» без дополнительного кода. Попробуйте в
примере в начале страницы.

```js
const accent = document.querySelector('sf-input-color[name="accent"]');
accent.addEventListener('change', (event) => {
  saveTheme({accent: event.detail.value || null});
});
```

### Тема в коде

Фирменный цвет удобно сохранить один раз и больше не держать поле на
странице: `css` в `detail` события `change` — готовое правило темы. Сохраните
его в CSS сайта (по соглашению — в `@layer project`), и тема действует на
каждой странице.

Тот же расчёт доступен в коде: `SF.ThemePalette` приходит на страницу вместе
с полем цвета вида `theme` или `brand`.

```js
const theme = SF.ThemePalette.themeFromColor('#2e7d32');
const css = SF.ThemePalette.themeToCss(theme, ':root');
```

| Функция | Что делает |
|:---|:---|
| `themeFromColor(color, options)` | тема из цвета `#rgb` или `#rrggbb` |
| `themeFromHct({hue, chroma}, options)` | тема из тона и насыщенности |
| `colorToHct(color)` | как цвет читается: `{hex, hue, chroma, tone}` |
| `themeVariables(theme)` | переменные темы `{имя: значение}`: тоны и полупрозрачные ступени |
| `themeToCss(theme, selector)` | правило CSS с теми же переменными под селектором, по умолчанию `:root` |
| `applyTheme(theme, target)` | пишет переменные во встроенный стиль `target` и возвращает функцию, которая их снимает |

Сервер или сборка проекта вызывают те же функции из исходников SIMAI
Framework: файл `src/core/js/theme-palette.js` открытого репозитория
[`simai/ui-source`](https://github.com/simai/ui-source). Модель HCT — из
пакета Google `material-color-utilities` (лицензия Apache-2.0).

## Доступность

- Поле — группа; её имя — `label`, а без видимой подписи — `aria-label`.
- Образец — кнопка: `Tab` переводит на него фокус, `Enter` или `Space`
  открывают окно, `Escape` закрывает его.
- Значок возврата в поле — следующая остановка `Tab` после значения; его
  имя и подсказка — «Вернуть унаследованный» или, у фирменного цвета,
  «Вернуть цвет SIMAI»; `clear-label` задаёт свои слова.
- В окне цвета — кнопки с названиями: «Синий», «Свой цвет #1f6feb»;
  выбранный цвет отмечен. Поле насыщенности, полосы оттенка и прозрачности
  называют своё значение словами: «оттенок 210°», «непрозрачность 50 %».
- Строки проверки у `brand` — обычный текст под полем, их читает экранный
  диктор вместе с полем.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Ступень размера поля, как у sf-input (1/3, 1/2, 1, 2, 3), чтобы цвет рядом с текстовым полем стоял с ним вровень. |
| `appearance` | строка | `bordered` | `bordered`, `outlined`, `plain` | Граница образца в поле: bordered (тонкая линия outline-variant), outlined (более заметная рамка поля) или plain (без границы). Цвет остаётся внутри границы, поэтому три вида различаются. |
| `variant` | строка | `field` | `field`, `theme`, `brand` | Что это за элемент. field — поле лестницы элементов (образец, значение и шеврон), которое открывает собственное окно цвета Framework. theme — только кружок текущего цвета, как в шапке сайта; открывает то же окно обычного размера, без текста и строки темы. brand — поле для экрана настроек («Оформление»), под ним строками то, что человеку надо знать о цвете (themeChecks ядра). theme и brand — цвет бренда: пока цвет двигается, они пересобирают из него тему (SF.ThemePalette: четыре динамические палитры, никогда не статус, и заливку бренда --sf-brand, --sf-on-brand шапки и обложки) на target и закрепляют её при выборе цвета. Их значение всегда код и без прозрачности. |
| `target` | строка | пусто | — | Вариант theme или brand: CSS-селектор элемента, на который ставится тема переменными в style (просмотр на экране настроек, чтобы админка сохраняла свои цвета); пусто — корень документа. Селектор, который ничего не находит, никуда тему не ставит. |
| `swatches` | строка | пусто | — | Цвета, которые уже есть у продукта, через запятую: каждый #hex, #hex\|Имя или имя из палитры (blue\|Имя); в имени могут быть пробелы. Часть без имени может перечислять несколько цветов через пробел. Они идут первой строкой палитры в окне, чтобы человек выбрал цвет бренда, а не подбирал код на глаз. |
| `palette` | да/нет | да | — | Показывает ли вкладка палитры в окне шестнадцать оттенков статической палитры. Оттенок хранится именем (blue), одинаковым на всех языках; поле показывает переведённое слово, а тон выбирает тема (50 в светлой, 70 в тёмной). palette="false" — только образцы продукта или одно «Своё». |
| `custom` | да/нет | да | — | Предлагает ли окно «Своё», свой цвет: область оттенков, пипетку, где она есть у браузера, полосу тона и нижнюю строку «код \| Применить». `custom="false"` оставляет только палитру (метки задач, серии графиков). Без палитры «Своё» предлагается всегда. |
| `alpha` | да/нет | нет | — | Может ли свой цвет быть полупрозрачным: рисуются полоса прозрачности и поле %, значение может быть #rrggbbaa. Без этого полупрозрачный код сохраняет цвет и теряет прозрачность, а полупрозрачные недавние цвета не показываются. |
| `clearable` | да/нет | нет | — | Можно ли вернуть выбранный цвет к унаследованному. С вариантом `theme`: вторая кнопка возвращает тему к тому, что было на странице до изменения (цвет SIMAI Framework, если страница не задала свой). |
| `disabled` | да/нет | нет | — | — |
| `readonly` | да/нет | нет | — | Цвет можно прочитать, но нельзя изменить, как `readonly` у sf-input: образец и имя или код цветом текста, рамка — линия области (`outline-variant`), без шеврона, окна и сброса; поле не своя остановка Tab, экранный диктор читает «имя: значение» вместе с полем. Отправляется с формой. Так цвет рисует просмотр карточки записи (`module.smart-field-renderers`); `disabled` остаётся полем, которым человек сейчас не может пользоваться. |
| `name` | строка | пусто | — | Имя в форме. Под ним скрытый input передаёт значение; оно пустое, пока действует унаследованный цвет. |
| `label` | строка | пусто | — | Подпись поля над строкой, как у `sf-input`; она же имя поля выбора цвета. Для имени без видимой подписи пишите `aria-label`. |
| `hint` | строка | пусто | — | Подсказка под полем, как у sf-input: шрифт подписи, на ступень меньше текста поля. |
| `help` | строка | пусто | — | Пояснение за «?» (sf-help-mark, вид C133) после текста подписи (C153 (8)), как `help` у sf-input: ступенью ниже значения, как подпись; строка подписи сохраняет высоту. Знак называется по теме («Подробнее: <подпись>»). Пусто или без подписи — знака нет. |
| `invalid` | да/нет | нет | — | Состояние ошибки: край рамки и линия под полем берут цвет ошибки. |
| `error-message` | строка | пусто | — | Ошибка под полем вместо подсказки, пока поле с ошибкой. |
| `choose-label` | строка | — | — | Слова на образце цвета. Без атрибута компонент берёт текст на языке страницы (по-английски — «Choose a colour»). |
| `clear-label` | строка | — | — | Слова на элементе, который возвращает унаследованный цвет. Без настройки — на языке страницы; с `variant` `theme` по умолчанию слова темы, с `variant` `brand` — слова бренда («Вернуть цвет SIMAI»). |
| `value` | строка | пусто | — | Цвет: имя из палитры (red, orange, amber, yellow, lime, green, teal, cyan, sky, blue, indigo, violet, purple, pink, brown, gray), одинаковое на всех языках, или код своего цвета #rrggbb (или #rrggbbaa с прозрачностью; #rgb и #rgba читаются и хранятся полной записью строчными). Пусто — ничего не выбрано, действует унаследованный цвет. Варианты theme и brand хранят код. |
| `inherited-value` | строка | пусто | — | Цвет, который действует, пока ничего не выбрано. Показан как унаследованный, а не как выбранный: так «не задано» и «задан тот же цвет» не путаются, и при смене темы цвет меняется вместе с ней. |
| `inherited-text` | строка | пусто | — | Текст, который выводится вместо значения, пока ничего не выбрано. Если не задан, используется язык страницы. |
| `reset-label` | строка | пусто | — | Доступное имя кнопки, которая возвращает к наследуемому цвету; `clear-label` тоже его задаёт. Если не задано — на языке страницы («Сбросить к наследуемому», «Reset to inherited»). |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Шаблон, которым рисуется элемент. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `clear()` | да/нет | Возвращает унаследованный цвет; то же, что setValue(""). Возвращает, изменилось ли значение. |
| `setValue(value: string)` | да/нет | Устанавливает и фиксирует цвет так же, как это делает пользователь: нормализует его, отражает в value и отправляет input, а затем change, если цвет отличается от зафиксированного. Возвращает, изменилось ли значение. |
| `resetToInherited()` | да/нет | Возвращает поле к унаследованному значению, как кнопка сброса: отправляет отменяемое `sf-field-reset`, очищает своё значение и ставит фокус в поле. Возвращает `false`, если сбрасывать нечего, поле недоступно или только для чтения, или событие отменили. |
| `openPicker(options?: object)` | да/нет | Открывает окно цвета на той вкладке, откуда взято значение, или на {view: 'palette' \| 'own'}. {anchor} ставит окно у элемента страницы и при закрытии возвращает фокус ему (например, строке меню настроек), а не полю. Возвращает, открыто ли окно (false, пока поле выключено). |
| `closePicker(options?: object)` | да/нет | Закрывает окно цвета и возвращает фокус на кнопку, если не задано {restoreFocus: false}. Возвращает true. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `{ value: string, name: string, theme: object, variables: object, css: string, checks: array }` | Цвет выбран окончательно: один раз при выборе образца, при отпускании после перетаскивания по полю оттенков или полосе, при уходе из поля кода или Enter, при остановке клавиши на полосе и при очистке — не на каждом шаге перетаскивания. Несёт значение и имя в форме; пустое значение значит, что снова действует унаследованный цвет. При variant theme или brand и заданном значении несёт ещё тему, её переменные (четыре палитры и заливку бренда), её CSS как правило :root и её проверки — те же имена, что у событий sf-theme-generator. |
| `input` | `{ value: string, name: string, theme: object, variables: object, css: string, checks: array }` | Цвет сдвинулся: на каждом шаге перетаскивания по полю оттенков или полосе, на каждой клавише в поле кода, которая даёт цвет, и перед каждым change. Несёт значение и имя в форме. При variant theme или brand — тему, переменные, css и проверки, как change. |
| `sf-field-reset` | `{ tag: string, value: string, inheritedValue: string, name: string }` | Человек нажал «сбросить к наследуемому». Это событие общее для всех таких полей: форма слышит их сразу и различает по `detail.tag`. Приходит до очистки; `preventDefault()` сохраняет значение. Иначе поле очищается, присылает обычный `change`, снова показывает наследуемое значение и получает фокус. |
