# Цвет

:badge[sf-input-color]{variant=tonal scheme=primary size=1/2} :badge[1.6.0]{variant=outline scheme=on-surface size=1/2}

Поле цвета даёт выбрать цвет: образец открывает системную палитру, рядом стоят
цвета, которые у продукта уже есть, а кнопка возврата снимает выбор, и снова
действует унаследованный цвет. Берите его для цвета темы, внешнего вида сайта,
метки или серии графика.

## Разметка

Полю нужна подпись, а для формы — имя поля:

```html
<sf-input-color name="brand" label="Основной цвет" value="#005bbe"></sf-input-color>
```

`label` — подпись над полем, как у других полей формы, она же имя для
экранного диктора. Где подписи над полем нет (строка таблицы, панель), имя
задайте атрибутом `aria-label`. `value` — выбранный цвет в виде `#rgb`,
`#rrggbb` или `#rrggbbaa`; другие строки контрол не принимает и считает
значение пустым.

## Варианты

### Вид

`appearance` • по умолчанию `bordered` • [справочник](#атрибуты)

Вид задаёт, чем ограничен образец цвета: рамкой поля (`bordered`, по
умолчанию), тонкой обводкой (`outlined`) или ничем (`plain`).

:::example {id="smart-components/color/appearance" label="Виды образца"}
:::

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

Размер — ступень шкалы `1/2`, `1` или `2`: берите ту же, что у полей
рядом, чтобы цвет встал с ними по одной линии.

:::example {id="smart-components/color/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Цвета продукта

`swatches` • [справочник](#атрибуты)

Рядом с образцом встают кнопки цветов, которые у продукта уже есть: человек
выбирает готовый цвет, а не подбирает его на глаз. Цвета перечисляются через
запятую, каждый как `#hex` или `#hex|Название`; название может состоять из
нескольких слов: `#3375d9|Синий, #198a27|Зелёный`. Цвета без названий можно
разделять и пробелом. Берите цвета из [палитры](/ru/guide/colour/palettes/)
SIMAI Framework — тогда они сочетаются с остальным экраном.

В примере каждая серия графика получает цвет из своего поля: нажмите цвет
продукта или выберите свой, и столбцы этой серии перекрасятся.

:::example {id="smart-components/color/swatches" label="Цвета серий графика" preview=sandbox}
:::

### Цвет темы всей страницы

`variant` • по умолчанию `field` • [справочник](#атрибуты)

Вид `theme` — одна кнопка со значком палитры для шапки сайта: она
открывает системную палитру и, пока цвет ведут, пересобирает тему страницы из
этого цвета — так сайт показывает человеку свой цвет сразу, а не после
перезагрузки. Выбор закрепляется, когда палитра закрыта.

С `clearable` рядом встаёт вторая кнопка: она возвращает тему к тому цвету,
который был у страницы до вмешательства контрола — цвету SIMAI Framework,
если сайт не задал свой.

Имя кнопки берётся из `label`, а если его нет — из языка страницы («Цвет
темы»). Этот вид — для шапки сайта и настроек оформления; цвет, который
является значением чего-то (метки, серии графика), оставляйте виду `field`
(по умолчанию).

:::example {id="smart-components/color/theme" label="Цвет темы в шапке сайта"}
:::

## Состояния

### Унаследованный цвет

`value`, `inherited-value`, `clearable` • [справочник](#атрибуты)

Пока ничего не выбрано, действует цвет, который пришёл сверху — от темы или
от родительской настройки; его задаёт `inherited-value`, а `value` остаётся
пустым. Унаследованный цвет контрол показывает как унаследованный, с подписью
«наследуется», а не как значение: «не задано» и «задан тот же цвет»
различаются, и при смене темы следует за ней только первое.

С `clearable` рядом с выбранным цветом стоит кнопка, которая возвращает
контрол к унаследованному цвету. Перед возвратом приходит отменяемое событие
`sf-field-reset`: `preventDefault()` сохраняет выбранный цвет. Из кода то же
делает `resetToInherited()`.

:::example {id="smart-components/color/state-inherited" label="Унаследованный цвет"}
:::

### Недоступен

`disabled` • [справочник](#атрибуты)

Недоступный контрол показывает цвет, но выбрать другой нельзя.

## Поведение

### Подписи управления

Слова на образце (`choose-label`), на кнопке возврата (`clear-label`) и
вместо значения, пока цвет наследуется (`inherited-text`), следуют языку
страницы; задайте их явно, если нужны другие слова.

### Значение и события

Пока пользователь ведёт цвет в палитре, элемент на каждом шаге отправляет
всплывающее событие `input`. Когда цвет зафиксирован — палитра закрыта, нажат
цвет продукта или возврат к унаследованному, — элемент один раз отправляет
`change`. У обоих событий одинаковый `event.detail`:

| Поле | Содержимое |
|:---|:---|
| `value` | выбранный цвет в нижнем регистре; пустая строка — снова действует унаследованный |
| `name` | значение атрибута `name` |

События внутреннего поля палитры за пределы элемента не выходят.

`setValue(value)` задаёт цвет так же, как пользователь, и отправляет `change`,
если цвет изменился; `clear()` — то же, что `setValue('')`. Оба возвращают
`true`, если значение изменилось.

### Значение в форме

С атрибутом `name` элемент кладёт в форму скрытое поле с этим именем. Его
значение — выбранный цвет, а пока действует унаследованный — пустая строка,
поэтому форма передаёт «не задано» без дополнительного кода.

```js
const accent = document.querySelector('sf-input-color[name="accent"]');
accent.addEventListener('change', (event) => {
  saveTheme({accent: event.detail.value || null});
});
accent.clear();
```

## Доступность

- `label` — видимая подпись над полем и имя образца для экранного диктора;
  без видимой подписи имя задаёт `aria-label`.
- Образец — нативное поле выбора цвета: `Tab` переводит на него фокус, `Enter`
  или `Space` открывают системную палитру.
- Цвета продукта — отдельные кнопки в общей группе. Название цвета служит
  доступным именем кнопки, `aria-pressed` отмечает выбранный цвет.
- Кнопка возврата к унаследованному цвету — следующая остановка `Tab`; её имя
  задаёт `clear-label`.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/2`, `1`, `2` | Ступень шкалы размеров, чтобы цвет рядом с текстовым полем выравнивался с ним. |
| `appearance` | строка | `bordered` | `bordered`, `outlined`, `plain` | Как ограничен образец цвета. |
| `variant` | строка | `field` | `field`, `theme` | Что это за контрол. `field` — образец, код и цвета продукта: цвет как значение чего-то. `theme` — одна основная кнопка со значком палитры: открывает палитру браузера, пересобирает тему страницы из цвета, пока его ведут (`SF.ThemePalette` на `<html>`), и закрепляет его, когда палитра закрыта. |
| `swatches` | строка | пусто | — | Цвета, которые уже есть у продукта, через запятую, каждый в виде #hex или #hex\|Name; имя может содержать пробелы. Фрагмент без имени может перечислять несколько цветов через пробел. Пользователь выбирает фирменный цвет, а не подбирает hex на глаз. |
| `clearable` | да/нет | нет | — | Можно ли вернуть выбранный цвет к унаследованному. С вариантом `theme`: вторая кнопка возвращает тему к тому, что было на странице до изменения (цвет SIMAI Framework, если страница не задала свой). |
| `disabled` | да/нет | нет | — | — |
| `name` | строка | пусто | — | Имя в форме. Под ним скрытый input передаёт значение; оно пустое, пока действует унаследованный цвет. |
| `label` | строка | пусто | — | Подпись поля над строкой, как у `sf-input`; она же имя поля выбора цвета. Для имени без видимой подписи пишите `aria-label`. |
| `choose-label` | строка | — | — | Слова на образце цвета. Без атрибута компонент берёт текст на языке страницы (по-английски — «Choose a colour»). |
| `clear-label` | строка | — | — | Подпись кнопки, которая возвращает унаследованный цвет. Пусто — на языке страницы; при `variant="theme"` — «Вернуть исходный цвет темы». |
| `value` | строка | пусто | — | Цвет в формате #rgb, #rrggbb или #rrggbbaa. Пустое значение означает, что ничего не выбрано и действует унаследованный цвет. |
| `inherited-value` | строка | пусто | — | Цвет, который действует, пока ничего не выбрано. Показан как унаследованный, а не как выбранный: так «не задано» и «задан тот же цвет» не путаются, и при смене темы цвет меняется вместе с ней. |
| `inherited-text` | строка | пусто | — | Текст, который выводится вместо значения, пока ничего не выбрано. Если не задан, используется язык страницы. |
| `reset-label` | строка | пусто | — | Доступное имя кнопки, которая возвращает к наследуемому цвету; `clear-label` тоже его задаёт. Если не задано — на языке страницы («Сбросить к наследуемому», «Reset to inherited»). |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Шаблон, которым рисуется элемент. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `clear()` | да/нет | Возвращает унаследованный цвет; то же, что setValue(""). Возвращает, изменилось ли значение. |
| `setValue(value: string)` | да/нет | Устанавливает и фиксирует цвет так же, как это делает пользователь: нормализует его, отражает в value и отправляет input, а затем change, если цвет отличается от зафиксированного. Возвращает, изменилось ли значение. |
| `resetToInherited()` | да/нет | Возвращает поле к унаследованному значению, как кнопка сброса: отправляет отменяемое `sf-field-reset`, очищает своё значение и ставит фокус в поле. Возвращает `false`, если сбрасывать нечего, поле недоступно или только для чтения, или событие отменили. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `{ value: string, name: string }` | Цвет зафиксирован: один раз, когда закрывается палитра платформы или нажат образец либо очистка, а не на каждом шаге перетаскивания. Передаёт значение и имя в форме; пустое значение означает, что снова действует унаследованный цвет. Собственное событие change палитры не выходит за пределы тега. |
| `input` | `{ value: string, name: string }` | Цвет изменился — на каждом шаге перетаскивания в палитре платформы и перед каждым change. Передаёт значение и имя в форме. |
| `sf-field-reset` | `{ tag: string, value: string, inheritedValue: string, name: string }` | Человек нажал «сбросить к наследуемому». Это событие общее для всех таких полей: форма слышит их сразу и различает по `detail.tag`. Приходит до очистки; `preventDefault()` сохраняет значение. Иначе поле очищается, присылает обычный `change`, снова показывает наследуемое значение и получает фокус. |
