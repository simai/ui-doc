# Количество

:badge[sf-input-quantity]{variant=tonal scheme=primary size=1/2} :badge[1.4.0]{variant=outline scheme=on-surface size=1/2}

Количество — поле для небольшого числа, которое удобно менять по шагу:
товаров в корзине, гостей, записей на странице. Число можно набрать или
поменять кнопками «−» и «+»; за границы оно не выходит.

То же на классах — [Количество](/ru/components/forms/quantity/): для
статической разметки без JavaScript.

## Пример

Поменяйте количество в корзине: сумма строки и итог пересчитаются. У ручки
верхняя граница — остаток на складе, «+» на ней недоступна. Журнал под
примером показывает события.

:::example {id="smart-components/quantity/overview" label="Корзина" preview=sandbox log_console=true log_open=false}
:::

Полю нужны подпись, имя для формы и границы:

```html
<sf-input-quantity label="Гостей" name="guests" value="2" min="1" max="8"></sf-input-quantity>
```

## Когда брать

- **Небольшое целое число, которое меняют по шагу**: количество товара,
  гостей, мест, записей на странице.
- **Число с известными границами**: от 1 до остатка на складе, от 5 до 100.

## Когда не брать

- **Сумма денег, длина, вес покупателя** — число печатают целиком, кнопки
  только мешают: [Текстовое поле](/ru/smart/forms/inputs/#тип-значения) с
  `input-type="number"`.
- **Значение на шкале, которое важнее видеть, чем набрать**: громкость,
  диапазон цен — [Слайдер диапазона](/ru/smart/forms/range-slider/).
- **Выбор из нескольких известных значений** —
  [Радиокнопки](/ru/smart/forms/radio/).

## Частые задачи

### Границы и шаг

`min`, `max`, `step`, `page-step` • по умолчанию `step="1"` • [справочник](#атрибуты)

Границы не дают выйти за допустимое: введённое число за границей
подтягивается к ней. Шаг — на сколько меняют значение «−», «+» и стрелки,
`page-step` — клавиши `PageUp` и `PageDown` (по умолчанию десять шагов).

:::example {id="smart-components/quantity/bounds" label="Шаг и год"}
:::

`grouping="false"` пишет цифры подряд, без разделителя тысяч, — для года
или кода, как во втором поле.

### Дробное число

`step`, `precision` • [справочник](#атрибуты)

Число знаков после запятой берётся из шага: у `0.25` их два. `precision`
задаёт его явно. Без знаков после запятой десятичный разделитель ввести
нельзя.

:::example {id="smart-components/quantity/decimals" label="Вес и масштаб"}
:::

`value` пишется с точкой (`2.5`); в поле число показано по правилам языка
страницы — на русской странице с запятой и разделителем тысяч. Форма получает
значение с точкой и без разделителей, что бы ни было видно в поле.

### Наследуемое значение

`inherited-value`, `inherited-text`, `reset-label` • [справочник](#атрибуты)

Наследуемое значение действует, пока у поля нет своего, — например,
значение родительского раздела. Оно видно в пустом поле цветом подсказки с
меткой «наследуется», но не уходит с формой. Поставьте своё число и нажмите
кнопку сброса — поле вернётся к наследуемому.

:::example {id="smart-components/quantity/inherited" label="Записей на странице"}
:::

## Внешний вид

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

Размер ставит поле в одну строку с кнопками и другими полями: поле каждого
размера одной высоты с кнопкой того же размера.

:::example {id="smart-components/quantity/sizes" label="Размеры"}
:::

Ширину поля задаёт страница: в примерах на этой странице она по числу, а не
на всю колонку.

## Состояния

### На границе

`min`, `max` • [справочник](#атрибуты)

На границе кнопка в её сторону недоступна: дальше идти некуда.

:::example {id="smart-components/quantity/state-bound" label="На границах"}
:::

### Только чтение

`readonly` • [справочник](#атрибуты)

Значение видно и уходит с формой, но кнопки и клавиши его не меняют.

:::example {id="smart-components/quantity/state-readonly" label="Только чтение"}
:::

### Недоступно

`disabled` • [справочник](#атрибуты)

Значение видно, но не меняется и не уходит с формой.

:::example {id="smart-components/quantity/state-disabled" label="Недоступное поле"}
:::

### Ошибка

`invalid`, `error-message` • [справочник](#атрибуты)

Ошибка показывает, что число не подходит, хотя оно в границах поля: например,
на складе меньше, чем просят. Сообщение встаёт на место пояснения, поле
получает `aria-invalid`.

## Работа из кода

### Значение и события

`value` • [справочник](#события)

Свойство `value` возвращает число или `null`.

| Событие | Когда приходит |
|:---|:---|
| `input` | значение сдвинулось: при вводе — когда текст читается как другое число, на кнопке или клавише — на каждом шаге |
| `change` | значение сохранено: после ввода (по `Enter` или уходу из поля), один раз на всё удержание кнопки или на нажатие клавиши |
| `sf-field-reset` | человек нажал сброс к наследуемому значению |

В `detail` событий `input` и `change` — `value`, `text`, `name` и `source`:
откуда пришло изменение. События видны в журнале под [примером](#пример).

```js
const guests = document.querySelector('sf-input-quantity[name="guests"]');
guests.addEventListener('change', (event) => {
  updateTotal(event.detail.value);
});
```

`setValue()`, `clear()`, `stepUp()` и `stepDown()` меняют число из кода без
событий; `setError()` показывает или снимает ошибку.

## Доступность

- Поле — `spinbutton` с `aria-valuenow`, `aria-valuemin`, `aria-valuemax` и
  `aria-valuetext` в формате языка страницы; его называет `label` или
  `aria-label`. В корзине из примера подписи нет, поэтому каждое поле
  называет товар через `aria-label`.
- `↑` и `↓` меняют значение на шаг, `PageUp` и `PageDown` — на десять
  шагов, `Home` и `End` переходят к границам, `Enter` сохраняет ввод, `Escape`
  отменяет его.
- «−» и «+» — настоящие кнопки с именами «Уменьшить значение» и «Увеличить
  значение»; имена меняют `decrement-label` и `increment-label`.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `name` | строка | пусто | — | Имя в форме: скрытый input отправляет значение с точкой и без разделителей (`2567.50`), что бы ни было видно в поле. У самого поля имени нет. |
| `label` | строка | пусто | — | Подпись над полем; называет spinbutton. Слот `label` принимает разметку вместо строки. |
| `hint` | строка | пусто | — | Пояснение под полем; слот `hint` принимает разметку вместо строки. |
| `placeholder` | строка | пусто | — | Видно в пустом поле. |
| `min` | число | — | — | Нижняя граница: на ней «−» недоступна, Home переходит к ней, введённое значение ниже неё при сохранении поднимается до неё. Пусто — границы нет; без неё или если она меньше нуля, можно ввести минус. |
| `max` | число | — | — | Верхняя граница: на ней «+» недоступна, End переходит к ней, введённое значение выше неё при сохранении опускается до неё. Пусто — границы нет. |
| `step` | число | `1` | — | На сколько меняют значение «−», «+», ArrowUp и ArrowDown. Положительное число; всё остальное считается 1. Его знаки после запятой — знаки поля, если `precision` не задаёт иное. |
| `page-step` | число | — | — | На сколько меняют значение PageUp и PageDown; пусто — десять шагов. |
| `precision` | целое число | — | от 0; до 20 | Знаки после запятой — видимые и хранимые; пусто — берутся из `step` (у 0.25 их два). Без них десятичный разделитель ввести нельзя. |
| `grouping` | да/нет | да | — | Разделяет тысячи по правилам языка страницы («2 567»); `grouping="false"` пишет цифры подряд — для года или кода. |
| `steppers` | строка | `sides` | `sides`, `none` | Вид (решение владельца C53): `sides` ставит «−» и «+» по обе стороны числа — для количества, которое меняют на несколько шагов (строка корзины, гости, записей на странице); `none` — простое числовое поле для точного значения (год, вес, цена), стрелки, PageUp/PageDown и Home/End по-прежнему меняют его на шаг. |
| `unit` | строка | пусто | — | Единица после числа внутри поля, приглушённым цветом («кг», «%», «₽»); счётчик (spinbutton) произносит её вместе со значением («2,5 кг»). |
| `digits` | целое число | — | от 1; до 20 | Сколько знаков вмещает место для числа. Если пусто — самое длинное из min, max, значения и наследуемого значения с десятичными знаками поля, не меньше 2, а без max — 6. Полям в одной колонке задайте одно число, чтобы колонка была ровной. |
| `locale` | строка | пусто | — | Язык, на котором число читается и пишется; если не задан — язык страницы (`lang`), поэтому на русской странице десятичный разделитель — запятая. |
| `size` | строка | `1` | `1/2`, `1`, `2` | Размер поля: 1/2, 1 или 2, как у любого поля формы. |
| `required` | да/нет | нет | — | В поле должно быть число: поле обязательно, поэтому форма не отправится, пока оно пустое. |
| `disabled` | да/нет | нет | — | Видно, но не меняется: поле и обе кнопки недоступны, скрытый input не отправляется. |
| `readonly` | да/нет | нет | — | Видно, но не меняется: поле только для чтения, кнопки недоступны, клавиши не меняют значение. |
| `invalid` | да/нет | нет | — | Состояние ошибки: край и сообщение окрашены цветом ошибки, у поля aria-invalid. |
| `error-message` | строка | пусто | — | Ошибка, которая видна вместо пояснения, пока поле с ошибкой; слот `error` принимает разметку вместо строки. |
| `decrement-label` | строка | — | — | Доступное имя «−». Если не задано — на языке страницы («Уменьшить значение», «Decrease value»). |
| `increment-label` | строка | — | — | Доступное имя «+». Если не задано — на языке страницы («Увеличить значение», «Increase value»). |
| `aria-label` | строка | пусто | — | Доступное имя spinbutton, когда подпись внутри поля не выводится: форма, которая печатает подпись рядом (рендереры полей Framework), называет поле без второй видимой подписи. |
| `error` | да/нет | нет | — | Состояние ошибки; то же, что invalid. |
| `value` | строка | пусто | — | Число в поле, записанное с точкой (`2567.5`); пусто — числа нет. Свойство возвращает число или null и принимает число, текст числа или null. Округляется до знаков поля. Заданное из кода, событий не отправляет. |
| `inherited-value` | строка | пусто | — | Значение, к которому поле возвращается, пока у него нет своего числа, — значение по умолчанию из родительской настройки. Видно в пустом поле цветом подсказки с меткой «наследуется», никогда как значение: значение формы остаётся пустым. Когда у поля появилось своё число, кнопка сброса возвращает сюда. |
| `inherited-text` | строка | пусто | — | Слова метки, которая видна, пока действует наследуемое значение. Если не задано — на языке страницы («наследуется», «inherited»). |
| `reset-label` | строка | пусто | — | Доступное имя кнопки, которая возвращает поле к наследуемому значению. Если не задано — на языке страницы («Сбросить к наследуемому», «Reset to inherited»). |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `clear()` | объект | Очищает поле из кода; то же, что setValue(null). Возвращает тег. |
| `stepUp(args?: object)` | объект | Увеличивает значение на `count` шагов (по умолчанию 1), не выходя за границы. Событий не отправляет. Возвращает тег. |
| `stepDown(args?: object)` | объект | Уменьшает значение на `count` шагов (по умолчанию 1) в пределах границ. Событий не отправляет. Возвращает тег. |
| `setError(args: object)` | объект | Показывает сообщение об ошибке и состояние ошибки или убирает оба пустым сообщением. Записывает error-message и invalid. Возвращает тег. |
| `setValue(value: number\|string\|null)` | объект | Задаёт число из кода: число, текст числа с точкой или null — нет значения. Округляется до знаков поля, но не подтягивается к границам. Событий не отправляет: значение из кода — не изменение. Возвращает тег. |
| `resetToInherited()` | да/нет | Возвращает поле к наследуемому значению, как кнопка сброса: сначала sf-field-reset (отменяемое), затем input и change. Возвращает, был ли сброс. |
| `getInputElement()` | объект или пусто | Возвращает текстовое поле spinbutton или null до отрисовки. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `{ value: number\|null, text: string, name: string, source: "typing" \| "commit" \| "button" \| "keyboard" \| "reset" }` | Значение сохранено: один раз на каждое изменение, сделанное человеком, — сохранение введённого текста (Enter или уход из поля), нажатие кнопки (одно на всё удержание), клавиша, сброс. CustomEvent на элементе; собственное change поля наружу не выходит. Сохранение, которое только переписывает текст, событий не отправляет. |
| `input` | `{ value: number\|null, text: string, name: string, source: "typing" \| "commit" \| "button" \| "keyboard" \| "reset" }` | Значение сдвинулось: при вводе — каждый раз, когда текст читается как другое число; на каждом шаге кнопки или клавиши; перед каждым change, значение которого ещё не сообщалось. detail тот же, что у change. |
| `sf-field-reset` | `{ tag: string, value: string, inheritedValue: string, name: string }` | Человек нажал «сбросить к наследуемому». Это событие общее для всех таких полей: форма слышит их сразу и различает по `detail.tag`. Приходит до очистки; `preventDefault()` сохраняет значение. Иначе поле очищается, присылает обычный `change`, снова показывает наследуемое значение и получает фокус. |
