# Количество

`<sf-input-quantity>` — поле для числа, которое меняют по шагам: количество,
сумма, целое свойство. Берите его для числа, которое удобно менять по шагам
и у которого есть границы. Для значения, которое выбирают перетаскиванием по
шкале, берите [Слайдер диапазона](/ru/smart/forms/range-slider/), для
произвольного числа без кнопок — [Текстовые поля](/ru/smart/forms/inputs/)
с `inputmode="decimal"`.

То же на классах — [Количество](/ru/components/forms/quantity/):
`<sf-input-quantity>` собирает разметку поля количества и добавляет границы, шаг,
клавиатуру и формат числа языка страницы.

## Разметка

Минимальная разметка — тег с `label`, `name` и, при необходимости, `value`,
`min` и `max`:

```html
<sf-input-quantity label="Количество" name="count" value="2" min="1" max="99"></sf-input-quantity>
```

- `value` пишется с точкой (`2567.5`); в поле число показано по правилам
  языка страницы — на русской странице с запятой и разделителем тысяч.
- Форма получает значение из скрытого input с именем `name`: с точкой и без
  разделителей (`2567.50`), что бы ни было видно в поле.
- Подпись выводит `label` (или слот `label`), пояснение — `hint`. Если подпись
  печатает страница, задайте `aria-label`.

## Варианты

### Размер

`size` выбирает ступень полей формы: `1/2`, `1` или `2`.

:::example {id="smart-components/quantity/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Границы и шаг

`min` и `max` задают границы: введённое число за границей подтягивается к
ней. `step` — на сколько меняют значение «−», «+» и стрелки, `page-step` —
клавиши `PageUp` и `PageDown` (по умолчанию десять шагов).

:::example {id="smart-components/quantity/bounds" label="Шаг 5 и год без разделителя"}
:::

### Формат числа

Число знаков после запятой берётся из `step` (у `0.25` их два); `precision`
задаёт его явно. Без знаков после запятой десятичный разделитель ввести
нельзя. `grouping="false"` пишет цифры подряд, без разделителя тысяч, — для
года или кода.

:::example {id="smart-components/quantity/decimals" label="Вес с шагом 0,25 и сумма с копейками"}
:::

## Состояния

### На границе

Когда значение стоит на `min` или `max`, кнопка в сторону границы
недоступна.

:::example {id="smart-components/quantity/state-bound" label="Значение на нижней и на верхней границе"}
:::

### Наследуемое значение

`inherited-value` — число, которое действует, пока у поля нет своего, —
например, значение родительского раздела. Оно видно в пустом поле цветом
подсказки с меткой «наследуется», но не попадает в форму. Когда у поля
есть своё число, кнопка сброса возвращает к наследуемому.

:::example {id="smart-components/quantity/inherited" label="Пустое поле с наследуемым значением"}
:::

### Только чтение

`readonly` — значение видно и отправляется, но кнопки и клавиши его не
меняют.

:::example {id="smart-components/quantity/state-readonly" label="Поле только для чтения"}
:::

### Недоступно

`disabled` — значение видно, но не меняется и не отправляется с формой.

:::example {id="smart-components/quantity/state-disabled" label="Недоступное поле"}
:::

### Ошибка

`invalid` (или `error`) и `error-message` показывают ошибку вместо пояснения;
поле получает `aria-invalid`.

:::example {id="smart-components/quantity/state-error" label="Ошибка с сообщением"}
:::

## Поведение

### Значение и события

Свойство `value` возвращает число или `null`. Событие `input` приходит, пока
значение меняется: при вводе — каждый раз, когда текст читается как другое
число, при нажатии кнопки или клавиши — на каждом шаге. Событие `change`
приходит один раз на изменение: после ввода (по `Enter` или уходу из поля),
после нажатия кнопки (одно на всё удержание) или клавиши. В `detail` обоих —
`value`, `text`, `name` и `source`.

`setValue()`, `clear()`, `stepUp()` и `stepDown()` меняют число из кода
без событий; `setError()` показывает или снимает ошибку.

```js
const count = document.querySelector('sf-quantity[name="count"]');
count.addEventListener('change', (event) => {
  updateTotal(event.detail.value);
});
```

## Доступность

- Поле — `spinbutton` с `aria-valuenow`, `aria-valuemin`, `aria-valuemax` и
  `aria-valuetext` в формате языка страницы; его называет `label` или
  `aria-label`.
- `↑` и `↓` меняют значение на шаг, `PageUp` и `PageDown` — на десять
  шагов, `Home` и `End` переходят к границам, `Enter` сохраняет ввод, `Escape`
  отменяет его.
- «−» и «+» — настоящие кнопки с именами «Уменьшить значение» и «Увеличить
  значение»; имена меняют `decrement-label` и `increment-label`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `clear()` | объект | Очищает поле из кода; то же, что setValue(null). Возвращает элемент. |
| `stepUp(count: number)` | объект | Увеличивает значение на `count` шагов (по умолчанию 1) в пределах границ, как stepUp() нативного поля. Событий не отправляет. Возвращает элемент. |
| `stepDown(count: number)` | объект | Уменьшает значение на `count` шагов (по умолчанию 1) в пределах границ. Событий не отправляет. Возвращает элемент. |
| `setError(message: string)` | объект | Показывает сообщение об ошибке и состояние ошибки или убирает оба пустым сообщением. Записывает error-message и invalid. Возвращает элемент. |
| `setValue(value: number\|string\|null)` | объект | Задаёт число из кода: число, текст числа с точкой или null — нет значения. Округляется до знаков поля, но не подтягивается к границам. Событий не отправляет: значение из кода — не изменение. Возвращает элемент. |
| `resetToInherited()` | да/нет | Возвращает поле к наследуемому значению, как кнопка сброса: сначала sf-field-reset (отменяемое), затем input и change. Возвращает, был ли сброс. |
| `getInputElement()` | объект или пусто | Возвращает текстовое поле spinbutton или null до отрисовки. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `{ value: number\\|null, text: string, name: string, source: any }` | Значение сохранено: один раз на каждое изменение, сделанное человеком, — сохранение введённого текста (Enter или уход из поля), нажатие кнопки (одно на всё удержание), клавиша, сброс. CustomEvent на элементе; собственное change поля наружу не выходит. Сохранение, которое только переписывает текст, событий не отправляет. |
| `input` | `{ value: number\\|null, text: string, name: string, source: any }` | Значение сдвинулось: при вводе — каждый раз, когда текст читается как другое число; на каждом шаге кнопки или клавиши; перед каждым change, значение которого ещё не сообщалось. detail тот же, что у change. |
| `sf-field-reset` | `{ tag: string, value: string, inheritedValue: string, name: string }` | Человек нажал сброс к наследуемому значению. Событие признака field-inherit@1: одно имя для всех полей семейства, поэтому форма слышит их все сразу и различает по detail.tag. Отправляется до очистки поля и отменяемо: preventDefault сохраняет значение. Если не отменено, поле очищается, сообщает об этом обычным change, снова показывает наследуемое значение и забирает фокус. |
| `sf-field:reset` | `{ value?: string, inheritedValue?: string, name?: string }` | устаревший псевдоним `sf-field-reset`: подписывайтесь на `sf-field-reset` |
