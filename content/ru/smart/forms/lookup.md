# Выбор из поиска

:badge[sf-input-lookup]{variant=tonal scheme=primary size=1/2} :badge[1.2.1]{variant=outline scheme=on-surface size=1/2}

Выбор из поиска даёт выбрать людей или объекты по имени: человек набирает имя,
видит строки с аватаром, именем и подписью и выбирает одно значение или
несколько. Выбранное показано плашками, каждую можно убрать; ищет сайт. Для
короткого постоянного списка без поиска берите [выпадающий
список](/ru/smart/navigation/dropdown/).

:::

## Разметка

Полю нужны подпись и имя для формы; варианты отдаёт сайт через свойство
`provider` или, для короткого списка, `options`:

```html
<sf-input-lookup label="Участники" name="members" multiple></sf-input-lookup>
```

`label` называет поле поиска и список; без него имя даёт `aria-label` на
элементе. `placeholder` виден в пустом поле поиска, `hint` — строка под
полем. `options` и `exclude` задаются свойством или JSON в дочернем
`<script type="application/json" data-sf-settings>`, как в примерах на этой
странице; `provider` — только свойством.

## Варианты

### Одно значение или несколько

Без `multiple` выбор сразу становится значением и закрывает список; в поле
видна подпись выбранного и кнопка очистки. С `multiple` выбранное
показывается плашками в порядке выбора, а список после выбора остаётся
открытым.

:::example {id="smart-components/lookup/single" label="Одно значение из списка: выбор закрывает список"}
:::

### Вид

`appearance` выбирает вид поля: `bordered` — с рамкой, `filled` — с
заливкой, как у [поля ввода](/ru/smart/forms/inputs/).

:::example {id="smart-components/lookup/appearance" label="Поле с рамкой и с заливкой"}
:::

### Размер

`size` выбирает ступень полей формы: `1/2`, `1` или `2`.

:::example {id="smart-components/lookup/sizes" label="Размеры 1/2, 1 и 2"}
:::

## Состояния

### Ошибка

`required` не даёт отправить форму без выбора, `invalid` и `error-message`
показывают ошибку под полем.

:::example {id="smart-components/lookup/state-error" label="Обязательное поле с ошибкой"}
:::

### Только чтение

`readonly` показывает значение и отправляет его с формой, но без кнопок
удаления.

:::example {id="smart-components/lookup/state-readonly" label="Поле только для чтения"}
:::

### Недоступно

`disabled` отключает поле целиком.

:::example {id="smart-components/lookup/state-disabled" label="Недоступное поле с выбранными людьми"}
:::

## Поведение

### Значение

- Одно значение — `{value, label}` или `null`.
- Несколько (`multiple`) — список `{value, label}` в порядке выбора; пустой
  список, когда ничего не выбрано.
- У элемента могут быть `caption` (подпись) и `avatar` (`{src}` или
  `{initials}`); выбранный элемент хранит их, поэтому плашке не нужен
  повторный запрос.
- С формой уходят только значения: одно или по записи на каждое. Подписи не
  отправляются.

Это то же значение, что у поля-справочника в
[карточке свойств](/ru/pro/admin/property-view/).

### Поиск на стороне сайта

Сайт отвечает через свойство `provider` — функцию, обычно асинхронную;
код подключения — в разделе «Подключение поиска» ниже.

- Пока набрано меньше `min-length` (по умолчанию 2) символов, список
  подсказывает, сколько набрать, и ничего не спрашивает.
- После паузы `debounce` (120 мс) вызывается `provider`; предыдущий вызов
  отменяется через `signal`, а опоздавший ответ отбрасывается.
- `{items}` — строки или «Ничего не найдено»; `{status: 'unavailable'}` —
  нейтральная строка «Поиск недоступен» без причины; ошибка — строка ошибки и
  кнопка «Повторить».
- «Показать ещё» появляется только при `nextCursor`; ровно `max-results`
  строк ещё не значит, что есть продолжение.
- `exclude` убирает значения из каждого ответа — например, самого человека
  или уже добавленных участников; фильтрует компонент.
- `options` — короткий список целиком: по нему ищет сам компонент, без
  `provider`.

### Предел числа

`max-items` ограничивает число выбранных при `multiple`. Выбор сверх предела
не молча игнорируется: под списком появляется строка «Не больше 3».

### События

- `input`, затем `change` — значение изменил человек: выбор, удаление плашки,
  `Backspace` в пустом поле поиска. `detail` — `{value, item, action}`, где
  `action` — `added`, `removed` или `replaced`.
- Набор текста событием значения не считается; значение из кода, сброс формы
  и восстановление браузером событий не отправляют.

### Подключение поиска

```js
const lookup = document.querySelector('sf-lookup[name="members"]');
lookup.provider = async (query, {cursor, limit, signal}) => {
  const response = await fetch(`/api/people?q=${encodeURIComponent(query)}&limit=${limit}`, {signal});
  return response.json(); // {items, nextCursor} или {status: 'unavailable'}
};
```

## Доступность

- Поле поиска — `combobox` с `aria-expanded`, `aria-controls` и
  `aria-activedescendant`; список — `listbox`, строки — `option` с
  `aria-selected`.
- Стрелки ходят по строкам, `Home` и `End` — к первой и последней, `Enter`
  выбирает, первый `Escape` закрывает список, второй очищает запрос,
  `Backspace` в пустом поле убирает последнюю плашку.
- Строка состояния — поиск, «ничего не найдено», ошибка, предел — объявляется
  вежливо (`role="status"`).
- Рамка, высота и текст совпадают с [полем ввода](/ru/smart/forms/inputs/)
  того же размера.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/2`, `1`, `2` | Размер поля, как у `sf-input`: рамка, отступы и текст; плашки по высоте строки текста, картинки в строках на размер меньше. |
| `appearance` | строка | `bordered` | `bordered`, `filled` | Вид поля: блок с рамкой или с заливкой — те же два вида, что у sf-input. |
| `label` | строка | пусто | — | Видимое имя поля; оно называет поле поиска и список. Без него имя даёт aria-label тега. |
| `placeholder` | строка | пусто | — | Показывается в поле поиска, пока оно пустое. |
| `hint` | строка | пусто | — | Строка под полем; она описывает поле поиска. |
| `name` | строка | пусто | — | Имя в форме: одна запись с выбранным значением или по записи на каждое при multiple. Отправляются только значения, подписи никогда. |
| `multiple` | да/нет | нет | — | Несколько значений — плашки в порядке выбора; после выбора список остаётся открытым. Без него выбор становится значением и закрывает список. |
| `max-items` | число | `0` | — | Только с multiple: наибольшее число выбранных (49 для группы). Выбор сверх предела отклоняется с видимой строкой; 0 — без предела. |
| `min-length` | число | `2` | — | Наименьшее число символов, с которым спрашивается provider; меньше — список показывает подсказку и ничего не спрашивает. По options ищется при любой длине. |
| `max-results` | число | `20` | — | Предел, с которым спрашивается provider, и наибольшее число строк одного ответа. |
| `debounce` | число | `120` | — | Сколько миллисекунд поле ждёт после последней клавиши, прежде чем спросить provider, как sf-search. |
| `maxlength` | число | `0` | — | Наибольшее число символов в поле поиска (80 для simai.chat); 0 — без предела. |
| `required` | да/нет | нет | — | Форма не отправляется, пока ничего не выбрано (value-missing). |
| `disabled` | да/нет | нет | — | Не ищет, не меняется, не получает фокус и не отправляется с формой; так же действует отключённый fieldset. |
| `readonly` | да/нет | нет | — | Выбранное показывается и отправляется, но не меняется: нет поиска и кнопок удаления. |
| `invalid` | да/нет | нет | — | Решение страницы: вид ошибки и aria-invalid, под полем — error-message. |
| `error-message` | строка | пусто | — | Показывается вместо подсказки, пока поле с ошибкой. |
| `aria-label` | строка | пусто | — | — |
| `options` | список | `[]` | — | Короткий список целиком, `[{value, label, caption?, avatar?}]`: поиск идёт по нему, `provider` не вызывается. Задаётся свойством или JSON в странице. |
| `exclude` | список | `[]` | — | Значения, которые не показываются ни в ответах, ни в `options`, например сам человек или текущие участники. Задаётся свойством или JSON в странице. |
| `provider` | объект | `null` | — | Поиск: async-функция (query, {cursor, limit, signal}), отвечающая {items: [{value, label, caption?, avatar?: {src} \| {initials}}], nextCursor?, notice?} или {status: 'unavailable'}; notice — своя строка приложения под строками (показаны первые 20, уточните поиск); брошенная ошибка или отклонённое обещание — состояние ошибки. Предыдущий вызов прерывается через signal, его опоздавший ответ отбрасывается. Только свойство. |
| `value` | объект | `null` | — | Одно значение: {value, label} или null. Несколько: список {value, label} в порядке выбора, [], когда ничего не выбрано. Выбранный элемент хранит подпись и аватар. Значение из кода (или атрибут value как JSON; одиночное значение ищется в options) событий не отправляет. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `search(query: string)` | да/нет | Ставит запрос в поле поиска и ищет его, как при наборе, сразу (без паузы), открывая список. Возвращает false, пока поле отключено или только для чтения. |
| `retry()` | да/нет | Повторяет последний вызов provider с тем же запросом и курсором, как кнопка «Повторить». Возвращает false, если повторять нечего. |
| `close()` | да/нет | Закрывает список и прерывает идущий поиск; запрос остаётся. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `input` | `{ value: object, item: object, action: string }` | Значение изменилось: выбор, удаление плашки, Backspace в пустом поле поиска. Отправляется перед change с тем же detail; собственный input поля поиска наружу не выходит. |
| `change` | `{ value: object, item: object, action: string }` | Значение изменил человек, один раз на выбор или удаление, как у select: detail.value — новое значение, detail.item — выбранный или убранный элемент, detail.action — added, removed или replaced. Значение из кода, сброс формы и восстановление событий не отправляют. |
