# Выбор из поиска

:badge[sf-input-lookup]{variant=outline scheme=on-surface size=1/2} :badge[1.19.0]{variant=outline scheme=on-surface size=1/2}

Выбор из поиска даёт выбрать людей или объекты по имени: человек набирает
имя, видит строки с аватаром, именем и подписью и выбирает одно значение или
несколько. Выбранное показано плашками, каждую можно убрать. Ищет сайт —
список может быть сколь угодно длинным.

## Пример

Добавьте участников группы: наберите букву, выберите человека, уберите
плашку. Больше трёх выбрать нельзя. Журнал под примером показывает события.

:::example {id="smart-components/lookup/overview" label="Участники" preview=sandbox log_console=true log_open=false}
:::

Полю нужны подпись и имя для формы; варианты отдаёт сайт:

```html
<sf-input-lookup label="Участники" name="members" multiple></sf-input-lookup>
```

## Когда брать

- **Выбор из длинного списка людей или объектов**: участники, ответственный,
  клиент, товар — то, что быстрее найти по имени, чем пролистать.
- **Список знает сайт**, а не страница: поиск идёт запросом на сервер.

## Когда не брать

- **До семи известных вариантов** — их видно сразу без поиска:
  [Радиокнопки](/ru/smart/forms/radio/) или [Выпадающий
  список](/ru/smart/navigation/dropdown/).
- **Свободный текст, а не выбор из готового** — [Текстовое
  поле](/ru/smart/forms/inputs/).
- **Независимые отметки** — [Флажок](/ru/smart/forms/checkbox/).

## Частые задачи

### Пояснение у подписи

`help` • [справочник](#атрибуты)

`help` ставит после подписи знак «?» с пояснением, которое нужно не всем:
оно открывается по нажатию, а подпись от знака не становится выше. Знак
называется по подписи — «Подробнее: Наблюдатели». `hint` — строка помощи под
полем, она видна всегда.

:::example {id="smart-components/lookup/help" label="Знак «?» у подписи"}
:::

### Одно значение или несколько

`multiple`, `max-items` • [справочник](#атрибуты)

Без `multiple` выбор сразу становится значением и закрывает список; в поле
видны имя выбранного и кнопка очистки. Выберите ответственного в примере.

:::example {id="smart-components/lookup/single" label="Ответственный"}
:::

С `multiple` выбранное показывается плашками в порядке выбора, а список после
выбора остаётся открытым, как в [примере](#пример). `max-items` ограничивает
число выбранных: выбор сверх предела отклоняется, и под списком появляется
строка «Не больше 3».

### Поиск на стороне сайта

`provider`, `min-length`, `max-results`, `exclude` • по умолчанию `min-length="2"` • [справочник](#атрибуты)

Сайт отвечает на поиск функцией `provider`. В примере она отвечает с
паузой, как сервер: наберите «ан» — найдётся больше пяти человек, и внизу
появится «Показать ещё»; «яя» — никого; «сбой» — ошибка с кнопкой
«Повторить»; «нет сети» — поиск недоступен. Себя пригласить нельзя: Анна
Петрова убрана из ответов через `exclude`.

:::example {id="smart-components/lookup/provider" label="Поиск на сайте" preview=sandbox log_console=true log_open=false}
:::

```js
const lookup = document.querySelector('sf-input-lookup[name="invitees"]');
lookup.provider = async (query, {cursor, limit, signal}) => {
  const response = await fetch(`/api/people?q=${encodeURIComponent(query)}&cursor=${cursor ?? ''}&limit=${limit}`, {signal});
  return response.json(); // {items, nextCursor} или {status: 'unavailable'}
};
```

| Ответ `provider` | Что видит человек |
|:---|:---|
| `{items}` | строки найденного; пустой список — «Ничего не найдено» |
| `{items, nextCursor}` | строки и «Показать ещё»: следующий вызов получит `cursor` |
| `{status: 'unavailable'}` | нейтральная строка «Поиск недоступен» |
| ошибка | строка ошибки и кнопка «Повторить» |

- Пока набрано меньше `min-length` символов, список подсказывает, сколько
  набрать, и ничего не спрашивает.
- После паузы `debounce` (120 мс) вызывается `provider`; предыдущий вызов
  отменяется через `signal`, опоздавший ответ отбрасывается.
- `max-results` — сколько строк просить за раз; ровно столько строк ещё не
  значит, что есть продолжение: его отмечает `nextCursor`.
- `exclude` убирает значения из каждого ответа — самого человека или уже
  добавленных участников; фильтрует компонент.

Короткий постоянный список можно отдать целиком в `options`: по нему ищет сам
компонент, без `provider`, — так устроены остальные примеры на этой
странице. `options` и `exclude` задаются свойством или JSON в дочернем
`<script type="application/json" data-sf-settings>`, `provider` — только
свойством.

### Недавние при фокусе

`suggest` • [справочник](#атрибуты)

С `suggest` фокус в пустом поле сразу спрашивает сайт с пустым запросом и
показывает, что он ответил: недавние выборы человека или самые частые
варианты. Без `suggest` пустое поле сразу подсказывает, сколько букв набрать.

Пока идёт поиск, прежние строки остаются на месте, на ступень бледнее; если
ответ задерживается дольше секунды, внизу появляется «Поиск…» с
индикатором. Совпавшая часть имени и подписи выделена средним начертанием.

:::example {id="smart-components/lookup/suggest" label="Недавние при фокусе" preview=sandbox log_console=true log_open=false}
:::

### Создание записи

`create` • [справочник](#атрибуты)

С `create` последней строкой списка стоит «Создать «…»» — когда среди
найденного и выбранного нет точного совпадения с набранным. Выбор этой строки
отправляет событие `create` с текстом; приложение создаёт запись и отвечает
через `detail.respond()`: новой записью — поле выберет её как обычную строку —
или ошибкой, которую поле покажет строкой под списком. `create="email"`
предлагает «Добавить адрес …» и только для адреса почты.

Наберите в примере «срочно» и выберите строку создания; «с» — короче двух
букв — приложение отклонит.

:::example {id="smart-components/lookup/create" label="Метки с созданием" preview=sandbox log="input change create" log_console=true log_open=false}
:::

```js
tags.addEventListener('create', (event) => {
  event.detail.respond(api.createTag(event.detail.text)); // {value, label} или {error}
});
```

### На телефоне

На узком экране, ниже ступени `lg`, список открывается листом поверх
страницы: поле поиска наверху, строки под ним, «Готово» закрывает лист.
Откройте [пример](#пример) в ширине телефона — кнопка просмотра рамки
примера.

## Работа из кода

### Значение и события

`value` • [справочник](#события)

- Одно значение — `{value, label}` или `null`.
- Несколько (`multiple`) — список `{value, label}` в порядке выбора; пустой
  список, когда ничего не выбрано.
- У элемента могут быть `caption` (подпись) и `avatar` (`{src}` или
  `{initials}`); выбранный элемент хранит их, поэтому плашке не нужен
  повторный запрос.
- С формой уходят только значения: одно или по записи на каждое. Подписи не
  отправляются.

Это то же значение, что у поля-справочника в
[карточке свойств](/ru/pro/admin/property-view/).

| Событие | Когда приходит |
|:---|:---|
| `input`, затем `change` | значение изменил человек: выбор, удаление плашки, `Backspace` в пустом поле поиска |
| `create` | человек выбрал строку «Создать «…»»; ответ — `detail.respond()` |

`detail` — `{value, item, action}`, где `action` — `added`, `removed` или
`replaced`. Набор текста событием значения не считается; значение из кода,
сброс формы и восстановление браузером событий не отправляют. События видны
в журнале под [примером](#пример).

```js
const members = document.querySelector('sf-input-lookup[name="members"]');
members.addEventListener('change', (event) => {
  console.log(event.detail.action, event.detail.value);
});
```

## Доступность

- Поле поиска — `combobox` с `aria-expanded`, `aria-controls` и
  `aria-activedescendant`; список — `listbox`, строки — `option` с
  `aria-selected`.
- Стрелки ходят по строкам, `Home` и `End` — к первой и последней, `Enter`
  выбирает, первый `Escape` закрывает список, второй очищает запрос,
  `Backspace` в пустом поле убирает последнюю плашку.
- Поле — одна остановка `Tab`. Стрелки `←` и `→` ходят по плашкам,
  `Delete` и `Backspace` убирают плашку; экранный диктор читает «Анна
  Петрова, 1 из 3, Delete — убрать».
- Строка состояния — поиск, «ничего не найдено», ошибка, предел — объявляется
  вежливо (`role="status"`).
- Рамка, высота и текст совпадают с [текстовым полем](/ru/smart/forms/inputs/)
  того же размера.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Ступень размера поля, как у sf-input (1/3, 1/2, 1, 2, 3): рамка, отступы и текст одного размера; плашки стоят на строке текста поля, картинки в строках на ступень меньше. |
| `width` | строка | пусто | пусто, `short`, `medium`, `long` | Ширина поля по значению, для которого оно сделано: `short` — 20 знаков лестницы ширин (`--sf-field--width-short`; дата, число, код), `medium` — 28 (имя, телефон), `long` — 44 (путь, e-mail, адрес). Поле не шире этого и не шире контейнера под ним; знаки следуют размеру текста, плотности и телефону (160 / 224 / 352 px при тексте 16, 140 / 196 / 308 в компактной плотности и на телефоне). Пусто, по умолчанию — вся ширина контейнера. |
| `appearance` | строка | `bordered` | `bordered`, `filled` | Вид поля: блок с рамкой или с заливкой — те же два вида, что у sf-input. |
| `label` | строка | пусто | — | Видимое имя поля; оно называет поле поиска и список. Без него имя даёт aria-label тега. |
| `placeholder` | строка | пусто | — | Показывается в поле поиска, пока оно пустое. |
| `hint` | строка | пусто | — | Строка под полем; она описывает поле поиска. |
| `help` | строка | пусто | — | Пояснение за «?» (sf-help-mark, вид C133) после текста подписи (C153 (8)): ступенью ниже значения, как подпись; строка подписи сохраняет высоту. Знак называется по теме («Подробнее: <подпись>»). Пусто — знака нет. |
| `name` | строка | пусто | — | Имя в форме: одна запись с выбранным значением или по записи на каждое при multiple. Отправляются только значения, подписи никогда. |
| `multiple` | да/нет | нет | — | Несколько значений — плашки в порядке выбора; после выбора список остаётся открытым. Без него выбор становится значением и закрывает список. |
| `chips` | строка | `wrap` | `wrap`, `row` | Только для множественного выбора: `wrap` показывает все фишки в стольких строках, сколько нужно (формы); `row` держит одну строку и фишку «+N» для остальных (фильтры, таблицы, карточки; C58). Нажатие на «+N» или фокус в поле раскрывает все фишки; уход из поля сворачивает их. |
| `max-items` | число | `0` | — | Только при `multiple`: сколько вариантов можно выбрать самое большее. Лишний выбор отклоняется с видимой строкой; 0 — без ограничения. |
| `min-length` | число | `2` | — | Наименьшее число символов, с которым спрашивается provider; меньше — список показывает подсказку и ничего не спрашивает. По options ищется при любой длине. |
| `suggest` | да/нет | нет | — | Приложение отвечает на пустой запрос: фокус в пустом поле сразу спрашивает provider с '' и показывает ответ — недавние элементы человека, частые варианты. min-length 0 делает то же. Без них фокус в пустом поле с поиском через provider сразу показывает подсказку min-length. |
| `max-results` | число | `20` | — | Предел, с которым спрашивается provider, и наибольшее число строк одного ответа. |
| `debounce` | число | `120` | — | Сколько миллисекунд поле ждёт после последнего нажатия клавиши, прежде чем спросить поставщика. |
| `maxlength` | число | `0` | — | Сколько символов самое большее принимает поле поиска; 0 — без ограничения. |
| `create` | строка | пусто | — | Временные имена значений. Предлагать создать набранное: атрибут без значения (или "item") — список заканчивается строкой «Создать «текст»», когда ни строка, ни выбранный элемент не совпадают с запросом в точности; "email" предлагает «Добавить адрес текст» только для почтового адреса. Выбор строки присылает create с текстом; приложение отвечает через detail.respond() новым элементом, который выбирается как строка, или ошибкой — видимой вежливой строкой поля. Нет атрибута или "false" — строки нет. |
| `required` | да/нет | нет | — | Форма не отправляется, пока ничего не выбрано (value-missing). |
| `disabled` | да/нет | нет | — | Не ищет, не меняется, не получает фокус и не отправляется с формой; так же действует отключённый fieldset. |
| `readonly` | да/нет | нет | — | Выбранное показывается и отправляется, но не меняется: нет поиска и кнопок удаления. |
| `invalid` | да/нет | нет | — | Решение страницы: вид ошибки и aria-invalid, под полем — error-message. |
| `error-message` | строка | пусто | — | Показывается вместо подсказки, пока поле с ошибкой. |
| `aria-label` | строка | пусто | — | Доступное имя поля без видимой подписи; оно называет поле поиска и список. |
| `options` | список | `[]` | — | Короткий список целиком, `[{value, label, caption?, avatar?, icon?}]`: поиск идёт по нему, provider не вызывается. Задаётся свойством или JSON в странице (data-sf-settings). Совпавшая с запросом часть имени или подписи выделяется средним начертанием. |
| `exclude` | список | `[]` | — | Значения, которые не показываются ни в ответах, ни в `options`, например сам человек или текущие участники. Задаётся свойством или JSON в странице. |
| `provider` | объект | `null` | — | Поиск: async-функция (query, {cursor, limit, signal}), отвечающая {items: [{value, label, caption?, avatar?: {src} \| {initials}, icon?, match?: {label?, caption?: [[start, end]]}}], nextCursor?, notice?} или {status: 'unavailable'}; notice — своя строка приложения под строками (показаны первые 20, уточните поиск); брошенная ошибка или отклонённое обещание — состояние ошибки. Предыдущий вызов прерывается через signal, его опоздавший ответ отбрасывается. Только свойство. Если приложение возвращает диапазоны match, совпавшая часть имени и подписи выделяется средним начертанием; варианты из options поле отмечает само. |
| `value` | объект | `null` | — | Одно значение: {value, label} или null. Несколько: список {value, label} в порядке выбора, [], когда ничего не выбрано. Выбранный элемент хранит подпись и аватар. Значение из кода (или атрибут value как JSON; одиночное значение ищется в options) событий не отправляет. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `search(query: string)` | да/нет | Ставит запрос в поле поиска и ищет его, как при наборе, сразу (без паузы), открывая список. Возвращает false, пока поле отключено или только для чтения. |
| `retry()` | да/нет | Повторяет последний вызов provider с тем же запросом и курсором, как кнопка «Повторить». Возвращает false, если повторять нечего. |
| `close()` | да/нет | Закрывает список и прерывает идущий поиск; запрос остаётся. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `input` | `{ value: object, item: object, action: string }` | Значение изменилось: выбор, удаление плашки, Backspace в пустом поле поиска. Отправляется перед change с тем же detail; собственный input поля поиска наружу не выходит. |
| `change` | `{ value: object, item: object, action: string }` | Значение изменил человек, один раз на выбор или удаление, как у select: detail.value — новое значение, detail.item — выбранный или убранный элемент, detail.action — added, removed или replaced. Значение из кода, сброс формы и восстановление событий не присылают. У созданного элемента рядом с action стоит created: true. |
| `sf-input-lookup-create` | `{ text: string, kind: "item" \| "email", respond: string }` | Человек выбрал строку создания: detail.text — набранный текст (без пробелов по краям), detail.kind — item или email. Ответьте через detail.respond(answer) — сразу или позже, ответом или обещанием: новым элементом {value, label, caption?, avatar?, icon?}, который поле выбирает как строку (приходят input и change, action added или replaced, created true), или {error: message}, Error или сообщением — оно показывается вежливой строкой поля («Не удалось создать», если сообщения нет). Пока ответа нет, строка не создаёт второй раз. |
