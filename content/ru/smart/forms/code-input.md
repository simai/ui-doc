# Код подтверждения

:badge[sf-input-code]{variant=outline scheme=on-surface size=1/2} :badge[1.7.0]{variant=outline scheme=on-surface size=1/2}

Код подтверждения — поле для одноразового кода из сообщения,
приложения-генератора или письма: код показан по ячейкам, а с формой уходит
одно обычное значение. Берите его для кода, который человек получил и вводит
или вставляет. PIN-код или пароль, который человек придумывает сам, вводят в
[текстовое поле](/ru/smart/forms/inputs/) с `input-type="password"`.

То же на классах — [Код подтверждения](/ru/components/forms/verification/):
`<sf-input-code>` собирает его разметку из атрибутов.

## Разметка

Минимальная разметка — тег с `label` и `name`:

```html
<sf-input-code label="Код из сообщения" name="code"></sf-input-code>
```

- Значение формы — один нативный input с именем `name` и
  `autocomplete="one-time-code"`, поэтому автозаполнение браузера и WebOTP
  вставляют код целиком.
- Без видимой подписи группу и поле называет `aria-label`.
- `hint` подсказывает, сколько символов и откуда код.

## Варианты

### Вид

`appearance` • по умолчанию `bordered` • [справочник](#атрибуты)

`appearance="bordered"` (по умолчанию) делит ячейки рамкой,
`appearance="filled"` ставит их на тоновую заливку; в фокусе ячейки получают
рамку.

:::example {id="smart-components/code-input/appearance" label="Виды bordered и filled"}
:::

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

`size` выбирает ступень полей формы: `1/2`, `1` или `2`.

:::example {id="smart-components/code-input/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Символы

`mode` • по умолчанию `numeric` • [справочник](#атрибуты)

`mode="numeric"` (по умолчанию) принимает цифры и открывает цифровую
клавиатуру, `mode="alphanumeric"` — латинские буквы и цифры. Остальное при
вводе и вставке отбрасывается.

:::example {id="smart-components/code-input/mode" label="Цифры и буквы с цифрами"}
:::

### Свой набор символов и группы

`charset`, `uppercase`, `groups` • [справочник](#атрибуты)

`charset` — свой набор символов вместо `mode`: остаются только они.
Например, код без похожих знаков 0, O, 1 и I. `uppercase` переводит
набранные и вставленные буквы в заглавные: вставленный `ab12cd` станет
`AB12CD`. `groups` делит ячейки на группы 3 + 3 или 4 + 4: разделитель
только рисуется — его нет ни в значении, ни при копировании, ни в том, что
читает экранный диктор.

:::example {id="smart-components/code-input/charset" label="Группы и свой набор символов"}
:::

### Длина

`length` • по умолчанию `6` • [справочник](#атрибуты)

`length` — сколько символов в коде, от 1 до 12; каждому символу — своя
ячейка.

:::example {id="smart-components/code-input/length" label="Коды из 4, 6 и 8 символов"}
:::

### Скрытый код

`mask` • [справочник](#атрибуты)

`mask` показывает каждый символ точкой; поле становится полем пароля, и
экранный диктор не читает код вслух.

:::example {id="smart-components/code-input/mask" label="Код, скрытый точками"}
:::

## Состояния

### Ошибка

`invalid`, `error-message` • [справочник](#атрибуты)

Когда приложение отклонило код, задайте `invalid` и `error-message`: ячейки
и сообщение окрашиваются цветом ошибки, поле получает `aria-invalid`.
Снимает состояние тоже приложение.

:::example {id="smart-components/code-input/state-error" label="Отклонённый код"}
:::

### Недоступно

`disabled` • [справочник](#атрибуты)

`disabled` запрещает ввод и не отправляет значение.

:::example {id="smart-components/code-input/state-disabled" label="Недоступное поле"}

### Только чтение

`readonly` • [справочник](#атрибуты)

`readonly` показывает код без правки.

## Поведение

### Ввод и вставка

Под ячейками — одно настоящее поле, ячейки только рисуют его состояние.
Курсор и рамка фокуса — только у текущей ячейки. Ввод заполняет следующую
ячейку, `Backspace` возвращается и стирает. Вставленный код заполняет все
ячейки, лишние и чужие символы отбрасываются. Код можно выделить и
скопировать, как обычный текст. Автозаполнение браузера и код из сообщения
на телефоне тоже вставляют код целиком.

Попробуйте в примере ниже: вставьте `246 810` — пробел отбросится, код
заполнит ячейки.

### Проверка кода и события

Когда заполнены все ячейки, приходит `sf-input-code-completed` с `value` —
один раз на каждый целый код. Компонент сам форму не отправляет и код не
проверяет: проверяет приложение. Обычные события `input` и `change` всплывают
от внутреннего поля без `detail`.

В примере подходит код `246810`: другой код приложение отклоняет, поле
показывает ошибку, а новый ввод её снимает. Журнал под примером показывает
события.

:::example {id="smart-components/code-input/verify" label="Проверка кода" preview=sandbox log="input change sf-input-code-completed" log_console=true log_open=true}
:::

```js
const code = document.querySelector('sf-input-code[name="code"]');
code.addEventListener('sf-input-code-completed', async (event) => {
  const ok = await verify(event.detail.value);
  code.toggleAttribute('invalid', !ok);
  if (!ok) code.setAttribute('error-message', 'Код не подошёл');
});
```

## Доступность

- Группа ячеек и поле названы `label` (или `aria-label`).
- Каждый раз, когда курсор переходит в другую ячейку, вежливая строка
  сообщает её место: «цифра 3 из 6», для буквенно-цифрового кода — «символ».
- `←` и `→` переходят между ячейками, `Home` и `End` — к первой и последней,
  `Backspace` и `Delete` стирают.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `length` | число | `6` | — | Сколько символов в коде, от 1 до 12; по ячейке на символ. |
| `default-value` | строка | пусто | — | Код, к которому возвращает сброс формы; поле начинается с него, если value нет. |
| `name` | строка | пусто | — | Имя поля в форме; с ним уходит значение. |
| `mode` | строка | `numeric` | `numeric`, `alphanumeric` | numeric — цифры, цифровая клавиатура; alphanumeric — латинские буквы и цифры. charset заменяет этот атрибут. Всё остальное при вводе или вставке отбрасывается. У внутреннего поля нет pattern: неполный код — too-short на самом компоненте, словами страницы. |
| `charset` | строка | пусто | — | Свой алфавит: остаются только эти символы, каждый пишется один раз, например 23456789BCDFGHJKMNPQRTVWXY (без 0 O 1 I). Если задан, заменяет mode; клавиатура цифровая, когда в алфавите только цифры, и тогда ячейка читается как цифра. |
| `uppercase` | да/нет | нет | — | Набранные или вставленные буквы становятся заглавными до того, как символы проверяются: вставленное ab12cd станет AB12CD, а клавиатура предлагает заглавные (autocapitalize characters). Включите вместе с алфавитом из заглавных, чтобы строчная буква тоже принималась. |
| `groups` | число | `0` | — | Сколько ячеек в группе, между группами рисуется разделитель: 3 — 3 + 3, 4 — 4 + 4; от 2 до 6 и меньше длины кода. 0 по умолчанию — без разделителя. Разделитель только рисуется: его нет ни в значении, ни при копировании и вставке, ни в том, что читает экранный диктор. |
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Ступень размера поля, как у sf-input (1/3, 1/2, 1, 2, 3): ячейки и их текст. |
| `appearance` | строка | `bordered` | `bordered`, `filled` | bordered: ячейки разделены рамкой; filled: ячейки на тоновой заливке, которые получают рамку, пока код в фокусе. |
| `label` | строка | пусто | — | Видимая подпись; называет группу и поле. |
| `hint` | строка | пусто | — | Текст под ячейками: сколько символов и откуда код. |
| `help` | строка | пусто | — | Пояснение за знаком «?» (sf-help-mark) после текста подписи, как `help` у sf-input: на ступень меньше значения, как подпись; высота строки подписи не меняется. Знак назван по предмету («Подробнее: <подпись>»). Пусто или без подписи — знака нет. |
| `required` | да/нет | нет | — | Форма требует целый код. |
| `disabled` | да/нет | нет | — | — |
| `readonly` | да/нет | нет | — | — |
| `invalid` | да/нет | нет | — | Код отклонён: ячейки и пояснение окрашены цветом ошибки, у поля aria-invalid. Задаёт и снимает приложение. |
| `error-message` | строка | пусто | — | Показывается вместо пояснения, пока поле с ошибкой, и служит aria-errormessage поля. |
| `mask` | да/нет | нет | — | Каждый символ показан точкой; поле становится полем пароля, поэтому экранный диктор не читает код вслух. |
| `value` | строка | пусто | — | Код. Заданный атрибутом, он управляемый: атрибут следует за вводом человека. Приводится к режиму и длине. |
| `aria-label` | строка | пусто | — | Имя группы и поля, когда видимой подписи нет. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `getInputElement()` | объект или пусто | Возвращает поле ввода внутри тега или `null`, пока оно не нарисовано. |
| `focus(options?: object)` | пусто | Ставит фокус в поле. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `input` | `null` | Код изменился при вводе, вставке или автозаполнении; значение уже очищено и обрезано по длине. `detail` нет. |
| `change` | `null` | Код сохранён: поле потеряло фокус с кодом, отличным от того, что был при получении фокуса. Отправляется один раз от внутреннего input. detail нет. |
| `sf-input-code-completed` | `{ value: string }` | Факт завершения: в каждой ячейке есть символ, после правки человека; один раз на каждый целый код, после его события input. Элемент сам форму не отправляет. |
