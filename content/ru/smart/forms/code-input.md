# Код подтверждения

:badge[sf-input-code]{type=tonal scheme=primary size=1/2} :badge[1.2.0]{type=outline scheme=on-surface size=1/2}

Код подтверждения — поле для одноразового кода из сообщения,
приложения-генератора или письма: код показан по ячейкам, а с формой уходит
одно обычное значение. Берите его для кода, который человек получил и вводит
или вставляет. PIN-код или пароль, который человек придумывает сам, вводят в
[текстовое поле](/ru/smart/forms/inputs/) с `input-type="password"`.

То же на классах — [Код подтверждения](/ru/components/forms/verification/):
`<sf-input-code>` собирает его разметку из атрибутов.

## Разметка

Минимальная разметка — тег с `label` и `name`:

```html
<sf-input-code label="Код из сообщения" name="code"></sf-input-code>
```

- Значение формы — один нативный input с именем `name` и
  `autocomplete="one-time-code"`, поэтому автозаполнение браузера и WebOTP
  вставляют код целиком.
- Без видимой подписи группу и поле называет `aria-label`.
- `hint` подсказывает, сколько символов и откуда код.

## Варианты

### Вид

`appearance="bordered"` (по умолчанию) делит ячейки рамкой,
`appearance="filled"` ставит их на тоновую заливку; в фокусе ячейки получают
рамку.

:::example {id="smart-components/code-input/appearance" label="Виды bordered и filled"}
:::

### Размер

`size` выбирает ступень полей формы: `1/2`, `1` или `2`.

:::example {id="smart-components/code-input/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Символы

`mode="numeric"` (по умолчанию) принимает цифры и открывает цифровую
клавиатуру, `mode="alphanumeric"` — латинские буквы и цифры. Остальное при
вводе и вставке отбрасывается.

:::example {id="smart-components/code-input/mode" label="Цифры и буквы с цифрами"}
:::

### Длина

`length` — сколько символов в коде, от 1 до 12; каждому символу — своя
ячейка.

:::example {id="smart-components/code-input/length" label="Коды из 4, 6 и 8 символов"}
:::

### Скрытый код

`mask` показывает каждый символ точкой; поле становится полем пароля, и
экранный диктор не читает код вслух.

:::example {id="smart-components/code-input/mask" label="Код, скрытый точками"}
:::

## Состояния

### Ошибка

Когда приложение отклонило код, задайте `invalid` и `error-message`: ячейки
и сообщение окрашиваются цветом ошибки, поле получает `aria-invalid`.
Снимает состояние тоже приложение.

:::example {id="smart-components/code-input/state-error" label="Отклонённый код"}
:::

### Недоступно

`disabled` запрещает ввод и не отправляет значение.

:::example {id="smart-components/code-input/state-disabled" label="Недоступное поле"}
:::

### Только чтение

`readonly` показывает код без правки.

## Поведение

### Ввод и вставка

Ввод заполняет следующую ячейку, `Backspace` возвращается и стирает,
вставленный код заполняет все ячейки.

### Проверка кода и события

Когда заполнены все ячейки, приходит `sf-code-input-completed` с `value` —
один раз на каждый целый код. Компонент сам форму не отправляет и код не
проверяет: проверяет приложение. Обычные события `input` и `change` всплывают
от внутреннего input без `detail`.
Прежнее имя `sf-code-input:complete` приходит следом с тем же `detail` до
2026-12-01.

```js
const code = document.querySelector('sf-code-input[name="code"]');
code.addEventListener('sf-code-input-completed', async (event) => {
  const ok = await verify(event.detail.value);
  code.toggleAttribute('invalid', !ok);
  if (!ok) code.setAttribute('error-message', 'Код не подошёл');
});
```

## Доступность

- Группа ячеек и поле названы `label` (или `aria-label`).
- Каждый раз, когда курсор переходит в другую ячейку, вежливая строка
  сообщает её место: «цифра 3 из 6», для буквенно-цифрового кода — «символ».
- `←` и `→` переходят между ячейками, `Home` и `End` — к первой и последней,
  `Backspace` и `Delete` стирают.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `length` | число | `6` | — | Сколько символов в коде, от 1 до 12; по ячейке на символ. |
| `default-value` | строка | пусто | — | Код, к которому возвращает сброс формы; поле начинается с него, если value нет. |
| `name` | строка | пусто | — | Имя нативного input в форме; его значение и есть значение формы. |
| `mode` | строка | `numeric` | `numeric`, `alphanumeric` | numeric: цифры и цифровая клавиатура; alphanumeric: латинские буквы и цифры. Остальное при вводе и вставке отбрасывается; нативный pattern требует ровно length символов режима. |
| `size` | строка | `1` | `1/2`, `1`, `2` | Ступень лестницы полей формы, как у sf-input: ячейки и их текст. |
| `appearance` | строка | `bordered` | `bordered`, `filled` | bordered: ячейки разделены рамкой; filled: ячейки на тоновой заливке, которые получают рамку, пока код в фокусе. |
| `label` | строка | пусто | — | Видимая подпись; называет группу и поле. |
| `hint` | строка | пусто | — | Текст под ячейками: сколько символов и откуда код. |
| `required` | да/нет | нет | — | Форма требует целый код. |
| `disabled` | да/нет | нет | — | — |
| `readonly` | да/нет | нет | — | — |
| `invalid` | да/нет | нет | — | Код отклонён: ячейки и пояснение окрашены цветом ошибки, у поля aria-invalid. Задаёт и снимает хост. |
| `error-message` | строка | пусто | — | Показывается вместо пояснения, пока поле с ошибкой, и служит aria-errormessage поля. |
| `mask` | да/нет | нет | — | Каждый символ показан точкой; поле становится полем пароля, поэтому экранный диктор не читает код вслух. |
| `value` | строка | пусто | — | Код. Заданный атрибутом, он управляемый: атрибут следует за вводом человека. Приводится к режиму и длине. |
| `aria-label` | строка | пусто | — | Имя группы и поля, когда видимой подписи нет. |
| `error` | да/нет | нет | — | Прежнее имя invalid, по-прежнему действует. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `getInputElement()` | объект или пусто | Возвращает внутренний нативный input или null до отрисовки. |
| `focus(options?: object)` | пусто | Ставит фокус на нативный input. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `input` | `null` | Код изменился при вводе, вставке или автозаполнении; нативное событие всплывает от внутреннего input, который является его целью, со значением, уже приведённым к режиму и длине. detail нет. |
| `change` | `null` | Код сохранён: поле потеряло фокус с кодом, отличным от того, что был при получении фокуса. Отправляется один раз от внутреннего input. detail нет. |
| `sf-input-code-completed` | `{ value: string }` | Факт завершения (стандарт 1.3.8 §8): в каждой ячейке есть символ, после правки человека; один раз на каждый целый код, после его события input. Элемент сам форму не отправляет. |
