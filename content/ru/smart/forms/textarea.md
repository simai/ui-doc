# Многострочное поле

:badge[sf-input-textarea]{variant=tonal scheme=primary size=1/2} :badge[1.7.0]{variant=outline scheme=on-surface size=1/2}

Многострочное поле — для комментариев, описаний и другого свободного текста.
Для короткого значения в одну строку берите [Текстовые
поля](/ru/smart/forms/inputs/).

То же на классах — [Многострочное поле](/ru/components/forms/textarea/):
`<sf-input-textarea>` собирает его разметку из атрибутов.

## Разметка

Полю нужны подпись и имя для формы:

```html
<sf-input-textarea label="Комментарий" name="comment"></sf-input-textarea>
```

`label` — видимая подпись поля, `hint` — постоянное пояснение под ним,
`placeholder` — образец ожидаемого текста. Placeholder исчезает, как только
пользователь начинает печатать, поэтому подпись и подсказку он не заменяет.
`required` ставит звёздочку у подписи и делает обязательным нативное поле.
Вместо строк подсказки и ошибки можно передать разметку в слоты `hint` и
`error`.

`maxlength` и `minlength` ограничивают длину текста средствами браузера;
сообщите ограничение в `hint`, как в примере.

## Варианты

### Вид

`appearance` выбирает вид поля: `bordered` — с рамкой, `filled` — с заливкой,
`flush` — без своего блока, внутри составного элемента.

:::example {id="smart-components/textarea/appearance" label="Поле с рамкой и с заливкой"}
:::

### Без рамки

`appearance="flush"` — поле внутри составного элемента, например строки ввода
сообщения, где рамку, фон, тень и фокус рисует общий блок. У поля нет своей
границы, фона, тени, скругления, боковых отступов, ручки изменения размера и
своего кольца фокуса — ни при наведении, ни при нажатии, ни при фокусе с
клавиатуры. Текст остаётся на размерной шкале: отступ сверху и снизу равен
отступу поля с рамкой вместе с её линией, поэтому одна строка равна высоте
`sf-input` или `sf-button` того же размера, а каждая следующая добавляет
высоту строки этого размера. `auto-grow`, `min-rows` и `max-rows` работают как
у других видов.

Фокус показывает составной блок через `:has(:focus-visible)` — поле само его
не рисует, как в примере. Назовите поле: `label` или `aria-label`. В режиме
высокой контрастности поле сохраняет системный контур фокуса.

:::example {id="smart-components/textarea/flush" label="Поле без рамки в строке ввода сообщения"}
:::

### Размер

`size` выбирает ступень размерной шкалы: `1/2`, `1` или `2`; берите ступень
остальных полей формы.

:::example {id="smart-components/textarea/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Изменение размера

`rows` задаёт начальную высоту в строках, по умолчанию три. Пользователь
может растянуть поле по вертикали.

:::example {id="smart-components/textarea/rows" label="Поля в две и в шесть строк"}
:::

### Высота по тексту

`auto-grow` делает высоту поля равной его тексту: поле начинается с
`min-rows` строк (по умолчанию одна), растёт по строке и после `max-rows`
остаётся этой высоты и прокручивается внутри. Без `max-rows` предела нет;
`max-rows` меньше `min-rows` считается равным `min-rows`. При удалении текста
поле уменьшается. `rows` с `auto-grow` не действует, и поле не растягивают
вручную. Одна строка равна высоте `sf-input` или `sf-button` того же размера.
`Enter` переносит строку: отправка по `Enter` — поведение окна чата, а не поля.

:::example {id="smart-components/textarea/auto-grow" label="Поле по высоте текста"}
:::

## Поведение

### Значение в форме и события

Внутри `<sf-input-textarea>` лежит обычный `<textarea>` с переданным `name`, поэтому
текст попадает в `FormData` и отправку формы, а браузер проверяет `required`
и длину перед отправкой. Свойство `value` элемента читает и задаёт текущий
текст.

`input` приходит при каждом изменении текста, `change` — когда пользователь
покинул изменённое поле. Оба — нативные события внутреннего `<textarea>`,
всплывают через `<sf-input-textarea>`, `detail` у них нет; текст читайте из
`event.target.value`.

```js
const comment = document.querySelector('sf-textarea[name="comment"]');
comment.addEventListener('input', (event) => {
  counter.textContent = `${event.target.value.length} из 500`;
});
comment.value = 'Черновик ответа';
```

### Фокус из кода

`focus()` на самом `<sf-input-textarea>` переводит фокус во внутреннее поле; отдельно
искать его не нужно.

## Доступность

- Задайте видимую подпись в `label`: она связана с полем и даёт ему доступное
  имя. Один `placeholder` имени не даёт.
- Подсказка и сообщение об ошибке связаны с полем через `aria-describedby`;
  при `invalid` поле получает `aria-invalid` и `aria-errormessage`.
- Поле — обычная остановка `Tab`; `Enter` переносит строку, а не отправляет
  форму.

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `setState(nextState: object)` | да/нет | Применяет disabled, error или invalid, errorMessage и value к внутреннему textarea и заново синхронизирует семантику поля; установка value отправляет input. Возвращает false, если textarea не отрисован. |
| `resetToInherited()` | да/нет | Возвращает поле к унаследованному значению, как кнопка сброса: отправляет отменяемое `sf-field-reset`, очищает своё значение и ставит фокус в поле. Возвращает `false`, если сбрасывать нечего, поле недоступно или только для чтения, или событие отменили. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `null` | Значение принято — человек ушёл из поля. |
| `input` | `null` | Значение меняется по мере ввода. |
| `sf-field-reset` | `{ tag: string, value: string, inheritedValue: string, name: string }` | Человек нажал «сбросить к наследуемому». Это событие общее для всех таких полей: форма слышит их сразу и различает по `detail.tag`. Приходит до очистки; `preventDefault()` сохраняет значение. Иначе поле очищается, присылает обычный `change`, снова показывает наследуемое значение и получает фокус. |
