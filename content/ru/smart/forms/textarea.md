# Многострочное поле

:badge[sf-input-textarea]{variant=tonal scheme=primary size=1/2} :badge[1.7.5]{variant=outline scheme=on-surface size=1/2}

Многострочное поле принимает свободный текст в несколько строк: комментарий,
описание задачи, отзыв, сообщение. Подпись, подсказка и сообщение об ошибке
устроены как у [текстового поля](/ru/smart/forms/inputs/).

То же на классах — [Многострочное поле](/ru/components/forms/textarea/): для
статической разметки без JavaScript.

## Пример

Заполните обращение и нажмите «Отправить». Слишком короткое описание покажет
ошибку; допишите текст и выйдите из поля — ошибка уйдёт. Журнал под примером
показывает события и отправленные значения.

:::example {id="smart-components/textarea/overview" label="Обращение" preview=sandbox log_console=true log_open=false}
:::

Полю нужны подпись и имя для формы:

```html
<sf-input-textarea label="Что случилось" name="details" rows="4"></sf-input-textarea>
```

## Когда брать

- **Свободный текст длиннее одной строки**: комментарий, описание, отзыв,
  сопроводительное письмо.
- **Строка ввода сообщения**, которая растёт по тексту, — вид `flush` внутри
  своего блока, см. [Строка ввода сообщения](#строка-ввода-сообщения).

## Когда не брать

- **Значение в одну строку**: имя, почта, тема — [Текстовое
  поле](/ru/smart/forms/inputs/).
- **Текст с заголовками, списками и ссылками** — [Форматированный
  текст](/ru/smart/forms/rich-text/).

## Частые задачи

### Длина текста

`minlength`, `maxlength` • [справочник](#атрибуты)

Ограничения длины проверяет браузер: больше `maxlength` символов ввести
нельзя, короче `minlength` — форма не отправится. Назовите ограничение в
подсказке, как в [примере](#пример): человек должен знать его до ошибки.

### Высота по тексту

`auto-grow`, `min-rows`, `max-rows` • по умолчанию `min-rows="1"` • [справочник](#атрибуты)

Поле по высоте текста не занимает места, пока текста мало, и растёт по
строке. После `max-rows` строк оно остаётся этой высоты и прокручивается
внутри; при удалении текста уменьшается. Напечатайте в первом поле несколько
строк.

:::example {id="smart-components/textarea/auto-grow" label="Высота по тексту" preview=inline}
:::

Одна строка равна высоте текстового поля и кнопки того же размера. `rows` с
`auto-grow` не действует, и поле не растягивают вручную. `Enter` переносит
строку: отправка по `Enter` — поведение окна чата, а не поля.

### Строка ввода сообщения

`appearance="flush"` • [справочник](#атрибуты)

Поле без своей рамки встраивают в общий блок с кнопкой отправки: рамку, фон
и выделение фокуса рисует блок, а поле занимает всю его ширину и растёт по
тексту.

:::example {id="smart-components/textarea/flush" label="Строка сообщения"}
:::

Блок примера — своя разметка страницы: поле в обёртке, которая забирает
свободную ширину, и кнопка рядом. Фокус блок показывает, когда фокус внутри
него, — поле само рамку фокуса не рисует. Назовите поле через `label` или
`aria-label`, как в примере.

### Наследуемое значение

`inherited-value`, `inherited-text`, `reset-label` • [справочник](#атрибуты)

Наследуемый текст действует, пока у поля нет своего: подпись из настроек
сайта, текст родительского раздела. Он виден в пустом поле цветом подсказки
с меткой «наследуется», но не уходит с формой. Напишите свою подпись и
нажмите кнопку сброса — поле вернётся к наследуемой.

:::example {id="smart-components/textarea/inherited" label="Подпись" preview=sandbox log_console=true log_open=false}
:::

## Внешний вид

### Вид

`appearance` • по умолчанию `bordered` • [справочник](#атрибуты)

Поле с рамкой — вид по умолчанию. Заливка — только для поиска и фильтров
над таблицей; когда что брать, — в руководстве
[Формы: фон и группировка](/ru/guide/colour/forms/#какое-поле-брать).

:::example {id="smart-components/textarea/appearance" label="Виды" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `bordered` | любая форма, на любом месте — вид по умолчанию |
| `filled` | только поиск и фильтры над таблицей или списком, на белом месте; с рамкой в одной форме не смешивают |
| `flush` | поле внутри своего блока, например [строки ввода сообщения](#строка-ввода-сообщения) |

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

Размер берите тот же, что у остальных полей формы: отступы и текст поля
совпадают с текстовым полем того же размера.

:::example {id="smart-components/textarea/sizes" label="Размеры" preview=inline}
:::

### Высота

`rows` • по умолчанию `3` • [справочник](#атрибуты)

Высота в строках подсказывает, сколько текста ждут: две строки — коротко,
шесть — подробно. Человек может растянуть поле по вертикали.

:::example {id="smart-components/textarea/rows" label="Две и шесть строк" preview=inline}
:::

### Недоступно

`disabled` • [справочник](#атрибуты)

Недоступное поле нельзя изменить, и оно не уходит с формой.

### Только чтение

`readonly` • [справочник](#атрибуты)

Текст только для чтения можно выделить и скопировать, и он уходит с формой.

### Ошибка

`invalid`, `error-message` • [справочник](#атрибуты)

Ошибка показывает, что текст надо исправить: сообщение встаёт на место
подсказки и связывается с полем. Ошибку ставит и снимает страница, как в
[примере](#пример).

## Работа из кода

### Значение и события

`value` • [справочник](#события)

Внутри `<sf-input-textarea>` лежит обычный `<textarea>` с переданным `name`,
поэтому текст попадает в `FormData` и отправку формы, а браузер проверяет
`required` и длину перед отправкой. Свойство `value` элемента читает и
задаёт текущий текст.

| Событие | Когда приходит |
|:---|:---|
| `input` | при каждом изменении текста |
| `change` | текст принят: человек ушёл из изменённого поля |
| `sf-field-reset` | человек нажал сброс к наследуемому тексту |

`input` и `change` — события самого поля, они всплывают через
`<sf-input-textarea>`; `detail` у них нет, текст читайте из
`event.target.value`. События видны в журнале под [примером](#пример).

```js
const details = document.querySelector('sf-input-textarea[name="details"]');
details.addEventListener('change', (event) => {
  saveDraft(event.target.value);
});
details.focus();
```

`focus()` на самом `<sf-input-textarea>` переводит фокус в поле — искать
внутренний `<textarea>` не нужно.

## Доступность

- Задайте видимую подпись в `label`: она связана с полем и даёт ему имя.
  Один `placeholder` имени не даёт; без видимой подписи задайте `aria-label`.
- Подсказка и сообщение об ошибке связаны с полем через `aria-describedby`;
  при `invalid` поле получает `aria-invalid` и `aria-errormessage`.
- Поле — обычная остановка `Tab`; `Enter` переносит строку, а не отправляет
  форму.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/2`, `1`, `2` | Ступень линейки, на которой стоит поле: размер текста, боковое поле и высота строки — как у `sf-input` того же размера. |
| `appearance` | строка | `bordered` | `bordered`, `filled`, `flush` | Вид поля: блок с рамкой, с заливкой или `flush` — без своего блока, внутри составного элемента, который сам рисует блок и фокус. |
| `label` | строка | пусто | — | Видимая подпись над полем; она же имя поля. Без неё задайте `aria-label`. |
| `required` | да/нет | нет | — | Поле должно быть заполнено: у подписи отметка обязательности, у поля — ограничение `required`. |
| `placeholder` | строка | пусто | — | Пример текста в пустом поле тихим цветом; исчезает с первым символом и подписью не служит. |
| `autocomplete` | строка | пусто | — | Подсказка автозаполнения для браузера, как `autocomplete` (email, tel, current-password, off). Пусто — не пишется. |
| `inputmode` | строка | пусто | пусто, `none`, `text`, `tel`, `url`, `email`, `numeric`, `decimal`, `search` | Какую клавиатуру откроет телефон, как `inputmode` браузера (numeric, decimal, tel, email, url, search). Пусто — клавиатура по типу поля. |
| `minlength` | число | — | — | Наименьшее число символов текста, как `minlength` браузера; более короткий текст неверен. Не задано — без ограничения. |
| `maxlength` | число | — | — | Наибольшее число символов текста, как `maxlength` браузера: больше поле не примет. Не задано — без ограничения. |
| `spell-check` | да/нет | да | — | Проверяет ли браузер орфографию, как `spellcheck`. По умолчанию да; для кодов и идентификаторов выключайте. |
| `wrap` | строка | `soft` | `soft`, `hard` | Как отправляется текст: `soft` — как набран; `hard` — ещё и с переносами строк, которые поле рисует по своей ширине, как `wrap` браузера. |
| `hint` | строка | пусто | — | Строка подсказки под полем; при ошибке на её месте сообщение об ошибке. |
| `name` | строка | пусто | — | Имя, под которым значение уходит с формой, как `name` браузера. |
| `rows` | число | `3` | — | Сколько строк текста видно в поле; более длинный текст прокручивается внутри. С `auto-grow` не действует. |
| `auto-grow` | да/нет | нет | — | Поле растёт по тексту между min-rows и max-rows, а после max-rows прокручивается внутри. Где поддерживается, работает CSS field-sizing, в остальных браузерах — запасной скрипт; rows при этом не учитывается. |
| `min-rows` | число | `1` | — | С auto-grow: наименьшее число строк в поле. Одна строка — высота поля ввода того же размера. |
| `max-rows` | число | — | — | С auto-grow: наибольшее число строк, после которого поле прокручивается внутри. Не задано — без предела; значение меньше min-rows считается равным min-rows. |
| `disabled` | да/нет | нет | — | Поле не принимает ввод и фокус и не уходит с формой; выглядит недоступным. |
| `readonly` | да/нет | нет | — | Значение можно прочитать, выделить и скопировать, но не изменить; оно уходит с формой. Вместо рамки поля — линия области. |
| `invalid` | да/нет | нет | — | Отмечает значение как неверное: рамка ошибки, `aria-invalid` у поля и `error-message` под ним. |
| `error-message` | строка | пусто | — | Текст под полем, пока значение неверно, цветом ошибки, вместо подсказки; для вспомогательных технологий — сообщение об ошибке поля. |
| `mask` | да/нет | нет | — | Включает маску ввода: набор держится `mask-pattern` (или `mask-options`), постоянные символы рисует маска. |
| `mask-pattern` | строка | пусто | — | Маска при включённом `mask`: `0` — цифра, `a` — буква, `*` — любой символ, `{...}` — постоянная часть, которая остаётся в значении, `[ ]` — необязательный хвост, `\` экранирует следующий символ; остальные символы только показываются. Пример: `+{7} (000) 000-00-00`. |
| `mask-options` | строка | пусто | — | Полная настройка маски в JSON — для того, что не выразить `mask-pattern`; важнее `mask-pattern`. Неверный JSON не учитывается. |
| `value` | строка | пусто | — | Текущий текст. Если его пишет страница, она управляет полем; свойство `value` читает набранное. |
| `aria-label` | строка | пусто | — | Имя поля для экранного диктора, когда видимой подписи нет; ставится на само поле. Видимая подпись важнее. |
| `aria-labelledby` | строка | пусто | — | `id` элементов, которые называют поле; ставится на само поле. |
| `inherited-value` | строка | пусто | — | Значение, к которому поле возвращается, пока у него нет своего. Показано как наследуемое — цветом подсказки и с меткой «наследуется» под полем, никогда как значение: значение формы остаётся пустым. Когда у поля появилось своё значение, кнопка сброса возвращает сюда. |
| `inherited-text` | строка | пусто | — | Слова метки, которая видна, пока действует наследуемое значение. Если не задано — на языке страницы («наследуется», «inherited»). |
| `reset-label` | строка | пусто | — | Доступное имя кнопки, которая возвращает поле к наследуемому значению. Если не задано — на языке страницы («Сбросить к наследуемому», «Reset to inherited»). |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `setState(nextState: object)` | да/нет | Применяет disabled, error или invalid, errorMessage и value к внутреннему textarea и заново синхронизирует семантику поля; установка value отправляет input. Возвращает false, если textarea не отрисован. |
| `resetToInherited()` | да/нет | Возвращает поле к унаследованному значению, как кнопка сброса: отправляет отменяемое `sf-field-reset`, очищает своё значение и ставит фокус в поле. Возвращает `false`, если сбрасывать нечего, поле недоступно или только для чтения, или событие отменили. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `null` | Значение принято — человек ушёл из поля. |
| `input` | `null` | Значение меняется по мере ввода. |
| `sf-field-reset` | `{ tag: string, value: string, inheritedValue: string, name: string }` | Человек нажал «сбросить к наследуемому». Это событие общее для всех таких полей: форма слышит их сразу и различает по `detail.tag`. Приходит до очистки; `preventDefault()` сохраняет значение. Иначе поле очищается, присылает обычный `change`, снова показывает наследуемое значение и получает фокус. |
