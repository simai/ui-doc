# Текстовые поля

:badge[sf-input]{variant=tonal scheme=primary size=1/2} :badge[1.6.0]{variant=outline scheme=on-surface size=1/2}

Текстовое поле принимает одну строку — текст, почту, пароль, поиск, телефон
или адрес — вместе с подписью, подсказкой и сообщением об ошибке. Для
многострочного текста берите [Многострочное поле](/ru/smart/forms/textarea/),
для даты — [Календарь](/ru/smart/forms/datepicker/).

То же на классах — [Текстовые поля](/ru/components/forms/inputs/):
`<sf-input>` собирает разметку поля ввода из атрибутов.

## Разметка

Полю нужны подпись и имя для формы:

```html
<sf-input label="Город" name="city"></sf-input>
```

`label` — видимая подпись и доступное имя поля, `hint` — постоянное
пояснение под ним, `placeholder` — образец формата внутри пустого поля.
Placeholder исчезает после ввода, поэтому подпись он не заменяет. `required`
ставит звёздочку у подписи и делает обязательным нативное поле. В компактной
панели подпись можно скрыть только визуально, оставив её в дереве
доступности. Вместо строк подсказки и ошибки можно передать разметку в слоты
`hint` и `error`.

Если подпись выводит сама страница — например, панель записи печатает её
рядом с полем, — не задавайте `label`, а передайте `aria-label`. Имя попадёт
на нативное поле, которое читают вспомогательные технологии, и подпись не
напечатается дважды. При видимой подписи `aria-label` не действует: имя поля
не расходится с тем, что написано на странице.

```html
<sf-input aria-label="Артикул" name="sku"></sf-input>
```

Места для [знака «?»](/ru/smart/feedback/help-mark/) в строке
подписи у `<sf-input>` нет. Поле с пояснением к подписи собирают на классах —
см. [Текстовые поля → Поле с пояснением к подписи](/ru/components/forms/inputs/#поле-с-пояснением-к-подписи).

## Варианты

### Вид

`appearance` выбирает вид: `bordered` — с рамкой, `filled` — с заливкой.
`appearance="hidden"` выводит только скрытое поле формы без подписи и рамки —
для значения, которое пользователь не видит.

:::example {id="smart-components/inputs/appearance" label="Поле с рамкой и с заливкой"}
:::

### Размер

`size` выбирает ступень размерной шкалы: `1/2`, `1` или `2`.

:::example {id="smart-components/inputs/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Тип значения

`input-type` выбирает тип нативного поля: `text`, `email`, `password`,
`search`, `tel` или `url`. Вместе с `autocomplete` и `inputmode` он подсказывает
браузеру автозаполнение и нужную экранную клавиатуру. `minlength`,
`maxlength` и `pattern` переходят на нативное поле, и браузер проверяет их
перед отправкой формы.

:::example {id="smart-components/inputs/types" label="Почта, пароль, телефон и адрес сайта"}
:::

### Состав

`icon-start` ставит значок у логического начала поля, `text-end` — короткий
текст у логического конца, `hint-icon` — значок подсказки в конце рамки.
Логические стороны следуют направлению письма, поэтому та же разметка верна и
справа налево. Своё содержимое передают слоты `start` и `end`; `left-icon` и
`right-text` — другие имена `icon-start` и `text-end`.

:::example {id="smart-components/inputs/composition" label="Значок в начале, текст в конце и значок подсказки"}
:::

### Маска

`mask` включает маску, `mask-pattern` задаёт шаблон, а `mask-options` — полные
настройки JSON. В шаблоне `0` — цифра, `a` — буква, `*` — любой символ, `{…}` —
постоянная часть, которая входит в значение (`+{7}(000)000-00-00`), `\`
экранирует символ, остальные символы только показываются. `mask-lazy="false"`
показывает весь шаблон сразу, `mask-placeholder-char` задаёт символ пустой
позиции; числовая маска — `{"mask": "Number"}`. Подробно грамматика и
настройки числа — на странице [«Текстовые поля»](/ru/components/forms/inputs/#маска).
Маска помогает вводить значение, но не заменяет нативную и серверную проверку.

:::example {id="smart-components/inputs/mask" label="Телефон с маской"}
:::

## Состояния

### Недоступно

`disabled` выключает поле и исключает его из отправки формы.

:::example {id="smart-components/inputs/state-disabled" label="Недоступное поле"}
:::

### Только чтение

`readonly` оставляет значение доступным для чтения и копирования.

:::example {id="smart-components/inputs/state-readonly" label="Поле только для чтения"}
:::

### Ошибка

`invalid` вместе с `error-message` показывает ошибку: сообщение встаёт на
место подсказки и связывается с полем.

Ошибку снимают так же, как ставят: уберите `invalid` (или `error`) либо
вызовите `setState({invalid: false})`. Поле возвращается к обычному виду
целиком — уходят рамка ошибки, сообщение и `aria-invalid`.

## Поведение

### Значение в форме и события

Внутри `<sf-input>` лежит обычный `<input>` с переданным `name`, поэтому
значение попадает в `FormData` и отправку формы. Атрибут `value` задаёт
значение, которым управляет страница: при перерисовке поле показывает его.
`default-value` задаёт только начальное значение, дальше поле хранит то, что
ввёл пользователь. Свойство `value` элемента читает и задаёт текущее значение.

`input` приходит при каждом изменении во время ввода, `change` — когда
значение зафиксировано. Оба — нативные события внутреннего поля, всплывают
через `<sf-input>`, `detail` у них нет; значение читайте из
`event.target.value`. `focus()` на самом `<sf-input>` переводит фокус во
внутреннее поле; `getInputElement()` возвращает этот `<input>`, если нужны его
собственные методы.

```js
const email = document.querySelector('sf-input[name="email"]');
email.addEventListener('change', (event) => {
  const valid = event.target.checkValidity();
  email.toggleAttribute('invalid', !valid);
  email.setAttribute('error-message', valid ? '' : 'Проверьте адрес почты');
});
email.focus();
```

## Доступность

- Задайте видимую подпись в `label`: она связана с полем и даёт ему доступное
  имя. Один `placeholder` имени не даёт. Если подпись выводит страница,
  передайте `aria-label`.
- Подсказка и сообщение об ошибке связаны с полем через `aria-describedby`;
  при `invalid` поле получает `aria-invalid` и `aria-errormessage`, а без него
  `aria-invalid` снимается.
- Значки у краёв поля декоративные: смысл, который они несут, повторите в
  подписи или подсказке.
- Поле — обычная остановка `Tab` с нативным редактированием текста; видимый
  фокус сохраняется при клавиатурной навигации.

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `getInputElement()` | объект или пусто | Возвращает поле ввода внутри тега или `null`, пока оно не нарисовано. |
| `onInput(handler: function, options?: object\|boolean)` | объект | Подписывает на `input` у тега. Возвращает тег. |
| `onChange(handler: function, options?: object\|boolean)` | объект | Подписывает на `change` у тега. Возвращает тег. |
| `onKeyUp(handler: function, options?: object\|boolean)` | объект | Подписывает на `keyup` у тега. Возвращает тег. |
| `onKeyDown(handler: function, options?: object\|boolean)` | объект | Подписывает на `keydown` у тега. Возвращает тег. |
| `onFocus(handler: function, options?: object\|boolean)` | объект | Подписывает на `focusin` у тега. Возвращает тег. |
| `onBlur(handler: function, options?: object\|boolean)` | объект | Подписывает на `focusout` у тега. Возвращает тег. |
| `resetToInherited()` | да/нет | Возвращает поле к унаследованному значению, как кнопка сброса: отправляет отменяемое `sf-field-reset`, очищает своё значение и ставит фокус в поле. Возвращает `false`, если сбрасывать нечего, поле недоступно или только для чтения, или событие отменили. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `null` | Значение принято — человек ушёл из поля; `detail` нет. |
| `input` | `null` | Значение меняется по мере ввода; `detail` нет. |
| `sf-field-reset` | `{ tag: string, value: string, inheritedValue: string, name: string }` | Человек нажал «сбросить к наследуемому». Это событие общее для всех таких полей: форма слышит их сразу и различает по `detail.tag`. Приходит до очистки; `preventDefault()` сохраняет значение. Иначе поле очищается, присылает обычный `change`, снова показывает наследуемое значение и получает фокус. |
