# Текстовое поле

:badge[sf-input]{variant=tonal scheme=primary size=1/2} :badge[1.7.2]{variant=outline scheme=on-surface size=1/2}

Текстовое поле принимает одну строку — имя, почту, пароль, телефон, адрес
сайта или поисковый запрос — вместе с подписью, подсказкой и сообщением об
ошибке. Значение уходит с формой, как у обычного поля.

То же на классах — [Текстовые поля](/ru/components/forms/inputs/): для
статической разметки без JavaScript.

## Пример

Заполните заявку и нажмите «Записаться». Пустое обязательное поле и неполная
почта покажут ошибку; исправьте значение и выйдите из поля — ошибка уйдёт.
Журнал под примером показывает события и отправленные значения.

:::example {id="smart-components/inputs/overview" label="Заявка" preview=sandbox log_console=true log_open=false}
:::

Полю нужны подпись и имя для формы:

```html
<sf-input label="Рабочая почта" name="email" input-type="email" required></sf-input>
```

## Когда брать

- **Значение в одну строку, которое человек печатает сам**: имя, почта,
  пароль, телефон, адрес сайта, поисковый запрос.
- **Число, которое печатают целиком**: сумма, вес, размер — поле с
  `input-type="number"`, см. [Тип значения](#тип-значения).

## Когда не брать

- **Текст в несколько строк** — [Многострочное поле](/ru/smart/forms/textarea/).
- **Небольшое целое число, которое меняют по шагу**: количество товара,
  гости — [Количество](/ru/smart/forms/quantity/).
- **Выбор из известных вариантов** — [Радиокнопки](/ru/smart/forms/radio/)
  для нескольких видимых, [Выбор из поиска](/ru/smart/forms/lookup/) для
  длинного списка людей или объектов.
- **Дата или время** — [Календарь](/ru/smart/forms/datepicker/).
- **Телефон с выбором страны** — [Код страны](/ru/smart/forms/country-code/).

## Частые задачи

### Подпись и подсказка

`label`, `hint`, `placeholder`, `required`, `aria-label` • [справочник](#атрибуты)

Подпись называет поле и для человека, и для экранного диктора, подсказка под
полем остаётся видна всё время. `placeholder` — образец формата в пустом
поле: он исчезает после ввода, поэтому подпись не заменяет. `required`
ставит звёздочку у подписи и не даёт отправить форму с пустым полем.

:::example {id="smart-components/inputs/label" label="Подпись и поиск" preview=inline}
:::

Если подпись выводит сама страница или поле стоит в панели без подписи, как
поиск в примере, задайте `aria-label`: имя попадёт на поле, которое читает
экранный диктор. При видимой подписи `aria-label` не действует. Вместо строк
подсказки и ошибки можно передать разметку в места `hint` и `error`.

Места для [знака «?»](/ru/smart/feedback/help-mark/) в строке подписи нет.
Поле с пояснением к подписи собирают на классах — см. [Текстовые поля → Поле
с пояснением к подписи](/ru/components/forms/inputs/#поле-с-пояснением-к-подписи).

### Тип значения

`input-type`, `autocomplete`, `inputmode` • по умолчанию `input-type="text"` • [справочник](#атрибуты)

Тип говорит браузеру, что за значение в поле: он проверяет почту и адрес
сайта, прячет пароль, предлагает автозаполнение и нужную экранную клавиатуру.
`minlength`, `maxlength` и `pattern` браузер тоже проверяет перед отправкой
формы.

:::example {id="smart-components/inputs/types" label="Типы значения" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `text` | имя, название, любой текст в строку |
| `email` | почта: браузер проверит адрес, телефон покажет клавиатуру с «@» |
| `password` | пароль: символы скрыты |
| `tel` | телефон: клавиатура с цифрами; формат задаёт [маска](#маска) |
| `url` | адрес сайта: браузер проверит, что он полный |
| `search` | поиск по странице или списку |
| `number` | число, которое печатают целиком: сумма, вес; `min`, `max` и `step` задают границы и шаг |

Для небольшого целого числа, которое удобнее менять кнопками «−» и «+»,
берите [Количество](/ru/smart/forms/quantity/).

### Значок и текст в поле

`icon-start`, `text-end`, `hint-icon` • [справочник](#атрибуты)

Значок в начале подсказывает, что вводить, текст в конце — единицу или
валюту, значок в конце рамки отмечает подсказку. Начало и конец следуют
направлению письма, поэтому та же разметка верна и справа налево. Своё
содержимое передают места `start` и `end`.

:::example {id="smart-components/inputs/composition" label="Значок и текст" preview=inline}
:::

Значки декоративные: смысл, который они несут, повторите в подписи или
подсказке.

### Маска

`mask`, `mask-pattern`, `mask-options` • [справочник](#атрибуты)

Маска помогает набрать значение в нужном формате: телефон, номер документа,
код. Наберите в примере десять цифр — скобки, пробел и дефисы встанут сами.

:::example {id="smart-components/inputs/mask" label="Телефон с маской" preview=sandbox log_console=true log_open=false}
:::

В шаблоне `0` — цифра, `a` — буква, `*` — любой символ, `{…}` — постоянная
часть: `+{7}` в примере. `\` экранирует символ, остальные символы только
показываются. Значение поля хранит номер вместе с форматом —
`+7 (900) 123-45-67`. `mask-lazy="false"` показывает весь шаблон сразу,
`mask-placeholder-char` задаёт символ пустой позиции, `mask-options` —
полные настройки JSON-строкой, например числовая маска `{"mask": "Number"}`.
Грамматика шаблона и настройки числа — на странице [«Текстовые
поля»](/ru/components/forms/inputs/#маска).

Учтите: маска помогает вводить, но не проверяет значение — проверка на
сервере нужна всё равно.

### Наследуемое значение

`inherited-value`, `inherited-text`, `reset-label` • [справочник](#атрибуты)

Наследуемое значение действует, пока у поля нет своего: имя из настроек
сайта, значение родительского раздела. Оно видно в пустом поле цветом
подсказки с меткой «наследуется», но не уходит с формой. Напечатайте своё
имя и нажмите кнопку сброса в конце поля — поле вернётся к наследуемому.

:::example {id="smart-components/inputs/inherited" label="Имя отправителя" preview=sandbox log_console=true log_open=false}
:::

Перед сбросом приходит отменяемое событие `sf-field-reset`; из кода сброс
делает `resetToInherited()`.

## Внешний вид

### Вид

`appearance` • по умолчанию `bordered` • [справочник](#атрибуты)

Поле с рамкой — вид по умолчанию на любом месте и в любой форме. Заливка —
только для поиска и фильтров над таблицей или списком, на белом месте; на
серой области, серой плашке и цветном фоне она сливается с местом. В одной
форме виды не смешивают ([Формы: фон и группировка](/ru/guide/colour/forms/#какое-поле-брать)).

:::example {id="smart-components/inputs/appearance" label="Виды" preview=inline}
:::

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

Размер ставит поле в одну строку с кнопками: поле каждого размера одной
высоты с кнопкой того же размера, как в примере. `1/3` — компактный поиск в панели, `3` —
крупный поиск на главной странице.

:::example {id="smart-components/inputs/sizes" label="Размеры" preview=inline}
:::

### Скругление

`radius` • по умолчанию `default` • [справочник](#атрибуты)

Скругление повторяет кнопки рядом: `rounded` — для поиска рядом с круглыми
кнопками, `square` — для поля, которое стыкуется с другими.

:::example {id="smart-components/inputs/radius" label="Скругление" preview=inline}

### Ошибка

`invalid`, `error-message` • [справочник](#атрибуты)

Ошибка показывает, что значение надо исправить: сообщение встаёт на место
подсказки и связывается с полем. Ошибку ставит и снимает страница. Допишите
адрес в примере и выйдите из поля — ошибка уйдёт.

:::example {id="smart-components/inputs/state-error" label="Почта с ошибкой" preview=sandbox log_console=true log_open=false}
:::

```js
email.addEventListener('change', () => {
  const valid = email.getInputElement().checkValidity();
  email.toggleAttribute('invalid', !valid);
});
```

Поле возвращается к обычному виду целиком — уходят рамка ошибки, сообщение и
`aria-invalid`.

## Работа из кода

### Значение и события

`value`, `default-value` • [справочник](#события)

Внутри `<sf-input>` лежит обычный `<input>` с переданным `name`, поэтому
значение попадает в `FormData` и отправку формы. `value` — значение, которым
управляет страница: при перерисовке поле показывает его. `default-value` —
только начальное значение, дальше поле хранит то, что ввёл человек. Свойство
`value` элемента читает и задаёт текущее значение.

| Событие | Когда приходит |
|:---|:---|
| `input` | при каждом изменении во время ввода |
| `change` | значение принято: человек ушёл из поля |
| `sf-field-reset` | человек нажал сброс к наследуемому значению |

`input` и `change` — события самого поля, они всплывают через `<sf-input>`;
`detail` у них нет, значение читайте из `event.target.value`. События видны в
журнале под [примером](#пример).

```js
const email = document.querySelector('sf-input[name="email"]');
email.addEventListener('change', (event) => {
  console.log(event.target.value);
});
email.focus();
```

`focus()` переводит фокус в поле; `getInputElement()` возвращает сам
`<input>`, если нужны его методы, например `checkValidity()`.

## Доступность

- Задайте видимую подпись в `label`: она связана с полем и даёт ему имя.
  Один `placeholder` имени не даёт. Если подпись выводит страница, передайте
  `aria-label`.
- Подсказка и сообщение об ошибке связаны с полем через `aria-describedby`;
  при `invalid` поле получает `aria-invalid` и `aria-errormessage`, а без него
  `aria-invalid` снимается.
- Значки у краёв поля декоративные: смысл, который они несут, повторите в
  подписи или подсказке.
- Поле — обычная остановка `Tab` с правкой текста как в любом поле; видимый
  фокус сохраняется при работе с клавиатуры.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Ступень линейки высот, на которой стоит поле, — высота `sf-button` и `sf-button-icon` того же размера. `sf-input` знает и крайние ступени `1/3` и `3` (компактный поиск в панели, крупный поиск на главной); остальные поля — `1/2`, `1` и `2`. |
| `radius` | строка | пусто | пусто, `default`, `square`, `rounded` | Скругление поля, как у `radius` кнопки: пусто и `default` — скруглённый квадрат элементов управления, `square` — без скругления, `rounded` — пилюля (поле поиска рядом с круглыми кнопками). `--sf-input-radius` сильнее. |
| `appearance` | строка | `bordered` | `bordered`, `filled`, `hidden` | Вид поля: блок с рамкой, с заливкой или скрытый. |
| `label` | строка | пусто | — | Видимая подпись над полем; она же имя поля. Без неё задайте `aria-label`. |
| `required` | да/нет | нет | — | Поле должно быть заполнено: у подписи отметка обязательности, у поля — ограничение `required`. |
| `placeholder` | строка | пусто | — | Пример текста в пустом поле тихим цветом; исчезает с первым символом и подписью не служит. |
| `input-type` | строка | `text` | `text`, `email`, `password`, `search`, `tel`, `url`, `number` | Вид вводимого текста, как `type` браузера: `text`, `email`, `password` (с кнопкой показа), `search`, `tel`, `url` или `number` (с `min`, `max` и `step`). |
| `autocomplete` | строка | пусто | — | Подсказка автозаполнения для браузера, как `autocomplete` (email, tel, current-password, off). Пусто — не пишется. |
| `inputmode` | строка | пусто | пусто, `none`, `text`, `tel`, `url`, `email`, `numeric`, `decimal`, `search` | Какую клавиатуру откроет телефон, как `inputmode` браузера (numeric, decimal, tel, email, url, search). Пусто — клавиатура по типу поля. |
| `minlength` | строка | пусто | — | Наименьшее число символов значения, как `minlength` браузера; более короткое значение неверно. Пусто — без ограничения. |
| `maxlength` | строка | пусто | — | Наибольшее число символов значения, как `maxlength` браузера: больше поле не примет. Пусто — без ограничения. |
| `pattern` | строка | пусто | — | Регулярное выражение, которому должно соответствовать всё значение, как у `pattern` браузера; несовпадающее значение неверно. |
| `min` | строка | пусто | — | Наименьшее число в числовом поле (`input-type="number"`); число меньше — ошибка. Для других типов не действует. |
| `max` | строка | пусто | — | Наибольшее число в числовом поле (`input-type="number"`); число больше — ошибка. Для других типов не действует. |
| `step` | строка | пусто | — | Шаг числового поля: по умолчанию `1`, `any` — любое число; число не по шагу — ошибка. Для других типов не действует. |
| `hint` | строка | пусто | — | Строка подсказки под полем; при ошибке на её месте сообщение об ошибке. |
| `default-value` | строка | пусто | — | Значение, с которым поле начинает и к которому возвращается при сбросе формы, не управляя им потом. Пусто — берётся `value`. |
| `name` | строка | пусто | — | Имя, под которым значение уходит с формой, как `name` браузера. |
| `icon-start` | строка | пусто | — | Значок в начале поля перед значением (лупа, конверт). Пусто — значка нет. |
| `text-end` | строка | пусто | — | Короткий текст в конце поля после значения: единица или валюта (кг, ₽, %). Пусто — текста нет. |
| `shortcut` | строка | пусто | — | Сочетание клавиш в конце поля мягкими клавишами в приглушённом цвете: слова через `+`, например `mod+k` (⌘K на Mac, Ctrl K на других системах), `shift+mod+p`, `/` или `escape`; `mod` — Cmd на Apple и Ctrl на остальных. Клавиши на шаг текста меньше значения. Записывается в `aria-keyshortcuts` поля. Только подсказка: поле само клавиши не слушает. Пусто — без клавиш. |
| `hint-icon` | строка | пусто | — | Значок-подсказка в конце поля (info, help). Пусто — значка нет. |
| `disabled` | да/нет | нет | — | Поле не принимает ввод и фокус и не уходит с формой; выглядит недоступным. |
| `readonly` | да/нет | нет | — | Значение можно прочитать, выделить и скопировать, но не изменить; оно уходит с формой. Вместо рамки поля — линия области. |
| `invalid` | да/нет | нет | — | Отмечает значение как неверное: рамка ошибки, `aria-invalid` у поля и `error-message` под ним. |
| `error-message` | строка | пусто | — | Текст под полем, пока значение неверно, цветом ошибки, вместо подсказки; для вспомогательных технологий — сообщение об ошибке поля. |
| `mask` | да/нет | нет | — | Включает маску ввода: набор держится `mask-pattern` (или `mask-options`), постоянные символы рисует маска. |
| `mask-pattern` | строка | пусто | — | Маска при включённом `mask`: `0` — цифра, `a` — буква, `*` — любой символ, `{...}` — постоянная часть, которая остаётся в значении, `[ ]` — необязательный хвост, `\` экранирует следующий символ; остальные символы только показываются. Пример: `+{7} (000) 000-00-00`. |
| `mask-lazy` | строка | пусто | — | При маске: `true` (или пусто) показывает постоянные символы только по мере набора, `false` — всю маску с символами-заполнителями сразу. |
| `mask-placeholder-char` | строка | пусто | — | При маске и `mask-lazy` false: символ на месте ещё не набранной позиции. Пусто — символ маски, `_`. |
| `mask-options` | строка | пусто | — | Полная настройка маски в JSON — для того, что не выразить `mask-pattern`; важнее `mask-pattern`. Неверный JSON не учитывается. |
| `value` | строка | пусто | — | Текущее значение. Если его пишет страница, она управляет полем; свойство `value` читает набранное. |
| `aria-label` | строка | пусто | — | Название поля для экранного диктора, если видимой подписи нет. |
| `inherited-value` | строка | пусто | — | Значение, к которому поле возвращается, пока у него нет своего, — значение по умолчанию из родительской настройки, бренда, темы. Показано как наследуемое — цветом подсказки и с меткой «наследуется», никогда как значение: значение формы остаётся пустым. Когда у поля появилось своё значение, кнопка сброса возвращает сюда. Числовое поле — это sf-input с inputmode numeric или decimal, оно принимает атрибут так же. |
| `inherited-text` | строка | пусто | — | Слова метки, которая видна, пока действует наследуемое значение. Если не задано — на языке страницы («наследуется», «inherited»). |
| `reset-label` | строка | пусто | — | Доступное имя кнопки, которая возвращает поле к наследуемому значению. Если не задано — на языке страницы («Сбросить к наследуемому», «Reset to inherited»). |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `getInputElement()` | объект или пусто | Возвращает поле ввода внутри тега или `null`, пока оно не нарисовано. |
| `onInput(handler: function, options?: object\|boolean)` | объект | Подписывает на `input` у тега. Возвращает тег. |
| `onChange(handler: function, options?: object\|boolean)` | объект | Подписывает на `change` у тега. Возвращает тег. |
| `onKeyUp(handler: function, options?: object\|boolean)` | объект | Подписывает на `keyup` у тега. Возвращает тег. |
| `onKeyDown(handler: function, options?: object\|boolean)` | объект | Подписывает на `keydown` у тега. Возвращает тег. |
| `onFocus(handler: function, options?: object\|boolean)` | объект | Подписывает на `focusin` у тега. Возвращает тег. |
| `onBlur(handler: function, options?: object\|boolean)` | объект | Подписывает на `focusout` у тега. Возвращает тег. |
| `resetToInherited()` | да/нет | Возвращает поле к унаследованному значению, как кнопка сброса: отправляет отменяемое `sf-field-reset`, очищает своё значение и ставит фокус в поле. Возвращает `false`, если сбрасывать нечего, поле недоступно или только для чтения, или событие отменили. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `null` | Значение принято — человек ушёл из поля; `detail` нет. |
| `input` | `null` | Значение меняется по мере ввода; `detail` нет. |
| `sf-field-reset` | `{ tag: string, value: string, inheritedValue: string, name: string }` | Человек нажал «сбросить к наследуемому». Это событие общее для всех таких полей: форма слышит их сразу и различает по `detail.tag`. Приходит до очистки; `preventDefault()` сохраняет значение. Иначе поле очищается, присылает обычный `change`, снова показывает наследуемое значение и получает фокус. |
