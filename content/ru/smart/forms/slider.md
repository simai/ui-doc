# Слайдер контента

:badge[sf-slider]{type=tonal scheme=primary size=1/2} :badge[1.1.7]{type=outline scheme=on-surface size=1/2}

Слайдер контента показывает слайды по одному: их листают стрелками, точками,
миниатюрами или жестом. Берите его для материалов, которые смотрят по очереди;
то, что нужно сравнить, выкладывайте на странице рядом.

То же на классах — [Слайдер контента](/ru/components/forms/slider/):
`<sf-slider>` собирает разметку слайдера вокруг переданных слайдов и
подключает его поведение.

## Разметка

Каждый непосредственный дочерний элемент с `slot="slide"` становится одним
слайдом:

```html
<sf-slider>
  <article slot="slide">Первый слайд</article>
  <article slot="slide">Второй слайд</article>
</sf-slider>
```

Заголовок, текст и действие одной карточки держите внутри одного такого
элемента. Пробелы и комментарии между элементами слайдами не становятся.
`slide-class` добавляет утилиты обёртке каждого слайда.

## Варианты

### Положение навигации

`root-class="sf-slider--content"` ставит стрелки и точки в поток под
слайдами — для текста и карточек. Без этого класса навигация лежит поверх
слайдов, что подходит изображениям.

:::

### Стрелки

`arrows` и `dots` включают стрелки и точки; оба включены по умолчанию.
`button-type` выбирает вид стрелок — `primary`, `secondary`, `dark` или
`light`, `button-size` — их размер.

`dots-type` задаёт вид точек.

### Размер точек

`dots-size` задаёт размер точек.

### Миниатюры

`thumbs` добавляет под слайдами полосу миниатюр: если в слайде есть
изображение или видео, миниатюра показывает его, иначе — копию слайда.
`thumbs-class` и `thumb-class` добавляют утилиты полосе и каждой миниатюре.

:::example {id="components/slider/smart-thumbnails" label="Слайдер с полосой миниатюр"}

### Повтор

`loop` замыкает последовательность.

:::example {id="smart-components/slider/loop" label="Слайдер с краями и по кругу"}
:::

### Оформление

`root-class`, `slide-class`, `thumbs-class` и `thumb-class` принимают утилиты
SIMAI Framework: цветовые роли, отступы и радиусы задавайте ими, без своих стилей.
Изменение только оформления сохраняет текущий слайд и фокус.

## Поведение

### Движение и автопрокрутка

Без `space-between` и `speed` расстояние между слайдами и длительность
перехода берутся из токенов SIMAI Framework; числа в этих атрибутах их
переопределяют. `data-autoplay="true"` на элементе включает автопрокрутку,
`data-autoplay-delay` задаёт паузу в миллисекундах. Автопрокрутка
останавливается, пока фокус внутри слайдера и пока вкладка скрыта. При
системной настройке «уменьшить движение» переход мгновенный, а
автопрокрутка не запускается.

### Управление из кода

`slideNext()` и `slidePrev()` листают вперёд и назад. Смена слайда
отправляет всплывающее событие `sf-slide-change`; в `event.detail`
`activeIndex` — номер текущего слайда, `previousIndex` — прошлого,
`realIndex` — номер слайда без учёта копий, которые добавляет `loop`.
`refresh()` пересчитывает раскладку после изменения размеров контейнера,
`getSlider()` возвращает экземпляр Swiper для настроек, которых нет в
атрибутах.

```js
const slider = document.querySelector('sf-slider');
slider.addEventListener('sf-slide-change', (event) => {
  counter.textContent = `${event.detail.realIndex + 1} из 3`;
});
slider.slideNext();
```

## Доступность

- Дайте слайдеру имя: поместите его в `<section>` с заголовком или
  `aria-labelledby`, чтобы экранный диктор назвал область.
- Стрелки — кнопки в порядке `Tab`. Их доступные имена английские —
  «Previous slide» и «Next slide» — и атрибутом не меняются.
- Слайды вне видимой области недоступны для фокуса и вспомогательных
  технологий: ссылки и кнопки в них не попадают в порядок `Tab`.
- Не прячьте в автопрокрутку единственную копию важных сведений.

## Справочник

Собран из манифеста компонента выпуска `ui-98143c0a0728` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |
| `button-type` | строка | `primary` | — | — |
| `button-size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Размер кнопок со стрелками — размер `sf-icon-button`. |
| `dots` | да/нет | да | — | — |
| `dots-type` | строка | `primary-dark` | `primary-dark`, `primary-light`, `primary`, `light`, `dark`, `clear` | Цвета точек: `primary-dark` (по умолчанию), `primary-light`, `primary` (как `primary-dark`), `light`, `dark`, `clear` (как `light`). |
| `dots-size` | строка | `2` | `1`, `2` | Ступень размера точек. |
| `thumbs` | да/нет | нет | — | — |
| `thumbs-class` | строка | пусто | — | — |
| `thumb-class` | строка | пусто | — | — |
| `arrows` | да/нет | да | — | — |
| `loop` | да/нет | нет | — | — |
| `space-between` | число | `12` | — | — |
| `speed` | число | `450` | — | — |
| `slide-class` | строка | пусто | — | — |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `refresh()` | объект | Заново привязывает слайдер после изменения его слайдов: передаёт data-атрибуты и пересоздаёт Swiper, сохраняя привязанные события. Возвращает элемент. |
| `slideNext()` | объект | Переходит к следующему слайду, как стрелка «вперёд». Возвращает элемент. |
| `slidePrev()` | объект | Переходит к предыдущему слайду, как стрелка «назад». Возвращает элемент. |
| `getSlider()` | объект или пусто | Экземпляр Swiper, на котором построен слайдер, или null до привязки. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `{ activeIndex: number, realIndex: number, previousIndex: number }` | — |
