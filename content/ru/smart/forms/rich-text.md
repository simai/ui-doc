# Форматированный текст

`<sf-input-rich>` — поле формы для текста с оформлением: абзацы, заголовки
второго–четвёртого уровня, полужирный, курсив, ссылки, маркированные и
нумерованные списки и цитаты. Над текстом — панель кнопок, есть отмена и
повтор. Значение поля — HTML из небольшого набора тегов, и ничего сверх него.
Для простого текста без оформления берите
[многострочное поле](/ru/smart/forms/textarea/).

## Разметка

Полю нужны подпись и имя для формы:

```html
<sf-input-rich label="Текст страницы" name="body"></sf-input-rich>
```

`label` — видимая подпись; без неё назовите поле через `aria-label`.
`hint` — строка под полем, `placeholder` виден, пока текста нет. `value` —
HTML из разрешённого набора тегов.

## Варианты

### Вид

`appearance` выбирает вид поля: `bordered` — с рамкой, `filled` — с
заливкой, как у [многострочного поля](/ru/smart/forms/textarea/).

:::example {id="smart-components/rich-text/appearance" label="Поле с рамкой и с заливкой"}
:::

### Размер

`size` выбирает ступень полей формы: `1/2`, `1` или `2`; кнопки панели — на
ступень меньше.

:::example {id="smart-components/rich-text/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Высота

`rows` — сколько строк поле показывает самое меньшее (по умолчанию 6); с
текстом поле растёт. `max-rows` — сколько строк самое большее, дальше текст
прокручивается внутри.

:::example {id="smart-components/rich-text/rows" label="Поле от двух строк и поле от четырёх до восьми строк"}
:::

## Состояния

### Ошибка

`required` требует непустой текст, `invalid` и `error-message` показывают
ошибку под полем.

:::example {id="smart-components/rich-text/state-error" label="Обязательное поле с ошибкой"}
:::

### Только чтение

`readonly` оставляет текст доступным для чтения и выделения; панель
недоступна, значение отправляется с формой.

:::example {id="smart-components/rich-text/state-readonly" label="Поле только для чтения"}
:::

### Недоступно

`disabled` отключает поле целиком и не отправляет его с формой.

:::example {id="smart-components/rich-text/state-disabled" label="Недоступное поле"}
:::

## Поведение

### Значение

Значение — строка HTML из тегов `p`, `h2`, `h3`, `h4`, `strong`, `em`,
`a`, `ul`, `ol`, `li`, `blockquote` и `br`.

- У ссылки остаётся только `href`, и только с адресом `https:`, `mailto:`,
  `tel:` или путём на сайте (`/ru/guide/`). Ссылка с другим адресом
  становится обычным текстом.
- Другие теги снимаются, их текст остаётся; `script`, `style` и похожие
  убираются вместе с содержимым. `b` и `i` становятся `strong` и `em`.
- Текст вне блока попадает в `p`. Пустое поле даёт пустую строку, а не
  `<p></p>`.
- Входящее значение тоже очищается: поле не доверяет тому, что пришло с
  сервера, и показывает только разрешённую разметку.

Сервер всё равно проверяет значение при сохранении: очистка в браузере
защищает человека за экраном, а не хранилище.

:::example {id="smart-components/rich-text/cleaning" label="Значение с лишней разметкой очищено при загрузке"}
:::

### Панель и клавиши

Кнопки панели: абзац и заголовки 2–4, полужирный, курсив, ссылка,
маркированный и нумерованный список, цитата, отмена и повтор.

- `Ctrl`/`Cmd`+`B` и `I` — полужирный и курсив, `Ctrl`/`Cmd`+`K` — ссылка;
- `Ctrl`/`Cmd`+`Z` — отмена, `Ctrl`/`Cmd`+`Shift`+`Z` или `Ctrl`+`Y` —
  повтор;
- ссылку правят в небольшом поле под панелью: `Enter` применяет адрес,
  `Escape` закрывает поле.

Вставка и перетаскивание тоже очищаются: из Word и веб-страниц остаётся
только разрешённое оформление, простой текст делится на абзацы по пустым
строкам.

### Значение в форме и события

Поле участвует в форме как `sf-input-textarea`: `name` и `value` уходят с формой,
`form.reset()` возвращает исходное значение.

- `input` приходит один раз на каждое изменение — ввод, вставку, кнопку
  панели, отмену или повтор — уже после очистки;
- `change` приходит, когда фокус ушёл из поля целиком и значение
  изменилось; переходы между панелью, полем ссылки и текстом уходом не
  считаются;
- значение, заданное из кода, сброс формы и восстановление браузером событий
  не отправляют.

```js
const field = document.querySelector('sf-rich-text[name="body"]');
field.addEventListener('change', () => save(field.value));
```

## Доступность

- Задайте видимую подпись в `label`; без неё назовите поле через
  `aria-label`.
- Панель — одна остановка `Tab`: стрелки, `Home` и `End` ходят по кнопкам,
  следующий `Tab` переводит в текст. `Tab` в тексте уводит из поля, а не
  вставляет табуляцию.
- Кнопки оформления сообщают своё состояние через `aria-pressed`; кнопка,
  которая сейчас не применима (заголовок внутри списка), остаётся
  достижимой и отмечена `aria-disabled`.
- Контраст текста и кнопок — не ниже AA в светлой и тёмной теме.

## Справочник

Собран из манифеста компонента выпуска `ui-e7b79c3a9e05` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |
| `size` | строка | `1` | `1/2`, `1`, `2` | Лестница размеров поля, как у sf-textarea: рамка, отступы и текст того же размера; кнопки панели на ступень ниже. |
| `appearance` | строка | `bordered` | `bordered`, `filled` | Вид поля: блок с рамкой или с заливкой — те же два вида, что у sf-textarea. |
| `label` | строка | пусто | — | Видимое имя поля; оно называет область правки. Без него имя даёт aria-label хоста. |
| `required` | да/нет | нет | — | Форма не отправляется, пока значение пустое (value-missing). |
| `placeholder` | строка | пусто | — | Показывается, пока в поле нет текста; озвучивается как aria-placeholder. |
| `hint` | строка | пусто | — | Строка под полем; она описывает область правки. |
| `name` | строка | пусто | — | Имя, под которым значение уходит с формой. |
| `rows` | число | `6` | — | Наименьшее число строк в области текста; она растёт вместе с текстом. |
| `max-rows` | число | — | — | Наибольшее число строк, после которого текст прокручивается внутри. Не задано — без предела; значение меньше rows считается равным rows. |
| `disabled` | да/нет | нет | — | Не редактируется, не получает фокус и не отправляется с формой; так же действует отключённый fieldset. |
| `readonly` | да/нет | нет | — | Текст читается и выделяется, но не меняется; панель отключена, значение отправляется с формой. |
| `invalid` | да/нет | нет | — | Решение страницы: вид ошибки и aria-invalid, под полем — error-message. |
| `error-message` | строка | пусто | — | Показывается вместо подсказки, пока поле с ошибкой. |
| `value` | строка | пусто | — | HTML из набора p, h2, h3, h4, strong, em, a[href], ul, ol, li, blockquote, br; href только https:, mailto:, tel: или путь на сайте. Очищается при задании и при правке; пустая строка, когда текста нет. |
| `aria-label` | строка | пусто | — | — |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `runCommand(command: string)` | да/нет | Выполняет команду панели над текущим выделением: paragraph, heading-2, heading-3, heading-4, bold, italic, link (открывает поле ссылки), bulleted-list, numbered-list, quote, undo, redo. Результат очищается, попадает в историю отмены и сообщается событием input. Возвращает, выполнена ли команда (false, пока поле отключено или только для чтения). |
| `undo()` | да/нет | Возвращает на одно очищенное состояние назад и сообщает input; false, если отменять нечего. |
| `redo()` | да/нет | Переходит на одно очищенное состояние вперёд и сообщает input; false, если повторять нечего. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `input` | `null` | Текст изменился при правке: ввод, вставка или перетаскивание, команда панели, отмена или повтор; один раз на изменение, после очистки значения. Нативное событие всплывает от области правки, которая является его целью. |
| `change` | `null` | Значение зафиксировано: человек ушёл из поля со значением, отличным от прежнего; нативное Event от области правки, как у textarea при уходе из него. |
