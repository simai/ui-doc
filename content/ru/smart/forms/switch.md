# Переключатель

:badge[sf-switch]{variant=tonal scheme=primary size=1/2} :badge[1.3.0]{variant=outline scheme=on-surface size=1/2}

Переключатель включает или выключает настройку сразу после нажатия. Подпись
называет состояние или возможность — «Уведомления», «Компактный режим», — а не
команду «Включить» или «Выключить»: положение переключателя уже говорит,
включена ли настройка. Если значение уходит с формой только после
подтверждения, берите [Флажок](/ru/smart/forms/checkbox/).

То же на классах — [Переключатель](/ru/components/forms/switch/):
`<sf-switch>` собирает его разметку из атрибутов.

## Разметка

Переключателю нужно название, а для формы — имя и значение:

```html
<sf-switch name="compact" value="on" label="Компактный режим"></sf-switch>
```

- Название обязательно: видимое в `label` или, если подпись выводит страница,
  в `aria-label`. Пояснение задаёт `description`; вместо строк можно передать
  разметку в слоты `label` и `description`.
- Если подпись выводит сама страница — например, панель записи печатает её
  рядом с переключателем, — не задавайте `label`, а передайте `aria-label`:
  имя попадёт на нативный input, и подпись не напечатается дважды. При
  видимой подписи `aria-label` не действует.
- Чтобы значение уходило с формой, задайте `name` и `value`; без `value`
  включённый переключатель отправляет `on`.
- Внутри компонент рисует обычный `<input type="checkbox" role="switch">` с
  этими `name` и `value`; дорожка и бегунок — его оформление.

### Размер

`size` выбирает ступень размерной шкалы: `1/2`, `1` или `2`. Берите ступень

### Состав

`label` называет настройку, `description` поясняет, что она меняет, `help`
выводит рядом с подписью значок с указанным именем; экранный диктор значок не
читает.

## Состояния

### Включён

`checked` включает переключатель. Атрибут следует за положением: после
нажатия он ставится или снимается.

:::example {id="smart-components/switch/state-checked" label="Выключен и включён"}
:::

### Недоступен

`disabled` запрещает менять положение; недоступный переключатель не попадает
в отправку формы.

:::example {id="smart-components/switch/state-disabled" label="Недоступный выключенный и включённый"}
:::

## Поведение

### Значение в форме

Включённый переключатель попадает в `FormData` и отправку формы,
выключенный — нет. Сброс формы возвращает положение, заданное атрибутом
`checked` в разметке.

### Применение настройки и событие `change`

Нажатие отправляет нативное событие `change` внутреннего input; оно
всплывает через `<sf-switch>`, `detail` у него нет. Новое положение читайте из
`event.target.checked` и применяйте настройку сразу.

`setChecked()` и `setDisabled()` меняют положение и доступность из кода,
события `change` при этом нет. Если сохранить настройку не удалось, верните
переключатель в прежнее положение.

```js
const compact = document.querySelector('sf-switch[name="compact"]');
compact.addEventListener('change', async (event) => {
  const enabled = event.target.checked;
  try {
    await saveSetting('compact', enabled);
  } catch {
    compact.setChecked(!enabled);
  }
});
```

## Доступность

- Переключателю нужно название: видимое в `label` или, если подпись выводит
  страница, `aria-label`, который попадает на внутренний input.
- Внутренний input с `role="switch"` сообщает экранному диктору, что это
  переключатель, и его положение — «вкл.» или «выкл.».
- Каждый переключатель — отдельная остановка `Tab`; `Space` меняет положение.
- Бегунок скрыт от вспомогательных технологий: положение передаёт input.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/2`, `1`, `2` | Размер переключателя: чем больше число, тем крупнее. |
| `label` | строка | пусто | — | — |
| `description` | строка | пусто | — | — |
| `help` | строка | пусто | — | — |
| `disabled` | да/нет | нет | — | — |
| `name` | строка | пусто | — | — |
| `value` | строка | `on` | — | Что отправляет включённый переключатель; без значения — "on", как у родного флажка (simai/ui-source#38). |
| `checked` | да/нет | нет | — | — |
| `aria-label` | строка | пусто | — | Доступное имя переключателя без видимой подписи — например, в панели записи, которая сама выводит подпись. |
| `inherited-value` | строка | пусто | — | Включён ли переключатель, пока у него нет своего значения: true/on или false/off. Бегунок стоит в указанном положении, приглушённо, с меткой «наследуется», а флажок ничего не отправляет. Когда атрибут задан, выбранное человеком «выкл.» хранится как checked="false" — собственное значение, — а отсутствие `checked` означает наследуемое состояние; кнопка сброса возвращает к нему. |
| `inherited-text` | строка | пусто | — | Слова метки, которая видна, пока действует наследуемое значение. Если не задано — на языке страницы («наследуется», «inherited»). |
| `reset-label` | строка | пусто | — | Доступное имя кнопки, которая возвращает поле к наследуемому значению. Если не задано — на языке страницы («Сбросить к наследуемому», «Reset to inherited»). |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `getInputElement()` | объект или пусто | Возвращает переключатель внутри тега или `null`, пока он не нарисован. |
| `setChecked(nextValue?: boolean)` | объект | Устанавливает свойство и состояние checked внутреннего input; не отправляет change. |
| `setDisabled(nextValue?: boolean)` | объект | Устанавливает или снимает disabled на теге и внутреннем input. |
| `setState(nextState: object)` | объект | Задаёт `checked` и `disabled`. |
| `onChange(handler: function, options?: object\|boolean)` | объект | Подписывает на `change` радиокнопки. |
| `onFocus(handler: function, options?: object\|boolean)` | объект | Подписывает на `focusin` у тега. |
| `onBlur(handler: function, options?: object\|boolean)` | объект | Подписывает на `focusout` у тега. |
| `resetToInherited()` | да/нет | Возвращает поле к унаследованному значению, как кнопка сброса: отправляет отменяемое `sf-field-reset`, очищает своё значение и ставит фокус в поле. Возвращает `false`, если сбрасывать нечего, поле недоступно или только для чтения, или событие отменили. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `null` | Переключатель включён или выключен. |
| `sf-field-reset` | `{ tag: string, value: string, inheritedValue: string, name: string }` | Человек нажал «сбросить к наследуемому». Это событие общее для всех таких полей: форма слышит их сразу и различает по `detail.tag`. Приходит до очистки; `preventDefault()` сохраняет значение. Иначе поле очищается, присылает обычный `change`, снова показывает наследуемое значение и получает фокус. |
