# Радиокнопки

`<sf-radio>` — радиокнопка: один вариант из группы взаимоисключающих, где
все варианты видны сразу. Для независимых вариантов берите
[Флажок](/ru/smart/forms/checkbox/), для длинного списка —
[Выпадающий список](/ru/smart/navigation/dropdown/).

То же на классах — [Радиокнопки](/ru/components/forms/radio/): `<sf-radio>`
собирает разметку радиокнопки из атрибутов.

## Разметка

Радиокнопке нужны общее для группы имя, своё значение и название:

```html
<sf-radio name="publish" value="now" label="Сейчас"></sf-radio>
```

`label` — видимое название варианта; щелчок по тексту тоже выбирает
вариант. Вместо строк `label` и `description` можно передать разметку в
одноимённые слоты.

## Варианты

### Размер

`size` выбирает ступень размерной шкалы: `1/2`, `1` или `2`.

:::

### Состав

`description` — пояснение под названием. `help` выводит рядом с названием
значок с указанным именем; экранный диктор его не читает.

## Состояния

### Выбрана

`checked` отмечает вариант; отметка одной радиокнопки снимает её с
остальных того же `name`. Атрибут `checked` следует за выбором у всех
радиокнопок группы.

:::example {id="smart-components/radio/state-checked" label="Невыбранная и выбранная"}
:::

### Недоступна

`disabled` выключает вариант.

:::example {id="smart-components/radio/state-disabled" label="Недоступные радиокнопки"}
:::

### Ошибка

`invalid` показывает недопустимое состояние только цветом и ставит
`aria-invalid` на внутреннюю радиокнопку; `error` — прежнее имя этого
атрибута. Текст ошибки разместите у группы.

:::example {id="smart-components/radio/state-error" label="Группа с ошибкой"}
:::

## Поведение

### Группа и значение

Радиокнопки с одинаковым `name` в одной форме составляют группу: отметка
одной снимает отметку с остальных. `value` — машинное значение варианта; при
отправке формы приходит значение отмеченного, а без `value` — `on`, как у
нативной радиокнопки. Общее имя дайте всем вариантам одного вопроса и не
давайте вариантам разных вопросов.

Группу размещайте в `<fieldset>`: общий вопрос пишется в `<legend>`, а не
повторяется в названии каждого варианта. Один вариант отмечайте заранее
атрибутом `checked`, если у вопроса есть разумный ответ по умолчанию.

### Значение в форме

Внутри `<sf-radio>` лежит обычный `<input type="radio">`, поэтому отмеченный
вариант попадает в `FormData` и отправку формы. Сброс формы возвращает
отметку, заданную в разметке.

### Выбор из кода и событие `change`

Выбор пользователем отправляет нативное событие `change` внутренней
радиокнопки; оно всплывает через `<sf-radio>`, `detail` у него нет. Слушайте
его на `<fieldset>` или форме и читайте `event.target.value`.

`setChecked(true)` отмечает вариант из кода, `setDisabled()` выключает его;
событие `change` при этом не отправляется.

```js
const publish = document.querySelector('fieldset');
publish.addEventListener('change', (event) => {
  showSchedule(event.target.value === 'later');
});
document.querySelector('sf-radio[value="draft"]').setChecked(true);
```

## Доступность

- Каждой радиокнопке нужно видимое название в `label`: отдельного
  `aria-label` у компонента нет.
- Группе нужно общее имя — `<legend>` внутри `<fieldset>`.
- Группа — одна остановка `Tab`: фокус приходит на отмеченный вариант или,
  если отмеченного нет, на первый. Стрелки переходят между вариантами и сразу
  выбирают их, `Space` отмечает вариант в фокусе.
- Ошибка показывается только цветом; текст ошибки свяжите с группой через
  `aria-describedby`.

## Справочник

Собран из манифеста компонента выпуска `ui-2d39b617a719` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | — |
| `root-style` | строка | пусто | — | — |
| `size` | строка | `1` | `1/2`, `1`, `2` | Токен размера переключателя (radio). |
| `label` | строка | пусто | — | — |
| `description` | строка | пусто | — | — |
| `help` | строка | пусто | — | — |
| `disabled` | да/нет | нет | — | — |
| `name` | строка | пусто | — | — |
| `value` | строка | `on` | — | Что отправляет выбранная радиокнопка; без значения — "on", как у родной радиокнопки (стандарт 1.3.8 §17.1, пункт 2). |
| `invalid` | да/нет | нет | — | Показанное состояние ошибки: вид ошибки и `aria-invalid` на родном поле ввода. |
| `checked` | да/нет | нет | — | — |
| `error` | да/нет | нет | — | Прежнее имя `invalid`: псевдоним с датой до 2026-12-01 (aliases.json, стандарт 1.3.8 §17.2). |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `getInputElement()` | объект или пусто | Возвращает внутренний нативный input (.sf-radio-button input[type="radio"]) или null до отрисовки. |
| `setChecked(nextValue?: boolean)` | объект | Устанавливает свойство и состояние checked внутреннего input; не отправляет change. |
| `setDisabled(nextValue?: boolean)` | объект | Устанавливает или снимает disabled на хост-элементе и внутреннем input. |
| `setState(nextState: object)` | объект | Применяет checked и disabled к внутреннему input (установка checked также обновляет остальную именованную группу) и отражает их в атрибутах хост-элемента; до отрисовки использует базовый setState. |
| `onChange(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик нативного события change, которое всплывает от внутреннего input. |
| `onFocus(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик focusin на хост-элементе. |
| `onBlur(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик focusout на хост-элементе. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `null` | Выбор изменился; нативное событие всплывает от внутренней радиокнопки, которая является его целью. Имя для привязки. |
