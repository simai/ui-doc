# Генератор темы

:badge[sf-theme-generator]{variant=tonal scheme=primary size=1/2} :badge[1.1.13]{variant=outline scheme=on-surface size=1/2}

Генератор темы строит тему из одного цвета: человек выбирает основной цвет и
сразу видит восемь тональных палитр SIMAI Framework — основную, вторичную,
дополнительную, нейтральную, ошибку, предупреждение, успех и информацию. Из
них получаются тона `--sf-<палитра>-<тон>` и полупрозрачные ступени
`--sf-<палитра>-<тон>--alfa-<ступень>`, на которых держатся цвета интерфейса.
Берите его в настройках сайта или документации, где владелец выбирает
фирменный цвет.

## Разметка

Генератору нужно доступное имя, если рядом нет видимого заголовка, и, при
необходимости, начальный цвет:

```html
<sf-theme-generator aria-label="Цвет темы" value="#2e7d32"></sf-theme-generator>
```

`value` — основной цвет в виде `#rgb` или `#rrggbb`. Без `apply` компонент
на странице ничего не меняет и только сообщает о выборе событиями.

## Поведение

### Цвет, тон и насыщенность

`value` — основной цвет в виде `#rgb` или `#rrggbb`. Пустое значение — цвет
SIMAI Framework `#005bbe` и его собственная тема. Цвет компонент читает в модели HCT
как тон (`hue`, от 0 до 360) и насыщенность (`chroma`, от 0 до 150): по ним
строятся все восемь палитр (см. [Как строятся палитры из одного цвета](/ru/guide/colour/palettes/#как-строятся-палитры-из-одного-цвета)).

Статусные палитры — ошибка, предупреждение, успех и информация — заданы
жёстко и за фирменным цветом не идут:
выбранный цвет двигает основную, вторичную, дополнительную и нейтральную
палитры. Палитра информации — своя палитра цвета `#005bbe`.

`hue` и `chroma` задают поля «Тонкая настройка». Заданные, они важнее
прочтения цвета: хост, который хранит все три значения, получает обратно ту
же тему.
### Применение к странице или участку

Без `apply` компонент на странице ничего не меняет: он только сообщает о
выборе. С `apply` он применяет тему при каждом изменении — пишет 226
переменных во встроенный стиль элемента `target` (CSS-селектор; по
умолчанию корневой элемент документа). Предыдущее применение снимается перед
следующим и при удалении компонента.

Семантические токены (`--sf-primary` и другие) объявлены на классах
`theme-light` и `theme-dark`. Поэтому участок страницы, к которому
применяется тема, тоже несёт такой класс, как в примере: без него на участке
сменятся только примитивы, а роли останутся прочитанными на корне.

Тема пишет и тона, и полупрозрачные ступени тонов
(`--sf-primary-50--alfa-12` и другие), из которых собраны заливки
`*-container` и фоны наведения и выбора, поэтому тональные кнопки и заливки
перекрашиваются вместе с основными.

### Сохранение выбора и события

Компонент ничего не хранит: выбор хранит хост — в настройках сайта или
документации. Он узнаёт о выборе событиями на самом элементе:

| Событие | Когда |
|:---|:---|
| `change` | выбор меняется: перетаскивание в палитре, образец цвета, число в поле |
| `sf-theme-generator-committed` | выбор зафиксирован: `change` палитры, образец цвета, `Enter` или уход из поля, «Сбросить» |

В `detail` обоих — `value` (пусто, пока действует цвет SIMAI Framework), `hue`,
`chroma`, `theme` (объект темы), `variables` (все переменные темы) и `css` —
правило под `selector` (по умолчанию `:root`). Сохраните `css` в CSS сайта —
и тема действует на каждой странице без компонента.

О смене светлой и тёмной темы сообщает другое событие — `sf-theme-change`
загрузчика на `window` (см. [События загрузчика](/ru/guide/connection/loader/#события-загрузчика)).

```js
const generator = document.querySelector('sf-theme-generator');
generator.addEventListener('sf-theme-generator-committed', ({detail}) => {
  saveSiteSetting('theme', {value: detail.value, hue: detail.hue, chroma: detail.chroma, css: detail.css});
});
```

Методы: `toCSS(selector)` — правило темы под селектором, `toJSON()` — объект
темы, `reset()` — вернуться к цвету SIMAI Framework; свойство `theme` — текущий
объект темы.

### Расчёт без компонента

Расчёт — модуль ядра `theme-palette`, опубликованный как `SF.ThemePalette`.
Он приходит на страницу вместе с кодом `<sf-theme-generator>`; на странице без
этого элемента его нет. Сервер или сборка проекта вызывают те же функции из
исходников SIMAI Framework: файл `src/core/js/theme-palette.js` открытого
репозитория [`simai/ui-source`](https://github.com/simai/ui-source) на коммите
исходников выпуска (`build_inputs.source.commit` в записи выпуска). Модуль
зависит только от файлов `material-color-utilities`, которые лежат рядом в
`src/core/js/vendor/`, и в Node.js 20 импортируется напрямую:

```js
import {themeFromColor, themeVariables} from './ui-source/src/core/js/theme-palette.js';

const variables = themeVariables(themeFromColor('#833ab6'));   // 226 пар {имя: значение}
```

Тот же расчёт без модуля описан в [Как построить палитру](/ru/guide/colour/palettes/#как-построить-палитру).

| Функция | Что делает |
|:---|:---|
| `themeFromColor(color, options)` | тема из цвета `#rgb` или `#rrggbb` |
| `themeFromHct({hue, chroma}, options)` | тема из тона и насыщенности; `options[палитра]` — свои `{hue, chroma}` для палитры |
| `colorToHct(color)` | как цвет читается: `{hex, hue, chroma, tone}` |
| `themeVariables(theme)` | переменные темы `{имя: значение}`: тоны и полупрозрачные ступени |
| `themeToCss(theme, selector)` | правило CSS с теми же переменными под селектором, по умолчанию `:root` |
| `applyTheme(theme, target)` | пишет переменные во встроенный стиль `target` и возвращает функцию, которая их снимает |

```js
const theme = SF.ThemePalette.themeFromColor('#2e7d32');
const css = SF.ThemePalette.themeToCss(theme, ':root');
```

`themeToCss()` возвращает правило без слоя. Оно сильнее слоёв SIMAI Framework и
работает как есть; по соглашению проекта его кладут в `@layer project`.

Тема всегда содержит все восемь палитр. Чтобы сменить только акцент, оставьте
из `themeVariables()` переменные `--sf-primary-*`, а остальные не записывайте
(статусные палитры, включая `info`, и так не меняются):

```js
const variables = SF.ThemePalette.themeVariables(theme);
const accent = Object.entries(variables).filter(([name]) => name.startsWith('--sf-primary-'));
const css = `@layer project { :root { ${accent.map(([name, value]) => `${name}: ${value};`).join(' ')} } }`;
```

Модель HCT — из пакета Google `material-color-utilities` 0.4.0 (лицензия
Apache-2.0): нужные модули лежат в исходниках SIMAI Framework без изменений и
перечислены в уведомлениях о стороннем коде поставки.

## Доступность

- Компонент — группа (`role="group"`); назовите её `aria-label`, если рядом
  нет видимого заголовка.
- В порядке `Tab` — выбор цвета, «Сбросить», раскрытие «Тонкая настройка» и
  два числовых поля; `Enter` в поле фиксирует тему.
- Предпросмотр — именованная область из подписанных образцов: у каждого
  названы палитра, тон и значение.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `value` | строка | пусто | — | Основной цвет, #rrggbb; пусто, пока действует собственный цвет SIMAI Framework. |
| `hue` | целое число | — | от 0; до 360 | Собственный тон генератора; если не задан — тон цвета. |
| `chroma` | целое число | — | от 0; до 150 | Собственная насыщенность генератора; если не задана — насыщенность цвета. |
| `size` | строка | `1` | `1/2`, `1`, `2` | — |
| `swatches` | строка | пусто | — | Цвета продукта рядом с палитрой, в том виде, в каком их принимает `sf-color`: `#hex\|Имя, #hex`. |
| `apply` | да/нет | нет | — | Ставить тему на target встроенными переменными при каждом изменении; без этого страница не меняется. |
| `target` | строка | пусто | — | CSS-селектор элемента, к которому применяется тема; пусто — корень документа. |
| `selector` | строка | `:root` | — | Селектор правила в событиях и в `toCSS()`. |
| `aria-label` | строка | пусто | — | — |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `reset()` | объект | Вернуть собственный цвет SIMAI Framework; выбор принят. |
| `toCSS(selector?: string)` | строка | Тема одним правилом таблицы стилей из примитивов и полупрозрачных ступеней — под заданным селектором или селектором из атрибута `selector`. |
| `toJSON()` | объект | Объект темы (`simai.framework.theme` с `schema_version: 1`): тон и насыщенность источника и у каждой палитры её тон, насыщенность и тона. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `{ value: string, hue: number, chroma: number, theme: object, variables: object, css: string }` | Выбор изменился — перетаскивание в палитре, образец, введённое число; имя браузера, тема — в detail. |
| `sf-theme-generator-committed` | `{ value: string, hue: number, chroma: number, theme: object, variables: object, css: string }` | Выбор принят — change палитры, образец, Enter или уход из поля, сброс: тема, которую сохраняет приложение. |
