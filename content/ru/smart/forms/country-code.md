# Код страны

:badge[sf-input-country]{variant=tonal scheme=primary size=1/2} :badge[1.2.0]{variant=outline scheme=on-surface size=1/2}

Код страны — телефонное поле с кнопкой выбора страны: флаг и код страны стоят
перед номером, а маска подстраивается под выбранную страну. Для телефона без
выбора страны хватит [поля ввода](/ru/smart/forms/inputs/) с маской.

То же на классах — [Код страны](/ru/components/forms/country-code/):
`<sf-input-country>` собирает его разметку из атрибутов.

## Разметка

Полю нужна подпись, имя для формы и начальная страна:

```html
<sf-input-country label="Телефон" name="phone" iso2="RU"></sf-input-country>
```

`label` — видимая подпись поля. Без `label` строки подписи нет вовсе, и
пустая строка над полем не остаётся. Если подпись выводит сама страница —
например, панель записи печатает её рядом с полем, — передайте `aria-label`:
имя попадёт на нативное поле номера, и подпись не напечатается дважды. При
видимой подписи `aria-label` не действует. `hint` — пояснение под полем,
`placeholder` — пример номера в пустом поле. `required` делает номер
обязательным.

## Варианты

### Выбор страны

`iso2` задаёт начальную страну двухбуквенным кодом, `dial-code` — телефонным
кодом. По умолчанию пользователь может сменить страну кнопкой с флагом.
`multi-country="false"` оставляет страну фиксированной: список не создаётся,
код остаётся перед номером.

:::example {id="components/country-code/smart-modes" label="Выбор страны и фиксированная страна"}
:::

### Размер

`size` выбирает ступень размерной шкалы: `1/2`, `1` или `2`. Подпись, поле и
подсказка сохраняют одну структуру на всех ступенях.

:::example {id="components/country-code/smart-sizes" label="Размеры 1/2, 1 и 2"}
:::

### Маска

`use-mask="true"` включает маску номера. Маска берётся из данных выбранной
страны и меняется вместе с ней; `use-country-masks="false"` отключает маски
стран, и тогда действует общий шаблон из `mask-pattern`. Маска помогает
вводить номер, но существование номера не проверяет: это задача приложения и
сервера.

:::example {id="smart-components/country-code/masks" label="Без маски, маска страны и общий шаблон"}
:::

### Свой список стран

Свойство `countries` принимает массив объектов с полями `iso2`, `code` или
`dialCode`, `label` и необязательным `maskPattern`. Для известных кодов ISO
пропущенные поля дополняются встроенным справочником. `max-items` ограничивает
число стран в списке. Присваивайте свойство после регистрации элемента —
`await customElements.whenDefined('sf-input-country')`.

:::example {id="components/country-code/smart-countries" label="Список из двух стран"}
:::

### Оформление

`root-class` добавляет корню утилиты SIMAI Framework: поверхность, отступы и радиус
контейнера меняются без своих стилей, а само поле сохраняет системный радиус.

:::example {id="components/country-code/smart-customization" label="Поверхность и отступы контейнера"}

## Поведение

### Значение в форме

Номер хранит обычный `<input type="tel">` с переданными `name`, `form` и
`required`, поэтому он попадает в `FormData`, проходит нативную проверку
обязательности, а сброс формы возвращает исходные номер и страну.

:::example {id="components/country-code/smart-form" label="Поле в форме с проверкой и сбросом"}
:::

### Флаги и язык

Флаг по умолчанию — символ эмодзи страны. `flag-base` задаёт папку с
изображениями флагов: компонент берёт из неё файл `<iso2>.svg`.

Названия стран и собственные подписи поля следуют языку страницы: на
странице с `lang="ru"` — русские, на любой другой — английские. `locale="ru"`
или `locale="en"` задаёт язык явно.

### Состояние из кода и событие `change`

Когда номер или страна зафиксированы, нативное событие `change` внутреннего
поля всплывает через `<sf-input-country>`; `detail` у него нет. Номер
читайте из `event.target.value`, а страну и код — из свойства `state`:
`value`, `iso2`, `dialCode`, `open` и `disabled`.

`setState()` принимает те же поля: `iso2` меняет страну и сохраняет местную
часть номера, `value` заменяет номер, `open` открывает список. Смена номера
или страны из `setState()` тоже отправляет `change`.

```js
const phone = document.querySelector('sf-country-code[name="phone"]');
phone.addEventListener('change', () => {
  const {value, iso2, dialCode} = phone.state;
  savePhone({value, iso2, dialCode});
});
phone.setState({iso2: 'KZ'});
```

## Доступность

- Задайте видимую подпись в `label`: компонент связывает её с полем номера.
  Если подпись выводит страница, передайте `aria-label`.
- Кнопка с флагом открывает список стран с одиночным выбором. Стрелки, `Home`,
  `End` и набор первых букв перемещают по списку, не меняя номер; `Enter` или
  `Space` выбирают страну, `Escape` закрывает список без выбора. В обоих
  случаях фокус возвращается на кнопку.
- `Tab` выходит из компонента и не удерживается в списке. Недоступное поле
  список не открывает.

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `setState(nextState?: object)` | да/нет | Применяет disabled, open (или active), value, iso2 и dialCode к отрисованному полю; установка value отправляет нативные input и change от внутреннего input. Возвращает true, если применено, и false до отрисовки. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `null` | Номер телефона или страна зафиксированы; нативное событие всплывает от внутреннего input, который является его целью. detail не передаётся. Имя для привязки. |
| `input` | `null` | — |
