# Выбор карточками

:badge[sf-input-choice]{variant=tonal scheme=primary size=1/2} :badge[1.1.2]{variant=outline scheme=on-surface size=1/2}

Поле формы, в котором человек выбирает один вариант или несколько из
карточек: у каждой название, пояснение, а если нужно — цена со сроком,
картинка или короткая метка. Берите его, когда вариантов немного и каждый
надо объяснить словами: способ доставки и оплаты, тариф, модули, шаблон
сайта. Все варианты видны сразу и на телефоне встают в столбик.

Вариантов много или пояснения не нужны — [Радиокнопки](/ru/smart/forms/radio/),
[Флажок](/ru/smart/forms/checkbox/) или
[Выпадающий список](/ru/smart/navigation/dropdown/).

## Разметка

Варианты передайте в `items`: свойством, JSON-блоком
`<script type="application/json" data-sf-settings>` внутри тега или
атрибутом с JSON.

```html
<sf-input-choice layout="list" label="Доставка" name="delivery" value="pickup">
  <script type="application/json" data-sf-settings>{"items": [
    {"value": "courier", "label": "Курьером", "caption": "Привезём в удобный интервал", "price": "350 ₽", "term": "2–3 дня"},
    {"value": "pickup", "label": "Пункт выдачи", "caption": "Больше 2 000 пунктов по стране", "price": "150 ₽", "term": "1–2 дня", "badge": "Выгодно"}
  ]}</script>
</sf-input-choice>
```

Поля варианта:

| Поле | | Значение |
|:---|:---|:---|
| `value` | обязательно | Значение, которое уходит с формой. Вариант без значения или с повторным значением пропускается. |
| `label` | | Название на карточке; можно `title`. Без него — значение. |
| `caption` | | Пояснение под названием. |
| `price` | | Цена: в строках — колонкой в конце строки названия, в плитках — внизу карточки за линией. |
| `term` | | Срок или период под ценой: «2–3 дня», «в месяц». |
| `image` | | Адрес картинки для раскладки `picture`. |
| `icon` | | Значок перед названием. |
| `badge` | | Короткая метка рядом с названием: «Выгодно», «Новое». |
| `disabled` | | Эту карточку нельзя выбрать. |

`label` — подпись над карточками, она же имя группы; `hint` — строка под
ними.

## Варианты

### Раскладка

`layout` • по умолчанию `tile` • [справочник](#атрибуты)

Раскладка выбирается по тому, что сравнивают. Нажимается вся карточка, а
отметка выбора — настоящая радиокнопка или флажок на строке названия.

**Строки** (`list`) — для доставки и оплаты: варианты в одной рамке через
линию, отметка в начале строки, цена и срок колонкой в конце. `columns` здесь
не действует.

:::example {id="smart-components/input-choice/layout-list" label="Строки: оплата" preview=sandbox}
:::

**Плитки** (`tile`) — для тарифов и модулей: отметка в правом верхнем углу,
название, пояснение и цена от одного левого края, цена внизу за линией.

:::example {id="smart-components/input-choice/layout-tile" label="Плитки: тариф" preview=sandbox}
:::

**Плитки с картинкой** (`picture`) — для шаблонов и оформления: картинка до
краёв карточки, подпись под ней, отметка в конце строки подписи. В поле уже
30rem (на телефоне) каждая плитка становится строкой с картинкой в начале.

:::example {id="smart-components/input-choice/layout-picture" label="Плитки с картинкой: шаблон сайта" preview=sandbox}
:::

### Один или несколько

`multiple` • по умолчанию выключено • [справочник](#атрибуты)

Без `multiple` выбирается один вариант: карточки работают как радиокнопки.
С `multiple` — несколько: на каждой карточке флажок. Выбранная карточка
отмечена заполненной отметкой и рамкой основного цвета на лёгкой заливке: два
признака, а не только цвет.

:::example {id="smart-components/input-choice/multiple" label="Несколько: модули" preview=sandbox}
:::

### Значок у названия

`icon` у варианта • [справочник](#атрибуты)

Значок помогает узнать вариант с первого взгляда, когда у вариантов нет цены
и картинки: тип сайта, раздел, способ входа. Ставьте значки всем вариантам
поля или никому.

:::example {id="smart-components/input-choice/icons" label="Значки: тип сайта" preview=sandbox}
:::

### Сетка

`columns` • по умолчанию `auto` • [справочник](#атрибуты)

`auto` заполняет ширину карточками не уже `--sf-choice-min-inline-size`
(15rem). Число от `1` до `4` — самое большее столько колонок; если карточка
получилась бы уже этой ширины, колонок меньше. На телефоне карточки встают в
столбик сами.

:::example {id="smart-components/input-choice/columns" label="Сетка auto, 2 и 1" preview=sandbox}
:::

## Состояния

### Ошибка и недоступность

`invalid`, `error-message`, `disabled` • [справочник](#атрибуты)

`invalid` — решение страницы, что поле заполнено неверно: невыбранные
карточки получают рамку цвета ошибки, а под ними вместо `hint` стоит
`error-message`. `disabled` выключает все карточки: их нельзя выбрать, и
значение не уходит с формой. `disabled` у варианта выключает только его
карточку — его видно в примере выше.

:::example {id="smart-components/input-choice/states" label="Ошибка и недоступное поле" preview=sandbox}
:::

## Поведение

### Значение в форме

`name`, `value`, `required` • [справочник](#атрибуты)

`value` — значение выбранного варианта; при `multiple` — значения через
запятую в порядке вариантов: `local,s3`. Атрибут `value` — то, к чему
возвращает сброс формы. С формой уходит поле `name` с выбранным значением,
при `multiple` — по полю на каждое значение. Если ничего не выбрано, поле не
уходит, а с `required` форма не отправится.

Из кода `value` принимает строку или список: `field.value = ['local', 's3']`.
Свойство `selected` отдаёт выбранные значения списком.

В примере отправьте форму без выбора типа, затем выберите тип и отправьте
снова; журнал покажет, что ушло с формой.

:::example {id="smart-components/input-choice/form" label="Два поля" preview=sandbox log_console=true log_open=false}
:::

### События

Когда человек выбирает вариант или снимает флажок, приходят `input`, затем
`change` — по одному на нажатие. В `detail`: `value` — новое значение,
`values` — список значений, `item` — нажатый вариант, `checked` — выбран ли
он сейчас. Запись `value` из кода, сброс и восстановление формы событий не
дают.

:::example {id="smart-components/input-choice/events" label="События" preview=sandbox log_console=true log_open=false}
:::

```js
const field = document.querySelector('sf-input-choice');
field.addEventListener('change', (event) => {
  console.log(event.detail.values);
});
```

## Доступность

- Внутри — обычные радиокнопки и флажки браузера, поэтому клавиатура
  привычная.
- Один вариант: `Tab` приводит на выбранную карточку, а если её нет — на
  первую; стрелки переходят к соседней карточке и выбирают её, с конца — на
  начало.
- Несколько вариантов: `Tab` проходит по каждой карточке, `Пробел` включает и
  выключает её.
- Группа названа `label` или `aria-label` элемента и описана подсказкой или
  ошибкой. Каждая карточка названа своим названием и описана пояснением.
- Кольцо фокуса обводит карточку при работе с клавиатуры; нажатие мышью его
  не рисует.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `multiple` | да/нет | нет | — | Можно выбрать несколько вариантов: карточки работают как флажки. Без атрибута выбирается один вариант, карточки работают как радиокнопки. |
| `layout` | строка | `tile` | `tile`, `list`, `picture` | Как стоят карточки (решение владельца C28). tile — карточки в сетке: элемент выбора в конце строки названия, название, описание и цена по одному левому краю, цена внизу после разделителя (тарифы, модули). list — одна рамка из строк, разделённых линиями: элемент выбора в начале, цена и срок — столбцом в конце строки названия (доставка, оплата); columns здесь не действует. picture — плитки с картинкой до краёв, подпись под ней, элемент выбора в конце строки названия подписи; в поле уже 30rem (телефон) каждая плитка становится строкой с картинкой в начале. |
| `columns` | строка | `auto` | `auto`, `1`, `2`, `3`, `4` | Сетка для tile и picture: auto заполняет ширину карточками не уже --sf-choice-min-inline-size (15rem); число — наибольшее количество столбцов, меньше там, где карточка стала бы уже, поэтому на телефоне они встают друг под другом. list — всегда один столбец. |
| `label` | строка | пусто | — | Подпись поля над карточками; она же имя группы. Без неё имя берётся из `aria-label` элемента. |
| `hint` | строка | пусто | — | Строка под карточками; описывает группу. |
| `name` | строка | пусто | — | Имя поля формы: с формой уходит выбранное значение, при `multiple` — по полю на каждое значение. |
| `required` | да/нет | нет | — | Форма не отправляется, пока ничего не выбрано (value-missing). |
| `disabled` | да/нет | нет | — | Ни одну карточку нельзя выбрать или поставить на неё фокус, значение не уходит с формой; так же действует выключенный `fieldset`. `disabled` у варианта выключает только его карточку. |
| `invalid` | да/нет | нет | — | Страница решила, что поле заполнено неверно: невыбранные карточки получают рамку цвета ошибки, под ними — `error-message`. |
| `error-message` | строка | пусто | — | Показывается вместо подсказки, пока поле с ошибкой. |
| `value` | строка | пусто | — | Значение выбранного варианта; при `multiple` — значения через запятую в порядке вариантов, пусто — если ничего не выбрано. Атрибут `value` — то, к чему возвращает сброс формы; запись из кода (строкой или списком) событий не даёт. Свойство `selected` отдаёт значения списком. |
| `aria-label` | строка | пусто | — | — |
| `items` | список | `[]` | например `[{"value":"courier","label":"Курьером","caption":"Привезём в удобный интервал","price":"350 ₽","term":"2–3 дня"},{"value":"pickup","label":"Пункт выдачи","caption":"Больше 2 000 пунктов по стране","price":"150 ₽","term":"1–2 дня","badge":"Выгодно"}]` | Варианты, [{value, label, caption?, icon?, badge?, price?, term?, image?, disabled?}]: каждый — карточка с названием (label или title), описанием под ним (caption), значком в строке названия, коротким бейджем (sf-badge) рядом с названием, ценой и сроком (list — столбец в конце строки названия; tile и picture — низ карточки после разделителя) и картинкой (picture — до краёв карточки, над подписью). Свойство, JSON-остров или атрибут в виде JSON. Вариант без value или с повторяющимся value пропускается. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

Публичных методов нет.

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `input` | `{ value: string, values: array, item: object, checked: boolean }` | Человек выбрал вариант или, при `multiple`, снял флажок. Приходит перед `change` с теми же данными; события внутренних полей наружу не выходят. |
| `change` | `{ value: string, values: array, item: object, checked: boolean }` | Человек изменил значение, по одному событию на нажатие: в `detail.value` — новое значение, `detail.values` — выбранные значения, `detail.item` — нажатый вариант, `detail.checked` — выбран ли он сейчас. Запись из кода, сброс и восстановление формы событий не дают. |
