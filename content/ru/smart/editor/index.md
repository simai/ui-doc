# Редактор страниц

- [Оверлей редактора](/ru/smart/editor/composition-overlay/) — Рисует поверх отрисованной страницы рамки, подписи, панель действий, места вставки и дерево структуры для редактора страниц.
- [Перетаскивание](/ru/smart/editor/sortable/) — Даёт переставлять элементы, переносить их между списками и копировать из библиотеки мышью, касанием и клавиатурой.
- [Inline-редактор](/ru/smart/editor/inline-editor/) — Даёт править текст заголовков и абзацев прямо на странице и возвращает модель content, а не HTML.
