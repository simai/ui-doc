# Шапка страницы

:badge[sf-header-page]{type=tonal scheme=primary size=1/2} :badge[1.2.1]{type=outline scheme=on-surface size=1/2}

Шапка страницы показывает в одной строке путь к странице, заголовок, число
записей, звезду избранного и главные действия. Ставьте её в начало каждой
страницы администрирования рядом с [Меню
администратора](/ru/pro/admin/admin-menu/): меню показывает, где находится
раздел, шапка — что это за страница и что на ней можно сделать.

## Разметка

Шапке нужен заголовок; путь и действия передаются в слоты:

```html
<sf-header-page heading="Каталог решений" count="448">
  <sf-breadcrumbs slot="path" aria-label="Путь к странице" items='[…]'></sf-breadcrumbs>
  <sf-button slot="actions" icon-start="add" text="Создать"></sf-button>
</sf-header-page>
```

`heading` — название страницы. Компонент выводит его как `h1` четвёртой
ступени заголовков; отдельно оформлять его не нужно, а длинное название
обрезается многоточием в одну строку.

`count` — сколько записей на странице, строкой: `448`, `1,2 тыс.`. Значение
выводится значком рядом с заголовком; пустое значение счётчик не рисует. Итоги
показывает шапка, а не меню: в строках меню бывают только счётчики
непрочитанного и ожидающего.

Слоты:

- `path` — путь к странице над строкой заголовка, обычно
  [Хлебные крошки](/ru/smart/navigation/breadcrumbs/);
- `actions` — главные действия страницы, прижатые к концу строки: одна
  основная кнопка и при необходимости несколько второстепенных;
- `start` — элемент перед заголовком, например кнопка открытия меню на узком
  экране.

Шапка не задаёт действиям вид: кнопки в слоте `actions` выглядят так, как их
передали. Подписи звезды и отметки «для всех сайтов» компонент берёт на языке
страницы (русском или английском); передавать их не нужно.

## Варианты

### Страница для всех сайтов

`level="install"` ставит рядом с заголовком отметку «для всех сайтов». Задавайте
её на страницах, которые относятся ко всей установке, а не к одному сайту:
пользователи, пакеты, обновления. Значение по умолчанию `site` отметки не
рисует.

## Состояния

### Избранное

`star` управляет звездой: без атрибута её нет, `off` (или `false`) и `on`
(или `true`) рисуют звезду в выключенном и включённом состоянии. Звезду
показывайте только там, где страницу действительно можно добавить в
избранное.

## Поведение

### Место на странице и размер действий

Кнопкам в слоте `actions` берите ступень остальных элементов страницы: рядом с полями
`sf-input--size-1` — кнопки размера 1 (`size="1"` у смарт-кнопки,
`sf-button--size-1` у классовой). Кнопка только со значком называется
своим атрибутом: `label` у `<sf-button-copy>`, `aria-label` у классовой
кнопки.

Своих отступов по краям у шапки нет: она встаёт в контейнер страницы с
отступами вместе с остальным содержимым, а не над ним. Иначе путь,
заголовок и действия прижимаются к краям окна.

```html
<main class="p-4 flex flex-col gap-3">
  <sf-header-page heading="Настройки решения">
    <sf-breadcrumbs slot="path">…</sf-breadcrumbs>
    <sf-button-copy slot="actions" value="https://larena.test/admin/solutions/42" icon="link" text="Скопировать ссылку" label="Скопировать ссылку на страницу" size="1"></sf-button-copy>
  </sf-header-page>
  <form>…</form>
</main>
```

### Избранное и событие `sf-page-header-toggle`

Нажатие на звезду отправляет отменяемое событие `sf-page-header-toggle` с
`event.detail.on` — состоянием, которое просит пользователь. Прежнее имя
`sf-page-header-star` приходит с тем же `detail`. Если событие не отменено,
компонент сам переключает `star`. Если состояние хранит сервер, отмените
событие, дождитесь ответа и задайте `star` по нему: так звезда не покажет
состояние, которое не сохранилось.

```js
const header = document.querySelector('sf-header-page');
header.addEventListener('sf-page-header-toggle', async (event) => {
  event.preventDefault();
  const saved = await saveFavourite(event.detail.on);
  header.setAttribute('star', saved ? 'on' : 'off');
});
```

Если та же страница отмечена в меню администратора, после ответа сервера
попросите меню перечитать избранное методом `refresh()` у `<sf-admin-menu>`.

## Доступность

- Заголовок страницы — `h1` внутри шапки. Не ставьте на странице второй `h1`:
  шапка уже называет страницу.
- Звезда — кнопка в обычном порядке `Tab` с `aria-pressed`. Её подпись
  говорит, что произойдёт при нажатии: «В избранное» или «Убрать из
  избранного». `Enter` и `Space` переключают её.
- Путь и действия получают фокус в порядке разметки: сначала путь, затем
  звезда, затем действия. У кнопки действия только со значком задайте
  `aria-label`.
- Дайте пути доступное имя, например `aria-label="Путь к странице"`.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `heading` | строка | пусто | — | Заголовок страницы, рисуется четвёртой ступенью заголовков |
| `count` | строка | пусто | — | Сколько записей на странице, как их записал хост (448, ~1 200); пусто — счётчик не рисуется |
| `level` | строка | `site` | `site`, `install` | `install` отмечает страницу, общую для всех сайтов |
| `star` | да/нет | нет | — | Нет атрибута — звезда не рисуется; `false` (или `off`) и `true` (или `on`) рисуют её в этом состоянии |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

Публичных методов нет.

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-header-page-toggle` | `{ on: boolean }` | Человек нажал на звезду: просьба добавить страницу в избранное (on) или убрать (off); хост, который отвечает сам, отменяет событие и записывает `star` |
