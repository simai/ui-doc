# Скачивание файла

:badge[sf-file-download]{variant=tonal scheme=primary size=1/2} :badge[1.4.1]{variant=outline scheme=on-surface size=1/2}

Скачивание файла показывает файл, который можно скачать: знак скачивания,
имя, тип и размер. С адресом это обычная ссылка на файл, без адреса — кнопка, по которой
приложение само готовит файл.

То же на классах — [Скачивание файла](/ru/components/actions/download-file/):
для статической разметки без JavaScript.

## Пример

Нажмите «Смета.csv» или «Логотип.svg»: браузер скачает файл. «Акт
сверки.csv» приложение собирает по нажатию и отдаёт браузеру, когда файл
готов. Журнал под примером показывает события.

:::example {id="smart-components/download-file/overview" label="Вложения" preview=sandbox log_console=true log_open=false}
:::

Готовый файл — ссылка с адресом, именем и размером:

```html
<sf-file-download href="/files/smeta.csv"
  file-name="Смета.csv" file-type="CSV" file-size="112 Б"></sf-file-download>
```

## Когда брать

- **Файл уже лежит по адресу** — задайте `href`: это ссылка, браузер скачает
  файл сам.
- **Файл собирает приложение** — без `href`: нажатие сообщает событием, что
  файл нужен. См. [Файл готовит приложение](#файл-готовит-приложение).

## Когда не брать

- **Действие без файла** — обычная [кнопка](/ru/smart/actions/buttons/).
- **Файл нужно показать, а не только скачать** — миниатюра, удаление,
  замена: [Предпросмотр файла](/ru/smart/content/file-preview/).
- **Человек выбирает и загружает файлы** — [Загрузка
  файлов](/ru/smart/forms/file-upload/).

## Частые задачи

### Ссылка на файл

`href`, `target` • [справочник](#атрибуты)

Ссылка на файл скачивает его в той же вкладке под именем из `file-name`.
`target="_blank"` вместо этого открывает файл для просмотра в новой вкладке:
у ссылки появляется знак новой вкладки, а экранный диктор слышит «откроется в
новой вкладке».

:::example {id="smart-components/download-file/link" label="Ссылки" preview=sandbox}
:::

`file-name` — видимое имя файла; задавайте его всегда. `file-type` — тип
словом: «PDF», «XLSX»; он стоит перед размером: «PDF · 2,4 МБ». `file-size` —
только размер, как его прочтёт человек: «2,4 МБ». Если размер не задан, компонент
один раз спрашивает его у адреса файла; известный размер передавайте сами:
тогда запроса нет.

### Файл готовит приложение

`sf-file-download-download`, `state` • [справочник](#события)

Без `href` нажатие отправляет событие, и приложение собирает файл: отчёт,
выгрузку, архив. На это время оно ставит `state="preparing"`: на месте знака
крутится индикатор, рядом — «Готовим файл…», повторное нажатие не
срабатывает. Когда файл готов, приложение задаёт его размер в `file-size`,
адрес в `href` и возвращает `state="ready"`: файл, за которым пришёл человек,
скачивается один раз.

:::example {id="smart-components/download-file/prepare" label="Выгрузка" preview=sandbox log_console=true log_open=false}
:::

```js
file.addEventListener('sf-file-download-download', async (event) => {
  if (file.getAttribute('href')) return;
  event.preventDefault();
  file.setAttribute('state', 'preparing');
  try {
    const {url, size} = await buildReport();
    file.setAttribute('file-size', size);
    file.setAttribute('href', url);
    file.setAttribute('state', 'ready');
  } catch {
    file.setAttribute('state', 'error');
  }
});
```

| Поле `detail` | Содержимое |
|:---|:---|
| `href` | адрес файла; у кнопки без адреса — пустая строка |
| `fileName` | имя файла |

## Внешний вид

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

Размер подгоняет элемент к тексту и кнопкам рядом: каждый размер одной
высоты с кнопкой того же размера — 28, 32, 40, 48 и 56 px на широком
экране. В примере рядом с каждым файлом стоит кнопка со значком той же
ступени.

## Состояния

### Подготовка и ошибка

`state`, `error-text` • по умолчанию `state="ready"` • [справочник](#атрибуты)

Пока приложение готовит файл, элемент показывает подготовку. Если файл
собрать не удалось, под ним появляется сообщение «Не удалось подготовить
файл» и кнопка «Повторить»: её нажатие приходит событием
`sf-file-download-retry`, и приложение готовит файл снова. `error-text`
добавляет к сообщению, что случилось и что делать.

:::example {id="smart-components/download-file/states" label="Состояния" preview=sandbox log_console=true log_open=false}
:::

### Недоступный

`disabled` • [справочник](#атрибуты)

Недоступный файл — кнопка без адреса, даже если `href` задан; событий он не
отправляет.

## Доступность

Имя ссылки или кнопки складывается из имени и размера файла. `aria-label`
заменяет его целиком: включите в него имя файла, например «Скачать отчёт за
квартал, PDF, 2,4 МБ».

Ссылка и кнопка — одна остановка Tab; ссылка срабатывает по Enter, кнопка —
по Enter и пробелу. Знаки скрыты от экранного диктора.

Ссылка с `target="_blank"` сама сообщает диктору, что откроется новая
вкладка. Подготовку элемент отмечает `aria-busy`, а ошибку — сообщением под
файлом; само нажатие ничего не объявляет.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Размер: чем больше число, тем крупнее. |
| `file-name` | строка | пусто | — | Видимое имя файла и имя, под которым он сохраняется. Пусто — последняя часть адреса, иначе «Файл» на языке страницы. |
| `file-size` | строка | пусто | — | Размер текстом в единицах страницы («2,4 МБ»). Если пусто и задан href, размер узнаётся одним запросом HEAD и пишется на языке страницы. |
| `file-type` | строка | пусто | — | Тип файла словом (PDF, XLSX); стоит перед размером: «PDF · 2,4 МБ». В file-size тип не пишут. |
| `href` | строка | пусто | — | Адрес файла. |
| `download` | да/нет | нет | — | Оставлен для совместимости: ссылка на файл скачивает его в той же вкладке, задан атрибут или нет; новую вкладку открывает только target="_blank". |
| `disabled` | да/нет | нет | — | Кнопка недоступна, ссылка не работает. |
| `state` | строка | `ready` | `ready`, `preparing`, `error` | ready — файл можно скачать. preparing — приложение его готовит: на месте знака индикатор, «Готовим файл…», aria-busy, нажатие не срабатывает; когда страница снова ставит ready с адресом в href, файл, за которым пришёл человек, скачивается один раз. error — подготовить не удалось: под файлом сообщение «Не удалось подготовить файл» и кнопка «Повторить». |
| `error-text` | строка | пусто | — | Дополнительные слова в сообщении об ошибке: что случилось и что делать; заголовок — «Не удалось подготовить файл». |
| `target` | строка | пусто | — | Где открывается ссылка. Пусто, по умолчанию, — файл скачивается в той же вкладке. _blank — файл открывается для просмотра в новой вкладке: у ссылки знак новой вкладки, а экранный диктор слышит «(откроется в новой вкладке)». |
| `aria-label` | строка | пусто | — | Имя ссылки или кнопки для экранного диктора вместо имени и размера файла; назовите в нём файл. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

Публичных методов нет.

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-file-download-download` | `{ href: string, fileName: string, download: boolean }` | Человек нажал на файл: запрос скачать его, событие отменяемое. Страница, которая его отменила, скачивает файл сама: на время подготовки ставит state="preparing", затем ready с адресом в href или error. |
| `sf-file-download-retry` | `{ href: string, fileName: string }` | Человек нажал «Повторить» под файлом, который не удалось подготовить: страница готовит файл снова и ставит состояние. |

### Переменные

Публичные переменные: имя стабильно, значение ставят на сам элемент или на любого предка.

| Переменная | Что задаёт |
|:---|:---|
| `--sf-file-download-background-color` | Заливка в покое; у наведения, нажатия и недоступного состояния свои. |
| `--sf-file-download-border-color` | Цвет рамки в покое. |
| `--sf-file-download-radius` | Скругление. |
| `--sf-file-download-padding` | Внутренний отступ. |
| `--sf-file-download-gap` | Промежуток между иконкой, именем и размером. |
| `--sf-file-download-icon-size` | Размер иконки. |
| `--sf-file-download-icon-color` | Цвет иконки. |
