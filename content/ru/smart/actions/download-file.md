# Скачивание файла

:badge[sf-file-download]{variant=tonal scheme=primary size=1/2} :badge[1.2.0]{variant=outline scheme=on-surface size=1/2}

Скачивание файла показывает файл, который можно скачать: иконку, имя и
размер. С адресом это обычная ссылка на файл, без адреса — кнопка, по которой
приложение само готовит файл.

То же на классах — [Скачивание файла](/ru/components/actions/download-file/):
для статической разметки без JavaScript.

## Пример

:::example {id="smart-components/download-file/overview" label="Два файла" preview=sandbox log_console=true log_open=false}
:::

Готовый файл — ссылка с адресом, именем и размером:

```html
<sf-file-download href="/files/report.pdf" download
  file-name="Отчёт за квартал.pdf" file-size="2,4 МБ"></sf-file-download>
```

## Когда брать

- **Файл уже лежит по адресу** — задайте `href`: это ссылка, браузер скачает
  файл сам.
- **Файл собирает приложение** — без `href`: нажатие сообщает событием, что
  файл нужен. См. [Файл готовит приложение](#файл-готовит-приложение).
- **Действие без файла** — обычная [кнопка](/ru/smart/actions/buttons/).

## Частые задачи

### Ссылка на файл

`href`, `download`, `target` • по умолчанию `target="_blank"` • [справочник](#атрибуты)

С `download` браузер скачивает файл под именем из `file-name`, а не
открывает его. Без `download` ссылка открывается в новой вкладке.

`file-name` — видимое имя файла; задавайте его всегда. `file-size` —
размер, как его прочтёт человек: «2,4 МБ». Если размер не задан, компонент
спрашивает его у адреса и показывает в английских единицах, поэтому
известный размер передавайте сами.

### Файл готовит приложение

`sf-file-download-download` • [справочник](#события)

Без `href` нажатие отправляет событие, и приложение собирает файл: отчёт,
выгрузку, архив. Пока файл готовится, элемент недоступен.

:::example {id="smart-components/download-file/prepare" label="Выгрузка по запросу" preview=sandbox log_console=true log_open=false}
:::

```js
document.addEventListener('sf-file-download-download', async (event) => {
  if (event.detail.href) return;
  const file = await buildReport();
  saveFile(file, event.detail.fileName);
});
```

| Поле `detail` | Содержимое |
|:---|:---|
| `href` | адрес файла; у кнопки без адреса — пустая строка |
| `fileName` | имя файла |
| `download` | `true`, если задан `download` |

## Доступность

Имя ссылки или кнопки складывается из имени и размера файла. `aria-label`
заменяет его целиком: включите в него имя файла, например «Скачать отчёт за
квартал, PDF, 2,4 МБ».

Ссылка и кнопка — одна остановка Tab; ссылка срабатывает по Enter, кнопка —
по Enter и пробелу. Иконка скрыта от экранного диктора.

Ссылка без `download` открывает новую вкладку: если это важно, скажите об
этом рядом. Когда приложение готовит файл, сообщите о готовности или ошибке
в области с `role="status"`: само нажатие ничего не объявляет.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Существующая шкала размеров компонентов от компактного до крупного. |
| `file-name` | строка | `File.pdf` | — | Видимое имя файла и нативное имя для скачивания по умолчанию. |
| `file-size` | строка | пусто | — | Размер текстом (2,4 МБ); пусто при заданном href — размер спрашивается одним запросом HEAD |
| `icon` | строка | `download` | — | Имя декоративной иконки. |
| `href` | строка | пусто | — | Реальное место ресурса; в доступном состоянии отрисовывает нативную ссылку (`a`). |
| `download` | да/нет | нет | — | Применяет к ссылке нативную семантику скачивания. |
| `disabled` | да/нет | нет | — | Отображает отключённую кнопку без действующего адреса перехода. |
| `target` | строка | `_blank` | — | — |
| `aria-label` | строка | пусто | — | — |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.
