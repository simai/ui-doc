# Скачивание файла

`<sf-download-file>` показывает файл, который можно скачать: иконку, имя и
размер. С адресом он становится нативной ссылкой, без адреса — кнопкой, по
которой приложение само готовит файл.

То же на классах — [Скачивание файла](/ru/components/actions/download-file/):
оформление совпадает с обычным компонентом.

## Разметка

Готовый файл — ссылка с адресом, именем и размером:

```html
<sf-download-file href="/files/report.pdf" download
  file-name="Отчёт за квартал.pdf" file-size="2,4 МБ"></sf-download-file>
```

`href` с адресом файла рисует ссылку. С `download` браузер скачивает файл под
именем из `file-name`, а не открывает его. Без `download` ссылка открывается в
`target`, по умолчанию `_blank`, с `rel="noopener noreferrer"`.

`file-name` — видимое имя файла, по умолчанию `File.pdf`, поэтому задавайте
его всегда. `file-size` — размер, как его прочтёт человек: «2,4 МБ».
Если `file-size` пуст, компонент запрашивает адрес методом `HEAD` и
показывает размер из заголовка `Content-Length` в английских единицах;
передавайте размер сами, когда он известен.

Без `href` компонент рисует кнопку: файл готовит приложение (см.
«Поведение»).

## Поведение

### Файл, который готовит приложение

Без `href` компонент рисует кнопку. Нажатие отправляет событие
`sf-download-file-download`, и приложение собирает файл — отчёт, выгрузку,
архив. Пока файл не готов, показывайте это рядом или переключите элемент в
`disabled`.

### Событие `sf-download-file-download`

Событие отправляется с внутренней ссылки или кнопки и всплывает до
`document`. Прежнее имя `sf-download-file:click` приходит с тем же `detail`.
Его `event.detail`:

| Поле | Содержимое |
|:---|:---|
| `href` | адрес файла; у кнопки без адреса — пустая строка |
| `fileName` | имя файла |
| `download` | `true`, если задан `download` |

```js
document.addEventListener('sf-download-file-download', async (event) => {
  if (event.detail.href) return;
  const file = await buildReport();
  saveFile(file, event.detail.fileName);
});
```

## Доступность

- Доступное имя ссылки или кнопки складывается из имени и размера файла.
  `aria-label` заменяет его целиком: если задаёте его, включите в него имя
  файла, например «Скачать отчёт за квартал, PDF, 2,4 МБ».
- Ссылка и кнопка — одна остановка `Tab`; ссылка срабатывает по `Enter`,
  кнопка — по `Enter` и `Space`. Иконка скрыта от вспомогательных
  технологий.
- Ссылка без `download` открывает новую вкладку. Если это важно, скажите об
  этом в подписи рядом.
- Когда приложение готовит файл, сообщите о готовности или ошибке в области
  с `role="status"`: само нажатие ничего не объявляет.

## Справочник

Собран из манифеста компонента выпуска `ui-2d39b617a719` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | — |
| `root-style` | строка | пусто | — | — |
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Существующая шкала размеров компонентов от компактного до крупного. |
| `file-name` | строка | `File.pdf` | — | Видимое имя файла и нативное имя для скачивания по умолчанию. |
| `file-size` | строка | пусто | — | Размер текстом (2,4 МБ); пусто при заданном href — размер спрашивается одним запросом HEAD |
| `icon` | строка | `download` | — | Имя декоративной иконки. |
| `href` | строка | пусто | — | Реальное место ресурса; в доступном состоянии отрисовывает нативную ссылку (`a`). |
| `download` | да/нет | нет | — | Применяет к ссылке нативную семантику скачивания. |
| `disabled` | да/нет | нет | — | Отображает отключённую кнопку без действующего адреса перехода. |
| `target` | строка | `_blank` | — | — |
| `aria-label` | строка | пусто | — | — |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

Публичных методов нет.

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-download-file-download` | `{ href: string, fileName: string, download: boolean }` | — |
| `sf-download-file:click` | `{ href?: string, fileName?: string, download?: boolean }` | устаревший псевдоним `sf-download-file-download`: подписывайтесь на `sf-download-file-download` |
