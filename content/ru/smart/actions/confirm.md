# Подтверждение

:badge[sf-confirm]{type=tonal scheme=primary size=1/2} :badge[1.0.0]{type=outline scheme=on-surface size=1/2}

Подтверждение спрашивает человека прямо там, где он работает: удалить файл в
его строке, убрать участника, вернуть вид раздела. Оно показывает, что
случится, два ответа, ожидание и итог. Само действие выполняет страница:
нажатие только сообщает ответ.

## Пример

Нажмите «Удалить»: вопрос ждёт, пока страница применит ответ, и показывает
итог. Журнал под примером показывает ответ.

:::example {id="smart-components/confirm/overview" label="Удаление в строке" preview=sandbox log_console=true log_open=false}
:::

```html
<sf-confirm question="Удалить файл «Отчёт.pdf»?" confirm-id="f-17"
            accept-text="Удалить" destructive></sf-confirm>
```

`question` — вопрос целым предложением, `confirm-id` — имя вопроса у
страницы: оно приходит в каждом событии.

## Когда брать

- **Вопрос о строке или объекте рядом.** Подтверждение стоит в потоке, окно
  поверх страницы не нужно.
- **Вся страница должна остановиться** — [Модальное
  окно](/ru/smart/overlays/modal/).
- **Нужно показать, каким станет каждое значение** — [Подтверждение
  изменения](/ru/pro/admin/change-confirm/).
- **Ответ называет действие.** «Удалить», «Убрать», а не «Да».

## Частые задачи

### Удаление с ответом сервера

Нажатый ответ переводит вопрос в ожидание. Страница ставит итог, а если
применить не удалось, возвращает вопрос открытым.

```js
confirm.addEventListener('sf-confirm-answer', (event) => {
  if (!event.detail.accepted) return;
  removeFile(event.detail.id)
    .then(() => { confirm.state = 'accepted'; })
    .catch(() => { confirm.state = 'open'; });
});
```

Отменённое событие `sf-confirm-answer` оставляет вопрос открытым.

## Внешний вид

### Вид

`appearance` • по умолчанию `inline` • [справочник](#атрибуты)

Вопрос стоит в строке или в карточке со своей рамкой.

:::example {id="smart-components/confirm/card" label="В карточке, с пояснением" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `inline` | вопрос в строке таблицы или списка, без рамки |
| `card` | вопрос отдельным блоком; пояснение — в месте `description` |

### Опасное действие

`destructive` • [справочник](#атрибуты)

Ответ «да» окрашен цветом ошибки: так видно, что действие что-то уничтожает.

:::example {id="smart-components/confirm/destructive" label="Обычный и опасный" preview=inline}
:::

Слова ответов задают `accept-text` и `decline-text`; без них — «Подтвердить»
и «Отмена» на языке страницы.

## Состояния

### Ожидание и итог

`state`, `disabled` • по умолчанию `state="open"` • [справочник](#атрибуты)

Состояние показывает, где вопрос: ответы предложены, ответ применяется или
виден только итог.

:::example {id="smart-components/confirm/states" label="Состояния" preview=inline}
:::

| Значение | Что видно |
|:---|:---|
| `open` | вопрос и ответы |
| `pending` | ответ применяется |
| `accepted`, `declined`, `expired` | только итог |
| `disabled` | ответы видны, но не нажимаются: где-то уже идёт отправка |

### Срок

`expires-at` • [справочник](#атрибуты)

После срока открытый вопрос читается как истёкший. В примере срок —
пять секунд после открытия.

:::example {id="smart-components/confirm/expiry" label="Срок ответа" preview=sandbox log_console=true log_open=false}
:::

Срок задаётся в формате ISO 8601. Об истечении вопрос один раз сообщает
событием `sf-confirm-expired`.

## Доступность

Вопрос — группа, названная самим вопросом. Строка состояния объявляется
вежливо и есть на странице до того, как заговорит.

Когда нажатие убирает ответы, фокус переходит на строку состояния; если
страница вернула вопрос открытым, фокус возвращается к первому ответу.

Tab доходит до ответов, Enter и пробел отвечают, Escape внутри открытого
вопроса — тот же ответ, что «Отмена».

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `question` | строка | пусто | — | Вопрос, сказанный на месте: что произойдёт, одним предложением («Удалить файл «Отчёт.pdf»?»). Он же называет группу; без него группа называется «Подтверждение». |
| `state` | строка | `open` | `open`, `pending`, `accepted`, `declined`, `expired` | open: ответы предложены. pending: ответ отправляется (ставится нажатием). accepted, declined, expired: виден только итог. |
| `expires-at` | строка | пусто | — | ISO 8601. После этого срока открытый вопрос считается истёкшим и один раз сообщает об этом событием `sf-confirm-expired`. |
| `confirm-id` | строка | пусто | — | Имя вопроса у хоста (строка, запись); возвращается в каждом событии. |
| `disabled` | да/нет | нет | — | Ответы видны, но их нельзя нажать (где-то уже идёт отправка). |
| `destructive` | да/нет | нет | — | Согласие что-то уничтожает (удаление): у принимающего ответа статус error. |
| `appearance` | строка | `inline` | `inline`, `card` | inline: вопрос и ответы в потоке строки, без своей рамки. card: в карточке с рамкой и собственным отступом. |
| `accept-text` | строка | — | — | Слова ответа «да»; пусто — «Подтвердить» на языке страницы. |
| `decline-text` | строка | — | — | Отказывающий ответ; пусто — «Отмена» на языке страницы. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `open()` | объект | Задаёт вопрос снова; если его попросила сборка, отвечает `{accepted, reason, value}`, когда человек ответил или время вышло. |
| `answer(accepted: boolean)` | объект | Отвечает, как ответил бы человек: `accepted` true подтверждает, false отказывается. Отказ: `unknown`, `closed`, `disabled` или `prevented`. |
| `confirm()` | объект | Согласие; `data-sf-action="<id>.confirm"`. |
| `cancel()` | объект | Отказывающий ответ; `data-sf-action="<id>.cancel"`. Escape внутри открытого вопроса — тот же ответ. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-confirm-answer` | `{ id: any, accepted: boolean }` | Человек ответил (слово словаря answer). Отмените событие, чтобы вопрос остался открытым. |
| `sf-confirm-expired` | `{ id: any }` | Открытый вопрос дождался `expires-at`; сообщается один раз на каждый срок. |
