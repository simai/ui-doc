# Закрытие

:badge[sf-button-close]{type=tonal scheme=primary size=1/2} :badge[1.1.0]{type=outline scheme=on-surface size=1/2}

Закрытие — это крестик нужного размера для кнопки, которая закрывает окно,
панель или сообщение. Сам он не кнопка: кнопку даёт обычный `<button>` или
[Кнопки с иконкой](/ru/smart/actions/icon-buttons/) с `kind="close"`, а
крестик стоит внутри неё.

Готовую кнопку закрытия даёт `<sf-button-icon kind="close">`: она сама
ставит `<sf-button-close>` того же размера, что кнопка. `<sf-button-close>` отдельно берите
для своей кнопки закрытия — в шапке панели, в теге, в карточке, где кнопку
рисует ваша разметка.

То же на классах — [Закрытие](/ru/components/actions/close/): оформление знака
совпадает с обычным компонентом.

## Разметка

Знак ставится внутрь нативной кнопки, у которой есть доступное имя:

```html
<button type="button" aria-label="Закрыть уведомление">
  <sf-button-close size="1"></sf-button-close>
</button>
```

Атрибутов, без которых знак не работает, нет. `root-class` добавляет классы
корню знака.

## Варианты

### Размер знака

`size` задаёт размер знака по шкале от `1/4` до `7`; по умолчанию `1/3`.
Внутри кнопки выбирайте размер знака по размеру кнопки: в кнопке
`sf-icon-button--size-1` — `size="1"`.

## Доступность

- Знак скрыт от вспомогательных технологий (`aria-hidden="true"`) и не
  получает фокус. Фокус и нажатие принадлежат кнопке вокруг него.
- Кнопке нужно доступное имя, которое называет, что закрывается:
  `aria-label="Закрыть уведомление"`, а не просто «Закрыть», если на экране
  несколько таких кнопок.
- Кнопка закрытия — нативный `<button type="button">`: `Enter` и `Space`
  нажимают её без дополнительного кода.

## Справочник

Собран из манифеста компонента выпуска `ui-98143c0a0728` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |
| `size` | строка | `1/3` | `1/4`, `1/3`, `1/2`, `1`, `2`, `3`, `4`, `5`, `6`, `7` | Токен размера декоративного символа закрытия. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.
