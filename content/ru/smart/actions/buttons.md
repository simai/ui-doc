# Кнопки

:badge[sf-button]{variant=tonal scheme=primary size=1/2} :badge[1.10.0]{variant=outline scheme=on-surface size=1/2}

Кнопка запускает действие: сохранить, отправить, открыть окно. Вид, цвет,
размер, иконки и индикатор загрузки задаются атрибутами. Берите её там, где
кнопку создаёт шаблон или код, а состояние меняется во время работы.

То же на классах — [Кнопки](/ru/components/actions/buttons/): для статической
разметки без JavaScript.

## Пример

:::example {id="smart-components/buttons/overview" label="Кнопки рядом"}
:::

Кнопке нужна только подпись:

```html
<sf-button text="Сохранить"></sf-button>
```

Подпись можно передать и текстом внутри тега или элементом со
`slot="text"`.

## Когда брать

- **Кнопка или ссылка.** Сохранить, отправить, открыть окно — кнопка.
  Перейти на другую страницу — ссылка; ей можно дать вид кнопки, см.
  [Ссылку в виде кнопки](#ссылка-в-виде-кнопки).
- **Одна главная на экран.** Вид `default` получает одно действие, ради
  которого открыт экран. Остальным — виды полегче: `tonal`, `outline` или
  `ghost`.
- **Подпись — глагол.** «Сохранить», «Отправить отчёт», а не «ОК» или «Да»:
  подпись говорит, что случится после нажатия.
- **Опасное действие.** Удаление отмечает `status="danger"`, а подпись
  называет, что пропадёт: «Удалить проект».

## Частые задачи

### Сохранение с загрузкой

Пока запрос идёт, кнопка показывает спиннер и не нажимается второй раз.

```js
const save = document.querySelector('#save');

save.addEventListener('sf-button-press', async () => {
  save.loading = true;
  try {
    await saveProfile();
  } finally {
    save.loading = false;
  }
});
```

### Удаление

Красный цвет `danger` и подпись с объектом предупреждают, что действие не
отменить.

```html
<sf-button status="danger" icon-start="delete" text="Удалить проект"></sf-button>
```

### Ссылка в виде кнопки

Переход остаётся ссылкой, даже когда выглядит кнопкой: работают Enter,
новая вкладка и адрес при наведении. Пример не переходит по ссылке, а пишет
в журнал её адрес.

:::example {id="smart-components/buttons/link" label="Ссылки" preview=sandbox log_console=true log_open=false}
:::

```html
<sf-button href="/ru/guide/" appearance="outline" text="Руководство"></sf-button>
```

Ссылкой становятся относительный адрес, якорь, адрес http и https, почта и
телефон. С другой схемой, например ftp, остаётся кнопка. У недоступной ссылки
и ссылки в загрузке адреса нет: по ней не перейти.

### Отправка формы

Кнопка отправки передаёт с формой своё имя и значение, как обычная кнопка.

:::example {id="smart-components/buttons/form" label="Форма" preview=sandbox log_console=true log_open=false}
:::

Учтите: без `native-type="submit"` кнопка форму не отправляет — по умолчанию
её тип `button`.

## Внешний вид

Вид, цвет, размер и форму кнопки задают независимые атрибуты: у каждого одно
значение.

### Вид

`appearance` • по умолчанию `default` • [справочник](#атрибуты)

Вид показывает, насколько действие важно рядом с другими.

:::example {id="smart-components/buttons/appearance" label="Виды" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `default` | главное действие экрана, обычно одно |
| `tonal` | важное, но не главное |
| `outline` | второстепенное: «Отмена», «Назад» |
| `ghost` | самое лёгкое: без фона и рамки, пока не наведут; в строке таблицы или рядом с текстом |
| `surface` | панель инструментов, цветной фон или изображение |

### Цвет и статус

`scheme`, `status` • по умолчанию `scheme="primary"` • [справочник](#атрибуты)

Цвет отделяет акцентное действие от нейтрального, а статус отмечает опасное.

:::example {id="smart-components/buttons/scheme" label="Цвета" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `primary` | акцентное действие |
| `secondary` | тихое второе действие и фильтры-чипы, обычно в виде `tonal` |
| `on-surface` | нейтральное действие рядом с главным: «Отмена» в виде `outline`, панели |
| `on-surface-variant` | кнопка, похожая на поле: поиск рядом с полями, в виде `outline` или `surface`. В виде `default` она такая же, как `on-surface` |

`status="danger"` окрашивает кнопку красным цветом ошибки поверх любого
цвета: для удаления и необратимых действий. Ведёт себя такая кнопка как
обычная.

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

Размер подгоняет кнопку к полям и строке, где она стоит.

:::example {id="smart-components/buttons/sizes" label="Размеры" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `1/3` | самые плотные места: строка таблицы, ячейка |
| `1/2` | панели инструментов и компактные формы |
| `1` | формы, диалоги и панели |
| `2` | заметное действие на странице |
| `3` | главное действие пустого экрана или заставки |

Кнопка и поле одного размера — одной высоты: в строке с полем берите тот же
размер.

### Высота

`height` • по умолчанию `default` • [справочник](#атрибуты)

Высота меняет только высоту кнопки, а размер текста и значков остаётся тем,
что задал `size`. Берите её, когда кнопка должна встать вровень с соседями
другой высоты или выделиться без крупного текста.

:::example {id="smart-components/buttons/height" label="Высота" preview=inline}
:::

| Значение | Высота при `size="1"` | Когда брать |
|:---|:---|:---|
| `low` | 32 | плотные таблицы и панели |
| `default` | 40 | почти везде |
| `high` | 48 | крупное одиночное действие |
| `highest` | 56 | самое крупное одиночное действие |

Боковые поля растут вместе с высотой, поэтому расстояние от края до значка не
меняется. В компактной области (`data-sf-density="compact"`) все ступени
сдвигаются на одну вниз. Высоту рисует классовая кнопка: `height` ставит ей
класс `sf-button--height-{значение}`, описанный на странице
[Кнопки](/ru/components/actions/buttons/#высота).

### Скругление

`radius` • [справочник](#атрибуты)

Скругление подстраивает кнопку под форму соседних элементов.

:::example {id="smart-components/buttons/radius" label="Скругление" preview=inline}
:::

`square` убирает скругление, `rounded` делает края полностью круглыми. Без
атрибута кнопка скруглена, как все элементы управления.

### Иконки

`icon-start`, `icon-end` • [справочник](#атрибуты)

Иконка помогает узнать действие с первого взгляда. Она стоит перед подписью
или после неё.

:::example {id="smart-components/buttons/icons" label="Иконки" preview=inline}
:::

| Атрибут | Где иконка | Когда брать |
|:---|:---|:---|
| `icon-start` | перед подписью | действие узнаётся по значку: «Скачать», «Добавить» |
| `icon-end` | после подписи | кнопка ведёт дальше или раскрывает список: «Далее», «Ещё» |

```html
<sf-button text="Скачать отчёт" icon-start="download"></sf-button>
```

Одну иконку можно задать короче: `icon` и сторона в `icon-position`. Свою
картинку передаёт дочерний элемент со `slot="icon-start"` или
`slot="icon-end"`. Кнопка без подписи — [Кнопки с
иконкой](/ru/smart/actions/icon-buttons/).

### Группа кнопок

`segment` • [справочник](#атрибуты)

Связанные действия стоят встык и читаются как одна кнопка из нескольких частей.

:::example {id="smart-components/buttons/segments" label="Группы кнопок"}
:::

| Значение | Когда брать |
|:---|:---|
| `start` | первая кнопка группы |
| `middle` | любая кнопка между первой и последней |
| `end` | последняя кнопка группы |

Группе нужны `role="group"` и общее имя в `aria-label`. Атрибут `segment`
подходит для действий: каждая кнопка делает своё. Если в группе выбирают
один вариант, берите готовый [Сегментный
переключатель](/ru/smart/actions/segmented/): в нём уже есть выбор, клавиатура
и событие `change`.

## Состояния

Наведение, нажатие и фокус кнопка показывает сама. Остальные состояния задают
атрибуты.

### Недоступная

`disabled` • [справочник](#атрибуты)

Недоступная кнопка показывает, что действие сейчас выполнить нельзя.

:::example {id="smart-components/buttons/state-disabled" label="Недоступные" preview=inline}
:::

Она не нажимается и выпадает из порядка Tab. Почему действие недоступно,
объясните текстом рядом.

### Загрузка

`loading` • [справочник](#атрибуты)

Пока действие выполняется, кнопка показывает спиннер и не нажимается
повторно.

:::example {id="smart-components/buttons/loading" label="Загрузка" preview=inline}
:::

| Кнопка | Где спиннер |
|:---|:---|
| с иконкой | на месте иконки: начальной, а если её нет — конечной |
| без иконки | поверх подписи; ширина кнопки не меняется |
| [только с иконкой](/ru/smart/actions/icon-buttons/) | на месте иконки |

Спиннер растёт вместе с кнопкой:

:::example {id="smart-components/buttons/loading-sizes" label="Загрузка по размерам" preview=inline}
:::

Вид спиннера один на всю страницу; как его выбрать —
[Спиннер](/ru/smart/feedback/spinner/#вид-страницы).

:::example {id="smart-components/buttons/loading-looks" label="Виды спиннера" preview=inline}
:::

### Включённая и выключенная

`pressed`, `text-pressed` • [справочник](#атрибуты)

Кнопка-переключатель включает и выключает настройку: жирный шрифт,
избранное.

:::example {id="smart-components/buttons/toggle" label="Переключатели" preview=sandbox log_console=true log_open=false}
:::

`pressed` — кнопка включена, `pressed="false"` — выключена. Без атрибута
кнопка не переключатель. Сама кнопка состояние не меняет: его переключает
страница.

Если подпись говорит о состоянии, задайте `text-pressed`: «В избранное»
превращается в «В избранном», пока кнопка включена. Вид нажатой кнопки
остаётся, а экранный диктор читает новую подпись вместо «нажата».

```html
<sf-button id="bold" pressed="false" icon-start="format_bold" text="Жирный"></sf-button>
<sf-button pressed="false" icon-start="star" text="В избранное" text-pressed="В избранном"></sf-button>
```

```js
const bold = document.querySelector('#bold');

bold.addEventListener('sf-button-press', () => {
  bold.pressed = !bold.pressed;
  editor.setBold(bold.pressed);
});
```

### Несколько значений по кругу

`cycle`, `theme-cycle`, `value` • [справочник](#атрибуты)

Одна кнопка перебирает несколько значений: каждое нажатие ставит следующее, за
последним снова идёт первое. Подходит для скорости воспроизведения, порядка
сортировки, темы. Нажмите кнопки в примере: журнал покажет событие `change`.

:::example {id="smart-components/buttons/cycle" label="Кнопки-циклы" preview=sandbox log_console=true log_open=false}
:::

Тему примеров задаёт сам сайт документации, поэтому кнопка темы в примере
тему не меняет и `change` не присылает. На вашей странице каждое нажатие
ставит следующую тему.

`cycle` — список значений `{value, label, icon, pressed?}`, `value` — текущее.
Подпись и значок говорят текущее значение, подсказка — текущее и следующее.
`pressed: true` рисует кнопку нажатой, пока стоит это значение. После нажатия
приходит `change` с `{previous, value, item}`.

```html
<sf-button value="1" cycle='[{"value":"1","label":"Скорость: 1×","icon":"speed"},{"value":"1.5","label":"Скорость: 1,5×","icon":"speed","pressed":true}]'></sf-button>
<sf-button theme-cycle></sf-button>
```

`theme-cycle` — готовый переключатель темы страницы: без значения он идёт по
трём темам, начиная с противоположной видимой, затем «как в системе»;
`theme-cycle="light dark"` только меняет светлую и тёмную. Кнопка-цикл — не
переключатель: `pressed` и `text-pressed` рядом с `cycle` не действуют.

## Сочетание клавиш

`shortcut`, `shortcut-listen` • [справочник](#атрибуты)

Сочетание на кнопке подсказывает быстрый путь, а `shortcut-listen` нажимает
кнопку с клавиатуры. В примере нажмите Alt+K (⌥ K на Mac): кнопка поиска
нажмётся, а журнал под примером покажет событие.

:::example {id="smart-components/buttons/shortcut" label="Сочетания клавиш" preview=sandbox log_console=true log_open=false}
:::

| Запись | На Mac | В других системах |
|:---|:---|:---|
| `mod+k` | ⌘ K | Ctrl K |
| `shift+mod+p` | ⇧ ⌘ P | Ctrl Shift P |
| `alt+n` | ⌥ N | Alt N |
| `escape` | Esc | Esc |

Слова пишутся через `+`, клавиша последней; `mod` — Cmd на Mac и Ctrl в
других системах. Клавиши рисует компонент [Клавиши](/ru/components/content/kbd/).

| Запись | Клавиши |
|:---|:---|
| `ctrl`, `alt`, `shift`, `meta` | модификаторы |
| `enter`, `escape`, `tab`, `space`, `backspace`, `delete` | Enter, Esc, Tab, пробел, удаление |
| `up`, `down`, `left`, `right`, `home`, `end`, `pageup`, `pagedown` | стрелки и переходы по странице |
| `plus` | клавиша + |

Учтите: сочетание без модификатора, например `/`, не срабатывает, пока фокус
в поле ввода.

## Работа из кода

Кнопку создают, слушают и настраивают из JavaScript, как обычный элемент.

### Нажатие

Для действия слушайте `sf-button-press`: его присылает только нажатие
человеком.

| Что произошло | `sf-button-press` | `click` |
|:---|:---|:---|
| щелчок, Enter или пробел на кнопке или ссылке | да | да |
| сочетание `shortcut-listen` | да | да |
| вызов `click()` у тега из кода | нет | да |
| щелчок по недоступной ссылке | нет | да |
| кнопка недоступна или в загрузке, ссылка в загрузке | нет | нет |

`detail` у `sf-button-press` — пустой объект. Метод `onClick(handler)`
подписывает на `click`.

### Свойства и методы

Свойства, которые нужны чаще всего; у каждого атрибута есть свойство с тем же
именем в camelCase — см. [справочник](#атрибуты).

| Свойство | Что даёт |
|:---|:---|
| `loading`, `disabled` | загрузка и недоступность: `true` или `false` |
| `pressed` | `true`, `false` или `undefined`, если кнопка не переключатель |
| `text` | подпись |
| `dataAttributes` | атрибуты `data-*`, записанные на теге: `data-add` — `.add` |

Методы — в [справочнике](#методы).

```js
const button = await SF.createAsync('button', {
  text: 'Экспортировать',
  iconStart: 'download',
  appearance: 'outline',
});
document.querySelector('#toolbar').append(button);
```

## Доступность

Имя кнопки — её подпись. Кнопке только с иконкой нужно имя в `aria-label`,
удобнее взять [Кнопки с иконкой](/ru/smart/actions/icon-buttons/):

```html
<sf-button-icon icon="close" aria-label="Закрыть"></sf-button-icon>
```

Фокус получает кнопка внутри: Tab останавливается на ней, Enter и пробел
нажимают её. Фокус из кода ставит метод тега:

```js
document.querySelector('sf-button').focus();
```

Почему действие недоступно, объясните текстом и свяжите его с кнопкой:

```html
<sf-button text="Отправить" disabled aria-describedby="send-hint"></sf-button>
<p id="send-hint">Заполните адрес, чтобы отправить.</p>
```

Кнопка, которая открывает меню или панель, сообщает, открыта ли она:

```js
menuButton.expanded = true; // aria-expanded="true" на кнопке внутри
```

Нарисованные клавиши сочетания скрыты от экранного диктора: сочетание он
узнаёт из `aria-keyshortcuts`, который кнопка ставит сама. Красный цвет не
заменяет подпись — см. [Удаление](#удаление).

**Прежние имена.** До 2027-01-01 `appearance="link"` читается как `ghost`, а
`status="error"` — как `danger`; новая разметка пишет `ghost` и `danger`.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Размер кнопки: от `1/3` (самая мелкая) до `3` (самая крупная). |
| `height` | строка | `default` | `low`, `default`, `high`, `highest` | Высота элемента управления (решение владельца C27), отдельно от size: size задаёт текст, значки и внутренний масштаб, а height выбирает высоту из ступеней плотности размера по контракту адаптивных размеров — low, default, high, highest: обычная ступень размера и её соседи на лестнице высот интерфейса. Компьютер: 1/3 — 24/28/32/40, 1/2 — 28/32/40/48, 1 — 32/40/48/56, 2 — 40/48/56/68, 3 — 48/56/68/80; телефон: 1/3 — 20/24/28/36, 1/2 — 24/28/36/44, 1 — 28/36/44/52, 2 — 36/44/52/64, 3 — 44/52/64/76. Боковой отступ растёт с высотой на половину прибавки, поэтому расстояние от края до значка не меняется. Компактная область (data-sf-density) сдвигает ступени на одну вниз, и height выбирает соседа уже там. Значение не из списка читается как default, с одним предупреждением в консоли. |
| `appearance` | строка | `default` | `default`, `tonal`, `outline`, `ghost`, `surface` | Вид кнопки: `default` — залитая, `tonal` — мягкая заливка, `outline` — с рамкой, `ghost` — без фона и рамки, пока не наведут (C15), `surface` — лёгкая нейтральная заливка с рамкой. `link` — прежнее имя `ghost`; ссылку делает `href`, а не вид. |
| `scheme` | строка | `primary` | `primary`, `secondary`, `on-surface`, `on-surface-variant` | Цвет кнопки: `primary` — основной, `secondary` — дополнительный, `on-surface` — нейтральный, `on-surface-variant` — нейтральный с приглушёнными подписью и иконками, например для кнопки поиска, похожей на поле. `status="error"` важнее. |
| `status` | строка | пусто | пусто, `danger` | О чём действие (C13): `danger` — удаляет, отбрасывает или не отменяется. Рисуется красным цветом ошибки и ведёт себя как обычная основная кнопка. `error` — прежнее имя этого значения у кнопок. |
| `text-position` | строка | `center` | `start`, `center`, `end`, `justify` | Выравнивание подписи в кнопке шире текста: `start` — к началу, `center` — по центру, `end` — к концу. |
| `text` | строка | пусто | — | Текст кнопки, например `Сохранить`. |
| `segment` | строка | пусто | пусто, `start`, `middle`, `end` | Место кнопки в слитной группе: `start`, `middle` или `end` делают прямыми углы со стороны соседей; пусто — отдельная кнопка. |
| `icon` | строка | пусто | например `home`, `settings`, `search`, `edit`, `check`, `close` | Иконка кнопки по имени, например `edit`. |
| `icon-start` | строка | пусто | например `home`, `settings`, `search`, `edit`, `check`, `close` | Иконка перед подписью, например `add`. |
| `icon-end` | строка | пусто | например `home`, `settings`, `search`, `edit`, `check`, `close` | Иконка после подписи, например `arrow_forward`. |
| `icon-position` | строка | `start` | `start`, `end` | Где стоит иконка из `icon`: `start` — перед подписью, `end` — после. |
| `radius` | строка | пусто | пусто, `default`, `square`, `rounded` | Скругление углов: `square` — прямые, `rounded` — полностью круглые. |
| `loading` | да/нет | нет | — | Идёт загрузка: на месте иконки крутится индикатор, а без иконки — поверх подписи; ширина кнопки не меняется, нажать её нельзя. |
| `disabled` | да/нет | нет | — | Кнопка недоступна. |
| `native-type` | строка | `button` | `button`, `submit`, `reset` | Тип кнопки: `button`, `submit` или `reset`, как у обычной кнопки. |
| `form` | строка | пусто | — | `id` формы, которую отправляет или сбрасывает кнопка; так кнопка вне формы, например в подвале мастера, отправляет её. У кнопки-ссылки не действует. |
| `name` | строка | пусто | — | Имя, под которым `value` кнопки уходит с формой. |
| `value` | строка | пусто | — | Значение, которое кнопка отправляет под `name`, когда форму отправляют ею (`next`, `skip`); у цикла — значение текущего пункта, нажатие переводит его к следующему. |
| `href` | строка | пусто | — | Адрес перехода: кнопка становится ссылкой с видом кнопки и открывается как обычная ссылка, в том числе в новой вкладке. Подходят относительный адрес, `#якорь`, `http(s)`, `mailto` и `tel`; с другим адресом остаётся кнопка. У ссылки не действуют `native-type`, `expanded` и `pressed`; недоступная или загружающаяся ссылка никуда не ведёт. |
| `target` | строка | пусто | — | Где открывается ссылка, как `target` у обычной ссылки: `_blank` — в новой вкладке. У кнопки не действует. |
| `rel` | строка | пусто | — | Связь ссылки, как `rel` у обычной ссылки. Ссылка в новой вкладке (`target="_blank"`) без `rel` получает `noopener noreferrer`, чтобы новая страница не могла управлять этой. У кнопки не действует. |
| `shortcut` | строка | пусто | — | Сочетание клавиш в конце кнопки, мягкими плашками цвета подписи: слова через `+`, например `mod+k` (⌘K на Mac, Ctrl K в остальных системах), `shift+mod+p`, `shift+/`, `/` или `escape`. `mod` — Cmd на Mac и Ctrl в остальных системах. Странице стилизовать клавиши не нужно; сочетание также записывается в `aria-keyshortcuts`. Пусто — без клавиш. |
| `shortcut-listen` | да/нет | нет | — | Сочетание из `shortcut` нажимает кнопку с любого места страницы. Сочетание без `mod`, `ctrl`, `alt` или `meta` не срабатывает, пока человек печатает в поле. |
| `expanded` | да/нет | нет | — | Для кнопки, которая открывает панель или меню: `true` — открыто, `false` — закрыто. Экранный диктор сообщает это; без атрибута ничего не сообщает. |
| `pressed` | да/нет | нет | — | Кнопка-переключатель: `pressed` — включена и выглядит нажатой, `pressed="false"` — выключена. Без атрибута кнопка обычная. |
| `text-pressed` | строка | пусто | — | Подпись, пока переключатель включён, например «В избранном» вместо «В избранное». Если задана, состояние говорит сама подпись. |
| `theme-cycle` | строка | пусто | — | Готовый переключатель темы: по нажатию — следующая тема. Пустой атрибут — три значения в порядке владельца: сначала тема, противоположная видимой, потом другая, потом «как в системе» (D11d); `"light dark"` — два значения, каждое нажатие меняет видимую тему. Значки `contrast`, `light_mode` и `dark_mode`, слова — на языке страницы («Тема: светлая. Нажмите — тёмная»). Рядом с ним `cycle` не действует. |
| `aria-label` | строка | пусто | — | Название кнопки для экранного диктора; нужно кнопке без подписи. |
| `cycle` | список | `[]` | например `[{"value":"off","label":"выключен","icon":"repeat"},{"value":"all","label":"весь список","icon":"repeat","pressed":true},{"value":"one","label":"один трек","icon":"repeat_one","pressed":true}]` | Одна кнопка, несколько значений (D11d): список `{value, label, icon, pressed?}`, по которому нажатие идёт по кругу. `value` — текущее значение. Имя и значок говорят текущее значение («Скорость: 1,5×»), подсказка — текущее и следующее, после нажатия вежливо объявляется новое значение, затем приходит `change` с `{previous, value, item}`. Это не переключатель: `pressed` и `text-pressed` рядом с ним не действуют, в консоли — одно предупреждение. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для кнопки. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

| Метод | Возвращает | Что делает |

| `onClick(handler: function, options?: object\|boolean)` | объект | Подписывает на `click` у тега. Возвращает тег. |
| `onFocus(handler: function, options?: object\|boolean)` | объект | Подписывает на `focusin` у тега. Возвращает тег. |
| `onBlur(handler: function, options?: object\|boolean)` | объект | Подписывает на `focusout` у тега. Возвращает тег. |
| `onMouseEnter(handler: function, options?: object\|boolean)` | объект | Подписывает на `mouseenter` у тега. Возвращает тег. |
| `onMouseLeave(handler: function, options?: object\|boolean)` | объект | Подписывает на `mouseleave` у тега. Возвращает тег. |
| `setDisabled(nextValue?: boolean)` | объект | Делает кнопку недоступной (`true`) или снова доступной (`false`). Возвращает тег. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-button-press` | пустой объект | Нажатие: щелчок, Enter или пробел на кнопке или ссылке либо клавиша из `shortcut-listen`. Не приходит, если кнопка выключена или загружается. |
| `change` | `{ previous: string, value: string, item: object\|null }` | Кнопка-цикл (`cycle` или `theme-cycle`) перешла к следующему значению после нажатия человеком; приходит на сам элемент после `press`, всплывает. Цикл темы присылает его, когда тема уже применена. Кнопка без цикла его не присылает. |

### Для разработчика

**Атрибуты данных.** Атрибут `data-*` с тега переезжает на кнопку внутри: у
неё есть размеры, фокус и нажатие. Атрибут, снятый только с кнопки внутри,
вернётся при следующей отрисовке; снимайте его методом
`removeHostDataAttribute`.

```js
const inner = panel.querySelector('[data-action="save"]'); // кнопка внутри
const tag = inner.closest('sf-button');                    // сам тег
tag.dataAttributes.action;                                 // 'save'
```

**Значение кнопки.** Свойство `value` у тега — объект с настройками кнопки, а
не значение для формы. С формой уходит атрибут `value`.

```js
const tag = document.querySelector('sf-button');
tag.value;                 // {size: '1', appearance: 'default', …}
tag.getAttribute('value'); // 'save' — уходит с формой
```

**Другие атрибуты.** Атрибуты, которых нет в справочнике, копируются на кнопку
внутри: например, `title` и `aria-describedby`. Атрибуты из справочника, `class`, `style`,
`id` и `slot` остаются на теге.
