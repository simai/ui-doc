# Кнопки

:badge[sf-button]{type=tonal scheme=primary size=1/2} :badge[1.4.1]{type=outline scheme=on-surface size=1/2}

Кнопка запускает действие: сохранить, отправить, открыть окно. Вид, цвет,
размер, иконки и индикатор загрузки задаются атрибутами. Берите её там, где
кнопку создаёт шаблон или код, а состояние меняется во время работы.

То же на классах — [Кнопки](/ru/components/actions/buttons/): для статической
разметки без JavaScript.

## Пример

:::example {id="smart-components/buttons/overview" label="Кнопки рядом"}
:::

Кнопке нужна только подпись:

```html
<sf-button text="Сохранить"></sf-button>
```

Подпись можно передать и текстом внутри тега или элементом со
`slot="text"`.

## Когда брать

- **Кнопка или ссылка.** Сохранить, отправить, открыть окно — кнопка.
  Перейти на другую страницу — ссылка; ей можно дать вид кнопки, см.
  [Ссылку в виде кнопки](#ссылка-в-виде-кнопки).
- **Одна главная на экран.** Вид `default` получает одно действие, ради
  которого открыт экран. Остальным — виды полегче: `tonal`, `outline` или
  `link`.
- **Подпись — глагол.** «Сохранить», «Отправить отчёт», а не «ОК» или «Да»:
  подпись говорит, что случится после нажатия.
- **Опасное действие.** Удаление отмечает статус ошибки, а подпись называет,
  что пропадёт: «Удалить проект».

## Частые задачи

### Сохранение с загрузкой

Пока запрос идёт, кнопка показывает спиннер и не нажимается второй раз.

```js
const save = document.querySelector('#save');

save.addEventListener('sf-button-press', async () => {
  save.loading = true;
  try {
    await saveProfile();
  } finally {
    save.loading = false;
  }
});
```

### Удаление

Цвет ошибки и подпись с объектом предупреждают, что действие не отменить.

```html
<sf-button status="error" icon-start="delete" text="Удалить проект"></sf-button>
```

### Ссылка в виде кнопки

Переход остаётся ссылкой, даже когда выглядит кнопкой: работают Enter,
новая вкладка и адрес при наведении.

:::example {id="smart-components/buttons/link" label="Ссылки" preview=sandbox}
:::

```html
<sf-button href="/ru/guide/" appearance="outline" text="Руководство"></sf-button>
```

Ссылкой становятся относительный адрес, якорь, адрес http и https, почта и
телефон. С другой схемой, например ftp, остаётся кнопка. У недоступной ссылки
и ссылки в загрузке адреса нет: по ней не перейти.

### Отправка формы

Кнопка отправки передаёт с формой своё имя и значение, как обычная кнопка.

:::example {id="smart-components/buttons/form" label="Форма" preview=sandbox}
:::

Учтите: без `native-type="submit"` кнопка форму не отправляет — по умолчанию
её тип `button`.

## Внешний вид

Вид, цвет, размер и форму кнопки задают независимые атрибуты: у каждого одно
значение.

### Вид

`appearance` · по умолчанию `default` · [справочник](#атрибуты)

Вид показывает, насколько действие важно рядом с другими.

:::example {id="smart-components/buttons/appearance" label="Виды" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `default` | главное действие экрана, обычно одно |
| `tonal` | важное, но не главное |
| `outline` | второстепенное: «Отмена», «Назад» |
| `link` | самое лёгкое: в строке таблицы или рядом с текстом |
| `surface` | панель инструментов, цветной фон или изображение |

### Цвет и статус

`scheme`, по умолчанию `primary` · `status` · [справочник](#атрибуты)

Цвет отделяет акцентное действие от нейтрального, а статус отмечает опасное.

:::example {id="smart-components/buttons/scheme" label="Цвета" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `primary` | акцентное действие |
| `secondary` | второе цветное действие рядом с главным, когда два `primary` спорят |
| `on-surface` | нейтральное действие: «Отмена», панели |
| `on-surface-variant` | тихая кнопка, похожая на поле: поиск |

`status="error"` окрашивает кнопку цветом ошибки поверх любого цвета: для
удаления и необратимых действий.

### Размер

`size` · по умолчанию `1` · [справочник](#атрибуты)

Размер подгоняет кнопку к полям и строке, где она стоит.

:::example {id="smart-components/buttons/sizes" label="Размеры" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `1/3` | самые плотные места: строка таблицы, ячейка |
| `1/2` | панели инструментов и компактные формы |
| `1` | формы, диалоги и панели |
| `2` | заметное действие на странице |
| `3` | главное действие пустого экрана или заставки |

Кнопка и поле одного размера — одной высоты: в строке с полем берите тот же
размер.

### Плотность

`spacing` · по умолчанию `normal` · [справочник](#атрибуты)

Плотность меняет поля внутри кнопки, не меняя размер текста.

:::example {id="smart-components/buttons/spacing" label="Плотность" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `compact` | плотные таблицы и панели |
| `normal` | почти везде |
| `comfortable` | крупное одиночное действие |
| `spacious` | самое крупное одиночное действие |

### Скругление

`radius` · [справочник](#атрибуты)

Скругление подстраивает кнопку под форму соседних элементов.

:::example {id="smart-components/buttons/radius" label="Скругление" preview=inline}
:::

`square` убирает скругление, `rounded` делает края полностью круглыми. Без
атрибута кнопка скруглена, как все элементы управления.

### Иконки

`icon-start`, `icon-end` · [справочник](#атрибуты)

Иконка помогает узнать действие с первого взгляда. Она стоит перед подписью
или после неё.

:::example {id="smart-components/buttons/icons" label="Иконки" preview=inline}
:::

| Атрибут | Где иконка | Когда брать |
|:---|:---|:---|
| `icon-start` | перед подписью | действие узнаётся по значку: «Скачать», «Добавить» |
| `icon-end` | после подписи | кнопка ведёт дальше или раскрывает список: «Далее», «Ещё» |

```html
<sf-button text="Скачать отчёт" icon-start="download"></sf-button>
```

Одну иконку можно задать короче: `icon` и сторона в `icon-position`. Свою
картинку передаёт дочерний элемент со `slot="icon-start"` или
`slot="icon-end"`. Кнопка без подписи — [Кнопки с
иконкой](/ru/smart/actions/icon-buttons/).

### Кнопки встык

`segment` · [справочник](#атрибуты)

Кнопки встык читаются как один элемент из нескольких частей.

:::example {id="smart-components/buttons/segments" label="Кнопки встык"}
:::

| Значение | Когда брать |
|:---|:---|
| `start` | первая кнопка ряда |
| `middle` | любая кнопка между первой и последней |
| `end` | последняя кнопка ряда |

В примере выбранная кнопка — `outline`, остальные — `link`: так выбор виден
без цвета. Ряду нужны `role="group"` и общее имя. Готовый выбор одного
варианта — [Сегментный переключатель](/ru/smart/actions/segmented/).

## Состояния

Наведение, нажатие и фокус кнопка показывает сама. Остальные состояния задают
атрибуты.

### Недоступная

`disabled` · [справочник](#атрибуты)

Недоступная кнопка показывает, что действие сейчас выполнить нельзя.

:::example {id="smart-components/buttons/state-disabled" label="Недоступные" preview=inline}
:::

Она не нажимается и выпадает из порядка Tab. Почему действие недоступно,
объясните текстом рядом.

### Загрузка

`loading` · [справочник](#атрибуты)

Пока действие выполняется, кнопка показывает спиннер и не нажимается
повторно.

:::example {id="smart-components/buttons/loading" label="Загрузка" preview=inline}
:::

| Кнопка | Где спиннер |
|:---|:---|
| с иконкой | на месте иконки: начальной, а если её нет — конечной |
| без иконки | поверх подписи; ширина кнопки не меняется |
| [только с иконкой](/ru/smart/actions/icon-buttons/) | на месте иконки |

Спиннер растёт вместе с кнопкой:

:::example {id="smart-components/buttons/loading-sizes" label="Загрузка по размерам" preview=inline}
:::

Вид спиннера один на всю страницу; как его выбрать —
[Спиннер](/ru/smart/feedback/spinner/#вид-страницы).

:::example {id="smart-components/buttons/loading-looks" label="Виды спиннера" preview=inline}
:::

### Включённая и выключенная

`pressed` · [справочник](#атрибуты)

Кнопка-переключатель включает и выключает настройку: жирный шрифт,
избранное.

:::example {id="smart-components/buttons/toggle" label="Переключатели" preview=sandbox}
:::

`pressed` — кнопка включена, `pressed="false"` — выключена. Без атрибута
кнопка не переключатель. Сама кнопка состояние не меняет: его переключает
страница.

```html
<sf-button id="bold" pressed="false" icon-start="format_bold" text="Жирный"></sf-button>
```

```js
const bold = document.querySelector('#bold');

bold.addEventListener('sf-button-press', () => {
  bold.pressed = !bold.pressed;
  editor.setBold(bold.pressed);
});
```

## Сочетание клавиш

`shortcut`, `shortcut-listen` · [справочник](#атрибуты)

Сочетание на кнопке подсказывает быстрый путь, а `shortcut-listen` нажимает
кнопку с клавиатуры.

:::example {id="smart-components/buttons/shortcut" label="Сочетания клавиш" preview=sandbox}
:::

| Запись | На Mac | В других системах |
|:---|:---|:---|
| `mod+k` | ⌘ K | Ctrl K |
| `shift+mod+p` | ⇧ ⌘ P | Ctrl Shift P |
| `alt+n` | ⌥ N | Alt N |
| `escape` | Esc | Esc |

Слова пишутся через `+`, клавиша последней; `mod` — Cmd на Mac и Ctrl в
других системах. Клавиши рисует компонент [Клавиши](/ru/components/content/kbd/).

| Запись | Клавиши |
|:---|:---|
| `ctrl`, `alt`, `shift`, `meta` | модификаторы |
| `enter`, `escape`, `tab`, `space`, `backspace`, `delete` | Enter, Esc, Tab, пробел, удаление |
| `up`, `down`, `left`, `right`, `home`, `end`, `pageup`, `pagedown` | стрелки и переходы по странице |
| `plus` | клавиша + |

Учтите: сочетание без модификатора, например `/`, не срабатывает, пока фокус
в поле ввода.

## Работа из кода

Кнопку создают, слушают и настраивают из JavaScript, как обычный элемент.

### Нажатие

Для действия слушайте `sf-button-press`: его присылает только нажатие
человеком.

| Что произошло | `sf-button-press` | `click` |
|:---|:---|:---|
| щелчок, Enter или пробел на кнопке или ссылке | да | да |
| сочетание `shortcut-listen` | да | да |
| вызов `click()` у тега из кода | нет | да |
| щелчок по недоступной ссылке | нет | да |
| кнопка недоступна или в загрузке, ссылка в загрузке | нет | нет |

`detail` у `sf-button-press` — пустой объект. Метод `onClick(handler)`
подписывает на `click`.

### Свойства и методы

Каждому атрибуту отвечает свойство с тем же именем в camelCase:
`icon-start` — `iconStart`.

| Свойство | Что даёт |
|:---|:---|
| `loading`, `disabled` | загрузка и недоступность: `true` или `false` |
| `pressed` | `true`, `false` или `undefined`, если кнопка не переключатель |
| `text` | подпись |
| `dataAttributes` | атрибуты `data-*`, записанные на теге: `data-add` — `.add` |

Методы — в [справочнике](#методы).

```js
const button = await SF.createAsync('button', {
  text: 'Экспортировать',
  iconStart: 'download',
  appearance: 'outline',
});
document.querySelector('#toolbar').append(button);
```

## Доступность

Имя кнопки — её подпись. Кнопке только с иконкой нужно имя в `aria-label`,
удобнее взять [Кнопки с иконкой](/ru/smart/actions/icon-buttons/):

```html
<sf-button-icon icon="close" aria-label="Закрыть"></sf-button-icon>
```

Фокус получает кнопка внутри: Tab останавливается на ней, Enter и пробел
нажимают её. Фокус из кода ставит метод тега:

```js
document.querySelector('sf-button').focus();
```

Почему действие недоступно, объясните текстом и свяжите его с кнопкой:

```html
<sf-button text="Отправить" disabled aria-describedby="send-hint"></sf-button>
<p id="send-hint">Заполните адрес, чтобы отправить.</p>
```

Кнопка, которая открывает меню или панель, сообщает, открыта ли она:

```js
menuButton.expanded = true; // aria-expanded="true" на кнопке внутри
```

Нарисованные клавиши сочетания скрыты от экранного диктора: сочетание он
узнаёт из `aria-keyshortcuts`, который кнопка ставит сама. Цвет ошибки не
заменяет подпись — см. [Удаление](#удаление).

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Размер кнопки. |
| `appearance` | строка | `default` | `default`, `tonal`, `outline`, `link`, `surface` | Вид кнопки. `surface` использует нейтральную шкалу прозрачности: лёгкая заливка и рамка. |
| `scheme` | строка | `primary` | `primary`, `secondary`, `on-surface`, `on-surface-variant` | Цветовое семейство элемента управления. `on-surface-variant` — семейство `on-surface` на ступень тише: заливка и край `on-surface`, подпись и иконки — `--sf-on-surface-variant` (кнопка поиска, похожая на поле). Назначение элемента задаёт ось статуса; заданный там статус имеет приоритет. |
| `status` | строка | пусто | пусто, `error` | Назначение элемента управления в общем словаре статусов. Элемент управления окрашивает только `error` — деструктивный статус: элемент, который удаляет, отбрасывает или выполняет необратимое действие. |
| `text-position` | строка | `center` | `start`, `center`, `end`, `justify` | Как подпись выравнивается в кнопке шире её содержимого: `start`, `center` или `end` (утилита `text-align` на подписи). |
| `text` | строка | пусто | — | Видимый текст кнопки, если слот text не передан. |
| `segment` | строка | пусто | пусто, `start`, `middle`, `end` | Место кнопки в слитной группе: `start`, `middle` или `end` делают прямыми углы, общие с соседями; пусто — отдельная кнопка. |
| `icon` | строка | пусто | например `home`, `settings`, `search`, `edit`, `check`, `close` | Сокращение для имени одной иконки. |
| `icon-start` | строка | пусто | например `home`, `settings`, `search`, `edit`, `check`, `close` | Имя иконки в логическом начале. |
| `icon-end` | строка | пусто | например `home`, `settings`, `search`, `edit`, `check`, `close` | Имя иконки в логическом конце. |
| `icon-position` | строка | `start` | `start`, `end` | Расположение единственной иконки-ярлыка. |
| `spacing` | строка | `normal` | `compact`, `normal`, `comfortable`, `spacious` | Семантический профиль внутренних отступов. |
| `radius` | строка | пусто | пусто, `default`, `square`, `rounded` | Модификатор скругления углов. |
| `loading` | да/нет | нет | — | Состояние загрузки: спиннер размером с иконку на месте начальной иконки (если её нет — конечной); без иконки он лежит поверх подписи, которая остаётся на месте, поэтому ширина не меняется. Спиннер берёт вид страницы (data-sf-spinner). Ставит aria-busy и делает кнопку внутри недоступной. |
| `disabled` | да/нет | нет | — | Кнопка недоступна. |
| `native-type` | строка | `button` | `button`, `submit`, `reset` | Атрибут `type` кнопки внутри. |
| `href` | строка | пусто | — | Адрес: кнопка рисуется ссылкой (`<a href>`) с видом кнопки; роль link, Enter и клавиши браузера для ссылок ведут по ней. Относительный адрес, фрагмент, http(s), mailto или tel; с другой схемой рисуется кнопка. `native-type`, `expanded` и `pressed` не действуют; у отключённой или загружающейся кнопки у ссылки нет href и она сообщает `aria-disabled`. |
| `shortcut` | строка | пусто | — | Сочетание клавиш в конце кнопки, приглушёнными клавишами: слова через `+`, например `mod+k` (Cmd K на Mac, Ctrl K в других системах), `shift+/`, `/` или `escape`. `mod` — Cmd на устройствах Apple и Ctrl в остальных. Сочетание записывается и в `aria-keyshortcuts` кнопки внутри. Пусто — клавиш нет |
| `shortcut-listen` | да/нет | нет | — | Кнопка слушает своё сочетание на странице и нажимается им, как щелчком. Сочетание без `mod`, `ctrl`, `alt` или `meta` не слышно, пока фокус в редактируемом поле |
| `expanded` | да/нет | нет | — | Открыта ли панель, которую открывает эта кнопка: `aria-expanded` на кнопке внутри; нет атрибута — ничего не сообщается |
| `pressed` | да/нет | нет | — | Включена ли эта кнопка-переключатель: `aria-pressed` на кнопке внутри и вид выбранной (активное состояние таблицы стилей классов); `pressed="false"` сообщает «выключено»; без атрибута кнопка не переключатель и ничего не сообщает |
| `aria-label` | строка | пусто | — | Доступная подпись для кнопок только с иконкой или пользовательских кнопок. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Дополнительные классы внутреннего элемента кнопки. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `onClick(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик click на хост-элементе. Возвращает элемент. |
| `onFocus(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик focusin на хост-элементе. Возвращает элемент. |
| `onBlur(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик focusout на хост-элементе. Возвращает элемент. |
| `onMouseEnter(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик mouseenter на хост-элементе. Возвращает элемент. |
| `onMouseLeave(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик mouseleave на хост-элементе. Возвращает элемент. |
| `setDisabled(nextValue?: boolean)` | объект | Устанавливает атрибут disabled, если nextValue истинно, и удаляет его в противном случае. Возвращает элемент. |

### Для разработчика

**Атрибуты данных.** Атрибут `data-*` с тега переезжает на кнопку внутри: у
неё есть размеры, фокус и нажатие. Атрибут, снятый только с кнопки внутри,
вернётся при следующей отрисовке; снимайте его методом
`removeHostDataAttribute`.

```js
const inner = panel.querySelector('[data-action="save"]'); // кнопка внутри
const tag = inner.closest('sf-button');                    // сам тег
tag.dataAttributes.action;                                 // 'save'
```

**Значение кнопки.** Свойство `value` у тега — объект с настройками кнопки, а
не значение для формы. С формой уходит атрибут `value`.

```js
const tag = document.querySelector('sf-button');
tag.value;                 // {size: '1', appearance: 'default', …}
tag.getAttribute('value'); // 'save' — уходит с формой
```

**Другие атрибуты.** Атрибуты, которых нет в справочнике, копируются на кнопку
внутри: например, `name` и `title`. Атрибуты из справочника, `class`, `style`,
`id` и `slot` остаются на теге.
