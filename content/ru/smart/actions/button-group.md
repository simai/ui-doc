# Группа кнопок

:badge[sf-button-group]{type=tonal scheme=primary size=1/2} :badge[1.2.0]{type=outline scheme=on-surface size=1/2}

Группа кнопок даёт выбрать ровно один вариант: вид списка, период отчёта,
режим просмотра. Она собрана из [смарт-кнопок](/ru/smart/actions/buttons/).
Для независимых действий, которые можно нажимать в любом сочетании, берите
отдельные кнопки.

То же на классах — [Группа кнопок](/ru/components/actions/button-group/): для
статической разметки без JavaScript.

## Разметка

Группе нужны доступное имя, варианты и выбранное значение:

```html
<sf-button-group aria-label="Период отчёта" value="week"
  items="day::День|week::Неделя|month::Месяц"></sf-button-group>
```

Варианты передаются в `items` массивом JSON с полями `value`, `label`,
`icon`, `aria-label`, `disabled` и `loading`; сегментированный вид читает ещё
`count` и `icon-only`. Поле `lang` ставит атрибут `lang` на сегмент, когда
подпись написана на другом языке, чем страница: «Deutsch» на русской странице
читается немецким голосом:

```html
<sf-button-group aria-label="Вид" value="list"
  items='[{"value":"list","label":"Список","icon":"list"},{"value":"grid","label":"Плитка","icon":"grid_view"}]'></sf-button-group>
```

Короткая запись — строка, где варианты разделены символом `|`, а части
варианта — `::`: значение, подпись и флаги через запятую, например
`day::День|year::Год::disabled` или `week::Неделя::loading`. Флаг `icon=имя`
добавляет иконку. Значения в группе не повторяются: вариант с уже занятым
значением пропускается.

Выбранный вариант задаёт `value`. Группа без `value` ничего не выделяет.

## Варианты

Выбранная кнопка залита цветом из `scheme`, остальные остаются контурными
кнопками нейтрального цвета. `size` и `spacing` берут ту же шкалу, что
обычные кнопки.

### Вид

`appearance="segmented"` рисует группу как сегментный переключатель:
утопленная дорожка, сегменты без рамок и плашка под выбранным. Поведение то
же. Плашка, размеры вровень с кнопками, числа, иконки, готовый переключатель
темы (`theme-switch`) и CSS-переменные — на странице
[Сегментный переключатель](/ru/smart/actions/segmented/).

:::example {id="smart-components/button-group/appearance" label="Обычный и сегментированный вид"}
:::

### Схема

`scheme` — цвет выбранной кнопки: `primary`, `secondary` или `on-surface`.

:::example {id="smart-components/button-group/scheme" label="Цветовые схемы выбранной кнопки"}
:::

### Размер

`size` берёт ступень общей шкалы кнопок: `1/3`, `1/2`, `1`, `2`, `3`.

:::example {id="smart-components/button-group/sizes" label="Размеры группы"}
:::

### Плотность

`spacing` меняет внутренние отступы кнопок: `compact`, `normal`,
`comfortable`, `spacious`.

:::example {id="smart-components/button-group/spacing" label="Плотность группы"}
:::

### Радиус

`radius` — `default`, `square` или `rounded`, как у
[кнопок](/ru/smart/actions/buttons/); без атрибута — обычный радиус
элементов. В обычном виде радиус получают внешние углы группы, в
сегментированном — плашка и дорожка
([Скругление](/ru/smart/actions/segmented/#скругление)).

:::example {id="smart-components/button-group/radius" label="Радиус группы"}
:::

### Ориентация

`orientation="vertical"` ставит кнопки столбцом и сообщает ориентацию
вспомогательным технологиям; стрелки по обеим осям работают в любой
ориентации. Иконки вариантов задают поле `icon` или флаг `icon=имя`.

:::example {id="smart-components/button-group/options" label="Горизонтальная группа и вертикальная с иконками"}
:::

## Состояния

### Недоступна

`disabled` на `<sf-button-group>` отключает всю группу, флаг `disabled` у
варианта — только его.

:::example {id="smart-components/button-group/state-disabled" label="Недоступная группа и недоступный вариант"}
:::

### Загрузка варианта

Поле `loading` у варианта показывает, что его выбор ещё готовится: кнопка
варианта показывает [Спиннер](/ru/smart/feedback/spinner/) размером
с иконку — на месте иконки, а без иконки поверх подписи. Подпись остаётся на
месте и остаётся доступным именем, поэтому ширина кнопки не меняется. Вариант
получает `aria-busy="true"` и недоступен, пока поле не снято: стрелки его
пропускают. Так работают и обычная, и сегментированная группа.

Чтобы снять загрузку, передайте `items` заново без поля `loading`.

:::example {id="smart-components/button-group/loading" label="Вариант в загрузке: обычная группа, сегменты с иконкой и короткая запись"}
:::

## Поведение

### Значение и событие `change`

Нажатие или стрелка выбирает вариант и отправляет всплывающее событие
`change`. Его `event.detail`:

| Поле | Содержимое |
|:---|:---|
| `previous` | значение до изменения; пустая строка, если выбора не было |
| `value` | новое значение; после `clear()` — пустая строка |
| `item` | данные выбранного варианта: `value`, `label`, `icon`, `disabled`; после `clear()` — `null` |
| `component` | элемент `<sf-button-group>` |

`component` — живой элемент, а не данные, поэтому `detail` — не JSON:
`JSON.stringify(event.detail)` падает на циклической структуре. Берите нужные
поля (`previous` и `value` — строки) и передавайте их дальше:

```js
group.addEventListener('change', (event) => {
  const {previous, value} = event.detail;
  apply(value, previous);
});
```

Группа хранит выбор только в атрибуте `value`; сохранить его и применить
выбранный вид — задача страницы. Методы `select(value)` и `clear()` меняют
выбор из кода и отправляют то же событие; повторный выбор текущего варианта и
выбор недоступного варианта ничего не меняют.

### Создание из кода

Группу можно создать из кода. `items` передавайте строкой: массив, переданный
в `SF.create`, превращается в значение через пробел.

```js
const group = await SF.createAsync('button-group', {
  ariaLabel: 'Период отчёта',
  items: 'day::День|week::Неделя|month::Месяц',
  value: 'week',
});
document.querySelector('#report-toolbar').append(group);
await group.whenRendered();

group.addEventListener('change', (event) => {
  loadReport({period: event.detail.value});
});
group.select('month');
```

### В форме

С атрибутом `name` группа участвует в форме: отправляет `name=value`
выбранного варианта, сброс формы возвращает начальное значение, а группа с
`disabled` в отправку не входит
([пример](/ru/smart/actions/segmented/#в-форме)).

## Доступность

- Группе нужно доступное имя: `aria-label` на `<sf-button-group>`. Подписи
  вариантов его не заменяют.
- Группа — один переключатель (`radiogroup`) с одной остановкой `Tab` на
  выбранном варианте. Стрелки и `Home`, `End` переходят по доступным
  вариантам по кругу и сразу выбирают их; недоступные варианты пропускаются.
- Вариант только с иконкой получает имя из поля `aria-label`; подпись `label`
  нужна и тогда, когда её не видно.
- Выбранный вариант отличается не только цветом: у него есть
  `aria-checked="true"`.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `name` | строка | пусто | — | Имя поля формы: группа отправляет своё значение вместе с формой, сброс формы возвращает начальное значение, а отключённая группа в отправку не входит. |
| `theme-switch` | да/нет | нет | — | Готовый переключатель темы: группа сама рисует три пункта только с иконками (`system`, `light`, `dark`) с подписями на языке страницы, выбирает предпочтение темы `SF.Loader` и следует за `sf-theme-change`; выбор вызывает `SF.Loader.setTheme`. `items` не используется. |
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Общий токен размера кнопки. |
| `spacing` | строка | `normal` | `compact`, `normal`, `comfortable`, `spacious` | Общий семантический профиль внутренних отступов. |
| `scheme` | строка | `primary` | `primary`, `secondary`, `on-surface` | Цветовая схема выбранной кнопки, а в сегментированном виде — плашки выбранного сегмента. |
| `appearance` | строка | `default` | `default`, `segmented` | Вид группы. `default` собирает контурные кнопки в общий контур; `segmented` рисует утопленную дорожку с сегментами без рамок и плашкой под выбранным. Выбор, клавиатура и события одинаковы в обоих видах. |
| `plate` | строка | `scheme` | `scheme`, `raised` | Плашка выбранного сегмента в сегментированном виде: заливка цвета схемы или приподнятая нейтральная поверхность с тенью. |
| `full-width` | да/нет | нет | — | В сегментированном виде дорожка занимает ширину контейнера, а сегменты делят её поровну. |
| `radius` | строка | пусто | пусто, `default`, `square`, `rounded` | Скругление углов, как у `sf-button`: пустое значение — обычный радиус элементов. В сегментированном виде плашка — сегмент размером с кнопку — получает радиус кнопки с тем же значением, а дорожка — его же плюс отступ (при `rounded` обе — «таблетки»). |
| `orientation` | строка | `horizontal` | `horizontal`, `vertical` | Ориентация раскладки и навигации с клавиатуры. |
| `disabled` | да/нет | нет | — | Отключает всю группу. |
| `value` | строка | пусто | — | Значение выбранного элемента. |
| `aria-label` | строка | пусто | — | Доступное имя группы. |
| `items` | список: объект | `[]` | например `[{"value":"list","label":"List","icon":"list"},{"value":"grid","label":"Grid","icon":"grid_view"}]`, `[{"value":"all","label":"Все","count":24},{"value":"light","label":"Светлые","count":17},{"value":"dark","label":"Тёмные","count":7}]` | Выбираемые элементы со стабильными полями value, label, lang, icon, count, icon-only, disabled и loading. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона. |
| `root-class` | строка | пусто | — | Дополнительные классы корневого элемента группы. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `select(value: string)` | объект | Выбирает доступный элемент по значению. |
| `clear()` | объект | Сбрасывает текущий выбор. |
| `focus()` | объект или пусто | Переводит фокус на выбранный или первый доступный элемент. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `{ previous: string, value: string, item: object\\|null }` | Выбранное значение изменилось через select() или clear(); событие отправляется на хост-элементе, всплывает и с composed: true. Имя для привязки. |
