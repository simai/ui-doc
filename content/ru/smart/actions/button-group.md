# Группа кнопок

:badge[sf-button-group]{variant=tonal scheme=primary size=1/2} :badge[1.2.0]{variant=outline scheme=on-surface size=1/2}

Группа кнопок даёт выбрать ровно один вариант: вид списка, период отчёта,
режим просмотра. Выбранная кнопка залита цветом, остальные остаются
контурными. Для независимых действий, которые можно нажимать в любом
сочетании, берите отдельные [кнопки](/ru/smart/actions/buttons/#группа-кнопок).

То же на классах — [Группа кнопок](/ru/components/actions/button-group/): для
статической разметки без JavaScript.

## Пример

:::example {id="smart-components/button-group/overview" label="Вид списка задач" preview=sandbox log_console=true log_open=false}
:::

Группе нужны имя, варианты и выбранное значение:

```html
<sf-button-group aria-label="Период отчёта" value="week"
  items="day::День|week::Неделя|month::Месяц"></sf-button-group>
```

Группа без `value` ничего не выделяет.

## Когда брать

- **Один вариант из двух–пяти.** Период отчёта, вид списка, режим: выбор
  сразу меняет страницу.
- **Подписи короткие.** Длинные подписи и много вариантов — в [выпадающий
  список](/ru/smart/navigation/dropdown/) или
  [переключатели](/ru/smart/forms/radio/).
- **Варианты переключают панели** — это [вкладки](/ru/smart/navigation/tabs/):
  у них есть панели содержимого.
- **Независимые действия** — не группа выбора, а [кнопки встык](/ru/smart/actions/buttons/#группа-кнопок).

## Внешний вид

Вид, цвет, размер и форму задают независимые атрибуты, как у
[кнопок](/ru/smart/actions/buttons/#внешний-вид).

### Вид

`appearance` • по умолчанию `default` • [справочник](#атрибуты)

Вид решает, как выглядит группа; выбор и клавиатура те же.

:::example {id="smart-components/button-group/appearance" label="Виды" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `default` | контурные кнопки встык, выбранная залита |
| `segmented` | утопленная дорожка с плашкой под выбранным — [Сегментный переключатель](/ru/smart/actions/segmented/) |

### Цвет

`scheme` • по умолчанию `primary` • [справочник](#атрибуты)

Цвет заливки выбранной кнопки.

:::example {id="smart-components/button-group/scheme" label="Цвета" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `primary` | выбор на виду, рядом нет главного действия |
| `secondary` | тихий выбор рядом с главным действием |
| `on-surface` | нейтральный выбор без цвета проекта |

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

Размер подгоняет группу к полям и кнопкам рядом: шкала та же, что у кнопок.

:::example {id="smart-components/button-group/sizes" label="Размеры" preview=inline}
:::

### Плотность

`spacing` • по умолчанию `normal` • [справочник](#атрибуты)

Плотность меняет поля внутри кнопок, не меняя размер текста.

:::example {id="smart-components/button-group/spacing" label="Плотность" preview=inline}
:::

### Скругление

`radius` • [справочник](#атрибуты)

Скругление получают внешние углы группы.

:::example {id="smart-components/button-group/radius" label="Скругление" preview=inline}
:::

`square` убирает скругление, `rounded` делает края группы полностью
круглыми. Без атрибута группа скруглена, как все элементы управления.

### Ориентация

`orientation` • по умолчанию `horizontal` • [справочник](#атрибуты)

Варианты стоят в строку или столбцом.

:::example {id="smart-components/button-group/options" label="Ориентация" preview=inline}
:::

Стрелки по обеим осям работают в любой ориентации.

## Состояния

Наведение, нажатие и фокус группа показывает сама. Остальные состояния задают
атрибут и поля вариантов.

### Недоступная

`disabled` • [справочник](#атрибуты)

`disabled` на группе отключает её всю, флаг `disabled` у варианта — только
его.

:::example {id="smart-components/button-group/state-disabled" label="Недоступные" preview=inline}
:::

Недоступный вариант не выбирается, стрелки его пропускают.

### Загрузка варианта

`items` • поле `loading` • [справочник](#атрибуты)

Пока выбор варианта готовится, кнопка варианта показывает спиннер и не
нажимается.

:::example {id="smart-components/button-group/loading" label="Варианты в загрузке" preview=inline}
:::

Спиннер стоит на месте иконки, а без иконки — поверх подписи, поэтому
ширина кнопки не меняется. Чтобы снять загрузку, передайте `items` заново
без поля `loading`.

## Работа из кода

Группу создают, слушают и меняют из JavaScript, как обычный элемент.

### Варианты

`items` • [справочник](#атрибуты)

Варианты передаются в `items` короткой записью или массивом JSON.

:::example {id="smart-components/button-group/items" label="Записи вариантов" preview=inline}
:::

Короткая запись — строка, где варианты разделены `|`, а части варианта —
`::`: значение, подпись и флаги через запятую, например
`day::День|year::Год::disabled`. Флаг `icon=имя` добавляет иконку.

| Поле в JSON | Что даёт |
|:---|:---|
| `value`, `label` | значение и подпись |
| `icon` | иконка перед подписью |
| `aria-label` | имя варианта только с иконкой |
| `disabled`, `loading` | недоступный вариант и вариант в загрузке |
| `lang` | язык подписи, если он не язык страницы: «Deutsch» читается немецким голосом |

Значения в группе не повторяются: вариант с уже занятым значением
пропускается.

### Выбор

`value` • [справочник](#события)

Нажатие или стрелка выбирает вариант и отправляет всплывающее событие
`change`. Методы `select(value)` и `clear()` меняют выбор из кода и
отправляют то же событие.

:::example {id="smart-components/button-group/events" label="Выбор из кода" preview=sandbox log_console=true log_open=false}
:::

| Поле `detail` | Содержимое |
|:---|:---|
| `previous` | значение до изменения; пустая строка, если выбора не было |
| `value` | новое значение; после `clear()` — пустая строка |
| `item` | данные выбранного варианта; после `clear()` — `null` |

Повторный выбор текущего варианта и выбор недоступного
ничего не меняют. Сохранить выбор и применить вид — задача страницы.

```js
const group = await SF.createAsync('button-group', {
  ariaLabel: 'Период отчёта',
  items: 'day::День|week::Неделя|month::Месяц',
  value: 'week',
});
document.querySelector('#report-toolbar').append(group);

group.addEventListener('change', (event) => {
  loadReport({period: event.detail.value});
});
```

`items` из кода передавайте строкой: массив, переданный в `SF.create`,
превращается в значения через пробел.

### В форме

`name` • [справочник](#атрибуты)

С атрибутом `name` группа отправляет выбранное значение вместе с формой.

:::example {id="smart-components/button-group/form" label="Форма" preview=sandbox log_console=true log_open=false}
:::

Форма получает `name=value` выбранного варианта, сброс возвращает значение,
с которым группа была написана, а недоступная группа в отправку не входит.

## Доступность

Группе нужно имя в `aria-label`: подписи вариантов его не заменяют. Вариант
только с иконкой называется полем `aria-label`.

Группа — один переключатель (`radiogroup`) с одной остановкой Tab на
выбранном варианте. Стрелки, Home и End переходят по доступным вариантам по
кругу и сразу выбирают их.

Выбранный вариант отличается не только цветом: экранный диктор слышит
`aria-checked="true"`.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `name` | строка | пусто | — | Имя поля формы: группа отправляет своё значение вместе с формой, сброс формы возвращает начальное значение, а отключённая группа в отправку не входит. |
| `theme-switch` | да/нет | нет | — | Готовый переключатель темы: группа сама рисует три пункта только с иконками (`system`, `light`, `dark`) с подписями на языке страницы, выбирает предпочтение темы `SF.Loader` и следует за `sf-theme-change`; выбор вызывает `SF.Loader.setTheme`. `items` не используется. |
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Общий токен размера кнопки. |
| `spacing` | строка | `normal` | `compact`, `normal`, `comfortable`, `spacious` | Общий семантический профиль внутренних отступов. |
| `scheme` | строка | `primary` | `primary`, `secondary`, `on-surface` | Цветовая схема выбранной кнопки, а в сегментированном виде — плашки выбранного сегмента. |
| `appearance` | строка | `default` | `default`, `segmented` | Вид группы. `default` собирает контурные кнопки в общий контур; `segmented` рисует утопленную дорожку с сегментами без рамок и плашкой под выбранным. Выбор, клавиатура и события одинаковы в обоих видах. |
| `plate` | строка | `scheme` | `scheme`, `raised` | Плашка выбранного сегмента в сегментированном виде: заливка цвета схемы или приподнятая нейтральная поверхность с тенью. |
| `full-width` | да/нет | нет | — | В сегментированном виде дорожка занимает ширину контейнера, а сегменты делят её поровну. |
| `radius` | строка | пусто | пусто, `default`, `square`, `rounded` | Скругление углов, как у `sf-button`: пустое значение — обычный радиус элементов. В сегментированном виде плашка — сегмент размером с кнопку — получает радиус кнопки с тем же значением, а дорожка — его же плюс отступ (при `rounded` обе — «таблетки»). |
| `orientation` | строка | `horizontal` | `horizontal`, `vertical` | Ориентация раскладки и навигации с клавиатуры. |
| `disabled` | да/нет | нет | — | Отключает всю группу. |
| `value` | строка | пусто | — | Значение выбранного элемента. |
| `aria-label` | строка | пусто | — | Доступное имя группы. |
| `items` | список: объект | `[]` | например `[{"value":"list","label":"List","icon":"list"},{"value":"grid","label":"Grid","icon":"grid_view"}]`, `[{"value":"all","label":"Все","count":24},{"value":"light","label":"Светлые","count":17},{"value":"dark","label":"Тёмные","count":7}]` | Выбираемые элементы со стабильными полями value, label, lang, icon, count, icon-only, disabled и loading. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона. |
| `root-class` | строка | пусто | — | Дополнительные классы корневого элемента группы. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `select(value: string)` | объект | Выбирает доступный элемент по значению. |
| `clear()` | объект | Сбрасывает текущий выбор. |
| `focus()` | объект или пусто | Переводит фокус на выбранный или первый доступный элемент. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `{ previous: string, value: string, item: object\\|null }` | Выбранное значение изменилось через select() или clear(); событие отправляется на хост-элементе, всплывает и с composed: true. Имя для привязки. |
