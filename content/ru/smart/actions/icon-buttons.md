# Кнопки с иконкой

:badge[sf-button-icon]{variant=tonal scheme=primary size=1/2} :badge[1.4.1]{variant=outline scheme=on-surface size=1/2}

Кнопка с иконкой запускает действие одной иконкой вместо подписи: изменить,
поделиться, закрыть, открыть меню. Берите её в панелях инструментов и строках
таблиц, где подпись не помещается, а смысл иконки понятен; если сомневаетесь,
берите [кнопку с подписью](/ru/smart/actions/buttons/).

То же на классах — [Кнопки с иконкой](/ru/components/actions/icon-buttons/):
для статической разметки без JavaScript.

## Пример

:::example {id="smart-components/icon-buttons/overview" label="Кнопки с иконкой рядом"}
:::

Кнопке нужны иконка и имя:

```html
<sf-button-icon icon="edit" aria-label="Изменить"></sf-button-icon>
```

Иконка имени не даёт, поэтому `aria-label` обязателен. Новое имя можно задать
и после отрисовки: кнопка сразу его получит.

## Когда брать

- **Иконка понятна без подписи.** Карандаш, корзина, крестик, три точки —
  да. Если иконку нужно угадывать, берите [кнопку с
  подписью](/ru/smart/actions/buttons/).
- **Мало места.** Панель инструментов, строка таблицы, шапка карточки.
- **Повторяющееся действие.** В каждой строке таблицы одна и та же кнопка
  читается быстрее подписи.
- **Имя называет действие и объект.** «Удалить строку», а не «Корзина».

## Внешний вид

Вид, цвет, размер и форму задают независимые атрибуты, как у
[кнопок](/ru/smart/actions/buttons/#внешний-вид).

### Вид

`appearance` • по умолчанию `default` • [справочник](#атрибуты)

Вид показывает, насколько действие важно рядом с другими.

:::example {id="smart-components/icon-buttons/appearance" label="Виды" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `default` | главное действие панели |
| `tonal` | важное, но не главное |
| `outline` | второстепенное рядом с главным |
| `link` | самое лёгкое: рядом с текстом |
| `surface` | панель инструментов, цветной фон или изображение |
| `ghost` | действия в строке таблицы и шапке: без фона, пока не наведут |

### Цвет и статус

`scheme`, `status` • по умолчанию `scheme="primary"` • [справочник](#атрибуты)

Цвет отделяет акцентное действие от нейтрального, а статус отмечает опасное.

:::example {id="smart-components/icon-buttons/scheme" label="Цвета" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `primary` | акцентное действие |
| `secondary` | тихое второе действие |
| `on-surface` | нейтральные действия в строке и на панели |
| `on-surface-variant` | тихая кнопка рядом с полем или в шапке панели; в виде `default` такая же, как `on-surface` |

`status="error"` окрашивает кнопку цветом ошибки: для удаления и необратимых
действий.

### Иконка

`icon`, `filled`, `kind` • по умолчанию `icon="add"` • [справочник](#атрибуты)

Иконка называет действие. Залитая иконка отмечает включённое, а кнопка
закрытия рисует свой знак.

:::example {id="smart-components/icon-buttons/content" label="Иконки" preview=inline}
:::

| Атрибут | Что даёт |
|:---|:---|
| `icon` | имя иконки Material Symbols |
| `filled` | залитый вариант той же иконки: отмеченное избранное |
| `kind="close"` | знак [Закрытия](/ru/smart/actions/close/) того же размера вместо иконки |

Свою картинку передаёт дочерний элемент со `slot="icon"`.

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

Размер подгоняет кнопку к полям и строке, где она стоит.

:::example {id="smart-components/icon-buttons/sizes" label="Размеры" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `1/3` | самые плотные места: строка таблицы, ячейка |
| `1/2` | панели инструментов и компактные формы |
| `1` | формы, диалоги и панели |
| `2` | заметное действие на странице |
| `3` | главное действие пустого экрана |

Кнопка с иконкой той же высоты, что кнопка с подписью и поле того же
размера.

### Плотность

`spacing` • по умолчанию `normal` • [справочник](#атрибуты)

Плотность меняет поля вокруг иконки, не меняя её размер.

:::example {id="smart-components/icon-buttons/spacing" label="Плотность" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `compact` | плотные таблицы и панели |
| `normal` | почти везде |
| `comfortable` | крупное одиночное действие |
| `spacious` | самое крупное одиночное действие |

### Скругление

`radius` • [справочник](#атрибуты)

Скругление подстраивает кнопку под форму соседних элементов.

:::example {id="smart-components/icon-buttons/radius" label="Скругление" preview=inline}
:::

`square` убирает скругление, `rounded` делает кнопку круглой. Без атрибута
кнопка скруглена, как все элементы управления.

### Группа кнопок

`segment` • [справочник](#атрибуты)

Связанные действия стоят встык и читаются как одна кнопка из нескольких
частей.

:::example {id="smart-components/icon-buttons/segments" label="Группа кнопок с иконкой"}
:::

Значения и правила те же, что у [кнопок](/ru/smart/actions/buttons/#группа-кнопок).
Если в группе выбирают один вариант, берите [Группу
кнопок](/ru/smart/actions/button-group/) или [Сегментный
переключатель](/ru/smart/actions/segmented/).

### Счётчик и точка

`badge-count`, `badge-dot`, `badge-cap`, `badge-label` • [справочник](#атрибуты)

Счётчик в углу кнопки говорит, сколько нового, а точка — что новое есть.

:::example {id="smart-components/icon-buttons/badge" label="Счётчик и точка" preview=inline}
:::

| Атрибут | Что даёт |
|:---|:---|
| `badge-count` | число больше `0`; `0` или пусто прячет счётчик |
| `badge-dot` | точка без числа: есть новое |
| `badge-cap` | порог, по умолчанию `99`: число больше порога показывается как `99+` |
| `badge-label` | свои слова вместо «непрочитанных»: формы через `\|` с `{count}` на месте числа |

Счётчик растёт вместе с кнопкой, а на размерах `1/3` и `1/2` рисуется точкой:

:::example {id="smart-components/icon-buttons/badge-sizes" label="Счётчик по размерам" preview=inline}
:::

Точное число всегда входит в имя кнопки: «Уведомления, 3 непрочитанных».
Устройство счётчика — [Бейдж на якоре](/ru/components/feedback/badges/#бейдж-на-якоре).

## Состояния

Наведение, нажатие и фокус кнопка показывает сама. Остальные состояния задают
атрибуты.

### Недоступная

`disabled` • [справочник](#атрибуты)

Недоступная кнопка показывает, что действие сейчас выполнить нельзя.

:::example {id="smart-components/icon-buttons/state-disabled" label="Недоступные" preview=inline}
:::

Она не нажимается и выпадает из порядка Tab. Почему действие недоступно,
объясните текстом рядом.

### Загрузка

`loading` • [справочник](#атрибуты)

Пока действие выполняется, кнопка показывает спиннер на месте иконки и не
нажимается повторно.

:::example {id="smart-components/icon-buttons/loading" label="Загрузка по размерам" preview=inline}
:::

Спиннер того же размера, что иконка, поэтому кнопка не меняет размер. Имя
кнопки остаётся. Вид спиннера один на всю страницу —
[Спиннер](/ru/smart/feedback/spinner/#вид-страницы).

### Включённая и выключенная

`pressed` • [справочник](#атрибуты)

Кнопка-переключатель включает и выключает настройку: жирный шрифт,
избранное.

:::example {id="smart-components/icon-buttons/toggle" label="Переключатели" preview=sandbox log_console=true log_open=false}
:::

`pressed` — кнопка включена, `pressed="false"` — выключена. Без атрибута
кнопка не переключатель. Сама кнопка состояние не меняет: его переключает
страница. Имя кнопки при этом не меняется.

```js
const bold = document.querySelector('#bold');

bold.onClick(() => {
  bold.pressed = !bold.pressed;
  editor.setBold(bold.pressed);
});
```

## Работа из кода

Кнопку создают, слушают и настраивают из JavaScript, как обычный элемент.

### Нажатие

`native-type` • по умолчанию `button` • [справочник](#атрибуты)

Нажатие приходит событием `click`. Кнопка с `native-type="submit"`
отправляет форму, как обычная кнопка отправки.

:::example {id="smart-components/icon-buttons/press" label="Нажатие и форма" preview=sandbox log_console=true log_open=false}
:::

`onClick(handler)` подписывает на `click` и возвращает элемент.

### Свойства и методы

| Свойство или метод | Что даёт |
|:---|:---|
| `loading`, `disabled`, `pressed` | состояния: `true` или `false` |
| `setDisabled(true)` | делает кнопку недоступной и возвращает элемент |
| `dataAttributes` | атрибуты `data-*`, записанные на теге |

Остальное — в [справочнике](#методы).

```js
const remove = await SF.createAsync('icon-button', {
  icon: 'delete',
  appearance: 'ghost',
  scheme: 'on-surface',
  ariaLabel: 'Удалить строку',
});
row.querySelector('.row-actions').append(remove);
remove.onClick(() => deleteRow(row));
```

## Доступность

Каждой кнопке нужно имя в `aria-label`: иконка его не даёт. Называйте
действие и, если кнопок несколько, его объект: «Удалить строку», а не
«Корзина». Иконка скрыта от экранного диктора.

Фокус получает кнопка внутри: Tab останавливается на ней, Enter и пробел
нажимают её. Кольцо фокуса видно при работе с клавиатурой и не появляется
при нажатии мышью. Фокус из кода ставит метод тега:

```js
document.querySelector('sf-button-icon').focus();
```

Кнопка-переключатель сообщает своё состояние через `aria-pressed`, поэтому
её имя не меняется при включении.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `kind` | строка | `icon` | `icon`, `close` | Тип кнопки-иконки: обычное действие с иконкой или элемент закрытия. |
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Токен размера кнопки-иконки. |
| `appearance` | строка | `default` | `default`, `tonal`, `outline`, `link`, `surface`, `ghost` | Вид кнопки-иконки. `surface` и `ghost` используют нейтральную шкалу прозрачности: `surface` сохраняет лёгкую заливку и рамку, `ghost` не имеет ничего, пока на него не наведут курсор или фокус. |
| `scheme` | строка | `primary` | `primary`, `secondary`, `on-surface`, `on-surface-variant` | Цветовое семейство элемента управления. `on-surface-variant` — семейство `on-surface` на ступень тише: заливка и край `on-surface`, значок — `--sf-on-surface-variant`; так выглядит тихая кнопка рядом с полем или в шапке панели. Залитый элемент (`default`) сохраняет обратный значок `on-surface`: на тёмной заливке тише некуда. Назначение элемента задаёт ось статуса; заданный там статус имеет приоритет. |
| `status` | строка | пусто | пусто, `error` | Назначение элемента управления в общем словаре статусов. Элемент управления окрашивает только `error` — деструктивный статус: элемент, который удаляет, отбрасывает или выполняет необратимое действие. |
| `segment` | строка | пусто | пусто, `start`, `middle`, `end` | Позиция в объединённой группе элементов управления, которой управляет композиция Button Group. |
| `icon` | строка | `add` | — | Имя иконки Material. |
| `filled` | да/нет | нет | — | Использует ось filled шрифта иконок для стандартного варианта иконки. |
| `spacing` | строка | `normal` | `compact`, `normal`, `comfortable`, `spacious` | Внутренние отступы: `compact` плотнее, `spacious` свободнее. |
| `radius` | строка | пусто | пусто, `default`, `square`, `rounded` | Скругление углов: `square` — прямые, `rounded` — полностью круглые. |
| `loading` | да/нет | нет | — | Состояние загрузки: spinner на месте иконки, размером с неё, в виде страницы (data-sf-spinner). Ставит aria-busy и отключает нативную кнопку. |
| `disabled` | да/нет | нет | — | Кнопка недоступна. |
| `native-type` | строка | `button` | `button`, `submit`, `reset` | Атрибут `type` кнопки внутри. |
| `badge-count` | строка | пусто | — | Счётчик на кнопке-иконке: целое число больше 0 показывается, 0 или пусто прячет бейдж. Больше badge-cap он показывается как порог с плюсом, например «99+»; точное число входит в доступное имя кнопки («Уведомления, 5 непрочитанных») и во всплывающую подсказку бейджа. На якоре размера 1/3 или 1/2 счётчик рисуется точкой. |
| `badge-dot` | да/нет | нет | — | Точка на кнопке-иконке — отметка без числа: есть новое. Показывается, когда badge-count не задан; при заданном счётчике он рисуется точкой. Её текстовый эквивалент («есть новое» / «new» по умолчанию, другой задаёт badge-label) входит в доступное имя. |
| `badge-cap` | целое число | `99` | от 1 | Наибольший счёт, который рисуется числом; больший показывается как порог с плюсом, например «99+». |
| `badge-label` | строка | пусто | — | Слова, которые бейдж добавляет к доступному имени и к всплывающей подсказке вместо слов по умолчанию для языка страницы: для точки — весь текстовый эквивалент; для счёта — фраза в формах множественного числа через «\|» (one\|few\|many для русского, one\|other для английского) с {count} на месте числа. |
| `pressed` | да/нет | нет | — | Включена ли эта кнопка-переключатель: `aria-pressed` на кнопке внутри и вид выбранной кнопки; `pressed="false"` сообщает «выключено»; без атрибута кнопка не переключатель и ничего не сообщает. |
| `aria-label` | строка | пусто | — | Доступная подпись. |
| `button-attributes` | объект | — | — | Атрибуты, которые внешний шаблон проекта может поставить на свою кнопку; встроенный шаблон их не читает. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Дополнительные классы внутреннего элемента кнопки-иконки. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `setButtonAttributes(attributes?: object)` | объект | Передаёт объект в setState() как buttonAttributes; встроенный шаблон его не читает, поэтому он доходит только до внешнего шаблона проекта. Возвращает тег. |
| `onClick(handler: function, options?: object\|boolean)` | объект | Подписывает на `click` у тега. Возвращает тег. |
| `onFocus(handler: function, options?: object\|boolean)` | объект | Подписывает на `focusin` у тега. Возвращает тег. |
| `onBlur(handler: function, options?: object\|boolean)` | объект | Подписывает на `focusout` у тега. Возвращает тег. |
| `onMouseEnter(handler: function, options?: object\|boolean)` | объект | Подписывает на `mouseenter` у тега. Возвращает тег. |
| `onMouseLeave(handler: function, options?: object\|boolean)` | объект | Подписывает на `mouseleave` у тега. Возвращает тег. |
| `setDisabled(nextValue?: boolean)` | объект | Устанавливает атрибут disabled, если nextValue истинно, и удаляет его в противном случае. Возвращает тег. |

### Для разработчика

**Атрибуты данных.** Атрибут `data-*` с тега переезжает на кнопку внутри: у
неё есть размеры, фокус и нажатие, поэтому селектор `[data-…]` находит ровно
её. Сам тег своей области не имеет, к нему ведёт `closest('sf-button-icon')`.
Атрибут, снятый только с кнопки внутри, вернётся при следующей отрисовке;
снимайте его методом `removeHostDataAttribute`.

```js
const inner = menu.querySelector('[data-search-toggle]'); // кнопка внутри
const tag = inner.closest('sf-button-icon');              // сам тег
tag.dataAttributes.searchToggle;                          // значение атрибута
```

`focus()` и `blur()` на теге передаются кнопке внутри.
