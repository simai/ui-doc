# Кнопки с иконкой

`<sf-button-icon>` — кнопка с одной иконкой вместо подписи: изменить,
поделиться, закрыть, открыть меню. Берите её в панелях инструментов и строках
таблиц, где подпись не помещается, а смысл иконки понятен; если сомневаетесь,
берите [кнопку с подписью](/ru/smart/actions/buttons/).

То же на классах — [Кнопки с иконкой](/ru/components/actions/icon-buttons/):
нативная кнопка с тем же оформлением в статической разметке.

## Разметка

Кнопке нужны иконка и доступное имя:

```html
<sf-button-icon icon="edit" aria-label="Изменить"></sf-button-icon>
```

`icon` — имя иконки Material Symbols, по умолчанию `add`. Свою разметку
иконки передаёт слот `icon`. `aria-label` обязателен: иконка имени не даёт.

## Варианты

### Вид

`appearance` работает как у [Кнопки](/ru/smart/actions/buttons/):
`default`, `tonal`, `outline`, `link`, `surface`, `ghost`. Для второстепенных
действий в строке берите `ghost` или `link` со схемой `on-surface`, чтобы ряд
кнопок не спорил с основным действием.

:::example {id="smart-components/icon-buttons/appearance" label="Виды кнопки с иконкой"}
:::

### Схема

`scheme` выбирает цветовое семейство: `primary`, `secondary`, `on-surface`
или `on-surface-variant`; `status="error"` — для действия, которое удаляет
данные.

`on-surface-variant` — семейство `on-surface` на ступень тише: заливка и край
те же, а иконка окрашена `--sf-on-surface-variant`. Наведение, нажатие и
недоступность — как у `on-surface`. Так выглядит тихая кнопка рядом с полем,
в шапке панели или у строки. Залитая кнопка вида `default` сохраняет обратный
цвет иконки `on-surface`.

:::example {id="smart-components/icon-buttons/scheme" label="Цветовые семейства и статус ошибки"}
:::

### Содержимое

`filled` берёт залитый вариант той же иконки — например, для отмеченного
избранного. `kind="close"` делает кнопку закрытия: вместо иконки она рисует
знак [Закрытие](/ru/smart/actions/close/) того же размера.

:::example {id="smart-components/icon-buttons/content" label="Иконка, залитая иконка и кнопка закрытия"}
:::

### Размер

`size` — ступень шкалы `1/3`, `1/2`, `1`, `2`, `3`.

:::example {id="smart-components/icon-buttons/sizes" label="Размеры кнопки с иконкой"}
:::

### Плотность

`spacing` меняет внутренние отступы: `compact`, `normal`, `comfortable`,
`spacious`.

:::example {id="smart-components/icon-buttons/spacing" label="Плотность кнопки с иконкой"}
:::

### Радиус

`radius` меняет скругление: `default`, `square` или `rounded`.

:::example {id="smart-components/icon-buttons/radius" label="Радиус кнопки с иконкой"}
:::

### Сегменты

`segment` (`start`, `middle`, `end`) ставит кнопку в объединённую группу
элементов управления; обычно его задаёт сама группа. Группе нужны
`role="group"` и общее доступное имя.

:::example {id="smart-components/icon-buttons/segments" label="Кнопки с иконкой в сегментах"}
:::

### Счётчик и точка

- `badge-count` — счётчик в верхнем углу кнопки: целое число больше `0`; `0`
  или пусто прячет бейдж. Размер бейджа следует `size`: на `1/3` и `1/2`
  число рисуется точкой.
- `badge-dot` — точка без числа: есть новое.
- `badge-cap` — порог, по умолчанию `99`: число больше порога показывается как
  `99+`.
- `badge-label` — свои слова вместо «непрочитанных» и «есть новое»: формы
  множественного числа через `|` с `{count}` на месте числа.

Фраза добавляется к `aria-label`: «Уведомления, 3 непрочитанных», и в имени
всегда точное число. Устройство бейджа описано в разделе
[Бейдж на якоре](/ru/components/feedback/badges/#бейдж-на-якоре).

:::example {id="smart-components/icon-buttons/badge" label="badge-count на всех размерах, порог, точка и свои слова"}
:::

## Состояния

### Недоступная

`disabled` отключает кнопку.

:::example {id="smart-components/icon-buttons/state-disabled" label="Недоступные кнопки с иконкой"}
:::

### Загрузка

`loading` показывает загрузку и делает кнопку недоступной. Кнопка показывает
[Спиннер](/ru/smart/feedback/spinner/) на месте иконки, ровно её размера на
каждой ступени `size`, поэтому кнопка не меняет размер. Доступное имя из
`aria-label` остаётся, внутренняя кнопка получает `aria-busy="true"` и
нативный `disabled`. Спиннер окрашен цветом недоступной кнопки; другой цвет
задаёт `--sf-loader--color`. Вид спиннера —
[вид страницы](/ru/smart/feedback/spinner/#вид-страницы); при уменьшении движения спиннер показывает неподвижный
кадр этого вида.

:::example {id="smart-components/icon-buttons/loading" label="Загрузка и покой на всех размерах"}
:::

Переменная `--sf-icon-button-loading-stripe` устарела: Framework её не
задаёт, а страница, которая задаёт её сама, до 2026-12-01 получает
неподвижные полосы поверх кнопки в загрузке. Удалите её.

## Поведение

### Кнопка в форме и в коде

`native-type` задаёт нативный `type`: `button`, `submit` или `reset`.

Нажатие приходит событием `click`. `onClick(handler)` и другие помощники
подписывают обработчик и возвращают элемент, `setDisabled(true)` отключает
кнопку.

```js
const remove = await SF.createAsync('icon-button', {
  icon: 'delete',
  appearance: 'ghost',
  scheme: 'on-surface',
  ariaLabel: 'Удалить строку',
});
row.querySelector('.row-actions').append(remove);
remove.onClick(() => deleteRow(row));
```

### Атрибуты `data-*` и фокус

Как у [Кнопки](/ru/smart/actions/buttons/#атрибуты-data-и-фокус),
атрибут `data-*` с `<sf-button-icon>` переносится на внутреннюю нативную
кнопку: у неё есть размеры, она получает фокус и нажатие, поэтому селектор
`[data-…]` находит ровно один элемент — её. Хост своей области не имеет
(`display: contents`), к нему ведёт `closest('sf-button-icon')`.

```js
const toggle = menu.querySelector('[data-search-toggle]');  // нативная кнопка
toggle.focus();
toggle.closest('sf-button-icon');                            // хост
```

Записанное на хосте читает свойство `dataAttributes`
(`data-column-key` → `.columnKey`), а `removeHostDataAttribute(name)`
убирает атрибут и с хоста, и с кнопки. `focus()` и `blur()` на хосте
передаются внутренней кнопке.

## Доступность

- Каждой кнопке нужно доступное имя в `aria-label`: иконка его не даёт.
  Называйте действие и, если кнопок несколько, его объект: «Удалить строку»,
  а не «Корзина».
- Если кнопка переключает состояние, например избранное, имя говорит о
  действии, которое произойдёт, или кнопке задают `pressed` (с
  `sf-button-icon` 1.4.0): `pressed` — включена, `pressed="false"` —
  выключена, а внутренняя кнопка получает `aria-pressed`.
- Фокус получает внутренняя нативная кнопка: `Tab` останавливается на ней,
  `Enter` и `Space` нажимают её. Кольцо фокуса видно при работе с
  клавиатурой и не появляется при нажатии мышью.
- Иконка скрыта от вспомогательных технологий.

## Справочник

Собран из манифеста компонента выпуска `ui-e7b79c3a9e05` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Дополнительные классы внутреннего элемента кнопки-иконки. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |
| `kind` | строка | `icon` | `icon`, `close` | Тип кнопки-иконки: обычное действие с иконкой или элемент закрытия. |
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | Токен размера кнопки-иконки. |
| `appearance` | строка | `default` | `default`, `tonal`, `outline`, `link`, `surface`, `ghost` | Вид кнопки-иконки. `surface` и `ghost` используют нейтральную шкалу прозрачности: `surface` сохраняет лёгкую заливку и рамку, `ghost` не имеет ничего, пока на него не наведут курсор или фокус. |
| `scheme` | строка | `primary` | `primary`, `secondary`, `on-surface`, `on-surface-variant` | Цветовое семейство элемента управления. `on-surface-variant` — семейство `on-surface` на ступень тише: заливка и край `on-surface`, значок — `--sf-on-surface-variant`; так выглядит тихая кнопка рядом с полем или в шапке панели (то же значение есть у sf-button 1.2.0). Залитый элемент (`default`) сохраняет обратный значок `on-surface`: на тёмной заливке тише некуда. Назначение элемента задаёт ось статуса; заданный там статус имеет приоритет. |
| `status` | строка | пусто | пусто, `error` | Назначение элемента управления в общем словаре статусов. Элемент управления окрашивает только `error` — деструктивный статус: элемент, который удаляет, отбрасывает или выполняет необратимое действие. |
| `segment` | строка | пусто | пусто, `start`, `middle`, `end` | Позиция в объединённой группе элементов управления, которой управляет композиция Button Group. |
| `icon` | строка | `add` | — | Имя иконки Material. |
| `filled` | да/нет | нет | — | Использует ось filled шрифта иконок для стандартного варианта иконки. |
| `spacing` | строка | `normal` | `compact`, `normal`, `comfortable`, `spacious` | Семантический профиль внутренних отступов. |
| `radius` | строка | пусто | пусто, `default`, `square`, `rounded` | Модификатор скругления углов. |
| `loading` | да/нет | нет | — | Состояние загрузки: spinner на месте иконки, размером с неё, в виде страницы (data-sf-spinner). Ставит aria-busy и отключает нативную кнопку. |
| `disabled` | да/нет | нет | — | Флаг отключённого состояния. |
| `native-type` | строка | `button` | `button`, `submit`, `reset` | Нативный атрибут `type` кнопки. |
| `badge-count` | строка | пусто | — | Счётчик на кнопке-иконке: целое число больше 0 показывается, 0 или пусто прячет бейдж. Больше badge-cap он показывается как порог с плюсом, например «99+»; точное число входит в доступное имя кнопки («Уведомления, 5 непрочитанных») и во всплывающую подсказку бейджа. На якоре размера 1/3 или 1/2 счётчик рисуется точкой. |
| `badge-dot` | да/нет | нет | — | Точка на кнопке-иконке — отметка без числа: есть новое. Показывается, когда badge-count не задан; при заданном счётчике он рисуется точкой. Её текстовый эквивалент («есть новое» / «new» по умолчанию, другой задаёт badge-label) входит в доступное имя. |
| `badge-cap` | целое число | `99` | от 1 | Наибольший счёт, который рисуется числом; больший показывается как порог с плюсом, например «99+». |
| `badge-label` | строка | пусто | — | Слова, которые бейдж добавляет к доступному имени и к всплывающей подсказке вместо слов по умолчанию для языка страницы: для точки — весь текстовый эквивалент; для счёта — фраза в формах множественного числа через «\|» (one\|few\|many для русского, one\|other для английского) с {count} на месте числа. |
| `pressed` | да/нет | нет | — | Включена ли эта кнопка-переключатель: `aria-pressed` на нативной кнопке и вид выбранной (активное состояние таблицы стилей классов); `pressed="false"` сообщает «выключено»; без атрибута кнопка не переключатель и ничего не сообщает |
| `aria-label` | строка | пусто | — | Доступная подпись. |
| `tightness` | строка | пусто | `low`, `high`, `highest` | Псевдоним spacing для совместимости. |
| `button-attributes` | объект | — | — | Атрибуты, которые внешний шаблон проекта может поставить на свою кнопку; встроенный шаблон их не читает |

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `setButtonAttributes(attributes?: object)` | объект | Передаёт объект в setState() как buttonAttributes; встроенный шаблон его не читает, поэтому он доходит только до внешнего шаблона проекта. Возвращает элемент. |
| `onClick(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик click на хост-элементе. Возвращает элемент. |
| `onFocus(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик focusin на хост-элементе. Возвращает элемент. |
| `onBlur(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик focusout на хост-элементе. Возвращает элемент. |
| `onMouseEnter(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик mouseenter на хост-элементе. Возвращает элемент. |
| `onMouseLeave(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик mouseleave на хост-элементе. Возвращает элемент. |
| `setDisabled(nextValue?: boolean)` | объект | Устанавливает атрибут disabled, если nextValue истинно, и удаляет его в противном случае. Возвращает элемент. |
