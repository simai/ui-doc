# Групповые действия

:badge[sf-bulk-actions]{variant=outline scheme=on-surface size=1/2} :badge[1.2.1]{variant=outline scheme=on-surface size=1/2}

Полоса групповых действий появляется у списка, пока в нём что-то выбрано:
«Выбрано N», до трёх действий кнопками, остальные в «⋯» и крестик «Снять
выбор». Одна полоса служит таблице, карточкам, галерее, дереву и простому
списку. Что выбрано и как выполнить действие, решает список; полоса
показывает выбор, спрашивает перед опасным действием и сообщает итог.

## Пример

Отметьте несколько заказов и выберите действие. «В архив» можно отменить в
уведомлении, «Удалить» в меню «⋯» сначала спрашивает. Код — на вкладке
JavaScript.

## Разметка

Список ставит полосу после себя и пишет в неё, сколько выбрано:

```html
<sf-bulk-actions count="2" page-count="12" total="240"></sf-bulk-actions>
```

- `count` — сколько выбрано сейчас. Пока он `0`, полосы нет. Список пишет
  его при каждом изменении выбора.
- `page-count` — сколько записей на экране, `total` — сколько всего по
  фильтру. Когда выбрана вся страница, а записей по фильтру больше, полоса
  предлагает «Выбрать все 240».
- `count-text` — своя строка счёта вместо «Выбрано N» («Выбрано 3 · с
  вложенными 48»).
- `actions` — действия. Свойство задают из скрипта или в блоке настроек
  `<script type="application/json" data-sf-settings>`:

```js
bar.actions = [
  {id: 'publish', text: 'Опубликовать', icon: 'public', 'done-text': 'Опубликовано'},
  {id: 'archive', text: 'В архив', icon: 'archive', undo: true},
  {id: 'delete', text: 'Удалить', icon: 'delete', status: 'danger'},
];
```

| Поле действия | Что задаёт |
|:---|:---|
| `id`, `text`, `icon` | Ключ действия в событиях, подпись и значок. На телефоне действие показывает значок; действие без значка уходит в «⋯». |
| `status: 'danger'` | Опасное действие: всегда последнее в «⋯», красным, и перед ним вопрос «Удалить 2 элемента?» с «Вернуть будет нельзя». |
| `confirm` | Вопрос перед действием: `true` — словами полосы; объект — свои слова: `question`, `accept-text`, `consequence`. `false` снимает вопрос с опасного действия. |
| `undo: true` | Обратимое действие: выполняется сразу, а в уведомлении есть «Отменить». |
| `done-text` | Слово итога: «Удалено: 5»; без него — «Готово: 5». |
| `long` | `true` — действие идёт в фоне, `false` — в полосе, сколько бы записей ни было. |
| `min`, `max`, `reason` | Действие доступно только при таком числе выбранных; причину называет подсказка. |
| `disabled` | Действие недоступно; фокус на нём останавливается. |
| `priority` | Какие действия стоят кнопками: меньшее число — раньше; `pin` — всегда первым. Опасное действие всё равно в «⋯». |

## Варианты

### Место

`place` • по умолчанию `dock` • [справочник](#атрибуты)

| Значение | Когда брать |
|:---|:---|
| `dock` | Под списком во всю его ширину; при прокрутке полоса прилипает к низу экрана. |
| `top` | На месте панели инструментов над списком, на основном контейнере. |
| `float` | Плашка посередине нижнего края окна: для галереи и карточек без своей строки под список. |
| `inline` | Обычная строка в потоке. |

Список ставит элемент сам: после себя для `dock` и `inline`, перед собой
для `top`.

:::example {id="smart-components/bulk-actions/place" label="Над списком, под списком и в строке"}
:::

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

`size` — ступень кнопок и счёта: `1/2`, `1`, `2`. Без него полоса берёт
размер ближайшего элемента с размером вокруг — обычно списка. Высота полосы —
высота кнопки этой ступени и по 4 px сверху и снизу.

## Состояния

### Все по фильтру

`all-selected` • [справочник](#атрибуты)

Когда выбрана вся страница (`count` равен `page-count`) и `total` больше,
полоса предлагает «Выбрать все 240». На телефоне, когда ряд не помещается
в одну строку, предложение стоит в «⋯». После нажатия она говорит «Выбраны все
240», ставит `all-selected`, а следующее действие приходит с `scope: 'all'`.
«Только эта страница (12)» возвращает выбор к экрану; любое другое
изменение выбора — тоже. Действие больше чем на 100 записей идёт в фоне: в
полосе на миг «идёт в фоне», итог — во всплывающем сообщении.

:::example {id="smart-components/bulk-actions/all" label="Выбрать все 240" log="sf-bulk-actions-select-all sf-bulk-actions-select-page sf-bulk-actions-action" log_console=true log_open=false}
:::

### Ход и итог

`progress()`, `result()` • [справочник](#методы)

Короткий прогон идёт в полосе: `progress({done, total})` показывает
«Выполняем: 4 из 12», и действия недоступны до итога. `result({id, ok,
failed})` сообщает итог. Без отказов полоса четыре секунды говорит «Удалено:
5» на месте счёта. С отказами — «Готово 10 из 12 · 2 не удалось»,
«Подробнее» открывает список того, что не вышло и почему, «Повторить для 2»
отправляет действие ещё раз. Не получившиеся записи список оставляет
выбранными.

:::example {id="smart-components/bulk-actions/result" label="Публикация: две страницы не вышли" log="sf-bulk-actions-action" log_console=true log_open=false}
:::

## Поведение

### Событие действия

Человек выбрал действие (после «да» в вопросе, если вопрос есть) — приходит
`sf-bulk-actions-action` с `{id, scope, count, long}`. `scope` — `selection`
(выбранные) или `all` (все по фильтру), `long` — действие пойдёт в фоне.
Список выполняет действие и отвечает `result()`:

```js
bar.addEventListener('sf-bulk-actions-action', async (event) => {
  const {id, scope, count} = event.detail;
  const answer = await orders.run(id, scope);
  bar.result({id, ok: answer.ok, failed: answer.failed});
});
```

Отменённое событие (`preventDefault()`) — действие не принято; уведомление
обратимого действия тогда не показывается.

### Где виден итог

- **Быстрое действие** — итог в полосе, на месте «Выбрано N».
- **Долгое действие** (больше 100 записей или `long: true`) — идёт в фоне;
  итог приходит всплывающим сообщением, ошибка ждёт, пока её закроют, и
  предлагает «Подробнее». Ход долгой работы показывает
  [Ход выполнения](/ru/smart/feedback/progress-run/): `progress()` больше
  чем для 100 записей отвечает отказом.
- **Обратимое действие** сообщает об успехе один раз — уведомлением с
  «Отменить»; нажатие приходит событием `sf-bulk-actions-undo`, и список
  возвращает записи.
- **Неудача** любого действия уходит через `SF.notify` событием
  `sf-notification` с `source: 'sf-bulk-actions'`: центр уведомлений
  продукта записывает её.

### Снять выбор

Крестик и `Escape` присылают `sf-bulk-actions-clear` с `reason` (`button`,
`escape` или `api`); список снимает выбор и пишет `count="0"`. `Escape`
работает, пока фокус в списке или в полосе и не занят меню, окном или полем
ввода. Метод `clear()` делает то же из кода.

### Внешний вид

Открытые переменные: `--sf-bulk-actions-background`,
`--sf-bulk-actions-border-color`, `--sf-bulk-actions-color`,
`--sf-bulk-actions-gap` и `--sf-bulk-actions-radius`.

## Доступность

- Полоса — область (`role="region"`) с именем «Действия с выбранными»;
  своё имя задаёт `label`.
- Кнопки стоят обычным рядом в порядке `Tab`: предложение «Выбрать все»,
  действия, «⋯», крестик. `Enter` и пробел нажимают кнопку.
- Фокус не переходит в полосу, когда человек отмечает строку; окно-вопрос
  возвращает фокус туда, откуда его открыли, меню — на «⋯».
- Экранный диктор слышит «Выбрано 3», «Выбраны все 240», «Выбор снят», ход и
  итог — спокойно, после того как выбор устоялся.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `count` | целое число | `0` | от 0 | Сколько записей выбрано. 0 прячет полосу (её живая область остаётся и говорит «Выбор снят»); выбор держит приложение и пишет это значение при каждом изменении. |
| `page-count` | целое число | `0` | от 0 | Сколько записей на экране (строк страницы). Когда `count` равен ему, а `total` больше, полоса предлагает «Выбрать все N». 0 — неизвестно, предложения нет. |
| `total` | число | — | от 0 | Сколько записей по фильтру. Не задано или 0 — неизвестно (список с курсором), «Выбрать все N» нет. |
| `all-selected` | да/нет | нет | — | Выбраны все записи по фильтру: счёт говорит «Выбраны все 240», предложение становится «Только эта страница (12)», действие приходит со `scope` `all`. Полоса ставит его по «Выбрать все N» и снимает по «Только эта страница», при снятии выбора и когда `count` перестаёт быть равен `page-count`. |
| `count-text` | строка | пусто | — | Своя строка счёта вместо «Выбрано N» («Выбрано 3 · с вложенными 48» у дерева). Пусто — слова полосы. |
| `place` | строка | `dock` | `dock`, `top`, `float`, `inline` | Где стоит полоса: `dock` — по нижнему краю списка во всю его ширину, прилипает к низу прокрутки; `top` — на месте панели инструментов, на основном контейнере; `float` — плашка посередине нижнего края окна; `inline` — обычная строка в потоке. Элемент ставит приложение: после списка для `dock` и `inline`, перед ним для `top`. |
| `size` | строка | `1` | `1/2`, `1`, `2` | Ступень линейки для кнопок и счёта (высота полосы — высота элемента управления этой ступени и `space-1/4` сверху и снизу: 42 px у `1/2`, 50 у `1`). Не задано — размер ближайшего элемента с размером вокруг (списка, который ставит полосу), иначе `1`. |
| `label` | строка | — | — | Имя области. Пусто — «Действия с выбранными». |
| `actions` | список | `[]` | — | Действия над выбранными: до трёх кнопок с подписью и рамкой (на телефоне — одна кнопка-значок), остальные в «⋯» (общее меню страницы, `SF.menu.open`); опасное — всегда последним в «⋯». |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `progress(args: object)` | объект | Короткий прогон в полосе: «Выполняем: 4 из 12» (или «<текст>: 4 / 12») над полосой прогресса; действия недоступны, пока `done` не дойдёт до `total` или не придёт `result()`. Больше чем для 100 записей — отказ `{reason: long}`: такое действие идёт в фоне, его итог — в уведомлении, а ход показывает `sf-progress-run` приложения; без `total` — отказ `{reason: invalid}`. |
| `result(args: object)` | объект | Как прошло действие; неудачи — списком `[{id, text, reason}]`. Быстрое действие без отказов: полоса на 4 секунды говорит «Удалено: 5» (`done-text` действия, иначе «Готово: 5») на месте счёта и возвращается, выбор тем временем может стать пустым. С отказами — «Готово 10 из 12 · 2 не удалось» с «Подробнее» (список в окне-вопросе) и «Повторить для 2»; приложение оставляет не получившиеся записи выбранными, итог уходит, когда выбор меняется. Долгое действие (`long` в событии действия) — уведомление: об успехе или об ошибке, которая ждёт с «Подробнее». Неудача в любом случае записывается в «Уведомления»: запись `sf-notification` от `SF.notify` с `source` `sf-bulk-actions` (неудача быстрого действия не всплывает второй раз — её показывает полоса). Успех обратимого действия больше ничего не говорит: уведомление с «Отменить» уже сказало. |
| `clear()` | объект | Присылает `clear` с `{reason: api}`, как крестик. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-bulk-actions-action` | `{ id: any, scope: "selection" \| "all", count: number, long: boolean }` | Человек выбрал действие (после «да» в вопросе, если вопрос есть): приложение выполняет его над выбранными или над всеми по фильтру и сообщает итог методом `result()`. Отменённое событие — действие не принято; уведомление обратимого действия тогда не показывается. |
| `sf-bulk-actions-undo` | `{ id: any, scope: "selection" \| "all", count: number }` | Человек нажал «Отменить» в уведомлении обратимого действия: приложение возвращает записи. |
| `sf-bulk-actions-select-all` | `{ total: number, count: number }` | Человек выбрал «Выбрать все N»: выбраны все записи по фильтру (`all-selected` поставлен). |
| `sf-bulk-actions-select-page` | `{ count: number }` | Человек выбрал «Только эта страница»: выбор вернулся к записям на экране (`all-selected` снят). |
| `sf-bulk-actions-clear` | `{ count: number, scope: "selection" \| "all", reason: "button" \| "escape" \| "api" }` | Человек нажал × или Escape (или страница вызвала `clear()`): приложение снимает выбор и пишет `count` 0. |
