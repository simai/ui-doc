# Действия

- [Кнопки](/ru/smart/actions/buttons/) — Запускает действие кнопкой с подписью, иконкой и состоянием загрузки.
- [Кнопки с иконкой](/ru/smart/actions/icon-buttons/) — Запускает действие компактной кнопкой с одной иконкой и доступным именем.
- [Группа кнопок](/ru/smart/actions/button-group/) — Переключает один из нескольких взаимоисключающих вариантов: вид списка, период, режим.
- [Сегментный переключатель](/ru/smart/actions/segmented/) — Выбирает одно значение из нескольких на утопленной дорожке: период, вид, фильтр, тему оформления.
- [Закрытие](/ru/smart/actions/close/) — Рисует знак закрытия внутри кнопки, которую задаёт страница.
- [Скачивание файла](/ru/smart/actions/download-file/) — Показывает файл для скачивания с именем и размером и сообщает о нажатии.
- [Кнопка копирования](/ru/smart/actions/copy-button/) — Копирует значение или текст элемента, показывает результат галочкой и сообщает о нём экранному диктору.
- [Подтверждение](/ru/smart/actions/confirm/) — Вопрос человеку прямо на месте: что случится, два ответа, ожидание, итог и срок.
