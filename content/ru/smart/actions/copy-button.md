# Кнопка копирования

:badge[sf-button-copy]{type=tonal scheme=primary size=1/2} :badge[1.2.0]{type=outline scheme=on-surface size=1/2}

Кнопка копирования копирует значение и сообщает о результате: значок на миг
становится галочкой, а «Скопировано» вежливо объявляется для чтения с экрана.
Берите её, когда копируется содержимое другого элемента (`target`), нужно
сообщение о результате и запасной путь там, где буфер обмена недоступен.

То же на классах — [Копирование](/ru/components/actions/clipboard/): классы
`sf-clipboard` для готовой разметки без смарт-компонентов.

## Разметка

Кнопке нужен источник текста и доступное имя:

```html
<code id="token">sk_test_51H…</code>
<sf-button-copy target="#token" label="Скопировать ключ"></sf-button-copy>
<sf-button-copy value="npm i @simai/ui" text="Копировать" label="Копировать команду"></sf-button-copy>
```

Источник задаёт один из двух атрибутов:

- `value` — сам текст;
- `target="#id"` — значение поля или текст элемента; пронумерованный блок
  кода копируется без номеров строк.

Задать сразу и `value`, и `target` — ошибка (`ambiguous_source`). Оба
атрибута читаются при каждом копировании, поэтому другое значение достаточно
присвоить свойству: `button.value = …` или `button.target = '#id'`.

`text` — видимая подпись; без неё кнопка — только значок. `label` — доступное
имя (см. «Доступность»).

## Варианты

### Оформление

`appearance` — `link` (по умолчанию), `ghost`, `outline` или `tonal`.
`root-style` ложится на саму кнопку.

:::

### Размер

`size` — `1/3`, `1/2` (по умолчанию), `1` или `2`, по общей лестнице
размеров: рядом с полем `sf-input--size-1` берите `1`.

:::example {id="smart-components/copy-button/sizes" label="Размеры кнопки копирования"}
:::

### Иконки и подпись

`icon` — значок в покое, по умолчанию `content_copy`: например, `link` для
ссылки или `key` для ключа. `success-icon` — значок после копирования, по
умолчанию `check`. С `text` рядом со значком стоит видимая подпись.

## Поведение

### Результат копирования

После копирования значок на время становится `success-icon`, а сообщение
объявляется для чтения с экрана. `success-text` и `error-text` — свои
сообщения, `duration` — сколько миллисекунд держится результат, по умолчанию
2000. Пока идёт копирование, повторное нажатие не срабатывает.

### Когда копировать нельзя

Если браузер не дал доступ к буферу обмена — страница во фрейме или так
настроена политика, — кнопка выделяет текст и сообщает «Выделено — нажмите
Ctrl+C» (⌘C на macOS), чтобы человек скопировал сам.

### События и код

`sf-copy-button-copied` приходит с `{text, method}`,
`sf-copy-button-copy-failed` — с `{code}`: `empty_source`, `missing_target`,
`ambiguous_source` или `denied`. Прежние имена `sf-copy` и `sf-copy-error`
приходят с тем же `detail`. Метод `copy()` копирует из кода так же, как
нажатие.

```js
document.addEventListener('sf-copy-button-copied', (event) => {
  console.log(event.detail.text);
});
```

## Доступность

- `label` — доступное имя: что именно копируется («Скопировать команду»). По
  умолчанию «Копировать». Если на странице несколько кнопок, называйте каждую,
  иначе экранный диктор не различит их.
- У кнопки с `text` доступное имя начинается с видимой подписи: при
  `text="Копировать"` — `label="Копировать команду"`, а не «Скопировать
  команду». Так человек, который управляет голосом, называет кнопку тем
  словом, которое видит.
- У кнопки только со значком видимого имени нет, а всплывающую подсказку
  к смарт-кнопке не подключить (см. [Подсказка](/ru/components/overlays-media/tooltip/#разметка)). Где зрячему человеку
  нужно имя, задайте `text`.
- Результат объявляется вежливо, не перебивая.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `value` | строка | пусто | — | Текст для копирования. |
| `target` | строка | пусто | — | `#id` поля (копируется его значение) или элемента (его текст; пронумерованный блок кода — без номеров строк). value и target вместе — ошибка. |
| `text` | строка | пусто | — | Видимая подпись; без неё кнопка — только значок. |
| `label` | строка | пусто | — | Доступное имя, говорящее, что копируется («Скопировать команду»); по умолчанию «Копировать». |
| `size` | строка | `1/2` | `1/3`, `1/2`, `1`, `2` | — |
| `appearance` | строка | `link` | `link`, `ghost`, `outline`, `tonal` | — |
| `icon` | строка | `content_copy` | — | Значок в покое: link, key и другие. |
| `success-icon` | строка | `check` | — | — |
| `success-text` | строка | пусто | — | — |
| `error-text` | строка | пусто | — | — |
| `duration` | целое число | `2000` | от 0 | Сколько миллисекунд результат остаётся на экране |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `copy()` | объект | Копирует так же, как нажатие; нажатие во время копирования игнорируется. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-button-copy-copied` | `{ text: string, method: any }` | — |
| `sf-button-copy-copy-failed` | `{ code: any }` | — |
