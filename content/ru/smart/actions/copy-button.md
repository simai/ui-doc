# Кнопка копирования

:badge[sf-button-copy]{variant=tonal scheme=primary size=1/2} :badge[1.2.0]{variant=outline scheme=on-surface size=1/2}

Кнопка копирования кладёт в буфер обмена значение — ключ, команду, ссылку —
и показывает, что всё получилось: значок на миг становится галочкой, а
экранный диктор слышит «Скопировано». Где буфер недоступен, кнопка выделяет
текст, чтобы человек скопировал его сам.

То же на классах — [Копирование](/ru/components/actions/clipboard/): для
статической разметки без JavaScript.

## Пример

:::example {id="smart-components/copy-button/overview" label="Ключ, команда, ссылка" preview=sandbox log_console=true log_open=false}
:::

Кнопке нужны источник текста и имя:

```html
<code id="token">sk_test_51H…</code>
<sf-button-copy target="#token" label="Скопировать ключ"></sf-button-copy>
```

## Когда брать

- **Значение, которое переносят в другое место**: ключ, идентификатор,
  команда, ссылка на запись.
- **Значение длинное или неудобное для выделения** — копировать мышью
  неудобно.
- **Имя называет, что копируется.** «Скопировать команду», а не
  «Копировать», если кнопок на экране несколько.

## Частые задачи

### Что копировать

`value`, `target` • [справочник](#атрибуты)

Источник задаёт один из двух атрибутов: `value` — сам текст, `target="#id"` —
значение поля или текст элемента. Пример выше копирует идентификатор по
`target`, а команду и ссылку — по `value`.

```html
<sf-button-copy value="npm i @simai/ui" text="Копировать" label="Копировать команду"></sf-button-copy>
```

Блок кода с номерами строк копируется без номеров. Оба атрибута читаются при
каждом копировании, поэтому новое значение достаточно присвоить свойству:
`button.value = …`. Задать сразу и `value`, и `target` — ошибка.

## Внешний вид

### Вид

`appearance` • по умолчанию `link` • [справочник](#атрибуты)

Вид показывает, насколько кнопка заметна рядом со значением.

:::example {id="smart-components/copy-button/appearance" label="Виды" preview=inline}
:::

| Значение | Когда брать |
|:---|:---|
| `link` | рядом с текстом и значением в строке |
| `ghost` | в таблице и шапке: без фона, пока не наведут |
| `outline` | рядом с полем ввода |
| `tonal` | заметное отдельное действие |

### Размер

`size` • по умолчанию `1/2` • [справочник](#атрибуты)

Размер подгоняет кнопку к полю или тексту рядом.

:::example {id="smart-components/copy-button/sizes" label="Размеры" preview=inline}
:::

Рядом с полем размера `1` берите `size="1"`.

### Значок и подпись

`icon`, `success-icon`, `text` • по умолчанию `icon="content_copy"` • [справочник](#атрибуты)

Значок подсказывает, что копируется, а подпись делает действие видимым
словом.

:::example {id="smart-components/copy-button/icons" label="Значок и подпись" preview=inline}
:::

| Атрибут | Что даёт |
|:---|:---|
| `icon` | значок в покое: `link` для ссылки, `key` для ключа |
| `success-icon` | значок после копирования, по умолчанию `check` |
| `text` | видимая подпись рядом со значком |

## Состояния

### Результат

`success-text`, `error-text`, `duration` • по умолчанию `duration="2000"` • [справочник](#атрибуты)

После копирования значок на время сменяется, а сообщение объявляется для
экранного диктора. Нажмите кнопки в примере.

:::example {id="smart-components/copy-button/result" label="Результат" preview=sandbox log_console=true log_open=false}
:::

`success-text` и `error-text` — свои слова сообщений, `duration` — сколько
миллисекунд держится результат. Пока идёт копирование, повторное нажатие не
срабатывает.

Если браузер не дал доступ к буферу обмена — например, страница во фрейме, —
кнопка выделяет текст и сообщает «Выделено — нажмите Ctrl+C» (⌘C на Mac).

## Работа из кода

### События

`sf-button-copy-copied`, `sf-button-copy-copy-failed` • [справочник](#события)

Кнопка сообщает, что скопировала, или почему не смогла. События видны в
журнале под [примером](#пример).

| Событие | `detail` |
|:---|:---|
| `sf-button-copy-copied` | `text` — скопированный текст, `method` — как скопировано |
| `sf-button-copy-copy-failed` | `code`: `empty_source`, `missing_target`, `ambiguous_source` или `denied` |

Метод `copy()` копирует из кода так же, как нажатие.

```js
document.addEventListener('sf-button-copy-copied', (event) => {
  console.log(event.detail.text);
});
```

## Доступность

`label` — имя кнопки: что именно копируется. По умолчанию «Копировать». Если
кнопок несколько, называйте каждую, иначе экранный диктор их не различит.

У кнопки с `text` имя начинается с видимой подписи: при `text="Копировать"`
— `label="Копировать команду"`, а не «Скопировать команду». Так человек,
который управляет голосом, называет кнопку словом, которое видит.

У кнопки только со значком видимого имени нет, а всплывающую подсказку к ней
не подключить (см. [Подсказка](/ru/components/overlays-media/tooltip/#разметка)).
Где зрячему человеку нужно имя, задайте `text`. Результат объявляется
вежливо, не перебивая.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `value` | строка | пусто | — | Текст для копирования. |
| `target` | строка | пусто | — | `#id` поля (копируется его значение) или элемента (его текст; пронумерованный блок кода — без номеров строк). value и target вместе — ошибка. |
| `text` | строка | пусто | — | Видимая подпись; без неё кнопка — только значок. |
| `label` | строка | пусто | — | Доступное имя, говорящее, что копируется («Скопировать команду»); по умолчанию «Копировать». |
| `size` | строка | `1/2` | `1/3`, `1/2`, `1`, `2` | — |
| `appearance` | строка | `link` | `link`, `ghost`, `outline`, `tonal` | — |
| `icon` | строка | `content_copy` | — | Значок в покое: link, key и другие. |
| `success-icon` | строка | `check` | — | — |
| `success-text` | строка | пусто | — | — |
| `error-text` | строка | пусто | — | — |
| `duration` | целое число | `2000` | от 0 | Сколько миллисекунд результат остаётся на экране. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `copy()` | объект | Копирует так же, как нажатие; нажатие во время копирования игнорируется. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-button-copy-copied` | `{ text: string, method: any }` | — |
| `sf-button-copy-copy-failed` | `{ code: any }` | — |
