# Пустое состояние

:badge[sf-empty-state]{type=tonal scheme=primary size=1/2} :badge[1.1.6]{type=outline scheme=on-surface size=1/2}

`<sf-empty-state>` — то, что список, панель или страница показывает, когда
показать нечего. Одна причина — один вид: значок, заголовок, пояснение и, если
нужно, действие.

## Разметка

Достаточно причины; без `kind` берётся `no-data`:

```html
<sf-empty-state kind="nothing-found" heading-level="4"></sf-empty-state>
```

`heading-level` (от 2 до 6, по умолчанию 3) ставит заголовок на нужный
уровень структуры страницы: на целой странице это обычно 2, в панели — 3
или 4. Вид заголовка от уровня не зависит. Действия передают в слот
`actions` — любые `sf-button`.

## Варианты

### Причина

| `kind` | Значок | Заголовок и текст по умолчанию |
|:---|:---|:---|
| `no-data` (по умолчанию) | `inbox` | «Пока ничего нет» / «Здесь появятся записи, когда они будут» |
| `nothing-found` | `search_off` | «Ничего не найдено» / «Попробуйте изменить запрос или фильтры» |
| `no-access` | `lock` | «Нет доступа» / «Обратитесь к администратору» |
| `error` | `error` | «Не удалось загрузить» / «Попробуйте ещё раз» и кнопка «Повторить» |

Тексты по умолчанию следуют языку страницы. `icon`, `heading` и `text`
заменяют их, когда причина конкретнее: «Машин пока нет», «Создайте первую».
`title` — другое имя `heading`, работает до 2026-12-01; это и общий атрибут
HTML, поэтому браузер показывает его всплывающей подсказкой при наведении на
блок.

:::example {id="smart-components/empty-state/kinds" label="Причины и свои тексты"}
:::

### Размер

- `size="1/2"` — внутри таблицы или панели;
- `size="1"` — по умолчанию;
- `size="2"` — целая страница.

От размера зависят значок, роль заголовка, текст и промежутки. Ширина — не
больше 28rem, её меняет переменная `--sf-empty-state-max-inline-size`.

:::example {id="smart-components/empty-state/sizes" label="Размеры пустого состояния"}
:::

### Компактная форма

`layout="inline"` (и всегда `size="1/3"`) — одна строка высотой с контрол 1/2
с отступом строки списка: маленький значок, текст (`text`, а без него —
заголовок причины) и не больше одного действия-ссылки, без заголовка. Её
ставят в списки меню, выпадающих списков и поиска; внутри `listbox` или меню
— вне элемента списка, чтобы она не считалась пунктом.

:::

## Поведение

### Действия

Действия передают в слот `actions` — любые `sf-button` — или свойством
`actions` со списком `[{id, text, appearance}]`. Кнопки из свойства рисуются в
размере компонента и сообщают `sf-empty-state-action` с `{id}`. У
`kind="error"` без своих действий есть «Повторить» (`id: retry`). Пустой
массив `actions = []` и кнопки в слоте `actions` тоже считаются своими
действиями, и «Повторить» не показывается; чтобы вернуть его, присвойте
`actions = null`.

```html
<sf-empty-state kind="error" id="failed"></sf-empty-state>
<script>
  failed.addEventListener('sf-empty-state-action', (event) => {
    if (event.detail.id === 'retry') reload();
  });
</script>
```

## Доступность

- `live="auto"` (по умолчанию): «Ничего не найдено» и ошибка объявляются
  вежливо (`role="status"`), остальные причины не объявляются. `live="alert"`
  — для ошибки, вызванной действием человека, `live="off"` — когда объявляет
  сам хост.
- Заголовок — настоящий заголовок уровня `heading-level`, поэтому состояние
  видно в оглавлении страницы.
- Значок декоративный.

## Справочник

Собран из манифеста компонента выпуска `ui-1ec283e856cd` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |
| `kind` | строка | `no-data` | `no-data`, `nothing-found`, `no-access`, `error` | Причина: от неё зависят значок, заголовок и текст по умолчанию, а у error — действие «Повторить». |
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2` | 1/3 — всегда компактная форма; 1/2 — внутри таблицы или панели, 2 — для целой страницы; от размера зависят значок, роль заголовка, текст и промежутки. |
| `icon` | строка | пусто | — | — |
| `heading` | строка | пусто | — | — |
| `text` | строка | пусто | — | — |
| `heading-level` | целое число | `3` | от 2; до 6 | Уровень заголовка в структуре страницы; его вид зависит от размера. |
| `layout` | строка | `block` | `block`, `inline` | inline — одна строка для списка в меню, выпадающем списке или поиске: маленький значок, текст и не больше одного действия-ссылки, без заголовка. |
| `live` | строка | `auto` | `auto`, `alert`, `off` | auto — nothing-found и error объявляются вежливо, остальные молчат; alert — ошибка, вызванная действием человека; off — объявляет хост. |
| `title` | строка | пусто | — | Псевдоним с датой для `heading` до 2026-12-01. |
| `actions` | список | — | — | — |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

Публичных методов нет.

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-empty-state-action` | `{ id: string }` | Человек нажал одно из действий (retry — у ошибки без собственных действий). |
