# Пустое состояние

:badge[sf-empty-state]{variant=outline scheme=on-surface size=1/2} :badge[1.6.8]{variant=outline scheme=on-surface size=1/2}

Пустое состояние объясняет, почему в списке, панели или на странице нечего
показать. Одна причина — один вид: значок, заголовок, пояснение и, если нужно,
действие.

## Разметка

Достаточно причины; без `kind` берётся `no-data`:

```html
<sf-empty-state kind="nothing-found" heading-level="4"></sf-empty-state>
```

`heading-level` (от 2 до 6, по умолчанию 3) ставит заголовок на нужный
уровень структуры страницы: на целой странице это обычно 2, в панели — 3
или 4. Вид заголовка от уровня не зависит. Действия передают в слот
`actions` — любые `sf-button`.

## Варианты

### Причина

`kind`, `icon`, `heading` • [справочник](#атрибуты)

| `kind` | Значок | Заголовок и текст по умолчанию |
|:---|:---|:---|
| `no-data` (по умолчанию) | `inbox` | «Пока ничего нет» / «Здесь появятся записи, когда они будут» |
| `nothing-found` | `search_off` | «Ничего не найдено» / «Попробуйте изменить запрос или фильтры» |
| `no-access` | `lock` | «Нет доступа» / «Обратитесь к администратору» |
| `error` | `error` | «Не удалось загрузить» / «Попробуйте ещё раз» и кнопка «Повторить» |
| `first-use` | `inbox` | раздел открыт впервые: объяснение и главная кнопка «Создать» |
| `offline` | `cloud_off` | «Нет связи» и «Повторить»; повторяет сам, когда сеть вернётся |
| `processing` | индикатор загрузки | работа идёт без участия человека: что происходит и сколько ждать; с `value` — кольцо с процентом |

Тексты по умолчанию следуют языку страницы. `icon`, `heading` и `text`
заменяют их, когда причина конкретнее: «Машин пока нет», «Создайте первую».
Заголовок задавайте в `heading`: общий атрибут HTML `title` браузер
показывает всплывающей подсказкой при наведении на блок.

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

- `size="1/2"` — внутри таблицы или панели;
- `size="1"` — по умолчанию;
- `size="2"` — целая страница.

От размера зависят значок, роль заголовка, текст и промежутки. Ширина — не
больше 28rem, её меняет переменная `--sf-empty-state-max-inline-size`.

:::example {id="smart-components/empty-state/sizes" label="Размеры пустого состояния"}
:::

### Компактная форма

`layout`, `size`, `text` • [справочник](#атрибуты)

`layout="inline"` (и всегда `size="1/3"`) — одна строка высотой с контрол 1/2
с отступом строки списка: маленький значок, текст (`text`, а без него —
заголовок причины) и не больше одного действия-ссылки, без заголовка. Её
ставят в списки меню, выпадающих списков и поиска; внутри `listbox` или меню
— вне элемента списка, чтобы она не считалась пунктом.

## Поведение

### Действия

Действия передают в слот `actions` — любые `sf-button` — или свойством
`actions` со списком `[{id, text, appearance}]`. Кнопки из свойства рисуются в
размере компонента и сообщают `sf-empty-state-action` с `{id}`. У
`kind="error"` без своих действий есть «Повторить» (`id: retry`). Пустой
массив `actions = []` и кнопки в слоте `actions` тоже считаются своими
действиями, и «Повторить» не показывается; чтобы вернуть его, присвойте
`actions = null`.

```html
<sf-empty-state kind="error" id="failed"></sf-empty-state>
<script>
  failed.addEventListener('sf-empty-state-action', (event) => {
    if (event.detail.id === 'retry') reload();
  });
</script>
```

## Доступность

- `live="auto"` (по умолчанию): «Ничего не найдено» и ошибка объявляются
  вежливо (`role="status"`), остальные причины не объявляются. `live="alert"`
  — для ошибки, вызванной действием человека, `live="off"` — когда объявляет
  сам хост.
- Заголовок — настоящий заголовок уровня `heading-level`, поэтому состояние
  видно в оглавлении страницы.
- Значок декоративный.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `kind` | строка | `no-data` | `no-data`, `first-use`, `nothing-found`, `no-access`, `error`, `offline`, `processing` | Причина — она выбирает значок, тон, заголовок и текст по умолчанию: first-use предлагает главную кнопку «Создать» (id create), error и offline — «Повторить» (id retry), offline к тому же повторяет сам, когда сеть возвращается, а processing рисует в круге значка индикатор загрузки для работы, которая закончится без участия человека, или, с value, кольцо с процентом. |
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2` | `1/3` — всегда строчная форма; `1/2` — внутри таблицы или панели, `2` — на всю страницу: иконка, роль заголовка и текст следуют за размером (промежутки — как у sf-placeholder на любом размере). |
| `icon` | строка | пусто | — | Значок раздела (тот же, что у его пункта меню) для no-data и first-use, без него — inbox; для «ничего не найдено по фильтрам» передайте filter_alt_off. Остальные причины сохраняют свой значок, если этот не задан. |
| `heading` | строка | пусто | — | — |
| `value` | число | — | от 0; до 100 | Только для processing: готовая доля в процентах, 0–100 (в пределах, целое). Если задано, в круге — sf-progress-ring с процентом; если нет — крутится индикатор загрузки. Строчная форма сохраняет индикатор. Имя временное. |
| `text` | строка | пусто | — | — |
| `heading-level` | целое число | `3` | от 2; до 6 | Уровень заголовка в структуре страницы; его вид зависит от размера. |
| `layout` | строка | `block` | `block`, `inline` | inline — одна строка для списка в меню, выпадающем списке или поиске: маленький значок, текст и не больше одного действия-ссылки, без заголовка. |
| `live` | строка | `auto` | `auto`, `alert`, `off` | auto — nothing-found и error объявляются вежливо, остальные молчат; alert — ошибка, вызванная действием человека; off — объявляет приложение. |
| `expressive` | да/нет | нет | — | Украшающий уровень: один мягкий круг цвета primary за значком состояния на всю страницу (размер 2) для «нет данных» и «ничего не найдено»; список, таблица или карточка остаются простыми. По умолчанию выключено, строгое состояние; data-sf-style="expressive" на корне или контейнере включает его для всех состояний внутри, data-sf-style="strict" снова выключает. |
| `actions` | список | — | — | — |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

Публичных методов нет.

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-empty-state-action` | `{ id: string, auto: boolean }` | Человек нажал одно из действий (retry — для error и offline без своих действий, create — для first-use); для offline присылается и само, с auto: true, когда событие online окна говорит, что сеть вернулась. |
