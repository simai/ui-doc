# Шкала прогресса

:badge[sf-progress-scale]{variant=tonal scheme=primary size=1/2} :badge[1.1.4]{variant=outline scheme=on-surface size=1/2}

Шкала прогресса показывает известную долю выполненного десятью делениями.
Берите её, когда точность до процента не нужна и ход удобнее читать крупными
шагами: заполненность профиля, этапы подготовки, занятое место. Для плавного
хода загрузки подходит [Прогресс](/ru/smart/feedback/progress-bar/).

То же на классах — [Шкала прогресса](/ru/components/feedback/progress-scale/):
элемент строится на классах этого компонента; классы годятся для статической
разметки без JavaScript.

## Разметка

Шкале нужны значение и доступное имя:

```html
<sf-progress-scale label="Заполнение профиля" value="40"></sf-progress-scale>
```

`value` — доля выполненного в процентах, от `0` до `100`; значения вне
диапазона приводятся к границе. Шкала закрашивает деления с округлением
вверх до десятка: при `41` закрашено пять делений из десяти. Точное значение
остаётся в подписи и в `aria-valuenow`.

## Варианты

### Подпись значения

`show-text` • [справочник](#атрибуты)

`show-text` (по умолчанию включён) показывает значение в процентах под
шкалой; `show-text="false"` оставляет одну шкалу.

:::example {id="smart-components/progress-scale/show-text" label="С подписью и без неё"}
:::

### Статус

`status` • по умолчанию `neutral` • [справочник](#атрибуты)

`status` сообщает смысл из общего словаря: `neutral` (по умолчанию), `info`,
`success`, `warning`, `error`. Компонент не выводит статус из процента:
предупреждение о почти занятом диске задаёт приложение, как во втором
примере раздела «Пример».

:::example {id="smart-components/progress-scale/status" label="Статусы шкалы"}
:::

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

`size` — ступень `1/3`, `1/2`, `1`, `2` или `3`.

:::example {id="smart-components/progress-scale/sizes" label="Размеры шкалы"}
:::

### В строке текста

`line` • [справочник](#атрибуты)

В ячейке таблицы или в ряду полей задайте `line` (`1/2`, `1`, `2`): шкала и
значение встанут в одну строку текста этого размера формы.

:::example {id="smart-components/progress-scale/line" label="В строке текста"}
:::

## Поведение

### Обновление из скрипта

Меняйте `value` или вызывайте `setProgress(n)`: шкала обновляется без
перерисовки. `getProgress()` возвращает текущее значение числом.

```js
const scale = document.querySelector('sf-progress-scale');
scale.setProgress(completedSteps * 20);
```

## Доступность

- Шкала — `role="progressbar"` со значениями от `0` до `100`. Задайте
  `label` — доступное имя: что измеряет шкала.
- `value-text` заменяет число словами, если процент сам по себе ничего не
  сообщает: «Занято 90%, осталось 2 ГБ».
- Цвет статуса не должен быть единственным сигналом: предупреждение
  называйте в `value-text` или в тексте рядом.
- Шкала не получает фокус и не объявляет изменения сама. О важном переходе —
  например, о заполнении до конца — сообщите отдельным текстом с
  `role="status"`.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | — |
| `line` | строка | пусто | пусто, `1/2`, `1`, `2` | Высота в строку текста этого размера — для ячейки таблицы или ряда полей, чтобы строка не стала выше. |
| `value` | число | `0` | от 0; до 100; шаблон `^(?:100\|[1-9]?[0-9])(?:\.[0-9]+)?$` | — |
| `show-text` | да/нет | да | — | — |
| `status` | строка | `neutral` | `neutral`, `info`, `success`, `warning`, `error` | Цвет по смыслу, например `success` или `error`. `primary` тоже принимается и значит `neutral`. |
| `label` | строка | пусто | — | — |
| `value-text` | строка | пусто | — | — |
| `aria-label` | строка | пусто | — | — |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `chunk(args: object)` | объект | Действие chunk. |
| `getProgress()` | число | Возвращает значение как число, ограниченное диапазоном 0..100; нечисловое значение читается как 0. |
| `setProgress(nextValue: number\|string)` | объект | Устанавливает атрибут value; null или undefined удаляет его. |

Своих событий нет. Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).
