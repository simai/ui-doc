# Плашка уведомлений

:badge[sf-alert-bar]{variant=tonal scheme=primary size=1/2} :badge[1.4.0]{variant=outline scheme=on-surface size=1/2}

Плашка уведомлений — полоса во всю ширину над шапкой страницы или
административного интерфейса для состояний, которые требуют действия сейчас:
диск почти заполнен, резервная копия не удалась, сайт не отвечает, вышло
обновление. Одна плашка держит все такие состояния, окрашена по самому
серьёзному и показывает его первым.

Новость, которая не требует действия, показывайте
[Всплывающим сообщением](/ru/smart/feedback/toast/); сообщение в потоке
страницы — [Уведомление](/ru/smart/feedback/alert/).

## Разметка

Ставьте одну плашку на страницу, над шапкой. Список уведомлений передайте
JSON-блоком, который печатает сервер, или свойством `items`:

```html
<sf-alert-bar>
  <script type="application/json" data-sf-settings>
    {"items": [
      {"id": "disk", "level": "error", "text": "Диск заполнен на 98%.",
       "source": "Сервер", "time": "2026-11-05T09:58:00Z",
       "action": {"label": "Освободить место", "href": "/server/disk/"}},
      {"id": "backup", "level": "warning", "text": "Последняя копия demo.test не удалась.",
       "action": {"label": "Открыть копии", "href": "/backups/"},
       "acknowledge": {"label": "Отметить, что видели"}}
    ]}
  </script>
</sf-alert-bar>
```

Поля уведомления:

| Поле | | Значение |
|:---|:---|:---|
| `id` | обязательно | Имя состояния у хоста; приходит в каждом событии. |
| `level` | обязательно | `error`, `warning` или `info`. |
| `text` | обязательно | Что случилось, одним предложением. |
| `source` | | Откуда: «Сервер», «Сайт demo.test». |
| `time` | | Когда началось, ISO 8601. В пределах суток читается как «5 минут назад», раньше — датой и временем. |
| `action` | | `{label, href}`: одна ссылка действия. |
| `acknowledge` | | `{label}`: кнопка «Отметить, что видели». |
| `dismissible` | | `false` не даёт закрыть предупреждение или сведения. |

Пустой список скрывает плашку. Когда состояние появляется или проходит, хост
передаёт весь список заново.

## Варианты

### Уровень

`level` уведомления задаёт его смысл и цвет: `error` — ошибка,
`warning` — предупреждение, `info` — сведения. Плашка берёт цвет первого
уведомления после сортировки.

:::example {id="smart-components/alert-bar/levels" label="Уровни" preview=sandbox log="sf-alert-bar-navigate sf-alert-bar-acknowledge sf-alert-bar-close sf-alert-bar-minimize" log_console=true log_open=false}
:::

### Размер

`size` • по умолчанию `1/2` • [справочник](#атрибуты)

`size` — ступень лестницы размеров: `1/2` по умолчанию, для плашки над
шапкой административного интерфейса; `1` — для страницы сайта с более крупным
текстом. За ступенью следуют строка текста, иконка, кнопки и отступы плашки.

:::example {id="smart-components/alert-bar/sizes" label="Ступени 1/2 и 1" preview=sandbox log="sf-alert-bar-navigate sf-alert-bar-acknowledge sf-alert-bar-close sf-alert-bar-minimize" log_console=true log_open=false}
:::

## Состояния

### Свёрнута

`minimized` • [справочник](#атрибуты)

Плашку с ошибкой закрыть нельзя, её можно только свернуть в тонкую полосу,
которая сохраняет цвет и число уведомлений. Нажатие на полосу разворачивает
плашку. Атрибут `minimized` показывает плашку свёрнутой сразу — так страница
сохраняет выбор человека между переходами. Ошибка, которой раньше не было в
списке, разворачивает плашку сама.

:::example {id="smart-components/alert-bar/state-minimized" label="Свёрнута" preview=sandbox log="sf-alert-bar-navigate sf-alert-bar-acknowledge sf-alert-bar-close sf-alert-bar-minimize" log_console=true log_open=false}
:::

## Поведение

### Порядок и несколько уведомлений

Плашка сортирует уведомления: ошибка, предупреждение, сведения; внутри
уровня — сначала новые по `time`. Если уведомлений больше одного, видны
«‹ 1 из N ›» для перелистывания и «Все N» — список всех под плашкой, у каждого
свои действие, отметка и закрытие. `Escape` закрывает список.

Когда собственная ширина плашки меньше 600 px, иконка, текст и закрытие
занимают первую строку, действия уходят под текст, стрелок нет, а «Все N»
стоит в конце строки. Действие всегда шириной в свою подпись: сначала
переносится текст сообщения, затем действия уходят на свою строку.

### Закрытие

- **Предупреждение** закрывается на сутки: `sf-alert-bar-close` несёт
  `hide: "day"`.
- **Сведения** закрываются насовсем: `hide: "always"`.
- **Ошибка** не закрывается: её кнопка сворачивает всю плашку.

Закрытое или отмеченное уведомление сразу уходит из плашки. Плашка ничего не
хранит: выбор человека запоминает хост и не передаёт это уведомление в
следующем списке.

### События

Все события всплывают и проходят границы теневого DOM.

| Событие | `detail` | Когда |
|:---|:---|:---|
| `sf-alert-bar-navigate` | `{id, level, href}` | Нажата ссылка действия. Событие отменяемое: без отмены браузер переходит по `href`, страница с маршрутизатором отменяет его и переходит сама. |
| `sf-alert-bar-acknowledge` | `{id, level}` | Человек отметил, что видел состояние. Отменяемое. |
| `sf-alert-bar-close` | `{id, level, hide, reason}` | Уведомление закрыто: `hide` — `day` или `always`, `reason` — `close` (кнопка) или `api` (`close()`). Отменяемое. |
| `sf-alert-bar-minimize` | `{minimized}` | Плашка с ошибкой свёрнута (`true`) или развёрнута (`false`). |

```js
const bar = document.querySelector('sf-alert-bar');
bar.addEventListener('sf-alert-bar-close', (event) => {
  const {id, hide} = event.detail;
  fetch('/api/alerts/hide', {method: 'POST', body: JSON.stringify({id, hide})});
});
```

### Закрытие из скрипта

`close(id)` закрывает уведомление так же, как его кнопка, с
`reason: "api"`. Метод отвечает `{outcome: 'applied'}` или
`{outcome: 'refused', reason}`: `missing` — такого уведомления нет на
плашке, `danger` — это ошибка или уведомление с `dismissible: false`,
`prevented` — страница отменила событие.

## Доступность

- Плашка — область с именем из `label`; без него — «Важные уведомления» на
  русской странице и «Important notices» на остальных.
- Плашка никогда не забирает фокус. Плашку, напечатанную вместе со страницей,
  экранный диктор не зачитывает. То, что появляется позже, объявляется:
  новая ошибка — сразу (`role="alert"`), остальное — вежливо
  (`role="status"`).
- Все элементы управления — нативные кнопки и ссылки в обычном порядке
  `Tab`. Если закрытое уведомление уносит элемент с фокусом, фокус переходит к
  следующему элементу плашки.
- Цвет не единственный признак: текст уведомления говорит, что случилось.
- Движение отключается при `prefers-reduced-motion: reduce`.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1/2` | `1/2`, `1` | Размер плашки: от него зависят текст, иконка, кнопки и отступы. `1/2` — над шапкой админки, `1` — на странице сайта с крупным текстом. |
| `label` | строка | — | — | Имя области; без него — «Важные уведомления» / «Important notices» на языке страницы. |
| `minimized` | да/нет | нет | — | Полоса с ошибкой свёрнута в тонкую строку, где остаётся число сообщений; по нажатию разворачивается. Сворачивается только полоса, где самое серьёзное — ошибка; страница, запомнившая состояние, ставит его снова. Новая ошибка в списке разворачивает полосу. |
| `items` | список | `[]` | — | Текущие сообщения, каждое `{id, level, text, source?, time?, action?: {label, href}, acknowledge?: {label}, dismissible?}`, где `level` — `error`, `warning` или `info` (прежнее `danger` читается как `error`). Задаётся свойством или JSON-островом, который печатает сервер; при появлении или окончании сообщения приложение задаёт весь список заново. Полоса сортирует: ошибки, предупреждения, сведения, новые — первыми по `time` (ISO 8601), и берёт цвет первого. `dismissible: false` не даёт закрыть предупреждение или сведения; ошибку закрыть нельзя, только свернуть. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `close(args: object\|string)` | объект | Закрывает пункт с этим `id`, как его кнопка закрытия, и присылает `sf-alert-bar-close` с `reason: api`. Отказ: `missing` — такого пункта нет, `danger` — пункт с ошибкой или с `dismissible: false`, `prevented` — страница отменила `sf-alert-bar-close`. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-alert-bar-navigate` | `{ id: string, level: string, href: string }` | Человек нажал ссылку действия уведомления (href}`). Это просьба: страница с маршрутизатором отменяет событие и переходит сама; без отмены браузер переходит по `href`. Нажатие с клавишей-модификатором или средней кнопкой открывает ссылку в другом месте и ничего не спрашивает. |
| `sf-alert-bar-acknowledge` | `{ id: string, level: string }` | Человек нажал кнопку отметки уведомления («Отметить, что видели»): приложение записывает, что состояние увидели, для всех, кого оно касается, пока оно не повторится. Без отмены уведомление уходит из плашки, пока приложение снова не задаст список. |
| `sf-alert-bar-close` | `{ id: string, level: string, hide: "day" \| "always", reason: "close" \| "api" }` | Человек закрыл пункт (`reason: close`) или страница вызвала `close(id)` (`reason: api`): предупреждение скрывается на сутки, сведения — насовсем. Полоса ничего не хранит: выбор сохраняет приложение и не передаёт этот пункт в следующий список. Пункт уходит сразу; ошибку закрыть нельзя. |
| `sf-alert-bar-minimize` | `{ minimized: boolean }` | Полоса с ошибкой свёрнута (`minimized: true`) или развёрнута снова (`false`): нажатием или, при развороте, новой ошибкой в списке. Приходит после изменения; страница может запомнить его и задать `minimized` на следующей странице. |
