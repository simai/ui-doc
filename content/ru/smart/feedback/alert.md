# Уведомление

:badge[sf-alert]{variant=tonal scheme=primary size=1/2} :badge[1.1.8]{variant=outline scheme=on-surface size=1/2}

Уведомление показывает сообщение, которое остаётся на странице, пока его не
закроют: предупреждение перед действием, ошибку формы, итог проверки. Для
короткого результата поверх интерфейса, который исчезает сам, берите
[Всплывающие сообщения](/ru/smart/feedback/toast/).

То же на классах — [Уведомления](/ru/components/feedback/alerts/): элемент
строится на классах этого компонента; классы годятся для статической разметки
без JavaScript.

## Разметка

Уведомлению нужны статус и заголовок:

```html
<sf-alert status="info" title="Доступно обновление"
  supporting-text="Сохраните изменения перед обновлением страницы."></sf-alert>
```

`title` — короткая суть сообщения, `supporting-text` — пояснение обычным
размером текста. Слоты `title` и `supporting-text` принимают разметку,
например ссылку на раздел помощи:

```html
<sf-alert status="warning" title="Письмо не доставлено">
  <span slot="supporting-text">Проверьте адрес. <a href="/help/mail">Как это сделать</a></span>
</sf-alert>
```

## Варианты

### Статус

`status` выбирает смысл из общего словаря: `neutral`, `info`, `success`,
`warning`, `error`. Выбирайте его по смыслу сообщения, а не ради цвета.
Статус ставит подходящую иконку.

:::example {id="smart-components/alert/status" label="Статусы уведомления"}
:::

### Вид

`appearance` задаёт, чем сообщение отделено от окружения: `default` —
заливкой и границей, `outlined` — только границей, `flat` — только заливкой,
когда границы задаёт окружающий контейнер.

:::example {id="smart-components/alert/appearance" label="Виды уведомления"}
:::

### Состав

Обязателен только заголовок. `icon` заменяет иконку статуса другой,
`icon="none"` убирает её. `action-text` показывает основную кнопку действия,
`secondary-action-text` — второстепенную, `closable` — кнопку закрытия.

:::example {id="smart-components/alert/composition" label="Части уведомления"}
:::

## Поведение

### Действия

`action` и `secondary-action` — машинные значения кнопок действий (по
умолчанию `action` и `secondary`). Нажатие отправляет всплывающее событие
`sf-alert-action`; в `event.detail.action` — значение кнопки, в
`event.detail.alert` — сам элемент. Действие выполняет приложение.

### Закрытие

Нажатие кнопки закрытия отправляет `sf-alert-close` и убирает элемент со
страницы после анимации выхода; при системной настройке уменьшения движения —
сразу. `close()` закрывает сообщение из скрипта.

```js
const alert = document.querySelector('sf-alert');
alert.onAction((action) => {
  if (action === 'edit-address') openAddressForm();
});
alert.onClose(() => saveDismissed('delivery-warning'));
```

`onAction(handler)` передаёт обработчику значение действия, `detail` и само
событие; `onClose(handler)` — `detail` и событие.

### Создание из скрипта

```js
const alert = await SF.createAsync('alert', {
  status: 'error',
  title: 'Не удалось сохранить',
  supportingText: 'Проверьте соединение и повторите попытку.',
  role: 'alert',
});
form.prepend(alert);
```

## Доступность

- Сообщение, которое есть на странице с первой загрузки, — обычный текст:
  живая роль ему не нужна. Сообщению, которое вставляется после действия,
  задайте `role="status"`, а срочной ошибке — `role="alert"`, чтобы экранный
  диктор его объявил.
- Иконка декоративна: смысл несёт текст. Начинайте `title` со слов, а не
  полагайтесь на цвет статуса.
- Кнопки действий и закрытия — нативные кнопки в обычном порядке `Tab`.
  Кнопка закрытия называется «Закрыть сообщение» на русской странице и
  «Close alert» на остальных; `close-label` задаёт своё имя.
- Если фокус был внутри закрытого сообщения, верните его на понятное место —
  например, на поле, к которому относилось сообщение. Компонент фокус не
  переносит.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `status` | строка | `neutral` | `neutral`, `info`, `success`, `warning`, `error` | О чём сообщает уведомление, в общем словаре статусов. Также принимаются значения clear и danger; они означают neutral и error. |
| `appearance` | строка | `default` | `default`, `outlined`, `flat` | Вид уведомления: заливка, контур или плоский. |
| `icon` | строка | пусто | — | Своя иконка вместо иконки по статусу; `none` скрывает иконку. |
| `heading` | строка | пусто | — | — |
| `supporting-text` | строка | пусто | — | Дополнительный основной текст обычного размера. |
| `action-text` | строка | пусто | — | Видимая подпись основного необязательного действия. |
| `action` | строка | `action` | — | Стабильное значение действия, передаваемое в sf-alert-action. |
| `secondary-action-text` | строка | пусто | — | Видимая подпись вторичного необязательного действия. |
| `secondary-action` | строка | `secondary` | — | Стабильное значение вторичного действия, передаваемое в sf-alert-action. |
| `closable` | да/нет | нет | — | Отображает явно названное действие закрытия. |
| `close-label` | строка | — | — | Доступное имя действия закрытия на языке страницы. Пусто — текст на языке страницы (по-английски «Close alert»). |
| `aria-label` | строка | пусто | — | — |
| `title` | строка | пусто | — | Короткий заголовок сообщения. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `onAction(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик sf-alert-action; обработчик получает (action, detail, event). Возвращает тег. |
| `onClose(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик sf-alert-close; обработчик получает (detail, event). Возвращает тег. |
| `dismiss()` | объект | Отправляет sf-alert-close, затем удаляет уведомление из DOM после анимации исчезновения (сразу при уменьшенном движении). Возвращает тег. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-alert-action` | `{ action: string }` | Активирована кнопка действия ([data-action] или [data-alert-action]) внутри уведомления. Всплывает и с composed: true; не отменяемое. Уведомление остаётся. |
| `sf-alert-close` | `{ reason: any }` | Уведомление закрывается кнопкой закрытия или через dismiss()/close(). Всплывает и с composed: true; не отменяемое; после него элемент удаляется. |
