# Скелетон

:badge[sf-skeleton]{variant=tonal scheme=primary size=1/2} :badge[1.1.3]{variant=outline scheme=on-surface size=1/2}

Скелетон занимает место содержимого, которое ещё загружается, серыми фигурами:
строками текста, аватаром, изображением, карточкой. Страница не прыгает, когда
приходят данные, и читатель заранее видит раскладку. Для ожидания без
известной раскладки берите [Спиннер](/ru/smart/feedback/spinner/), для
известной доли выполненного — [Прогресс](/ru/smart/feedback/progress-bar/).

То же на классах — [Скелетон](/ru/components/feedback/skeleton/): элемент
строится на классах этого компонента; классы годятся для статической разметки
без JavaScript.

## Разметка

Одна строка текста — тег без атрибутов:

```html
<sf-skeleton></sf-skeleton>
```

Скелетон ставят на место будущего содержимого внутри области, которая ждёт
данных; область отмечают `aria-busy="true"` (см. «Доступность»).

## Варианты

### Форма

`kind` задаёт форму фигуры: `text` — строка со скруглением (по умолчанию),
`circle` — круг, `square` — без скругления, `rounded` — скругление как у
строки. `type="icon"` делает ширину равной высоте — вместе с
`kind="circle"` получается место под аватар или иконку, как в разделе
«Пример».

:::example {id="smart-components/skeleton/kind" label="Формы фигуры"}
:::

### Размер

`size` — высота каждой фигуры по шкале текста, от `1/7` до `7`, по умолчанию
`1`: берите ступень текста, который встанет на это место.

:::example {id="smart-components/skeleton/sizes" label="Высота фигуры по шкале текста"}
:::

### Строки

`count` (от 1 до 20) задаёт число фигур одного элемента. `width` и `height`
принимают список через запятую; значения применяются к фигурам по очереди и
повторяются по кругу. Так три строки разной длины описываются одним
элементом: `width="100%,80%,60%"`. Значение — процент, имя токена размера
(`a8`, `b4`) или `var(--sf-…)`; остальные значения игнорируются.

:::example {id="smart-components/skeleton/lines" label="Три строки одной длины и разной длины"}
:::

### Движение

`animation` выбирает движение: `pulse` — мягкое изменение прозрачности (по
умолчанию), `wave` — блик по фигуре, `none` — без движения. При системной
настройке уменьшения движения фигуры остаются статичными.

:::example {id="smart-components/skeleton/animation" label="Движение фигур"}
:::

## Поведение

### Замена на содержимое

Скелетон не знает, когда данные готовы. Приложение держит его на месте
содержимого и заменяет, когда ответ пришёл.

```js
const region = document.querySelector('#author');
region.setAttribute('aria-busy', 'true');
const author = await api.getAuthor(id);
region.replaceChildren(renderAuthor(author));
region.removeAttribute('aria-busy');
```

## Доступность

- Фигуры скрыты от экранного диктора и не получают фокус: они ничего не
  сообщают.
- О загрузке сообщает область, в которой стоит скелетон: задайте ей
  `aria-busy="true"` и уберите атрибут, когда содержимое на месте.
- Если ожидание долгое, объявите его текстом с `role="status"` один раз, а
  не для каждой фигуры.
- Не используйте скелетон как сообщение об ошибке или пустом результате:
  когда данных нет, покажите текст.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/7`, `1/6`, `1/5`, `1/4`, `1/3`, `1/2`, `1`, `2`, `3`, `4`, `5`, `6`, `7` | — |
| `width` | строка | `100%` | — | Ширина каждой формы — список через запятую, значения берутся по очереди и повторяются: процент, размер `a0`–`a9` или `b0`–`b9` либо `var(--sf-...)`; другие значения не учитываются. По умолчанию 100%. |
| `height` | строка | пусто | — | Высота каждой формы — список через запятую, значения берутся по очереди и повторяются: процент, размер `a0`–`a9` или `b0`–`b9` либо `var(--sf-...)`; другие значения не учитываются. Пусто — высота ступени размера. Форма `type="icon"` не берёт ни того, ни другого. |
| `count` | целое число | `1` | от 1; до 20 | — |
| `animation` | строка | `pulse` | `pulse`, `wave`, `none` | — |
| `kind` | строка | `text` | `text`, `circle`, `square`, `rounded` | Форма заглушки: строка текста, круг, квадрат или скруглённый блок. |
| `items` | строка | пусто | — | — |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `setState(nextState: object)` | объект | Записывает каждый ключ как атрибут в kebab-case: false, null, undefined или пустая строка удаляет его, true устанавливает пустым, всё остальное приводится к строке. |
