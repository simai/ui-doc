# Прогресс

:badge[sf-progress-bar]{variant=outline scheme=on-surface size=1/2} :badge[1.5.4]{variant=outline scheme=on-surface size=1/2}

Прогресс показывает ход процесса, у которого известна доля выполненного:
загрузка файла, импорт, проверка. Когда доля неизвестна, берите
[Спиннер](/ru/smart/feedback/spinner/); когда ход удобнее читать крупными
шагами — [Шкала прогресса](/ru/smart/feedback/progress-scale/).

То же на классах — [Прогресс](/ru/components/feedback/progress-bar/): элемент
строится на классах этого компонента; классы годятся для статической разметки
без JavaScript.

## Разметка

Полосе нужны значение и доступное имя:

```html
<sf-progress-bar label="Загрузка файлов" value="40"></sf-progress-bar>
```

`value` — доля выполненного в процентах, от `0` до `100`; значения вне
диапазона приводятся к границе. `label` называет, что выполняется,
`value-text` заменяет число словами.

## Варианты

### Статус

`status` • по умолчанию пусто • [справочник](#атрибуты)

Без `status` полоса основного цвета темы. `status` сообщает смысл из общего
словаря: `neutral` — серая, как точка и бейдж, `info`, `success`, `warning`,
`error`. Компонент не выводит статус из процента: ошибку или завершение
задаёт приложение. Для количества в пределах статус по порогу ставят
`warning-at` и `error-at` — раздел [Объём](#объём).

:::example {id="smart-components/progress-bar/status" label="Статусы полосы"}
:::

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

`size` — толщина полосы по ступени: `1/3` и `1/2` — 4 пикселя, `1` (по
умолчанию) и `2` — 8, `3` — 12. Концы полосы круглые, на телефоне толщина
та же.

:::example {id="smart-components/progress-bar/sizes" label="Толщина полосы"}
:::

### Положение значения

`text-position` • по умолчанию `none` • [справочник](#атрибуты)

`text-position` показывает число рядом с полосой: `top` — строка над
полосой, подпись в начале, число в конце; `inline-end` — число в конце
строки полосы; `none` (по умолчанию) — не показывает.

:::example {id="smart-components/progress-bar/text-position" label="Число рядом с полосой"}
:::

### Объём

`meter`, `warning-at`, `error-at` • [справочник](#атрибуты)

`meter` — полоса показывает не ход задачи, а количество в известных
пределах: занятое место на диске, израсходованную квоту. Вид тот же, а
экранный диктор читает её как объём, а не как ход работы. Пороги
`warning-at` и `error-at` в процентах сами меняют цвет: с 80 % полоса
предупреждает, с 95 % — сообщает об ошибке. Если задан и `status`, полоса
берёт более серьёзное из двух.

:::example {id="smart-components/progress-bar/meter" label="Занятое место"}
:::

## Состояния

### Размер работы неизвестен

`indeterminate` • [справочник](#атрибуты)

`indeterminate` — работа идёт, а её размер ещё неизвестен: отрезок заливки
бежит по дорожке, число не читается. Когда размер стал известен, страница
снимает атрибут, и та же полоса заполняется от значения.

:::example {id="smart-components/progress-bar/indeterminate" label="Размер работы неизвестен"}
:::

### Пауза

`paused` • [справочник](#атрибуты)

`paused` — работа остановлена: полоса в цвете предупреждения, а экранный
диктор читает «35 %, на паузе».

:::example {id="smart-components/progress-bar/states" label="Пауза"}
:::

## Поведение

### Обновление из скрипта

Меняйте `value` по мере хода процесса: компонент обновляет полосу и
`aria-valuenow` без перерисовки. `setProgress(n)` делает то же, а
`getProgress()` возвращает текущее значение числом.

```js
const progress = document.querySelector('sf-progress-bar');
upload.addEventListener('progress', (event) => {
  progress.setProgress(Math.round((event.loaded / event.total) * 100));
});
upload.addEventListener('load', () => {
  progress.setAttribute('status', 'success');
  progress.setAttribute('value-text', 'Файлы загружены');
});
```

## Доступность

- С `meter` полоса — `role="meter"`: экранный диктор читает её как объём.
- Полоса — `role="progressbar"` с `aria-valuemin="0"`, `aria-valuemax="100"`
  и текущим `aria-valuenow`. Задайте `label` — доступное имя: что именно
  выполняется. Без него экранный диктор прочитает одно число.
- `value-text` заменяет число словами: «Загружено 3 файла из 5»,
  «Проверка завершена».
- Полоса не получает фокус. Экранный диктор не объявляет каждое изменение
  значения; о завершении или ошибке сообщите отдельным текстом с
  `role="status"` или [Уведомление](/ru/smart/feedback/alert/).
- Область, которая ждёт результата, отметьте `aria-busy="true"` до конца
  процесса.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | — |
| `value` | число | `0` | от 0; до 100; шаблон `^(?:100\|[1-9]?[0-9])(?:\.[0-9]+)?$` | — |
| `text-position` | строка | `none` | `none`, `top`, `inline-end` | Где стоит процент: top — одна строка над полосой, подпись в начале, значение в конце; inline-end — значение в конце строки полосы; none — нигде. Прежние слова bottom и right читаются как top и inline-end до 2027-01-01. |
| `status` | строка | пусто | пусто, `neutral`, `info`, `success`, `warning`, `error` | О чём сообщает значение, по общему словарю статусов. Пусто (по умолчанию) — primary темы; neutral — серый, как у sf-dot и sf-badge; info, success, warning и error — свои роли. Прежнее слово primary ещё принимается и значит то же, что по умолчанию. С warning-at или error-at полоса берёт более серьёзное из этого статуса и порога, которого достигло значение. |
| `warning-at` | число | — | от 0; до 100 | Порог в процентах: начиная с него полоса сама становится предупреждением, например диск заполнен на 83 % при `warning-at="80"`. Без атрибута порога нет. |
| `error-at` | число | — | от 0; до 100 | Порог в процентах: начиная с него полоса сама становится ошибкой. Если заданы оба порога, этот выше `warning-at`. Без атрибута порога нет. |
| `indeterminate` | да/нет | нет | — | Работа идёт, а её размер ещё неизвестен: отрезок заливки бежит по дорожке, значение не читается (`aria-valuenow` не ставится). Страница снимает атрибут, когда размер стал известен, и та же полоса заполняется от значения, один раз. При ограничении движения отрезок стоит на месте. |
| `paused` | да/нет | нет | — | Работа на паузе: полоса — предупреждение (если статус или порог не говорят «ошибка»), и экранный диктор это слышит: текст значения читается «35 %, на паузе», если страница не дала `value-text` (C34). Страница ставит это там, где работа действительно остановилась. |
| `meter` | да/нет | нет | — | Значение — количество в известных пределах (занятая квота, заполненный диск), а не ход задачи: role meter вместо progressbar. У meter всегда есть значение, поэтому неопределённым он не бывает. Вид не меняется. |
| `inline` | да/нет | нет | — | Вид счётчика в конце строки (C203, 2026-11-15): строка настроек, ячейка таблицы, конец строки списка. У дорожки своя ширина, 64 (другую задаёт `--sf-progress-bar-track-size`), её число не занимает; толщина 4 на любом размере, плотности и ширине; число стоит перед дорожкой, всегда видно, «72 %», и на пороге берёт цвет статуса. `text-position` не действует. Используйте с `meter`; полосы на всю ширину остаются по C131. |
| `label` | строка | пусто | — | — |
| `value-text` | строка | пусто | — | — |
| `aria-label` | строка | пусто | — | — |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `chunk(args: object)` | объект | Действие chunk. |
| `getProgress()` | число | Возвращает атрибут value как число (0, если атрибута нет); значение не ограничивается. |
| `setProgress(nextValue: number\|string)` | объект | Устанавливает атрибут value; null или undefined удаляет его. |
| `setTextPosition(nextValue: string)` | объект | Устанавливает text-position; null или undefined удаляет его. |
