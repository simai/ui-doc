# Прогресс

:badge[sf-progress-bar]{variant=tonal scheme=primary size=1/2} :badge[1.2.1]{variant=outline scheme=on-surface size=1/2}

Прогресс показывает ход процесса, у которого известна доля выполненного:
загрузка файла, импорт, проверка. Когда доля неизвестна, берите
[Спиннер](/ru/smart/feedback/spinner/); когда ход удобнее читать крупными
шагами — [Шкала прогресса](/ru/smart/feedback/progress-scale/).

То же на классах — [Прогресс](/ru/components/feedback/progress-bar/): элемент
строится на классах этого компонента; классы годятся для статической разметки
без JavaScript.

## Разметка

Полосе нужны значение и доступное имя:

```html
<sf-progress-bar label="Загрузка файлов" value="40"></sf-progress-bar>
```

`value` — доля выполненного в процентах, от `0` до `100`; значения вне
диапазона приводятся к границе. `label` называет, что выполняется,
`value-text` заменяет число словами.

## Варианты

### Статус

`status` сообщает смысл из общего словаря: `neutral` (по умолчанию), `info`,
`success`, `warning`, `error`. Компонент не выводит статус из процента:
ошибку или завершение задаёт приложение.

:::example {id="smart-components/progress-bar/status" label="Статусы полосы"}
:::

### Размер

`size` — толщина полосы, ступень `1/3`, `1/2`, `1`, `2` или `3`.

:::example {id="smart-components/progress-bar/sizes" label="Толщина полосы"}
:::

### Положение значения

`text-position` показывает число рядом с полосой: `inline-end` — в конце
строки, `bottom` — под полосой, `none` (по умолчанию) — не показывает.

:::example {id="smart-components/progress-bar/text-position" label="Число рядом с полосой"}
:::

## Поведение

### Обновление из скрипта

Меняйте `value` по мере хода процесса: компонент обновляет полосу и
`aria-valuenow` без перерисовки. `setProgress(n)` делает то же, а
`getProgress()` возвращает текущее значение числом.

```js
const progress = document.querySelector('sf-progress-bar');
upload.addEventListener('progress', (event) => {
  progress.setProgress(Math.round((event.loaded / event.total) * 100));
});
upload.addEventListener('load', () => {
  progress.setAttribute('status', 'success');
  progress.setAttribute('value-text', 'Файлы загружены');
});
```

## Доступность

- Полоса — `role="progressbar"` с `aria-valuemin="0"`, `aria-valuemax="100"`
  и текущим `aria-valuenow`. Задайте `label` — доступное имя: что именно
  выполняется. Без него экранный диктор прочитает одно число.
- `value-text` заменяет число словами: «Загружено 3 файла из 5»,
  «Проверка завершена».
- Полоса не получает фокус. Экранный диктор не объявляет каждое изменение
  значения; о завершении или ошибке сообщите отдельным текстом с
  `role="status"` или [Уведомление](/ru/smart/feedback/alert/).
- Область, которая ждёт результата, отметьте `aria-busy="true"` до конца
  процесса.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/3`, `1/2`, `1`, `2`, `3` | — |
| `value` | число | `0` | от 0; до 100; шаблон `^(?:100\|[1-9]?[0-9])(?:\.[0-9]+)?$` | — |
| `text-position` | строка | `none` | `none`, `inline-end`, `bottom`, `right` | — |
| `status` | строка | `neutral` | `neutral`, `info`, `success`, `warning`, `error` | Цвет по смыслу, например `success` или `error`. `primary` тоже принимается и значит `neutral`. С порогами `warning-at` и `error-at` берётся более серьёзный из двух цветов. |
| `warning-at` | число | — | от 0; до 100 | Порог в процентах: начиная с него полоса сама становится предупреждением, например диск заполнен на 83 % при `warning-at="80"`. Без атрибута порога нет. |
| `error-at` | число | — | от 0; до 100 | Порог в процентах: начиная с него полоса сама становится ошибкой. Если заданы оба порога, этот выше `warning-at`. Без атрибута порога нет. |
| `label` | строка | пусто | — | — |
| `value-text` | строка | пусто | — | — |
| `aria-label` | строка | пусто | — | — |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `chunk(args: object)` | объект | Действие chunk. |
| `getProgress()` | число | Возвращает атрибут value как число (0, если атрибута нет); значение не ограничивается. |
| `setProgress(nextValue: number\|string)` | объект | Устанавливает атрибут value; null или undefined удаляет его. |
| `setTextPosition(nextValue: string)` | объект | Устанавливает text-position; null или undefined удаляет его. |
