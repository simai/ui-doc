# Ход выполнения

:badge[sf-progress-run]{variant=tonal scheme=primary size=1/2} :badge[1.2.2]{variant=outline scheme=on-surface size=1/2}

Показывает долгое задание так, как его видит человек: создание сайта,
обновление, резервную копию и восстановление, импорт, публикацию, установку
пакета. Шаги с состояниями и временем, сворачиваемый вывод, итог, когда
задание закончилось, и кнопки «Отменить», «Повторить» и «Скрыть».

Одну полосу хода без шагов показывайте [Прогрессом](/ru/smart/feedback/progress-bar/);
шаги, которые проходит сам человек, — [Шагами](/ru/smart/navigation/steps/).

## Пример

Задание идёт само; нажмите «Отменить», затем «Повторить», а когда оно
закончится — «Скрыть». Журнал под примером покажет события.

## Разметка

Шаги передайте JSON-блоком, который печатает сервер, или свойством `steps`:

```html
<sf-progress-run label="Создание сайта demo.test" cancelable retryable hideable>
  <script type="application/json" data-sf-settings>
    {"steps": [
      {"id": "dns", "title": "Адрес", "state": "done", "duration": 1200},
      {"id": "files", "title": "Файлы сайта", "state": "running", "started": "2026-11-07T09:00:00Z"},
      {"id": "ssl", "title": "Сертификат", "state": "waiting"}
    ]}
  </script>
</sf-progress-run>
```

Поля шага:

| Поле | | Значение |
|:---|:---|:---|
| `id` | обязательно | Имя шага; по нему хост меняет шаг. |
| `title` | обязательно | Название шага. |
| `state` | | `waiting`, `running`, `done`, `failed` или `skipped`; другое значение читается как `waiting`. |
| `text` | | Строка под названием. |
| `started`, `finished` | | Начало и конец шага, ISO 8601. |
| `duration` | | Время шага в миллисекундах; без него время — `finished` минус `started`. |

Время шага пишется как `м:сс`, дольше часа — `ч:мм:сс`. Идущий шаг с
`started` считает время каждую секунду.

`label` — название задания: заголовок и имя области. Без него — «Ход
выполнения» на русской странице и «Progress» на остальных.

Компонент ничего не опрашивает и ничего не делает сам: шаги задаёт хост,
вывод дописывает хост, на «Отменить», «Повторить» и «Скрыть» отвечает хост.
Выдвижную панель или подтверждение вокруг собирает страница.

```js
const run = document.querySelector('sf-progress-run');
job.on('output', (text) => run.chunk({text}));
job.on('step', ({id, state, duration}) => run.step({id, state, duration}));
run.addEventListener('sf-progress-run-cancel', () => job.cancel());
run.addEventListener('sf-progress-run-retry', () => job.start());
```

## Состояния

### Готово, не удалось, отменено

`run-state`, `result-text` • по умолчанию `auto` • [справочник](#атрибуты)

С `run-state="auto"` состояние задания считается по шагам: не удалось, если
не удался хоть один шаг; идёт, пока идёт шаг; готово, когда все шаги
выполнены или пропущены; иначе ждёт. `cancelled` ставит только хост, после
того как остановил задание. Нарисованное состояние хост читает из атрибута
`data-state`.

`result-text` — итог словами, когда задание закончилось: «Сайт создан» или
причина неудачи. Без него — «Готово», «Не удалось» или «Отменено».

:::example {id="smart-components/progress-run/states" label="Готово, не удалось и отменено" preview=sandbox}
:::

### Кнопки

`cancelable`, `retryable`, `hideable` • [справочник](#атрибуты)

`cancelable` показывает «Отменить», пока задание идёт; `retryable` —
«Повторить» после неудачи или отмены; `hideable` — «Скрыть», когда задание
закончилось. Все три работают в примере в начале страницы.

## Поведение

### Вывод

`output`, `output-open`, `output-label`, `file-name` • [справочник](#атрибуты)

`output` — вывод задания простым текстом, без разметки; `chunk({text})`
дописывает к нему, `clear()` очищает. Панель вывода открывает и закрывает
кнопка «Вывод»; страница может открыть её сама через `output-open`,
например при неудаче. Пока читатель в конце вывода, панель идёт за новыми
строками; если он прокрутил выше, место остаётся. Хранятся последние
500 000 знаков, лишние целые строки уходят с начала.

Вывод можно скопировать кнопкой копирования и скачать: нажатие на
скачивание отправляет `sf-progress-run-download` с `{fileName}`. Без отмены
браузер сохраняет вывод текстом под именем `file-name`; страница, у которой
есть полный журнал, отменяет событие и отдаёт свой файл. Открытие и закрытие
панели сообщает `sf-progress-run-toggle` с `{open}`.

:::example {id="smart-components/progress-run/output" label="Вывод дописывается; скачивание отменено" preview=sandbox log_console=true log_open=false}
:::

### Шаг из кода

`step({id, state, text, started, finished, duration})` меняет один шаг: данные
заменяют поля этого шага, пока хост не задаст список заново. Для
неизвестного `id` метод отвечает отказом `{reason: 'missing'}`. Так в
примере в начале страницы идут шаги.

### События

| Событие | `detail` | Когда |
|:---|:---|:---|
| `sf-progress-run-cancel` | `{}` | Нажата «Отменить». Хост останавливает задание и ставит `run-state="cancelled"`. |
| `sf-progress-run-retry` | `{}` | Нажата «Повторить». Хост запускает задание заново и задаёт шаги. |
| `sf-progress-run-close` | `{reason: 'close'}` | Нажата «Скрыть». Без отмены хост убирает задание или закрывает панель, в которой оно стоит. |
| `sf-progress-run-download` | `{fileName}` | Нажато скачивание вывода. |
| `sf-progress-run-toggle` | `{open}` | Панель вывода открыта или закрыта. |

## Доступность

- Задание — область страницы с именем из `label`.
- Шаги — упорядоченный список; каждый говорит своё состояние словом после
  названия, идущий шаг отмечен как текущий.
- Строка итога объявляется, когда задание закончилось; смена шагов вслух не
  читается.
- У кнопки «Вывод» есть состояние «развёрнуто»; вывод — журнал, который можно
  прокрутить с клавиатуры.
- `Tab` проходит по кнопке «Вывод», выводу, копированию, скачиванию и
  кнопкам действий; `Enter` или `Пробел` нажимают кнопку. Сам компонент фокус
  не забирает.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `label` | строка | пусто | — | Название задания, как его говорит человек («Создание сайта demo.test»): заголовок и имя области. Без него — «Ход выполнения» на русской странице и «Progress» на остальных. |
| `run-state` | строка | `auto` | `auto`, `running`, `done`, `failed`, `cancelled` | Состояние задания. `auto` считает его по шагам: не удалось, если не удался шаг; идёт, пока идёт шаг; готово, когда все шаги выполнены или пропущены; иначе ждёт. `cancelled` ставит только хост, после того как остановил задание. |
| `result-text` | строка | пусто | — | Итог словами, когда задание закончилось: «Сайт создан» при успехе, причина при неудаче («Не хватает места на диске»). Без него — «Готово», «Не удалось» или «Отменено». |
| `output` | строка | пусто | — | Вывод задания простым текстом, который печатает сервер; метод `chunk` дописывает к нему. Показывается моноширинным шрифтом, никогда как разметка. |
| `output-label` | строка | — | — | Подпись кнопки панели вывода; без неё — «Вывод» на русской странице и «Output» на остальных. |
| `file-name` | строка | `output.txt` | — | Имя файла, под которым кнопка скачивания сохраняет вывод. |
| `cancelable` | да/нет | нет | — | Показывает «Отменить», пока задание идёт; нажатие отправляет `sf-progress-run-cancel`. |
| `retryable` | да/нет | нет | — | Показывает «Повторить» после неудачи или отмены; нажатие отправляет `sf-progress-run-retry`. |
| `hideable` | да/нет | нет | — | Показывает «Скрыть», когда задание закончилось; нажатие отправляет `sf-progress-run-close`. |
| `size` | строка | `1` | `1/2`, `1` | Размер: от него зависят название шага, текст, время, вывод и высота шага. `1/2` — для узкой выдвижной панели. |
| `output-open` | да/нет | нет | — | Панель вывода открыта. Человек открывает и закрывает её кнопкой; страница может открыть её сама, например при неудаче. Панель идёт за новыми строками, только пока читатель в конце вывода. |
| `steps` | список | `[]` | — | Шаги задания по порядку, каждый `{id, title, state, text?, started?, finished?, duration?}`, где `state` — `waiting`, `running`, `done`, `failed` или `skipped`. Свойство или JSON-блок, который печатает сервер; хост задаёт весь список заново или меняет один шаг методом `step`. Время шага — `duration` в миллисекундах, иначе `finished` минус `started` (ISO 8601); идущий шаг с `started` считает время каждую секунду. Неизвестное состояние читается как `waiting`. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `chunk(args: object\|string)` | объект | Добавляет текст в вывод: chunk({text}) — очередная часть потока; короткая запись chunk(text) тоже принимается. Перевод строки завершает строку; окно следует за новым текстом, только пока читатель в конце. Без текста — отказ с причиной invalid. |
| `clear()` | объект | Очищает вывод, например когда задание запущено заново. |
| `step(args: object)` | объект | Меняет один шаг: переданные поля (`state`, `text`, `started`, `finished`, `duration`) заменяют поля этого шага. Для неизвестного `id` — отказ `{reason: missing}`. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-progress-run-cancel` | пустой объект | Человек нажал «Отменить», пока задание шло. Это просьба: хост останавливает задание и ставит состояние `cancelled` (или неудачный шаг); сам компонент ничего не меняет. |
| `sf-progress-run-retry` | пустой объект | Человек нажал «Повторить» после неудачи или отмены: хост запускает задание заново и задаёт шаги. |
| `sf-progress-run-close` | `{ reason: any }` | Человек нажал «Скрыть» после конца задания. Это просьба: без отмены хост убирает задание или закрывает панель, в которой оно стоит; сам компонент не скрывается. |
| `sf-progress-run-download` | `{ fileName: string }` | Человек нажал скачивание вывода. Без отмены браузер сохраняет вывод текстом под именем `file-name`; страница, у которой есть полный журнал, отменяет событие и отдаёт свой файл. |
| `sf-progress-run-toggle` | `{ open: boolean }` | Панель вывода открыта или закрыта кнопкой: `open` — состояние после изменения. |
