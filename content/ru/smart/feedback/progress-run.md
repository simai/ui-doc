# Ход выполнения

:badge[sf-progress-run]{variant=tonal scheme=primary size=1/2} :badge[1.3.3]{variant=outline scheme=on-surface size=1/2}

Показывает долгое задание так, как его видит человек: создание сайта,
обновление, резервную копию и восстановление, импорт, публикацию, установку
пакета. Шаги с состояниями и временем, сворачиваемый вывод, итог, когда
задание закончилось, и кнопки «Отменить», «Повторить» и «Скрыть».

Одну полосу хода без шагов показывайте [Прогрессом](/ru/smart/feedback/progress-bar/);
шаги, которые проходит сам человек, — [Шагами](/ru/smart/navigation/steps/).

## Пример

Задание идёт само; нажмите «Отменить», затем «Повторить», а когда оно
закончится — «Скрыть». Журнал под примером покажет события.

## Разметка

Шаги передайте JSON-блоком, который печатает сервер, или свойством `steps`:

```html
<sf-progress-run label="Создание сайта demo.test" cancelable retryable hideable>
  <script type="application/json" data-sf-settings>
    {"steps": [
      {"id": "dns", "title": "Адрес", "state": "done", "duration": 1200},
      {"id": "files", "title": "Файлы сайта", "state": "running", "started": "2026-11-07T09:00:00Z"},
      {"id": "ssl", "title": "Сертификат", "state": "waiting"}
    ]}
  </script>
</sf-progress-run>
```

Поля шага:

| Поле | | Значение |
|:---|:---|:---|
| `id` | обязательно | Имя шага; по нему хост меняет шаг. |
| `title` | обязательно | Название шага. |
| `state` | | `waiting`, `running`, `done`, `failed` или `skipped`; другое значение читается как `waiting`. |
| `text` | | Строка под названием. |
| `started`, `finished` | | Начало и конец шага, ISO 8601. |
| `duration` | | Время шага в миллисекундах; без него время — `finished` минус `started`. |

Время шага пишется как `м:сс`, дольше часа — `ч:мм:сс`. Идущий шаг с
`started` считает время каждую секунду.

`label` — название задания: заголовок и имя области. Без него — «Ход
выполнения» на русской странице и «Progress» на остальных.

Компонент ничего не опрашивает и ничего не делает сам: шаги задаёт хост,
вывод дописывает хост, на «Отменить», «Повторить» и «Скрыть» отвечает хост.
Выдвижную панель или подтверждение вокруг собирает страница.

```js
const run = document.querySelector('sf-progress-run');
job.on('output', (text) => run.chunk({text}));
job.on('step', ({id, state, duration}) => run.step({id, state, duration}));
run.addEventListener('sf-progress-run-cancel', () => job.cancel());
run.addEventListener('sf-progress-run-retry', () => job.start());
```

## Состояния

### Готово, не удалось, отменено

`run-state`, `result-text` • по умолчанию `auto` • [справочник](#атрибуты)

С `run-state="auto"` состояние задания считается по шагам: не удалось, если
не удался хоть один шаг; идёт, пока идёт шаг; готово, когда все шаги
выполнены или пропущены; иначе ждёт. `cancelled` ставит только хост, после
того как остановил задание. Нарисованное состояние хост читает из атрибута
`data-state`.

`result-text` — итог словами, когда задание закончилось: «Сайт создан» или
причина неудачи. Без него — «Готово», «Не удалось» или «Отменено».

:::example {id="smart-components/progress-run/states" label="Готово, не удалось и отменено" preview=sandbox}
:::

### Кнопки

`cancelable`, `retryable`, `hideable` • [справочник](#атрибуты)

`cancelable` показывает «Отменить», пока задание идёт; `retryable` —
«Повторить» после неудачи или отмены; `hideable` — «Скрыть», когда задание
закончилось. Все три работают в примере в начале страницы.

## Поведение

### Вывод

`output`, `output-open`, `output-label`, `file-name` • [справочник](#атрибуты)

`output` — вывод задания простым текстом, без разметки; `chunk({text})`
дописывает к нему, `clear()` очищает. Панель вывода открывает и закрывает
кнопка «Вывод»; страница может открыть её сама через `output-open`,
например при неудаче. Пока читатель в конце вывода, панель идёт за новыми
строками; если он прокрутил выше, место остаётся. Хранятся последние
500 000 знаков, лишние целые строки уходят с начала.

Вывод можно скопировать кнопкой копирования и скачать: нажатие на
скачивание отправляет `sf-progress-run-download` с `{fileName}`. Без отмены
браузер сохраняет вывод текстом под именем `file-name`; страница, у которой
есть полный журнал, отменяет событие и отдаёт свой файл. Открытие и закрытие
панели сообщает `sf-progress-run-toggle` с `{open}`.

:::example {id="smart-components/progress-run/output" label="Вывод" preview=sandbox log_console=true log_open=false}
:::

### Шаг из кода

`step({id, state, text, started, finished, duration})` меняет один шаг: данные
заменяют поля этого шага, пока хост не задаст список заново. Для
неизвестного `id` метод отвечает отказом `{reason: 'missing'}`. Так в
примере в начале страницы идут шаги.

### События

| Событие | `detail` | Когда |
|:---|:---|:---|
| `sf-progress-run-cancel` | `{}` | Нажата «Отменить». Хост останавливает задание и ставит `run-state="cancelled"`. |
| `sf-progress-run-retry` | `{}` | Нажата «Повторить». Хост запускает задание заново и задаёт шаги. |
| `sf-progress-run-close` | `{reason: 'close'}` | Нажата «Скрыть». Без отмены хост убирает задание или закрывает панель, в которой оно стоит. |
| `sf-progress-run-download` | `{fileName}` | Нажато скачивание вывода. |
| `sf-progress-run-toggle` | `{open}` | Панель вывода открыта или закрыта. |

## Доступность

- Задание — область страницы с именем из `label`.
- Шаги — упорядоченный список; каждый говорит своё состояние словом после
  названия, идущий шаг отмечен как текущий.
- Строка итога объявляется, когда задание закончилось; смена шагов вслух не
  читается.
- У кнопки «Вывод» есть состояние «развёрнуто»; вывод — журнал, который можно
  прокрутить с клавиатуры.
- `Tab` проходит по кнопке «Вывод», выводу, копированию, скачиванию и
  кнопкам действий; `Enter` или `Пробел` нажимают кнопку. Сам компонент фокус
  не забирает.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `look` | строка | `full` | `full`, `compact`, `notice` | Вид: `full` — карточка: заголовок со значком состояния, общая полоса с «N из M · %» и оставшимся временем, счётчики, первые ошибки, шаги с журналом у каждого, действия; после завершения это и итог. `compact` — одна строка для строки таблицы: тонкая полоса с «62 % · 3 мин», пока идёт работа, значок состояния после остановки, действия иконками. `notice` — одна строка для угловой панели: кольцо на месте иконки, название, строка цифр и «Развернуть». Данные во всех видах одни; вид меняет приложение (`minimize`, `expand`). Атрибут называется `look`, а не `view`: `view` занято самим элементом. |
| `label` | строка | пусто | — | Название задачи так, как его говорит человек («Импорт товаров из «Прайс_ноябрь.xlsx»»): заголовок уровня `heading-level` и имя области. Без него область называется «Ход выполнения» / «Progress», а в полном виде нет строки заголовка. |
| `heading-level` | строка | `3` | `1`, `2`, `3`, `4`, `5`, `6` | Уровень заголовка в структуре страницы (h1–h6), по умолчанию 3. Только смысл: заголовок рисуется полужирной строкой текста своей ступени при любом уровне, поэтому следует плотности и шкале телефона. |
| `caption` | строка | пусто | — | Строка под заголовком: где и когда («Каталог «Электроника» · запущено в 14:02»). Обычный текст. |
| `value` | число | — | от 0 | Сколько сделано, в единицах `total` (например `4812`). С `total` общая полоса показывает долю, а цифры читаются «4 812 из 12 000 товаров · 40 %»; без `total` полоса бежит (неопределённый ход), а цифра показывает, сколько сделано на сейчас. |
| `total` | число | — | от 0 | Сколько всего (например `12000`). Не задано или `0` — размер ещё неизвестен, полоса бежит; как только значение задано, та же полоса заполняется, один раз. |
| `unit` | строка | пусто | — | Слово для цифр, формы множественного числа через `\|` в порядке категорий языка страницы (ru: «товар\|товара\|товаров», en: «item\|items»); одна форма используется для всех чисел. |
| `remaining` | число | — | от 0 | Оставшееся время в миллисекундах, когда приложение его знает. Без него компонент вычисляет его по скорости роста `value`, скрывает, пока скорость не установится (5 с изменений), и всегда округляет вверх («осталось ≈ 6 мин», «меньше минуты»). |
| `started-at` | строка | пусто | — | Когда задача началась (ISO 8601): прошедшее время, пока размер неизвестен, и «заняло 8:08» после завершения. Без него время считается с момента, когда компонент впервые увидел, что задача идёт. |
| `finished-at` | строка | пусто | — | Когда задача закончилась (ISO 8601), для итога, который печатает сервер: «заняло» — это `finished-at` − `started-at`. |
| `run-state` | строка | `auto` | `auto`, `running`, `paused`, `done`, `partial`, `failed`, `cancelled` | Состояние задачи (имя `state` занято самим элементом). `auto` выводит его из шагов: `failed`, если один не удался, `running`, пока один идёт, `done`, когда все шаги выполнены или пропущены (`partial`, если `errors-total` или счётчик ошибок больше 0), иначе `waiting` (рисуется как в очереди). `paused` — приложение остановило задачу и продолжит: значок и полоса предупреждения. `partial` — задача закончилась с ошибками: значок и полоса предупреждения, никогда не успеха. `cancelled` — приложение остановило задачу насовсем: нейтральное. |
| `result-text` | строка | пусто | — | Итог словами после завершения: «Сайт создан» при успехе, причина при сбое («Не хватает места на диске»), что делать при частичном результате. Без него итог говорит «Готово», «Готово с ошибками», «Не удалось» или «Отменено». |
| `errors-total` | число | — | от 0 | Сколько всего ошибок было у задачи (например `40`). Если больше показанных — «Ещё 35 ошибок» отправляет `report`; при значении больше `0` завершённая задача в `auto` считается частично выполненной. |
| `output` | строка | пусто | — | Вывод задания простым текстом, который печатает сервер; метод `chunk` дописывает к нему. Показывается моноширинным шрифтом, никогда как разметка. |
| `output-label` | строка | — | — | Подпись кнопки панели вывода; без неё — «Вывод» на русской странице и «Output» на остальных. |
| `file-name` | строка | `output.txt` | — | Имя файла, под которым кнопка скачивания сохраняет вывод. |
| `cancelable` | да/нет | нет | — | Показывает «Отменить», пока задание идёт; нажатие отправляет `sf-progress-run-cancel`. |
| `pausable` | да/нет | нет | — | Показывает «Пауза», пока задача работает, и «Продолжить», пока она на паузе; нажатия отправляют `pause` и `resume`. Только там, где приложение действительно может приостановить задачу. |
| `retryable` | да/нет | нет | — | Показывает «Повторить» после сбоя, отмены или частичного результата; нажатие отправляет `retry {scope, from?}`: «Повторить неудачные» (`scope: failed`) при частичном результате, «Повторить» (`scope: all`, с шага сбоя) при сбое. |
| `hideable` | да/нет | нет | — | Показывает «Скрыть», когда задание закончилось; нажатие отправляет `sf-progress-run-close`. |
| `minimizable` | да/нет | нет | — | Показывает «Свернуть» в полном виде; нажатие отправляет `minimize`, и приложение показывает вид уведомления (угловую панель собирает страница). |
| `size` | строка | `1` | `1/2`, `1` | Размер: от него зависят название шага, текст, время, вывод и высота шага. `1/2` — для узкой выдвижной панели. |
| `output-open` | да/нет | нет | — | Панель вывода открыта. Человек открывает и закрывает её кнопкой; страница может открыть её сама, например при неудаче. Панель идёт за новыми строками, только пока читатель в конце вывода. |
| `steps` | список | `[]` | — | Шаги задачи по порядку, каждый — `{id, title, state waiting\|running\|done\|failed\|skipped, text?, value?, total?, unit?, log?, started?, finished?, duration?}`. Свойство или JSON-остров, который печатает сервер; приложение задаёт весь список заново или меняет один шаг действием `step`. Время шага: `duration` в миллисекундах, иначе `finished` − `started` (ISO 8601), а у идущего шага со `started` время растёт каждую секунду. Неизвестное состояние читается как `waiting`. `value` и `total` дают шагу свои цифры («18 240 из 42 600 файлов») перед его текстом; `log` — журнал шага на сейчас обычным текстом (его печатает сервер), а `chunk({text, step})` дописывает к нему. |
| `counters` | список | `[]` | — | Итоговые счётчики одной строкой табличными цифрами: «Добавлено 9 227 · Обновлено 2 755 · 18 ошибок». Каждый — `{id, label, value, status?, zero?}`: подпись и за ней значение, или `{n}` там, где стоит число; формы множественного числа через `\|` («{n} ошибка\|{n} ошибки\|{n} ошибок»). Счётчик со значением 0 пропускается; счётчик ошибок со значением 0 после завершения показывает свои слова `zero` («ошибок нет») тихим цветом. Цветом выделяется только ненулевое число ошибок, и оно — ссылка, которая отправляет `report`. |
| `errors` | список | `[]` | — | Первые ошибки задачи, каждая — `{where?, key?, text}`: где случилась (строка «218»), что (артикул «TV-55-QL») и почему. В итоге показываются первые 5; сколько их всего — в `errors-total`. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `chunk(args: object\|string)` | объект | Добавляет текст в вывод: `chunk({text, step?})`; строка `chunk(text)` — короткая запись. Со `step` текст идёт в журнал этого шага (его строка раскрывает журнал; у шага со сбоем он открыт сам); без `step` — в общий вывод. Перевод строки заканчивает строку; панель следует за новым текстом, только пока читатель в её конце. Отказ `{reason: invalid}` — нет текста, `{reason: missing}` — такого шага нет. |
| `clear()` | объект | Очищает вывод, например когда задание запущено заново. |
| `step(args: object)` | объект | Меняет один шаг: переданные поля заменяют поля шага (`state`, `text`, `value`, `total`, `started`, `finished`, `duration`). Отказ `{reason: missing}` — такого шага нет. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-progress-run-cancel` | пустой объект | Человек нажал «Отменить», пока задание шло. Это просьба: хост останавливает задание и ставит состояние `cancelled` (или неудачный шаг); сам компонент ничего не меняет. |
| `sf-progress-run-retry` | `{ scope: "all" \| "failed", from?: string }` | Человек нажал «Повторить»: `{scope: failed}` после частичного результата — только то, что не удалось; `{scope: all, from?}` после сбоя (`from` — шаг, на котором произошёл сбой) или отмены. Приложение запускает задачу заново и задаёт шаги снова. |
| `sf-progress-run-close` | `{ reason: any }` | Человек нажал «Скрыть» после конца задания. Это просьба: без отмены хост убирает задание или закрывает панель, в которой оно стоит; сам компонент не скрывается. |
| `sf-progress-run-download` | `{ fileName: string }` | Человек нажал скачивание вывода. Без отмены браузер сохраняет вывод текстом под именем `file-name`; страница, у которой есть полный журнал, отменяет событие и отдаёт свой файл. |
| `sf-progress-run-toggle` | `{ open: boolean }` | Панель вывода открыта или закрыта кнопкой: `open` — состояние после изменения. |
| `sf-progress-run-pause` | пустой объект | Человек нажал «Пауза» во время работы задачи (`pausable`). Это запрос: приложение приостанавливает задачу и ставит `run-state="paused"`; компонент сам ничего не меняет. |
| `sf-progress-run-resume` | пустой объект | Человек нажал «Продолжить», когда задача стояла на паузе (`pausable`). Это запрос: приложение продолжает задачу и ставит `run-state="running"`. |
| `sf-progress-run-minimize` | пустой объект | Человек нажал «Свернуть» в полном виде (`minimizable`). Это запрос: приложение показывает вид уведомления в своей угловой панели. |
| `sf-progress-run-expand` | пустой объект | Человек нажал «Развернуть» в виде уведомления. Это запрос: приложение показывает полный вид (в выдвижной панели или на месте). |
| `sf-progress-run-report` | пустой объект | Человек попросил ошибки: ссылка с числом ошибок или «Ещё N ошибок». Если событие не отменено, ссылка ведёт к списку ошибок в итоге; полный отчёт (файл, страницу) отдаёт ваше приложение. |
