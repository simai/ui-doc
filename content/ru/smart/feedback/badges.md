# Бейджи

:badge[sf-badge]{type=tonal scheme=primary size=1/2} :badge[1.2.1]{type=outline scheme=on-surface size=1/2}

Бейдж показывает короткую пометку рядом с объектом: статус записи, категорию,
версию, число новых событий. Пометку не нажимают. Для метки, которую выбирают
или удаляют, берите [Теги](/ru/smart/content/tags/).

То же на классах — [Бейджи](/ru/components/feedback/badges/): элемент строится
на классах этого компонента; классы годятся для статической разметки без
JavaScript.

## Разметка

Пометке нужен текст:

```html
<sf-badge text="Черновик"></sf-badge>
```

Текст задаёт атрибут `text`. Слоты `text`, `icon-start` и `icon-end`
заменяют части своей разметкой.

## Варианты

У пометки отдельные оси: насколько она заметна (`appearance`), какой
цветовой роли (`scheme`), о чём сообщает (`status`), размер, строка текста,
иконки и состояние работы.

### Вид

`appearance` задаёт, насколько пометка заметна: `main` — плотная заливка
(по умолчанию), `tonal` — спокойная, `outline` — контур.

:::example {id="smart-components/badges/appearance" label="Виды пометки"}
:::

### Цвет

`scheme` выбирает цветовую роль: `neutral`, `primary`, `secondary`,
`tertiary`, `on-surface`. `status` говорит, о чём пометка сообщает: `info`,
`success`, `warning`, `error`. `status` сильнее `scheme`: пометка со статусом
окрашивается по статусу. Цветовую роль берите для категорий, статус — для
состояния объекта, и не передавайте состояние одним цветом — текст пометки
называет его словами.

:::example {id="smart-components/badges/color" label="Цветовые роли и статусы"}
:::

### Размер

`size` — ступень `1/3` (по умолчанию), `1/2` или `1`.

:::example {id="smart-components/badges/sizes" label="Размеры пометки"}
:::

### В строке текста

В строке таблицы или в ряду полей задайте `line` (`1/2`, `1`, `2`): пометка
займёт строку текста этого размера формы, и строка не станет выше.

:::example {id="smart-components/badges/line" label="Пометка рядом с кнопкой того же размера"}
:::

### Иконки

`icon` ставит иконку перед текстом; `icon-position="end"` переносит её за
текст. Для двух иконок сразу есть `icon-start` и `icon-end`.

:::example {id="smart-components/badges/icons" label="Иконки в пометке"}
:::

### Состояние работы

`activity` показывает, где сейчас работа: `running`, `waiting`, `done`,
`stopped` или `failed`. У каждого состояния своя иконка и слово на языке
страницы: у `running` вместо иконки индикатор загрузки. Это отдельный вопрос от
`status`, который говорит, чем всё закончилось: если заданы оба, `activity`
определяет иконку, текст и цвет. `text` и `icon` заменяют слово и иконку.

`compact` оставляет видимой только иконку, а слово становится доступным именем:
так метка помещается в строку списка. Пометка не объявляется вслух сама: строка
списка не живая область. Без анимации индикатор стоит на месте.

:::example {id="smart-components/badges/activity" label="Пять состояний работы и компактный вид"}
:::

## Доступность

- Пометка — текст, она не получает фокус и не реагирует на клавиатуру.
- Видимый текст читается как есть. Если он понятен только из контекста —
  число «3», сокращение «β», — задайте `aria-label` с полным смыслом: «3
  ошибки». Тогда экранный диктор читает `aria-label` вместо видимого текста.
- Пометка без текста и без `aria-label` скрыта от экранного диктора: так
  ведёт себя точка или одна иконка. Сообщите то же самое текстом рядом.
- Иконки декоративны.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1/3` | `1/3`, `1/2`, `1` | — |
| `line` | строка | пусто | пусто, `1/2`, `1`, `2` | Занимает строку текста этого размера формы — для ячейки таблицы или ряда полей, чтобы строка сохраняла высоту элемента управления. |
| `appearance` | строка | `main` | `main`, `tonal`, `outline` | Вид значка: наиболее заметная заливка, более спокойная тональная или контур. |
| `scheme` | строка | `neutral` | `neutral`, `primary`, `secondary`, `tertiary`, `on-surface` | Какой смысловой цвет берёт бейдж. Слово статуса здесь тоже работает и попадает на ось status. |
| `status` | строка | пусто | пусто, `info`, `success`, `warning`, `error` | О чём сообщает бейдж, в общем словаре статусов. Также принимается значение danger; оно означает error. |
| `activity` | строка | пусто | пусто, `running`, `waiting`, `done`, `stopped`, `failed` | Где находится выполнение: `running` рисует индикатор на месте значка, `waiting`, `done`, `stopped` и `failed` — свой значок, у каждого своё слово и цветовая роль. Важнее `status` и `scheme` для значка, текста и цвета; `text` и `icon` его переопределяют. |
| `compact` | да/нет | нет | — | Показывает только значок — для тесной строки списка; текст остаётся доступным именем. Нужен значок: без него текст остаётся видимым. Вид не меняется. |
| `text` | строка | пусто | — | — |
| `icon` | строка | пусто | — | — |
| `icon-start` | строка | пусто | — | — |
| `icon-end` | строка | пусто | — | — |
| `icon-position` | строка | `start` | `start`, `end` | — |
| `aria-label` | строка | пусто | — | — |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.
