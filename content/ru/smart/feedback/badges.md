# Бейджи

:badge[sf-badge]{variant=outline scheme=on-surface size=1/2} :badge[1.6.3]{variant=outline scheme=on-surface size=1/2}

Бейдж показывает короткую пометку рядом с объектом: статус записи, категорию,
версию, число новых событий. Пометку не нажимают. Для метки, которую выбирают
или удаляют, берите [Теги](/ru/smart/content/tags/).

То же на классах — [Бейджи](/ru/components/feedback/badges/): элемент строится
на классах этого компонента; классы годятся для статической разметки без
JavaScript.

## Разметка

Пометке нужен текст:

```html
<sf-badge text="Черновик"></sf-badge>
```

Текст задаёт атрибут `text`. Слоты `text`, `icon-start` и `icon-end`
заменяют части своей разметкой.

## Варианты

У пометки отдельные оси: насколько она заметна (`appearance`), какой
цветовой роли (`scheme`), о чём сообщает (`status`), размер, строка текста,
иконки и состояние работы.

### Вид

`appearance` • по умолчанию `tonal` • [справочник](#атрибуты)

`appearance` задаёт, насколько пометка заметна: `tonal` — спокойная заливка
(по умолчанию), `outline` — контур, `main` — плотная заливка. Плотную
заливку берите только для счётчика, который зовёт человека, — со
`status="error"`.

:::example {id="smart-components/badges/appearance" label="Виды пометки"}
:::

Вид следует за работой пометки:

| Работа | Вид |
|:---|:---|
| Статус или значение: раздел, тег, выбор в ячейке таблицы | `tonal` со `status` или цветом роли |
| Пометка рядом с названием: версия, тип | `outline` |
| Количество | `tonal`, серый |
| Счётчик, который зовёт человека | `main` со `status="error"` |
| Где сейчас работа | `activity` |

Размер пометки следует за тем, где она стоит. Так её ставят компоненты
Framework, так ставьте и свою:

| Где стоит | Размер | Как стоит |
|:---|:---|:---|
| Строка списка, ячейка таблицы, ряд полей размера `1/2` или `1` | `1/3` | `line` того же размера; в списке и таблице — `tight` |
| Ряд размера `2` | `1/2` | `line="2"` |
| Заголовок раздела размера `3` | `1` | `line="text"` |
| Рядом с заголовком страницы | `1/2` | `outline` для пометки, серый `tonal` для числа |
| Пункт оглавления, вкладка | — | `line="text"`: высотой со строку, одна цифра — круг |
| Изменение в плитке с показателем | на ступень меньше плитки | `tonal` со `status` |

### Цвет

`scheme`, `status` • [справочник](#атрибуты)

`scheme` выбирает цветовую роль: `neutral`, `primary`, `secondary`,
`tertiary`, `on-surface`. `status` говорит, о чём пометка сообщает: `info`,
`success`, `warning`, `error`. `status` сильнее `scheme`: пометка со статусом
окрашивается по статусу. Цветовую роль берите для категорий, статус — для
состояния объекта, и не передавайте состояние одним цветом — текст пометки
называет его словами.

:::example {id="smart-components/badges/color" label="Цветовые роли и статусы"}
:::

### Размер

`size` • по умолчанию `1/3` • [справочник](#атрибуты)

`size` — ступень `1/3` (по умолчанию), `1/2` или `1`.

:::example {id="smart-components/badges/sizes" label="Размеры пометки"}
:::

Отступ текста от края — `--sf-space-1/2`: 12 px на компьютере и 8 px на телефоне, как у всей линейки отступов; плотный `sf-badge--tight` — свой отступ размера.

:::example {id="smart-components/badges/tight" label="Размер"}
:::

### В строке текста

`line` • [справочник](#атрибуты)

В строке таблицы или в ряду полей задайте `line` (`1/2`, `1`, `2`): пометка
займёт строку текста этого размера формы, и строка не станет выше.

:::example {id="smart-components/badges/line" label="В строке текста"}
:::

### Иконки

`icon`, `icon-position`, `icon-start` • [справочник](#атрибуты)

`icon` ставит иконку перед текстом; `icon-position="end"` переносит её за
текст. Для двух иконок сразу есть `icon-start` и `icon-end`.

:::example {id="smart-components/badges/icons" label="Иконки в пометке"}
:::

### Состояние работы

`activity`, `status`, `text` • [справочник](#атрибуты)

`activity` показывает, где сейчас работа: `running`, `waiting`, `done`,
`stopped` или `failed`. У каждого состояния своя иконка и слово на языке
страницы: у `running` вместо иконки индикатор загрузки. Это отдельный вопрос от
`status`, который говорит, чем всё закончилось: если заданы оба, `activity`
определяет иконку, текст и цвет. `text` и `icon` заменяют слово и иконку.

`icon-only` оставляет видимой только иконку, а слово становится доступным именем:
так метка помещается в строку списка. Пометка не объявляется вслух сама: строка
списка не живая область. Без анимации индикатор стоит на месте.

:::example {id="smart-components/badges/activity" label="Состояние работы"}
:::

## Доступность

- Пометка — текст, она не получает фокус и не реагирует на клавиатуру.
- Видимый текст читается как есть. Если он понятен только из контекста —
  число «3», сокращение «β», — задайте `aria-label` с полным смыслом: «3
  ошибки». Тогда экранный диктор читает `aria-label` вместо видимого текста.
- Пометка без текста и без `aria-label` скрыта от экранного диктора: так
  ведёт себя точка или одна иконка. Сообщите то же самое текстом рядом.
- Иконки декоративны.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1/3` | `1/3`, `1/2`, `1` | — |
| `line` | строка | пусто | пусто, `1/2`, `1`, `2`, `text` | Берёт строку текста этого размера формы — для ячейки таблицы или ряда полей, чтобы ряд сохранял высоту элемента. text берёт строку текста, рядом с которым стоит: размер и высота строки наследуются, без внутренних отступов по вертикали, поэтому счётчик в пункте оглавления, вкладке или строке списка высотой со строку, а одна цифра — круг. |
| `appearance` | строка | `tonal` | `main`, `tonal`, `outline` | Вид бейджа: tonal (по умолчанию, спокойная заливка своего цвета), outline (отметка рядом с заголовком: версия, тип) или main — залитый вид, только для счётчика внимания (со статусом error). main с любым другим цветом рисуется как tonal; такая запись пишется в SF.deprecations до 2027-01-01. |
| `scheme` | строка | `neutral` | `neutral`, `primary`, `secondary`, `tertiary`, `on-surface` | Цвет бейджа, например `primary`. Слово статуса, например `error`, здесь тоже работает. |
| `status` | строка | пусто | пусто, `info`, `success`, `warning`, `error` | Цвет по смыслу, например `success` или `error`. `danger` тоже принимается и значит `error`. |
| `activity` | строка | пусто | пусто, `running`, `waiting`, `done`, `stopped`, `failed`, `paused`, `queued` | Где находится выполнение: `running` рисует спиннер на месте иконки, у `waiting` (нужен ввод человека), `done`, `stopped`, `failed`, `paused` (остановлено и продолжится) и `queued` (в очереди) — своя иконка, своё слово и свой цвет. Важнее `status` и `scheme` для иконки, текста и цвета; `text` и `icon` его переопределяют. |
| `icon-only` | да/нет | нет | — | Показывает только значок — для тесной строки списка; текст остаётся доступным именем, а рамка становится квадратом. Нужен значок: без него текст остаётся видимым. Вид не меняется. Прежний флаг compact рисует то же до 2027-01-01 (каждое использование пишется в SF.deprecations). |
| `tight` | да/нет | нет | — | Оставляет узкие поля по бокам для плотных мест — таблицы, счётчика, плашки в строке: --sf-space-1/3, на шаг меньше, чем --sf-space-1/2 по умолчанию (8 · 4 в компактной · 8 на телефоне). |
| `text` | строка | пусто | — | — |
| `icon` | строка | пусто | — | — |
| `icon-start` | строка | пусто | — | — |
| `icon-end` | строка | пусто | — | — |
| `icon-position` | строка | `start` | `start`, `end` | — |
| `aria-label` | строка | пусто | — | — |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.
