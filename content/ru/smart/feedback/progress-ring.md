# Кольцо прогресса

:badge[sf-progress-ring]{variant=outline scheme=on-surface size=1/2} :badge[1.6.4]{variant=outline scheme=on-surface size=1/2}

Кольцо прогресса показывает значение от 0 до 100 кольцом размером с элемент
управления: в панели инструментов, в боковой полосе, вокруг аватара. Для
длинной задачи в теле страницы берите
[Прогресс](/ru/smart/feedback/progress-bar/), а там, где сказать можно только
«идёт работа», — [Спиннер](/ru/smart/feedback/spinner/).

## Разметка

В разметке — один тег: `<sf-progress-ring>` с `label` и `value`. Значение и
доступное имя задаёт страница.

```html
<sf-progress-ring label="Загрузка файлов" value="62"></sf-progress-ring>
```

- `value` — проценты, число от 0 до 100; значения вне диапазона приводятся к
  границе.
- `label` — доступное имя: что именно выполняется. Без него кольцо называет
  `aria-label` на самом теге.
- `value-text` — значение словами («3 из 5 файлов»); экранный диктор читает
  его вместо процента.
- `show-text` показывает процент в середине кольца.
- Слот `content` занимает середину вместо процента. Его место — кольцо без
  линии и зазора, по 2 px с каждой стороны, поэтому картинка не касается
  линии: аватар на ступень меньше кольца (`size="1/2"` в кольце `1`,
  `size="1"` в кольце `2`) заполняет середину точно.

## Варианты

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

`size` — ступень общей лестницы: `1/2`, `1` (по умолчанию) и `2`. На каждой
ступени кольцо занимает габарит кнопки со значком или аватара того же
размера, поэтому стоит в одной строке с ними.

:::example {id="smart-components/progress-ring/sizes" label="Три ступени размера"}
:::

### Статус

`status` • по умолчанию `neutral` • [справочник](#атрибуты)

`status` сообщает смысл из общего словаря: `neutral` (по умолчанию), `info`,
`success`, `warning`, `error`. Кольцо не выводит статус из значения: порог
«с 80 % — предупреждение» — дело страницы, она и задаёт `status`.

:::example {id="smart-components/progress-ring/statuses" label="Пять статусов"}
:::

### Счётчик и мера

`meter` • [справочник](#атрибуты)

`meter` говорит, что кольцо показывает величину в известных границах —
занятую долю квоты, а не ход задачи: роль становится `meter` вместо
`progressbar`.

:::example {id="smart-components/progress-ring/meter" label="Квота и аватар в середине"}
:::

## Состояния

### Значение неизвестно

`indeterminate` • [справочник](#атрибуты)

`indeterminate` показывает, что работа идёт, а доля неизвестна: по кольцу
бежит дуга спиннера, и значение не называется.

:::example {id="smart-components/progress-ring/indeterminate" label="Подготовка без известной доли"}
:::

## Поведение

### Значение из скрипта

Меняйте `value` по ходу работы — кольцо перерисовывает заливку и обновляет
`aria-valuenow`. Действие `chunk({done, total})` показывает часть работы:
`value` становится долей `done` от `total` в процентах (`total` по умолчанию
100) и отвечает `applied` или `refused`.

```js
const ring = document.querySelector('sf-progress-ring');
for (const [index, file] of files.entries()) {
  await upload(file);
  ring.chunk({done: index + 1, total: files.length});
}
ring.setAttribute('status', 'success');
ring.setAttribute('value-text', 'Файлы загружены');
```

### Кольцо вокруг картинки

Кольцо вокруг аватара показывает долю и оставляет картинку на месте: кольцо
несёт роль и значение, а содержимое слота стоит рядом с ним, поэтому у
картинки остаётся своё имя. Кольцо внутри кнопки называет кнопка — дайте ей
имя, в котором есть и значение.

```html
<button type="button" class="account" aria-label="Анна Ким, использовано 62 % лимита">
  <sf-progress-ring value="62" meter label="Использовано">
    <sf-avatar slot="content" size="1/2" text="АК"></sf-avatar>
  </sf-progress-ring>
</button>
```

### Без скрипта

Кольцо, значение которого не меняется после загрузки страницы, можно
записать классами — так его рисует и сам компонент до запуска скрипта.
Блок `sf-progress-ring` с размером `sf-progress-ring--size-*` и статусом
`sf-progress-ring--success`, `--warning`, `--error` или `--info` получает
долю в переменной `--sf-progress-ring--value` (от 0 до 100). Внутри —
`sf-progress-ring-indicator` с ролью `progressbar` и значением для экранного
диктора и необязательный текст `sf-progress-ring-content`, скрытый от
диктора. `sf-progress-ring--indeterminate` рисует ожидание без доли.

```html
<div class="sf-progress-ring sf-progress-ring--size-1" style="--sf-progress-ring--value: 62">
  <span class="sf-progress-ring-indicator" role="progressbar" aria-valuemin="0"
        aria-valuemax="100" aria-valuenow="62" aria-label="Загрузка файлов"></span>
  <span class="sf-progress-ring-content" aria-hidden="true">62%</span>
</div>
```

Значение классового кольца меняют сами: и переменную, и `aria-valuenow`.
Если доля меняется, берите `<sf-progress-ring>`.

:::example {id="smart-components/progress-ring/static" label="Кольцо на классах"}
:::

### Внешний вид

Открытые переменные: `--sf-progress-ring-size`,
`--sf-progress-ring-line-width` (2 px), `--sf-progress-ring-gap` (2 px),
`--sf-progress-ring-fill-color`, `--sf-progress-ring-track-color` и
`--sf-progress-ring-color` — цвет процента. Ноль — допустимое значение линии
и зазора. Заливка переходит между значениями плавно и стоит неподвижно при
системной настройке уменьшения движения, как и дуга неопределённого
ожидания.

## Доступность

- Кольцо несёт роль `progressbar`, а с `meter` — `meter`, вместе с
  `aria-valuemin="0"`, `aria-valuemax="100"` и текущим `aria-valuenow`. При
  `indeterminate` значения нет.
- `label` — доступное имя: что выполняется. `value-text` читается вместо
  процента.
- Кольцо не получает фокус и не слушает клавиши. Если кольцо стоит в кнопке,
  имя даёт кнопка.
- О завершении или ошибке сообщите отдельно — текстом с `role="status"` или
  [Уведомлением](/ru/smart/feedback/alert/): экранный диктор не
  объявляет каждое изменение значения.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1/4`, `1/3`, `1/2`, `1`, `2`, `3` | Лестница аватара: на каждой ступени кольцо — рамка sf-avatar того же размера: 16 / 24 / 32 / 40 / 48 / 56 px для 1/4…3 на широком экране, 16 / 20 / 28 / 36 / 44 / 52 на телефоне, 16 / 20 / 24 / 32 / 40 / 48 в компактной области (1/4 — 16 на любом экране). Поэтому кольцо может стоять на месте аватара своей ступени и обнимать аватар на ступень меньше: с 1/3 на широком экране, с 1/2 на телефоне и в компактной области (там 1/3 — 20, середина 12); у 1/4 ступени аватара ниже нет. 3 — ещё и круг пустого состояния страницы. Проценты показываются с 1. |
| `value` | число | `0` | от 0; до 100; шаблон `^(?:100\|[1-9]?[0-9])(?:\.[0-9]+)?$` | Проценты, от 0 до 100; значения вне диапазона приводятся к границе. |
| `status` | строка | пусто | пусто, `neutral`, `info`, `success`, `warning`, `error` | О чём сообщает значение, по общему словарю статусов. Пусто (по умолчанию) — primary темы; neutral — серый, как у sf-dot и sf-badge; info, success, warning и error — свои роли. Прежнее слово primary ещё принимается и значит то же, что по умолчанию. С warning-at или error-at кольцо берёт более серьёзное из этого статуса и порога, которого достигло значение. |
| `warning-at` | число | — | от 0; до 100 | Порог в процентах: с этого значения компонент сам становится предупреждением (диск заполнен на 83 % при warning-at 80). Порог задаёт страница, компонент только сравнивает. Не задан — порога нет. |
| `error-at` | число | — | от 0; до 100 | Порог в процентах: с этого значения компонент сам становится ошибкой (диск заполнен на 83 % при error-at 80). Порог задаёт страница, компонент только сравнивает. Не задан — порога нет. Если заданы оба, он выше warning-at. |
| `indeterminate` | да/нет | нет | — | Значение неизвестно: по кольцу бежит дуга, число не показывается. |
| `meter` | да/нет | нет | — | Кольцо показывает величину в известных границах (занятую квоту), а не ход задачи: роль `meter` вместо `progressbar`. |
| `show-text` | да/нет | нет | — | Показывает процент в середине; содержимое слота занимает его место, если задано. |
| `label` | строка | пусто | — | Доступное имя; без него кольцо называет `aria-label` на самом теге. |
| `value-text` | строка | пусто | — | Значение словами («3 из 5 файлов»); читается вместо процента. |
| `aria-label` | строка | пусто | — | — |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `chunk(args: object)` | объект | Показывает часть работы (`chunk {done, total}`): `value` становится долей `done` от `total` в процентах; `total` по умолчанию 100. Принимает `chunk({done, total})` или `chunk(done, total)`. |
