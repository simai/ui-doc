# Уведомления и состояния

- [Уведомление](/ru/smart/feedback/alert/) — Показывает постоянное сообщение в потоке страницы: статус, текст, до двух действий и закрытие.
- [Плашка уведомлений](/ru/smart/feedback/alert-bar/) — Полоса во всю ширину над шапкой страницы для состояний, которые требуют действия сейчас: ошибка, предупреждение, сведения.
- [Требует внимания](/ru/smart/feedback/list-attention/) — Список проблем, которым нужен человек: самые серьёзные первыми, у каждой одно действие.
- [Всплывающие сообщения](/ru/smart/feedback/toast/) — Кратко сообщает результат действия поверх интерфейса, не прерывая работу пользователя.
- [Бейджи](/ru/smart/feedback/badges/) — Показывает короткую неинтерактивную пометку рядом с объектом: статус, категорию, версию или число.
- [Прогресс](/ru/smart/feedback/progress-bar/) — Показывает известный ход процесса сплошной полосой от 0 до 100 процентов.
- [Кольцо прогресса](/ru/smart/feedback/progress-ring/) — Показывает долю выполненного кольцом в габарите элемента управления: в панели, в строке, вокруг аватара.
- [Шкала прогресса](/ru/smart/feedback/progress-scale/) — Показывает известный ход процесса шкалой из десяти делений.
- [Ход выполнения](/ru/smart/feedback/progress-run/) — Долгое задание по шагам: состояния и время шагов, вывод, итог, отмена и повтор.
- [Скелетон](/ru/smart/feedback/skeleton/) — Занимает место будущего содержимого фигурами той же формы, пока данные загружаются.
- [Спиннер](/ru/smart/feedback/spinner/) — Показывает ожидание, длительность которого неизвестна, в одном из четырёх видов с подписью; вид задаётся один раз для страницы.
- [Подсказка](/ru/smart/feedback/tooltip/) — Рисует поверхность короткой подсказки с текстом, пояснением и стрелкой для компонентов, которые сами управляют её показом.
- [Подсказка «?»](/ru/smart/feedback/help-mark/) — Знак «?» рядом с подписью: по нажатию открывает короткое пояснение, работает на сенсорных экранах и может содержать ссылки.
- [Пустое состояние](/ru/smart/feedback/empty-state/) — Показывает, почему в списке, панели или на странице нечего показать: нет данных, ничего не найдено, нет доступа или ошибка.
