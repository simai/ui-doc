# Подсказка «?»

:badge[sf-help-mark]{type=tonal scheme=primary size=1/2} :badge[1.1.8]{type=outline scheme=on-surface size=1/2}

Подсказка «?» стоит рядом с подписью и открывает короткое пояснение: что
значит поле или настройка. Для короткого имени кнопки-иконки берите
[Всплывающую подсказку](/ru/smart/feedback/tooltip/).

## Разметка

Знаку нужны пояснение и доступное имя:

```html
<sf-help-mark label="Подробнее: код решения"
  text="Уникальное имя модуля латиницей, например simai.billing."></sf-help-mark>
```

- `text` — пояснение; вместо него можно передать слот `content` со ссылками или
  списком.
- `heading` — короткая строка заголовка над пояснением; `title` — другое имя
  `heading`, работает до 2026-12-01.
- `label` — доступное имя кнопки, по умолчанию «Подробнее».

```html
<sf-help-mark label="Подробнее: уровни доступа">
  <div slot="content">Права задаются ролями. Подробнее — в <a class="sf-link" href="/help/access">руководстве по доступу</a>.</div>
</sf-help-mark>
```

Ширина пояснения — не больше 20rem.

## Варианты

### Размер

`size` — `1/3`, `1/2` (по умолчанию) или `1`. Знак не добавляет высоты ни
строке текста, ни строке подписи поля: кнопка стоит посередине строки и
выходит за неё, не раздвигая. У подписи поля удобен `1/3`.

:::example {id="smart-components/help-mark/sizes" label="Размеры знака"}
:::

### Положение

`placement` — `auto` (по умолчанию: снизу, с переворотом, если места нет),
`top`, `bottom`, `start`, `end`.

## Поведение

### Подсказка «?» или всплывающая подсказка

| | [Всплывающая подсказка](/ru/smart/feedback/tooltip/) | Подсказка «?» |
|:---|:---|:---|
| Для чего | короткое имя кнопки-иконки: «Удалить», «Копировать» | пояснение: что значит поле или настройка |
| Как открывается | наведением или фокусом, исчезает сама | нажатием, остаётся, пока её не закроют |
| На сенсорном экране | не работает | работает |
| Ссылки внутри | нельзя | можно |

### Открытие и закрытие

Пояснение открывается только нажатием — мышью, пальцем, `Enter` или пробелом;
наведение его не открывает. Второе нажатие, `Escape` или щелчок мимо
закрывают пояснение. Из скрипта его открывают `open()` и закрывают `close()`.
При открытии и закрытии приходят события `sf-help-mark-opened` и
`sf-help-mark-closed`; `sf-help-mark-open` и `sf-help-mark-close` — их
устаревшие имена с тем же `detail`.

### Рядом с подписью поля

```html
<label for="solution-code">Код решения</label>
<sf-help-mark label="Подробнее: код решения" heading="Код решения" size="1/3"
              text="Уникальное имя модуля латиницей, например simai.billing."></sf-help-mark>
<input id="solution-code" name="code">
```

Знак стоит рядом с подписью, а не внутри `<label>`: внутри подписи он стал бы
её элементом управления, и нажатие на текст подписи открывало бы пояснение
вместо перехода в поле. Полная разметка поля со знаком — в
[Текстовые поля → Поле с пояснением к подписи](/ru/components/forms/inputs/#поле-с-пояснением-к-подписи).

## Доступность

- `label` — доступное имя кнопки, по умолчанию «Подробнее». Называйте, о чём
  пояснение: «Подробнее: код решения». Имя стоит только в `aria-label`: у
  кнопки нет `title`, поэтому экранный диктор не повторяет имя описанием.
- Кнопка сообщает `aria-expanded`; при открытии текст пояснения вежливо
  объявляется для чтения с экрана, фокус остаётся на кнопке.
- Если в пояснении есть ссылка или другой элемент управления, `Tab` с кнопки
  переходит в пояснение, а пояснение закрывается, когда фокус уходит и с
  кнопки, и из него. Без таких элементов `Tab` идёт дальше, а пояснение
  остаётся открытым до `Escape`, повторного нажатия или щелчка мимо.

## Справочник

Собран из манифеста компонента выпуска `ui-98143c0a0728` и обновляется вместе с выпуском. Чтобы исправить описание, исправьте манифест.

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |
| `text` | строка | пусто | — | Пояснение; вместо него слот `content` принимает ссылки или списки. |
| `heading` | строка | пусто | — | — |
| `label` | строка | — | — | Доступное имя кнопки; по умолчанию «Подробнее». Лучше назвать, о чём пояснение («Подробнее: код решения»). |
| `size` | строка | `1/2` | `1/3`, `1/2`, `1` | — |
| `placement` | строка | `auto` | `auto`, `top`, `bottom`, `start`, `end` | — |
| `title` | строка | пусто | — | Псевдоним с датой для `heading` до 2026-12-01. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `open()` | объект | Открывает пояснение. |
| `close()` | объект | Закрывает пояснение. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-help-mark-opened` | нет | — |
| `sf-help-mark-closed` | нет | — |
