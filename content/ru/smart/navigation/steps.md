# Шаги

:badge[sf-steps]{variant=tonal scheme=primary size=1/2} :badge[1.4.1]{variant=outline scheme=on-surface size=1/2}

Шаги показывают этапы процесса, который проходят по порядку: оформление
заказа, публикация, мастер настройки. Пройденные этапы отмечены галочкой,
текущий выделен.

То же на классах — [Шаги](/ru/components/navigation/step/): компонент собирает
разметку обычного шага из строки или массива.

## Разметка

Этапы и имя группы:

```html
<sf-steps aria-label="Этапы оформления заказа"
  items="Корзина|Доставка|Оплата|Подтверждение" current="2"></sf-steps>
```

`items` перечисляет этапы через `|`; после `::` идут флаги, например
`Публикация::disabled`. Можно передать и массив объектов с полями `label` и
`disabled`. `current` — номер текущего этапа, считая с нуля; этапы перед
ним отмечаются пройденными.

### Текущий

`current` • по умолчанию `0` • [справочник](#атрибуты)

### Ошибка

`error-step` • [справочник](#атрибуты)

`error-step` отмечает этап с ошибкой — номер, тоже с нуля. Такой этап

## Поведение

### Переход по этапам

Каждый доступный этап — кнопка. Нажатие делает этап текущим и отправляет
всплывающее событие `sf-steps-change` с `detail.previous`, `detail.current`
(номера с нуля), `detail.item` — данными этапа и `detail.items` — всеми
этапами.
Недоступный этап не нажимается. Если переход назад или вперёд нельзя
разрешить без проверки — например, пока форма этапа не заполнена, —
отметьте следующие этапы `disabled` и снимайте флаг по мере прохождения.

`goToStep(index)` переходит из кода и отправляет то же событие,
`onStepChange(handler)` передаёт обработчику номер нового этапа первым
аргументом. Кнопки «Назад» и «Далее» рядом с этапами задаёт страница.

```js
const steps = document.querySelector('sf-steps');
steps.onStepChange((current) => showPanel(current));

document.querySelector('#next').addEventListener('click', () => {
  if (validateCurrentPanel()) steps.goToStep(Number(steps.getAttribute('current')) + 1);
});
```

## Доступность

- Группе этапов нужно доступное имя: `aria-label` на `<sf-steps>`. По
  умолчанию на русской странице она называется «Шаги».
- Каждый этап — нативная кнопка: `Tab` останавливается на ней, `Enter` и
  `Space` нажимают её. Недоступный этап выпадает из порядка `Tab`.
- Текущий этап отмечен `aria-current="step"`. К имени пройденного этапа
  добавляется «Завершено», к имени этапа с ошибкой — «Ошибка». Слова
  берутся из языка страницы; `completed-label` и `error-label` заменяют их.
- Иконки и разделители скрыты от вспомогательных технологий: состояние
  передаёт имя кнопки, а не цвет.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1`, `1/2` | Ступень: 1 или 1/2 для плотных карточек и панелей. Отметка — строка текста этой ступени (24 при 1, 20 при 1/2 на компьютере). |
| `marker` | строка | `number` | `number`, `dot` | Чем отмечен шаг: номером (галочка у пройденного, «!» при ошибке) или точкой — для простого статуса и плотных карточек. Три формы одни и те же: залитая — пройден, залитая с кольцом — текущий, пустая — впереди. |
| `layout` | строка | `auto` | `auto`, `row`, `column`, `count` | auto: строка, пока шаги помещаются в одну строку своей ширины, иначе колонка (подпись и вторая строка); если собственная ширина меньше 20rem — строка счёта «Шаг N из M · подпись» над sf-progress-bar. row, column и count рисуют свою раскладку всегда; явная строка шире своего места прокручивается внутри. |
| `navigation` | строка | пусто | пусто, `visited`, `free` | Пусто — шаги просто список, ничего не нажимается. visited: шаг позади текущего или пройденный, пропущенный или с ошибкой — кнопка перехода к нему; free: кнопка — любой не выключенный шаг. Как в sf-wizard; текущий шаг кнопкой не бывает. |
| `error-step` | целое число | — | от 0 | Прежний способ отметить шаг с ошибкой: читается до 2027-01-01 и пишется в SF.deprecations. Теперь пункт говорит state "error". |
| `separator-icon` | строка | пусто | — | Прежнее: значок между шагами (chevron_right). Шаги соединяет линия, настройка не действует; пишется в SF.deprecations, удаляется после 2027-01-01. |
| `completed-label` | строка | — | — | Слово, которое экранный диктор слышит после подписи пройденного шага. Пусто — текст на языке страницы. |
| `current-label` | строка | — | — | Слово, которое экранный диктор слышит после подписи текущего шага. Пусто — текст на языке страницы. |
| `ahead-label` | строка | — | — | Слово, которое экранный диктор слышит после подписи ещё не начатого шага. Пусто — текст на языке страницы. |
| `error-label` | строка | — | — | Слово, которое экранный диктор слышит после подписи шага с ошибкой. Пусто — текст на языке страницы. |
| `skipped-label` | строка | — | — | Слово, которое экранный диктор слышит после подписи пропущенного шага. Пусто — текст на языке страницы. |
| `running-label` | строка | — | — | Слово, которое экранный диктор слышит после подписи шага, который идёт. Пусто — текст на языке страницы. |
| `count-label` | строка | — | — | Строка счёта с подставленными {n} и {count}. Пусто — текст на языке страницы. |
| `current` | целое число | `0` | от 0 | Текущий шаг, с 0. Равен числу шагов — все пройдены, текущего нет. |
| `aria-label` | строка | пусто | — | Пусто — текст на языке страницы (по-английски «Steps»). |
| `items` | список | `[]` | — | Шаги по порядку, в JSON: {label, text?, state?, disabled?}. text — вторая строка, которую показывает колонка (дата, время, «необязательно», причина ошибки). state — собственное состояние шага: done, skipped, running или error, либо ahead для шага до текущего, который не пройден; без него решает место (до текущего — done, на текущем — current, после — ahead). completed и default — прежние слова для done и ahead, читаются до 2027-01-01. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `goToStep(args: object\|number)` | объект | Переводит текущий шаг на шаг с индексом index (в пределах списка); выключенный или текущий шаг отклоняет. Двигает независимо от navigation (navigation — то, что может нажать человек). sf-steps-change не присылает: это событие нажатия человеком. |
| `setState(nextState: object)` | объект | Пишет каждый ключ атрибутом в kebab-case; массив (items) пишется в JSON. false, null, undefined или пусто удаляют атрибут, true ставит его пустым. |
| `onStepChange(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик sf-steps-change; обработчик вызывается с (current, detail, event). Обработчик, не являющийся функцией, игнорируется. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-steps-change` | `{ previous: number, current: number, item: object, items: array }` | — |
