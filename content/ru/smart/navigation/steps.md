# Шаги

:badge[sf-steps]{variant=tonal scheme=primary size=1/2} :badge[1.2.1]{variant=outline scheme=on-surface size=1/2}

Шаги показывают этапы процесса, который проходят по порядку: оформление
заказа, публикация, мастер настройки. Пройденные этапы отмечены галочкой,
текущий выделен.

То же на классах — [Шаги](/ru/components/navigation/step/): компонент собирает
разметку обычного шага из строки или массива.

## Разметка

Этапы и имя группы:

```html
<sf-steps aria-label="Этапы оформления заказа"
  items="Корзина|Доставка|Оплата|Подтверждение" current="2"></sf-steps>
```

`items` перечисляет этапы через `|`; после `::` идут флаги, например
`Публикация::disabled`. Можно передать и массив объектов с полями `label` и
`disabled`. `current` — номер текущего этапа, считая с нуля; этапы перед
ним отмечаются пройденными.

### Текущий

`current` • по умолчанию `0` • [справочник](#атрибуты)

Этап с номером `current` выделен, этапы перед ним отмечены пройденными.

### Ошибка

`error-step` • [справочник](#атрибуты)

`error-step` отмечает этап с ошибкой — номер, тоже с нуля. Такой этап

## Поведение

### Переход по этапам

Каждый доступный этап — кнопка. Нажатие делает этап текущим и отправляет
всплывающее событие `sf-steps-change` с `detail.previous`, `detail.current`
(номера с нуля), `detail.item` — данными этапа и `detail.items` — всеми
этапами.
Недоступный этап не нажимается. Если переход назад или вперёд нельзя
разрешить без проверки — например, пока форма этапа не заполнена, —
отметьте следующие этапы `disabled` и снимайте флаг по мере прохождения.

`goToStep(index)` переходит из кода и отправляет то же событие,
`onStepChange(handler)` передаёт обработчику номер нового этапа первым
аргументом. Кнопки «Назад» и «Далее» рядом с этапами задаёт страница.

```js
const steps = document.querySelector('sf-steps');
steps.onStepChange((current) => showPanel(current));

document.querySelector('#next').addEventListener('click', () => {
  if (validateCurrentPanel()) steps.goToStep(Number(steps.getAttribute('current')) + 1);
});
```

## Доступность

- Группе этапов нужно доступное имя: `aria-label` на `<sf-steps>`. По
  умолчанию на русской странице она называется «Шаги».
- Каждый этап — нативная кнопка: `Tab` останавливается на ней, `Enter` и
  `Space` нажимают её. Недоступный этап выпадает из порядка `Tab`.
- Текущий этап отмечен `aria-current="step"`. К имени пройденного этапа
  добавляется «Завершено», к имени этапа с ошибкой — «Ошибка». Слова
  берутся из языка страницы; `completed-label` и `error-label` заменяют их.
- Иконки и разделители скрыты от вспомогательных технологий: состояние
  передаёт имя кнопки, а не цвет.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `size` | строка | `1` | `1`, `1/2` | — |
| `error-step` | целое число | — | от 0 | — |
| `separator-icon` | строка | `chevron_right` | — | — |
| `completed-label` | строка | — | — | Пусто — текст на языке страницы (по-английски «Completed»). |
| `error-label` | строка | — | — | Пусто — текст на языке страницы (по-английски «Error»). |
| `skipped-label` | строка | — | — | Пусто — текст на языке страницы (по-английски «Skipped»). |
| `running-label` | строка | — | — | Пусто — текст на языке страницы (по-английски «In progress»). |
| `current` | целое число | `0` | от 0 | — |
| `aria-label` | строка | пусто | — | Пусто — текст на языке страницы (по-английски «Steps»). |
| `items` | список | `[]` | — | — |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `goToStep(args: object\|number)` | объект | Переводит current на шаг с индексом index, ограничивая его границами списка; ничего не делает для отключённого или текущего шага. Отправляет sf-steps-change. |
| `setState(nextState: object)` | объект | Записывает каждый ключ как атрибут в kebab-case; массив (items) сериализуется как записи label:disabled, соединённые через \|. false, null, undefined или пустое значение удаляет атрибут, true устанавливает его пустым. |
| `onStepChange(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик sf-steps-change; обработчик вызывается с (current, detail, event). Обработчик, не являющийся функцией, игнорируется. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-steps-change` | `{ previous: number, current: number, item: object, items: array }` | — |
