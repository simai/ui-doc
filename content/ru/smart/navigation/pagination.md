# Пагинация

:badge[sf-pagination]{variant=outline scheme=on-surface size=1/2} :badge[1.8.9]{variant=outline scheme=on-surface size=1/2}

Пагинация ведёт по страницам одного длинного списка: каталога, результатов
поиска, таблицы в админке. Она показывает, где читатель, и даёт перейти на
другую страницу. Записи загружает приложение: оно передаёт числа и по
событиям загружает нужную страницу.

Соседнюю страницу по смыслу — следующую статью или запись — открывает
[Листалка страниц](/ru/smart/navigation/pager/). То же на классах —
[Пагинация](/ru/components/navigation/pagination/).

## Разметка

Пагинации нужны числа списка, вид и имя ориентира:

```html
<sf-pagination appearance="numbers" aria-label="Страницы каталога"
  current="1" total="240" page-size="20"></sf-pagination>
```

`total` — сколько записей всего, `page-size` — сколько на странице,
`current` — номер текущей страницы, начиная с единицы. Число страниц
компонент считает сам и держит `current` в его пределах.

## Варианты

`appearance` выбирает вид. Во всех видах кнопка на краю списка не исчезает,
а становится недоступной: ряд не меняет ширину, пока человек листает.

### Поле номера

`appearance` • по умолчанию `field` • [справочник](#атрибуты)

`appearance="field"` — «|‹ ‹ [3] из 12 › ›|» для плотной таблицы в админке.
В поле можно набрать номер и нажать `Enter`; номер за пределами списка
приводится к первой или последней странице. Поле шириной в самый длинный
номер и не растёт, пока человек листает.

:::example {id="smart-components/pagination/field" label="Поле номера"}
:::

### Номера страниц

`appearance` • по умолчанию `field` • [справочник](#атрибуты)

`appearance="numbers"` — «‹ 1 … 4 [5] 6 … 12 ›» для сайта, каталога и
поиска. В ряду до семи мест, на телефоне — пять; первая и последняя
страницы видны всегда, пропуск отмечен многоточием.

:::example {id="smart-components/pagination/numbers" label="Номера страниц"}
:::

### Назад и далее

`appearance` • по умолчанию `field` • [справочник](#атрибуты)

`appearance="arrows"` — «‹ Назад · Страница 3 · Далее ›», когда число
страниц неизвестно или известно только примерно: ни последней страницы, ни
поля номера. «Далее» доступно, пока `has-next` говорит, что следующая
страница есть.

:::example {id="smart-components/pagination/arrows" label="Назад и далее"}
:::

### В начало и дальше

`appearance` • по умолчанию `field` • [справочник](#атрибуты)

`appearance="cursor"` — «В начало · Дальше ›» для списка, который отдаёт
записи порциями и знает только, есть ли следующая (`has-next`). Номера
страницы и последней страницы нет.

:::example {id="smart-components/pagination/cursor" label="В начало и дальше"}
:::

### Показать ещё

`appearance` • по умолчанию `field` • [справочник](#атрибуты)

`appearance="more"` — кнопка «Показать ещё 20», под ней «Показано 40 из 240»
и тонкая полоса. Нажатие дописывает порцию в конец списка
(`sf-pagination-load-more`), `current` — сколько порций показано. Когда
показано всё, кнопка уходит, строка остаётся. Этот вид всегда стоит
отдельно и никогда — в одном ряду со стрелками.

:::example {id="smart-components/pagination/more" label="Показать ещё" log="sf-pagination-load-more" log_open=false}
:::

`size` • по умолчанию `1` • [справочник](#атрибуты)

## Состояния

### Края списка

На первой странице «В начало» и «Назад» недоступны, на последней —
«Далее» и «Последняя». Кнопки остаются на своих местах.

:::example {id="smart-components/pagination/ends" label="Первая и последняя страница"}
:::

### Догрузка

`show-more-busy` • [справочник](#атрибуты)

`show-more-busy` делает кнопку «Показать ещё» занятой, пока приложение
догружает записи.

:::example {id="smart-components/pagination/show-more-busy" label="«Показать ещё» занята"}
:::

### Количество неизвестно

`count-known`, `has-next`, `can-count` • [справочник](#атрибуты)

Список, который не считает записи на каждом запросе, задаёт
`count-known="false"` и сообщает `has-next`, есть ли следующая страница. В
поле номера тогда не пишется «из 12». Если задан `can-count`, стрелка
«Последняя» сначала просит посчитать записи: приходит `sf-pagination-count`
с причиной в `detail.reason`. Пока приложение считает, компонент показывает
короткое ожидание; ответ приходит атрибутами `total`, `count-known` и
снятым `counting`.

:::

## Поведение

### Переход и события

Компонент сам меняет `current` и сообщает об изменении всплывающим
событием; приложение по нему загружает записи. В `event.detail` только
данные, без самого элемента.

| Событие | Когда | Поля `event.detail` |
|:---|:---|:---|
| `sf-pagination-change` | открыта другая страница | `previous`, `current`, `total`, `pageCount`, `pageSize` |
| `sf-pagination-load-more` | нажата «Показать ещё» | `direction` (всегда `after`), `current`, `total`, `pageSize`, `pageCount`, `hasNext` |
| `sf-pagination-count` | запрошено общее количество | `reason`, `current`, `pageSize` |

`goToPage(n)` и `showMore()` делают то же из кода, `onPageChange(handler)`
передаёт обработчику номер новой страницы первым аргументом.

```js
const pagination = document.querySelector('sf-pagination');

pagination.addEventListener('sf-pagination-change', async (event) => {
  const {current, pageSize} = event.detail;
  renderRows(await loadOrders({page: current, size: pageSize}));
});
```

### Ссылки и адрес страницы

`href`, `page-param`, `page-in-title` • [справочник](#атрибуты)

`href` — адрес страницы шаблоном: `{page}` — номер, `{page-size}` — размер
(`?page={page}`). Тогда номера и стрелки — ссылки с `rel="prev"` и
`rel="next"`: список, который печатает сервер, листается и без скрипта.
Обработчик, который отменяет `sf-pagination-change`, загружает страницу на
месте, и ссылка не открывается. `page-param` хранит номер в адресе: «Назад»
и «Вперёд» браузера возвращают страницу. `page-in-title` добавляет номер к
заголовку документа: «Новости — Страница 3».

```html
<sf-pagination appearance="numbers" aria-label="Страницы новостей"
  current="3" total="240" page-size="20"
  href="/news/?page={page}" page-param="page" page-in-title></sf-pagination>
```

### Подвал списка в админке

Число записей «41–60 из 240» и выбор размера страницы «По 20 ▾» —
части списка, а не пагинации: их рисует подвал
[Представления данных](/ru/pro/admin/table/) рядом с пагинацией вида
`field`. Там же — действия с отмеченными строками.

### Подписи

Подписи и доступные имена — «Назад», «Далее», «В начало», «Дальше»,
«Показать ещё», «Страница:» — берутся из языка страницы: на русской
странице они русские. Атрибуты `previous-label`, `next-label`,
`first-label`, `last-label`, `page-field-label` и другие из справочника
заменяют отдельные слова.

## Доступность

- Корень — ориентир `nav`. Имя по умолчанию — «Страницы результатов»; если на
  странице несколько списков, задайте каждому своё в `aria-label`.
- Стрелки — кнопки-иконки или ссылки с доступными именами и подсказками.
  Текущая страница в виде `numbers` отмечена `aria-current="page"`.
- Поле номера подписано «Страница:» и переходит по `Enter`; стрелки и поле —
  обычные остановки `Tab`.
- Недоступная кнопка на краю списка остаётся на месте и сообщает, что она
  недоступна; ссылка теряет адрес и получает `aria-disabled`.
- Строка места в виде `arrows` — живая область: экранный диктор произносит
  новую страницу. О загрузке новых записей сообщите в области с
  `role="status"`, если они появляются не рядом с пагинацией.

Если задан, стрелки становятся ссылками с rel prev/next, а страница, набранная в поле, открывается по адресу; обработчик, который отменяет sf-pagination-change, переходит на месте, и ссылка не открывается. Пусто — стрелки кнопки. |
| `page-param` | строка | пусто | — | Имя параметра адреса, в котором хранится страница («page»). Если задано, страница читается из адреса при вставке элемента и при «Назад» и «Вперёд» (сообщается как sf-pagination-change), а переход пишется новой записью истории; страница 1 — адрес без параметра. Пусто — адрес не трогается. |
| `page-in-title` | да/нет | нет | — | Добавлять страницу к заголовку документа («Новости — Страница 3»); страница 1 и удалённый элемент оставляют заголовок как был. Пишет это одна пагинация документа. |
| `current` | целое число | `1` | от 1 | Читаемая страница, с 1. |
| `aria-label` | строка | пусто | — | Доступное имя области навигации. Пусто — текст на языке страницы (по-английски «Result pages»). |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `goToPage(args: object\|number)` | объект | Переходит на страницу: номер разбирается как целое число и ограничивается диапазоном 1..pageCount, если количество известно (иначе только снизу значением 1). Отправляет sf-pagination-change, когда страница действительно меняется; ничего не делает, если известно, что всего страниц ноль. |
| `showMore()` | объект | Отправляет sf-pagination-load-more с текущими параметрами пагинации и переданным пунктом; не выполняет запрос и не меняет состояние. |
| `getTopSection()` | объект или пусто | Возвращает элемент верхней секции (.sf-pagination-top) или null, если она не отрисована. |
| `getMainSection()` | объект или пусто | Возвращает элемент основной секции (.sf-pagination-main) или null, если она не отрисована. |
| `getBottomSection()` | объект или пусто | Возвращает элемент нижней секции (.sf-pagination-bottom) или null, если она не отрисована. |
| `setPageSize(size: number\|string)` | объект | Устанавливает положительный размер страницы, удерживает текущую страницу в пределах нового числа страниц и отправляет sf-pagination-size-change. Неположительный, нечисловой или неизменный размер игнорируется. |
| `setAction(action: string)` | объект | Выбирает групповое действие по значению (пустое значение сбрасывает выбор) и отправляет sf-pagination-action-change, если оно отличается от текущего. |
| `setActionForAll(value: boolean)` | объект | Задаёт, применяется ли групповое действие ко всем записям под фильтром, и отправляет sf-pagination-action-for-all-change. При включении также запрашивает количество (sf-pagination-count с reason action-for-all), если оно ещё неизвестно. |
| `setState(nextState: object)` | объект | Записывает каждый ключ как атрибут в kebab-case: false, null, undefined или пустая строка удаляет атрибут, true устанавливает его пустым, всё остальное приводится к строке. |
| `onPageChange(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик sf-pagination-change; обработчик вызывается с (current, detail, event). Обработчик, не являющийся функцией, игнорируется. |
| `onShowMore(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик sf-pagination-load-more; обработчик вызывается с (detail, event). Обработчик, не являющийся функцией, игнорируется. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-pagination-change` | `{ previous: number, current: number, total: number, pageCount: number\|null, pageSize: number }` | — |
| `sf-pagination-size-change` | `{ previous: number, pageSize: number, current: number, total: number, pageCount: number\|null }` | Прежнее до 2027-01-01: присылается меню размера страницы совместимого подвала; список, который сам собирает «По 20 ▾», присылает своё. |
| `sf-pagination-count` | `{ reason: "total" \| "last-page" \| "action-for-all", current: number, pageSize: number }` | — |
| `sf-pagination-load-more` | `{ direction: any, current: number, total: number, pageSize: number, pageCount: number\|null, hasNext: boolean }` | — |
| `sf-pagination-selection-clear` | `{ selectedCount: number, total: number }` | Прежнее до 2027-01-01: присылается полосой массовых действий, которая теперь принадлежит sf-view. |
| `sf-pagination-action-change` | `{ previous: string, action: string }` | Прежнее до 2027-01-01: присылается полосой массовых действий, которая теперь принадлежит sf-view. |
| `sf-pagination-action-for-all-change` | `{ previous: boolean, actionForAll: boolean }` | Прежнее до 2027-01-01: присылается полосой массовых действий, которая теперь принадлежит sf-view. |
| `sf-pagination-apply` | `{ action: string, scope: "selection" \| "filter", current: number, total: number, pageSize: number, pageCount: number\|null }` | Прежнее до 2027-01-01: присылается полосой массовых действий, которая теперь принадлежит sf-view. |
