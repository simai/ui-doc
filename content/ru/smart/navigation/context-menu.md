# Контекстное меню

:badge[sf-menu-context]{variant=tonal scheme=primary size=1/2} :badge[1.8.0]{variant=outline scheme=on-surface size=1/2}

Контекстное меню — панель с коротким списком действий над объектом: страницей,
строкой таблицы, файлом, профилем; пунктами можно управлять с клавиатуры.
Пункты задаются данными, а метод `openFor` открывает меню у кнопки и дальше
управляет им сам. Для выбора значения в форме берите [Выпадающий
список](/ru/smart/navigation/dropdown/), для панели настроек —
[Настройки](/ru/smart/navigation/settings/).

То же на классах — [Контекстное меню](/ru/components/navigation/context-menu/):
меню оформлено как этот компонент; для статической разметки без JavaScript.

## Разметка

Меню нужны доступное имя и пункты. Всплывающее меню прячет до открытия
атрибут `popup`:

```html
<sf-menu-context popup aria-label="Действия со страницей"></sf-menu-context>
```

Любое меню действий строится одинаково: пункты передаются данными в
свойстве `entries`, атрибут `popup` прячет меню до открытия, а
`toggleFor(кнопка)` открывает его у кнопки или закрывает, если оно уже
открыто у неё. Выбор пункта приходит событием `sf-menu-context-select`.

:::example {id="smart-components/context-menu/standard" label="Меню действий у кнопки"}
:::

### Пункты данными

`entries` — массив записей; его задают свойством или JSON в атрибуте. Если
`entries` задан, он заменяет `items` и пункты из разметки. Запись без `type`
— пункт меню:

- `id` возвращается в событии выбора, `text` — подпись;
- `icon` — имя иконки Material Symbols перед подписью, `caption` — вторая
  строка под подписью;
- в конце строки стоят `value` — текущее значение, например выбранный язык,
  и `shortcut` — сочетание клавиш; оба только показываются;
- `kind: 'check'` или `kind: 'radio'` делает пункт отмечаемым, `checked` —
  его отметка: галочка `check` стоит слева, в колонке иконок, выбранный
  `radio` отмечен заливкой строки;
- `submenu` — массив записей, который открывается сбоку от пункта;
- `danger` отмечает опасное действие, `disabled` — недоступное, `current`
  — место, где человек находится;
- `href` делает пункт ссылкой, `lang` — язык, на котором написана подпись;
- `avatar` — адрес картинки в начале строки вместо иконки, например логотип
  сайта или фото человека; без картинки там рисуются инициалы `initials`.

Другие записи задаются полем `type`: `{type: 'separator'}` — разделитель,
`{type: 'heading', text}` — заголовок группы пунктов. Если иконка есть хотя
бы у одного пункта, место под иконку остаётся у всех, и подписи начинаются
на одной линии.

### Пункты в разметке

Меню без `entries` показывает пункты, переданные со `slot="content"`:
`<sf-button>`, нативные `<button>` и `<a href>`. Обычно берут `<sf-button>`
вида `link` со схемой `on-surface` и размером `1/2`; держите в одном меню
пункты одного размера. Меню выравнивает подписи по началу строки.

Пункты можно передать и данными в свойстве `items`: каждый элемент массива —
`{component, props}`. Для `component: 'sf-button'` в `props` читаются
`text`, `type` (вид кнопки), `scheme`, `size`, `iconLeft`, `iconRight`,
`ariaLabel`, `disabled` и обработчик `'@click'`. `text` без пунктов
показывает в меню простой текст.

## Варианты

### Размер пунктов

Меню бывает двух размеров: `size="1/2"` (по умолчанию) и `size="1"`. Строки
меню высотой с поле того же размера; от размера зависят текст, иконки,
отступы, поиск и подвал. Подменю берёт размер родительского меню.

## Состояния

### Недоступен

`disabled` в записи делает пункт недоступным: стрелки его пропускают, и
выбрать его нельзя. `danger` отмечает опасное действие, `current` — место,
где человек находится.

:::example {id="smart-components/context-menu/state-disabled" label="Недоступный пункт и опасное действие"}
:::

### Отмечен

`kind: 'check'` делает пункт флажком: отметить можно несколько, `checked` —
отметка. Галочка стоит слева, в колонке иконок и той же ширины; колонка
остаётся у всех строк уровня, если хоть одну можно отметить, поэтому подписи
начинаются на одной линии. Неотмеченная строка показывает на этом месте свою
иконку, если она есть. Отметки хранит приложение — см.
[Выбор пункта](#выбор-пункта).

:::example {id="smart-components/context-menu/state-checked" label="Флажки с галочкой слева и выбранный вариант"}
:::

### Выбранная строка

В списке, где выбирают одно, — `kind: 'radio'` или варианты на уровне панели
с заходом, — выбранная строка отмечена мягкой заливкой, без галочки. Места
под галочку в конце строки нет: строки занимают всю ширину, и значение
`value` кончается у правого отступа панели. Наведение на другие строки —
нейтральная подложка, фокус с клавиатуры — рамка, поэтому их не спутать с
выбранной строкой. Заливку даёт класс `.sf-context-menu-item--chosen`.

:::example {id="smart-components/context-menu/state-chosen" label="Выбранная строка в списке сортировки"}
:::

## Поведение

### Открытие у кнопки

`openFor(кнопка, options)` открывает меню в верхнем слое страницы: его не
обрезает прокручиваемый блок и не перекрывает таблица. Меню встаёт под
кнопкой по её началу, а у края окна переворачивается вверх или
сдвигается; если окно ниже меню, его строки прокручиваются. Подменю
открывается сбоку, и его первый пункт стоит на одной линии с пунктом,
который его открыл. Ширина меню подстраивается под самый длинный пункт, от
нижней границы `--sf-e8` до верхней `--sf-g2`; меню, которому нужно шире,
задаёт переменную `--sf-context-menu--min-inline-size`.

`options` уточняет открытие: `side` — сторона кнопки (`block-end` по
умолчанию, `block-start`, `inline-start`, `inline-end`), `align` —
выравнивание по ней (`start` по умолчанию, `center`, `end`), `focus` — куда
встаёт фокус: на первый пункт (`first`, по умолчанию), на последний
(`last`) или никуда (`none`). `toggleFor(кнопка, options)` закрывает меню,
открытое у этой кнопки, а иначе открывает его; `close()` закрывает меню
вместе с подменю.

Меню, открытое через `openFor`, управляет собой само: `Escape` закрывает
текущий уровень, а `Tab`, нажатие вне меню и выбор пункта закрывают всё
меню и возвращают фокус туда, где он был до открытия, а если фокус нигде
не стоял — на кнопку, у которой меню открывалось. Открытие и закрытие
сообщают события `sf-menu-context-open` и `sf-menu-context-close`.
`openFor` и `toggleFor` возвращают `Promise<boolean>`: дождитесь его, если
следующий шаг зависит от того, открылось ли меню.

### Выбор пункта

Выбор на любом уровне, в том числе в подменю, приходит одним событием
`sf-menu-context-select` на самом меню. В `event.detail` — `id` и запись
`entry`; для отмечаемого пункта `checked` — отметка, которую пункт просит
поставить, для обычного — `null`. После выбора меню закрывается. Чтобы оно
осталось открытым, например в списке с несколькими отметками, отмените
событие через `preventDefault()` или задайте пункту `keepOpen: true`.

Отметки `check` и `radio` хранит приложение: получив событие, оно
записывает новое `checked` и значение `value` в `entries`, как в примере
выше.

### Ширина и подвал

Ширину задаёт атрибут `width` или параметр `openFor(кнопка, {width})`:

- `content` (по умолчанию) — по самой длинной строке, в пределах
  `--sf-context-menu--min-inline-size` и `--sf-context-menu--max-inline-size`;
- `trigger` — точно по кнопке, которая открыла меню, как у выбора сайта или
  меню профиля; длинная строка обрезается многоточием;
- длина CSS, например `16rem`.

Окно с собственным содержимым (`slot="content"`) собирается из тех же частей:
`.sf-context-menu-top` для поиска или заголовка, `.sf-context-menu-body` для
прокручиваемого списка и подвал в `slot="footer"` с кнопками вроде
«Сбросить» и «Применить». Подвал стоит под строками и остаётся на месте, пока
список прокручивается; его кнопки делят ширину поровну.

```html
<sf-menu-context popup size="1/2" aria-label="Настройки">
  <div slot="content" class="sf-context-menu-body">…</div>
  <sf-button slot="footer" size="1/2" appearance="outline" scheme="on-surface" text="Сбросить"></sf-button>
  <sf-button slot="footer" size="1/2" text="Применить"></sf-button>
</sf-menu-context>
```

### Меню, которым управляет страница

Меню без `popup` рисуется там, где стоит в разметке, и не открывается и не
закрывается само. Показывает его страница — по нажатию кнопки или правой
кнопке мыши — и после показа переводит в него фокус методом `focus()`,
дождавшись отрисовки. По `Escape` и после выбора пункта страница скрывает
меню и возвращает фокус на кнопку, которая его открыла. Действие пункта —
обычный `click` на кнопке. Скрывайте обёртку меню: сам `<sf-menu-context>`
не занимает места в раскладке, и атрибут `hidden` на нём не действует.

```js
const layer = document.querySelector('#file-menu-layer');
const menu = layer.querySelector('sf-menu-context');
const opener = document.querySelector('#file-menu-button');

opener.addEventListener('click', async () => {
  layer.hidden = false;
  opener.setAttribute('aria-expanded', 'true');
  await menu.whenRendered();
  menu.focus();
});

layer.addEventListener('keydown', (event) => {
  if (event.key !== 'Escape') return;
  layer.hidden = true;
  opener.setAttribute('aria-expanded', 'false');
  opener.focus();
});
```

### Подменю в той же панели

Подменю по умолчанию открывается сбоку — `submenu="flyout"`. Атрибут
`submenu="drill"` оставляет одну панель: вместо своих строк она показывает
подменю, а в шапке появляются стрелка «назад» и название пункта, через который
вошли. Ширина панели от глубины не растёт — это и есть ответ на панель, которая
раздувалась на каждом уровне.

```html
<sf-menu-context id="menu" popup submenu="drill" width="280px" aria-label="Вид"></sf-menu-context>
```

У пункта с подменю значение `value` в этом случае стоит под названием: длинное
значение обрезается многоточием (полностью оно в подсказке) и не двигает
стрелку. Длинное название переносится на вторую строку, потому что ширина панели
задана.

`Escape` и `←` сначала возвращают на уровень выше — фокус встаёт на ту строку,
через которую вошли, — и закрывают меню только на верхнем уровне. `→` и `Enter`
уходят на уровень вниз. Фокус переходит на новый уровень и после щелчка мышью,
только без рамки, поэтому клавиши продолжают работать. Закрытое меню в
следующий раз открывается с верхнего уровня. Методы те же:
`drillInto(путь)`, `drillBack()`.

Панель, которую показывает страница (без `popup`), тоже возвращается на
уровень выше по `Escape` и `←`. На вложенном уровне `Escape` до страницы не
доходит: страница скрывает меню только с верхнего уровня.

### Меню профиля

Меню профиля собирается из тех же записей и ещё трёх типов строк.
`{type: 'header'}` показывает, о ком меню: имя в `text`, строки под ним в
`caption` (строка или массив строк) и фото `avatar`; без фото рисуются
инициалы из имени или из `initials`. `{type: 'choice'}` ставит несколько
вариантов `options` рядом, например тему: выбранный вариант отмечается
сразу, меню остаётся открытым, а событие несёт `id` варианта и `group` —
`id` строки. `keepOpen: false` на строке выбора закрывает меню после
выбора. `{type: 'note'}` — пояснение мелким текстом.

Пункт с `search: {placeholder, empty}` открывает подменю с полем поиска: оно
сужает пункты по подписи, второй строке и словам `keywords`, а `empty` —
текст, когда ничего не найдено. Такое подменю открывается сразу на поле, и
мышью, и с клавиатуры.

### Строки со значением

Запись с полем `type` — `switch`, `choice`, `range` — рисуется не командой, а
строкой, которая показывает и меняет значение, как выбор темы в меню профиля
выше. Такие строки нужны смешанному меню, где рядом с действиями стоят одна-две
настройки. Значение меняют события `sf-menu-context-change` (отменяемое, до
записи) и `sf-menu-context-changed` (после записи) и методы `setValue`,
`setAll`, `show` и `reset` — они в справочнике ниже. Панель, в которой одни
настройки, — это отдельный компонент [Настройки](/ru/smart/navigation/settings/)
(`<sf-settings>`): три вида раскладки, кнопка или место в потоке страницы,
запоминание выбора.

### Поиск

Свойство `search: {placeholder, empty}` ставит над строками поле поиска; в
записи пункта оно же открывает подменю с поиском. Поле сужает строки по
подписи, второй строке и словам `keywords`, а `empty` — текст, когда ничего
не найдено. Меню с поиском открывается сразу на поле, `↓` переводит к
строкам.

Поле стоит на месте: прокручиваются только строки, в своей области под
полем, и полоса прокрутки начинается под ним. Вокруг поля — 8 px, как и
отступ панели, у обоих размеров меню; строки стоят там же, где без
поиска. Так устроено любое меню с поиском: верхний уровень, подменю и уровень
панели с заходом. Панель с вкладками прокручивает своё тело под шапкой, как и
раньше.

### Поиск на стороне хоста

Если пунктов слишком много, чтобы передать их все, на поиск отвечает хост.
Свойство `search` самого меню ставит поле над строками, а
`search: {remote: true}` отключает поиск по пунктам: на каждый запрос меню
поднимает событие `sf-menu-context-search` с `detail.query`, а хост
записывает найденные пункты в `entries`. Для подменю то же задаёт
`search: {remote: true}` в записи пункта. Закрытие меню запроса не
поднимает.

```js
menu.search = {placeholder: 'Найти сайт', empty: 'Ничего не найдено', remote: true};
menu.addEventListener('sf-menu-context-search', async (event) => {
  menu.entries = await findSites(event.detail.query);
});
```

Хост сам решает, сколько строк вернуть и что делать с запросом, который
устарел, пока сервер отвечал. В примере сервер отвечает с задержкой и отдаёт
шесть первых сайтов, а ответ на прежний запрос, пришедший позже нового,
отбрасывается.

### Панель с вкладками

Окно с вкладками — настройки списка, фильтр — собирается тем же меню.
`tabs` задаёт вкладки: подписи через `|`, например `"Поля|Вид"`, или свойство
`[{id, label}]`. `active-tab` — id или номер выбранной вкладки, `closable`
добавляет в шапку кнопку закрытия.

Шапка — отдельная строка высотой с контрол и шагом отступа над ним: вкладки
стоят по её нижнему краю, кнопка закрытия — по центру. Под шапкой одна линия
через всю панель, в том числе под кнопкой закрытия; своей линии у вкладок нет.
Шапка не прокручивается: прокручивается только
содержимое слота `content`, а подвал в слоте `footer` остаётся внизу. Ширина у
панели своя — восемь контролов или значение `width`, — поэтому панель не
меняет размер при смене вкладки или подписи кнопки в подвале.

Выбор вкладки отправляет событие `sf-menu-context-tab` с `{id, index}`, и
страница кладёт в `content` строки этой вкладки. Кнопка закрытия закрывает
меню, открытое через `openFor`; если меню поставила страница, оно отправляет
`sf-menu-context-close`, и закрывает его страница. Строка панели —
`.sf-context-menu-row`: в ней может быть ручка, флажок или кнопка, а подпись
`.sf-context-menu-row-text` занимает остаток и обрезается многоточием.

## Применение

### Выбор языка в шапке

Кнопка с иконкой `translate` открывает меню языков. Каждый пункт написан
на своём языке и несёт `lang`, выбранный отмечен как `radio` и выделен
заливкой. Страница
вызывает `SF.language.use(code)` и ставит документу `lang` и `dir`:
арабский в примере пишется справа налево. Доступное имя кнопки называет
текущий язык («Язык: Русский») — иконка одна при любом выборе. Подробно о
словах компонентов — в руководстве
[Язык интерфейса](/ru/guide/size-and-type/language/).

## Доступность

- На сенсорном экране каждая строка меню — действие, флажок, вариант выбора —
  не ниже 44 px, чтобы в неё попадал палец; с мышью строки остаются на
  лестнице размеров.
- Меню нужно доступное имя: `aria-label` на `<sf-menu-context>`. Подменю
  получает имя по подписи пункта, который его открыл.
- Пункты из `entries` получают роли `menuitem`, `menuitemcheckbox` или
  `menuitemradio` с `aria-checked`; пункт с подменю — `aria-haspopup` и
  `aria-expanded`. Заголовок профиля и пояснение — обычный текст, варианты
  строки выбора — `menuitemradio` в группе.
- В порядке `Tab` остаётся один пункт. Стрелки вверх и вниз переходят по
  пунктам по кругу, `Home` и `End` — к первому и последнему, `Enter` и
  `Space` выбирают пункт. Недоступные и скрытые пункты пропускаются.
- В меню, открытом через `openFor`, `→` открывает подменю, `←` и `Escape`
  закрывают текущий уровень, `Tab` закрывает всё меню. Буквы переводят фокус
  к следующему пункту, подпись которого с них начинается. Варианты строки
  выбора перебирают стрелки влево и вправо.
- В меню и подменю с поиском фокус стоит в поле: буквы и боковые стрелки
  остаются полю, `↓` переходит к пунктам.
- Выбранная строка `radio` сообщает выбор через `aria-checked="true"`, а не
  только заливкой.
- Кнопка, у которой открыто меню, получает `aria-haspopup="menu"` и
  `aria-expanded`. Меню, которым управляет страница, сообщает состояние
  через `aria-expanded` на кнопке силами страницы.
- Атрибут `role` со значением, отличным от `menu`, отключает клавиатурную
  модель меню: задавайте его, только если пункты — не команды.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `openFor(anchor: object, options: object)` | `Promise<boolean>` | Открыть рядом с элементом: в верхнем слое, с привязкой через SF.Position с переворотом и сдвигом, фокус на первом пункте (или 'last', или 'none'). Дальше меню управляет собой само: Escape, Tab, нажатие снаружи и выбор пункта закрывают его и возвращают фокус — туда, где он был, или на элемент управления якоря, если фокуса нигде не было. |
| `toggleFor(anchor: object, options: object)` | `Promise<boolean>` | Закрывает меню, если оно уже открыто у этого элемента, иначе вызывает openFor(). |
| `close(reason: any)` | да/нет | Закрывает это меню и все подменю. |
| `chooseTab(index: number)` | объект | Выбирает вкладку по номеру и отправляет sf-context-menu-tab. |
| `requestClose()` | да/нет | Закрывает меню, открытое самим компонентом; для меню, которое поставило приложение, отправляет `sf-context-menu-close`, чтобы его закрыло приложение. |
| `setValue(id: string, value: any)` | объект | Записывает значение настройки в её пункт: ответ приложения на `change` или значение, восстановленное при загрузке. Значение живёт в пункте и больше нигде, поэтому второй карты, которая могла бы с ним разойтись, нет; меню ничего не вызывает. Отказ, если такого `id` нет ни у одного пункта. |
| `setAll(values: object)` | объект | Записывает сразу целую карту настроек — `{id: value}` — в пункты с этими `id`: панель, восстановленная из хранилища, одним вызовом вместо `set-value` на каждую строку. Меню ничего не вызывает. Отказ, если ни одного `id` из карты нет ни у одного пункта. |
| `show(id: string)` | объект | Сразу переходит к одной настройке: в меню с переходами панель открывает уровни до неё (её собственное подменю, если оно есть, иначе уровень, на котором стоит её строка), и фокус переходит на строку. Отказ, если такого `id` нет ни у одного пункта; недоступно во всплывающем меню: там нет уровней, куда переходить. |
| `reset()` | объект | Возвращает объявленные значения — те, что были в пунктах, когда их задало приложение, — и вызывает `reset`. Слушатель, отменивший `reset`, сохраняет текущие значения. |
| `focus(options?: object)` | пусто | Переводит фокус на текущий доступный пункт. Приложение, которое рисует меню само, ждёт отрисовки и само отвечает за открытие и закрытие. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-menu-context-select` | `{ id: string\\|null, entry: object, checked: boolean\\|null, group: string\\|null }` | Выбран пункт на любом уровне. Отмените событие, чтобы меню осталось открытым. |
| `sf-menu-context-change` | `{ id: string\\|null, value: any, previous: any, entry: object }` | Человек просит изменить настройку в строке значения: это запрос, он приходит до записи значения. Возникает после `select` и только если `select` не отменён; командная строка вызывает только `select`. Если отменить, ничего не меняется и строка сохраняет прежнее значение — вид никогда не показывает значение, которое приложение не приняло. |
| `sf-menu-context-changed` | `{ id: string\\|null, value: any, previous: any, entry: object }` | Факт изменения: значение записано в пункт, и строка его показывает. Приложение, которое только сохраняет сделанное человеком, слушает это событие и больше ничего. `reset` вызывает его по разу на каждую сдвинувшуюся строку; `set-value` и `set-all` его не вызывают: значение, заданное извне, обратно не сообщается (стандарт, §8). |
| `sf-menu-context-reset` | пустой объект | Человек попросил вернуть объявленные значения: это запрос. Если отменить, текущие значения остаются; иначе меню показывает объявленные, по разу на каждую сдвинувшуюся строку сообщает `changed` и ждёт, пока приложение их сохранит, как при `sf-tabs-settings-reset`. |
| `sf-menu-context-open` | пустой объект | Открыто через openFor(). Всплывает и с composed: true; detail не передаётся. |
| `sf-menu-context-opened` | пустой объект | — |
| `sf-menu-context-close` | `{ reason: any, unsaved: boolean }` | Меню, открытое через openFor(), закрыто. Всплывает и с composed: true; detail не передаётся. |
| `sf-menu-context-closed` | `{ reason: any }` | — |
| `sf-menu-context-search` | `{ query: string }` | Запрос поиска, на который отвечает приложение (search.remote). |
| `sf-menu-context-tab` | `{ id: string, index: number }` | Выбрана вкладка панели; приложение показывает её строки. |
