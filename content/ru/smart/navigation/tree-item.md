# Элемент дерева

:badge[sf-tree-item]{type=tonal scheme=primary size=1/2} :badge[1.1.5]{type=outline scheme=on-surface size=1/2}

Элемент дерева — один пункт [дерева](/ru/smart/navigation/tree/): папка с
вложенными пунктами, файл или ссылка на раздел. Пункты ставят внутрь дерева:
оно даёт им общий порядок фокуса, клавиатуру и выбор.

То же на классах — [Элемент дерева](/ru/components/navigation/tree-item/):
оформление совпадает с обычным пунктом дерева.

## Разметка

Пункту нужна подпись; вложенные пункты ставят внутрь:

```html
<sf-tree aria-label="Папки проекта">
  <sf-tree-item label="Документы" value="docs">
    <sf-tree-item label="Договоры" value="contracts"></sf-tree-item>
  </sf-tree-item>
</sf-tree>
```

`label` — подпись пункта; без неё подписью служит текст внутри
`<sf-tree-item>`. `text` — другое имя `label`, работает до 2026-12-01.
`value` — код пункта: его получает строка как `data-value`, и его несут
события.

Внутри `<sf-tree>` пункт читается один раз как данные и убирается: строки
рисует само дерево той же классовой разметкой. Отдельно от дерева пункт
рисует свою строку и, раскрытый, — вложенные пункты. Значки строки — символы
шрифта значков (`<i class="sf-icon">`), а не элементы `<sf-icon>`.

## Варианты

### Папка или файл

`kind` — `folder` (по умолчанию) или `file`; `type` — другое имя `kind`,
работает до 2026-12-01. Папка с вложенными `<sf-tree-item>` получает кнопку
раскрытия и иконку открытой или закрытой папки, файл — иконку документа и
никогда не раскрывается. Дерево с файлами удобнее передавать данными, как в
[примере Дерево](/ru/smart/navigation/tree/#пункты-данными).

:::example {id="smart-components/tree-item/kind" label="Папка и файлы"}
:::

### Иконка

`icon="false"` убирает иконку пункта: так выглядит дерево разделов, а не
файлов, как в разделе «Пример». `open-icon` и `closed-icon` заменяют иконки
папки, `chevron-open-icon` и `chevron-closed-icon` — стрелку раскрытия.

:::example {id="smart-components/tree-item/icons" label="Без иконки и со своими иконками"}

## Поведение

### Действия

Действия отвечают исходом: `{outcome: "applied"}` или `{outcome: "refused"}`
с причиной `leaf` у файла или пункта без вложенных и `disabled` у
выключенного.

| Действие | Что делает |
|:---|:---|
| `expand()` | раскрывает ветвь |
| `collapse()` | сворачивает ветвь |
| `toggleOpen()` | раскрывает свёрнутую ветвь и сворачивает раскрытую |
| `activate()` | то же, что `Enter` на листе: открывает ссылку или отправляет `sf-tree-item-open` |
| `focusItem()` | переводит фокус на строку пункта |

`open` — значение ветви, свойство, поэтому вместо `item.open()` пишите
`item.expand()` или `item.open = true`; методы `open()`, `close()` и
`toggle()` не используйте.

### События

| Событие | Когда | `event.detail` | Прежнее имя (до 2026-12-01) |
|:---|:---|:---|:---|
| `sf-tree-item-open` | нажата подпись или `Enter` на листе без ссылки | `id`, `value` | `sf-tree-item-click` с `{item, value, originalEvent}` |
| `sf-tree-item-toggle` | ветвь раскрыта или свёрнута | `id`, `open`, `value` | имя то же; элемента в `detail` нет — это `event.target` |

`onToggle(handler)` передаёт обработчику новое состояние первым аргументом.
Внутри `<sf-tree>` слушайте события дерева — `sf-tree-open` и
`sf-tree-toggle`, см. [Дерево](/ru/smart/navigation/tree/#события).

```js
const section = document.querySelector('sf-tree-item[value="reports"]');
section.onToggle((open) => {
  if (open) loadReports();
});
section.expand();
```

## Доступность

- Пункт — элемент дерева (`treeitem`), его доступное имя — подпись.
- Фокус между пунктами переводит дерево стрелками; на странице `Tab`
  останавливается на одном пункте дерева. Кнопка раскрытия и ссылка внутри
  пункта не получают отдельной остановки `Tab`.
- Кнопка раскрытия сообщает `aria-expanded`. Её подписи по умолчанию — из
  файлов слов на языке страницы («Развернуть» и «Свернуть»); другие задают
  `open-label` и `close-label`.
- Недоступный пункт сообщает `aria-disabled="true"`, пункт текущей страницы —
  `aria-current="page"`.

| `href` | строка | пусто | — | — |
| `target` | строка | пусто | — | — |
| `rel` | строка | пусто | — | — |
| `kind` | строка | `folder` | `folder`, `file` | Тип элемента дерева: папка или файл. |
| `value` | строка | пусто | — | id узла: `data-value` его строки, id, который несут его события |

| `open-icon` | строка | `folder_open` | — | — |

| `chevron-open-icon` | строка | `keyboard_arrow_down` | — | — |
| `chevron-closed-icon` | строка | `chevron_right` | — | — |
| `open-label` | строка | — | — | Имя шеврона, пока ветка закрыта |
| `close-label` | строка | — | — | Имя шеврона, пока ветка открыта |
| `item-class` | строка | пусто | — | Классы рамки строки |

| `name-class` | строка | пусто | — | Классы имени строки |
| `open` | да/нет | нет | — | Ветка открыта |
| `selected` | да/нет | нет | — | — |
| `active` | да/нет | нет | — | Узел — текущая страница: `aria-current` |
| `text` | строка | пусто | — | Псевдоним с датой для `label` до 2026-12-01. |
| `items-data` | список: объект | `[]` | — | Дети узла как данные (форма записи `sf-tree`); иначе один раз читаются дети, написанные внутри |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя варианта шаблона для внешних шаблонов SfBaseElement. |
| `root-class` | строка | пусто | — | Классы, которые добавляются корневому элементу, нарисованному компонентом. |
| `root-style` | строка | пусто | — | Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `expand()` | объект | Открывает ветку; отказ для файла, листа или выключенного узла |
| `collapse()` | объект | Закрывает ветку |
| `toggleOpen()` | объект | Открывает закрытую ветку, закрывает открытую |
| `activate()` | объект | Что делает Enter на листе: переходит по его ссылке или отправляет open |
| `focusItem()` | объект | Переводит фокус на строку узла |
| `setOpen(open?: boolean)` | объект | Открывает или закрывает ветку и отправляет `sf-tree-item-toggle` — код под действиями `expand`, `collapse` и `toggle-open`; для файла, листа или недоступного пункта отклоняется, при неизменном состоянии выполняется без события. |
| `onToggle(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик sf-tree-item-toggle; обработчик вызывается с (open, detail, event). Обработчик, не являющийся функцией, игнорируется. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-tree-item-open` | `{ id: string, value: string }` | Нажатие на имя или Enter на листе без ссылки: open `{id}` словаря 1.1.5 §5 |
| `sf-tree-item-toggle` | `{ id: string, open: boolean, value: string }` | Ветка открылась или закрылась (словарь §5 toggle); DOM-имя `sf-tree-item-toggle` не изменилось |
