# Настройки отображения

:badge[sf-display-settings]{variant=outline scheme=on-surface size=1/2} :badge[1.1.5]{variant=outline scheme=on-surface size=1/2}

Настройки отображения дают посетителю сайта крупнее текст, другую цветовую
схему, шире интервалы, картинки серыми или скрытыми и остановку движения —
то, чего он не нашёл в настройках своего устройства. Панель только
записывает выбор; показывает его ядро SIMAI Framework на каждой странице
сайта, в том числе там, где панели нет. Берите её для сайта школы,
библиотеки, ведомства, где просят «версию для слабовидящих», и для любого
сайта, который хочет дать людям размер текста и контраст. Зачем это и где
граница с настоящей доступностью — в главе
[Настройки отображения](/ru/guide/accessibility/display-settings/).

## Пример

Страница библиотеки: шапка, новости, сообщения, карточки, таблица, форма
и код. Откройте «Версию для слабовидящих» над шапкой и нажмите «А+»,
«Шире» или «Скрыть» картинки — меняется вся страница. `Escape` закрывает
панель. Код — на вкладке JavaScript.

:::example {id="smart-components/display-settings/overview" label="Страница сайта с панелью над шапкой" preview=sandbox log="sf-display-settings-change" log_console=true log_open=false}
:::

Цветовые схемы в рамке этого примера показываются неверно: рамка
документации переносит в пример цвета самой документации, и они
перекрывают схему. На странице сайта схема перекрашивает всё: текст, края,
кнопки, отметки и ссылки.

## Разметка

```html
<sf-display-settings label="Версия для слабовидящих"></sf-display-settings>
```

- `label` — подпись кнопки и имя панели. Без него — «Настройки
  отображения». На российских сайтах, где кнопку ищут по старому имени,
  пишут «Версия для слабовидящих».
- Больше ничего не нужно: панель сама хранит выбор в браузере человека, а
  ядро применяет его на каждой странице.

## Варианты

### Кнопка или панель

`layout` • по умолчанию `disclosure` • [справочник](#атрибуты)

| Значение | Когда брать |
|:---|:---|
| `disclosure` | Кнопка в шапке или подвале; панель раскрывается под ней. |
| `panel` | Панель стоит открытой, без кнопки: своя страница настроек, подвал. |

:::example {id="smart-components/display-settings/panel" label="Панель на странице" preview=sandbox}
:::

### Шрифт и ссылки

`show-font`, `show-links` • по умолчанию выключены • [справочник](#атрибуты)

Две группы включает автор сайта: «Шрифт» — шрифт сайта, без засечек или с
засечками; «Ссылки» — подчёркивать ссылки. В цветовой схеме ссылки
подчёркнуты всегда.

## Поведение

### Что в панели

| Группа | Варианты |
|:---|:---|
| Текст | 100, 125, 150, 175 и 200 %: доля размера текста браузера, а не замена его |
| Цвет | Как на сайте; чёрный на белом, белый на чёрном, жёлтый на чёрном, синий на голубом, коричневый на кремовом |
| Интервалы | Обычные или шире: строка, абзацы, буквы и слова по WCAG 1.4.12 |
| Картинки | Цветные, чёрно-белые или скрытые; на месте скрытой картинки — её описание `alt` |
| Движение | Как в системе или остановить: анимации и переходы стоят |
| Обычная версия | Всё как на сайте, выбор забыт |

Если в системе включены контрастные цвета (`forced-colors`), группа «Цвет»
выключена и говорит «Цвета задаёт система». Если устройство уже уменьшает
движение, группа «Движение» говорит об этом.

### Где хранится выбор

Только в браузере человека: в `localStorage`, без cookie, ничего не уходит
на сервер. Ядро пишет выбор на `<html>` атрибутами `data-sf-scheme`,
`data-sf-text-scale`, `data-sf-text-spacing`, `data-sf-images`,
`data-sf-motion`, `data-sf-font` и `data-sf-links`; сайт может поставить их
и сам. Из скрипта выбор читает и пишет
[`SF.displaySettings`](/ru/guide/functions/person/display-settings/).

### Событие и сброс

Человек изменил настройку — приходит `sf-display-settings-change` с
`{settings, previous, setting}`: `setting` — что изменилось (`scheme`,
`textScale`, `textSpacing`, `images`, `motion`, `font`, `links`) или
`reset`. Событие приходит после того, как страница уже показывает выбор.
Свойство `settings` — выбор сейчас, только для чтения. Метод `reset()` — то
же, что «Обычная версия».

```js
const panel = document.querySelector('sf-display-settings');
panel.addEventListener('sf-display-settings-change', (event) => {
  console.log(event.detail.setting, event.detail.settings);
});
```

### Внешний вид

Открытые переменные: `--sf-display-settings-background` (поверхность
панели), `--sf-display-settings-border-color` (край),
`--sf-display-settings-label-color` (подписи групп),
`--sf-display-settings-gap` (между группами) и
`--sf-display-settings-group-gap` (внутри группы).

## Доступность

- Кнопка — обычная кнопка с `aria-expanded`; `Escape` закрывает панель и
  возвращает фокус на кнопку.
- Панель — группа с именем из `label`; каждая настройка — группа с
  подписью, выбор — кнопки-переключатели с `aria-pressed`. «А−» и «А+»
  названы словами: «Текст меньше», «Текст больше».
- Панель — удобство, а не заявление о доступности: ни подпись, ни текст
  рядом не обещают, что сайт соответствует стандарту. Основной сайт
  отвечает WCAG сам.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `label` | строка | — | — | Подпись кнопки и имя панели. Не задано — «Настройки отображения». Российский сайт, где кнопку ищут по названию, пишет «Версия для слабовидящих». |
| `layout` | строка | `disclosure` | `disclosure`, `panel` | `disclosure` — кнопка, которая раскрывает панель под собой (`aria-expanded`); Escape закрывает её, и фокус возвращается на кнопку. `panel` — панель стоит открытой, без кнопки (своя страница, подвал). |
| `open` | да/нет | нет | — | Открыта ли панель вида `disclosure`; кнопка переключает её, Escape закрывает. |
| `show-font` | да/нет | нет | — | Показывает группу «Шрифт»: шрифт сайта, без засечек или с засечками (системные `--sf-sans` и `--sf-serif`). По умолчанию выключено: включает автор сайта. |
| `show-links` | да/нет | нет | — | Показывает «Подчёркивать ссылки». По умолчанию выключено: включает автор сайта. В цветовой схеме ссылки подчёркнуты всегда. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `reset()` | объект | «Обычная версия»: все настройки возвращаются к виду сайта, запомненный выбор удаляется; приходит `change` с `setting` `reset`. Отказ `{reason: unchanged}`, если ничего не меняли. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-display-settings-change` | `{ settings: object, previous: object, setting: string }` | Человек изменил настройку или выбрал «Обычную версию»: событие приходит, когда страница уже показывает выбор и браузер его запомнил. Никуда ничего не отправляется; страница, которой нужно знать, слушает это событие. |
