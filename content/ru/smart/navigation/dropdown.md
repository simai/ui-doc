# Выпадающий список

:badge[sf-dropdown]{variant=tonal scheme=primary size=1/2} :badge[1.7.4]{variant=outline scheme=on-surface size=1/2}

Выпадающий список даёт выбрать одно или несколько значений из раскрывающегося
списка с поиском. Берите его, когда вариантов больше, чем удобно показать
[радиокнопками](/ru/components/forms/radio/) или
[флажками](/ru/components/forms/checkbox/), или когда значения нужно показать
тегами.

То же на классах — [Выпадающий список](/ru/components/navigation/dropdown/):
для статической разметки без JavaScript.

## Разметка

Полю нужны имя, подпись и пункты — дочерние
[строки списка](/ru/smart/content/list-item/):

```html
<sf-dropdown name="status" label="Статус" placeholder="Выберите статус">
  <sf-list-item value="open" text="Открыт"></sf-list-item>
  <sf-list-item value="done" text="Готов"></sf-list-item>
</sf-dropdown>
```

`name` — машинное имя отправляемого значения, `label` — видимая подпись поля;
они не дублируют друг друга. `placeholder` приглашает к выбору, но не заменяет
подпись. `search-placeholder` относится только к полю поиска внутри раскрытого
списка; без атрибута в нём слово на языке страницы — «Поиск», по-английски
«Search».

`aria-label` на `<sf-dropdown>` заменяет видимую подпись в доступном имени.
Задавайте его, только если адаптеру нужно отдельное имя, и с тем же
локализованным смыслом, что у `label`. В компактной панели инструментов подпись
можно скрыть только визуально — это решается композицией панели, а не другим
вызовом Dropdown.

Пункты можно передать и данными — массивом `options` в свойстве вместо
дочерних `sf-list-item`.

## Варианты

### Вид поля

`appearance` • по умолчанию `outlined` • [справочник](#атрибуты)

`appearance` выбирает вид поля: `outlined` (по умолчанию) — с рамкой,
`filled` — с заливкой.

:::example {id="smart-components/dropdown/appearance" label="Поле с рамкой и с заливкой"}
:::

### Отображение выбора

`multiple`, `mode` • [справочник](#атрибуты)

`multiple` разрешает несколько значений; `mode="tag"` показывает выбранное
тегами, `select` (по умолчанию) — подписями строкой.

При `multiple` у каждого пункта в списке есть чекбокс: по нему видно, что
выбрано, а не только по цвету строки. Пункт со своей картинкой — значком,
цветом или аватаром — показывает её на месте чекбокса.

:::example {id="smart-components/dropdown/mode" label="Отображение выбора"}
:::

### Размер

`size` • по умолчанию `1` • [справочник](#атрибуты)

`size` — ступень `1/2`, `1` (по умолчанию) или `2`, как у полей форм.

:::example {id="smart-components/dropdown/sizes" label="Размеры 1/2, 1 и 2"}
:::

### Сетка пунктов

`layout`, `columns` • [справочник](#атрибуты)

`layout="grid"` раскладывает пункты по нескольку в ряд, `columns` задаёт
сколько. Сетка выше нескольких рядов прокручивается; её высоту задаёт токен
`--sf-dropdown--grid-height`. Ячейка сетки высотой с поле того же размера,
что и список, а сетка за собственным триггером шириной ровно в свои колонки.
В сетке пункт показывает свою картинку, а
подпись остаётся именем для поиска и подсказкой при наведении. Так удобно
выбирать из сотни значков: колонкой их не долистать.

:::example {id="smart-components/dropdown/grid" label="Сетка пунктов"}
:::

### Группы

`options` • [справочник](#атрибуты)

Пункт может сказать, откуда он: поле `group` в данных `options` или атрибут
`group` у `sf-list-item`. Идущие подряд пункты с одинаковым `group` рисуются
под одним заголовком, поэтому длинный список читается кусками, а название
места не повторяется в каждой строке.

:::example {id="components/dropdown/groups" label="Пункты по группам"}
:::

### Свой триггер

Собственный триггер Dropdown — поле: рамка, текст выбранного, шеврон. Там, где
список нужен за другим управляющим элементом — за «+» в шапке группы, за
кнопкой со значком, — передайте его в `slot="trigger"`. Компонент отдаёт такому
триггеру только нажатие, которое открывает список; как триггер выглядит, решает
тот, кто его передал. Список в этом случае берёт свою ширину, а не ширину
кнопки.

:::example {id="components/dropdown/trigger" label="Список за кнопкой со значком"}
:::

## Поведение

### Значение и событие

Свойство `value` возвращает выбранное машинное значение строкой. При
`multiple` значения перечислены через запятую, без выбора это пустая строка.
Присваивание `value` принимает строку или массив строк и выбирает пункты с
этими значениями. Кнопки очистки нет: из кода присвойте `value = ''`;
событие `change` при этом не приходит. Присвоенный массив `options`
перерисовывает список и сохраняет выбранное значение, если такой вариант в
нём есть.

Выбор пункта и удаление тега отправляют всплывающее событие `change`. Его
`event.detail`:

| Поле | Содержимое |
|:---|:---|
| `value` | значение нажатого пункта; при удалении тега — пустая строка |
| `label` | подпись нажатого пункта; при удалении тега — пустая строка |
| `values` | массив всех выбранных значений после изменения |
| `item` | данные нажатого пункта; при удалении тега — `null` |
| `root` | элемент `<sf-dropdown>` |
| `multiple` | `true`, если разрешён выбор нескольких значений |

Устаревшее имя `sf-dropdown:change` приходит вместе с `change` и с тем же
`detail`; подписывайтесь на `change`.

`root` — живой элемент, а не данные, поэтому `detail` — не JSON:
`JSON.stringify(event.detail)` падает на циклической структуре. Берите нужные
поля — `value`, `label` и `values` — и записывайте или отправляйте их:

```js
field.addEventListener('change', (event) => {
  const {value, label, values, multiple} = event.detail;
  save(multiple ? values : value);
});
```

Полное значение после изменения дают `event.detail.values` и
`event.target.value`. Повторный выбор уже выбранного пункта `change` не
отправляет, а при `multiple` снимает выбор пункта и отправляет `change`.

Событие `change` на элементе отправляет только сам компонент: нативный
`change` своего поля поиска он останавливает. Слушатель на предке, например
на форме, слышит и `change` других полей, поэтому проверяет `event.target`.

Свойство `selectedOptions` возвращает данные выбранных пунктов — те же, что
приходят в `event.detail.item`. Свойство `triggerText` возвращает подписи
выбранных пунктов через запятую, как их показывает поле; при `mode="tag"`
оно пустое, потому что выбранное показывают теги.

```js
const view = document.querySelector('sf-dropdown[name="view"]');
view.addEventListener('change', (event) => {
  applyView(event.detail.values);
});
view.value = 'archived';
```

### Список внутри панели или окна

Открытый список сам отвечает на `Escape`. Пока он открыт, на корне страницы
стоит общая отметка `data-sf-popover-open`, и боковая панель, модальное окно
или панель записи этот `Escape` пропускают. Первое нажатие закрывает только
список, второе — панель или окно за ним.

## Применение

### Язык в настройках профиля

Когда язык — одна из настроек, он становится полем формы. Список с поиском
вмещает любое число языков; пункты подписаны на своём языке («English», а не
«Английский»), чтобы человек нашёл свой, даже не читая текущий. По событию
`change` страница вызывает `SF.language.use(value)` и сохраняет выбор:
SIMAI Framework язык не запоминает.

:::

## Доступность

- Каждому Dropdown нужно доступное имя: видимый `label` или `aria-label`.
  Один `placeholder` имени не даёт.
- Триггер — одна остановка `Tab`. Стрелки открывают список и перемещают по
  пунктам, `Home` и `End` — к первому и последнему, `Enter` и `Space`
  выбирают, `Escape` закрывает список и возвращает фокус на триггер. Внутри
  боковой панели или модального окна это нажатие закрывает только список.
- Поле поиска в списке сохраняет обычное поведение `Home` и `End` при
  редактировании текста.
- Свой триггер в `slot="trigger"` должен быть кнопкой с доступным именем: у
  кнопки со значком — `aria-label`.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `appearance` | строка | `outlined` | `filled`, `outlined` | Вид выпадающего списка: поле с заливкой или с контуром. |
| `columns` | число | `6` | — | Сколько вариантов помещается в строку в раскладке-сетке. В списке игнорируется. |
| `disabled` | да/нет | нет | — | — |
| `label` | строка | пусто | — | — |
| `layout` | строка | `list` | `list`, `grid` | Раскладка вариантов. В списке — один вариант в строке; в сетке — несколько в строке, и только так можно просмотреть сотню символов: их столбец никто не прокручивает до конца. В сетке вариант показывает изображение, а текст сохраняется как имя для поиска и подсказки при наведении. |
| `mode` | строка | `select` | `tag`, `select` | — |
| `multiple` | да/нет | нет | — | Разрешает несколько значений с сохранением порядка выбора при сериализации. В режиме тегов множественный выбор включён по умолчанию. |
| `name` | строка | пусто | — | Имя поля в форме; с ним уходит выбранное значение. |
| `placeholder` | строка | — | — | Что поле показывает, пока ничего не выбрано. Пусто — текст на языке страницы («Не выбрано» по-русски, «Not selected» по-английски). За человека ничего не выбирается: значение остаётся пустым, пока он не выберет сам. |
| `portal` | да/нет | да | — | Список открывается поверх страницы и не выходит за экран; если не помещается — переворачивается. `portal="false"` оставляет список в потоке страницы. |
| `required` | да/нет | нет | — | — |
| `search` | да/нет | да | — | — |
| `search-placeholder` | строка | — | — | Пусто — текст на языке страницы (по-английски «Search»). |
| `size` | строка | `1` | `1/2`, `1`, `2` | — |
| `value` | строка | пусто | — | Выбранное машинное значение или список значений через запятую при множественном выборе. |
| `aria-label` | строка | пусто | — | — |
| `options` | список | `[]` | — | Варианты, переданные данными вместо дочерних `sf-list-item`: `[{text, value, type?, size?, icon?, selected?, disabled?, colorClass?, avatarImageUrl?, avatarTitle?, ariaLabel?, group?}]`. Строка или число используется и как подпись, и как значение. Родитель, отрисовывающий этот выпадающий список из шаблона, передаёт варианты так, потому что захват дочерних элементов означает их удаление, и родитель уже не сможет вернуть изменённый список. Идущие подряд варианты с одинаковым `group` выводятся под одним заголовком, чтобы длинный список показывал, откуда взят каждый его фрагмент, а не повторял это в каждой строке. |
| `inherited-value` | строка | пусто | — | Значение варианта (при множественном выборе — значения через запятую), к которому поле возвращается, пока ничего не выбрано. Подписи этих вариантов показаны как наследуемые — цветом подсказки и с меткой «наследуется», никогда как выбор: значение формы остаётся пустым. Когда что-то выбрано, кнопка сброса возвращает сюда. Только в режиме выбора; в режиме тегов не рисуется. |
| `inherited-text` | строка | пусто | — | Слова метки, которая видна, пока действует наследуемое значение. Если не задано — на языке страницы («наследуется», «inherited»). |
| `reset-label` | строка | пусто | — | Доступное имя кнопки, которая возвращает поле к наследуемому значению. Если не задано — на языке страницы («Сбросить к наследуемому», «Reset to inherited»). |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `openDropdown()` | объект | Открывает список вариантов, если поле доступно и список ещё закрыт. Возвращает тег. |
| `closeDropdown()` | объект | Закрывает список вариантов и очищает текст поиска. Возвращает тег. |
| `toggleDropdown()` | объект | Закрывает список, если он открыт, иначе открывает. Возвращает тег. |
| `resetToInherited()` | да/нет | Возвращает поле к унаследованному значению, как кнопка сброса: отправляет отменяемое `sf-field-reset`, очищает своё значение и ставит фокус в поле. Возвращает `false`, если сбрасывать нечего, поле недоступно или только для чтения, или событие отменили. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `change` | `{ value: string, label: string, values: array, item: object, multiple: boolean }` | Выбор изменился; событие отправляется на элементе. Имя для привязки. |
| `sf-field-reset` | `{ tag: string, value: string, inheritedValue: string, name: string }` | Человек нажал «сбросить к наследуемому». Это событие общее для всех таких полей: форма слышит их сразу и различает по `detail.tag`. Приходит до очистки; `preventDefault()` сохраняет значение. Иначе поле очищается, присылает обычный `change`, снова показывает наследуемое значение и получает фокус. |
