# Дерево

:badge[sf-tree]{variant=outline scheme=on-surface size=1/2} :badge[2.4.1]{variant=outline scheme=on-surface size=1/2} :badge[sf-tree-item]{variant=outline scheme=on-surface size=1/2} :badge[1.3.4]{variant=outline scheme=on-surface size=1/2}

Дерево показывает вложенный список: папки и файлы, разделы сайта, категории
каталога. Ветви раскрываются и сворачиваются, пункты выбираются мышью и
клавиатурой; каждый пункт — [узел дерева](#узел-дерева) `<sf-tree-item>`.
Для короткого плоского списка берите обычный список, для пути к текущей
странице — [Хлебные крошки](/ru/smart/navigation/breadcrumbs/).

То же на классах — [Дерево](/ru/components/navigation/tree/): оформление
совпадает с обычным деревом; классы годятся для статической разметки без
JavaScript.

## Разметка

Дереву нужны имя и пункты:

```html
<sf-tree aria-label="Папки проекта">
  <sf-tree-item label="Документы" open>
    <sf-tree-item label="Договоры"></sf-tree-item>
    <sf-tree-item label="Счета"></sf-tree-item>
  </sf-tree-item>
  <sf-tree-item label="Архив"></sf-tree-item>
</sf-tree>
```

Пункты — дочерние `<sf-tree-item>`, вложенные друг в друга так же, как ветви
дерева. Дерево читает их один раз при подключении как данные и убирает;
дальше оно рисует записи само. Подпись, ссылку, тип и состояние пункта
задают его атрибуты — они описаны в разделе [Узел дерева](#узел-дерева).

### Узел дерева

Узел `<sf-tree-item>` — один пункт дерева: папка с вложенными пунктами, файл
или ссылка на раздел. Внутри `<sf-tree>` узел читается один раз как данные и
убирается: строки рисует само дерево. Отдельно от дерева узел рисует свою
строку и, раскрытый, — вложенные узлы.

`label` — подпись узла; без неё подписью служит текст внутри
`<sf-tree-item>`. `value` — код узла: его несут события дерева. Все атрибуты
узла — в [справочнике](#атрибуты-1); их же можно передать полями записи в
[`items`](#пункты-данными).

:::example {id="smart-components/tree-item/overview" label="Разделы руководства" preview=sandbox log="sf-tree-open sf-tree-toggle" log_console=true log_open=false}
:::

#### Папка или файл

`kind` • по умолчанию `folder` • [справочник](#атрибуты-1)

Папка с вложенными узлами получает стрелку раскрытия и значок открытой или
закрытой папки, файл — значок документа и никогда не раскрывается. Другие
типы записи и значки по расширению — в разделе [Значки](#значки).

:::example {id="smart-components/tree-item/kind" label="Папка и файлы"}
:::

#### Иконка узла

`icon`, `open-icon`, `closed-icon` • [справочник](#атрибуты-1)

`icon="false"` убирает значок узла: так выглядит дерево разделов, а не
файлов. `open-icon` и `closed-icon` заменяют значки папки,
`chevron-open-icon` и `chevron-closed-icon` — стрелку раскрытия.

:::example {id="smart-components/tree-item/icons" label="Без иконки и свои иконки"}
:::

#### Подпись-ссылка

`href`, `target`, `rel` • [справочник](#атрибуты-1)

`href` делает подпись ссылкой, `target` и `rel` переходят на неё. `Enter` на
таком узле открывает ссылку.

:::example {id="smart-components/tree-item/link" label="Узлы-ссылки"}
:::

#### Состояния узла

`open`, `selected`, `active`, `disabled` • [справочник](#атрибуты-1)

`open` раскрывает ветвь. `selected` отмечает выбранный узел, если дерево
разрешает выбор (`selection`). `active` выделяет узел текущей страницы и
ставит ему `aria-current="page"`. `disabled` выключает узел: он не
раскрывается, его ссылка не работает, а нажатие ничего не делает.

:::example {id="smart-components/tree-item/states" label="Раскрыт, выбран, текущая страница, недоступен"}
:::

#### Узел в коде

Действия узла отвечают исходом: `{outcome: "applied"}` или
`{outcome: "refused"}` с причиной `leaf` у файла или узла без вложенных и
`disabled` у выключенного.

| Действие | Что делает |
|:---|:---|
| `expand()` | раскрывает ветвь |
| `collapse()` | сворачивает ветвь |
| `toggleOpen()` | раскрывает свёрнутую ветвь и сворачивает раскрытую |
| `activate()` | то же, что `Enter` на листе: открывает ссылку или отправляет `sf-tree-item-open` |
| `focusItem()` | переводит фокус на строку узла |

Внутри `<sf-tree>` слушайте события дерева — `sf-tree-open` и
`sf-tree-toggle` (см. [События](#события)); пример в начале раздела пишет их
в журнал. Узел вне дерева отправляет свои: `sf-tree-item-open` `{id, value}`
и `sf-tree-item-toggle` `{id, open, value}`.

## Варианты

### Значки

`icons`, `file-types` • по умолчанию `all` • [справочник](#атрибуты)

Каждая строка дерева — стрелка раскрытия и значок типа. Значок выбирается
так: `icon` записи, если он задан; иначе `kind` — одно из двенадцати слов:
`folder`, `file`, `page`, `document`, `image`, `code`, `data`, `table`,
`archive`, `video`, `audio`, `link`; иначе расширение имени («Смета.xlsx» —
таблица); иначе папка или файл. Ветка — папка, открытая или закрытая; запись
без детей — файл, если у неё нет `kind="folder"`.

`icons="all"` (по умолчанию) ставит значок на каждую строку,
`icons="branches"` — только у папок, `icons="none"` убирает значки, и
остаётся одна стрелка. `file-types="none"` не читает тип из расширения.

:::example {id="smart-components/tree/icons" label="Значки по типу записи"}
:::

### Размер и отступ уровня

`size` • по умолчанию `1` • [справочник](#атрибуты)

`size` — `1/2`, `1` (по умолчанию) или `2`: от него зависят высота строки,
текст, стрелка и значок. Отступ вложенного уровня — одно правило для всех
деревьев: имя ребёнка стоит под значком родителя. Шаг уровня — колонка
стрелки и промежуток строки; листья держат место стрелки, поэтому имена
одного уровня стоят ровно.

:::example {id="smart-components/tree/sizes" label="Три ступени размера"}
:::

### Статичное дерево

`static` • [справочник](#атрибуты)

`static` — дерево как структура в тексте документации: вложенный список,
все уровни видны, без стрелок, без остановки `Tab` и без наведения. Строки
высотой в строку текста, имена моноширинным шрифтом. Шаг уровня здесь —
значок и промежуток.

:::example {id="smart-components/tree/static" label="Структура папок проекта"}
:::

## Поведение

### Пункты данными

Свойство `items` принимает массив записей. Поля записи: `id`, `label`,
`value`, `href`, `target`, `rel`, `kind` (`folder` или `file`), `open`,
`selected`, `active`, `disabled`, `icon`, `open-icon`, `closed-icon`,
`chevron-open-icon`, `chevron-closed-icon`, `open-label`, `close-label`,
`revision` и `children` — массив вложенных записей. Поля в camelCase
(`openIcon`) и `type` — другое имя `kind` — тоже читаются. Код записи — `id`, иначе
`value`, иначе её место в дереве. Задавайте `items` после регистрации тега.

:::example {id="smart-components/tree/files" label="Результат"}
:::

### Строки на классах и длинные деревья

Дерево рисует записи плоско — строками той же классовой разметки, что у
[обычного дерева](/ru/components/navigation/tree/)
(`.sf-tree-item[role=treeitem][data-value]`, `.sf-tree-item-container`,
`.sf-tree-item-name`), с `aria-level`, `aria-setsize` и `aria-posinset`.
Внутри дерева нет элементов `<sf-tree-item>`, а значки — символы шрифта
значков, а не `<sf-icon>`.

- Строки связаны с записями по `id`. Новый `items`, в котором изменилась
  одна запись, переписывает только её строку, на месте; раскрытость ветвей
  переживает новый `items`.
- Если видимых записей больше 300, рисуются только строки в поле зрения
  ближайшей прокрутки с запасом, а событие `sf-tree-window {first, last}`
  говорит, какие нарисованы. Поэтому дерево из 10 000 узлов рисуется так же
  быстро, как из 2 000: первая отрисовка в замере укладывается в два кадра,
  а раскрытие, выбор пункта и переход стрелкой — тоже в два кадра и
  переписывают одну-две строки.
- Код страницы, который искал внутри дерева элементы `sf-tree-item`, ищет
  строки `.sf-tree-item[data-value]`.

### Выбор

`selection` задаёт, что делает нажатие на пункт:

| Значение | Нажатие |
|:---|:---|
| `none` (по умолчанию) | открывает пункт: его ссылку или событие `sf-tree-open` |
| `one` | выбирает один пункт |
| `many` | переключает выбор каждого пункта отдельно |

Значение `selected` — код текущего пункта, `selected-ids` — все выбранные
при `many`, по порядку записей. Изначальный выбор задают атрибутом
`selected` у пункта или полем `selected: true` у записи.

:::example {id="smart-components/tree/selection" label="Результат"}
:::

### События

| Событие | Когда | `event.detail` |
|:---|:---|:---|
| `sf-tree-open` | нажата подпись пункта или `Enter` на листе без ссылки | `id`, `value` |
| `sf-tree-select` | выбор изменился | `ids` — весь выбор, `id` — нажатый пункт, `selected` |
| `sf-tree-toggle` | ветвь раскрыта или свёрнута | `id`, `open`, `value` |
| `sf-tree-move` | на пункт отпустили записи из списка (`accept-records`) | `ids`, `parent`, `before`, `source` |
| `sf-tree-attach` | на пункт отпустили файлы (`accept-files`) | `files`, `parent` |
| `sf-tree-window` | изменилось окно длинного дерева | `first`, `last` |

События приходят на `<sf-tree>`. В `detail` — только данные: код записи, а
не элемент. `onToggle(handler)` слушает `sf-tree-toggle` и
передаёт обработчику элемент строки первым аргументом.

```js
const tree = document.querySelector('sf-tree[selection="one"]');

tree.addEventListener('sf-tree-select', (event) => {
  saveTarget(event.detail.id);
});

tree.addEventListener('sf-tree-toggle', (event) => {
  if (event.detail.open) loadChildren(event.detail.id);
});

await customElements.whenDefined('sf-tree');
tree.items = await fetchFolders();
```

### Действия

`expand({id})` и `collapse({id})` раскрывают и сворачивают ветвь,
`focusEntry({id})` переводит фокус на пункт и сначала рисует его, если окно
его не держит. Каждое действие отвечает исходом: `{outcome: "applied"}` или
`{outcome: "refused"}` — для неизвестного кода, листа или выключенного
пункта.

### Перетаскивание на узел

Дерево может принимать на узел то, что на него перетащили, — например, в
файловом менеджере. Само оно ничего не перемещает и не загружает: оно
сообщает, что и куда отпустили, а дальше действует приложение. Узел, над
которым сейчас перетаскивают, подсвечивается.

- `accept-records` — узел принимает записи, перетащенные из списка, например
  строки [таблицы](/ru/pro/admin/table/) с `drag-rows`. После
  отпускания приходит `sf-tree-move` с `{ids, parent, before, source}`:
  `ids` — записи, `parent` — узел, `source` — откуда их взяли. Это просьба
  переместить; переносит записи хост.
- `accept-files` — узел принимает файлы с компьютера; приходит
  `sf-tree-attach` с `{files, parent}` — просьба приложить файлы к узлу.

### Начальный вид

Пока записи не пришли, дерево показывает скелетон, выведенный из снимка
примера: полоски на месте подписей, той же высоты, что готовые строки.
Записи, которые приходят позже, объявлены в манифесте
(`"presentation": {"skeleton": {"late": ["items"]}}`); см.
[Первый кадр и ленивая загрузка](/ru/guide/smart-components/first-paint/).

## Доступность

- Дереву нужно доступное имя: `aria-label` или `aria-labelledby` на
  `<sf-tree>`. Это атрибуты хоста, а не настройки; роль всегда `tree`.
- Дерево — одна остановка `Tab`. Стрелки вверх и вниз переходят по видимым
  пунктам, `Home` и `End` — к первому и последнему. Стрелка вправо раскрывает
  ветвь, а у раскрытой переходит к первому вложенному пункту; стрелка влево
  сворачивает ветвь или переходит к родителю. Набор букв переводит фокус к
  пункту, подпись которого с них начинается.
- `Enter` раскрывает ветвь, а на листе открывает его ссылку или отправляет
  `sf-tree-open`; `Space` выбирает пункт при `selection="one"` или `many`.
  Фокус и выбор независимы: стрелки двигают фокус, не меняя выбор.
- Узел — элемент дерева (`treeitem`), его доступное имя — подпись.
  Недоступный узел сообщает `aria-disabled="true"`, узел текущей страницы —
  `aria-current="page"`.
- Кнопка раскрытия ветви подписана словами из файлов слов на языке
  страницы: «Развернуть» и «Свернуть». Другие подписи задают `open-label` и
  `close-label` у пункта или записи; примеры на этой странице задают их
  явно.
- При выборе пункты сообщают `aria-selected`, а при `selection="many"`
  дерево сообщает и `aria-multiselectable`.

## Справочник

### `<sf-tree>`

#### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `selection` | строка | `none` | `none`, `one`, `many`, `check` | Что делает нажатие: none открывает запись (или переходит по её ссылке), one выбирает одну запись, many переключает каждую, check ставит флажок в каждую строку — ветка отмечает всё внутри и показывает «частично», когда отмечена только часть (aria-checked true, false, mixed). |
| `icons` | строка | `all` | `all`, `branches`, `none` | Значки типа: all — на каждой строке, branches — только у папок, none — ни на одной (шеврон остаётся). |
| `file-types` | строка | `name` | `name`, `none` | name: лист без kind берёт тип из расширения имени («Смета.xlsx» — таблица); none: такой лист — просто файл. |
| `size` | строка | `1` | `1/2`, `1`, `2` | Ступень строк на лестнице размеров: колонка шеврона и значок типа — значок этой ступени, строка — её высота элемента, имя — её текст; шаг уровня следует за ними (колонка + промежуток в строке). |
| `static` | да/нет | нет | — | Структура в тексте для документации: вложенный список (не role tree), все уровни видны, без шевронов, без остановки Tab и без наведения, строки высотой в строку текста, имена моноширинным шрифтом, пояснения после них. На классах — .sf-tree--static. |
| `reorder` | да/нет | нет | — | Запись можно перетащить в другое место дерева: до или после строки либо в папку или страницу; дерево спрашивает событием move {ids, parent, before} и само ничего не переносит. |
| `accept-records` | да/нет | нет | — | Запись принимает записи, перетащенные из списка (application/x-sf-records+json). |
| `accept-files` | да/нет | нет | — | Запись принимает файлы, перетащенные с компьютера. |
| `selected` | строка | пусто | — | id текущей записи; при `selection` many — последней нажатой. |
| `aria-label` | строка | пусто | — | — |
| `items` | список: объект | `[]` | — | Дерево как данные: записи с детьми; иначе один раз читаются дети `sf-tree-item`, написанные внутри. id записи — id, иначе value, иначе её место. |
| `selected-ids` | список | `[]` | — | Выбранные id в порядке записей, при `selection` many. |

##### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | — | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

#### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `expand(args: object)` | объект | Открывает ветку; отказ для неизвестного id, листа или выключенной записи. |
| `collapse(args: object)` | объект | Действие collapse. |
| `focusEntry(args: object)` | объект | Переводит фокус на запись, сначала нарисовав её, если окно её не показывает. |
| `expandAll()` | объект | Открывает все невыключенные ветки; toggle для каждой открывшейся. |
| `collapseAll()` | объект | Закрывает все открытые ветки. |
| `onToggle(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик sf-tree-toggle от любого пункта дерева; обработчик вызывается с (item, detail, event). |

#### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-tree-open` | `{ id: any, value: string }` | Нажатие на имя записи или Enter на листе без ссылки. |
| `sf-tree-select` | `{ ids: array, id: any, selected: boolean }` | Выбор изменился: ids — весь выбор, id — нажатая запись, selected — выбрана ли она теперь. |
| `sf-tree-toggle` | `{ id: any, open: boolean, value: string }` | Ветка открылась или закрылась. |
| `sf-tree-retry` | `{ id: any, value: string }` | «Повторить» в строке ошибки ленивой ветки: ветка снова показывает «Загрузка…»; приложение ещё раз загружает её детей и задаёт новые items. |

| `sf-tree-window` | `{ first: number, last: number }` | При более чем 300 видимых записях — какие из них нарисованы. |

| `onToggle(handler: function, options?: object\|boolean)` | объект | Добавляет обработчик sf-tree-item-toggle; обработчик вызывается с (open, detail, event). Обработчик, не являющийся функцией, игнорируется. |
