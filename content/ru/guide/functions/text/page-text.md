# Слово компонента

Свой код на странице — подпись, сообщение, компонент проекта — должен
говорить на том же языке, что и компоненты Framework рядом с ним.
`SF.pageLanguage(node)` отвечает, какой язык действует для узла, а
`SF.pageText` берёт слово из словаря компонента на этом языке, с учётом
слов, которые страница добавила через `SF.language.register`.

## Вызов

```js
const WORDS = {ru: {empty: 'Пока пусто'}, en: {empty: 'Nothing yet'}};

SF.pageLanguage(node);                         // 'ru'
SF.pageText(WORDS, 'empty', node);             // 'Пока пусто'
SF.pageText(WORDS, 'empty', node, 'shop-cart'); // со словами, добавленными для shop-cart
```

| Функция | Что возвращает |
|:---|:---|
| `SF.pageLanguage(node)` | Язык без региона (`ru`, `pt`) для узла: ближайший `[lang]` ниже `<html>`, иначе язык, выбранный через `SF.language.use()`, иначе `<html lang>`, иначе `en`. |
| `SF.pageText(dictionary, key, node, component)` | Слово `key` на языке узла. Ищет сначала слова, добавленные для `component` (по умолчанию — тег самого узла), потом слова из `dictionary`; затем то же для языка без региона и для английского. |

## Когда доступно

Ядро: сразу после выполнения `core.js`, ждать не нужно.

## Пример

Два блока с разным `lang` берут одно и то же слово из одного словаря. Кнопка
добавляет русскому слову свою замену через `SF.language.register`, и блок
показывает её.

## Особые случаи

- Слова нет ни на одном языке — возвращается сам ключ.
- `lang` ищется и через теневое дерево: узел внутри смарт-элемента получает
  язык блока, в котором стоит элемент.
