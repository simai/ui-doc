# Маска поля

Маска ведёт человека при вводе: телефон сам получает скобки и дефисы, код —
разделители, сумма — пробелы между разрядами. Поля ввода Framework надевают
маску по атрибуту `data-mask-pattern`. `SF.Mask` нужен, когда маску надевает
скрипт — на своё поле или поле, созданное позже, — и когда значение надо
вывести по маске без поля.

## Вызов

```js
const phone = await SF.Mask.create(input, {mask: '+{7} (000) 000-00-00', lazy: false});
phone.unmaskedValue;   // '79161234567'
phone.destroy();

await SF.Mask.pipe('9161234567', '+{7} (000) 000-00-00');       // '+7 (916) 123-45-67'
await SF.Mask.pipe(1234.5, {mask: Number, thousandsSeparator: ' ', scale: 2, padFractionalZeros: true}); // '1 234,50'
```

| Член | Что делает |
|:---|:---|
| `create(target, options)` | Надевает маску на поле — элемент или селектор. Обещание выполняется с маской поля, или с `null`, если поля или настроек нет. |
| `pipe(value, mask)` | Обещание строки: значение по маске без поля. `mask` — шаблон строкой или объект настроек. |
| `destroy(instance)` | Снимает маску; то же, что `instance.destroy()`. |
| `load()` | Обещание функции, которая создаёт маску; `create` вызывает её сам. |

Шаблон: `0` — цифра, `a` — буква, `*` — любой знак, `{…}` — постоянная часть,
которая входит в значение (`+{7}`), `\` — следующий знак как есть, остальные
знаки показываются, но в значение не входят.

| Настройка | Что делает |
|:---|:---|
| `mask` | Шаблон строкой, `Number` для числа, регулярное выражение или функция. |
| `lazy` | `false` показывает весь шаблон с пустыми местами сразу; по умолчанию места появляются по мере ввода. |
| `placeholderChar` | Знак пустого места, по умолчанию `_`. |
| `radix`, `thousandsSeparator`, `scale`, `padFractionalZeros`, `min`, `max`, `signed` | Для числа: десятичный знак (по умолчанию запятая), разделитель разрядов, знаки после запятой (по умолчанию 2), дописывать нули, границы, разрешить минус. |

У маски поля: `value` — то, что в поле; `unmaskedValue` — только введённое и
постоянные части; `typedValue` — число для числовой маски; `updateValue()` —
перечитать поле; `destroy()` — снять маску. Все три значения можно и
записать.

## Когда доступно

Ядро: сразу после выполнения `core.js`, ждать не нужно.

## Особые случаи

- Число проверяется, когда человек уходит из поля: тогда применяются `min`,
  `max` и `scale`. Пока он печатает, `12,` и `-` остаются как есть.
- Знак, которого шаблон в этом месте не ждёт, переходит к следующему месту,
  которое его принимает.
