# Язык страницы

Компоненты Framework говорят на языке страницы. `SF.language` меняет этот
язык из скрипта — например, по переключателю языка — и добавляет компонентам
слова на языке, которого Framework не знает, или правит одно слово, не
переписывая остальные. Компоненты на странице рисуются заново сами.

## Вызов

```js
SF.language.use('en');                                     // язык всей страницы
SF.language.register('sf-pager', 'ru', {next: 'Вперёд'});  // поправить одно слово
SF.language.registerAll('kk', {'sf-pager': {next: 'Келесі'}});
const stop = SF.language.onChange(() => redraw());
```

| Член | Что делает |
|:---|:---|
| `current(node)` | Язык с регионом, который действует для узла (по умолчанию — для `<html>`). |
| `use(language)` | Выбирает язык всей страницы и пишет его в `<html lang>`. `use(null)` возвращает язык разметки. Возвращает выбранный язык. |
| `register(component, language, words)` | Добавляет или заменяет слова одного компонента на одном языке. Слова сливаются с прежними; `null` вместо слов убирает добавленное. |
| `registerAll(language, {компонент: слова})` | То же для многих компонентов сразу. |
| `known(component)` | Языки, на которых компоненту добавлены слова. |
| `components()` | Компоненты, которым что-то добавлено. |
| `onChange(listener)` | Вызывает `listener` при смене языка или слов; возвращает функцию, которая отписывает. |
| `forget()` | Забывает всё добавленное и выбор языка. |

## Когда доступно

Ядро: сразу после выполнения `core.js`, ждать не нужно.

## Пример

Кнопки меняют язык страницы, третья добавляет листалке своё слово «Вперёд».
Листалка рисуется заново, журнал показывает язык после каждого изменения.

## Особые случаи

- Язык части страницы сильнее выбора: блок со своим `lang` говорит на своём
  языке и после `use()`.
- Слово из атрибута самого элемента (например, `next-label` у листалки) не меняется ни
  от языка, ни от `register`.
- `register` без компонента или языка бросает `TypeError`.
