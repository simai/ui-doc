# Чужой HTML

HTML, который пришёл не от самого сайта — ответ сервера, сообщение
пользователя, ответ ИИ-ассистента, — вставляют на страницу только через
`SF.sanitizeHtml`. Функция оставляет абзацы, списки, выделение, код, таблицы и
безопасные ссылки, а скрипты, обработчики событий, стили и всё, что может
загрузить или выполнить чужой код, убирает. `SF.safeHref` отвечает, можно ли
оставить адрес ссылки.

## Вызов

```js
element.replaceChildren(SF.sanitizeHtml(html));                // DocumentFragment
SF.sanitizeHtml(html, {elements: ['p', 'br', 'a']});            // список ещё уже
SF.sanitizeHtml(html, {codeLanguage: true});                    // оставить language-* у <code>
SF.safeHref('https://example.com/a');                           // адрес или null
```

| Параметр | Что делает |
|:---|:---|
| `html` | Строка HTML. Не строка и пустая строка дают пустой фрагмент. |
| `elements` | Свой, более узкий список разрешённых элементов. Вернуть запрещённый элемент он не может. |
| `codeLanguage` | `true` оставляет у `<code>` один класс `language-*` для подсветки. По умолчанию выключено. |
| `document` | Документ, в котором создаётся фрагмент; по умолчанию документ страницы. |

`SF.sanitizeHtml` возвращает `DocumentFragment`, его вставляют через
`append` или `replaceChildren`. `SF.safeHref(url)` возвращает адрес, если он
`http:`, `https:`, `mailto:` или путь от корня сайта (`/docs/a`), иначе `null`.

## Что остаётся

- **Элементы:** `p br strong em code pre ul ol li blockquote a table thead
  tbody tr th td h2 h3 h4 del`.
- **Убираются вместе с содержимым:** `script`, `style`, `iframe`, `svg`,
  `img`, `video`, `form`, `input`, `button` и другие элементы, чьё содержимое
  не текст для читателя.
- **Раскрываются:** остальные элементы (`div`, `span`, `h1`, `b`) заменяются
  своим текстом и детьми.
- **Атрибуты** убираются все, кроме `href` у ссылки (если его оставил
  `SF.safeHref`), `colspan`, `rowspan` и `scope` у ячеек таблицы. Каждая
  оставленная ссылка открывается в новой вкладке с
  `rel="noopener noreferrer nofollow"`.

## Когда доступно

Ядро: сразу после выполнения `core.js`, ждать не нужно.

## Особые случаи

- Разбор не выполняет ничего: строка читается в `<template>`, и ни скрипт,
  ни загрузка, ни обработчик не срабатывают даже на время очистки.
- Ссылка, чей адрес не прошёл `SF.safeHref`, остаётся своим текстом.
  `//host` и `/\host` уводят на чужой сайт и не проходят.
- Свою разметку сайта очищать не нужно; очистка — для того, что пришло
  извне.
