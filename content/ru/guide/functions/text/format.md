# Даты, числа и размеры

`SF.format` выводит дату, «вчера» или «5 минут назад», число, сумму и размер
файла так, как принято на языке страницы: на русской странице — «1 234,50 ₽»
и «3 нояб. 2026 г.», на английской — «1,234.50» и «Nov 3, 2026». Язык берётся
у узла, рядом с которым стоит значение, поэтому английский блок на русской
странице получает английские даты. Те же правила используют компоненты
Framework, и подписи на странице не расходятся.

## Вызов

```js
const {format} = window.SF;
format.date(at, {node});                         // 3 нояб. 2026 г.
format.date(at, {node, date: 'long', time: 'short'}); // 3 ноября 2026 г. в 14:05
format.relativeDay(at, {node});                  // сегодня, вчера, пятница, 27 октября
format.relativeTime(at, {node});                 // 5 минут назад
format.number(1234.5, 'currency-RUB', {node});   // 1 234,50 ₽
format.fileSize(1468006, {node});                // 1,4 МБ
```

Каждая функция принимает `{locale, node}`: язык — `locale`, если он задан,
иначе язык страницы для `node` (ближайший `[lang]` выше узла).

| Член | Что делает |
|:---|:---|
| `date(value, {date, time, intl})` | Дата и время. `date` и `time` — `'short'`, `'medium'` (дата по умолчанию), `'long'` или `null`, чтобы не показывать часть; `intl` — параметры Intl напрямую. |
| `relativeDay(value, {now, today, yesterday, tomorrow, weekday, capital})` | «Сегодня», «вчера», «завтра», день недели в пределах недели или дата. Дни считаются по календарю в часовом поясе читателя. `weekday: false` не называет день недели, `capital: true` пишет с заглавной, свои слова передают в `today`, `yesterday`, `tomorrow`. |
| `msUntilNextDay(now)` | Сколько миллисекунд до полуночи читателя: когда «сегодня» станет «вчера». |
| `relativeTime(value, {now})` | «5 минут назад», «через 2 часа». |
| `dayOffset(value, {now})` | Разница в календарных днях: `0` — сегодня, `-1` — вчера. |
| `number(value, format, {step, grouping, gap})` | Число по слову формата: `number`, `integer`, `decimal-<n>`, `percent`, `compact`, `currency-<КОД>`, `unit-<единица>`. `grouping: false` убирает разделитель разрядов. |
| `numberOptions(format, step)` | Параметры Intl для слова формата. |
| `fileSize(size, {units})` | Размер файла в Б, КБ, МБ и ГБ; свои слова единиц — массивом `units`. |
| `locale({locale, node})` | Язык с регионом, которым будет выведено значение. |

## Когда доступно

Ядро: сразу после выполнения `core.js`, ждать не нужно.

## Особые случаи

- Не значение — нет даты, `NaN`, `null` — выводится пустой строкой. Свой
  знак передают в `gap`: `format.number(NaN, 'number', {gap: '—'})`.
- Неизвестное слово формата читается как `number`, неизвестная валюта или
  единица — как обычное число.
- «Сегодня» меняется в полночь. Компонент, который показывает дни, ставит
  таймер на `msUntilNextDay()` с запасом в секунду и рисует подписи заново.
- Компонент, который собирается вместе с Framework, импортирует только
  нужные функции из модулей `core/js/format-number.js`,
  `core/js/format-date.js`, `core/js/format-relative.js` и
  `core/js/format-file-size.js`; импорт ничего не меняет на странице.
