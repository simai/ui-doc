# Настройки отображения

Человек может попросить сайт показываться иначе: крупнее текст, другая
цветовая схема, шире интервалы, без картинок, без движения. `SF.displaySettings`
хранит такой выбор в этом браузере и применяет его на каждой странице сайта —
есть на странице панель настроек или нет. Ничего не уходит на сервер.

## Вызов

```js
SF.displaySettings.write({textScale: 150, scheme: 'black-on-white'});
const now = SF.displaySettings.current();                // то, что показано сейчас
const stop = SF.displaySettings.subscribe((settings) => redraw(settings));
SF.displaySettings.reset();                              // обычная версия сайта
```

| Член | Что делает |
|:---|:---|
| `read()` | Выбор человека из браузера, а если его нет — то, что показано на странице. |
| `current()` | Настройки, которые показаны сейчас: их читают с атрибутов `<html>`. |
| `write(settings)` | Запоминает выбор в браузере и сразу показывает его. Неизвестные поля и значения отбрасываются. |
| `reset()` | Возвращает обычный вид сайта и забывает выбор. |
| `subscribe(listener)` | Вызывает `listener(settings)`, когда выбор изменился, в том числе в другой вкладке сайта. Возвращает функцию отписки. |
| `reducedMotion()` | `true`, если движение просит убрать устройство или человек на этом сайте. |
| `forcedColors()` | `true`, если цвета задаёт система (контрастные темы Windows). |
| `installSkipLink(doc?)` | Ставит ссылку «Перейти к содержимому», если её ещё нет. |
| `storageKey` | Ключ хранилища браузера: `sf-display-settings`. |
| `schemes`, `textScales`, `defaults` | Допустимые схемы, ступени размера текста и значения по умолчанию. |

## Поля

| Поле | Значения | Атрибут `<html>` |
|:---|:---|:---|
| `scheme` | `''` (цвета сайта), `black-on-white`, `white-on-black`, `yellow-on-black`, `blue-on-sky`, `brown-on-cream` | `data-sf-scheme` |
| `textScale` | `100`, `125`, `150`, `175`, `200` — проценты от размера текста браузера | `data-sf-text-scale` |
| `textSpacing` | `normal`, `wide` | `data-sf-text-spacing` |
| `images` | `colour`, `grey`, `hide` | `data-sf-images` |
| `motion` | `system`, `reduce` | `data-sf-motion` |
| `font` | `site`, `sans`, `serif` | `data-sf-font` |
| `links` | `site`, `underline` | `data-sf-links` |

Значение по умолчанию атрибута не ставит. Атрибуты читают стили ядра, поэтому
страница, которую сервер отдал уже с атрибутом на `<html>`, показывается так
с первой отрисовки; выбор человека в браузере сильнее.

## Когда доступно

Ядро: сразу после выполнения `core.js`, ждать не нужно.

## Особые случаи

- Ссылку «Перейти к содержимому» ядро ставит первой в `<body>` на каждой
  странице, где есть основная область и нет своей такой ссылки.
  `<html data-sf-skip-link="off">` её убирает.
- Где браузерное хранилище недоступно, выбор действует до ухода со страницы.
- Прежние имена схем версии для слабовидящих (`white`, `black`, `yellow`,
  `blue`, `green`) читаются как ближайшие новые до 2027-01-01 и отмечаются
  в `SF.deprecations`.
- Настройки не означают, что сайт соответствует какому-либо стандарту
  доступности.
