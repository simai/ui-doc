# Значки на выбор

Когда человек сам отмечает значком раздел записи, пункт меню или плитку
панели, ему нужен понятный выбор, а не весь шрифт иконок. `SF.icons.choices`
— общий для всех наборов список значков, сгруппированных по
смыслу: что это, чьё, когда, сколько стоит, из чего состоит. Выбор рисуют
выпадающим списком в виде сетки значков.

## Вызов

```js
SF.icons.choices;          // ['folder', 'folder_open', 'topic', 'home', 'dashboard', …]
SF.icons.choices.length;   // сколько значков в списке
```

| Член | Что это |
|:---|:---|
| `choices` | Неизменяемый массив имён значков Material Symbols. |

## Когда доступно

Ядро: сразу после выполнения `core.js`, ждать не нужно.

## Особые случаи

- Список заморожен: его нельзя изменить. Своему выбору возьмите копию —
  `[...SF.icons.choices, 'rocket']`.
- В списке только имена; подписи пунктов для экранного диктора даёт сама
  страница.
