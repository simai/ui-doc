# Уведомления

Когда нужно сообщить, что что-то произошло — сохранено, отправлено, не
получилось, — скрипт вызывает `SF.notify`. Сообщение появляется в одной для
всей страницы области у края окна, а не рядом с компонентом, который его
поднял: сообщения не перекрывают друг друга и встают в очередь.
`SF.notifications` настраивает эту область и отдаёт показанные сообщения.

## Вызов

```js
const handle = SF.notify({status: 'success', title: 'Сохранено', text: 'Изменения видны всем.'});
SF.notify('Ссылка скопирована');      // строка — текст сообщения
handle.close();

SF.notifications.configure({placement: 'top-end', max: 3});
SF.notifications.history();          // последние 50 сообщений, новые первыми
```

| Параметр | Что делает |
|:---|:---|
| `status` | `neutral` (по умолчанию), `info`, `success`, `warning`, `error`. Неизвестное значение — `neutral`. |
| `title`, `text` | Заголовок и текст. Нужен хотя бы один. |
| `action` | Кнопка в сообщении: `{label, onSelect(record)}`. После нажатия сообщение закрывается. |
| `duration` | Сколько миллисекунд сообщение видно; `0` — до закрытия. Без значения — 5 секунд, предупреждение — 8, ошибка — 10. |
| `icon` | Свой значок вместо значка статуса. |
| `key` | Сообщения с одним ключом считаются одним: повтор увеличивает счётчик на уже показанном. Без ключа одним считаются сообщения с тем же статусом, заголовком и текстом. |
| `source` | Кто поднял сообщение; попадает в запись. |
| `silent` | `true` записывает сообщение и объявляет его событием, но не показывает. |

`SF.notify` возвращает `{id, close()}`. `SF.notifications`:
`configure({placement, max})` — угол (`top-start`, `top-end`, `bottom-start`,
`bottom-end`; по умолчанию `bottom-end`) и сколько сообщений видно сразу (по
умолчанию 4); `close(id)` — закрыть сообщение; `history()` — записи
`{id, status, title, text, source, time}`.

## Когда доступно

Ядро: сразу после выполнения `core.js`. Компонент сообщений загружается при
первом вызове.

## Особые случаи

- Без заголовка и текста ничего не показывается: `SF.notify` возвращает
  `null` и пишет в консоль предупреждение.
- Перед показом на документе приходит событие `sf-notification` с записью в
  `detail`. Центр уведомлений может записать её и отменить событие
  (`preventDefault()`): тогда сообщение сохраняется, но не показывается.
- Ошибка объявляется экранному диктору сразу, остальные статусы — вежливо.
- Таймер сообщения останавливается, пока на нём указатель или фокус.
