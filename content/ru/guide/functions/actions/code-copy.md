# Копирование кода в тексте

Имя события, команда или адрес в абзаце часто нужно перенести в код.
Контейнер с атрибутом `data-sf-code-copy` превращает каждый `<code>` в
тексте внутри себя в кнопку копирования: нажатие или Enter копируют его, а
рядом на миг появляется «Скопировано». Так работает и эта документация.
`SF.codeCopy` нужен, когда скрипт хочет скопировать код сам или проверить,
копируется ли он.

## Вызов

```html
<article data-sf-code-copy>
  <p>Событие <code>sf-button-press</code> приходит после нажатия.</p>
</article>
```

```js
await SF.codeCopy.copy(code);     // true — скопировано
SF.codeCopy.isCopyable(code);      // копируется ли этот <code> по нажатию
SF.codeCopy.refresh(root);         // заново разметить код внутри root
```

| Член | Что делает |
|:---|:---|
| `copy(code)` | Копирует текст одного `<code>` и говорит об этом рядом словами кнопки копирования. Выполняется с `true`, если скопировано, и с `false`, если браузер отказал: тогда текст выделяется и подсказка называет клавиши. |
| `isCopyable(code)` | Отвечает, копируется ли этот `<code>` по нажатию. |
| `refresh(root)` | Размечает код внутри `root` и снимает разметку с того, что больше не должно копироваться. Добавленные и изменённые контейнеры отслеживаются и без вызова. |

## Когда доступно

Ядро: сразу после выполнения `core.js`. Код размечается, как только документ
разобран.

## Пример

Нажмите на код в абзаце или перейдите к нему клавишей Tab и нажмите Enter.
Кнопка добавляет абзац с новым кодом — он копируется так же; в журнале — что
отвечает `isCopyable`.

## Особые случаи

- Копируется только код в тексте. Код в блоке `<pre>`, в `kbd` и `samp`, в
  кнопке и `<code>` со своим классом `sf-` остаётся как есть.
- `data-sf-code-copy="false"` на части внутри контейнера выключает
  копирование в этой части.
- Нажатие, которым человек заканчивает выделение внутри кода, не копирует:
  он выделял текст.
- Слова «Скопировано» — слова кнопки копирования (`sf-button-copy`):
  поправленные через `SF.language.register` для неё, они звучат и здесь.
