# Копирование текста

`SF.copyText` кладёт текст в буфер обмена — ключ, ссылку, номер заказа.
Если браузер не даёт современный способ (страница не защищена, встроенный
фрейм, запрет политики), функция копирует запасным способом. Ответ говорит,
каким способом скопировано или почему не получилось. Ею копируют
[кнопка копирования](/ru/smart/actions/copy-button/) и класс
[Копирование](/ru/components/actions/clipboard/).

## Вызов

```js
try {
  const how = await SF.copyText('INV-2041');   // 'native' или 'legacy'
} catch (error) {
  // выделите текст и подскажите нажать Ctrl+C
}
```

| Параметр | Что делает |
|:---|:---|
| `text` | Текст для буфера обмена. |
| `{document}` | Документ, в котором копировать; для элемента в другом окне — `element.ownerDocument`. |

Обещание выполняется со значением `'native'` (Clipboard API) или
`'legacy'` (копирование через скрытое поле, которое сразу убирается).

## Когда доступно

Ядро: сразу после выполнения `core.js`, ждать не нужно.

## Особые случаи

- Обещание отклоняется ошибкой с сообщением `copy_unsupported`, если не
  сработал ни один способ, или ошибкой браузера (`NotAllowedError`,
  `SecurityError`), если он запретил копирование.
  Тогда выделите текст и подскажите человеку нажать Ctrl+C — так делает
  кнопка копирования.
- Браузер разрешает копировать в ответ на действие человека: вызывайте
  функцию из обработчика нажатия.
- `SF.Clipboard` с заглавной буквы — скрипт компонента на классах, а не эта
  функция.
