# Действия на странице

Функции для того, что происходит по нажатию: скопировать, сообщить о
результате, переключить тему.

- [Копирование текста](/ru/guide/functions/actions/copy-text/) — положить текст в буфер обмена.
- [Копирование кода в тексте](/ru/guide/functions/actions/code-copy/) — код в абзаце копируется по нажатию.
- [Уведомления](/ru/guide/functions/actions/notify/) — сообщение в общей области уведомлений страницы.
- [Тема](/ru/guide/functions/actions/theme/) — светлая, тёмная или как в системе.
