# Положение чтения

В ленте, журнале или переписке содержимое меняется под читателем: сверху
подгружается история, снизу приходят новые записи. `SF.readingPosition`
держит место человека: то, что он читает, не сдвигается, за новой записью
колонка идёт, только если он был внизу, а близкий край вызывает загрузку
ещё одной порции. На этом правиле построены [Лента](/ru/smart/content/list-feed/)
и [Список](/ru/smart/content/list/).

## Вызов

```js
const {create, watchEdge, scrollerOf} = SF.readingPosition;

const position = create(scroller, {onStart: () => loadEarlier()});
scroller.addEventListener('scroll', () => position.check());

position.keep(() => column.prepend(earlier));   // история сверху, читаемое на месте
const follow = position.atEnd();
column.append(entry);
if (follow) position.toEnd();                   // за новой записью — только если был внизу
```

| Член | Что делает |
|:---|:---|
| `create(scroller, {nearEnd, nearStart, onStart})` | Контроллер одной прокручиваемой области. `nearEnd` — сколько пикселей до конца ещё считается «внизу» (96), `nearStart` — до начала (240), `onStart` — что вызвать, когда начало близко. |
| `watchEdge(sentinel, callback, {root, margin})` | Следит за меткой у края и вызывает `callback`, когда она близко (`margin`, по умолчанию `200px`). Возвращает функцию, которая останавливает слежение. |
| `scrollerOf(node)` | Ближайший предок узла с прокруткой по вертикали; `null` — прокручивается страница. Его передают в `root`. |
| `NEAR_END`, `NEAR_START`, `EDGE_MARGIN` | Значения по умолчанию: 96, 240 и `'200px'`. |

У контроллера: `atEnd()` и `atStart()` — близко ли конец и начало; `keep(mutate)`
— выполнить изменение, не сдвинув читаемое; `toEnd({instant, settle, then})` —
перейти в конец в следующем кадре, плавно, если не задано `instant`;
`check()` — вызывать при прокрутке; `hold()` и `release()` — придержать и
отпустить сообщения о начале; `element` — сама область, её можно заменить.

## Когда доступно

Ядро: сразу после выполнения `core.js`, ждать не нужно.

## Пример

Колонка сообщений. «Новое внизу» добавляет запись в конец: если вы
прокрутили вверх, колонка остаётся на месте. «История сверху» добавляет
записи в начало, не сдвигая то, что видно. Прокрутите к началу — журнал
покажет вызов `onStart`.

## Особые случаи

- Колонка, которую ещё не нарисовали, считается стоящей в конце.
- `toEnd` идёт плавно, если у человека не включено уменьшение движения
  (`prefers-reduced-motion: reduce`); тогда переход мгновенный.
- `toEnd({settle: true})` после замены колонки придерживает `onStart` на
  кадр: колонка, на миг оказавшаяся в начале, не просит раннюю историю.
- `check()` спрашивает `onStart` при каждом вызове у начала. Ушёл ли уже
  запрос, решает вызывающий код.
- Без `IntersectionObserver` `watchEdge` ничего не делает: оставьте кнопку
  «Показать ещё».
