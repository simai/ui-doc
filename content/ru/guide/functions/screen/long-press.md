# Долгое нажатие

`SF.longPress` следит за пальцем, который держат на элементе: через 500 мс
вызывает вашу функцию. Это то же долгое нажатие, которым пользуются списки,
карточки и доски Framework, поэтому оно ведёт себя у всех одинаково (правила —
в разделе [«Сенсорные экраны»](/ru/guide/size-and-type/touch-screens/#долгое-нажатие)).

## Вызов

```js
const watch = SF.longPress.watch(card, {
  accepts: (event) => !event.target.closest('button, a, input'),
  press: () => openMenu(card),
});

card.addEventListener('click', (event) => {
  if (watch.swallowed()) return;   // это отпускание после долгого нажатия
  openCard(card);
});

watch.stop();                      // снять наблюдение
```

| Член | Что делает |
|:---|:---|
| `ms` | `500` — сколько миллисекунд держать палец. |
| `watch(target, {accepts, press, ms})` | Вызывает `press(event)`, когда основное касание держат `ms` мс на `target`, а `accepts(event)` принял его начало (`pointerdown`). По умолчанию `accepts` принимает всё, `ms` — 500. Возвращает `{swallowed(), stop()}`. |
| `swallowed()` | Один раз отвечает `true` — на щелчок, который браузер шлёт после сработавшего нажатия. Так обычный щелчок по элементу не срабатывает вслед за долгим нажатием. |
| `stop()` | Снимает все обработчики. |

## Как ведёт себя

- Работает только для касания пальцем (`pointerType` `touch`) и только для
  основного касания; мышь и перо его не вызывают.
- Если браузер принял касание за прокрутку, нажатие отменяется
  (`pointercancel`) и `press` не вызывается.
- Пока палец держат, меню браузера по долгому нажатию не появляется.
- Что делает нажатие, решает `press`: на поверхности с выбором нескольких
  элементов — выбирает элемент и включает режим выбора, без выбора —
  открывает меню «⋯» элемента. У долгого нажатия всегда есть видимая замена —
  кнопка «Выбрать» или «⋯».

## Когда доступно

Ядро: сразу после выполнения `core.js`, ждать не нужно. В выпусках до
`core.runtime` 1.69.0 объекта нет; проверяйте `window.SF?.longPress`.

## Пример

Откройте страницу на телефоне или включите в инструментах разработчика
режим сенсорного экрана и подержите палец на карточке: журнал покажет
нажатие. Короткое нажатие открывает карточку, а щелчок после долгого
нажатия не засчитывается.
