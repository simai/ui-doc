# Контрольные точки

Стили Framework переключаются на шагах ширины `sm`, `md`, `lg`, `xl` и
`xxl`. `SF.breakpoints` даёт те же шаги скрипту: компонент, которому нужно
знать, узкая ли страница, проверяет её по той же шкале, что и стили, и не
расходится с ними на границе.

## Вызов

```js
SF.breakpoints.ladder;                       // {xs: '0rem', sm: '32rem', md: '44rem', lg: '60rem', xl: '72rem', xxl: '80rem'}
SF.breakpoints.query('lg');                  // '(min-width: 60rem)'
SF.breakpoints.query('md', {below: true});   // '(max-width: 43.9375rem)'
SF.breakpoints.matches('lg');                // широка ли страница сейчас
SF.breakpoints.media('lg')?.addEventListener('change', redraw);
```

| Член | Что делает |
|:---|:---|
| `ladder` | Шаги шкалы в rem, как их пишут стили. |
| `query(name, {below})` | Медиазапрос шага: от этой ширины и шире, а с `below: true` — уже этой ширины, как `breakpoint-max` в стилях. |
| `media(name, {below, view})` | `MediaQueryList` того же запроса: на него подписываются, чтобы узнать о смене ширины. `view` — окно, по которому мерить (по умолчанию текущее). |
| `matches(name, {below})` | `true`, если страница сейчас такой ширины. |

## Когда доступно

Ядро: сразу после выполнения `core.js`, ждать не нужно.

## Особые случаи

- Неизвестное имя шага даёт `null` у `query` и `media` и `false` у
  `matches`: запроса, который выполняется всегда, нет.
- Ширина считается по окну документа: в примере — по ширине его рамки.
