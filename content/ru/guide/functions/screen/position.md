# Привязка к якорю

Выпадающие списки, меню, панели дат и подсказки Framework открываются у
своей кнопки одинаково: с нужной стороны, переворачиваются у края окна,
сдвигаются внутрь и не вылезают за экран. `SF.Position` даёт то же правило
своей панели проекта: панель встаёт у якоря и следует за ним при прокрутке и
изменении размера.

## Вызов

```js
const anchored = SF.Position.anchor(button, panel, {side: 'block-end', align: 'start'});
await anchored.update();   // пересчитать сейчас
anchored.side;             // сторона, с которой панель встала
anchored.stop();           // отпустить панель
```

| Настройка | Что делает |
|:---|:---|
| `side` | Сторона якоря: `block-end` (снизу, по умолчанию), `block-start`, `inline-start`, `inline-end`. В письме справа налево стороны отражаются. |
| `align` | Выравнивание вдоль якоря: `start` (по умолчанию), `center`, `end`. |
| `offset` | Расстояние до якоря: число пикселей или длина CSS, в том числе переменная (по умолчанию `var(--sf-space-1\/4)`). |
| `alignmentOffset` | Сдвиг вдоль края якоря. |
| `padding` | Отступ от краёв окна (по умолчанию `var(--sf-space-1\/2)`). |
| `flip`, `shift` | Перевернуть на другую сторону, если не помещается, и сдвинуть внутрь окна. Оба включены. |
| `matchWidth` | Ширина панели по ширине якоря. |
| `fitHeight` | Ограничить высоту местом, которое осталось в окне (включено). |
| `autoUpdate` | Следить за прокруткой и размерами (включено). |
| `topLayer` | Поднять панель в верхний слой страницы, пока она привязана (включено). |
| `onPosition({side, placement, x, y})` | Вызывается после каждого расчёта. |

`anchor` возвращает `{update(), stop(), side}`. Пока панель привязана, у неё
стоит `data-sf-side` с текущей стороной. `stop()` возвращает стили, которые
написала привязка, и опускает панель из верхнего слоя.

Другие члены: `resolveLength(value, context)` — длина CSS в пикселях;
`logicalSide` и `physicalPlacement` — перевод между логической стороной и
стороной на экране; `anchorReference`, `referenceRect` и `liftToTopLayer` —
части, из которых собран `anchor`.

## Когда доступно

Ядро: сразу после выполнения `core.js`, ждать не нужно.

## Пример

Кнопка открывает свою панель у себя. Кнопка «Сверху» привязывает её с
верхней стороны; у края рамки панель переворачивается. В журнале — сторона
после каждого расчёта.

## Особые случаи

- Якорь без своего прямоугольника — смарт-элемент с `display: contents`,
  например `sf-button`, — измеряется по тому, что он рисует.
- `anchor` бросает `TypeError`, если якорь — не элемент или панель — не
  HTML-элемент. Неизвестная сторона или выравнивание отклоняют расчёт
  (`update()`) с `TypeError`.
- Ограничения высоты и ширины из стилей панели сохраняются: привязка может
  только уменьшить их под окно.
