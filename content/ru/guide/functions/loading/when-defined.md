# Ожидание элемента

Смарт-элемент в разметке становится рабочим не сразу: Loader сначала
загружает его код. `SF.whenDefined` ждёт этого момента, после него у
элемента есть свойства и методы. Функция принимает короткие имена
Framework и полные имена элементов пакетов и ждёт сразу несколько тегов.

## Вызов

```js
const [tag] = await SF.whenDefined('datepicker');          // ['sf-datepicker']
const tags = await SF.whenDefined(['button', 'dropdown']); // ['sf-button', 'sf-dropdown']
```

| Аргумент | Что принимает |
|:---|:---|
| теги | Строка, массив строк или несколько строк подряд. Короткое имя (`datepicker`) означает элемент Framework (`sf-datepicker`); полное имя элемента пакета (`shop-catalog`) остаётся как есть, если его называет правило пакета. |

Обещание выполняется с массивом полных имён тегов в том же порядке — даже
для одного тега. Без аргументов — сразу с пустым массивом.

## Когда доступно

Loader: после события `sf-loader-init`, вместе с `SF.Loader`. Дождитесь его
через [`await SF.ready`](/ru/guide/functions/loading/ready/).

## Пример

Карточка показателя стоит в разметке: обещание выполняется, как только Loader
её загрузил, и пример читает значение элемента. Вторая кнопка ждёт тег,
которого на странице нет: через три секунды журнал показывает, что ответа
всё ещё нет.

## Особые случаи

- `SF.whenDefined` ничего не загружает. Обещание для тега, которого нет в
  разметке и который никто не загрузил, не выполнится никогда. Для такого
  элемента берите [`SF.Loader.ensure()`](/ru/guide/functions/loading/loader/)
  или [`SF.createAsync()`](/ru/guide/functions/loading/create/).
- Определён — ещё не нарисован. Чтобы читать размеры или содержимое, после
  определения дождитесь `await element.whenRendered()` (см. [Ожидание
  готовности](/ru/guide/smart-components/page/#ожидание-готовности)).
- Тег пакета, чьи правила ещё не пришли, ждётся под обоими именами
  (`shop-catalog` и `sf-shop-catalog`): выполняется первое определённое.
- Свой тег проекта без правила пакета (`project-greeting`) ждут через
  `customElements.whenDefined('project-greeting')`: `SF.whenDefined`
  прочтёт имя без правила как имя Framework.
