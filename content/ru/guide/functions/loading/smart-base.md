# Загрузка основы смарт-компонентов

Все смарт-компоненты страницы работают на одной общей основе: в ней базовый
класс, шаблоны и язык страницы. Обычно её приносит первый смарт-элемент.
Скрипту, которому основа нужна раньше — для своего смарт-компонента
проекта, — `SF.loadSmartBase()` загружает её сама, а `SF.smartBaseReady`
отвечает, когда она пришла, каким бы путём это ни случилось.

## Вызов

```js
const smart = await SF.loadSmartBase();   // то же, что SF.smart
const same = await SF.smartBaseReady;      // основа, как бы она ни пришла
```

| Имя | Что делает |
|:---|:---|
| `SF.loadSmartBase()` | Загружает основу, если её ещё нет, и выполняется с `SF.smart`. Повторный вызов ничего не загружает заново. |
| `SF.smartBaseReady` | Обещание основы: выполняется с `SF.smart`, когда основу принёс смарт-элемент или `SF.loadSmartBase()`. Само ничего не загружает. |

## Когда доступно

Loader: обе функции появляются после события `sf-loader-init`, сама основа —
после вызова. Дождитесь Loader через [`await SF.ready`](/ru/guide/functions/loading/ready/).

## Особые случаи

- На странице без смарт-элементов основа сама не загружается: без вызова
  `SF.loadSmartBase()` обещание `SF.smartBaseReady` ждёт.
- Если основа не загрузилась, `SF.loadSmartBase()` не отклоняется: оно
  выполняется с `null`, а в консоли появляется предупреждение
  `smart base load failed`. Проверяйте результат перед `extends`.
- Когда основа пришла, на `window` приходит событие `sf-smart-base-ready` —
  один раз на страницу. Обещание надёжнее: оно выполняется и для скрипта,
  который спросил позже.
