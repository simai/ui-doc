# Загрузка по требованию

Loader сам находит в разметке компоненты и загружает их код. Когда элемент
появляется не из разметки — меню, которое скрипт добавит позже, редактор в
открытом окне, — `SF.Loader` загружает его заранее и говорит, что пришло, а
что нет. Он же отдаёт объект компонента на классах, когда тот
зарегистрирован, и читает как страницу блок, в который элемент рисует своё
содержимое.

## Вызов

```js
const {ready, missing} = await SF.Loader.ensure(['datepicker', 'sf-dropdown'], {timeout: 3000});
SF.Loader.ready('Inputs', (Inputs) => { /* класс или объект компонента */ });
SF.Loader.ensurePlugin('toast');
const stop = SF.Loader.watch(panel);
SF.Loader.preloadIcons([{icon: 'mail'}]);
```

| Член | Что делает |
|:---|:---|
| `ensure(tags, {timeout})` | Загружает код элементов `tags` (строка или массив; короткое имя `datepicker` означает `sf-datepicker`) и выполняется с `{ready, missing}` — какие теги определены, а какие нет. Ждёт до `timeout` миллисекунд, по умолчанию 3000; `Infinity` ждёт без срока. Никогда не отклоняется. Уже определённый тег ничего не стоит. |
| `ready(name, callback)` | Вызывает `callback` с классом или объектом компонента на классах, когда он зарегистрирован, — сразу, если уже. `name` — имя в реестре (`Inputs`, `Toast`), оно может отличаться от имени объекта (`SF.Input`). Сам ничего не загружает. |
| `ensurePlugin(name)` | Загружает правило по имени — компонент, утилиту — так, как если бы его класс встретился в разметке. Возвращает `false`, если такого правила нет. |
| `watch(root)` | Отмечает блок, в который элемент рисует содержимое (панель, окно в конце `body`), и читает его как страницу: компоненты в нём загружаются и потом. Возвращает функцию, которая снимает отметку. |
| `unwatch(root)` | Снимает отметку `watch`. |
| `preloadIcons(entries)` | Добавляет значки в первый запрос шрифта иконок, если компонент узнаёт их только во время работы. Подробно — [Иконки](/ru/components/content/icons/#javascript). |
| `theme`, `themePreference`, `setTheme`, `changeTheme` | Тема страницы, см. [Тема](/ru/guide/functions/actions/theme/). |
| `clearCache()` | Стирает сохранённые в браузере списки правил; следующая загрузка страницы составит их заново. |
| `smartPath`, `minified` | Адрес папки смарт-компонентов поставки и признак сжатых файлов. |

`registerComponent` и `ensureSmartElementLoaded` нужны самим компонентам и
Loader; странице их вызывать не нужно.

## Когда доступно

Loader: `SF.Loader` появляется, когда Loader запустился, — после события
`sf-loader-init`. Дождитесь его через [`await SF.ready`](/ru/guide/functions/loading/ready/).

## Особые случаи

- `ensure` не бросает ошибку: тег без правила или не успевший загрузиться
  оказывается в `missing`. Нарисуйте то, что пришло, и запасной вид для
  остального.
- Для элемента, который уже стоит в разметке, `ensure` не нужен: Loader
  загрузит его сам. Дождаться его — [Ожидание элемента](/ru/guide/functions/loading/when-defined/).
- Без `watch` элемент, нарисованный внутри чужого блока после загрузки
  страницы, может остаться неопределённым тегом: Loader читает страницу, а не
  содержимое каждого элемента.
