# Создание элемента

Когда элемент компонента нужен не в разметке, а в скрипте — кнопка в
строке таблицы, поле в окне, — `SF.create` собирает его одним вызовом: тег по
короткому имени, атрибуты, обработчики событий, вложенное содержимое.
`SF.createAsync` делает то же и вдобавок загружает код компонента и ждёт,
когда тег будет определён.

## Вызов

```js
const button = SF.create('button', {
  text: 'Сохранить',
  appearance: 'filled',
  disabled: true,
  onClick: () => save(),
});

const tag = await SF.createAsync('tag', {text: 'Новое'});
list.append(tag);
```

| Параметр | Что делает |
|:---|:---|
| `name` | Короткое имя Framework (`button` — `sf-button`) или полное имя элемента пакета. Прежнее имя переименованного тега создаёт элемент с текущим. Пустое имя — ошибка `SF.create(name, params): name is required`. |
| ключи `params` | Каждый ключ — атрибут: `appearanceKind` пишется как `appearance-kind`, `className` — как `class`. `true` ставит пустой атрибут, `false`, `null` и `undefined` его не ставят, массив соединяется пробелами, объект в `style` становится строкой стилей. |
| `onИмя` с функцией | Обработчик события: `onClick` слушает `click`, `onSfTabsChange` — `sf-tabs-change`. |
| `attrs`, `attributes` | Те же атрибуты отдельным объектом. |
| `dataset` | Атрибуты `data-*`: `{rowId: 7}` — `data-row-id="7"`. |
| `children` | Узлы и строки внутрь элемента; вложенные массивы раскрываются. |
| `html`, `textContent` | Содержимое строкой: `html` — разметкой, `textContent` — текстом. |

`SF.create` возвращает элемент сразу, `SF.createAsync` — обещание этого
элемента после определения тега. Оба не вставляют элемент на страницу.

## Когда доступно

Loader: `SF.create` и `SF.createAsync` появляются после события
`sf-loader-init`. Дождитесь его через [`await SF.ready`](/ru/guide/functions/loading/ready/).

## Особые случаи

- `SF.create` не загружает код: элемент компонента, которого ещё нет на
  странице, остаётся неопределённым тегом, пока Loader его не найдёт. Если
  элемент нужен рабочим сразу, берите `SF.createAsync`.
- Значение атрибута — строка. Объект или массив данных передают свойством
  элемента после создания, а не ключом `params`.
- `html` вставляет разметку как есть. Текст из чужого источника сначала
  очистите через [`SF.sanitizeHtml`](/ru/guide/functions/text/sanitize-html/).
