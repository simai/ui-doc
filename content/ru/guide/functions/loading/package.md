# API набора

Наборы компонентов — pro, view, chat, mail, editor, effects, chart —
подключаются к странице отдельно от Framework, и у каждого могут быть свои
функции для скрипта. `SF.package('<набор>')` отдаёт их: это обещание
объекта, который набор зарегистрировал. Сами функции и их параметры
описывает документация набора.

## Вызов

```js
const effects = await SF.package('effects');
```

| Параметр | Что делает |
|:---|:---|
| `name` | Имя набора, как оно записано на странице: в `data-sf-sets` у скрипта ядра или в `SF_BOOT_CONFIG.packages`. |

Обещание выполняется с объектом функций набора — тем, что его сборка
передала в `SF.RuleLoader.registerPackage(name, {exports})`. Если код набора
ещё не загружен, Loader загружает его элемент API.

## Когда доступно

Ядро: `SF.package` можно вызвать сразу после выполнения `core.js`. До
запуска Loader вызов ждёт его.

## Пример

Первая кнопка спрашивает набор `pro`, который эта страница объявила, вторая —
набор `chart`, которого на странице нет. В журнале — что отдал набор и текст
ошибки для необъявленного.

Набор объявляют одной строкой у скрипта ядра:

```html
<script src=".../distr/core/js/core.min.js" data-sf-sets="effects"></script>
```

## Особые случаи

- Набор не объявлен на странице — обещание отклоняется с ошибкой, которая
  называет строку, которую нужно добавить: `data-sf-sets="<набор>"` у
  скрипта ядра или `SF_BOOT_CONFIG.packages.<набор> = true`.
- Набор объявлен, но не отдал функции за 10 секунд — обещание отклоняется с
  ошибкой `gave no exports within 10000 ms`.
