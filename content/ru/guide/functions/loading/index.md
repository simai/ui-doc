# Загрузка и готовность

Framework появляется на странице по частям: сначала ядро, потом Loader,
потом основа смарт-компонентов и сами компоненты. Функции этой группы
отвечают, когда нужная часть уже на месте, и загружают то, чего на странице
ещё нет.

- [Готовность Loader](/ru/guide/functions/loading/ready/) — дождаться, когда запустился Loader.
- [Загрузка по требованию](/ru/guide/functions/loading/loader/) — загрузить элемент, которого нет в разметке, и следить за новой частью страницы.
- [Ожидание элемента](/ru/guide/functions/loading/when-defined/) — дождаться определения тега, который уже стоит на странице.
- [Создание элемента](/ru/guide/functions/loading/create/) — создать элемент компонента из скрипта.
- [Загрузка основы смарт-компонентов](/ru/guide/functions/loading/smart-base/) — получить основу на странице без смарт-элементов.
- [Свой смарт-компонент](/ru/guide/functions/loading/smart/) — базовый класс и шаблон для компонента проекта.
- [API набора](/ru/guide/functions/loading/package/) — функции набора компонентов.
