# Язык интерфейса

Компоненты Framework говорят **по-английски по умолчанию** и **по-русски на
русской странице**. Это касается их собственных слов: доступных имён кнопок,
подписей по умолчанию, подсказок для клавиатуры, сообщений об ошибке.

## Как выбирается язык

Компонент смотрит на ближайший к нему атрибут `lang`, а если его нет — на
`lang` документа. Если язык русский (`ru`, `ru-RU`), компонент берёт русские
слова, во всех остальных случаях — английские.

```html
<html lang="ru">
  …
  <sf-tag kind="default" closable text="Отчёт"></sf-tag>
  <!-- кнопка удаления называется «Удалить» -->
</html>
```

Язык можно задать и для части страницы:

```html
<section lang="en">
  <sf-country-code></sf-country-code>
  <!-- поле называется Phone number, страны — по-английски -->
</section>
```

## Свои тексты важнее

Если подпись передана атрибутом, компонент показывает её как есть, на любом
языке. Язык страницы влияет только на слова, которые компонент подставляет
сам, когда ему ничего не передали.

## Где это уже работает

Выпадающее меню администратора, теги, телефон с кодом страны, календарь,
выдвижная панель, загрузка файлов, слайдер, подсветка кода и редактор
композиции. Таблица, пагинация и связанные с ними компоненты переходят на это
правило отдельно.
