# Фокус

Клавиатурный фокус — единственное, по чему человек без мыши понимает, где он
сейчас находится. Поэтому кольцо в Framework одно на всю систему, и компонент
его не изобретает: он берёт готовые переменные.

Кольцо появляется **только при работе с клавиатуры** — через `:focus-visible`.
На щелчке мышью его нет: там место назначения и так видно.

## Из чего собрано

```css
.project-control:focus-visible {
    outline: var(--sf-focus--width) var(--sf-focus--style) var(--sf-focus--color);
    outline-offset: var(--sf-focus--offset);
}
```

Четыре переменные, и ничего больше. Значения и замеры, которые за ними стоят, —
на странице [Focus](/ru/reference/color-primitives/focus/).

Три вещи в этих значениях стоит понимать, потому что каждая появилась из
измерения, а не из вкуса.

**Кольцо сплошное, не полупрозрачное.** При 24% прозрачности оно давало 1.4:1 к
светлой поверхности, тогда как индикатору нужно 3:1.

**Два пикселя, не четыре и не один.** Это нижняя граница площади индикатора,
которую требует WCAG 2.2: кольцо в один пиксель её не набирает.

**Пиксель зазора, не вплотную.** Прижатое кольцо тонет в заливке того же цвета:
переключатель на синей дорожке давал 1.0:1. Зазор показывает поверхность под
элементом, и кольцу всегда есть на чём читаться.

## Кольцо не тень

Тень делит своё свойство с высотой элемента, рисуется поверх соседей и
пропадает в режиме высокой контрастности. Поэтому кольцо — `outline`, а
`--sf-ui-focus` остался только для совместимости.

В утилитах тот же выбор: `focus-visible:outline-*` рисует настоящий контур,
`focus-visible:ring-*` — тень. Для кольца берите первое.

## Элемент вплотную к соседям

Сегмент группы кнопок, вкладка, ячейка календаря, строка списка — там внешнее
кольцо съело бы соседа или его обрезал бы контейнер с прокруткой. Меняется
только знак смещения, всё остальное то же:

```css
.project-segment:focus-visible {
    outline-offset: calc(var(--sf-focus--width) * -1);
}
```

## Залитый элемент

Цвет кольца выбран так, чтобы читаться на поверхности. У залитого элемента
заливка может оказаться соседней ступенью той же палитры — в тёмной теме
основная кнопка залита `--sf-primary-80`, а кольцо рисуется `--sf-primary-90`,
и это 1.31:1. Кольцо читается как часть кнопки.

Одним цветом это не решается: к тёмной поверхности кольцо должно быть светлым,
к светлой заливке — тёмным. Поэтому залитый элемент рисует внутри вторую линию
чернилами собственной подписи — они контрастны его заливке по построению. Два
слоя прикрывают друг друга: где не тянет кольцо, тянут чернила, и наоборот.

Линия идёт через собственную переменную тени компонента и складывается с его
высотой, а не заменяет её.

## Кто рисует кольцо

Глобальное правило красит тот элемент, который держит фокус. Если компонент
рисует кольцо на видимой обёртке — у поля ввода это рамка поля, а не сам
`input` — он обязан снять кольцо с контрола внутри:

```css
.project-field:has(input:focus-visible) .project-field-box {
    outline: var(--sf-focus--width) var(--sf-focus--style) var(--sf-focus--color);
    outline-offset: var(--sf-focus--offset);
}

.project-field input:focus-visible {
    outline: none;
}
```

Без второго правила колец будет два: одно вокруг поля, другое вокруг голого
ввода. То же касается флажка, радио и переключателя: там фокус держит скрытое
нативное поле, а кольцо принадлежит видимой коробке или дорожке.

## Чего не делать

- Не убирать кольцо без равноценной замены. `outline: none` в одиночку — это
  элемент, которого с клавиатуры не видно.
- Не рисовать кольцо тенью: оно закроет соседа и исчезнет в высокой
  контрастности.
- Не заводить свой цвет. Проект меняет `--sf-focus--color` один раз, и это
  действует везде.
- Не подменять `:focus-visible` на `:focus`: кольцо начнёт появляться на
  щелчке мышью.
