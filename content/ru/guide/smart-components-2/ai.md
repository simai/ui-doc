# Для ИИ

У стандарта есть сжатая машиночитаемая сводка —
`simai.smart-component.ai.json` (схема `simai.smart-component.ai.v1`). Она
нужна ИИ, который ставит смарт-компоненты на страницу, собирает из них
сборки и пишет правила. Нормативен полный стандарт; сводка обязана с ним
совпадать.

## Что в сводке

| Раздел | Что содержит |
|:---|:---|
| `model` | четыре части интерфейса, виды `leaf` и `assembly`, типы |
| `assembly` | ключи и их хозяева, форма роли, правила: поводы, шаги, чтения, условия, порядок выполнения, рамка, коды экземпляров |
| `host_answers`, `data_states` | четыре ответа хоста и семь состояний данных |
| `events`, `verbs` | шаблон имён событий, запреты и все глаголы словаря с содержимым и русским словом |
| `page` | кнопка `data-sf-action` и три вида слотов |
| `look`, `language`, `naming` | вид, порядок выбора языка, правила имён и зарезервированные имена |
| `limits` | числовые пределы: окно с 300 записей, 30 узлов на запись, время отрисовки |
| `recipes` | готовые рецепты частых задач |
| `do_not` | чего делать нельзя |
| `source_files` | где лежат стандарт, словарь и краткая версия |

## Отрывок

```json
{
  "schema": "simai.smart-component.ai.v1",
  "standard": "simai.smart-component 1.3.5",
  "vocabulary": "simai.smart-vocabulary 1.1.2",
  "events": {
    "request": "sf-<tag>-<verb>",
    "fact": "sf-<tag>-<verb>ed",
    "no": ["colons", "-intent suffix", "role names in DOM event names"]
  },
  "recipes": [
    {"task": "open a modal from a page button",
     "do": "<button data-sf-action=\"<modal-id>.open\">"},
    {"task": "confirm before a destructive action",
     "do": "rule step ask <confirm-role>.open with answer key; then check the answer key is yes"}
  ],
  "limits": {"window_from_entries": 300, "nodes_per_entry": 30}
}
```

## Как ИИ пользуется сводкой

1. **Читает модель.** Любой компонент — четыре списка: настройки, значения,
   события, действия. ИИ не ищет у компонента ничего сверх них.
2. **Берёт интерфейс из манифеста.** Конкретные имена настроек и событий —
   в `component.json` компонента; сводка задаёт правила, по которым эти имена
   устроены.
3. **Собирает по рецептам.** Для частых задач — показать записи с сервера,
   запомнить выбранную запись, спросить подтверждение — в `recipes` есть
   готовая схема из ролей, ключей и правил.
4. **Проверяет себя по `do_not`.** Например: не копировать содержимое
   страницы, не делать компонент в продукте, не связывать детали напрямую,
   не класть элементы страницы в `detail`, не применять действие под
   фильтром при приблизительном числе.
5. **Сверяется со словарём.** Глагол события берётся из `verbs`; свой
   глагол — только если ни один из словаря не подходит.

## Где лежит сводка

Сводка, стандарт, словарь и краткая русская версия переезжают в
`simai/ui-source` в папку `src/core/contracts/standards/simai.smart-component/1.3.5/`.
