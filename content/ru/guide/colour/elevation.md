# Поверхность и тень

Тень показывает, где элемент стоит относительно страницы: лежит на ней,
приподнят, всплывает поверх или держит страницу, пока его не закроют. Во
Framework таких мест четыре, и у каждого — своя тень и своя поверхность.
Компоненты берут только эти четыре тени, поэтому одинаковые места выглядят
одинаково во всех продуктах и в обеих темах. Какой фон у каждого места и что
кладётся поверх него — на странице [Фоны](/ru/guide/colour/surfaces/).

## Четыре места

| Место | Тень | Поверхность | Где |
|:---|:---|:---|:---|
| На странице | `--sf-shadow-flat` — тени нет, край рисует линия `--sf-outline-variant` | `--sf-surface-page`, `--sf-surface-area`, `--sf-surface-card` | страница, область, карточка в покое |
| Приподнятое | `--sf-shadow-raised` | `--sf-surface-raised` | карточка-ссылка под указателем, шапка сайта, пока под ней прокручивается содержимое, ручка ползунка, плашка выбранного сегмента |
| Всплывающее | `--sf-shadow-overlay` | `--sf-surface-popup` | выпадающий список, меню, контекстное меню, поповер, подсказка, календарь, уведомление |
| Окно | `--sf-shadow-modal` | `--sf-surface-popup` | диалог, шторка; всегда над затемнением |

Смещения и размытия теней — ступени линейки размеров:

| Тень | Короткая (ключевая) | Широкая (рассеянная) |
|:---|:---|:---|
| `--sf-shadow-raised` | `0 1px 2px` | `0 2px 8px` |
| `--sf-shadow-overlay` | `0 2px 4px` | `0 8px 16px` |
| `--sf-shadow-modal` | `0 4px 8px` | `0 16px 32px` |

Чем выше место, тем дальше и мягче тень. Шагов три: лежащее, приподнятое,
всплывающее и окно глаз различает уверенно, а более мелкие ступени — уже нет.

## Два цвета тени

Каждая тень состоит из двух слоёв, и у каждого слоя свой цвет — ступень
чёрного из [шкалы прозрачности](/ru/guide/colour/transparency/):

| Цвет | Светлая тема | Тёмная тема | Что делает |
|:---|:---|:---|:---|
| `--sf-shadow-key-color` | чёрный 16 | чёрный 28 | короткий тёмный край прямо под элементом |
| `--sf-shadow-ambient-color` | чёрный 8 | нет | широкое мягкое облако вокруг |

В тёмной теме рассеянной тени нет: чёрное облако на почти чёрной странице не
видно. Там место показывает поверхность — каждая следующая на ступень
светлее: карточка, приподнятое, всплывающее. Поэтому всё, что стоит выше
страницы, берёт **и тень, и поверхность своего места**.

Тень не несёт цвета. Цветное свечение читается как фокус или как статус,
поэтому цветных теней в системе нет: фокус показывает
[кольцо](/ru/utilities/outline/ring/), статус — цвет самого элемента.

## Затемнение

Окно и шторка держат страницу: пока они открыты, страница под ними не
работает. Это показывает затемнение `--sf-scrim-color` — чёрный 64 из шкалы
прозрачности, одинаковый в обеих темах. Окно над затемнением отделяет от
страницы именно затемнение, а не более тёмная тень, поэтому у окна тень
`--sf-shadow-modal`, а не своя.

## Какие компоненты где стоят

| Место | Компоненты |
|:---|:---|
| На странице | карточка в покое, шапка сайта в начале страницы, нижняя панель меню админки (отделена линией) |
| Приподнятое | карточка-ссылка и карточка-кнопка под указателем, шапка сайта при прокрутке, плашка сегментного переключателя, полоса пагинации, кнопка вставки в сортируемом списке, стрелки и точки слайдера, ручки ползунка диапазона, значок-акцент |
| Всплывающее | подсказка, поповер, выпадающий список, подменю, контекстное меню, выбор кода страны, календарь, уведомление, оглавление, знак справки, выбор профиля, поиск, поле с поиском, переход по ленте, редакторы поверх страницы, значение ползунка диапазона |
| Окно | диалог (`sf-modal`), шторка (`sf-drawer`), панель шапки сайта на телефоне, шторка редактора композиции |

## Как применять

Утилиты ставят тень места одним классом:
[`shadow-flat`, `shadow-raised`, `shadow-overlay`, `shadow-modal`](/ru/utilities/shadows/element-shadow/)
и те же имена у [падающей тени](/ru/utilities/shadows/drop-shadow/).
[`elevation-N`](/ru/utilities/shadows/elevation/) ставит тень вместе с
поверхностью и приглушённым текстом на ней.

В своих стилях берите тень и поверхность одного места вместе:

```css
.project-popup {
  background: var(--sf-surface-popup);
  box-shadow: var(--sf-shadow-overlay);
  --sf-on-surface-variant: var(--sf-on-surface-popup-variant);
}

.project-tile:hover {
  background: var(--sf-surface-raised);
  box-shadow: var(--sf-shadow-raised);
}
```

Правила:

- компонент берёт одну из четырёх теней и ничего больше: ни `rgb()`, ни
  `color-mix`, ни своих смещений;
- карточка в потоке страницы стоит на странице: край — линия
  `--sf-outline-variant`, тень появляется только у карточки-ссылки под
  указателем;
- окно и шторка всегда открываются над затемнением.

## Настройка в теме

Тема меняет систему теней двумя цветами на классах темы, не трогая компоненты. Например,
сделать тени мягче в светлой теме:

```css
@layer project {
  .theme-light,
  .theme-dark {
    --sf-shadow-key-color: light-dark(var(--sf-black--alfa-12), var(--sf-black--alfa-28));
  }
}
```

Одну тень места можно переопределить целиком — она поменяется во всех
компонентах этого места:

```css
@layer project {
  .theme-light,
  .theme-dark {
    --sf-shadow-overlay: 0 var(--sf-a2) var(--sf-a8) var(--sf-shadow-key-color);
  }
}
```
