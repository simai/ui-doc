# Страница, секция, блок и компонент

Макет читается сверху вниз. Страница задаёт общий контейнер. Секции делят её на смысловые части. Блок объединяет законченную функцию, например выдачу каталога. Компоненты формируют конкретные элементы внутри блока.

## Когда применять

Используйте уровни для ясной ответственности. Если часть нужна только для расположения соседей, достаточно секции. Если она решает самостоятельную задачу и должна повторяться на разных страницах, оформляйте блок. Повторяемый элемент интерфейса выбирайте из каталога компонентов.

## Пример

На странице каталога секция может содержать заголовок и блок выдачи. Блок выдачи объединяет фильтры, список и пагинацию. Кнопка сброса фильтра остаётся компонентом. В первой версии стандарт напрямую предоставляет типы страницы, секции, колонок, заголовка и абзаца. Блоки и Smart-компоненты подключаются как зарегистрированные типы после подтверждения их контракта.
