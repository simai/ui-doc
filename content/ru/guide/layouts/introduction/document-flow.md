# Как проходит сборка

Сборка идёт по одному пути. Framework читает Recipe, получает разрешённые проектом настройки и содержимое, раскрывает только выбранные шаблоны и создаёт готовый Document. Затем рендерер — программа, создающая разметку — превращает Document в HTML. Ошибка на любом шаге останавливает сборку целиком.

## Когда применять

Этот порядок нужен при предварительном просмотре, публикации и пересборке после изменения шаблона или содержимого. Он позволяет точно узнать, какие данные участвовали в результате, и не активировать неполную страницу.

## Пример

Настройка `headerMode` выбирает одну из двух шапок. `resolveRecipe()` читает только выбранный фрагмент и текст статьи, возвращает готовый Document и перечень использованных зависимостей. После этого `render()` строит HTML без новых обращений к данным.

```text
Recipe + настройки + содержимое
              ↓ resolveRecipe()
     Document + список зависимостей
              ↓ render()
        HTML + ресурсы
```

Если доступ к тексту запрещён или ревизия шаблона не совпала, результата нет: `document` имеет значение `null`, а диагностика указывает причину.

## Если Recipe создаёт продукт

Не каждый сайт обязан хранить отдельный Recipe для каждой страницы. Docara
читает Markdown и унаследованные настройки сайта, раздела и страницы,
создаёт из них Recipe и передаёт общему сборщику Framework. Полученный
Document описывает страницу, её области, секции и блоки. Зарегистрированные
рендереры Docara создают из этого проверенного дерева статический HTML.

```text
Markdown + настройки Docara
             ↓ адаптер Docara
           Recipe
             ↓ resolveRecipe()
          Document
             ↓ рендереры Docara
       статический HTML
```

Чтение исходников и наследование настроек остаются обязанностью продукта.
Общий стандарт отвечает за проверяемую сборку дерева. После получения
Document рендереры не выбирают варианты заново и не запрашивают новые данные.
Отчёт страницы содержит отпечатки Recipe и Document, поэтому можно проверить,
из каких именно входов получен результат.
