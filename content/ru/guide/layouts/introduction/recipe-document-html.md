# Recipe, Document и HTML

`Recipe` — это инструкция по сборке страницы. В ней указаны шаблоны, места вставки, настройки и ссылки на содержимое. `Document` — уже собранное дерево: все варианты выбраны, данные подставлены, а узлы получили устойчивые идентификаторы. `HTML` — то, что renderer показывает в браузере.

## Когда применять

Recipe нужен, когда одна страница может выглядеть по-разному. Готовый Document удобно проверять, кешировать и публиковать. HTML создаётся в самом конце и не используется как исходное описание страницы.

## Пример

Для статьи Recipe говорит: «возьми общий шаблон, выбери шапку по настройке и вставь текст статьи». При значении `compact` Document содержит короткую шапку. При значении `expanded` в том же месте появляется ещё и поясняющая строка. Основной текст остаётся тем же.

| Представление | Что хранит | Кто с ним работает |
|:---|:---|:---|
| Recipe | правила сборки и ссылки на входные данные | редактор и продукт |
| Document | готовое проверенное дерево интерфейса | Framework и механизм публикации |
| HTML | итоговую разметку | браузер |

Полные исходные данные и ожидаемые результаты доступны в [проверяемом JSON](/demos/guide/composition-recipe/header-switch.json). Этот файл предназначен для тестов, инструментов разработки и ИИ; для понимания трёх представлений достаточно таблицы выше.
