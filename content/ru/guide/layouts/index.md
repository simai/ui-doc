# Макеты

Раздел объясняет, как собрать страницу из шаблонов, блоков, содержимого и настроек. Вы увидите весь путь: Recipe описывает правила сборки, Framework получает из него готовый Document, а renderer превращает Document в HTML.

## Когда применять

Начните отсюда, если внешний вид страницы зависит от настроек сайта, одни блоки используются повторно или макет создаётся в системе управления сайтом. Готовый HTML хранить как исходные данные не нужно.

## Пример

Основной пример — страница статьи с двумя вариантами шапки. Один Recipe содержит общий шаблон страницы, место для шапки и место для текста. Настройка выбирает краткую или расширенную шапку, а содержимое статьи приходит из проекта. Framework собирает один готовый Document и показывает его.
