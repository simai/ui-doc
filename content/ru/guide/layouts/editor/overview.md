# Как устроен редактор страниц

Визуальный редактор страниц в Framework не хранит собственную копию страницы и не меняет её HTML. Страница по-прежнему описана Document, а редактор только показывает, что можно выбрать, переместить, вставить или исправить. Каждое действие человека превращается в намерение — событие с понятными данными. Приложение применяет намерение к своей копии Document, проверяет результат, сохраняет его и заново отрисовывает страницу.

Редактор собирается из четырёх Smart-компонентов: [оверлея](/ru/smart-components/editor/composition-overlay/), [перетаскивания](/ru/smart-components/editor/sortable/), [inline-редактора](/ru/smart-components/editor/inline-editor/) и закреплённого [Drawer](/ru/smart-components/overlays/drawer/). Их код загружается только на странице редактора, поэтому обычные страницы сайта не получают лишний JavaScript.

## Когда применять

Используйте эти компоненты, когда страницу собирает человек в системе управления сайтом: переставляет секции, добавляет блоки из библиотеки, правит заголовки и абзацы. Если страница полностью строится из Recipe и настроек без ручной правки, редактор не нужен.
