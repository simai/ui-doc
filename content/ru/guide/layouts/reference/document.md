# Документ макета

Документ `simai.composition.document.v1` содержит `schema`, `id`, `profile`, необязательный `locale`, корневой узел `root` и расширения с пространством имён. Эти поля образуют переносимую оболочку для любого поддерживаемого дерева.

## Когда применять

Сверяйтесь с этой страницей при создании генератора, хранении макета или диагностике ошибки верхнего уровня. Размер документа ограничен 1 МиБ, глубина — 32 уровнями, число узлов — 2 000, а один слот принимает до 500 детей.

## Пример

`profile: "ui-layout"` выбирают для интерфейса, `structured-content` — для самостоятельного структурированного материала. Все ID внутри документа уникальны. Неизвестная обязательная возможность останавливает обработку; необязательное расширение с пространством имён сохраняется.
