# Инспектор макета

Инспектор позволяет изменить JSON и сразу увидеть результат в этой документации. Он использует ту же зафиксированную сборку Core, поэтому показывает реальную проверку, нормализацию и рендеринг, а не иллюстрацию, написанную отдельно.

## Когда применять

Открывайте инспектор при изучении примера, подготовке fixture, обсуждении ошибки с разработчиком или передаче задания ИИ. Для публикации и прав доступа по-прежнему нужен проект.

## Как читать документ

Измените JSON в примере ниже и запустите проверку. Контрольная сумма digest помогает сравнить документы, HTML показывает результат рендеринга, а диагностика указывает ошибочное поле. Предпросмотр находится в изолированном iframe и не выполняет скрипты из результата.
