# Инспектор макета

**Инспектор макета** позволяет изменить JSON и сразу увидеть результат. Он
работает на той же закреплённой поставке Core, поэтому показывает настоящие
проверку, нормализацию и отрисовку: отпечаток документа, полученный HTML и
диагностику с путём к ошибочному полю. Предпросмотр находится
в изолированном iframe и не выполняет скрипты из результата. Простые стили предпросмотра нужны
для чтения структуры; оформление и поведение подключает проект.

Попробуйте заменить тип узла на `unknown.type` — появится ошибка с путём к
полю.

Инспектор находится в документации, на страницах макетов, вместе с готовыми
примерами: в списке «Пример» — каталог, информационная страница и составной
интерфейс.
