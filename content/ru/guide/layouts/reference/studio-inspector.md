# Инспектор макета в Studio

Инспектор соединяет документацию с рабочим Framework. Он использует ту же зафиксированную сборку Core, поэтому показывает реальную проверку, нормализацию и рендеринг, а не иллюстрацию, написанную отдельно.

## Когда применять

Открывайте инспектор при изучении примера, подготовке fixture, обсуждении ошибки с разработчиком или передаче задания ИИ. Для публикации и прав доступа по-прежнему нужен проект.

## Пример

Перейдите в [Studio](https://ui-studio.test/?mode=layout&example=catalog), выберите пример, измените JSON и запустите проверку. Дерево помогает увидеть вложенность, digest — сравнить результат, HTML — проверить renderer, а блок диагностики — найти точное поле. Предпросмотр находится в изолированном iframe и не выполняет скрипты из результата.
