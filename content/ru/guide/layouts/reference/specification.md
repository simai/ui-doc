# Где взять спецификацию

Руководство объясняет, как пользоваться макетами. Точные правила лежат в
**нормативных комплектах** Framework:

- **Recipe** (стандарт `simai.composition-recipe`) — описание алгоритма, схемы Recipe, входов и
  перечня зависимостей, лимиты, контрольные примеры с ожидаемым результатом и
  lock-файл с отпечатками всех нормативных файлов.
- **Composition Regions**, **Composition Routing**, **поля редактора** —
  отдельные комплекты для областей, маршрутов и полей свойств.

Комплекты лежат в поставке `ui` (`distr/core/contracts/composition-*`) и в каталоге
документации для ИИ (`/ai/standards/composition-recipe/<версия>/`); корневой
индекс находит их по идентификатору
`urn:simai:framework:composition-recipe:specification`. Каталог — это знание,
а не разрешение менять сайт: доступ к данным и публикацию контролирует
проект.

Комплект Recipe на сайте документации:

| Файл | Что проверяет |
|:---|:---|
| [описание алгоритма](/ai/standards/composition-recipe/1.0.1/README.md) | полный алгоритм сборки; его читают первым |
| [схема Recipe](/ai/standards/composition-recipe/1.0.1/recipe.schema.json) | сам план сборки |
| [схема входов](/ai/standards/composition-recipe/1.0.1/inputs.schema.json) | снимок разрешённых данных и настроек проекта |
| [файл фиксации](/ai/standards/composition-recipe/1.0.1/contract.lock.json) | точные отпечатки всех нормативных файлов |
| [пример шапки](/ai/standards/composition-recipe/1.0.1/fixtures/header-switch.json) | ожидаемые Document и перечень зависимостей для обоих вариантов шапки |

Редакция 1.0.1 уточняет статус работающего сборщика; правила JSON те же, что
в редакции 1.0.0.

По контрольному примеру можно проверить собственный сборщик или убедиться,
что ИИ не придумал поле, тип узла или способ получения данных. В примере шапки
настройка `headerMode` выбирает шаблон; источник второго варианта не
читается:

| Значение `headerMode` | Используемый шаблон | Неиспользуемый источник |
|:---|:---|:---|
| `compact` | `header.compact` | `header.expanded` |
| `expanded` | `header.expanded` | `header.compact` |

Сравните свой результат с ожидаемыми Document и перечнем зависимостей,
прежде чем подключать сборку к сайту. Комплект открывают, когда создают Recipe
в своём проекте, пишут адаптер продукта или передают задачу ИИ ([Работа с ИИ](/ru/guide/standards/ai/#работа-с-ии)).

Место Recipe среди стандартов Framework и требования, которые на него
опираются, описаны в [Recipe (`simai.composition-recipe`)](/ru/guide/standards/map/#recipe-simai-composition-recipe).
