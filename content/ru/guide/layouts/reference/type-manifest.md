# Manifest типа

Описание типа, или manifest `simai.composition.type-manifest.v1`, объясняет проверяющему и функции рендеринга, что означает один тип узла. В нём перечислены профили, данные, свойства, слоты, виды, пресеты, модификаторы и необходимые ресурсы.

## Когда применять

Создавайте описание типа до использования собственного блока или компонента в сохраняемых макетах. Это общий контракт для разработчика, редактора макетов, документации и ИИ: все участники видят одинаковые разрешённые поля.

## Пример

Тип колонок объявляет слот `columns`, число колонок и модификатор адаптивности. Тип кнопки объявляет `sf-button` как способ рендеринга и только подтверждённые параметры. Если описание разрешает слот, которого нет в реализации, контракт считается неверным — поэтому Smart-компоненты подключаются по одному после теста.

```json
{
  "schema": "simai.composition.type-manifest.v1",
  "type": "project.product-grid",
  "version": "1.0.0",
  "category": "component",
  "mode": "composite",
  "profiles": ["ui-layout"],
  "data_schema": {"type": "object"},
  "props_schema": {"type": "object"},
  "presentation": {"views": ["default"], "presets": ["cards"], "modifiers": []},
  "slots": {"items": {"min": 0, "max": 100}},
  "renderer": {"kind": "registered", "name": "project.product-grid"},
  "assets": ["project/product-grid"],
  "capabilities": []
}
```

Это сокращённый учебный пример. Полное описание также задаёт схемы данных и свойств, разрешённые варианты оформления и ограничения дочерних типов.
