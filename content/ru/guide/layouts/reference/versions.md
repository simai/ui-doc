# Версии и совместимость

Версия формата находится в поле `schema`, а точное содержимое нормализованного документа подтверждает SHA-256 digest. Версия Framework и digest схем показывают, с каким контрактом выполнялась проверка.

## Когда применять

Храните версию документа вместе с данными и фиксируйте точную версию Framework в проекте. При обновлении сначала прогоняйте сохранённые примеры и только затем переключайте рабочую сборку.

## Пример

Нормализация одного документа должна давать одинаковый JSON и digest в Node.js и браузере. Добавление необязательной возможности может быть совместимым; удаление типа, слота или допустимого значения требует новой версии контракта и плана преобразования данных.
