# Версии и совместимость

Формат указывается в поле `schema`, а точное содержимое подтверждает SHA-256 digest. Для воспроизводимой сборки перечень зависимостей также фиксирует отпечатки контракта, реестра типов и renderer. Номер пакета сам по себе этого не доказывает.

## Когда применять

Храните schema ID и перечень зависимостей вместе с результатом. Точную поставку Framework фиксируйте в BOM проекта, а меняющиеся номера пакетов показывайте на общей странице совместимости. При обновлении сначала прогоняйте контрольные примеры и только затем активируйте новый результат.

## Пример

Нормализация одного документа должна давать одинаковый JSON и digest в Node.js и браузере. Добавление необязательной возможности может быть совместимым; удаление типа, слота или допустимого значения требует новой версии контракта и плана преобразования данных.

```json
{
  "schema": "simai.composition.dependencies.v1",
  "documentDigest": "sha256:результат-нормализации",
  "executionContract": {
    "contractDigest": "sha256:контракт",
    "registryDigest": "sha256:реестр-типов",
    "rendererDigest": "sha256:renderer"
  }
}
```

Schema ID меняется только при изменении правил формата. Digest меняется при изменении конкретного содержимого. Это уменьшает число версий в тексте документации и оставляет точную проверку машинным контрактам.
