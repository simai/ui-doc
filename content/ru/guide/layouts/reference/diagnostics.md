# Ошибки и диагностика

Каждая ошибка содержит код, путь до проблемного значения, цепочку ссылок на шаблоны и понятное сообщение. Путь позволяет редактору подсветить конкретное поле, а код остаётся устойчивым для автоматической обработки.

## Когда применять

Показывайте диагностику рядом с исходным JSON и блокируйте публикацию при ошибках. Не заменяйте подробности одним сообщением «неверный документ»: разработчику и ИИ нужен точный путь исправления.

## Пример

Если шаблон статьи ссылается сам на себя, сборка возвращает `reference_cycle`, путь к ссылке и всю цепочку вызовов. Если продукт отказал в доступе к тексту, возвращается `access_denied`. Ни одна из этих ошибок не создаёт частично готовый Document.

```json
{
  "code": "reference_cycle",
  "sourcePath": "/root/ref",
  "referenceChain": ["template:article@r1"],
  "message": "Reference cycle detected"
}
```

Для готового Document также проверяются небезопасные ссылки, повторяющиеся ID, неизвестные типы и слоты, превышение лимитов и отсутствующий renderer.
