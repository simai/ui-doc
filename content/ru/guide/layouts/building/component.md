# Компонент в макете

Обычный компонент даёт готовую разметку и оформление повторяемого элемента. В макете он представлен зарегистрированным типом, поэтому проверяющий код заранее знает допустимые свойства, варианты и области содержимого.

## Когда применять

Используйте компонент для кнопки, карточки, поля или меню, если ему не нужно самостоятельно управлять сложным состоянием. Справочник компонента остаётся главным источником его параметров; раздел «Макеты» объясняет только участие в дереве.

## Пример

Тип `project.product-card` может принимать название, цену и изображение через данные, а вид карточки — через `presentation`. Проверка отклонит неизвестное свойство или вариант до рендеринга. Сама HTML-разметка карточки остаётся у renderer типа и не дублируется в JSON.

```json
{
  "id": "product-42",
  "type": "project.product-card",
  "data": {"title": "Кресло", "price": "12 900 ₽"},
  "presentation": {"preset": "catalog"}
}
```

Такой узел станет допустимым только после регистрации manifest и renderer типа `project.product-card`.
