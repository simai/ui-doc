# Компонент

Обычный компонент (см. [Что такое компонент](/ru/guide/components/what-is/#что-такое-компонент)) попадает в макет как **зарегистрированный тип**.
Манифест типа заранее говорит, какие данные, настройки и варианты допустимы;
HTML-разметка компонента остаётся у рендерера типа и не дублируется в JSON.
Компонент в макете подходит для кнопки, карточки, поля или меню, которым не
нужно самим управлять сложным состоянием; для элемента с состоянием есть
[Smart-компонент в макете](/ru/guide/layouts/building/smart-component/).

```json
{
  "id": "product-42",
  "type": "project.product-card",
  "data": {"title": "Кресло", "price": "12 900 ₽"},
  "presentation": {"preset": "catalog"}
}
```

Такой узел допустим только после регистрации манифеста и рендерера типа
`project.product-card` ([Собственный тип](/ru/guide/layouts/reference/custom-type/)). Проверка отклоняет неизвестное
свойство или вариант до отрисовки. Справочник компонента остаётся главным источником его
параметров; эта часть объясняет только участие в дереве.
