# Страница

`layout.page` — корневой тип макета интерфейса. Он обозначает границу одного документа и содержит верхнеуровневые элементы в области `default`. У документа всегда один корень и уникальный идентификатор.

## Когда применять

Выбирайте страницу для полного экрана или самостоятельного содержимого, которое публикуется по отдельному адресу. Для фрагмента, вставляемого внутрь уже существующей страницы, используйте секцию или собственный тип блока.

## Пример

```json
{
  "schema": "simai.composition.document.v1",
  "id": "about-page",
  "profile": "ui-layout",
  "root": {
    "id": "page",
    "type": "layout.page",
    "slots": {"default": []}
  }
}
```
Поле `profile` сообщает, что документ описывает интерфейс. Массив `default` хранит элементы в том же порядке, в котором они будут показаны.
