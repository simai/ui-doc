# Страница

`layout.page` — корневой тип интерфейсного документа. У документа всегда
ровно один корень. Страницу выбирают для полного экрана или самостоятельного
материала, который публикуется по своему адресу. Фрагмент, вставляемый внутрь
существующей страницы, — это секция или блок ([Блок](/ru/guide/layouts/building/block/)).

```json
{
  "schema": "simai.composition.document.v1",
  "id": "about-page",
  "profile": "ui-layout",
  "root": {
    "id": "page",
    "type": "layout.page",
    "slots": {"default": []}
  }
}
```

Поле `profile` со значением `ui-layout` говорит, что документ описывает
интерфейс. Массив `default` хранит элементы в том порядке, в котором они
показываются. Встроенная страница выводится тегом `<main>`; если на странице
проекта `<main>` уже есть, корнем документа делают секцию.

У встроенной страницы есть только слот `default`. Если в шаблоне Recipe автор
объявил места вроде `header` и `main`, при сборке они превращаются в обычных
детей `default` в нужном порядке.
