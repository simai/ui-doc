# Шаблоны, вставки и варианты

Шаблон задаёт общую форму страницы или секции. Именованные места вставки показывают, куда передать шапку, основное содержимое или другой блок. Фрагмент хранит повторно используемую часть без параметров. Если часть должна принимать параметры или вложенные элементы, используйте шаблон.

## Когда применять

Используйте шаблоны для общей структуры, фрагменты — для неизменяемых повторных частей, а выбор варианта — когда результат зависит от настройки сайта. В Recipe нет условий на JavaScript: допустимые значения заранее перечислены, и каждому соответствует понятная ветвь.

## Пример

Шаблон статьи объявляет места `header` и `main`. В `header` Recipe передаёт выбор между `header.compact` и `header.expanded`, а в `main` — текст статьи. Отсутствующий аргумент использует значение шаблона по умолчанию, пустой массив намеренно очищает место.

```json
"slots": {
  "header": [{
    "id": "header-choice",
    "select": {
      "value": { "input": "headerMode" },
      "cases": {
        "compact": { "id": "chosen", "ref": { "kind": "fragment", "owner": "example/library", "ref": "header.compact", "policy": "pinned", "revision": "r1" } },
        "expanded": { "id": "chosen", "ref": { "kind": "fragment", "owner": "example/library", "ref": "header.expanded", "policy": "pinned", "revision": "r1" } }
      }
    }
  }]
}
```

Framework проверяет синтаксис обеих ветвей, но загружает источник только активного варианта. Поэтому изменение неиспользуемой шапки не заставляет пересобирать страницу.
