# Блок

Блок — законченная часть страницы, которую можно использовать повторно: форма заявки, список новостей или каталог. Стандарт не заставляет каждый блок иметь один общий тип. Проект или продукт регистрирует конкретный тип с понятным назначением.

## Когда применять

Создавайте блок, когда секция уже содержит самостоятельный сценарий, имеет собственные данные или повторяется на разных страницах. Если нужна только рамка и отступы, оставайтесь на уровне секции.

## Пример

Для каталога можно зарегистрировать `project.product-catalog`. Его области содержимого зададут места для фильтров, списка и пагинации, а ссылка на данные укажет владельца товаров. Пока такой тип не зарегистрирован, тот же пример собирается из `layout.section`, `layout.columns` и текстовых элементов. Это позволяет начать с малого и добавить блок без смены формата документа.

| Сейчас, без собственного блока | После регистрации блока |
|:---|:---|
| `layout.section` содержит колонки и текстовые узлы | `project.product-catalog` скрывает повторяемое внутреннее устройство |
| документ работает на встроенных типах | manifest подтверждает слоты фильтров, списка и пагинации |
| проект отдельно связывает данные | блок сохраняет ту же внешнюю ссылку на товары |
