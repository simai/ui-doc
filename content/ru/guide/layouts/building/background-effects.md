# Фоновые эффекты

**Фоновый эффект** — анимированный фон, который рисуется в одной области
страницы: художественная половина страницы входа, фон крупного блока. Эффект
состоит из манифеста `effect.json` и одного модуля JavaScript. По манифесту
продукт показывает эффект в списке, описывает его и строит форму настроек, не
запуская его код. Правила эффекта задаёт стандарт
[`simai.effect`](#требования-стандарта); Framework даёт схему манифеста,
`SF.Effects` в ядре и набор проверок, а встроенные эффекты, их установка,
включение и хранение настроек остаются за продуктом.

## Манифест

```json
{
  "schema": "simai.effect.v1",
  "id": "sample-dots",
  "version": "1.0.0",
  "label": {"ru": "Точки", "en": "Dots"},
  "entry": "sample-dots.js",
  "surfaces": ["sign-in"],
  "settings": [
    {"key": "count", "type": "integer", "label": {"ru": "Сколько точек"}, "default": 24, "min": 4, "max": 200},
    {"key": "speed", "type": "number", "label": {"ru": "Скорость"}, "default": 1, "min": 0.25, "max": 4, "step": 0.25},
    {"key": "color", "type": "color", "label": {"ru": "Цвет"}, "default": "#6688ff"},
    {"key": "shape", "type": "choice", "label": {"ru": "Форма"}, "default": "round",
      "options": [{"value": "round", "label": {"ru": "Круг"}}, {"value": "square", "label": {"ru": "Квадрат"}}]}
  ],
  "needs": {"network": false}
}
```

| Поле | Обязательно | Что задаёт |
|:---|:---|:---|
| `schema` | да | ровно `simai.effect.v1` |
| `id` | да | имя эффекта: строчная латинская буква, затем от 1 до 40 строчных букв, цифр или дефисов |
| `version` | да | версия эффекта `<старшая>.<младшая>.<исправление>` |
| `label` | да | подпись по языкам: `{"ru": "…", "en": "…"}`, до 200 символов |
| `author` | нет | автор, до 200 символов |
| `entry` | да | файл модуля рядом с манифестом, `.js` или `.mjs` |
| `styles` | нет | до восьми файлов `.css` рядом с манифестом |
| `preview` | нет | картинка для списка: `.png`, `.jpg`, `.jpeg` или `.webp` |
| `surfaces` | да | области страниц, для которых эффект можно выбрать, например `sign-in` |
| `settings` | да | до 40 настроек; может быть пустым списком |
| `needs` | да | ровно `{"network": false}`: эффект не ходит в сеть |

Других полей нет. Схема лежит в поставке `ui`
(`distr/core/contracts/effect.v1.schema.json`).

## Настройки

У каждой настройки есть `key` (латинская буква, затем до 40 букв и цифр),
`type`, `label` и `default`, который сам проходит проверку настройки.
Необязательные поля — `hint`, `unit` и `step`.

| `type` | Что хранит | Что обязательно |
|:---|:---|:---|
| `choice` | одно значение из `options` | `options` — список `{value, label}` |
| `integer` | целое число в границах | `min` и `max` |
| `number` | число в границах | `min` и `max` |
| `boolean` | да или нет | — |
| `string` | строка без переноса строки | `max` — наибольшая длина |
| `text` | многострочный текст | `max` — наибольшая длина |
| `color` | цвет `#rgb`, `#rrggbb` или `#rrggbbaa` | — |
| `file` | файл сайта: адрес или идентификатор, который продукт уже проверил, или пусто | ничего; необязательный `accept` называет виды файлов, например `image/webp` |

Значение вне границ не подрезается, а считается неверным. Хранимые значения
приводятся только там, где смысл очевиден: числовая строка для числа, `"1"`,
`"0"`, `"true"`, `"false"` для логического значения. Форму настроек продукт
строит из `settings` своим представлением записи, а не пишет руками для
каждого эффекта.

## Модуль эффекта

Модуль экспортирует одну функцию `mount(host, settings, context)` и
возвращает объект с методами `update(settings)`, `pause()`, `resume()` и
`destroy()`. `context` содержит `reducedMotion` (человек просил меньше
движения) и `locale` (язык страницы).

```js
export function mount(host, settings, context) {
  const canvas = document.createElement('canvas');
  canvas.style.cssText = 'position:absolute;inset:0;inline-size:100%;block-size:100%';
  host.append(canvas);
  const ratio = Math.min(globalThis.devicePixelRatio || 1, 2);
  let values = settings;
  let frame = 0;
  let running = false;
  const paint = () => { /* рисует кадр по values с плотностью ratio */ };
  const tick = () => { paint(); frame = requestAnimationFrame(tick); };
  const start = () => { if (running || context.reducedMotion) return; running = true; frame = requestAnimationFrame(tick); };
  const stop = () => { running = false; cancelAnimationFrame(frame); };
  paint();
  start();
  return {
    update(next) { values = next; paint(); },
    pause: stop,
    resume: start,
    destroy() { stop(); canvas.remove(); }
  };
}
```

Эффект рисует только внутри `host` — добавляет туда свой `canvas` или
`video` — и не трогает остальную страницу. Плотность пикселей он ограничивает
двумя. При `reducedMotion` он рисует один неподвижный кадр и больше кадров не
просит. Новые настройки приходят в `update` без повторного монтирования, а
после `destroy` не остаётся ни узлов, ни кадров, ни наблюдателей, ни
слушателей.

## Подключение на странице

`SF.Effects` доступен сразу после выполнения `core.js`:

| Член | Что делает |
|:---|:---|
| `checkEffectManifest(manifest)` | проверяет манифест; возвращает список проблем, пустой — манифест верен |
| `checkSetting(setting, value)` | проверяет одно значение; возвращает `{ok, value}` |
| `effectSettings(manifest, stored)` | превращает хранимые значения в настройки эффекта: каждый ключ манифеста, верное хранимое значение или значение по умолчанию; возвращает `{settings, invalid}`, где `invalid` — ключи, чьи значения отброшены |
| `mountEffect(host, {manifest, module, stored, locale})` | проверяет манифест, монтирует модуль по правилам и возвращает объект с `update`, `pause`, `resume`, `destroy` |
| `EFFECT_SCHEMA` | метка формата `simai.effect.v1` |

```js
const manifest = await fetch('/effects/sample-dots/effect.json').then((response) => response.json());
const module = await import('/effects/sample-dots/sample-dots.js');
const host = document.querySelector('.sign-in-art');
const effect = SF.Effects.mountEffect(host, {manifest, module, stored: savedValues});

effect.update(newValues); // настройки после сохранения формы
effect.destroy();         // уход со страницы
```

`mountEffect` выбрасывает `TypeError`, если манифест неверен или модуль не
экспортирует `mount`. Смонтировав эффект, он:

- ставит области `aria-hidden="true"`, `pointer-events: none` и
  `data-sf-effect` с именем эффекта — фон не читается экранным диктором и
  не мешает указателю;
- передаёт эффекту настройки через `effectSettings`, поэтому неверное или
  отсутствующее значение заменяется значением по умолчанию;
- вызывает `pause()`, пока вкладка скрыта, и `resume()`, когда она снова
  видна;
- монтирует эффект заново, когда человек включает или выключает уменьшение
  движения, — неподвижный кадр появляется сразу;
- при ошибке в `update`, `pause`, `resume` или `destroy` отправляет
  всплывающее событие `sf-effect-error` с `detail: {effect, phase, message}`;
- после `destroy()` очищает область и снимает свои слушатели. Методы можно
  вызывать в любом порядке и повторно.

Ошибку монтирования ловит продукт: он показывает вместо эффекта свой эффект
по умолчанию. Эффект, который продукт не поставляет и не проверял сам,
запускается только во фрейме с `sandbox` без `allow-same-origin`, со строгой
политикой безопасности содержимого и получает проверенные настройки
сообщением; `SF.Effects` работает и внутри такого фрейма.

## Набор проверок

Перед тем как показать эффект в списке, продукт прогоняет на нём набор
проверок — скрипт `scripts/effect-kit.mjs` из исходников Framework
(`simai/ui-source`, ревизия выпуска). Скрипту нужны Node.js и Playwright с
установленным Chromium. Он принимает папку эффекта (`effect.json` и файлы,
которые тот называет) и корень собранного Framework — выход
`sf-build framework --out` ([Сборка пакета: `sf-build`](/ru/guide/introduction/structure/#сборка-пакета-sf-build)): скрипт берёт из него
`core/core/js/core.js`. Подойдёт и папка, в которой `core/core` — это
`distr/core` поставки `ui` того же выпуска.

```bash
node scripts/effect-kit.mjs ./effects/sample-dots ./framework-build
```

Скрипт печатает каждую проверку с результатом (`ok` или `FAIL` и подробности)
и завершается с кодом 1, если хотя бы одна не прошла:

| Проверка | Что проверяет |
|:---|:---|
| `manifest` | манифест проходит `checkEffectManifest`; если нет, остальные проверки не запускаются |
| `defaults` | значение по умолчанию каждой настройки верно |
| `mounts` | `mount()` возвращает `update`, `pause`, `resume`, `destroy` и рисует в области |
| `no-network` | эффект не запрашивает ничего, кроме своих файлов |
| `still-motion` | при уменьшении движения эффект рисует и перестаёт просить кадры |
| `hidden-tab` | пока вкладка скрыта, кадры не запрашиваются |
| `pixel-ratio` | `canvas` не больше двойного размера области |
| `update` | `update()` с новыми настройками не монтирует эффект заново: узлы области остаются |
| `cleanup` | после `destroy()` область пуста и кадры не запрашиваются |
| `remount` | после `destroy()` эффект монтируется снова |
| `accessibility` | область вне дерева доступности и не принимает указатель |

В исходниках лежат два образца: `tests/fixtures/effect-sample` проходит все
проверки, а `tests/fixtures/effect-bad` нарушает четыре правила — ходит в
сеть, рисует при уменьшении движения и в скрытой вкладке, продолжает просить
кадры после `destroy` — и не проходит `no-network`, `still-motion`,
`hidden-tab` и `cleanup`.

## Требования стандарта

| Требование | Уровень | Суть |
|:---|:---|:---|
| `manifest-describes-everything` | обязательно | Эффект описан только манифестом: имя, версия, подпись, модуль, стили, превью, области, настройки и потребности; продукт показывает и настраивает его, не запуская код |
| `settings-are-typed-and-bounded` | обязательно | У каждой настройки ключ, тип, подпись и верное значение по умолчанию; числа называют границы, строки — длину, выбор — варианты, файлы — виды файлов сайта |
| `settings-form-from-the-manifest` | обязательно | Форму настроек продукт строит из манифеста своим представлением записи, а не пишет для каждого эффекта |
| `values-checked-before-use` | обязательно | Каждое хранимое значение проверяется перед сохранением и перед передачей эффекту; неверное или отсутствующее заменяется значением по умолчанию |
| `one-module-one-mount` | обязательно | Модуль экспортирует `mount(host, settings, context)` и отвечает методами `update`, `pause`, `resume`, `destroy` |
| `draws-in-its-host-only` | обязательно | Эффект рисует только в своей области и не трогает остальную страницу |
| `no-network` | обязательно | Эффект не делает запросов: только свои файлы и файлы сайта, которые называют его настройки |
| `reduced-motion-still` | обязательно | При уменьшении движения — один неподвижный кадр; включивший настройку человек получает его сразу |
| `hidden-tab-idle` | обязательно | В скрытой вкладке эффект ничего не рисует и не просит кадры |
| `pixel-density-capped` | обязательно | Плотность пикселей не больше двух |
| `not-in-the-way` | обязательно | Область вне дерева доступности и не принимает указатель: эффект стоит под элементами управления страницы |
| `update-without-remount` | обязательно | Новые настройки приходят через `update`, без повторного монтирования |
| `clean-destroy` | обязательно | После `destroy` не остаётся узлов, кадров, наблюдателей и слушателей, и эффект можно смонтировать снова |
| `failure-falls-back` | обязательно | Эффект, который не смонтировался или упал, заменяется эффектом продукта по умолчанию, а сбой сообщается (`sf-effect-error`), а не показывается сломанной страницей |
| `foreign-effects-sandboxed` | обязательно | Чужой эффект работает только во фрейме без `allow-same-origin`, под строгой политикой безопасности содержимого, и получает настройки сообщением |
| `installed-effects-checked` | обязательно | Эффект устанавливается только после проверки пакета — допустимые файлы, размер, манифест, отпечаток каждого файла — и выключенным, пока его не включит человек |
| `kit-before-listing` | обязательно | Перед показом в списке продукт прогоняет набор проверок |

Стандарт опирается на [правила взаимодействия компонентов](/ru/guide/standards/interaction-rules/) в части движения и
изоляции сбоев. Проверка ручная, а набор проверок меряет то, что можно
измерить в браузере.
