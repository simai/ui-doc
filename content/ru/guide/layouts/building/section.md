# Секция

`layout.section` группирует связанную часть страницы: вступление,
преимущества, выдачу каталога или контакты. Новую секцию заводят, когда у
группы элементов есть своя тема или назначение. Пример ниже показывает секцию
с заголовком и выбранными вариантами оформления:

```json
{
  "id": "intro",
  "type": "layout.section",
  "presentation": {"preset": "surface", "modifiers": ["contained"]},
  "slots": {"default": [
    {"id": "title", "type": "content.heading",
     "data": {"level": 1, "content": [{"type": "text", "value": "О компании"}]}}
  ]}
}
```

`presentation` принимает только варианты, объявленные в манифесте типа. У
секции это пресеты `surface` и `contrast` и модификаторы `contained` и
`spacious`. Значение вне списка отклоняется при проверке. Встроенный рендерер
не оставляет в разметке следов `presentation` (см.
[Встроенные типы](/ru/guide/layouts/introduction/levels/#встроенные-типы)).
Произвольные CSS-классы в документ не передаются.

Секция версии 1.2.0 и без параметров выглядит готовой: у неё есть отступы
сверху и снизу, а текст не прижат к краю листа. Для этого рендерер выводит
утилиты SIMAI Framework по значениям типа по умолчанию: ширину `normal` и
отступ `padding_y: 8`. Пример выше даёт такую разметку:

```html
<section class="p-y-8" data-sf-composition-id="intro">
  <div class="container m-inline-auto" data-sf-composition-part="frame">
    <div class="space-y-3" data-sf-composition-part="content">
      <h1 data-sf-composition-id="title">О компании</h1>
    </div>
  </div>
</section>
```

- `frame` — контейнер страницы с боковыми полями, по центру;
- `content` — содержимое секции. Блоки в нём стоят на одном расстоянии друг
  от друга: `space-y-3`, это 24 px на компьютере и 16 px на телефоне. Если
  задан `gap`, расстояние берётся из него, для каждого экрана своё. Если
  заданы `columns`, содержимое становится сеткой, и расстояние задаёт её `gap`;
- контейнер внутри секции не добавляет второе боковое поле: он получает
  `container-flush`, поэтому на телефоне его текст такой же ширины, как у
  самой секции.

Свои значения документа заменяют значения по умолчанию. Например, секция с
`"props": {"width": "full", "padding_y": 4}` выводит
`<section class="p-y-4" data-sf-composition-id="intro">` без частей `frame` и
`content`.

Секция не загружает данные и не выполняет действия проекта; она хранит порядок
вложенных узлов. В примере [Каталог товаров](/ru/guide/layouts/examples/catalog/) заголовок, вступление и колонки
лежат в одной секции; их можно поменять в JSON и сразу увидеть результат.
