# Секция

`layout.section` группирует связанную часть страницы: вступление,
преимущества, выдачу каталога или контакты. Новую секцию заводят, когда у
группы элементов есть своя тема или назначение. Пример ниже показывает секцию
с заголовком и выбранными вариантами оформления:

```json
{
  "id": "intro",
  "type": "layout.section",
  "presentation": {"preset": "surface", "modifiers": ["contained"]},
  "slots": {"default": [
    {"id": "title", "type": "content.heading",
     "data": {"level": 1, "content": [{"type": "text", "value": "О компании"}]}}
  ]}
}
```

`presentation` принимает только варианты, объявленные в манифесте типа. У
секции это пресеты `surface` и `contrast` и модификаторы `contained` и
`spacious`. Значение вне списка отклоняется при проверке. Встроенный рендерер
секции выводит `<section data-sf-composition-id="intro">` без следов
`presentation` (см. [Встроенные типы](/ru/guide/layouts/introduction/levels/#встроенные-типы)).
Произвольные CSS-классы в документ не передаются.

Секция не загружает данные и не выполняет действия проекта; она хранит порядок
вложенных узлов. В примере [Каталог товаров](/ru/guide/layouts/examples/catalog/) заголовок, вступление и колонки
лежат в одной секции; их можно поменять в JSON и сразу увидеть результат.
