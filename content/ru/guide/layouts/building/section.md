# Секция

`layout.section` группирует связанную часть страницы: вступление, преимущества, выдачу каталога или контакты. Секция сохраняет смысловую структуру и даёт одно место для настройки её представления.

## Когда применять

Создавайте новую секцию, когда у группы элементов есть собственная тема или назначение. Не оборачивайте каждый абзац отдельной секцией: лишняя вложенность усложняет документ и не добавляет смысла.

## Пример

```json
{
  "id": "intro",
  "type": "layout.section",
  "presentation": {"preset": "surface", "modifiers": ["contained"]},
  "slots": {"default": [
    {"id": "title", "type": "content.heading", "data": {"level": 1, "content": [{"type": "text", "value": "О компании"}]}}
  ]}
}
```
`presentation` хранит только зарегистрированные варианты оформления. Произвольные CSS-классы в документ не передаются.

Секция не загружает товары и не выполняет действия проекта. Она сохраняет порядок вложенных узлов. Посмотрите [работающий каталог](/ru/guide/layouts/examples/catalog/): вступление и область с колонками представлены отдельными секциями, их можно менять в JSON и сразу видеть результат.
