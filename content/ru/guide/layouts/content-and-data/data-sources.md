# Данные и внешние источники

Recipe может объявить настройку или содержимое, но не обращается к базе и API самостоятельно. Проект проверяет права и передаёт Framework доверенный снимок. Происхождение значения содержит область сайта, владельца, идентификатор и ревизию.

## Когда применять

Используйте входы, когда текст, карточки или настройки приходят из базы, API проекта или системы управления сайтом. `bindings` в готовом Document сохраняют связь поля с источником. Не помещайте в Recipe токены, SQL, закрытые адреса или готовые запросы.

## Пример

```json
"body": {
  "kind": "content",
  "expectedOrigin": {
    "owner": "project/catalog",
    "ref": "products",
    "revision": "42"
  }
}
```

Проект передаёт значение только после проверки доступа. Framework сверяет область, происхождение, ревизию и digest. Отказ доступа считается ошибкой, а не отсутствующим значением; частичный Document при этом не создаётся.
