# Данные и внешние источники

Макет может ссылаться на внешние данные, но не загружает их самостоятельно. Ссылка указывает владельца, идентификатор набора и ожидаемую ревизию. Конкретный проект понимает эту ссылку, проверяет доступ и возвращает данные.

## Когда применять

Используйте `bindings`, когда карточки, новости или профиль приходят из базы, API проекта или системы управления сайтом. Не помещайте в документ токены, SQL, URL закрытого сервиса или готовые запросы.

## Пример

```json
"bindings": [{
  "owner": "project/catalog",
  "ref": "products",
  "target": "items",
  "revision": "42"
}]
```
Framework видит непрозрачную ссылку и сообщает её проекту. Если ревизия не совпадает или пользователь не имеет права видеть товары, проект возвращает ошибку либо безопасный результат.
