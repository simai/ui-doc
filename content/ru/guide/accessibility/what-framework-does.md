# Что SIMAI Framework делает за вас

Эта страница перечисляет, что сайт получает от SIMAI Framework без
настройки. Каждое свойство держит проверка самого Framework, поэтому оно не
пропадает с новым выпуском.

| Что | Как это работает |
|:---|:---|
| Масштаб текста | Размеры текста и элементов заданы в `rem`: размер текста браузера и увеличение страницы меняют весь сайт, ничего не обрезая. |
| Видимый фокус | У каждого элемента, до которого доходят клавишей Tab, есть кольцо фокуса `:focus-visible` цвета `--sf-focus` в обеих темах. |
| Клавиатура | Смарт-компоненты проходятся с клавиатуры: Tab, Enter, пробел, Escape и стрелки внутри списков и меню. Клавиши каждого — на странице [Компоненты](/ru/guide/accessibility/components/). |
| Роли и имена | Компонент сам ставит роль, имя и состояние (`aria-expanded`, `aria-pressed`, `aria-current`) и объявляет изменения в области `role="status"`. |
| Контрастные темы системы | При `forced-colors: active` (контрастные темы Windows) компоненты оставляют форму, границы и фокус в системных цветах. |
| Меньше движения | `prefers-reduced-motion` и выбор «Остановить движение» убирают анимации, автопрокрутку и эффекты. |
| Больше контраста | При `prefers-contrast: more` тихие границы и второстепенный текст становятся полным цветом текста. |
| Без прозрачности | При `prefers-reduced-transparency` стекло и размытие становятся сплошной заливкой. |
| Тёмная тема | Цвета — пары `light-dark()`: тема следует системе или выбору человека, контраст держится в обеих. |
| Язык | Слова компонентов берутся по ближайшему `lang`; одиннадцать языков в реестре, свои слова регистрируются. |
| Письмо справа налево | Отступы и стороны заданы логическими свойствами, поэтому раскладка отражается для `dir="rtl"`. |
| Ссылка «Перейти к содержимому» | Ядро ставит её первой в `<body>`, если на странице есть основная область и нет своей такой ссылки. |
| Настройки отображения | `SF.displaySettings` и панель [Настройки отображения](/ru/guide/accessibility/display-settings/): текст до 200 %, пять цветовых схем, интервалы, картинки, движение. Выбор хранится только в браузере человека. |

## Что остаётся за автором

Framework не знает, что значит содержимое страницы. Заголовки по порядку,
подписи картинок, понятные тексты ссылок и ошибок, контраст своих цветов и
раскладка, которая переносится при увеличении, — работа автора. Что
проверить — на странице [Чек-лист автора](/ru/guide/accessibility/author-checklist/).
