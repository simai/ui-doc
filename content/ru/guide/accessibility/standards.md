# Стандарты и заявление о соответствии

## Цель — WCAG 2.2 AA

SIMAI Framework держит свои компоненты на уровне WCAG 2.2 AA. С 2025 года
WCAG 2.2 — международный стандарт ISO/IEC 40500:2025. Законы разных стран
ссылаются на WCAG напрямую или через свои стандарты, и везде требование одно:
доступным должен быть **основной сайт**. Отдельная «версия для слабовидящих»
нигде этого требования не заменяет.

| Где | Что требуется |
|:---|:---|
| Весь мир | WCAG 2.2 AA, он же ISO/IEC 40500:2025. |
| Европейский союз | Европейский акт о доступности действует с 28 июня 2025 года и для частных сервисов: магазины, банки, транспорт. Стандарт EN 301 549: версия 3.2.1 — WCAG 2.1 AA, версия 4.1.1 (сентябрь 2026) — WCAG 2.2 AA. Государственным сайтам нужно заявление о доступности. |
| США | ADA, раздел II: WCAG 2.1 AA для сайтов штатов и муниципалитетов (для крупных — с 26 апреля 2027 года). Section 508: WCAG 2.0 AA для федеральных систем. Для частных сайтов суды опираются на WCAG 2.x AA. |
| Великобритания | Правила доступности сайтов государственного сектора 2018 года: WCAG 2.2 AA и заявление о доступности по образцу. |
| Япония | JIS X 8341-3:2016 (WCAG 2.0); готовится переход на ISO/IEC 40500:2025. |
| Россия | ГОСТ Р 52872-2019 (на основе WCAG 2.1). Приказ Минцифры № 953 для государственных и муниципальных сайтов: доступ для программ экранного доступа, текст до 200 % без горизонтальной прокрутки, контраст по ГОСТ, информация не только цветом; отдельной версии не требует. Для школьных сайтов обязательная версия для слабовидящих отменена с 1 марта 2026 года. |

## Чего Framework обещать не может

- **Соответствие сайта.** Компоненты доступны, но страницу собирает автор:
  заголовки, подписи, тексты, свои цвета и раскладку проверяют на готовом
  сайте.
- **Автоматическое исправление.** Framework не переписывает разметку, не
  придумывает подписи картинок и не читает текст вслух: программы экранного
  доступа делают это лучше. Инструменты, которые обещают «доступность одной
  строкой», регуляторы штрафуют за такие обещания.
- **Панель вместо доступного сайта.** [Настройки отображения](/ru/guide/accessibility/display-settings/)
  — удобство для человека, а не подтверждение соответствия.

## Заявление о соответствии

Заявление о доступности пишет владелец сайта: какому стандарту сайт
следует, что известно как недоступное и куда писать о проблеме. Для
государственных сайтов ЕС и Великобритании оно обязательно. Заготовка — на
странице [Образец заявления о доступности](/ru/guide/accessibility/statement-template/).

В заявлении можно сослаться на SIMAI Framework как на основу интерфейса:
«компоненты интерфейса следуют WCAG 2.2 AA». Сам сайт так описывать можно
только после проверки по [чек-листу автора](/ru/guide/accessibility/author-checklist/)
и, лучше, после проверки специалистом.
