# Образец заявления о доступности

Заявление о доступности говорит человеку, насколько сайт доступен, что
известно как недоступное и куда писать о проблеме. Образец ниже построен по
структуре образцовых заявлений ЕС и Великобритании. Замените текст в
угловых скобках и удалите строки, которые к сайту не относятся. Пишите
только то, что проверено на вашем сайте.

## На русском

```text
Заявление о доступности сайта <адрес сайта>

<Организация> стремится сделать сайт <адрес сайта> доступным для всех,
в том числе для людей с инвалидностью.

Стандарт
Мы проверяем сайт по WCAG 2.2 уровня AA (ГОСТ Р 52872-2019 / EN 301 549).

Состояние
Сайт <полностью / частично / не> соответствует этому стандарту.

Что пока недоступно
- <Что именно>: <почему>. Исправим до <дата>.
- <Документы PDF до 2025 года не размечены для программ экранного доступа>.

Как мы проверяли
Сайт проверен <собственными силами / организацией …> <дата>
по <чек-листу, методике>.

Настройки отображения
На сайте есть панель «Настройки отображения»: размер текста, цветовые
схемы, интервалы, картинки и движение. Она не заменяет доступность сайта.

Обратная связь
Если что-то на сайте недоступно для вас, напишите на <почта> или
позвоните <телефон>. Мы ответим в течение <срок> рабочих дней.

Заявление подготовлено <дата>, пересмотрено <дата>.
```

## На английском

```text
Accessibility statement for <site address>

<Organisation> is committed to making <site address> accessible to
everyone, including disabled people.

Standard
We test this website against WCAG 2.2 level AA (EN 301 549).

Compliance status
This website is <fully / partially / not> compliant with this standard.

Non-accessible content
- <What>: <why>. We plan to fix it by <date>.

How we tested
The website was tested <internally / by …> on <date>
using <checklist, method>.

Display settings
The website has a «Display settings» panel: text size, colour schemes,
spacing, images and motion. It does not replace an accessible website.

Feedback and contact
If you find something on this website you cannot access, email <address>
or call <phone>. We will reply within <number> working days.

This statement was prepared on <date> and last reviewed on <date>.
```
