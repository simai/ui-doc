# Чек-лист автора

SIMAI Framework отвечает за компоненты, а этот список — за то, что решает
автор сайта. Пройдите его на готовых страницах с настоящим содержимым.

## Структура и текст

- У страницы один заголовок `h1`, остальные идут по порядку, без
  пропусков уровней.
- У `<html>` есть `lang`, а у фрагментов на другом языке — свой `lang`.
- У страницы есть основная область `<main>`; ссылку «Перейти к
  содержимому» тогда ставит ядро.
- Текст ссылки говорит, куда она ведёт, без «здесь» и «подробнее».
- У кнопки с одной иконкой есть `aria-label`.

## Картинки и медиа

- У картинки, которая что-то сообщает, есть `alt` с этим смыслом; у
  украшения — пустой `alt=""`.
- У видео есть субтитры, у аудио — расшифровка.
- Ничего не движется само дольше пяти секунд без кнопки «Пауза».

## Цвет

- Свои цвета текста держат контраст не ниже 4.5:1, крупного текста и
  границ контролов — не ниже 3:1, в обеих темах.
- Информация не передаётся только цветом: у статуса есть слово, у
  ошибки — текст.

## Формы

- У каждого поля есть видимая подпись, а не только подсказка внутри.
- Ошибка говорит, что не так и как исправить, и стоит рядом с полем.
- Обязательные поля отмечены не только звёздочкой цветом.

## Увеличение и узкий экран

- При тексте 200 % и ширине 320 px нет горизонтальной прокрутки
  страницы.
- Колонки при увеличении **переносятся**, а не сжимаются: колонка
  постоянной ширины рядом с текстом сжимает его до буквы в строке, и
  прокрутки при этом нет, поэтому её не замечают.
- С интервалами «шире» (строка 1.5, абзац 2, буквы 0.12, слова 0.16 от
  размера текста) текст не обрезается и не налезает.

## Клавиатура

- Всё, что нажимается мышью, доступно с клавиатуры, порядок Tab
  совпадает с порядком чтения.
- Фокус всегда виден и не прячется под липкой шапкой.
- Окно возвращает фокус туда, откуда его открыли.

## Проверка

- Пройдите главные сценарии только с клавиатуры.
- Прослушайте страницу программой экранного доступа (VoiceOver, NVDA).
- Включите в [настройках отображения](/ru/guide/accessibility/display-settings/)
  текст 200 %, жёлтый на чёрном и интервалы «шире» и пройдите страницы ещё
  раз.
