# Поля формы

У поля есть машинное имя, видимая подпись и, если нужно, пояснение. Эти части решают разные задачи и не заменяют друг друга.

## Когда применять

Проверяйте структуру каждого поля формы, особенно если подпись хочется скрыть ради компактного интерфейса. Пользователь и вспомогательные технологии всё равно должны понимать назначение поля.

## Пример

```html
<label for="email">Электронная почта</label>
<input id="email" name="email" type="email" aria-describedby="email-hint">
<p id="email-hint">Пришлём на этот адрес подтверждение.</p>
```

`name` используется при отправке данных, `label` называет поле, а пояснение сообщает формат или последствия ввода. Placeholder годится только как короткий пример и не заменяет подпись.
