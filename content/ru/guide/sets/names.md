# Имена компонентов

Компоненты всех наборов называются так же, как компоненты SIMAI Framework:
с приставкой `sf-`. Своей приставки у набора нет. Чтобы имена разных наборов
не совпадали, каждое имя начинается с семейства, а у каждого семейства один
владелец.

## Как устроено имя

Имя компонента строится как `sf-<семейство>-<часть>-<вариант>`; часть и
вариант могут отсутствовать. Семейство — первое слово после `sf-`:

| Компонент | Семейство | Чьё |
|:---|:---|:---|
| `sf-effect` | `effect` | набор `effects` |
| `sf-chat-composer` | `chat` | набор `chat` |
| `sf-message-log` | `message` | набор `chat` |
| `sf-view-table` | `view` | набор `view` |
| `sf-button` | `button` | SIMAI Framework |

По имени тега сразу видно, из какого набора компонент и какую строку
`data-sf-sets` нужно добавить на страницу.

## Общий реестр имён

- Все семейства записаны в один общий реестр имён SIMAI Framework. У каждого
  семейства ровно один владелец: SIMAI Framework или один набор.
- Набор может занимать несколько семейств: например, `chat` владеет
  семействами `chat` и `message`.
- Новый компонент в семействе, которое уже принадлежит набору, добавляют без
  изменения реестра. Новое семейство набор сначала записывает в реестр.
- Проверка при выпуске не пропустит набор, если его семейство уже занято
  другим набором или SIMAI Framework.

Поэтому любые наборы можно подключать на одну страницу вместе: два набора
никогда не объявят компонент с одним и тем же именем.

## Старые имена

Когда компонент переименовывают, старое имя ещё какое-то время работает и
пишет в консоль подсказку с новым именем, как и у компонентов SIMAI Framework
(см. [Жизненный цикл изменений](/ru/guide/connection/change-lifecycle/)). Срок,
до которого действует старое имя, набор указывает сам.
