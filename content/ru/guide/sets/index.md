# Наборы компонентов

Бесплатный SIMAI Framework содержит универсальные части интерфейса: утилиты,
компоненты, смарт-компоненты, простой список и простую таблицу. Всё, что
нужно для отдельной задачи — админка, канбан, чат, конструктор писем,
графики, — поставляется **наборами компонентов** поверх него.

> **Скоро.** Наборы подключаются начиная с выпуска SIMAI Framework, в котором
> есть поддержка наборов (`core.runtime` 1.25.0). Этот выпуск ещё не вышел;
> до него компоненты Pro подключают как пакет `pro`, см. раздел [Pro](/ru/pro/).

## Что такое набор

Набор — это смарт-компоненты одной задачи, которые выпускаются вместе:

- у набора одно короткое имя, например `effects` или `chat`;
- набор работает поверх SIMAI Framework и использует его компоненты, а не
  повторяет их;
- набор сам описывает свои компоненты, поэтому новый компонент в наборе не
  требует нового выпуска SIMAI Framework;
- у каждого набора свой сайт с документацией и демонстрациями.

Страница подключает SIMAI Framework и называет нужные наборы. Loader загружает
только те компоненты набора, которые есть на странице.

## Какие бывают наборы

| Набор | Для чего | Лицензия | Сайт |
|:---|:---|:---|:---|
| `admin` | Админка: меню, рабочие экраны, настройки | Pro | [admin.simai.io](https://admin.simai.io/) |
| `view` | Представления данных: умная таблица с сортировкой, фильтрами и страницами, канбан, календарь, диаграмма Ганта | Pro | view.simai.io, появится |
| `chat` | Чат: лента сообщений, поле ввода, список диалогов | Pro | свой поддомен, появится |
| `mail` | Письма: конструктор и просмотр писем | Pro | свой поддомен, появится |
| `editor` | Редактор страниц и текста | Pro | свой поддомен, появится |
| `chart` | Графики и диаграммы | Pro | свой поддомен, появится |
| `effects` | Фоновые эффекты и анимации | Бесплатно | [effects.simai.io](https://effects.simai.io/) |

Простой список и простая таблица остаются в бесплатном SIMAI Framework.
Набор `view` нужен, когда данным требуются сортировка, фильтры, страницы или
другой способ показа.

## Что в Framework, а что в наборе

- Всё универсальное — в SIMAI Framework: кнопки, поля, меню, списки, формы,
  окна, токены и темы.
- В наборе — то, что нужно одной задаче. Набор собирает свои компоненты из
  компонентов Framework.
- Наборы могут опираться друг на друга: например, админка показывает данные
  компонентами набора `view`. Такие наборы страница называет все.
