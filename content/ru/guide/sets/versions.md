# Версии и совместимость

Набор выпускается отдельно от SIMAI Framework и со своей версией. Каждый
выпуск набора знает, какой SIMAI Framework ему нужен, и записан в общий
каталог выпусков. По этому каталогу Loader подбирает к странице подходящий
выпуск.

## Где лежат выпуски

- Каждый набор публикуется в npm как `@simai-studio/<набор>`, например
  `@simai-studio/effects`. Файлы выпуска лежат на jsDelivr по адресу
  `https://cdn.jsdelivr.net/npm/@simai-studio/<набор>@<версия>/dist/smart/`.
- Все выпуски всех наборов перечислены в одном каталоге — пакете npm
  `@simai-studio/sets`. Его пополняет только выпуск набора, вручную каталог не
  правят, а записанный выпуск не меняется.

## Какой SIMAI Framework нужен набору

У каждого выпуска набора в каталоге записаны:

- версия набора;
- выпуск SIMAI Framework, на котором набор собран и проверен;
- самая младшая версия ядра (`core.runtime`), с которой набор работает,
  например `>=1.25.0`;
- другие наборы, без которых он не работает;
- контрольные суммы архива выпуска, по которым его можно проверить.

Каталог лежит по адресу
`https://cdn.jsdelivr.net/npm/@simai-studio/sets@1/index.json`. Запись о
выпуске выглядит так:

```json
{
  "set": "effects",
  "release": "effects-ad9823f83a56",
  "version": "1.0.0",
  "framework": {
    "core_runtime": ">=1.25.0",
    "pair": "ui-eea8c0a97cc7"
  },
  "requires_sets": [],
  "published_on": "2026-11-03"
}
```

В записи есть и другие поля (ревизия исходников, контрольные суммы); здесь они
опущены.

Выпуск набора работает на своём SIMAI Framework и на всех более новых. Когда
страница называет набор без версии, Loader берёт из каталога самый новый
выпуск этого набора, которому хватает ядра на странице. Если страница
работает на более старом SIMAI Framework, чем нужен набору, такой выпуск
пропускается.

## Как обновлять

- Без версии в `data-sf-sets` страница получает новый выпуск набора сразу
  после его публикации. Это удобно для черновиков и демонстраций.
- В рабочем проекте версию набора закрепляют (`data-sf-sets="effects@1.0.0"`)
  и записывают рядом с выпуском SIMAI Framework в файл блокировки проекта, как
  описано в разделе [Версии](/ru/guide/connection/versions/).
- Переходя на новый SIMAI Framework, проверяют, что закреплённые наборы ему
  подходят; переходя на новый выпуск набора — что ему хватает вашего SIMAI
  Framework.
