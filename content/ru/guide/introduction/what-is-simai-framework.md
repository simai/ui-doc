# Что такое SIMAI Framework

SIMAI Framework — система для создания согласованных адаптивных веб-интерфейсов. Она объединяет дизайн-токены, утилиты, обычные компоненты, Smart-компоненты и готовые блоки.

Framework поставляется готовыми модулями. Проект выбирает доступные варианты в разметке, а Loader подключает нужные стили и сценарии. Для предусмотренной настройки не требуется заново собирать CSS на каждой установке.

## Когда применять

Используйте Framework, когда проекту нужен единый внешний вид, повторяемые элементы и возможность развивать интерфейс независимо от серверной части проекта.

Выбирайте самый простой подходящий уровень: утилиту для одного свойства, компонент для повторяемого элемента, Smart-компонент для состояния и поведения, блок для законченной части страницы.

## Пример

Карточку товара можно собрать из токенов, утилит и обычных компонентов. Если выбор варианта должен менять цену и доступность, добавляется Smart-компонент, а получение данных и проверка прав остаются в проекте.
