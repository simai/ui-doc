# Стандарт файла языка

Язык компонентов — это
один файл слов: его может написать команда Framework, продукт или любой
разработчик, не меняя ни одного компонента. Эта страница описывает, как
устроен такой файл, откуда компонент берёт слово и как добавить свой язык
или поправить одно слово.

Как компонент выбирает язык по разметке страницы, описано в главе
[Язык интерфейса](/ru/guide/size-and-type/language/).

## Коротко

- **В компоненты встроен только английский.** Он есть в каждой сборке и не
  стоит ни одного запроса; на него компонент и откатывается.
- **Язык — один файл на язык и поставку:** один для
  Framework, один для пакета `pro`, один для своего продукта. Общего словаря
  нет: каждый компонент несёт свои слова. Русский — такой же файл языка
  Framework, как остальные.
- **Язык может выходить частями.** Слово, которого нет в файле, компонент
  говорит по-английски, а проверка показывает, каких слов не хватает.
- **Свой язык или одно слово — одной строкой** в своём коде, тем же способом,
  каким Framework подключает свои файлы.

## Пример

Немецкого языка в компонентах нет: страница регистрирует слова из файла
одной строкой. Файл намеренно неполный: слова «из 12» у пагинации в нём нет,
и оно остаётся английским — «of 12». Флажок меняет одно слово поверх файла:
доступное имя кнопки следующей страницы.

:::example {id="guide/language-file" label="Свой язык"}
:::

```js
SF.language.registerAll(pack.lang, pack.words);                       // весь файл
SF.language.register('sf-pagination', 'de', {'next-label': 'Weiter'}); // одно слово
```

`registerAll(код, слова)` принимает часть `words` файла как есть: слова по
компонентам, затем по ключам. Слова дополняют уже зарегистрированные, поэтому
одно слово можно поправить, не повторяя остальные.

## Файл

Файл языка — JSON в формате `simai.language-pack`:

```json
{
  "schema": "simai.language-pack",
  "schema_version": 1,
  "delivery": "my-shop",
  "lang": "de",
  "name": "Deutsch",
  "dir": "ltr",
  "status": "draft",
  "review": "Черновик, ждёт проверки носителем языка.",
  "words": {
    "sf-pagination": {
      "next-label": "Nächste Seite",
      "page-label": "Seite",
      "title-page": "Seite {page}",
      "shown": "{shown} von {total} angezeigt"
    },
    "sf-empty-state": {
      "nothing-found-title": "Nichts gefunden"
    }
  }
}
```

| Поле | Обязательное | Что значит |
|:---|:---|:---|
| `schema` | да | Всегда `simai.language-pack`. |
| `schema_version` | да | `1`. Версию, которую не знает, компонент не читает. |
| `lang` | да | Код языка строчными буквами: `de`, `es`, `pt-br`. Файл языка с регионом проверяется раньше файла самого языка. |
| `words` | да | Слова: по компонентам, затем по ключам. |
| `delivery` | нет | Чьи слова: `framework` (по умолчанию), `pro`, `chart` или имя своего продукта. Слова Framework уступают словам любой другой поставки. |
| `name` | нет | Название языка на нём самом: `Deutsch`, `Español`. |
| `dir` | нет | Направление письма: `ltr` (по умолчанию) или `rtl`. |
| `status` | нет | `draft`, пока носитель языка не прочитал весь файл, затем `reviewed`. |
| `review` | нет | Кто проверил файл или что осталось проверить. |
| `coverage` | нет | Сколько слов поставки файл переводит; записывает сборка. |

Других полей на верхнем уровне нет: дат, месяцев, форматов чисел и правил
множественного числа в файле не бывает (см. [Числа и даты](#числа-и-даты)).

### Компоненты и ключи

`words` разбит по имени, под которым компонент регистрирует свои слова: тег
смарт-компонента (`sf-pagination`, `sf-input-date`) или имя компонента на
классах из его документации (`sf-modal`, `sf-toast`). Ключи — те же, что в
английском файле компонента `lang/en.json`, в части `runtime`, через дефис:
`next-label`, `nothing-found-title`.

- Ключа, которого нет в английском файле, быть не может — это ошибка файла.
- Ключ, которого нет в вашем файле, — не ошибка: слово скажется по-английски.
- Слова для Studio и документации (`title`, `events`, `settings`) — не слова
  интерфейса, в файл языка они не входят.

### Подстановки и знаки

Слово — строка. Фигурные скобки заполняет компонент:

- `{n}` — число, записанное цифрами и разделителями языка страницы;
- `{name}`, `{count}`, `{page}`, `{total}` и другие — текст, который даёт
  компонент.

Слово говорит те же подстановки, что его русское слово, не меньше и не
больше, и может ставить их в любое место: «Загрузка {name}» по-немецки —
«{name} wird geladen». Кавычки, десятичный знак и пробел перед `%` — по
правилам языка.

### Множественное число

Слово, которое зависит от числа, — объект с формой для каждой категории
языка из `Intl.PluralRules`; форма `other` есть всегда.

| Язык | Категории | Пример |
|:---|:---|:---|
| английский `en`, немецкий `de` | `one`, `other` | `{"one": "{n} Ergebnis", "other": "{n} Ergebnisse"}` |
| испанский `es`, французский `fr`, итальянский `it`, португальский `pt-BR` | `one`, `many`, `other` | `{"one": "{n} resultado", "many": "{n} de resultados", "other": "{n} resultados"}` — `many` только для круглых миллионов |
| русский `ru` | `one`, `few`, `many`, `other` | `{"one": "{n} результат", "few": "{n} результата", "many": "{n} результатов", "other": "{n} результата"}` |
| арабский `ar` | `zero`, `one`, `two`, `few`, `many`, `other` | |
| китайский `zh-Hans`, японский `ja`, корейский `ko` | `other` | `{"other": "{n} 个结果"}` |

Категории любого языка называет сам браузер:
`new Intl.PluralRules('de').resolvedOptions().pluralCategories`.

### Числа и даты

В файле их нет. Числа, даты, названия месяцев и дней недели, «5 минут
назад», названия языков и стран компоненты пишут через `Intl` на языке
страницы. Слово, в котором есть дата или время, получает их подстановкой уже
записанными: `"saved": "Projekt um {time} gespeichert"`.

Не все браузеры знают все языки одинаково: если у браузера нет данных
языка, месяцы приходят как `M01`. Проверяйте даты своего
языка в тех браузерах, где работают ваши пользователи.

## Откуда берётся слово

На странице на языке `de` компонент берёт первое найденное:

1. атрибут самого компонента (`next-label="…"`) — его назвал автор страницы;
2. слово, которое зарегистрировал продукт: файлом или одним словом;
3. слово из файла языка Framework;
4. встроенное слово компонента — встроен только английский;
5. то же для языка без региона: для `de-AT` — `de`;
6. английское слово — и проверка отмечает его как недостающее;
7. сам ключ — пропуск виден, а не превращается в пустое место.

## Как страница получает файл языка

Страница на языке, у которого есть файл Framework, получает его сама. Ядро
загружает слова ядра (`core/lang/<код>/core.json`) и части семейств
компонентов, которые есть на странице (`core/lang/<код>/<семейство>.json`,
список — в `core/lang/index.json`). Часть страницы со своим `[lang]` получает
свой язык, когда её компонент впервые ищет слово. Английская страница ничего
не загружает.

| Вызов | Что делает |
|:---|:---|
| `SF.language.load(код)` | Загружает все части языка сразу. |
| `SF.language.addPack(код, адрес)` | Подключает файл языка продукта — один файл. |
| `SF_BOOT_CONFIG.languages = {код: адрес}` | То же до запуска ядра. |

### Русский сайт: одна строка перед ядром

```html
<html lang="ru">
<head>
  <script src="/assets/simai/distr/core/lang/ru.js"></script>
  <script src="/assets/simai/distr/core/js/core.min.js"></script>
  <link rel="stylesheet" href="/assets/simai/distr/core/css/core.css">
</head>
```

`core/lang/ru.js` — обычный скрипт со всем русским файлом. Он регистрирует
слова до того, как рисуется хоть один компонент, поэтому ядро ничего не
загружает для русского, а первый кадр каждого компонента сразу русский. Файлу
не нужны сервер и `fetch`: он работает без сети, со страницы, открытой с
диска, и в сборке «одним файлом» — его текст ставится в тот же `<script>`
перед ядром. Подключённый после ядра, он тоже работает: страница один раз
перерисуется.

Без этой строки русская страница работает как страница на любом языке с
файлом: ядро загружает нужные части.

### Ожидание языка страницы

Пока части языка страницы загружаются, Loader держит скрипты компонентов,
которые он добавляет, и тем временем загружает их заранее, поэтому ничего не
приходит позже, чем без ожидания. Ожидание — не больше 800 мс; после него
компонент рисуется по-английски и перерисовывается, когда придут слова. Это
касается любого языка с файлом и файла продукта из `SF_BOOT_CONFIG.languages`.

```html
<script>window.SF_BOOT_CONFIG = {languageWait: 400};</script>  <!-- мс; 0 — не ждать -->
```

Если `ru.js` подключён перед ядром, ждать нечего.

## Свой язык одной строкой

Файл, который уже есть в памяти (собран вместе с кодом продукта или отдан
сервером), регистрируется одной строкой, как в примере:

```js
import de from './lang/de.json';
SF.language.registerAll(de.lang, de.words);
```

Укажите в файле `"delivery"` — имя своего продукта: так ваши слова сильнее
слов Framework на том же языке.

## Одно слово

```js
SF.language.register('sf-pagination', 'de', {'next-label': 'Weiter'});
SF.language.register('sf-pagination', 'de', null);   // убрать свои слова этого компонента
```

Так же меняются встроенные слова. Слово для одного элемента, а не
для всех, — его собственный атрибут: `<sf-pagination next-label="Weiter">`.

## Недостающие слова

Слово, которого нет в файле, компонент говорит по-английски — страница не
ломается, и язык можно выпускать частями.

## Как переводить

Файл пишут для людей, которые каждый день читают на этом языке: перевод не
дословный, а привычный.

- **Обращение.** Та форма, которой программы на этом языке обращаются к
  незнакомому человеку: немецкое `Sie` (`Wählen Sie eine Datei`),
  французское `vous`, вежливая форма японского.
- **Прямота.** Кнопки — короткие глаголы в привычной форме языка
  (немецкий инфинитив: `Schließen`, `Speichern`); ошибка говорит, что
  сделать, а не что сломалось.
- **Привычные слова.** Слова операционных систем и больших сервисов на этом
  языке, а не пересказ русского или английского.
- **Порядок и числа.** Подстановка стоит там, где её ставит язык; порядковые
  числа — как пишет язык (`3. Schritt`, `Seite {page}`).
- **Не склеивать.** Фразу из кусков перевести нельзя. Если компонент
  приклеивает слово к числу или имени в коде, это дефект компонента: нужно
  одно слово с подстановкой.
- **Статус.** Машинный или непроверенный перевод — `"status": "draft"`;
  `reviewed` ставит только носитель языка, прочитавший каждое слово, и
  называет себя в `review`.
