# Состояния и загрузка данных

Smart-компонент показывает своё состояние — ошибку, пустой результат, ожидание — и сообщает о загрузке данных. Здесь — состояния и скелетоны на время загрузки.

## Состояния

Состояние — то, от чего зависит показ компонента в данный момент. Глава
описывает виды состояний, их объявление в манифесте и обязательные состояния
данных.

### Виды состояний

| Вид | Примеры | Кто задаёт |
|:---|:---|:---|
| Визуальные | обычное, наведение, фокус, нажато, заблокировано | Компонент и CSS |
| Поведенческие | закрыт → открывается → открыт → закрывается | Компонент |
| Состояния данных | загрузка, есть данные, пусто, ошибка | Компонент показывает, приложение сообщает |

### Как состояния объявляются

В манифесте у каждого компонента есть раздел `state`:

- `visual_states` — визуальные состояния, которые компонент показывает;
- `machines` — именованные автоматы поведения: список состояний, через которые
  проходит компонент.

Ветвление шаблона по признаку, которого нет в манифесте, запрещено: вид
выбирается только объявленными настройками.

### Обязательные состояния данных

Компонент, который показывает данные приложения, объявляет как минимум четыре
состояния — **загрузка, есть данные, пусто, ошибка** — и показывает текущее.

- Пока запрос выполняется, компонент не рисует придуманные данные.
- Незавершённая операция никогда не показывается как выполненная.
- Без своего серверного адреса компонент прямо сообщает, что возможность не
  подключена.

### Граница состояния

- Компонент хранит открытие панели или выбранное значение.
- Корзина, права и сохранение — в проекте. После операции проект передаёт
  результат компоненту.
- Состояние, которое другой человек должен увидеть по ссылке, живёт в адресе
  страницы; личные удобства могут оставаться в браузерном хранилище.

## Загрузка данных и скелетоны

Глава описывает, как компонент показывает загрузку данных. Правила нужны,
чтобы страница не сдвигалась после загрузки и не показывала устаревшие данные.

Правила:

- Во время загрузки компонент показывает состояние загрузки: у кнопок и полей —
  атрибут `loading`, у списков и таблиц — скелетон (`sf-skeleton`) по форме
  будущего содержимого.
- Скелетон повторяет геометрию настоящего содержимого и берёт размеры из
  лестницы текста: высота строки-заглушки равна размеру текста той же ступени
  (`--sf-text-size-*`).
- Загрузка не блокирует остальную страницу и не скрывает уже показанные данные
  без причины.
- Ответ, который старше последнего запроса, отбрасывается: каждый экземпляр
  нумерует свои запросы.
