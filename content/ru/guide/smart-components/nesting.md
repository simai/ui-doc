# Вложенность и составные компоненты

Составной смарт-компонент объединяет несколько элементов в один сценарий. Вложенность может иметь несколько уровней: заказ содержит карточку товара, карточка — выбор количества. По-английски — Composite Smart Component. Он передаёт настройки дочерним компонентам и связывает их события и состояния. Просто разместить несколько компонентов рядом недостаточно. Составной компонент подключается так же, как любой другой смарт-компонент.

## Когда применять

Объединяйте компоненты, когда повторяется целый сценарий с общей логикой. Сам факт вложенности не требует создавать новый уровень API для каждого контейнера.

## Ответственность уровней

Контрол количества сообщает новое число. Карточка отвечает за товар. Заказ связывает карточки с проектными данными. Нижний уровень не должен искать родителя через фиксированное число `parentElement`: такая связь сломается при изменении разметки.

## Готовность и ограничения

Регистрация родителя не гарантирует готовность всех детей. Используйте `customElements.whenDefined(tag)` для определения класса и `whenRendered()` конкретного элемента для его первой отрисовки. Собственное условие готовности составного сценария задавайте явно.

Число уровней браузерной вложенности не равно ограничениям JSON-документа композиции. JSON имеет отдельные лимиты глубины и числа узлов; работающий браузерный класс ещё не означает, что для него зарегистрирован декларативный тип.
