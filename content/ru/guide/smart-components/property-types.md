# Галерея типов свойств

Карточки записей, таблицы, настройки сайта в Larena и формы в других
продуктах рисуют свойства одним набором —
[полями по типу свойства](/ru/guide/smart-components/field-renderers/).
Здесь каждый тип и каждый его вариант показан рядом в двух видах: как
значение читается и как оно правится. Список строится из реестра набора
`SF.fieldRenderers.registry`, поэтому тип, добавленный в выпуск, появляется
здесь сам.

## Все типы

Переключатель «Только чтение» показывает, как поле выглядит, когда менять
его нельзя. Изменения уходят странице-хосту через `setFieldValue`; строка
под таблицей показывает, что хост получил.

## Как читать галерею

- **Тип** — название и код `propertyType`; после точки — `variant`.
- **Просмотр** — `renderViewField`: значение в карточке записи. Пустое
  значение показано прочерком страницы.
- **Правка** — `renderEditField` со ступенью `1/2`: элемент управления
  поля. Поля выбора записи (`user`, `record`, `relation`) получают короткий
  список от хоста; `lookup` берёт варианты из `options`.
- Файлы в галерее только показываются: загрузку хост включает методами
  `startFieldUpload` и `getFieldUploads`.

Что каждый тип принимает и возвращает, описано в таблицах
[значений по типам](/ru/guide/smart-components/field-renderers/#значения-по-типам)
и [изменений через хост](/ru/guide/smart-components/field-renderers/#хост-и-изменения).
