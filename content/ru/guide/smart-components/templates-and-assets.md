# Шаблоны Smart-компонентов

Шаблон определяет внутреннюю разметку Smart-компонента. Обычная поставка уже содержит готовый шаблон, поэтому для стандартного вида ничего настраивать не требуется.

## Когда применять

Подключайте собственный каталог шаблонов, только если проекту нужна другая внутренняя разметка. Наличие отдельных стилей и допустимые параметры всегда проверяйте у конкретного компонента.

## Пример

Задайте общий каталог до создания Smart-компонентов:

```html
<script>
  window.SF_SMART_TEMPLATE_PATH = '/assets/project/smart-templates';
</script>
```

Framework будет искать шаблон внутри этого каталога по имени компонента и выбранному варианту.
