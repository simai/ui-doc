# Шаблоны Smart-компонентов

Шаблон — функция, которая получает данные и возвращает разметку Lit. Поведение остаётся в классе, а шаблон определяет, что увидит пользователь. Стандартный вариант `default` встроен; именованный внешний вариант загружается отдельно.

## Когда применять

Внешний шаблон нужен, когда один сценарий должен иметь проектное представление без копирования всего класса. Сначала проверьте, достаточно ли существующих атрибутов и слотов.

## Папки и выбор имени

При `window.SF_SMART_TEMPLATE_PATH = '/assets/project/smart-templates'` для `<sf-button template="compact">` запрашивается `/assets/project/smart-templates/button/compact/index.js`. Обратите внимание на `button`: имя берётся из тега без префикса `sf-`, а не из имени папки пакета `buttons`.

Необязательные стили находятся рядом в `index.css`. Для локального `project-greeting` полное имя сохраняется: `<base>/project-greeting/compact/index.js`. Пример использует каталог `./assets` только внутри своего изолированного предпросмотра.

## Контракт внешнего модуля

```js
export default function ({ html, context, component }) {
  return html`<p>Здравствуйте, ${context.name}!</p>`;
}
```

Модуль получает `html`, `nothing`, `context`, `component` и `changedAttributes`. Интерполяция текста через `html` экранирует значение. Шаблон является доверенным исполняемым кодом проекта: нельзя подставлять произвольный путь или код пользователя.

Если модуль создаёт собственные подписки или таймеры, экспортируйте функцию
`destroy({ component })`. Базовый класс вызовет её при смене внешнего шаблона и
при удалении компонента со страницы.

## Поведение и ошибки

Выбор `default` использует встроенный шаблон; внешний `default/index.js` не подменяет его автоматически. Если именованный модуль не найден или не экспортирует функцию, текущая реализация возвращается к встроенному шаблону. Поэтому проверяйте фактический внешний вид и сеть, а не только отсутствие падения страницы.

Кеш модулей живёт в пределах загруженной страницы. При обновлении шаблонов меняйте версию пути поставки и перезагружайте страницу. Не путайте этот кеш с долговременным HTTP-кешированием сервера.

Для внешней папки используйте абсолютный URL: `new URL('./assets', document.baseURI).href`. Проверка файла и динамический импорт должны обращаться к одному адресу; простой относительный путь может вычислиться от файла библиотеки. Отсутствующий шаблон приводит к резервному отображению, поэтому проверяйте сам результат, а не только завершение рендеринга.

Загрузка внешнего модуля асинхронна. Если за это время компонент удалён или
пользователь выбрал другой шаблон, устаревший результат не отображается.
