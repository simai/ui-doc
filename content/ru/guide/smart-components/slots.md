# Слоты и передача содержимого

Слот — именованное место для содержимого, которое передаёт пользователь компонента. Компонент решает, какие имена поддерживать и где показывать переданные узлы.

## Когда применять

Слот полезен для иконки, подписи, панели действий или содержимого карточки. Он помогает менять содержимое, сохраняя поведение самого компонента.

## Пример

:::example {label="Подпись библиотечной Smart-кнопки"}
```html
<sf-button text="Резервная подпись">
  <span slot="text">Сохранить <strong>черновик</strong></span>
</sf-button>
```
:::

В шаблоне кнопки проверяется `component.hasSlotContent('text')`, затем содержимое получается через `component.getSlotContent('text')`. Если его нет, используется атрибут `text`. Это подтверждено реализацией кнопки, но не является обещанием такого же слота у всех элементов.

## Два разных контракта

HTML-слот браузерного компонента и `slots` в JSON-макете описываются отдельно. Для декларативного типа допустимые области задаёт manifest типа. Не объявляйте JSON-слоты только потому, что в шаблоне нашлось похожее имя.

Для собственного компонента заранее задайте допустимые имена и поведение при отсутствии содержимого. Передавайте текст как текст или безопасный шаблон; не превращайте пользовательскую строку в произвольный HTML.
