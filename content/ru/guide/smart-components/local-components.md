# Локальные компоненты проекта

Локальный Smart-компонент хранится в вашем проекте и не входит в общую библиотеку. Он использует тот же базовый класс, но имеет собственное имя, исходные файлы и правила подключения.

## Когда применять

Так удобно реализовать карточку товара, панель конкретного сервиса или внутренний редактор, который не нужен всем пользователям Framework.

Сохраните код JavaScript под демонстрацией в `/assets/project/counter.js` и подключите его после Core обычным скриптом. Внутри вызовите `await SF.loadSmartBase()`, затем зарегистрируйте `project-counter`. Это полный ручной способ подключения локального класса: запись в библиотечный список Loader для него не требуется.

```html
<script src="/assets/project/counter.js" defer></script>
<project-counter count="1"></project-counter>
```

## Зависимости и поставка

Локальные классы детей зарегистрируйте до их использования. Для библиотечных `sf-*` элементов укажите путь Smart-поставки, как на странице подключения. Загружайте проектный скрипт один раз и фиксируйте его версию вместе с проектом.

Loader автоматически распознаёт только известные ему правила. Он не выводит путь `/assets/project/counter.js` из имени тега. Если потребуется загрузка по собственным правилам, сначала подтвердите интерфейс расширения Loader; не добавляйте придуманную запись в generated-пакет.
