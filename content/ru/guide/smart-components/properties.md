# Атрибуты, свойства и состояние

Атрибут — строка в HTML, например `count="2"`. Свойство — значение объекта JavaScript. Состояние — текущие данные, от которых зависит показ компонента. Эти способы передачи значений связаны только тогда, когда реализация явно связывает их.

## Когда применять

Простые начальные значения удобно задавать атрибутами. Объекты и массивы передавайте через подтверждённые методы или свойства конкретного компонента. Простое присваивание `element.count = 3` не обязано вызывать перерисовку.

В примере объявлено `count: { type: Number, default: 0 }`. Метод `getProp('count')` читает значение с преобразованием типа. `setAttribute('count', '3')` запускает наблюдаемое обновление. Начальное `count="1"` перекрывает значение по умолчанию.

## Описание входа

`static get props()` возвращает имена с настройками `type`, `default`, `attribute` и при необходимости `values`. Например, `templateName` можно связать с атрибутом `template`. `attribute: false` исключает поле из списка HTML-атрибутов.

Булевы значения проверяйте по контракту компонента: строка `"false"` и отсутствие атрибута не всегда означают одно и то же. Для готовых кнопок используйте описанные `disabled` и `loading`, а не стили, которые только имитируют блокировку.

## Граница состояния

Компонент может хранить открытие панели или выбранное значение. Корзина, права доступа и сохранение на сервере остаются в проекте. После завершения операции проект передаёт результат компоненту.
