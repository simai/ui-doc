# Работа со Smart-компонентами

Smart-компонент — часть интерфейса в виде собственного тега: он сам
подгружается, следит за своими свойствами и перерисовывается. Раздел о том,
как его подключить, настроить и встроить в свою страницу.

## Когда применять

Когда нужен компонент с поведением, а не только с видом: поле, которое
проверяет ввод, таблица, которая сортирует, список, который подгружает данные.

## Пример

Тег ставится в разметку, остальное он делает сам:

```html
<sf-input size="1" label="Название" placeholder="Введите название"></sf-input>
```
