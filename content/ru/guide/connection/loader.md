# Как работает Loader

Loader просматривает разметку страницы, распознаёт используемые классы и обычные компоненты и подключает для них необходимые CSS- и JavaScript-модули. Core загружается первым и создаёт общую основу.

## Когда применять

Обычно Loader не требует ручного управления. Достаточно сохранить структуру каталога `distr`, правильно задать `window.sfPath` и писать классы Framework в итоговой HTML-разметке.

## Пример

```html
<script>
  window.sfPath = '/assets/simai-framework/distr/';
</script>
<script src="/assets/simai-framework/distr/core/js/core.js"></script>

<button class="button p-x-3">Сохранить</button>
```

После загрузки Core Loader находит классы и обычный компонент кнопки и подключает доступные для них модули. [Подключение Smart-компонентов](/ru/guide/smart-components/connection/) описывается отдельно.

## Если `sfPath` не задан

`window.sfPath` должен стоять **до** `core.js` — это единственное, что говорит
рантайму, где лежит ваш каталог `distr`.

Страница без него всё равно поднимется, но возьмёт файлы из
`https://cdn.jsdelivr.net/gh/simai/ui@main/distr/`. `@main` — незакреплённая
ветка: её содержимое меняется без предупреждения, и проект в этот момент
показывает не ту сборку, которую выпустил, а сегодняшнюю. Внешне всё выглядит
рабочим, и отличить это по экрану нельзя.

Поэтому рантайм пишет об этом в консоль:

```
SIMAI Framework: window.sfPath is not set, so the runtime is loading from
https://cdn.jsdelivr.net/gh/simai/ui@main/distr/ — an unpinned branch that
changes without notice. Set window.sfPath to your own copy of distr/, before
core.js, or to a pinned tag.
```

Увидели это сообщение — задайте `sfPath` на свою копию `distr/` или на
закреплённый тег. Если страница действительно должна брать файлы из сети,
укажите тег явно, а не `@main`: готовый HTML с точным тегом во всех трёх
адресах лежит в [быстром старте](/ru/guide/introduction/quick-start/).

Это касается и собранных страниц с примерами: если примеры открываются в
`iframe` со своим документом, `sfPath` нужно задать и там.

Если CSS-файл временно не загрузился из-за сети, Loader убирает незавершённое
подключение и позволяет повторить попытку после перезагрузки страницы. Ошибка
JavaScript сохраняется осторожнее: повторное выполнение частично загруженного
скрипта может создать два обработчика или оставить противоречивое состояние.
