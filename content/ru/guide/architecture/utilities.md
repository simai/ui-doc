# Утилиты

Утилита — короткий CSS-класс, который решает одну задачу: задаёт отступ, размер, цвет, расположение или другое свойство элемента.

## Когда применять

Используйте утилиты для локальной настройки разметки и для вариантов, которым не нужна собственная повторяемая структура компонента.

## Пример

```html
<div class="display-flex gap-3 p-4 bg-surface-container radius-2">
  <span>Название</span>
  <strong>Значение</strong>
</div>
```
