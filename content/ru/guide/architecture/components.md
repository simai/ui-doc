# Компоненты

Компонент объединяет устойчивую HTML-структуру, оформление и варианты одного элемента интерфейса — например кнопки, поля ввода или карточки.

## Когда применять

Выбирайте компонент, когда элемент должен собираться и выглядеть одинаково в разных частях проекта. Для единичной корректировки внутри компонента можно добавить утилиту.
