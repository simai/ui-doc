# Общая схема

SIMAI Framework состоит из уровней, которые добавляют интерфейсу всё больше готовой структуры и поведения. Макет связывает эти уровни в описание целой страницы.

## Когда применять

Используйте эту карту перед реализацией, чтобы выбрать самый простой уровень, который полностью решает задачу.

## Пример

| Уровень | Что даёт | Когда выбирать |
|:---|:---|:---|
| Core | Общие стили, токены, темы и Loader | Всегда как основу страницы |
| Утилиты | Одно точечное свойство в одном классе | Для настройки макета и оформления |
| Компоненты | Готовую структуру повторяемого элемента | Для кнопки, поля, карточки и похожих элементов |
| Smart-компоненты | Состояние, события и интерактивное поведение | Когда CSS и разметки недостаточно |
| Составные смарт-компоненты | Согласованную работу нескольких интерактивных частей | Для повторяемого составного сценария |
| Блоки | Законченную часть страницы | Для повторного использования целого фрагмента страницы |
| Макеты | Дерево страницы из секций, блоков и компонентов | Когда структуру страницы нужно хранить, проверять или собирать из данных |

Макет не заменяет перечисленные уровни: он указывает, из каких частей состоит страница и в каком порядке их показать. Правило выбора остаётся простым: используйте самый простой уровень, который решает задачу без дублирования, а макет добавляйте, когда самой структурой страницы нужно управлять как данными.
