# Framework и проект

SIMAI Framework отвечает за представление и поведение интерфейса. Проект отвечает за данные, права доступа, бизнес-правила и выполнение операций.

## Когда применять

Проверяйте эту границу при проектировании интеграции. Она не даёт переносить бизнес-логику в интерфейс и не связывает Framework с конкретным backend.

## Пример

В каталоге Framework отображает фильтры, карточки товаров, выбранные состояния, загрузку и сообщения об ошибках. Проект получает товары из базы или API, проверяет права, применяет фильтры, рассчитывает доступность и выполняет добавление в корзину. Между ними передаются данные и события, но решение о бизнес-операции остаётся у проекта.
