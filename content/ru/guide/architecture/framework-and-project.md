# Framework и проект

SIMAI Framework показывает элементы интерфейса и управляет их поведением. Проект получает и сохраняет данные, проверяет права и выполняет действия.

## Когда применять

Разделяйте эти задачи до начала разработки. Правила работы сайта должны оставаться в проекте, а Framework не должен зависеть от конкретной серверной части.

## Пример

В каталоге обязанности делятся так:

| Framework показывает | Проект выполняет |
|:---|:---|
| поля фильтра и выбранные значения | получает варианты фильтра и применяет запрос |
| карточки, загрузку и сообщение об ошибке | получает товары и сообщает результат |
| кнопку «В корзину» и её состояния | проверяет права, остаток и сохраняет корзину |

Когда пользователь нажимает кнопку, Framework сообщает проекту о действии. Проект решает, можно ли его выполнить, и возвращает новое состояние интерфейса.
