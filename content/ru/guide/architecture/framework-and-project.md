# Framework и проект

SIMAI Framework показывает элементы интерфейса и управляет их поведением. Проект получает и сохраняет данные, проверяет права и выполняет действия.

## Когда применять

Разделяйте эти задачи до начала разработки. Правила работы сайта должны оставаться в проекте, а Framework не должен зависеть от конкретной серверной части.

## Пример

В каталоге Framework показывает фильтры, карточки товаров, выбранные значения, загрузку и сообщения об ошибках. Проект получает товары из базы или с сервера, проверяет права, применяет фильтры, рассчитывает доступность и добавляет товар в корзину. Framework передаёт проекту действия пользователя, а проект решает, можно ли их выполнить.
