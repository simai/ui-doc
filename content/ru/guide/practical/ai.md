# Работа с ИИ

ИИ помогает найти подходящие возможности Framework, объяснить выбор и собрать черновик разметки. Источником истины остаётся документация установленной версии, а результат необходимо проверить в браузере.

## Когда применять

Используйте ИИ для поиска, прототипирования и ревью. Передавайте ему задачу, версию Framework и ссылки на конкретные страницы. Не разрешайте придумывать отсутствующие классы, параметры или события.

## Пример

```text
Собери панель действий для SIMAI Framework.
Используй только классы и компоненты из указанных страниц документации.
Для каждого решения укажи источник. Не придумывай параметры и способы управления.
Проверь мобильную ширину, клавиатуру и ошибки в Console.
```

После ответа сопоставьте классы с каталогом, запустите пример с настоящим Loader и проверьте нужные состояния интерфейса. Проект по-прежнему получает и сохраняет данные, проверяет права и выполняет действия.

## Где взять документацию для ИИ

Начните с [ai.json](/ai.json). Это индекс AI First 0.1: он перечисляет опубликованные страницы, их адреса, язык и контрольные суммы текстов. На каждой странице есть своя версия: например [ai.json этой страницы](/ru/guide/practical/ai/ai.json) и [текст в Markdown](/ru/guide/practical/ai/ai.md).

Представления Markdown содержат код демонстраций, включая JavaScript и текстовые ресурсы. ИИ не должен угадывать содержимое вкладок по HTML страницы. Точная пара пакетов записана в [файле версий](/ai/framework-lock.json), его контрольная сумма также включена в индекс.

Это машиночитаемая выдача, а не обещание, что любой ИИ автоматически найдёт сайт. Передайте адрес индекса системе с доступом к сайту или загрузите нужные Markdown-файлы вручную. Локальный домен `ui-doc.test` доступен только в вашем окружении; внешняя система без такого доступа его не прочитает.

## Как проверяется актуальность

Команда `composer docs:build` создаёт сайт и AI-выдачу из одних исходников. `composer docs:ai:check` повторно вычисляет тексты и контрольные суммы: изменённый или отсутствующий файл останавливает проверку. В CI отдельно проверяются контракты Framework и примеры. Экспорт не подтверждает правильность любой фразы автоматически: изменение поведения требует содержательного пересмотра связанных уроков.
