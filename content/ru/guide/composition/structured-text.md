# Структурированный текст без HTML

Текст хранится как последовательность обычных фрагментов и ссылок. Для фрагмента можно указать отметки `strong`, `em` или `code`. Готовые теги в документ не записываются: Framework сам создаёт и экранирует HTML.

## Когда применять

Используйте этот формат для заголовков и абзацев, которые должны безопасно отображаться в разных проектах. Он сохраняет смысл текста и не допускает исполняемую разметку.

## Пример

```json
{
  "id": "intro",
  "type": "content.paragraph",
  "data": {
    "content": [
      { "type": "text", "value": "Найдите ", "marks": [] },
      { "type": "text", "value": "нужный товар", "marks": ["strong"] },
      { "type": "link", "href": "/catalog/help/", "children": [{ "type": "text", "value": "Помощь" }] }
    ]
  }
}
```

Разрешены адреса сайта, якоря, `http`, `https`, `mailto` и `tel`. Опасные и файловые адреса отклоняются.
