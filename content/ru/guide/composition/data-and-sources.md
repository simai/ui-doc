# Данные и внешние источники

Документ может указать, какие внешние данные нужны элементу. Ссылка содержит владельца, понятный ему идентификатор, место назначения и ожидаемую ревизию. Самих запросов, паролей и правил доступа в документе нет.

## Когда применять

Используйте внешнюю ссылку, когда карточкам нужны товары, профилю — сведения о пользователе, а списку — записи из проекта. Проект получает данные и проверяет права до передачи результата Framework.

## Пример

```json
{
  "id": "catalog-list",
  "type": "layout.section",
  "bindings": [
    {
      "owner": "project/catalog",
      "ref": "products",
      "target": "items",
      "revision": "42"
    }
  ]
}
```

Framework знает, куда передать результат, но не знает устройство базы и права конкретного проекта.
