# Создание собственного типа

Собственный тип задаёт одно устойчивое имя, поддерживаемые профили, правила данных и свойств, области содержимого, варианты оформления, ресурсы и способ отображения. После регистрации он проверяется так же, как встроенные типы.

## Когда применять

Создавайте тип, когда готового элемента нет и новый элемент будет повторно использоваться. Сначала определите его смысл и публичные свойства, затем допустимых детей и только после этого отображение.

## Пример

```json
{
  "schema": "simai.composition.type-manifest.v1",
  "type": "project.product-grid",
  "version": "1.0.0",
  "category": "component",
  "mode": "composite",
  "profiles": ["ui-layout"],
  "slots": {
    "items": { "min": 0, "max": 100, "categories": ["content"] }
  },
  "renderer": { "kind": "registered", "name": "project.product-grid" },
  "assets": ["project/product-grid"]
}
```

Не принимайте произвольные CSS-классы, готовый HTML и исполняемый код как свойства типа.
