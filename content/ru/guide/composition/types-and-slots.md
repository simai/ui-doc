# Типы и области содержимого

Тип отвечает за смысл элемента и правила его проверки. Описание типа перечисляет допустимые данные, варианты оформления, ресурсы и области для вложенного содержимого. Каждая такая область принимает только разрешённые элементы.

## Когда применять

Проверяйте описание типа, когда выбираете элемент или добавляете ему детей. Это заранее показывает, какие значения и вложения будут приняты.

## Пример

`layout.columns` содержит область `columns`. В ней можно разместить несколько элементов, которые Framework покажет как колонки.

```json
{
  "id": "columns",
  "type": "layout.columns",
  "slots": {
    "columns": [
      { "id": "left", "type": "content.paragraph", "data": { "content": [{ "type": "text", "value": "Фильтры" }] } },
      { "id": "right", "type": "content.paragraph", "data": { "content": [{ "type": "text", "value": "Товары" }] } }
    ]
  }
}
```
