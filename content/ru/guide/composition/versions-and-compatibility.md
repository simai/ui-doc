# Версии и совместимость

Поле `schema` фиксирует правила документа. После нормализации Framework вычисляет SHA-256 хеш: одинаковые данные всегда дают одинаковое значение. Изменение схемы, описания типа или примера требует повторной проверки документации и потребителей.

## Когда применять

Проверяйте совместимость перед обновлением Framework, подключением нового типа или обменом документами между проектами. Храните точную версию поставки рядом с документом или выпуском проекта.

## Пример

```js
const checked = SF.Composition.validate(document, registry);
const normalized = await SF.Composition.normalize(document, registry);

if (checked.valid) {
  console.log(normalized.digest);
}
```

Неизвестное необязательное расширение с собственным пространством имён сохраняется. Неизвестная обязательная возможность должна остановить обработку.
