# Что такое декларативная композиция

Декларативная композиция — это способ описать страницу обычными данными. В документе указано, какие элементы нужны и как они вложены друг в друга. Framework проверяет это описание и собирает HTML.

## Когда применять

Используйте композицию, когда устройство страницы нужно хранить, передавать между системами или редактировать без записи готового HTML. Она подходит для страниц, блоков и структурированного текста.

## Пример

Каталог можно описать как страницу с секцией, заголовком и карточками. Документ хранит структуру, Framework показывает её, а проект предоставляет товары и решает, что разрешено пользователю.

```json
{
  "schema": "simai.composition.document.v1",
  "id": "catalog",
  "profile": "ui-layout",
  "root": { "id": "page", "type": "layout.page" }
}
```
