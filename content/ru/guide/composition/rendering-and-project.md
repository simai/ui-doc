# От документа к странице

Framework проверяет документ, приводит его к устойчивому виду и превращает элементы в HTML. Вместе с разметкой он возвращает список нужных ресурсов, сведения для интерактивных элементов и найденные ошибки.

## Когда применять

Эта граница нужна при подключении композиции к сайту или системе управления. Она помогает не смешивать устройство интерфейса с хранением данных, правами и публикацией.

## Пример

На странице каталога Framework рисует фильтры и карточки. Проект загружает товары, скрывает недоступные позиции, сохраняет черновик и публикует страницу. Если тип неизвестен или для него нет способа отображения, обработка завершается ошибкой.

```js
const result = await SF.Composition.render(document, {
  resolveBinding: (link) => projectData.resolve(link)
});
page.innerHTML = result.html;
```
