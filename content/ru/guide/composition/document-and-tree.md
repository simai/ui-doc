# Документ и дерево элементов

Документ содержит служебные сведения и один корневой элемент `root`. Каждый элемент имеет уникальные `id` и `type`. Вложенные элементы лежат в именованных областях, а их порядок совпадает с порядком в массиве.

## Когда применять

Эта схема нужна при создании документа, сохранении страницы или разборе ошибки проверки. Она позволяет однозначно найти каждый элемент и его место.

## Пример

В секции сначала идёт заголовок, затем абзац. Значение `sort` не нужно: порядок уже задан массивом.

```json
{
  "id": "section-main",
  "type": "layout.section",
  "slots": {
    "default": [
      { "id": "title", "type": "content.heading", "data": { "level": 1, "content": [{ "type": "text", "value": "Каталог" }] } },
      { "id": "intro", "type": "content.paragraph", "data": { "content": [{ "type": "text", "value": "Выберите товар" }] } }
    ]
  }
}
```
