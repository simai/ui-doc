# Глоссарий

Глоссарий определяет термины SIMAI Framework, которые используются в
руководстве. Для каждого термина указаны английское название или имя в коде,
краткое определение и глава, где термин объяснён подробно. Латинские имена,
у которых нет русского названия, собраны в конце таблицы.

| Термин | Англ. / в коде | Что это | Где |
|:---|:---|:---|:---|
| Адаптивная ступень | `--sf-space-1`, `--sf-text--size-1` | Ступень шкалы с парой значений: для мобильного и для настольного режима | [Адаптивные размеры](/ru/guide/size-and-type/adaptive-sizing/) |
| Блок | block | Пример компоновки на определённую тему, который проект хранит и повторно использует как шаблон Recipe; не тип Framework и не отдельный уровень, своей схемы нет | [Макеты и блоки](/ru/guide/introduction/levels/#макеты-и-блоки), [Блок](/ru/guide/layouts/building/block/) |
| Браузерная проба | browser probe | Проверка, которая открывает страницу в настоящем браузере и измеряет нарисованное | [Браузерные пробы](/ru/guide/standards/framework-checks/#браузерные-пробы) |
| Версия стандарта | `version` | Полная версия издания стандарта `<старшая>.<младшая>.<исправление>`, записана отдельно от `id` | [Конверт](/ru/guide/standards/what-is/#конверт), [Имена и версии](/ru/guide/standards/map/#имена-и-версии) |

| Вертикальный контракт | `simai.vertical-sizing` | Машиночитаемый контракт кегля, высоты строки, высоты контролов и интервалов | [Вертикальный контракт](/ru/guide/size-and-type/adaptive-sizing/#вертикальный-контракт) |

| Гейт владельца | owner gate | Все слои проверок, через которые проходит изменение Framework; ядро — `npm test` | [Гейт владельца](/ru/guide/standards/framework-checks/#гейт-владельца) |
| Гейт документации | docs gate | Правило: изменение публичного контракта обновляет документацию в той же поставке | [Гейт документации](/ru/guide/standards/framework-checks/#гейт-документации) |
| Граница контрола | `--sf-outline` | Роль границы элемента, который человек должен найти; держит 3 : 1 | [Границы](/ru/guide/colour/colour-roles/#границы), [Границы](/ru/guide/size-and-type/borders-and-radii/#границы) |
| Граница области | `--sf-outline-variant` | Тихая роль края области и линий внутри неё | [Границы](/ru/guide/colour/colour-roles/#границы), [Границы](/ru/guide/size-and-type/borders-and-radii/#границы) |
| Дизайн-токен | design token, `--sf-*` | Именованная CSS-переменная, хранящая одно дизайнерское решение | [Дизайн-токены](/ru/guide/colour/design-tokens/) |

| Имя формата | `schema` | Имя формата данных без версии, вида `simai.<имя>` | [Имена и версии](/ru/guide/standards/map/#имена-и-версии) |
