# Цветовые примитивы

Сгенерированные с помощью описанной выше методики цвета записываются в цветовые примитивы — CSS-переменные, используемые
для формирования токенов. Такой под
од обеспечивает гибкое и понятное управление цветовыми параметрами интерфейса.
