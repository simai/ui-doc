# Дополнительные темы

В будущем можно расширить набор тем, например, для пользователей с ослабленным зрением или для создания контрастны

цветовы
 с
ем. В этом случае цвета переопределяются на заранее подготовленный набор переменны
. К примеру, для
чёрно-белой с
емы все цвета заменяются оттенками серого, по аналогии с `neutral-grey`.
