# Основные роли

* **Surface** — фоновая роль для крупны
 областей (фон сайта или его частей). Имеет низкий акцент и основана на
  нейтральны
 цвета
.
* **Primary** — главный акцентный цвет, выделяющий самые важные элементы.
* **Secondary** — вторичный акцентный цвет, более приглушённый. Используется для часто повторяющи
ся элементов
  интерфейса.
* **Tertiary** — цвет-антагонист к primary, выделяет элементы рядом с primary, придавая композиции визуальный баланс.
* **Error** — цвет для индикации ошибок или серьёзны
 проблем.
* **Warning** — цвет для предупреждений.
* **Success** — цвет, указывающий на успешное состояние.
