# Focus

Роль Focus используется для визуализации фокуса на элементе. Фокус во всём
Framework рисуется как `outline` из одной тройки токенов и появляется **только
при работе с клавиатуры** (`:focus-visible`), а не при щелчке мышью.

Компонент не изобретает своё кольцо: он берёт эти переменные. Элемент, стоящий
вплотную к соседям — сегмент группы кнопок, ячейка, вкладка, — поворачивает то
же кольцо внутрь отрицательным смещением, а не заводит второе.

![Роль Focus в светлой и тёмной темах][image28]

Переменные для роли Focus:

| Переменная           | Значение (light)           | Значение (dark)            |
|:---------------------|:---------------------------|:---------------------------|
| `--sf-focus--color`  | `--sf-primary-50--alfa-24` | `--sf-primary-90--alfa-24` |
| `--sf-focus--width`  | `--sf-a4`                  | `--sf-a4`                  |
| `--sf-focus--style`  | `solid`                    | `solid`                    |
| `--sf-focus--offset` | `--sf-a0`                  | `--sf-a0`                  |

Кольцо собирается так:

```css
.project-control:focus-visible {
    outline: var(--sf-focus--width) var(--sf-focus--style) var(--sf-focus--color);
    outline-offset: var(--sf-focus--offset);
}
```

Если элемент прижат к соседям, меняется только знак смещения:

```css
.project-segment:focus-visible {
    outline-offset: calc(var(--sf-focus--width) * -1);
}
```

Токен `--sf-ui-focus` — прежнее теневое кольцо. Он сохранён для совместимости,
новых мест ему не отдают: тень рисует кольцо поверх макета другим способом и
расходится с тем, как выглядят компоненты.

В утилитах тот же выбор есть у классов: `focus-visible:ring-*` и
`focus-visible:outline-*` срабатывают только с клавиатуры. Вариант `focus:*`
сохранён и считается устаревшим — он срабатывает и при щелчке мышью.
