# Библиотека блоков письма

:badge[sf-mail-library]{variant=outline scheme=on-surface size=1/2} :badge[1.0.7]{variant=outline scheme=on-surface size=1/2}

Библиотека показывает блоки, которые можно добавить в письмо, по группам
назначения, с чипами категорий, поиском по названию и описанию и вариантами шапки
и подвала. Строка сообщает, что выбрал человек, а куда вставить блок, решает
приложение: сама библиотека `<sf-mail-library>` письмо не меняет.

**Компонент Pro.** Входит в [SIMAI Pro](/ru/pro/), а не в выпуск SIMAI
Framework: поставляется пакетом `pro` из репозитория `simai/ui-pro`.
Лицензия и подключение — на странице [Pro](/ru/pro/#лицензия).

## Разметка

В разметке — только тег; блоки передаёт скрипт свойствами на языке человека.

- `groups` — `{id, title}`, группы в порядке показа. Строка, чьей группы здесь
  нет, не показывается.
- `items` — `{type, title, purpose, icon, group, sample}`, блоки по одной строке;
  `sample` необязателен.
- `places` — места, которые есть в каждом письме: `{family, title, current, items}`.

## Варианты

### Категория

`category` — `all` или `id` одной группы; чипы над списком переключают его сами. Чипы стоят одной строкой, лишние прокручиваются.
Пока выбрана категория, раздел шапки и подвала скрыт: категория — про содержание.
`id`, которого нет среди групп, показывает все группы, поэтому устаревший фильтр
не оставит список пустым.

:::example {id="smart-components/mail-library/category" label="Выбрана категория «Товары»"}
:::

### Одна группа

Чипы рисуются, только если групп больше одной.

:::example {id="smart-components/mail-library/one-group" label="Одна группа, без чипов"}
:::

## Состояния

### Ничего не найдено

`query` — слова поиска; поле внутри элемента записывает его, пока человек
печатает. Блок находится по названию, назначению и типу. Группа, в которой не
осталось строк, не рисуется; если не осталось ничего, элемент говорит «Ничего не
найдено».

:::example {id="smart-components/mail-library/nothing-found" label="Поиск без результата"}
:::

## Поведение

### Данные и события

- `sf-mail-library-add` — `{type}`, строка добавляет свой блок;
- `sf-mail-library-replace` — `{family, type}`, выбран другой вариант шапки или
  подвала. Заменяет приложение — одним шагом, который можно отменить, — и передаёт
  новый `current` обратно в `places`.

```js
const library = document.querySelector('sf-mail-library');
library.groups = [{id: 'basics', title: 'Основа'}, {id: 'commerce', title: 'Товары'}];
library.items = [
  {type: 'heading', title: 'Заголовок', purpose: 'Главная мысль письма', icon: 'title', group: 'basics'},
  {type: 'price', title: 'Цена', purpose: 'Цена и старая цена', icon: 'sell', group: 'commerce'},
];
library.addEventListener('sf-mail-library-add', (event) => addBlock(event.detail.type));
library.addEventListener('sf-mail-library-replace', (event) => {
  replaceVariant(event.detail.family, event.detail.type);
  library.places = currentPlaces();
});
```

### Шапка и подвал

Вариант из `current` отмечен галочкой и не предлагается повторно: нажатие на него
ничего не сообщает. Раздел виден только при категории «Все».

### Действия

Приложение может сделать то же, что человек: `search {query}`, `filter {category}`,
`add {type}` и `replace {family, type}`. Неизвестный блок или вариант отклоняется
ответом `refused unknown`, текущий вариант — ответом `refused current`.

## Доступность

- Порядок `Tab`: поле поиска, чипы, затем каждая строка — обычная кнопка; `Enter`
  и `Space` добавляют блок или меняют вариант.
- Выбранный чип и текущий вариант отмечены `aria-pressed="true"`.
- Группа — `role="group"` с названием. Имя кнопки — её же слова, название и
  назначение блока, затем действие, поэтому голосовая команда с названием блока до
  неё доходит.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `query` | строка | пусто | — | Слова поиска; поле внутри элемента записывает их, пока человек печатает. Блок находится по названию, назначению и типу. |
| `category` | строка | `all` | — | `all` или `id` одной группы, как задал бы её сегмент в переключателе категорий. `id`, которого нет ни у одной группы, показывает все, поэтому устаревший фильтр не оставит библиотеку пустой. |
| `items` | список: объект | `[]` | — | Блоки, которые может принять письмо, по одной строке: `{type, title, purpose, icon, group, sample?}`, словами человека. Строка, чьей группы нет в `groups`, не показывается. |
| `groups` | список: объект | `[]` | — | Группы в порядке показа: `{id, title}`. Если их больше одной, над строками рисуется переключатель категорий: «Все» и по сегменту на группу. |
| `places` | список: объект | `[]` | — | Места, которые есть в каждом письме («Шапка», «Подвал»), и их варианты: `{family, title, current, items: [{type, title, purpose, icon}]}`. Текущий вариант отмечен и не предлагается снова; видны только при «Все». |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | `default` | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `search(args: object)` | объект | Ищет, как поле: задаёт `query` и сразу фильтрует. |
| `filter(args: object)` | объект | Показывает одну группу или все, как её сегмент в переключателе категорий. |
| `add(args: object)` | объект | Добавляет блок, как его строка: отправляет `add {type}`; `refused unknown`, если такого блока нет. |
| `replace(args: object)` | объект | Выбирает вариант места, как его строка: отправляет `replace {family, type}`; `refused current` для варианта, который сейчас в письме. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-mail-library-add` | `{ type: any }` | Выбран блок, который нужно добавить: `{type}`. Приложение добавляет его туда, куда решит; сам элемент письмо не меняет. |
| `sf-mail-library-replace` | `{ family: any, type: any }` | Выбран другой вариант места: `{family, type}`. Блок заменяет приложение; вариант, который сейчас в письме, ничего не сообщает. |
