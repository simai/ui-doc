# Письма

- [Список писем](/ru/pro/mail/mail-letters/) — Письма человека в редакторе: поиск по названию, порядок и действия строки — открыть, копия, переименование, удаление.
- [Библиотека блоков письма](/ru/pro/mail/mail-library/) — Блоки, которые можно добавить в письмо, по группам, с чипами категорий, поиском и вариантами шапки и подвала.
- [Структура письма](/ru/pro/mail/mail-structure/) — Параметры письма, строки блоков в порядке письма и способ добавить блок; письмо меняет приложение.
- [Холст письма](/ru/pro/mail/mail-canvas/) — Готовое письмо в рамке, которая ничего не запускает, переключатель ширины, заметки и слой выбора блоков.
- [Панель свойств письма](/ru/pro/mail/mail-inspector/) — Заголовок с действиями, путь, вкладки, разделы и поля редактора писем, нарисованные из данных приложения.
