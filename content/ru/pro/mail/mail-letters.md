# Список писем

:badge[sf-mail-letters]{variant=outline scheme=on-surface size=1/2} :badge[1.0.8]{variant=outline scheme=on-surface size=1/2}

Список писем показывает письма человека в редакторе писем: поиск по названию,
порядок и то, что предлагает строка, — «Открыть» и под ⋯ копия, переименование
и удаление. Список `<sf-mail-letters>` не хранит писем и ничего не делает сам: он сообщает, что
выбрал человек, а письма передаёт и меняет приложение.

**Компонент Pro.** Входит в [SIMAI Pro](/ru/pro/), а не в выпуск SIMAI
Framework: поставляется пакетом `pro` из репозитория `simai/ui-pro`.
Лицензия и подключение — на странице [Pro](/ru/pro/#лицензия).

## Разметка

В разметке — только тег; письма передаёт скрипт свойством `letters`.

- Письмо — `{id, title, at, blocks}`. `at` — момент изменения, а не фраза:
  строка сама пишет «5 минут назад» на языке страницы. `blocks` — число блоков,
  строка сама подбирает форму слова: «1 блок», «4 блока», «7 блоков».
- `current` называет письмо, открытое в редакторе.

## Варианты

### Порядок

`order` — `changed`, сначала изменённые, или `title`, по названию с сортировкой
по языку страницы. Список порядка внутри элемента записывает этот атрибут сам.

## Состояния

### Ничего не найдено

`query` — поиск по названию; поле внутри элемента записывает его, пока человек
печатает. Если по запросу ничего нет, элемент говорит «Ничего не найдено».

:::example {id="smart-components/mail-letters/nothing-found" label="Поиск без результата"}
:::

### Пусто

Если писем нет совсем, элемент говорит «Писем пока нет» и оставляет кнопку
«Новое письмо». Это разные состояния, и человек видит, какое из них его.

:::example {id="smart-components/mail-letters/empty" label="Писем ещё нет"}
:::

## Поведение

### Данные и события

Всё, что делает человек, приходит событиями; письмо меняет приложение и передаёт
новый список в `letters`:

- `sf-mail-letters-open` — `{id}`, нажали «Открыть»;
- `sf-mail-letters-copy` — `{id}`, «Копия» под ⋯;
- `sf-mail-letters-rename` — `{id}`, «Переименовать» под ⋯; новое название
  спрашивает приложение;
- `sf-mail-letters-delete` — `{ids: [id], id}`, «Удалить» под ⋯; подтверждает и
  удаляет приложение;
- `sf-mail-letters-create` — «Новое письмо».

```js
const list = document.querySelector('sf-mail-letters');
list.letters = await api.letters();
list.addEventListener('sf-mail-letters-open', (event) => {
  openLetter(event.detail.id);
  list.setAttribute('current', event.detail.id);
});
list.addEventListener('sf-mail-letters-delete', async (event) => {
  if (await confirmDelete(event.detail.id)) list.letters = await api.remove(event.detail.id);
});
```

### Открытое письмо

Строка письма из `current` отмечена, говорит «открыто сейчас» словами, а не
только цветом, и не предлагает «Открыть».

### Поиск и порядок

Второго поля поиска или списка порядка рядом не рисуют: приложение задаёт те же
`query` и `order` атрибутами или действиями `search {query}` и `sort {order}`.
Неизвестный порядок действие отклоняет с ответом `refused unknown`.

## Доступность

- Порядок `Tab`: сначала панель — поиск, порядок, «Новое письмо», — затем у каждой
  строки «Открыть» и ⋯.
- Меню строки — `sf-menu-context` со своей клавиатурой.
- Имя кнопки ⋯ называет письмо: «Действия с письмом: <название>», поэтому две
  строки не звучат одинаково.

## Справочник

### Атрибуты

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `query` | строка | пусто | — | Поиск по названию; поле внутри элемента записывает его, пока человек печатает. |
| `order` | строка | `changed` | `changed`, `title` | `changed` (сначала новые) или `title` (по названию, с сортировкой по языку страницы); список порядка внутри элемента записывает его сам. |
| `current` | строка | пусто | — | Письмо, открытое в редакторе: его строка отмечена, говорит «открыто сейчас» и не предлагает «Открыть». |
| `letters` | список: объект | `[]` | — | Письма, по одной строке: `{id, title, at, blocks}`. `at` — момент изменения письма; строка записывает его («5 минут назад») и число блоков («4 блока») на языке страницы. |

#### Общие для всех компонентов

| Атрибут | Тип | По умолчанию | Значения | Что делает |
|:---|:---|:---|:---|:---|
| `template` | строка | `default` | `default` | Имя шаблона отрисовки; `default` — встроенный. |
| `root-class` | строка | пусто | — | Свои CSS-классы для нарисованного элемента. |
| `root-style` | строка | пусто | — | Свои стили для нарисованного элемента, например `max-width: 20rem`. |

Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `icon-start` — `iconStart`. Свойство атрибута `template` называется `templateName`.

### Методы

| Метод | Возвращает | Что делает |
|:---|:---|:---|
| `search(query: string)` | объект | Ищет, как поле: задаёт `query`. |
| `sort(order: any)` | объект | Упорядочивает строки, как список порядка; `refused unknown` для порядка, отличного от `changed` и `title`. |
| `choose(action: any, id: any)` | объект | Делает то же, что строка или панель: отправляет `open`, `copy`, `rename`, `delete` или `create`; `refused current` при открытии уже открытого письма. |

### События

События приходят на сам элемент и всплывают; глаголы в именах — из [общего словаря](/ru/guide/smart-components/names/). Общие события базового элемента — в главе [Модель компонента](/ru/guide/smart-components/model/#базовый-интерфейс).

| Событие | `detail` | Когда приходит |
|:---|:---|:---|
| `sf-mail-letters-open` | `{ id: any }` | Открыть это письмо: `{id}`. Текущее письмо не предлагается. |
| `sf-mail-letters-copy` | `{ id: any }` | Сделать копию этого письма: `{id}`. |
| `sf-mail-letters-rename` | `{ id: any }` | Переименовать это письмо: `{id}`. Новое название спрашивает приложение. |
| `sf-mail-letters-delete` | `{ ids: array, id: any }` | Удалить это письмо: `{ids: [id], id}`. Подтверждает и удаляет приложение. |
| `sf-mail-letters-create` | пустой объект | Запрошено новое письмо. |
