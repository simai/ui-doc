# Pro

> Компоненты Pro переходят в [наборы компонентов](/ru/guide/sets/): `admin`,
> `view`, `chat`, `mail`, `editor`. У каждого набора будет свой сайт с
> документацией и демонстрациями. Пока сайта набора нет, его компоненты
> описаны здесь, а пакет `pro` подключает их все сразу.

SIMAI Pro — большие смарт-компоненты для продуктов SIMAI: админка, чат,
конструктор писем и редактор страниц. Они построены на SIMAI Framework и
устроены так же, как его смарт-компоненты, но поставляются отдельно и под
другой лицензией. На каждой странице этого раздела стоит пометка «Компонент
Pro».

## Лицензия

SIMAI Framework распространяется по лицензии Apache-2.0. Компоненты Pro
бесплатны для малого бизнеса (PolyForm Small Business 1.0.0) и для
некоммерческого использования (PolyForm Noncommercial 1.0.0). Остальным нужна
коммерческая лицензия SIMAI — её выдают по запросу. В составе Larena
компоненты используются по лицензии Larena.

## Подключение

Компоненты Pro лежат в репозитории `simai/ui-pro` и собираются в пакет
компонентов, который Loader знает под именем `pro`. Каждая сборка пакета
делается поверх одного выпуска SIMAI Framework и публикуется выпуском
репозитория `simai/ui-pro` вместе с контрольной суммой. Пакет объявляют
до подключения Core:

```html
<script>
  window.SF_BOOT_CONFIG = {packages: {pro: {base: '/assets/pro/<коммит пакета>/smart'}}};
</script>
```

Подробнее — в разделе
[Подключение смарт-компонентов](/ru/guide/smart-components/page/#подключение-к-странице).
