# Редактор страниц

- [Редактор страниц](/ru/pro/editor/editor/) — Единый редактор блоков страницы: раскладка и текст — один документ, глубина вместо режимов.
- [Редактор содержимого](/ru/pro/editor/content-editor/) — Страница набирается одним потоком: блоки, меню «/» и «+», параметры блока; документ сохраняет приложение.
- [Свои блоки](/ru/pro/editor/blocks/) — как сделать свой блок для каталога редактора: шаблон, генератор и проверка.
