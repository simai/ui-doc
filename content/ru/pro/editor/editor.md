# Редактор страниц

:badge[sf-editor]{type=tonal scheme=primary size=1/2} :badge[1.2.0]{type=outline scheme=on-surface size=1/2}

`<sf-editor>` — единый редактор блоков страницы SIMAI: раскладка и текст —
один документ и один редактор. Режимов нет, есть глубина: щелчок по тексту —
печать, щелчок рядом — выбор блока, `Esc` — уровень вверх, `Enter` — вниз.

Элемент ничего не хранит: после каждого изменения он отправляет `change` с
новым документом, а сохраняет хост. Режим одного потока текста — отдельный
компонент [Редактор содержимого](/ru/pro/editor/content-editor/); свои блоки
для каталога редактора описывает страница [Свои блоки](/ru/pro/editor/blocks/).

## Данные

```js
editor.document = doc;           // Composition Document, профиль ui-layout
editor.types = [cardsType];      // свои типы блоков хоста
editor.renderers = {'site.cards': renderCards};
editor.editorManifests = [cardsEditor];
editor.siteBlocks = savedBlocks; // блоки сайта из конструктора
editor.words = {ru: {...}, en: {...}};
editor.rights = {layout: true, template: false, builder: true};
editor.theme = {name: 'brand', label: 'Фирменная', settings_url: '/admin/theme', defaults: {}};
editor.addEventListener('change', (event) => save(event.detail.document, event.detail.scope));
editor.addEventListener('sf-editor-block-save', (event) => keepBlock(event.detail.manifest, event.detail.words));
editor.connectPort({sources, fields, preview, saveBlock});
```

Страница с шаблоном сайта — `layout.regions` с областями `banner`, `main` и
`contentinfo`. Шапка и подвал — шаблон: они приглушены с замком и меняются
только явно, кнопкой «Изменить шаблон» (`edit-template`). `change` с
`scope: 'template'` — изменение шапки или подвала всех страниц.

## Панель и места хоста

Сверху одна строка: отмена и повтор, переключатель экранов по центру,
справка, результат и тема — кнопками со значком. Свои элементы хоста
(переключатель списка страниц, языка) ставятся в ту же строку через места
(slots) — второй строки у хоста нет:

```html
<sf-editor>
  <sf-button-icon slot="start" icon="menu" aria-label="Страницы"></sf-button-icon>
  <sf-dropdown slot="actions" size="1/2" aria-label="Язык"></sf-dropdown>
</sf-editor>
```

- `start` — в начале строки, перед отменой и повтором;
- `actions` — в конце строки, перед справкой, результатом и темой;
- `page` — свои настройки страницы в панели справа, пока ни один блок не
  выбран (см. [Настройки страницы](#настройки-страницы)).

Элементы мест забираются при первом подключении элемента (как у
`sf-header-page`); добавленные позже ставятся через `setSlot(name, element)`.
Размер элементов в строке — `1/2`.

Название страницы и подпись под ним хост передаёт настройками `heading` и
`caption` — они стоят в начале строки, как в прототипе:

```html
<sf-editor heading="Главная" caption="Страница сайта · черновик"></sf-editor>
```

«Изменить шаблон» — тихая текстовая ссылка рядом, без значка.

Библиотека слева — разделы SIMAI Framework со значком и числом блоков
(`CATALOGUE_GROUPS`, `CATALOGUE_GROUP_TABLE`), избранное (пустое — с короткой подсказкой) и недавние сверху.
Раздел открывается на месте, с «Назад»; найденное поиском подписано
разделом. Варианты блока — карточки с картинкой из дерева варианта.

Страница — лист с тенью на спокойном фоне. Выбранный блок обведён, над ним —
плавающая панель: путь, ручка, вверх, вниз, копия, «Ещё». Панель справа —
значок, имя и раздел блока, вкладки «Параметры», «JSON», «HTML», поля в
группах «Содержимое», «Расположение», «Дополнительно»; у каждого поля —
точка происхождения значения, «Сбросить» и привязка SIMAI Framework мелким
моноширинным шрифтом. «Сбросить» возвращает значение варианта, если блок
вставлен вариантом, затем темы и типа. У экземпляра блока сайта — только
открытые конструктором параметры, без «Дополнительных классов».

## Настройки страницы

Пока ни один блок не выбран, панель справа показывает настройки самой
страницы, если хост передал их свойством `pageSettings` (атрибут
`page-settings`) или разметкой в месте `page`:

```js
editor.pageSettings = {
  name: 'Главная', address: '/', status: 'черновик · изменения не опубликованы',
  template: {value: 'main', options: [{value: 'main', text: 'Основной: шапка и подвал'}, {value: 'none', text: 'Без шапки и подвала'}]},
  theme: {label: 'Обычная', settings_url: '/admin/site'},
  publish: {note: 'Пока страница не опубликована, посетители видят прошлую версию.'},
  history: {count: 12},
};
editor.addEventListener('sf-editor-page-change', (event) => savePage(event.detail.key, event.detail.value));
editor.addEventListener('sf-editor-page-action', (event) => event.detail.action === 'publish' ? publish() : openHistory());
```

Каждый ключ необязателен: чего нет, того нет в панели. Шаблон со списком
`options` — выпадающий список, без него — только название. Тема — название и
ссылка на её настройки. Редактор ничего не хранит: изменение названия, адреса
или шаблона приходит событием `sf-editor-page-change` с `{key, value}`
(`key` — `name`, `address` или `template`), нажатие «Опубликовать» или
«История» — событием `sf-editor-page-action` с `{action}` (`publish` или
`history`). Хост сохраняет изменение и задаёт `pageSettings` заново. Без
настроек и без содержимого в месте `page` панель показывает короткую
подсказку.

```html
<sf-editor>
  <div slot="page">…свои настройки страницы…</div>
</sf-editor>
```

## Права и тема

Права приходят от хоста, переключателя ролей в редакторе нет.
`layout: false` — автор пишет только внутри текстовых областей
(`layout.area`), остальное приглушено с замком и объяснением.
`reasons` заменяют объяснения замка словами хоста.

Тема только читается: её значения по умолчанию — один из уровней
происхождения значения, её атрибуты ставятся на нарисованную страницу.
`settings_url` ведёт туда, где тему меняют.

## Вставка, перемещение, колонки

Один каталог открывается тремя путями: «+» между блоками, «/» в пустой
строке и библиотека слева (перетаскиванием или нажатием). «+» и «/»
показывают тот же список разделов, что библиотека: раздел со значком и числом
блоков открывается на месте, «Назад» (или `←` и `Backspace` в пустом поиске)
возвращает к разделам, найденное поиском подписано разделом. «/» в тексте
сразу открывает раздел «Текст». Тип с `catalogue.also_in` (например, кнопка)
стоит и в своём разделе, и в перечисленных; в поиске — один раз. Раздел, где
ничего не подходит месту, скрыт.

Блок двигают за ручку с линией места, Alt+↑↓ у выбранного блока и
Alt+Shift+↑↓ во время набора. Сброс к боковому краю соседнего блока делит
место на колонки; «Разделить на колонки» есть в меню ручки и в панели.

## Параметры и данные

Панель справа показывает у каждого значения, откуда оно: тип, тема, вариант,
блок, экран. Переключатель экранов (компьютер, планшет, телефон) задаёт, для
какого экрана пишется значение, и показывает страницу на этом экране.
Вкладка «Данные» связывает блок с источником хоста через порт источников:
источник, сопоставление полей, сколько, текст на пустой случай, состояние
предпросмотра (данные, пусто, ошибка, загрузка) и связь с блоком той же
секции. Блок сам ничего не загружает.

## Конструктор блоков

«Создать свой блок» или «Сделать блоком сайта» открывает конструктор: блок
собирается из тех же частей, для автора открываются выбранные параметры,
блок сохраняется как блок сайта (`sf-editor-block-save`). Изменение блока
сайта сохраняется новой версией и переносит все его экземпляры на странице
(`upgradeComposed`), сохраняя тексты и значения автора.

## Результат

«Результат» показывает страницу как JSON, как HTML с классами утилит и как
Markdown текстовых областей; то же даёт действие `output`.

## Клавиши

| Где | Клавиша | Что делает |
|:---|:---|:---|
| страница | Enter / Esc | вниз / вверх по глубине |
| страница | ↑ ↓ | соседний блок |
| страница | Alt+↑↓ | переместить блок |
| страница | ⌫, ⌘D | удалить, дублировать |
| текст | Enter, ⌫ в начале | разделить, соединить |
| текст | / | каталог |
| текст | Alt+Shift+↑↓ | переместить блок, не прерывая набор |
| везде | ⌘Z, ⇧⌘Z | одна история для текста и структуры |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, нарисованному компонентом.
- `root-style` — `string`, по умолчанию пусто. Объявления стиля, которые ставятся корневому элементу, нарисованному компонентом, в том числе пользовательские свойства.
- `screen` — `string`, по умолчанию `desktop`, значения: `desktop`, `tablet`, `phone`. Экран, для которого рисуется страница и задаются значения: desktop (lg), tablet (md), phone (xs).
- `preferences-key` — `string`, по умолчанию пусто. Где хранятся избранные и недавние блоки через SF.Preferences (sf-editor/&lt;key&gt;); пусто — только на время сеанса.
- `heading` — `string`, по умолчанию пусто. Название редактируемой страницы в начале верхней строки (имя страницы у хоста).
- `caption` — `string`, по умолчанию пусто. Короткая строка под названием: где живёт страница или её состояние (слова хоста).
- `label` — `string`. Доступное имя страницы.
- `document` — `object`, по умолчанию `null`. Страница: Composition Document профиля ui-layout (layout.page или layout.regions с областями banner, main и contentinfo для страницы с шаблоном сайта). Новый документ начинает новую правку; документ, который редактор сам отправил в change, узнаётся и сохраняется.
- `types` — `array`, по умолчанию `[]`. Свои типы блоков хоста рядом с типами SIMAI Framework; их отрисовщики приходят в renderers.
- `renderers` — `object`, по умолчанию `null`. Отрисовщики типов хоста: страница рисуется ими так, как её рисует сайт.
- `editor-manifests` — `array` из `object`, по умолчанию `[]`. Манифесты редактора композиции для типов хоста или заменяющие манифесты SIMAI Framework: по ним строится панель параметров.
- `site-blocks` — `array`, по умолчанию `[]`. Собственные блоки сайта из конструктора блоков; в каталоге предлагается новейшая версия каждого.
- `words` — `object`, по умолчанию `null`. Слова блоков хоста по локалям.
- `rights` — `object`, по умолчанию `null`. Что человеку можно менять, по данным хоста: layout false позволяет автору писать только внутри текстовых областей; template false держит шаблон сайта закрытым; builder false скрывает конструктор блоков. Переключателя ролей в редакторе нет.
- `theme` — `object`, по умолчанию `null`. Тема сайта: её значения по умолчанию — один из уровней происхождения значения, её атрибуты ставятся на нарисованную страницу. Редактор её никогда не меняет; settings_url ведёт туда, где её меняют.
- `page-settings` — `object`, по умолчанию `null`. Собственные настройки страницы, которые панель параметров показывает, пока ни один блок не выбран: название и адрес (изменяются), шаблон сайта (список, если переданы `options`), тема со ссылкой туда, где её меняют, публикация и история. Редактор ничего не хранит: изменение и нажатие приходят событиями `page-change` и `page-action`; хост сохраняет и задаёт настройки заново. Без них (и без содержимого в месте `page`) панель показывает короткую подсказку.

### Методы

- `select(id: any)` — возвращает `object`. Выбирает блок так же, как нажатие; без id выбор снимается.
- `edit(id: any)` — возвращает `object`. Ставит курсор в конец текстового блока.
- `insert(type: string, variant: any, after: any)` — возвращает `object`. Добавляет блок типа (и варианта) после блока или туда, где он первым подходит; значение — id нового блока.
- `undo()` — возвращает `object`. Шаг назад, как ⌘Z: набор текста и структура — одна история.
- `redo()` — возвращает `object`. Шаг вперёд, как ⇧⌘Z.
- `setParameter(id: any, key: string, value: string, screen: any)` — возвращает `object`. Задаёт параметр блока, для экрана — если значение различается по экранам.
- `editTemplate(on: boolean)` — возвращает `object`. Начинает (или, при false, заканчивает) правку шаблона сайта: шапки и подвала всех страниц.
- `buildBlock(id: any, type: string)` — возвращает `object`. Открывает конструктор блоков: новый блок сайта, блок из выбранного блока или блок сайта, который нужно изменить везде.
- `output(format: any)` — возвращает `object`. Страница как JSON, HTML (классы утилит) или Markdown её текстовых областей; значение — текст.

### События

Все события приходят на сам элемент и всплывают. Что означает глагол в имени события, говорит общий словарь: [Имена и общие слова](/ru/guide/smart-components/names/). Общие события базового элемента перечислены в главе [Модель компонента → Базовый интерфейс](/ru/guide/smart-components/model/#базовый-интерфейс).

- `change` — `detail`: `{ document: object, reason: string, scope: any }`. Страница изменилась: {document, reason, scope}. Хост сохраняет документ; scope template означает шапку или подвал всех страниц.
- `sf-editor-select` — `detail`: `{ ids: array }`. Выбран блок: {ids}; пусто, если не выбран ни один.
- `sf-editor-block-save` — `detail`: `{ manifest: object, words: object, changes: array }`. Сохранён блок сайта: {manifest, words, changes}. Сохраните манифест в site-blocks.
- `sf-editor-page-change` — `detail`: `{ key: any, value: string }`. Изменилась настройка страницы: `{key: name | address | template, value}`. Сохраните её и задайте `page-settings` заново.
- `sf-editor-page-action` — `detail`: `{ action: any }`. Нажата кнопка публикации или истории: `{action: publish | history}`. Действует хост.

### Доступность

- Роль: группа (`group`).
- Доступное имя: внутренний.
- Клавиши: `Tab`, `Enter`, `Escape`, `ArrowUp`, `ArrowDown`, `Alt+ArrowUp`, `Alt+ArrowDown`, `Meta+Z`.
- Фокус: Страница — одна остановка Tab; Enter и Esc двигают по глубине, стрелки — по соседям; панели — элементы управления SIMAI Framework в порядке Tab; изменения сообщаются в строке состояния.

### Минимальная разметка

```html
<sf-editor id="page"></sf-editor> <script>page.document = doc; page.addEventListener('change', (e) => save(e.detail.document));</script>
```
