# Анимация при появлении


При помощи пакета классов `animation` в SIMAI Framework вы можете задать анимацию появления элемента; с классом
`animation-on-view` она срабатывает, когда элемент появляется в зоне видимости окна браузера. Также есть возможность указать бесконечный повтор анимации.

## Классы и их значения

| Класс     | Значение                                                                                                      |
|:----------|:----------------------------------------------------------------------------------------------------------------------------------|
| animation | Запускает анимацию при отрисовке элемента.                                                                                        |
| animation-on-view | Вместе с `animation` откладывает анимацию до появления элемента в зоне видимости; замена класса `wow` из прошлой версии. |
| infinite  | Повторяет анимацию бесконечно.                                                                                                    |

## Описание

Используя класс `animation`, элемент будет анимирован при отрисовке; с классом `animation-on-view` — при появлении в зоне видимости окна браузера. Если добавить к нему
класс `infinite`, анимация будет повторяться без остановки.

## Синтаксис

Использование модификатора: `{animation}` и при необходимости `{infinite}`

```html
<div class="animation infinite">
    Этот блок анимируется при появлении и делает это бесконечно.
</div>
```

## Пример использования

```html
<div class="animation p-2 radius-1/3 bg-primary color-on-surface-inverse">
    Появляюсь с анимацией!
</div>

<div class="animation infinite p-2 radius-1/3 bg-secondary color-on-surface-inverse">
    Появляюсь с анимацией и повторяюсь бесконечно!
</div>
```
