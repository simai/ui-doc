# Reverse translation (pixels to alpha-numeric)

1. **Find the zone:**  
   Example: 56px.  
   Thresholds: 56 > 40 and < 80, so this is zone D.

2. **Subtract the start:**  
   For D it is 40, so 56 - 40 = 16.

3. **Divide by the multiplier:**  
   Multiplier for D = 4.  
   16 ÷ 4 = 4 → so `d4`.
