# Quickstart

A short route for your first steps:

1. Connect CSS and JS as described in [Installation](/ru/guide/connection/project-setup/).
2. Open any example from the [Playground](/en/start/playground/) and copy the markup.
3. Add a few basic modifiers (spacing, colors, typography) and check responsiveness across breakpoints.

Next, move on to [Fundamentals](/ru/guide/) to learn grids and breakpoints for building responsive interfaces.
