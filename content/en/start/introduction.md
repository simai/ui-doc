- [Installation](/en/start/installation/) — basic steps to connect UI Utilities.

- [Playground](/en/start/playground/) — links to interactive examples and ways to run them.
- [Project setup](/en/start/project-setup/) — structure, environment, and useful commands.
- Loader — SFLoader architecture and settings.

After starting, continue with [Fundamentals](/en/fundamentals/) and the [Utilities reference](/en/utilities/).
