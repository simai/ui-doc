# Полнота раздела «Основы» SIMAI Framework

## Цель

Сделать русскую версию раздела «Основы» полноценной точкой входа в систему
значений SIMAI Framework 5.4 и сверить справочные данные с актуальным CSS ядра.

## Границы

- только русская документация;
- раздел «Основы» и его связи с уже существующей документацией утилит;
- компоненты и смарт-компоненты не входят в этот пакет;
- публикация, push и production deploy не входят в этот пакет.

## Источники

- текущая документация `ui-doc`;
- фактические переменные `ui/distr/core/css/core.css` на ревизии `1f6ed1ff`;
- исходное полное описание утилит версии 5.3 как контроль полноты тем.

## Что должно быть сделано

- размерная шкала `--sf-a0` — `--sf-i9` полностью перечислена и доступна из меню;
- описаны служебные размеры, интервалы, контейнеры, радиусы, иконки и уровни;
- перечислены актуальные цветовые палитры и объяснены семантические роли тем;
- заполнены справочники контрольных точек и типографической шкалы;
- параметры модификаторов и система дизайн-токенов доступны из меню;
- индекс раздела объясняет рекомендуемый порядок чтения;
- production-сборка и внутренние ссылки проходят проверку без новых ошибок.

## Особенность маршрутизации

Federation route ошибочно выбрал бухгалтерский owner для задачи документации.
Работа ведётся по raw-source fallback: Docara как владелец структуры
документации, SIMAI Framework как владелец предметных данных, tester как
контур проверки. Это зафиксированный graph gap, а не изменение предметной
области задачи.

## Результат аудита

В прежнем верхнем меню отсутствовали уже существующие разделы размеров,
параметров модификаторов, сокращений, направлений и выравнивания. Видимые
страницы цветов, контрольных точек и типографики не содержали справочных
значений. Раздел переменных содержал устаревшие примеры и поэтому не был
выведен в меню; вместо него подготовлена актуальная сводная страница
дизайн-токенов.

Документация теперь покрывает 90 из 90 размерных примитивов и все 128 ячеек
восьми сплошных цветовых палитр. Значения проверены по собранному CSS ядра.

## Выявленный долг в исходниках фреймворка

- фактические media query утилит используют 520, 720, 960 и 1140px, тогда как
  переменные `--sf-breakpoint-*` ссылаются на другие размерные примитивы;
- ядро ссылается на `--sf-radius-1/3`, но в том же собранном файле этот токен
  не объявлен;
- в дереве документации остаются скрытые исторические дубли `concept`,
  `color`, `typography` и `variables`; их не следует возвращать в меню без
  отдельной сверки и миграции.

Эти пункты не скрыты правками документации и должны быть вынесены в отдельный
пакет развития исходников/очистки legacy-контента.
