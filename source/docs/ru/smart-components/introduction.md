Что будет добавлено:

- Обзор принципов смарт-компонентов и сценарии использования.
- Примеры шаблонов и настройки зависимостей.
- Советы по кэшированию и работе через загрузчик.
- Точный контракт Badge: размеры, типы, цветовые схемы и иконки.

Раздел развивается, новые страницы появятся по мере подготовки контента.
