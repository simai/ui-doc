# Вертикальный ритм контента

SIMAI Framework задаёт значения интервалов, а родительская композиция выбирает
токен по смысловой связи соседних элементов. Компонент по умолчанию не должен
самостоятельно добавлять внешний отступ: иначе одинаковый компонент невозможно
предсказуемо использовать в разных потоках.

Эта страница синхронизирована с owner-контрактом
`simai.vertical-sizing@1.3.0`, SHA-256
`b70d02d6902345e17954eafb44f24052b7478439184286bed5a8df6c69c1fe45`.

## Семантические токены

| Токен | Роль | Отношение | До 960px | От 960px |
|:---|:---|:---|---:|---:|
| `--sf-content--space-text` | `text` | Обычный ритм текста | 12px | 16px |
| `--sf-content--space-related` | `related` | Тесно связанные элементы одной композиции | 16px | 20px |
| `--sf-content--space-block` | `block` | Самостоятельные блоки внутри одного раздела | 16px | 24px |
| `--sf-content--space-section` | `section` | Переход к новому разделу | 24px | 32px |
{.table}

Значения токенов ссылаются на адаптивную шкалу `--sf-space-*`. Поэтому проект
может изменить шкалу централизованно, не переписывая правила потока.

## Как выбирать интервал

- Текст после текста использует `--sf-content--space-text`.
- Подпись, управляющий элемент или пояснение внутри одного блока используют
  `--sf-content--space-related`.
- Таблица, уведомление, пример, карточка или другой самостоятельный блок рядом
  с самостоятельным блоком используют `--sf-content--space-block`.
- Новый смысловой раздел использует `--sf-content--space-section`.
- Заголовок и относящийся к нему контент остаются одной группой: после
  заголовка используется текстовый интервал, а перед `h2`–`h6` — интервал
  раздела.

Интервал задаётся один раз на границе между соседями. Не складывайте нижний
отступ первого блока с верхним отступом второго.

```css
.article-flow > :where(p, ul, ol) + :where(p, ul, ol) {
    margin-top: var(--sf-content--space-text);
}

.article-flow > [data-content-block] + [data-content-block] {
    margin-top: var(--sf-content--space-block);
}

.article-flow > :where(p, ul, ol, [data-content-block]) + :where(h2, h3, h4, h5, h6) {
    margin-top: var(--sf-content--space-section);
}
```

Селекторы принадлежат проектному потоку и показаны как пример. Framework не
вводит обязательный wrapper-класс и не определяет тип элемента по имени
компонента.

## Заголовки и совместимость

Типографические переменные продолжают работать через новые роли:

- `--sf-text--space-bottom` ссылается на `--sf-content--space-text`;
- `--sf-heading--space-top` ссылается на `--sf-content--space-section`;
- `--sf-heading--space-bottom` ссылается на `--sf-content--space-text`;
- deprecated `--sf-heading--margin` остаётся alias для
  `--sf-heading--space-top`.

Это сохраняет поведение существующих проектов. Новые композиции должны
использовать `--sf-content--space-*`, когда выбирают расстояние между блоками.

## Что не следует делать

- Не задавайте всем компонентам одинаковый `margin-bottom`.
- Не используйте интервал заголовка для каждой пары блочных элементов.
- Не добавляйте локальную числовую шкалу поверх `--sf-space-*`.
- Не меняйте интервалы внутри дочернего компонента, если расстояние описывает
  отношение этого компонента к соседнему элементу.
