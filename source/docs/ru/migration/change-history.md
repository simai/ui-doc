# История версий

## 5.4.0

Текущая редакция документации:

- описывает единую архитектуру SIMAI Framework;
- содержит актуальный раздел «Старт» и документацию загрузчика;
- систематизирует синтаксис модификаторов и условий;
- публикует полный справочник размерной шкалы;
- описывает цветовые роли, темы и дизайн-токены;
- содержит справочник контрольных точек и типографики;
- группирует CSS-утилиты по назначению.

Изменения самого Framework публикуются отдельно вместе с соответствующим
релизом. При обновлении проекта следуйте [порядку обновления](/ru/start/compatibility/).
