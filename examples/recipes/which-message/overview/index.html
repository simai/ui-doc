Полоса — состояние всего продукта. Стоит над шапкой, пока жива причина.

Уведомление — состояние этой страницы или раздела. Стоит в начале страницы.

Всплывающее — короткий ответ на нажатие. Успех уходит сам, ошибка — только по крестику.

Ошибки полей — сводкой над формой и у каждого поля. Всплывающее — только когда сохранение не дошло до сервера.

Центр уведомлений — история. В админке Larena он открывается из меню.

Вопрос — решение человека. Опасный ответ залит, фокус на «Отмене».
